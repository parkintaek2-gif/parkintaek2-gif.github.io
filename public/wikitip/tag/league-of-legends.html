We stopped using the Riot data. Nothing measured here was found to be wrong.

You asked for /tag/league-of-legends. These pages were built on the League of Legends ranked ladder, read through Riot's API. In September 2026 we stopped drawing from that well, so the pages that depended on it could no longer be kept current — and we would rather retire an address than leave a number on it that we can no longer check. The measurements themselves still stand; what changed is our access to the source, not the arithmetic. Esports has not left this site. We still count it, from a well that needs no key: Wikipedia reading. See which countries actually read about esports at /esports-nations.

What we do still hold is the front page.
