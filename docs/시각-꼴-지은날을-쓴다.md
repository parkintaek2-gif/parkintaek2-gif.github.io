# 지면에 시각을 찍을 때는 `지은날()` 을 쓴다 — **새로 만들지 않는다**

> 적은 날 2026-09-08 · 적은 자 5번 (K Culture Wire) · 전 유닛 공용

## 한 줄

**자료에 적힌 시각을 지면에 그대로 찍으면 한국어(「오전」·「오후」)가 손님 화면으로 샌다.**
그것을 바꿔 주는 자가 **이미 있다** — `scripts/lib/kcw-date.mjs` 의 `지은날()`.

```js
import { 지은날 } from '../../lib/kcw-date.mjs';

지은날('2026. 9. 7. 오후 11:58:54')   // → '2026-09-07'
지은날('2026-09-07T14:58:54.000Z')    // → '2026-09-07'
지은날('말이 안 되는 값')              // → null   ⛔ 지어내지 않는다
```

⛔ `null` 이 오면 **아무것도 안 찍는다.** 「알 수 없음」도 안 찍는다.

---

## 왜 이 문서가 생겼나

### 1. 2026-08-09 — 처음 샌 날

손님으로 걸어 보니 영어 지면에 **「Updated 2026. 8. 9. 오전 8:40:57 KST」** 가 박혀 있었다.
「오전」은 한국어다. 영어권 손님을 받는 사이트에서 그 한 낱말이 화면에 있었다.

그때 두 가지가 만들어졌다.

```
scripts/lib/kcw-date.mjs 의 지은날()   고치는 자
check-kcw-korean-leak                  잡는 자
```

`지은날()` 의 머리글에 그때의 판단이 적혀 있다 — **시·분·초는 버리고 날짜만 남긴다.**
까닭은 두 가지다.

- 그것은 **빌드 시각**이지 자료의 날이 아니다. 손님에게 아무 뜻이 없다
- 빌드마다 바뀌어서 **같은 지면이 어제와 다른 수를 보인다**

### 2. 2026-09-08 — 같은 것이 또 샜고, **나는 있는 자를 안 찾았다**

`/attention-share` 를 내면서 앞자료의 `잰때` 를 그대로 찍었다. 그 값이
`2026. 9. 7. 오후 11:58:54` 였다. `check-kcw-korean-leak` 이 「오후」로 배포를 막아 주었다.

⛔ 그런데 나는 **`지은날()` 을 찾지 않고** 자료 파일의 시각을 직접 갈아 끼웠다.
결과는 같았지만 **길이 두 갈래가 됐다** — 다음 사람이 어느 쪽을 밟아야 하는지 모른다.

---

## 그래서 어느 쪽을 밟나

```
① 지면에서 지은날() 을 씌운다              ← 이것이 정본이다
② 그것으로 안 되면 그때 자료를 손댄다        ← 마지막 수단
```

### ⚠ 자료 43개에 그 꼴이 들어 있다 (2026-09-08 실측)

`src/data` 를 훑어 세었다 — `2026. 9. 4. 오후` 꼴이 든 파일이 **43개**다.
그것을 적는 자(`toLocaleString('ko-KR')`)도 20개가 넘는다.

**그러나 이것은 쓸어 고칠 일이 아니다.**

```
⛔ 43개를 쓸어 고치지 않는다 — 지면이 «안 찍는 한» 새지 않는다.
   그리고 남의 자·남의 자료를 내가 고치면 그쪽 세션이 짐작하지 못한다
✅ 할 일은 하나다 — **새 지면에서 시각을 찍을 때 `지은날()` 을 씌운다**
```

⭐ 새로 자를 «적는» 쪽이라면 KST 꼴로 적어 두는 것이 낫다. 아래 한 줄이 그 꼴이다.

```js
/* ⚠ 이 PC 는 이미 KST 다 — 9시간을 더하지 않고 toISOString() 도 쓰지 않는다 */
const 이제 = () => { const d = new Date(); const p = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())} ${p(d.getHours())}:${p(d.getMinutes())} KST`; };
```

## 확인하는 법

```bash
node scripts/check-kcw-korean-leak.mjs      # 지면에 한국어가 샜나 (막는 검사다)
```

⛔ 이 검사가 빨간불이면 배포하지 않는다. 그리고 **자료를 고치기 전에 `지은날()` 을 먼저 본다.**
