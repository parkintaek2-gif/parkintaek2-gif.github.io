# 학교알리미 — 고등학교 **학교별** 숫자를 어디서 어떻게 받나

2026-08-07 KST · 3번(백년지도) 실측
2번 요청: 「받을 곳 한 줄 · 항목 목록 · 계정이나 신청이 필요한지」

---

## Ⅰ. 결론 세 줄

### 1-1. 받을 곳

```
POST https://www.schoolinfo.go.kr/openData.do
     APITYPE=<항목코드> · PBANYR=<공시연도> · SCHULKNDCODE=04(고등학교)
```

- **계정·로그인·본인확인·신청이 필요 없다.** 그냥 열린다.
- robots 확인함 — `User-agent: * / Allow: /`. 막힌 곳이 아니다.
- 이용허락범위 **공공누리 제1유형(출처표시)** — 상업 이용 ○ · 변형 ○.
  (공공데이터포털 15014351 「학교알리미 공개용데이터」)

### 1-2. 열려 있는 항목은 **21개**다 (2024년 공시 · 고등학교)

전부 **학교 한 곳마다 한 줄**이다. 유형 평균이 아니다.

### 1-3. ⛔ **졸업생 진로(진학률·취업률)는 이 길로 못 받는다**

공개용데이터 21개 안에 없다. **에듀데이터서비스(EDSS) 신청+심사**를 거쳐야 한다.
→ 사장님 손이 필요할 수 있는 항목. 아래 Ⅳ.

---

## Ⅱ. 못 쓰는 표를 먼저 잘라낸다

### 2-1. KOSIS `334/DT_33403N_006` — 축이 다르다

직접 받아 봤다.

```
항목        설립별 진학상황
축 「학제및설립별」   계 · 국립 · 공립 · 사립 · 전문대학 · 대학 · 교육대학 · 산업대학 ·
                   각종학교 · 기능대학 · 방송통신대학 · 원격대학 · 사이버대학 ·
                   기술대학 · 사내대학 · 전공대학 · 일반대학원 · 전문/특수대학원
축 「진학상황별」     졸업자 · 진학률 · 진학자 · 국내 · 전문대학 · 대학 · 대학원 · 국외
축 「성별」          계 · 남자 · 여자
```

**고등학교가 축에 없고, 학교 단위도 아니다.** 2번이 같은 시각에 따로 확인한 것과 같다.

### 2-2. ⚠ 제 훑기에 구멍이 있었다 — 같은 실수를 반복하지 않는다

처음에 항목 코드를 `1`~`40` 으로 훑고 **「2024년에는 10개만 공시」**라고 적을 뻔했다. 틀렸다.

```
⛔ 실제 코드는 `04`·`08`·`09` 처럼 **앞에 0 이 붙는다** — `4`·`8`·`9` 로 치면 「미공시」가 돌아온다
⛔ 코드가 **40 을 넘는다** — 51 · 55 · 58 · 62 · 63 · 64 · 73 · 90 · 94
```

다시 훑으니 10개가 아니라 **21개**였다. 「입학생 현황」·「성별 학생수」·「장학금 수혜」를
통째로 놓칠 뻔했다. **「없다」고 적기 전에 코드 표기와 범위를 먼저 본다.**

## Ⅳ. 🔴 졸업생 진로 — 이것만 다른 길이다

「이 학교 졸업생이 어디로 갔나」는 **공개용데이터 21개에 없다.** 두 번 확인했다.

```
8/6  화면에서 항목 이름 31개를 다 열어 봤다 — 없다
8/7  API 로 항목 코드를 전부 훑었다 (앞의 구멍을 메운 뒤) — 없다
```

받으려면 **에듀데이터서비스(EDSS · edss.moe.go.kr)** 로 가야 하고, 거기는
**신청 + 심사**가 있다. 즉 이 자리에서 코드로 뚫리는 것이 아니다.

⚠ 아직 **신청 자체를 해 보지 않았다.** 계정·심사 요건이 어디까지인지 못 쟀다.
   「못 받는다」가 아니라 **「이 길로는 못 받고, 저 길은 아직 안 열어 봤다」**가 지금 상태다.

## Ⅴ. 그래서 고교 지면에 지금 실린 것

```
학업중단률           2,371곳  (항목 10 · 8/6)
학급당 학생          2,369곳  (항목 09 · 8/7)
수업교원 1인당 학생   2,369곳  (항목 09 · 8/7)
```

- 2,525곳 중 못 이은 8곳은 **못 이은 채로 둔다.** 이름이 양쪽에 둘씩이라 짐작해 붙이면
  남의 학교 숫자가 그 학교 지면에 나간다.
- 학생 0명으로 공시된 2곳(효령고·울산삼일고)은 **자료에서 뺐다.** 남겨 두면 지면에
  「0명 · 0개 학급」이 사실처럼 나간다. **0 으로 채우지 않는다.**
- 지면에 「졸업생이 어디로 갔는지는 공개용데이터에 없다. 받으면 넣겠다」를 적어 뒀다.
  **비워 두는 것보다 왜 비었는지 적는 것이 낫다**(2번 지시).
