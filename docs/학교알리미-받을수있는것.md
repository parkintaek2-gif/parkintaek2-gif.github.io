**고등학교가 축에 없고, 학교 단위도 아니다.** 2번이 같은 시각에 따로 확인한 것과 같다.

### 2-2. 🔴 제가 **두 번 틀렸습니다** — 원인이 같습니다

이 절은 지우지 않고 그대로 둔다. 같은 함정에 세 번째로 빠지지 않기 위해서다.

**① 코드 범위를 잘못 훑었다**

```
⛔ `1`~`40` 만 훑었다. 실제 코드는 `04`·`08`·`09` 처럼 **앞에 0 이 붙고**,
   `51`·`52`·`55`·`62`·`63`·`64`·`73`·`90`·`94` 처럼 **40 을 넘는다**
→ 「10개만 공시」로 적을 뻔했다
```

**② 항목 이름을 잘못 긁었다**

```
⛔ 화면에서 `value="숫자">이름` 꼴로 긁었다 → **37개**만 잡혔고 `52` 가 빠졌다
✅ `JG_HANGMOK_CD` 로 제대로 짝지으니 **55개**였고 그 안에 「졸업생의 진로 현황」이 있었다
```

**그래서 「졸업생 진로는 공개용데이터에 없다」고 두 번 결론 내고 문서·메모·지면 2,369장에
그렇게 적었다. 틀렸다.** 열려 있었고, 계정도 신청도 필요 없었다.

> ⭐ **「없다」는 결론은 「있다」보다 검증이 더 필요하다.**
> 「있다」는 한 건만 보이면 참이지만, 「없다」는 **내가 전부 봤다는 것**이 참이어야 한다.
> 없다고 적기 전에 **대상보다 내 자를 먼저 의심한다.**
> (1번이 같은 날 「값이 이상하면 대상보다 자를 먼저 의심하라」고 넘겨 준 것과 같은 건이다)

## Ⅳ. 항목 52 「졸업생의 진로 현황」 — 칸 뜻을 확정한 근거

### 4-1. 공식 정의 (학교알리미 설명문 · 고등학교)

```
졸업자 = 진학자(등록자) + 취업자 + 기타
진학자 = 전문대학 + 대학교 + 국외진학     (1학생 1학교 등록 원칙)
취업자 = 1개월 근로시간 60시간 이상 + 그에 대한 소득 (정규·비정규·자영업 포함)
기타   = 진학에 속하지 않는 경우 등        ← **재수생이 여기 들어간다**
```

### 4-2. 🔴 국외진학 칸은 **자리가 고정돼 있지 않다**

같은 표 안에서 학교마다 `TOTAL5` 에도 `TOTAL6` 에도 들어간다(실측 14건 대 251건).
`TOTAL5` 로 못 박았더니 **269곳에서 합이 안 맞았다.**

```
⛔ 인덱스 칸(TOTAL5·TOTAL6)을 믿지 않는다
✅ 이름 있는 칸을 쓴다 — TOT_SUM(진학 계) · OUT_TOT_SUM(국외)
   → `TOTAL3 + TOTAL4 + OUT_TOT_SUM = TOT_SUM` 이 **2,076행 전부** 맞는다
```

### 4-3. 🔴 취업·기타 칸도 **자리가 흔들린다** — 갈라서 싣지 않는다

```
분당중앙고    졸 216 · 진학 109 · TOTAL7 107 · TOTAL8  0   → 7 을 취업으로 읽으면 「취업 49.5%」
서울사대부고   졸 224 · 진학 165 · TOTAL7   0 · TOTAL8 59   → 8 이 나머지를 다 갖는다
수지고        졸 371 · 진학 226 · TOTAL7 124 · TOTAL8 21   → 지면에 「취업 33.4%」가 찍혔다
```

셋 다 학군지 일반고다. 「취업 49.5%」는 있을 수 없다. **나머지가 통째로 한 칸에 들어가는데
그 칸이 7 이기도 8 이기도 하다.** 일반고 1,350곳 중 831곳이 `TOTAL7` 이 0 이다.

⚠ **총합만 보면 안 걸린다** — 전국 `TOTAL7` 1.7% · `TOTAL8` 20.1% 로 오히려 그럴듯하다.
  지면을 렌더해 수지고에 「취업 33.4%」가 찍힌 것을 **눈으로 보고서야** 잡았다.
  **총합이 맞아도 개별이 틀릴 수 있다.**

⛔ 그래서 취업률을 **내지 않는다.** `그 밖 = 졸업자 − 진학` 으로만 적는다 —
  이 값은 칸 자리와 무관하게 항상 맞는다.

### 4-3-1. ⚠ 이 절이 만들어진 경위 — **셸이 백틱을 또 먹었다**

이 절을 `node -e` 안의 문자열로 쓰다가 셸이 백틱 안 내용을 전부 삼켰다. 오늘 여섯 번째다.
⛔ **긴 마크다운은 Write/Edit 로 쓴다.** 셸 문자열로 쓰지 않는다. 규칙이 있는데 내가 어겼다.

### 4-4. ⚠ 이 표에 **직업계고는 거의 없다** — 빠뜨린 것이 아니다

```
항목 09  특성화고 487곳
항목 52  특성화고 **4곳**
```

직업계고 졸업자 진로는 **별도 조사**(직업계고 졸업자 취업통계 · KOSIS 920024)로 간다.
우리는 그것을 이미 `/work` 지면에 쓰고 있다. **갈래가 다른 것이지 어긋난 것이 아니다.**
⛔ 두 숫자를 빼서 견주지 않는다. **재는 자가 다르다.** 그 말을 지면에도 적었다.
