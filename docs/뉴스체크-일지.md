## 2026-08-29 (13:4x — 국민연금 원천 직접확인 시도)

- ⛔ 신조: 보도 인용(107.37%)만으로 서둘러 안 씀 — «우리가 직접 뽑은 재현 가능한 수치»가 기사 근간. 지금은 fund-level 27.22%만 자체확인, 자산군 분해는 미확인.
- **블록·다음 경로**: ① 브라우저(claude-in-chrome) 연결되면 fund.nps.or.kr 렌더해 자산군별·적립금 직접 확인 ② 대안: KOSIS/data.go.kr 에 국민연금 기금 운용현황 표 있는지 탐침(있으면 API로 자체수집=최선). 둘 중 되는 대로 기사화.

## 2026-08-30 (11:2x — 가계동향/소득분배 착수·보류)
가계동향 원표(DT_1L9U103)·소득분배지표표(**DT_1HDALF05**) 확인. 후자가 우리가 원하는 그 지표를 정확히 담음: 5분위배율(ITM20)·지니계수(10)·상대빈곤율(90)·팔마비율(51), 그리고 **시장소득(T001) vs 처분가능소득(T002)** = 세금·이전이 불평등을 얼마나 줄이나(남 안 쓴 축, 강한 각도).
🔴 **보류 사유(신조: 못 재면 못 잰다고 적는다):** 이 표의 **objL 파라미터가 표준 statisticsData 메타(type=OBJ/OBJ_L1)로 안 잡히고**, objL1=ALL/구체값 모두 err21(잘못된 변수). API 자동수집이 막혀 지금은 우리가 뽑은 재현 수치를 못 만든다. ⛔ 틀린 불평등 수치 안 냄.
**다음경로:** KOSIS 포털 파라미터 빌더(지표 화면의 «OpenAPI» 버튼)로 objL 정확 코드 확보 → build-income-distribution 수집기 → «시장 vs 처분 불평등 격차» 롱테일. 브라우저 연결 시 포털에서 확인 가능.
