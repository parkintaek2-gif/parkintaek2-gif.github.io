# 검색 등록 · 콘텐츠 유통 계획

사이트 쪽에서 자동화할 수 있는 건 이미 코드에 다 들어가 있다(사이트맵·RSS·JSON-LD·IndexNow 키).
아래는 **계정 로그인이 필요해 제가 대신 못 하는 것**과, **어디에 유통할지**의 판단이다.

| 항목 | 위치 | 상태 |

## B. 사장님이 직접 해주셔야 하는 등록 (로그인 필요)

순서대로 하면 된다. 전부 무료.

### 1. Google Search Console — 제일 중요
1. https://search.google.com/search-console → 속성 추가 → **도메인** 방식
2. Google이 주는 TXT 레코드를 Spaceship DNS에 추가
3. 확인되면 **Sitemaps** 메뉴 → `sitemap.xml` 제출
4. 색인 생성 → URL 검사로 첫 기사 1건 수동 요청

### 2. Bing Webmaster Tools
1. https://www.bing.com/webmasters → **Import from Google Search Console** (한 번에 끝난다)
2. IndexNow 메뉴에서 키가 자동 인식되는지 확인
- Bing 등록은 ChatGPT·Copilot 검색 노출로도 연결된다. 생각보다 값이 크다.

### 3. Naver 서치어드바이저
1. https://searchadvisor.naver.com → 사이트 등록 → HTML 태그 또는 DNS 확인
2. 사이트맵 · RSS 둘 다 제출
- 영문 사이트라 네이버 유입 기대치는 낮다. 다만 "한국 증시 영문" 검색은 한국 거주 외국인이
  네이버로도 찾는다. 등록 비용이 0이니 해둔다.

### 4. Google News Publisher Center — 중기 과제
- https://publishercenter.google.com
- **기사가 20~30건 쌓이고 발행 주기가 안정된 뒤에 신청한다.** 빈 사이트로 신청하면 반려되고
  재신청에 시간이 걸린다.
- 신청 전 필수: About에 실제 법인·주소·연락처, 기사별 저자·발행일, 정정(Corrections) 정책.
  → **셋 다 이미 About 페이지에 넣어놨다.** PLACEHOLDER만 채우면 된다.

### 5. Google AdSense — 수익화
- 기사 15~20건 이상, 발행 이력 1개월 이상일 때 신청하는 게 승인률이 높다.
- 승인되면 `src/consts.ts` 의 `ADS.client` 와 `ADS.slots` 두 곳만 채운다.
  광고 슬롯(헤더 아래 1개, 본문 중간 1개)은 이미 자리를 잡아뒀고, 미설정 상태에서는
  빈 박스를 그리지 않는다.

## C. 발행할 때마다 돌릴 것

```bash
npm run build && npm run indexnow
```
Bing·Yandex·Naver·Seznam에 새 URL을 즉시 통보한다. (구글은 IndexNow를 안 받는다 —
구글은 사이트맵과 Search Console 경로로 간다.)

## D. 콘텐츠 유통처 추천

지시서에 나온 Benzinga·IBN 말고도 쓸 만한 곳이 있다. **비용 대비 순서**로 정리했다.

### 1순위 — 지금 바로, 무료

| 채널 | 왜 |
|---|---|
| **Reddit** r/investing, r/stocks, r/SecurityAnalysis, r/korea | 미국 개인투자자 밀도가 가장 높다. 단, 자기 글 도배하면 밴 당한다. 커뮤니티에서 먼저 댓글로 활동한 뒤 주 1~2건만 올린다. |
| **Hacker News** | 데이터저널리즘·방법론 글은 먹힌다. 시세 기사는 안 먹힌다. 기사 성격을 골라 올린다. |
| **X(구 트위터) FinTwit** | 기사당 차트 1장 + 핵심 문장 1줄. 이 사이트는 차트가 강점이니 잘 맞는다. |
| **LinkedIn** | 기관·리서치 쪽 독자. 거시 기사와 궁합이 좋다. |
| **Substack 크로스포스트** | 요약 + 원문 링크만. 이메일 구독자 명단은 검색 순위와 무관하게 남는 자산이다. |

### 2순위 — 자동 유입, 설정만 하면 끝

| 채널 | 방법 |
|---|---|
| **Flipboard** | RSS(`/rss.xml`)를 매거진에 연결. 미국 모바일 트래픽이 꾸준히 들어온다. |
| **Feedly / Inoreader** | RSS가 있으면 자동 등재. 별도 신청 불필요. |
| **Apple News Publisher** | 무료. RSS 연동 가능. 미국 iOS 독자 대상이면 값이 있다. |
| **Medium 크로스포스트** | canonical URL을 원문으로 지정해야 SEO 중복 문제가 없다. |

### 3순위 — 유료 신디케이션 (기사 30건 이상 쌓인 뒤 판단)

| 채널 | 비고 |
|---|---|
| **Benzinga Contributor** | 지시서에 언급된 곳. 금융 특화. 기고 승인 절차가 있다. |
| **IBN / InvestorBrandNetwork** | 배포망은 넓지만 건당 비용이 든다. |
| **PR Newswire / Business Wire** | 보도자료용이다. **기사 유통용으로는 돈 낭비다.** 쓰지 말 것. |

### 하지 말 것
- 기사 전문을 외부에 통째로 재게시하는 것. **중복 콘텐츠로 원문이 밀려난다.**
  RSS는 이미 요약(dek)만 내보내도록 짜뒀다.
- 링크 구매·게스트포스트 대량 살포. 금융(YMYL) 사이트는 이걸로 제재당하면 회복이 어렵다.

## E. 현실적인 기대치

검색 유입은 **최소 3~6개월** 걸린다. 금융 YMYL은 신규 도메인 신뢰도 쌓는 데 시간이 더 든다.
초기 트래픽은 위 1순위 채널(레딧·X·링크드인)에서 나온다고 보고, 검색은 그 뒤에 붙는다.

이 사이트의 차별점은 속보가 아니라 **"출처와 기준시각을 매 기사에 박아둔 것"** 이다.
유통할 때도 그 점을 앞세우는 게 맞다 — 속보로 경쟁하면 데이터가 T+1이라 진다.
