```

## 3-2. 매일

### ① 목표 진도 (⛔ 「했나」가 아니라 **「닿았나」**)
```

□ 🔴 하루치에 못 미친 채널이 있나 → **까닭을 그 자리에 캐묻는다**(⛔ 내가 대신 만들지 않는다)

### ② 사장님 지시 실현 대장
```
□ 오늘 받은 지시를 한 줄씩 적는다 (원문 그대로)
□ 어제까지 받은 지시 중 **아직 실현 안 된 것**을 세운다 → 누가 언제까지인지 적는다
□ 🔴 사흘 넘게 안 닫힌 지시가 있나 → 그것부터 오늘 친다
```

### ③ 밖에 나간 것 검사 (⛔ 내가 만들지 않아도 **내가 잰다**)
```
□ 어제 올라간 콘텐츠의 **숫자가 지면 주소로 뒷받침되나** (⛔ 못 대면 내린다)
□ 제목·설명이 속과 맞나 (2026-08-08 내가 틀린 제목을 올렸다)
□ 답 안 한 댓글 (24시간 넘은 것)
□ 유입 꼬리 — ⛔ **utm_source·utm_medium·utm_campaign** 이 빠진 링크가 있나 (from= 만으로는 GA4 가 못 읽는다)
```

### ④ 집 안 점검
```
□ 사이트 넷 200 · /v1/research 200        □ npm test 초록 · 안 불리는 검사 수(늘었나)
□ 배포 대기 0 · 락이 20분 넘게 잡혀 있나   □ 자료 수집기 어제치가 비었나(Riot·연금 등)
□ 지면 흠 — 까닭 없는 빈 칸 · 끊긴 링크 수
```

### ⑤ 보고
```

⛔ 사장님께 콘텐츠·채널·리포트·사이트·매출을 여쭙지 않는다. 결과만 올린다
```
