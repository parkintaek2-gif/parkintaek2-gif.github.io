# 6번(SeoulMarkets) — 데이터 판매 외 새 매출원 기획 (2번 52019)

> 사장님 원칙: 「상품 퀄리티를 높이거나 더 좋은 새 상품을 만들지 못하면 잘못 경영한 것」.
> ⛔ 강령: **1차 데이터만 쓴다 · 투자자문이 아니다.** 자문·추천으로 버는 갈래는 넣지 않는다.
> 기존(제외): P1·P3·P7 데이터셋 라이선스 판매($188/$330). 아래는 **그 외** 갈래.

## A. 디스플레이 광고 (콘텐츠 매체 매출)
```
① 무엇을   기사 38편(→40편)의 페이지 광고. AdSense 로 시작, 트래픽 크면 직접 광고
② 누구에게  광고주는 구글 네트워크(자동). 우리 지면 = 재무·금융 독자 → 핀테크·증권·B2B SaaS 광고 단가 높음
③ 얼마에   RPM(1,000뷰당) $2~8(금융 콘텐츠). 매출 = 월 페이지뷰 × RPM/1000
④ 매출    2027: 월 3만뷰×$4 ≈ $120/월(연 $1.4k)  ·  2029: 월 20만뷰 ≈ $9.6k/년  ·  2032: 월 80만뷰 ≈ $46k/년
⑤ 무너지는 조건  검색 유입이 안 큰다(현재 유입 낮음). 트래픽 없으면 광고도 0. ⚠ 이 갈래는 트래픽에 전적으로 종속
강령  콘텐츠 옆 광고 = 매체 매출. 투자자문 아님. ⛔ 광고가 기사 신뢰를 해치지 않게 밀도 제한
```

## B. 데이터 임베드 위젯 라이선스
```
① 무엇을   우리 표·차트(업종 노동패널·목표주가 적중률 등)를 다른 사이트에 임베드하는 위젯. 월 구독
② 누구에게  ⓐ 경제·산업 매체(우리 데이터를 자기 기사에 임베드) ⓑ 핀테크 앱(종목 화면에 우리 지표)
           ⓒ HR·리서치 SaaS. 국내 경제매체 ~30·핀테크 ~50 = 셀 수 있는 후보 ~80
③ 얼마에   위젯 라이선스 월 $99~$499(트래픽·위젯 수별). 출처표기가 우리 브랜드 노출도 됨
④ 매출    2027: 3곳×$200/월 ≈ $7.2k/년  ·  2029: 15곳 ≈ $36k/년  ·  2032: 40곳 ≈ $120k/년
⑤ 무너지는 조건  임베드 대신 스크린샷으로 무단 사용. → 위젯에 실시간 갱신·상호작용을 넣어 임베드가 더 낫게
강령  데이터 표시일 뿐 투자자문 아님. 위젯에 「투자자문 아님」 자동 고지
```

## C. 스폰서드 데이터 리포트 (브랜디드, 투자자문 아님)
```
① 무엇을   기관이 후원해 특정 주제의 데이터 리포트를 우리가 만들어 공개(후원사 로고·서문). 데이터·방법은 우리 것
② 누구에게  ⓐ 협회·정책기관(노동·산업 데이터 필요) ⓑ HR·컨설팅펌(업종 임금 벤치마크) ⓒ ESG 평가사
           ⛔ 증권사 후원은 받되 「종목 추천」은 절대 안 함(강령). 후원사가 결론에 개입 못 함을 계약에 명시
③ 얼마에   리포트 1건 $5k~$20k(범위·기간별)
④ 매출    2027: 2건 ≈ $20k/년  ·  2029: 6건 ≈ $70k/년  ·  2032: 15건 ≈ $180k/년
⑤ 무너지는 조건  후원사가 결론을 흔들려 함 → 신뢰 훼손. 계약에 「데이터·결론은 우리 것, 후원은 주제·비용만」 못 박음
강령  후원은 주제·비용까지. 결론·추천은 안 판다. 투자자문 아님
```

## 합계 매출 예상 (데이터 판매 제외, 위 A+B+C)
```
2027 ≈ $28k   ·   2029 ≈ $116k   ·   2032 ≈ $346k
```
⚠ 전부 **가정**이다(현재 유입·계약 0). 셋의 공통 병목 = **트래픽·평판**. 그래서 기사·소셜(오늘 한 것)이 매출의 뿌리다.

## ⛔ 안 하는 것 (강령)
투자자문·종목추천·유료 리딩·자문 구독. 후원이라도 결론 개입 불가. 1차 데이터 밖 갈래 없음.

## 왜 돈을 내나 (2번 53282 · 고객 지불 이유)
```
A 광고     광고주가 사는 것은 지면이 아니라 독자다. 우리 독자 = 금융·산업 데이터를 읽는
          의사결정자(운용·IR·핀테크). 이 층에 닿는 단가가 일반 지면보다 높다 —
          「누가 읽나」를 사는 것이라 돈이 된다.
B 임베드    매체·핀테크가 사는 것은 「직접 만들지 않아도 되는 신뢰 데이터」다. 우리 표를 자기
          지면에 넣으면 체류·신뢰가 오르고, 라이선스료가 자체 구축·유지 비용보다 싸다.
          출처표기가 우리 노출이 되니 양쪽에 값이 선다.
C 스폰서드   후원사가 사는 것은 「중립 기관의 방법론과 이름」이다. 자체 발간은 「자기 자랑」으로
          읽히지만, 우리 데이터·결론에 로고만 얹으면 신뢰가 옮는다. 결론을 못 흔들기에
          오히려 값이 있다 — 흔들 수 있으면 후원사도 안 산다.
```
공통: 셋 다 **「우리가 이미 만든 것」의 재판매**라 한계비용이 낮다. 데이터셋 판매와 같은 자산을 다른 값으로 판다.
