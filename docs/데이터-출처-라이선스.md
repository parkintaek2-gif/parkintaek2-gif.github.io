# 데이터 출처 라이선스 확인 결과

실제 광고 매출이 유의미해지면 변호사 검토를 한 번 받는 것을 권한다.

## 1. 쓸 수 있는 것 — 공공데이터포털 금융위원회 시세 API

금융위원회가 공공데이터포털에 등재한 시세 API 계열이다. 원 데이터는 한국거래소가
생산하지만, **금융위원회 명의로 공공데이터로 개방되어 있고 이용허락범위가 명시적으로
"제한 없음"** 이다. 비용은 무료이고 활용신청은 자동승인된다.

- [금융위원회_주식시세정보](https://www.data.go.kr/data/15094808/openapi.do) — 이용허락범위 **제한 없음**, 비용 무료
- [금융위원회_지수시세정보](https://www.data.go.kr/data/15094807/openapi.do)
- [금융위원회_증권상품시세정보](https://www.data.go.kr/data/15094806/openapi.do) — ETF·ETN·ELW
- [금융위원회_KRX상장종목정보](https://www.data.go.kr/data/15094775/openapi.do) — 이용허락범위 **제한 없음**
- [금융위원회_주식발행정보](https://www.data.go.kr/data/15043423/openapi.do)

### ⚠ 반드시 알아야 할 제약 — 실시간이 아니다

포털 화면에는 갱신주기가 "실시간"으로 적혀 있지만, 실제 안내문은 이렇다.

> 데이터 갱신은 기준일자로부터 **영업일 하루 뒤 오후 1시 이후**에 업데이트된다.
> (금요일 데이터는 차주 월요일에 제공, 월요일이 공휴일이면 다음 영업일)

**즉 이 사이트는 구조적으로 T+1 매체다.** 장중 속보를 낼 수 없다.
이건 제약이 아니라 편집 방침으로 삼는 게 맞다 — 속보 경쟁이 아니라 **하루 뒤에
맥락을 붙여 설명하는 매체**로 포지셔닝한다. 기사에는 반드시 데이터 기준시각
(as-of)을 KST/ET 병기로 노출한다.

트래픽 한도: 개발계정 10,000건. 운영계정은 활용사례 등록 시 증액 신청 가능.
하루 여러 건 발행이면 초기엔 충분하지만, **운영계정 전환과 활용사례 등록은 미리 해둘 것.**

## 2. 거시경제 — 한국은행

- 한국은행 ECOS Open API (https://ecos.bok.or.kr/api/) — 무료 키 발급, 일 1,000회 제한.
  **다만 ECOS 자체 약관의 재배포 조항을 아직 원문으로 확인하지 못했다.**
- 대신 [한국은행_국민계정](https://www.data.go.kr/data/15059629/openapi.do),
  [한국은행_대외채권및대외채무](https://www.data.go.kr/data/15059636/openapi.do) 등
  **공공데이터포털에 등재된 한국은행 데이터셋을 우선 사용한다.** 이용허락 근거가 명확하다.
- ECOS를 직접 써야 할 지표가 생기면, 그때 ECOS 약관 원문을 확인하고 이 문서를 갱신한다.

## 3. 쓰면 안 되는 것 — KRX 정보데이터시스템 직접 수집

data.krx.co.kr 화면을 크롤링하거나 내부 조회 엔드포인트를 호출하는 방식은 약관 위반이다.

> **제12조(이용자의 의무) ②** 이용자는 당 사이트의 정보를 거래소의 사전 허락 없이
> 복사·복제·배포·전송·공중송신하여서는 아니 됩니다.
>
> **제13조(지식재산권)** 당 사이트의 화면, 프로그램, 문서, 로고 등 모든 저작권과
> 지식재산권은 거래소 또는 정당한 권리자에게 귀속됩니다.
>
> — [KRX 홈페이지 이용약관](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd)

파이썬 `pykrx` 같은 라이브러리는 내부적으로 이 사이트를 스크래핑한다.
**라이브러리가 MIT 라이선스인 것과, 그 라이브러리가 긁어오는 데이터를 재배포해도 되는지는
완전히 별개 문제다.** 코드 라이선스는 데이터 라이선스가 아니다. 이 저장소의 파이프라인에
pykrx류를 넣지 않는다.

[KRX Open API](https://openapi.krx.co.kr/)(openapi.krx.co.kr)는 별도 서비스이며 지수·주식·
채권·파생·일반상품(석유·금·배출권)·ESG를 제공하나, **재배포·상업적 이용 조건이 서비스
목록 페이지에 명시돼 있지 않다.** 쓰려면 마켓데이터 이용약관을 먼저 확인해야 한다.
현재는 사용하지 않는다.

## 4. 저작권이 붙지 않는 부분 — 우리가 만드는 것

숫자 사실 자체(종가, 등락률)에는 저작권이 없다. 문제가 되는 건 **DB 전체 또는 상당 부분의
복제·재배포**다. 따라서 안전한 작업 방식은 이렇다.

- ✅ 소수 종목·지표를 **선별**해 인용하고, 우리가 계산한 파생지표(추세, 상관, 비교)와
  해설을 붙인다 → 우리 저작물
- ❌ 전 종목 시세표를 그대로 떠서 페이지로 만든다 → 데이터베이스 재배포. 하지 않는다.
- ✅ 모든 기사에 출처를 기관명 + API명으로 명시 (Data & Verification Notes 섹션)
