# 데이터 출처 라이선스 확인 결과

작성일 2026-07-31 · 최초 확인자 Claude Code
**이 문서는 법률자문이 아니다.** 공개된 이용약관·이용허락범위 표기를 읽고 정리한 것이다.
실제 광고 매출이 유의미해지면 변호사 검토를 한 번 받는 것을 권한다.

생산하지만, **금융위원회 명의로 공공데이터로 개방되어 있고 이용허락범위가 명시적으로

개발계정 트래픽 10,000건.

### ⚠ 반드시 알아야 할 제약 — 실시간이 아니다

포털 화면에는 갱신주기가 "실시간"으로 적혀 있지만, 실제 안내문은 이렇다.

> 데이터 갱신은 기준일자로부터 **영업일 하루 뒤 오후 1시 이후**에 업데이트된다.
> (금요일 데이터는 차주 월요일에 제공, 월요일이 공휴일이면 다음 영업일)

**즉 이 사이트는 구조적으로 T+1 매체다.** 장중 속보를 낼 수 없다.
이건 제약이 아니라 편집 방침으로 삼는 게 맞다 — 속보 경쟁이 아니라 **하루 뒤에
맥락을 붙여 설명하는 매체**로 포지셔닝한다. 기사에는 반드시 데이터 기준시각
(as-of)을 KST/ET 병기로 노출한다.

트래픽 한도: 개발계정 10,000건. 운영계정은 활용사례 등록 시 증액 신청 가능.
하루 여러 건 발행이면 초기엔 충분하지만, **운영계정 전환과 활용사례 등록은 미리 해둘 것.**

## 2. 외환 (fx)

- [한국수출입은행 환율 정보](https://www.data.go.kr/data/3068846/openapi.do) — 제공기관 한국수출입은행,
  이용허락범위 **제한 없음**, 무료.
- **주의 1 — 이건 은행 고시환율이지 은행간 시장 스팟 호가가 아니다.**
  기사에 "the rate published by the Export-Import Bank of Korea" 라고 정확히 써야 한다.
  "the won traded at ~" 이라고 쓰면 사실과 다르다. 이 구분을 흐리면 법적 방어선이 무너진다.
- **주의 2** — 요청 도메인이 `www.koreaexim.go.kr` → `oapi.koreaexim.go.kr` 로 바뀌었다.
- **주의 3** — 일 1,000회 제한.
- 원/달러 시계열 교차검증은 아래 한국은행 통계를 병행한다.
- 달러선물·엔선물 등 통화선물은 1번의 파생상품시세정보(15094802)에서 받는다.

## 3. 거시경제·금리 — 한국은행

- 한국은행 ECOS Open API (https://ecos.bok.or.kr/api/) — 무료 키 발급, 일 1,000회 제한.
  **다만 ECOS 자체 약관의 재배포 조항을 아직 원문으로 확인하지 못했다.**
- 대신 [한국은행_국민계정](https://www.data.go.kr/data/15059629/openapi.do),
  [한국은행_대외채권및대외채무](https://www.data.go.kr/data/15059636/openapi.do) 등
  **공공데이터포털에 등재된 한국은행 데이터셋을 우선 사용한다.** 이용허락 근거가 명확하다.
- ECOS를 직접 써야 할 지표가 생기면, 그때 ECOS 약관 원문을 확인하고 이 문서를 갱신한다.

## 4. 다른 금융기관들은 어떤가 (2026-07-31 조사)

사장님 질의 — 금융결제원·한국투자공사·금융투자협회 등에도 데이터가 있는지.
있다. 다만 **"데이터가 있다"와 "상업적으로 재배포해도 된다"는 전혀 다른 문제**이고,
아래 대부분이 두 번째 관문에서 걸린다.

### ⚠ 한국예탁결제원(KSD) — 확인 전까지 사용 금지

공공데이터포털에 주식정보·증권대차·증권예탁통계·국제거래정보 등 **쓸모 많은 데이터셋**이 있다.
배당순위, 종목별 대차거래현황 같은 건 다른 데서 못 구하는 것들이다.

**그런데 조사 중 "한국예탁결제원 데이터는 제2유형(출처표시 + 상업적 이용금지)이며,
상업적 활용은 예탁결제원과 별도 협의가 필요하다"는 서술이 나왔다.**
(2차 자료에서 나온 것이고, 아래에 적었듯 원문 확인은 실패했다.)

이게 사실이면 **광고 수익을 내는 이 사이트에서는 쓸 수 없다.** 금융위원회 API가
"제한 없음"인 것과 정반대다. 같은 공공데이터포털에 있다고 라이선스가 같지 않다.

> **미해결.** 조사 시점에 data.go.kr 가 자동조회를 차단해 데이터셋 페이지의 「이용허락범위」
> 필드를 원문으로 확인하지 못했다. **확인될 때까지 사용 금지로 둔다.**
> 확인 방법: [주식정보서비스](https://www.data.go.kr/data/15001145/openapi.do) 등
> 데이터셋 페이지를 브라우저로 직접 열어 「이용허락범위」 값을 읽고 이 문서를 갱신할 것.

### 금융결제원(KFTC) — 우리 용도가 아니다

[오픈API 개발자사이트](https://developers.kftc.or.kr/dev)가 있지만 제공 서비스가
계좌이체·오픈뱅킹·인증·물품대금결제 등 **금융거래 실행용 API**다. 이용하려면 기관 자격과
계약이 필요하고, 애초에 기사에 쓸 시장 데이터가 아니다.
지급결제 통계는 별도로 존재하나 재배포 조건을 확인하지 않았다. 현재 계획 없음.

### 한국금융투자협회(금투협·KOFIA) — 상당 부분은 신청 없이 쓸 수 있다

**2026-08-01 갱신 — 협회에 직접 신청할 필요가 줄었다.** 협회 데이터 일부가 금융위원회 명의로
공공데이터포털에 「제한 없음」으로 개방돼 있다. 아래 「증권사·자산운용사」 항목을 볼 것.

포털에 없는 것(채권 최종호가수익률=민평 등)이 필요해지면 그때
[openapi.kofia.or.kr](http://openapi.kofia.or.kr/) 또는
[종합통계포털 freeSIS](https://freesis.kofia.or.kr/) 로 간다.
그 경우 **활용 신청 → 승인 → API키** 절차와 별도 「오픈API 활용약관」이 적용되며,
**재배포·상업적 이용 조항은 아직 확인하지 않았다.** 신청 전에 약관 원문부터 읽을 것.

### 한국투자공사(KIC) — 데이터 제공기관이 아니다

국부펀드 운용기관이지 시장데이터 배포기관이 아니다. 공개되는 건 연차보고서 수준의
운용자산·수익률이고 API가 없다. 기사에 인용할 수는 있어도 데이터원으로 쓸 대상은 아니다.

### ✅ 금융감독원 DART — 해결됐다. 공공데이터포털 경유로 쓴다

**OpenDART 사이트에 직접 신청할 필요가 없다.** 같은 데이터가 공공데이터포털에
**「이용허락범위 제한 없음」**으로 열려 있다. KRX 시세가 금융위 명의로 열린 것과 같은 구조다.

**넷 다 이용허락범위 「제한 없음」, 무료로 직접 확인했다.** (2026-08-01)

이게 왜 큰가 — 지금까지는 "주가가 움직였다"까지만 쓸 수 있었다. 이제 **왜 움직였는지를
재무제표와 공시로 뒷받침**할 수 있다. 자기주식 취득 공시, 유상증자, 합병 같은 건 그 자체가
기사거리다. 다중회사 주요계정은 동종업계 비교 기사를 가능하게 한다.

> OpenDART 자체 약관도 확인했다 — 저작권은 금감원에 있고 **"약관에 명시되지 않은 사항은
> 저작권법 및 공공데이터법에 따른다"** 고 돼 있다. 다만 명시적 재배포 허용 문구는 없다.

### ⚡ 공시는 실시간이다 — 이 사이트의 T+1 제약을 깨는 유일한 구멍

시세는 T+1 이지만 **공시는 기업이 제출하는 즉시 공개된다.** 경로에 따라 갈린다.

| 경로 | 실시간 | 라이선스 |
|---|---|---|
| OpenDART 직접 (`opendart.fss.or.kr`) | ✅ 접수 즉시 | ⚠ 재배포 조항 미확인 |
| 15059649 공시정보 (포털) | ❌ T+1 | ✅ 제한 없음 |
| 15043459 기업 재무정보 (포털) | ❌ T+1 | ✅ 제한 없음 |
| **15060622 다중회사주요계정** | ✅ **실시간** | ✅ **제한 없음** |

**15060622 는 API 유형이 `LINK` 다.** 포털이 데이터를 복사해 두는 게 아니라 금감원 API 로
바로 연결하는 방식이고, 그게 「제한 없음」으로 등재돼 있다. 원본을 실시간으로 쓰면서
라이선스 근거는 포털 등재로 확보되는 구조로 읽힌다.

> **미확인 — 단정하지 말 것.** `LINK` 유형의 「제한 없음」이 원본 API 호출 전반을 커버하는지,
> 아니면 그 데이터셋이 정의한 오퍼레이션에만 한정되는지 확인하지 못했다.
> **확인 전에는 15060622 가 정의한 범위(상장법인 XBRL 주요계정) 안에서만 쓴다.**

### 편집 방침에 미치는 영향

**시세는 T+1, 공시는 당일.** 이원으로 간다.

- 자기주식 취득·처분, 유상증자, 합병·분할, 감자, 전환사채 발행, 부도, 회생절차 개시
  → **그 자체가 기사다.** 시세 없이도 쓴다. 당일 발행이 가능하다.
- 시세 해설 기사는 종전대로 T+1. 기준시각(as-of)을 반드시 병기한다.
- **한 기사 안에서 두 시각을 섞지 말 것.** 공시는 오늘, 시세는 어제인데 그걸 뭉뚱그리면
  독자가 오늘 종가로 오해한다. `dataAsOf` 를 항목별로 명시하거나 기사를 나눈다.

### 🔴 네이버 금융 경로 — **내가 적어 둔 근거가 틀렸다** (2026-08-03 KST 실측)

`scripts/collect-research.mjs` 머리에 이렇게 적혀 있었다.

> 「`finance.naver.com/robots.txt` 가 `/research/` 를 **명시적으로 Allow** 한다」

**틀렸다.** 실측한 robots.txt 전문은 이렇다.

```
User-agent: *          ← 우리 봇이 여기 걸린다
Disallow: /            ← 전부 금지

User-agent: yeti       ← 네이버 자사 크롤러
Disallow: /
Allow: /sise/
Allow: /research/      ← 이 Allow 는 **yeti 그룹 소속**이다
Allow: /marketindex/
Allow: /fund/
...
```

**Allow 줄만 보고 그것이 어느 `User-agent` 그룹에 속하는지를 안 봤다.**
RFC 9309 상 그룹은 `User-agent` 줄로 나뉜다. `*` 에게 적용되는 규칙은 `Disallow: /` 뿐이다.

**같은 실수를 두 번째로 했다** — 인텔리티비 때는 루트만 보고 하위 도메인을 안 봤고,
여기서는 Allow 줄만 보고 그 위의 그룹 헤더를 안 봤다. **부분을 보고 전체라고 했다.**

## 7. 저작권이 붙지 않는 부분 — 우리가 만드는 것

숫자 사실 자체(종가, 등락률)에는 저작권이 없다. 문제가 되는 건 **DB 전체 또는 상당 부분의
복제·재배포**다. 따라서 안전한 작업 방식은 이렇다.

- ✅ 소수 종목·지표를 **선별**해 인용하고, 우리가 계산한 파생지표(추세, 상관, 비교)와
  해설을 붙인다 → 우리 저작물
- ❌ 전 종목 시세표를 그대로 떠서 페이지로 만든다 → 데이터베이스 재배포. 하지 않는다.
- ✅ 모든 기사에 출처를 기관명 + API명으로 명시 (Data & Verification Notes 섹션)

## ⚠ 같은 데이터라도 **경로에 따라 라이선스가 다르다** (2026-08-02 KST)

포털이 「전환 작업」으로 막혀 있을 때 내가 **직접 창구로 우회하자**고 했다.
DART 는 그게 맞았는데 **관세청은 틀렸다.** 약관을 읽고 알았다.

| 같은 관세청 데이터 | 조건 |
|---|---|
| **공공데이터포털 경유** | **이용허락범위 제한 없음** — 포털이 라이선스를 붙여 개방한다 |
| UNIPASS 직접 | **영리·재배포에 사전 승낙 필요** |

UNIPASS 이용약관 제15조.

> 2. 회원은 통관포털의 **사전 승낙 없이 서비스를 이용하여 어떠한 영리행위도 할 수 없습니다.**
> 3. 회원은 ... 얻은 정보를 사전승낙 없이 복사, 복제, **변경, 번역**, 출판·방송 기타의
>    방법으로 사용하거나 **이를 타인에게 제공할 수 없습니다.**

**우리가 하려는 것이 정확히 여기 적힌 것들이다** — 영문 번역, 가공, 재배포, 영리.
모르고 수집했으면 나중에 사업이 통째로 걸렸다.

### 그래서 원칙

> **포털이 막히면 기다린다. 우회로의 약관이 더 나쁘면 우회하지 않는다.**
> 사장님 판단(2026-08-02): 「당연히 이걸로 해야지. **한 번만 하면 되잖아**」
> 한 번 열리면 「제한 없음」으로 전부 받는다. 조건 나쁜 경로를 탈 이유가 없다.

**우회를 검토할 때는 접근 가능 여부가 아니라 약관부터 본다.**
열려 있다는 것과 쓸 수 있다는 것은 다르다.

## ✅ 증권사 직접 수집 — **된다. 그리고 PDF 를 안 받아도 된다** (2026-08-03 17:3x KST)

사장님 지시(11번): 「사람하고 비즈니스 안 한다. 너희들로 충분해」
→ 홍보팀에 부탁하는 경로를 접고 **우리가 직접 받는 길**을 실측했다.

### 실측 결과 — 한양증권

```
목록 페이지   /board/researchAnalyzeCompany/list
              번호 · [07/22] 엔알비(475230) : 제목 · 2026.07.22 · 조회수
              ⚠ 목록에는 목표주가가 없다

상세 페이지   /board/researchAnalyzeCompany/detail/{번호}?boardNo=17
              ✅ 여기 다 있다
                Analyst  이준석          ← ⭐ 네이버에는 없던 것
                투자의견  N.R
                목표주가  -              (이 건은 미제시)
                현재주가  (07/21) 7,160원
```

### ⭐ 이것이 왜 큰가

**PDF 를 받을 필요가 없다.** 상세 페이지 HTML 에 증권사가 스스로 요약해 둔 줄이 있고,
목표주가·투자의견·애널리스트가 거기 평문으로 들어 있다.

```
저작권      리포트 본문이 아니라 증권사가 자기 페이지에 공표한 요약 줄이다
robots      한양증권은 Disallow:/download 뿐 — 목록·상세는 허용
애널리스트   ⭐ 네이버 경로로는 0.3%도 못 채웠는데 여기서는 나온다
```

### 남은 확인

⬜ 22곳이 다 이 구조인지 — **한양 하나로 단정하지 않는다.**
   오늘만 「부분을 보고 전체라 했다」로 두 번 틀렸다(intellitv 루트, robots Allow 줄).
⬜ 목표주가를 실제로 제시한 건이 얼마나 되는지 (이 표본은 N.R 이었다)
