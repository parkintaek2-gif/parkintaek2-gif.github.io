> 사장님(2026-08-09): 「열에 체크해야 하는 항목을, 행에 유닛명으로 해서 표를 만들 것.
> **체크박스를 만들어 제대로 확인하는 절차를 두도록**」

---

## ⛔ ☑ 를 치는 법 — **이것부터 지킨다**

```
☑   라이브·실물에서 **재서 확인했다**
☐   아직 아니다
▨   **계정·권한이 없어 못 한다** (벽 — 그 자리 잘못이 아니다)
?   못 쟀다
```
🔴 **「했다」로 ☑ 를 치지 않는다. 「재서 봤다」라야 ☑ 다.**
⛔ 오늘 1번이 「배포 10회」라 적었는데 라이브는 0/6 이었다. **push 는 ☑ 가 아니다.**

## 🔴 제대로 확인하는 절차 — **세 단계다. 자기 체크만으로는 안 친다**

```
① 각 자리가 자기 줄에 ☑ 를 친다
② **2번이 자로 다시 잰다**   →  node scripts/check-board.mjs
③ ☑ 인데 자가 아니라고 하면 → **그 칸을 ☐ 로 되돌리고 그 자리에 알린다**
```
⭐ 자가 잴 수 있는 칸(사이트·이름·홈화면·광고)은 **2번이 매시간 다시 잽니다.**
⛔ 자가 못 재는 칸(매출·상품·계획)은 **●본 것 / ○정한 것** 표시로 대신합니다.
