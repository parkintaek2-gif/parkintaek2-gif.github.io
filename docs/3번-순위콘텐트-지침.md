# 3번(100yearmap) 「순위 + 문제제기」 콘텐트 지침

> 사장님 지시 원문 모음(2026-08-31, 시간순). 이 시리즈를 만들 때마다 이 문서를
> 먼저 다시 읽는다 — 낱개 지시를 흩어진 채로 기억하지 않는다.

## 원문 모음 (그대로)

1. 「과감하게 학교 순위를 공개해, 과연 그게 학생들이 좋아하고, 행복한 순위인지
   문제제기를 해」「학원 순위도 공개해, 일타강사도 공개해」「사람들의 관심을 갖는
   순위를 다 찾아 공개해」「사람은 돈, 성적, 권력만으로 살지 않잖아」
2. 「내가 예시를 든 것만 찾지마...너도 사람들이 뭘 궁금해 하는 지 찾아」
3. 「사람들이 관심이 많은 모든 것에 대해 순위를 매겨...그 순위가 의미가 있는 지
   생각해보게 해」
4. 「우리나라는 주식부자 순위 이런게 공개돼. CEO스코어, 재벌닷컴 보도자료나 여기
   자료를 갖고 기사를 쓴 게 많아」— 이미 공개된 3자 순위(공시 지분율×주가 기반)를
   인용하는 건 안전하다는 뜻
5. 「국내외 순위를 공개해...특히 부자들, 대학 순위(이상한 외국 평가기관이 있어,
   국내는 중앙일보가 순위를 공개해)는 관심이 많겠지」
6. (주식부자 순위를 6번에게 넘기자는 내 제안에) 「네가 해」— **내(3번)가 전부 한다,
   유닛별로 안 나눈다**
7. 「성격이 달라...너는 부자를 얘기하지만, 결국 부자가 되자고 얘기하는 게 아니잖아」
   — **부자 되는 법·재테크 조언이 아니다.** 톤은 비판적 질문이지 동경이 아니다
8. 「콘텐트 제목도 사람들의 이목을 끌어 클릭할 수 있게 만들어, 그래프도 만들고,
   그 안에서 우리가 하고 싶은 얘기를 해, 데이터로...댓글을 달 수 있게 해」

## 이 지침에서 나오는 규칙 (요약)

| 항목 | 규칙 |
|---|---|
| 범위 | 예시(학교·학원·일타강사·부자·권력·명예·아이큐)에 갇히지 않는다. 실제 관심사를 찾는다 |
| 순위 출처 | **이미 존재하는 3자 공개 순위만 인용**한다(중앙일보 대학평가·CEOscore·재벌닷컴 등). 저희가 개인·기관을 직접 평가해 순위를 새로 만들지 않는다 |
| 톤 | 순위는 «사실»로 보여주되, 그것이 «전부는 아님»을 100yearmap 실측 데이터로 반박한다. 동경·선망 조장 금지("부자가 되려면"류 없음) |
| 담당 | 유닛별로 나누지 않는다 — 소재가 뭐든 3번이 만든다(사장님이 직접 「네가 해」로 확정) |
| 제목 | 클릭하고 싶게. 백년지도 기존 문체(과장 없이 사실로 흥미 유발)와 절충 |
| 형식 | 그래프(간단한 인라인 SVG, 새 JS 라이브러리 안 씀 — 사이트 관행) 필수 |
| 인용 표기 | 3자 순위 인용은 korea-japan-youth 지면과 같은 방식 — 언제·누가 발표했는지, 원자료 못 찾으면 그 사실도 적는다 |
| 금지어 검사 | "순위"는 이 시리즈에서 의도적으로 쓴다 — `check-100y-banned-words.mjs`의 대장(`docs/금지말-대장.json`)에 새 지면을 의도적으로 등록해 「새로 생긴 위반」 오탐을 정리한다(숨기는 게 아니라 의도를 기록) |
| 댓글 | **결정됨(2026-08-31)** — 사장님이 2번에게 자체(추적 없는) 댓글 시스템 제작을 직접 지시. 3번은 만들지 않는다 — 2번 쪽이 완성되면 이 시리즈 지면에 붙이는 연동만 한다. Giscus 등 3자 트래킹 위젯은 쓰지 않는다(결론) |

## 원문 모음 (계속)

9. 「대학들이 왜 우리 순위가 이것밖에 안돼, 우리 순위가 이렇게 높아라는 생각이
   들게 공격적으로 대학명을 제목에 기재해」— **완곡한 표현 금지, 학교 실명을 헤드라인에
   직접 쓴다.** 단 "나쁘다" 판정 문장은 여전히 안 씀 — 실명+실제 수치 대비 자체가 이미
   자극적이라 그걸로 충분하다
10. 「전국 순위, 각 지역순위, 4년제, 3년제, 2년제, 폴리텍대학 등 특수학교, 국립대,
    공립대 순위 다 나눠서 공격적으로 제목을 달아」— 대학 순위를 **여러 갈래로 쪼개서**
    각각 지면을 만든다(아래 목록)

## 진행 중 목록

- [ ] **대학 순위 — 전국 종합** (중앙일보 대학평가 vs 실측 취업률 등) — 1차 제작 중,
      제목에 대학 실명 대비 직접 기재로 수정 지시함
- [ ] 대학 순위 — **지역별**(수도권/영남/호남/충청/강원·제주 등, 같은 지역 안에서
      취업률 등으로 다시 줄 세우기 — `pages-university.json`의 `지역` 필드로 가능)
- [ ] 대학 순위 — **설립별**(국립대·공립대·사립대, `설립` 필드로 가능)
- [ ] 대학 순위 — **구분별**(4년제 대학교 vs 2·3년제 전문대학 — `구분` 필드 확인 필요,
      전문대 데이터가 pages-university.json에 있는지부터 확인)
- [ ] 폴리텍대학 등 특수목적 학교 — 이미 `/polytech` 지면 있음, 순위 프레임으로
      재구성할지 검토
- [ ] 주식부자 순위(CEOscore/재벌닷컴 인용) vs 100yearmap 실측(청년 가구 자산 스케일
      대비) — 1차 제작 중
- [ ] 그 밖의 관심사 발굴 — 후보: 아파트값(자료 없음, 보류)·연봉 순위·행복도
      국가순위(OECD)·학원/일타강사(원자료 신뢰도 낮아 보류 검토)

⚠ 지역·설립·구분별로 쪼개면 지면 수가 빠르게 늘어난다 — 각 지면이 진짜 다른 이야기를
하는지(단순 재탕이 아닌지) 만들 때마다 확인한다.
