# SeoulMarkets 광고 자리 지도 (2번 55437)

> 승인 오는 날 「붙이기만」 하도록 미리 짠 지도. AdSense 신청은 사장님 손(docs/사장님-할일.md).
> ⛔ 원칙(2번·백년지도와 동일): **자료 표 안에는 광고를 넣지 않는다.** 우리는 숫자를 파는 곳이라, 표 안 광고는 그 숫자를 의심받게 한다. 표 밖(콘텐츠 상단)에만 둔다.

## ⛔ 표 안 자리 — 뺀 것
```
자료 표 안에 든 자리: 0개 (뺄 것 없음)
```
- 이유: AdSlot 은 콘텐츠 지면(기사·홈·카테)의 **본문/목록 상단**에만 삽입돼 있다.
- ⭐ **데이터 판매지면(`/data/*` — 업종패널·임금패널·목표주가·지배구조)에는 AdSlot 이 아예 없다.** 숫자를 파는 지면이라 광고를 안 붙였다. 55437 원칙을 이미 지키고 있었다.
- esports 2장은 `noAds`(Riot 약관) — 재고에서 제외.

## 남은 자리 (다시 셈)
```
47 → 47  (표 안 자리 0 제거 → 변동 없음)
```

## 자리를 더 낼 곳 (금액 유지, 자리만 확장 여지)
```
· 기사 하단(read-next 위) 배너 1자리 × 40 = +40  ← 표 밖, 다 읽은 사람에게
· 카테고리 목록 중간(N번째 카드 뒤) 인피드 1자리 × 6 = +6
→ 필요하면 47 → 최대 ~93자리까지. ⛔ 다만 밀도가 신뢰를 해치지 않는 선까지만
```
⚠ 승인 오면: `src/consts.ts` 의 `ADS.client` 를 pub 코드로 채우면 47자리가 즉시 켜진다. 코드는 이미 삽입돼 있다(AdSlot 3종).
