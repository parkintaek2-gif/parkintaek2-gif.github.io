## 사장님이 누르실 것 (순서대로)

```
① claude.ai 로그인(admin@klifedesign.net) → 좌하단 「보스」 → Settings → Billing
   → 「Next billing date」 확인해 저희에게 알려 주십시오(저희 권한으로는 못 봅니다)
② 같은 화면 → Members/Team → 「Invite members」 → u1@klifedesign.net 입력
   ⭐ 좌석 종류는 **u5@klifedesign.net과 같은 것**을 고른다(목록에서 u5 확인) —
   나머지 여섯이 쓰는 team_standard/default_raven이 아니라 5번만 쓰는
   team_tier_1/default_claude_max_5x라 5번만 하루 종일 안 굶었다
③ 2번·7번도 같은 병(admin@ 공유)이다 — 오늘은 1번만 먼저, 2번·7번은 5번이 따로 정리
```
