# 비즈니스 리뷰 — **광고 없이 버는 길** · 2026-10-03 · 5번 K Culture Wire

## 왜 이 문서가 생겼나

사장님 (2026-10-03):

> 「**광고는 안한다. 광고없이 스스로 해결할 수 있는 방법이 진짜 매출이다.
>  검색, AI, 우리 사이트의 네트워크 외 다른 방법이 있는 지 찾아. 특히 커뮤니티 등**」

> 「**예전에 이미 지시한거야**」

🔴 사장님 말씀이 맞다. **2026-08-09 에 이미 적혀 있었다** —

> 「여기에 비즈니스(**데이터판매, 콘텐츠(외부 유입용 포함)판매**, 광고인벤토리판매…)도 해야 한다」
> 「리뷰에 **데이터 판매 · 콘텐츠 판매(외부 유입용 포함) · 광고 인벤토리 판매**가 반드시 실린다」

⛔ 그런데 나는 2026-08-22 의 「b2c 매출은 너에게 있어서는 광고밖에 없다」 한 줄만 붙들고,
그 뒤 마흔 날 넘게 보고마다 「광고가 유일한 수단」이라고 적어 왔다. **내가 범위를 좁혔다.**
그리고 사장님이 「세 바퀴마다 비즈니스 리뷰」라고 하신 그 리뷰를 **한 번도 안 냈다.**
이것이 그 첫 리뷰다.

## 1. 지금 우리가 쥔 것 — 재서 적는다

```
순방문자      어제 3명 · 28일 하루평균 6명꼴 (진짜 손님만)
기사          266편
지면          주소 2,985개
자료          넷플릭스 주간 Top10(공개 파일) · 위키데이터 크레딧 · 위키미디어 열람수
결제          페이팔이 서버에 붙어 있다 (계정 가입·로그인도 있다)
커뮤니티 도구   댓글 서버 · 투표 서버 — 둘 다 살아 있다
```

### ⛔ 오늘 재서 찾은 것 — 도구는 있는데 «안 붙어» 있었다

```
            오늘 아침        오늘 저녁
댓글 자리     2장            268장      ← 기사 266편 전부에 붙였다
투표          1편 · 득표 0    1편        ← 아직 그대로
커뮤니티 첫 화면  「아직 글을 쓸 수 없습니다」  →  말할 자리를 냈다
```

백년지도(3번)는 66장에 댓글이 붙어 있었다. **내 유닛만 둘이었다.**
사장님이 「거기에 댓글을 달 수 있게 해」라고 하신 것이 우리 지면 주석에 그대로 적혀 있었다.

⚠ 글쓰기가 실제로 되는 것을 POST 로 넣어 확인했다(200 · 저장 확인). 넣은 시험 글은 지웠다.

## 2. 데이터 판매 — 시장조사 (사장님이 정하신 전제 ①)

### 사는 곳이 실제로 있나

```
스튜디오·제작사   무엇에 투자할지 정하는 데 시청 지표를 본다
광고주           넷플릭스 광고 요금제 참여도 자료로 캠페인을 고친다
조사회사         Ampere Analysis · Media Partners Asia · Nielsen Korea · KOCCA
                 — 이들이 «우리와 같은 공개 자료»로 보고서를 만들어 판다
```

⭐ KOCCA 집계로 넷플릭스가 2026년 한국 콘텐츠에 **4억 8천만 달러**를 쓴다(전년 대비 +35%).
돈이 도는 자리에는 그 돈을 어디에 쓸지 정하려는 수요가 있다.

### 얼마에 사나 — 벤치마킹 (전제 ②)

```
Chartmetric   Manager $40/월 · Premium $117/월 · Ultra $150/월 · Artist $10/월
Luminate      $295~395/월 (연 $3,900)
콘텐츠 신디케이션  기사 한 편 $149~700 · 묶음 $99~3,500
뉴스레터 후원     구독자 5만 미만이면 보통 정액 · 한 자리 $200~500 · CPM $10~50
```

### ⇒ 판단

```
✅ 시장은 있다. 값대도 있다 — 월 $40~150 이 「작은 도구」의 자리다
🔴 그러나 우리 자료는 «공개 자료로 지은 것»이다. 남도 지을 수 있다 ⇒ 값을 높게 못 받는다
⭐ 우리만 가진 것은 «자료»가 아니라 «태도»다 —
   「못 잰 것은 못 쟀다고 적는다」. Ampere·Nielsen 은 그 칸을 안 만든다
⛔ 지금 팔러 나가지 않는다. 하루 손님 3명으로는 살 사람이 우리를 못 찾는다
```

## 3. 커뮤니티 — 사장님이 직접 짚으신 갈래

### 우리에게 맞는 구조 — 재서 고른 하나

커뮤니티로 광고 없이 버는 길은 여럿이지만(유료 멤버십 · 전용 방 · 굿즈 · 모임),
**우리 강령과 부딪히지 않고 우리 자산을 키우는 것은 하나뿐이다** —

```
🔴 커뮤니티가 «자료를 만드는 자리»가 된다

   우리가 재는 것     위키백과가 실제로 읽힌 수        (사실)
   손님이 주는 것     앞으로 어떻게 될 것 같은가        (예상)
   그 둘의 «차이»     아무도 안 가진 자료가 된다
```

⭐ 이것이 강령과 맞는 까닭 — 우리는 판정하지 않는다. **사실과 예상을 나란히 놓을 뿐**이고,
   어느 쪽이 맞았는지는 시간이 말한다. 「나침반을 주되 바늘은 세우지 않는다」 그대로다.

⭐ 팔 수 있는 까닭 — 「사람들이 무엇을 기대했나」는 실제 수치만큼이나 돈이 되는 자리다.
   그리고 그것은 **우리 커뮤니티 안에서만** 생긴다. 공개 자료로는 못 짓는다.

### 그래서 할 일의 차례

```
① 말할 자리를 연다        ✅ 오늘 했다 (댓글 268장 · 커뮤니티 첫 화면)
② 투표를 늘린다           🔜 지금은 266편 중 1편뿐 · 득표 0
③ 「잰 것 ↔ 예상」을 겹친다  투표가 쌓여야 시작된다
④ 그 자료를 판다          ③ 이 쌓인 뒤
```

⛔ ②를 기계로 266편에 뿌리지 않는다 — 물음이 억지스러우면 아무도 안 누른다.
  비교가 «이미 들어 있는» 기사부터 붙인다.

## 4. 콘텐츠 판매 (외부 유입용 포함) — 사장님 지시의 셋째 줄

```
✅ 우리는 기사 266편과 마크다운 판 266개를 이미 내고 있다 (dist/wikitip/article/*.md)
⭐ 그 마크다운 판이 AI 인용의 입구다 — 이미 Dataset 구조화 데이터가 122편에 붙어 있다
🔜 아직 안 한 것 — 그 글을 «남의 지면»에 실어 값을 받는 길을 재 본 적이 없다
```

⚠ 신디케이션 값대(기사 한 편 $149~700)는 **파는 쪽이 아니라 사는 쪽** 값이다.
  우리가 받는 값은 다르다. 그것은 아직 안 쟀다 — 다음 리뷰에서 잰다.

## 5. 결론 — 지금 하는 것과 안 하는 것

```
✅ 한다    커뮤니티가 자료를 만들게 한다 (①②③)
✅ 한다    유입 — 사장님이 「당분간 방문자에 올인」이라 하셨다. 그것이 모든 것의 밑이다
🔜 뒤에    데이터 판매 · 콘텐츠 판매 — 살 사람이 우리를 찾을 수 있게 된 뒤
⛔ 안 한다  광고
⛔ 안 한다  방문자 3명인데 상품을 먼저 만드는 것
```

⭐ 사장님 말씀 그대로 — 「**사람이 안 오면 아무리 좋은 상품도 의미가 없다**」(2026-08-23).
  광고를 뺀 자리는 **커뮤니티가 만드는 자료**로 채운다. 그것이 우리 손으로 값을 정할 수 있는
  유일한 것이다.
