### 🎯 고른 것 — **인구 5% · 1인당 연 4만원 = 1,020억**

```
왜 5%     자리잡은 것들의 띠가 4.8%(웨이브) ~ 13.4%(넷플릭스)입니다
          5% 는 **웨이브 바로 옆**이고 티빙(6.9%)보다 낮습니다. 띠의 아래쪽입니다
왜 4만원   한 벌 9,900원을 **1년에 네 번** 사는 것입니다
          진학·이직·아이 진로 — 1년에 네 번 물어볼 일이 있는 물건입니다
```
⛔ 사장님이 「중간을 잡으라」 하셨는데, 띠의 산술 중간은 9% 입니다. **티빙보다 큰 회사**가 됩니다.
   그래서 **띠의 아래쪽인 5%** 를 잡고, 모자란 만큼을 **1인당 값**으로 채웠습니다.
   ⭐ 사람을 더 모으는 것보다 **한 사람이 네 번 사게 하는 쪽**이 우리가 할 수 있는 일입니다.

⚠ 사장님 말씀대로 **0살~100살이 다 고객**이라 인구 전체(5,100만)를 밑수로 썼습니다.

### 🔴 그런데 3번이 밑에서부터 재니 **2031 이 4.9억**이었습니다

```
제가 위에서 잰 것   시장 1.4조 · 인구 5% · 1인당 4만원  →  1,020억
3번이 밑에서 잰 것   지금 만들 수 있는 지면 × 1.75 × 벌 수 × 9,900원  →  **4.9억**
                    (다섯 해 다 합쳐도 14.41억)
```
⛔ **208배 어긋납니다.** 둘 다 맞습니다. 재는 것이 다릅니다.

```
1,020억 = 시장이 허락하는 크기      ← 천장
4.9억  = **지금 지면으로 팔 수 있는 것**  ← 바닥
```
🔴 **그 사이가 「닿는 길」입니다.** 3번이 「300억이 되려면 SAM 의 19.5%가 사야 한다」고 적었습니다.
   지금 지면은 1만 3천 장이고, 그걸로는 255만 명에게 못 닿습니다.

⭐ **그래서 3번이 스스로 낸 결론이 옳습니다** — 「소매는 다섯 해를 다 걸어도 5억이 천장이다.
   693억 자리는 소매가 아니라 **자료 판매**다」.

⛔ 저는 목표를 안 내립니다. **길을 바꿉니다** —
```
소비자 소매(9,900원 건당)   2031 에 5억 ~ 수십억. 천장이 낮다 ●
693억 자리                  **자료 판매(B2B)** 로 옮긴다 → 아래 ②
```

⚠ **이 표는 제가 방금 한 번 10배 틀렸다가 고친 것입니다.**
   51만 명 × 2만원을 1,020억이라 적었는데 **102억**이었습니다.
   ⭐ 그래서 이 표는 **곱셈이 보이게** 적었습니다. 총액만 적으면 또 틀립니다.

## ② 8번 원자료 — **무엇인지부터 적습니다**

### 파는 것이 무엇인가

```
원본        공공데이터입니다. 공짜고 누구나 받습니다
파는 것     원본에 **네 칸을 붙인 한 벌**
            ① 출처      기관·데이터셋 번호·이용허락범위·받은 날·원본 경로
            ② 덮는범위  이 자료가 **못 보는 것**
            ③ 대조      어느 공표치와 몇 % 다른가
            ④ 경고문    이 수로 하면 안 되는 말
```
⭐ 실제로 붙여 놓은 것입니다 — 학과 축 공표와 **0.03%** 안 · 취업 갈래 **0.04%** 안 ·
   지역 축 **r=0.935** · 업종 축은 **「공표에 같은 칸이 없다」고 적음** ●

⛔ 파는 것은 자료가 아니라 **「이 숫자 어디서 났습니까」에 한 줄로 답이 나오는 것**입니다.

### 값을 어떻게 예측하나 — **대체비용법**

⛔ 시세를 두 번 찾다 못 찾았습니다(나라장터 API 미등록 · 데이터거래소에 단가 공개 없음).
⭐ 그래서 **시세 대신 「사는 쪽이 직접 하면 얼마 드나」**로 셉니다. 이건 우리가 잽니다.

```
사는 쪽이 직접 하면        원본 받기 + 정의 확인 + 공표치 대조 + 못 보는 것 찾기
8번이 실제로 쓴 시간        ⬜ 8번이 적습니다 (며칠인지 본인이 압니다)
분석 담당자 하루 인건비      ⬜ 8번이 공표 자료로 잽니다
값 = 걸린 날 × 하루 인건비 × (1 - 우리 할인)
```
⭐ **이 방법의 좋은 점** — 시세를 몰라도 되고, 손님에게 그대로 설명이 됩니다.
   「직접 하시면 N일 걸립니다. 우리는 그 절반 값입니다」

⚠ 3,392곳 × 곳당 300만원 = 100억은 **제가 짐작으로 적었던 수입니다. 걷습니다.**
   위 방법으로 8번이 다시 냅니다.
