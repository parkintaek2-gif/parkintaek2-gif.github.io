## 5. ⚠ 이 세션에서 내가 틀린 것 — 되풀이하지 말 것

**두 번 다 「확인 안 하고 단정」이었다.**

```
① 루트만 보고 하위 도메인을 안 봤다
   intellitv.net 을 「글 1편」이라 했는데 하위 3곳에 407편이 있었다.
   옆 세션이 잡아 줬다. 바로 앞 글에서 내가 그쪽에 「실측하라」고 써 놓고 그랬다

② 건수만 보고 내용을 안 봤다
   wikitip 티스토리 56편을 「버리면 안 될 자산」이라 했는데
   열어 보니 전부 2020년 한국어 요리 글이었다. 한 편도 콘셉트에 안 맞는다

→ 「안 뜨는 것」과 「없는 것」은 다르다. 「건수」는 「가치」가 아니다.
   DNS 패널의 CNAME 목록이 하위 도메인 지도다. 옮기기 전에 제목이라도 전수로 읽는다
```

**그 밖에 배운 것**
```
Cloudtype 프록시가 5xx 본문을 자기 에러페이지로 갈아치운다 → 4xx 로 내렸다
스테이지 시크릿은 저장(ctype stage secret)과 주입(app.yaml env)이 별개다
maxLength 는 타이핑만 막고 붙여넣기는 통과시킨다 → 폼 제출 전 값을 직접 읽는다
React 폼은 네이티브 setter + input/change 이벤트라야 값이 들어간다
가비아 DNS 패널은 실물과 다를 수 있다. nslookup @8.8.8.8 이 사실이다

⭐ 2026-08-03 에 크게 배운 것 넷
  SPA 화면과 씨름하지 말고 **그 사이트의 API 를 세션 쿠키로 직접 부른다**
    Cloudflare 존 생성·DNS 4건을 /api/v4 로 30초에 끝냈다. 대시보드는 뜨지도 않았다
  화면이 iframe 안에 있으면 바깥 DOM 조회가 **0개**로 나온다
    RapidAPI Studio 가 그랬다. document.getElementById('studio-iframe').contentDocument
  쿠키 동의 배너가 **클릭을 통째로 가로챈다** → #onetrust-consent-sdk 를 remove()
  OpenAPI **3.1 은 RapidAPI 가 못 읽는다** → 3.0.3 + nullable:true
```

```

⬜ 가비아에서 NS 교체  kami.ns.cloudflare.com / keenan.ns.cloudflare.com
   ← 이것만 하면 뜬다. **다만 아래를 고치기 전에는 바꾸지 말 것**
```

한 번 지웠다가 같은 날 되살렸다. **도메인과 존을 안 지워 둔 덕에 한 줄로 복구됐다.**
자산은 함부로 없애지 않는다.

## Ⅳ. ⭐⭐ 포털 신청은 자동화된다 — 오늘 4건을 사장님 손 없이 끝냈다

원인 진단을 **두 번 틀렸다.** 「내 클릭이 등록 안 된다」·「CAPTCHA 때문이다」 둘 다 아니다.
진짜는 `fn_save()` 가 띄우는 **네이티브 `confirm("신청하시겠습니까?")`** 다.
그게 뜨면 **브라우저 자동화가 통째로 멎는다.** 에러도 안 난다.

```js
window.confirm = () => true; window.alert = () => {}; fn_save();
```

이 세 줄로 국민연금 변경 1건 + 대학알리미 3건이 통과했다.
**「눌렀는데 안 된다」에서 멈추고 원인을 지어내지 말 것. 계측하면 1분이다.**

곁들여 — 「전체 선택」은 안 먹는다(개별 `click()`), textarea 는 네이티브 setter + input/change.
