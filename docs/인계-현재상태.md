   wikitip 티스토리 56편을 「버리면 안 될 자산」이라 했는데
   열어 보니 전부 2020년 한국어 요리 글이었다. 한 편도 콘셉트에 안 맞는다

→ 「안 뜨는 것」과 「없는 것」은 다르다. 「건수」는 「가치」가 아니다.
   DNS 패널의 CNAME 목록이 하위 도메인 지도다. 옮기기 전에 제목이라도 전수로 읽는다
```

**그 밖에 배운 것**
```
Cloudtype 프록시가 5xx 본문을 자기 에러페이지로 갈아치운다 → 4xx 로 내렸다
스테이지 시크릿은 저장(ctype stage secret)과 주입(app.yaml env)이 별개다
maxLength 는 타이핑만 막고 붙여넣기는 통과시킨다 → 폼 제출 전 값을 직접 읽는다
React 폼은 네이티브 setter + input/change 이벤트라야 값이 들어간다
가비아 DNS 패널은 실물과 다를 수 있다. nslookup @8.8.8.8 이 사실이다

⭐ 2026-08-03 에 크게 배운 것 넷
  SPA 화면과 씨름하지 말고 **그 사이트의 API 를 세션 쿠키로 직접 부른다**
    Cloudflare 존 생성·DNS 4건을 /api/v4 로 30초에 끝냈다. 대시보드는 뜨지도 않았다
  화면이 iframe 안에 있으면 바깥 DOM 조회가 **0개**로 나온다
    RapidAPI Studio 가 그랬다. document.getElementById('studio-iframe').contentDocument
  쿠키 동의 배너가 **클릭을 통째로 가로챈다** → #onetrust-consent-sdk 를 remove()
  OpenAPI **3.1 은 RapidAPI 가 못 읽는다** → 3.0.3 + nullable:true

사장님 지시(2026-08-03 21:1x KST):

> 「**서울마켓이 현재로선 제일 할 게 많으니 그걸 하라는 거야**」
> 「서울마켓이 어느 정도 **큰 업무가 마무리 되면, 위키팁을 시작하자**」

**PG 승인 지연은 위키팁과 무관하다** — 무료 매체라 결제가 없다.
멈춘 이유는 그게 아니라 **순서**다. 서울마켓츠에 할 일이 더 많다.

### 지금 상태 — 되살려 뒀다. 시작하려면 NS 한 번이면 된다

```
✅ src/pages/wikitip/index.astro    영문 첫 화면 (K컬처 · 동남아 1차 독자)
✅ src/pages/wikitip/esports.astro  랭크 사다리 지면
✅ server.mjs  SITE_PREFIX 에 'wiki-tip.com' → '/wikitip'
✅ Cloudflare 존 + 레코드(34.8.247.175) + Cloudtype 소유확인 TXT
⬜ 가비아에서 NS 교체  kami.ns.cloudflare.com / keenan.ns.cloudflare.com
   ← 이것만 하면 뜬다. **다만 아래를 고치기 전에는 바꾸지 말 것**
```

한 번 지웠다가 같은 날 되살렸다. **도메인과 존을 안 지워 둔 덕에 한 줄로 복구됐다.**
자산은 함부로 없애지 않는다.

### ⚠ 시작 전에 반드시 고칠 것 — 브랜드가 섞여 있다

```
wiki-tip.com/esports  제목: "Why Korea's ladder looks different | SeoulMarkets"
                      머리말·꼬리말도 SeoulMarkets 것이다 (Base.astro 를 쓴다)
```

**K컬처 도메인에 금융 매체 얼굴이 나온다.** 사장님이 Riot 신청 때 지적하신 그 문제다.
제목만 고치면 머리말이 남아 **반쪽짜리가 더 나쁘다.** 시작할 때 제대로 한다.

고치는 방법은 둘이다. 후자를 권한다.
1. `Base.astro` 에 `siteName` prop 을 뚫는다 → 제목은 고쳐지나 머리말·꼬리말이 남는다
2. `wikitip/index.astro` 처럼 **자체 레이아웃**으로 뗀다 → 맞는 방법. 12KB 한 파일이다

### ⚠ 그리고 Riot

`src/pages/esports.astro`(seoulmarkets.com 쪽)는 **Riot 심사 App 866800 의 Product URL** 이다.
승인 전까지 **지우지도 내리지도 않는다.** 승인 후에 위키팁으로 옮기고 그때 원본을 지운다.
두 벌로 두는 이유가 이것이다.
