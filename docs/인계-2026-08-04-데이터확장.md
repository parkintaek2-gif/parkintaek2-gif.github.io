### KDI 는 **A만 승인됐다**

```
✅ cd=A  기본연구보고서  838건 (영문제목 249 · 영문요약 128)
⚠ cd=B~F  전부 null — 현안자료·경제전망·경제동향·학술지·영상보고서
```
신청 URL 이 `openAPIApp?...&type=A` 였다. **A만 신청된 것**이다.
B~F 가 필요하면 **같은 폼에서 type 을 바꿔 다시 신청**해야 한다. 사장님 손이 필요하다.
호출 꼴 — `https://www.kdi.re.kr/KDIOpenAPI?type=json&apiKey={키}&cd=A`
⚠ 오류 응답이 **EUC-KR** 이다. UTF-8 로 읽으면 깨져서 원인을 못 찾는다.

## 3. ⚠ 반드시 알고 있어야 할 함정

```
① DART 신고 단위가 회사마다 다르다
   근속 「54」= 개월을 년 칸에 · 급여 「24,400」= 천원 단위 · 「453억」= 총액
   → render-ranking.mjs 의 `이상점검()` 이 60개사를 걸러낸다. **고치지 않고 걸러만 뒀다**
   → 순위표는 1위가 쓰레기면 표 전체를 못 믿게 된다

② 재직기간(hffc_pd)이 자유 서식이다
   「10개월」「3년 2개월」「2012.12.18~현재」「-」 → 파싱 67.1%
   → 원문(`재직원문`)을 NDJSON 에 남겨 뒀다. **API 재호출 없이 다시 읽을 수 있다**

③ induty_code 자릿수가 2~5자리로 섞인다 (실측 40개사: 2자리1·3자리15·4자리8·5자리16)
   → 앞 2자리로 정규화해야 업종 집계가 갈라지지 않는다

④ 학력 파서가 「대학」이 없는 학교를 놓친다 — KAIST·POSTECH 등. 약칭 목록을 유지한다

⑤ `??` 와 `||` 를 괄호 없이 못 섞는다 (문법 오류)
⑥ `import.meta.url === pathToFileURL(process.argv[1])` 는 argv[1] 가드가 필요하다
```
