# 아시아 상장기업 **신용등급** — 어디서 받나 (2026-09-15 실측)

> 사장님: **「아시아 상장기업 신용등급 데이터 찾아서 서비스하자. 등급만 무료로 주는데 있지 않나?」**

**있습니다. 다만 문이 둘로 갈립니다** — 이것이 이 문서의 전부입니다.

```
⛔ 신용평가사 «자기 지면»   보는 것은 공짜지만 «다시 파는 것»은 대개 금지다.
                          등급이 그들의 상품이기 때문이다
✅ 거래소·규제기관 «공시»   회사가 «자기 공시로» 낸 등급이다. 여기가 열린 문이다
```

⭐ 이것은 우리가 이미 쓰는 수법과 같습니다 — 사장님이 정하신
「공시는 중대사건만 뽑으면 라이선스가 안 걸린다」가 등급에도 그대로 걸립니다.

---

## 1. 🇮🇳 인도 — **지금 바로 되는 곳.** 공짜 · 구조화 · 날마다

2025-08-02 부터 인도 규제(SEBI)가 **신용평가사에게 등급을 날마다 엑셀로 올리게** 하고,
거래소(NSE)가 그것을 **자기 지면에 자동으로 뿌리게** 했습니다(LODR Reg 30 · 시스템 공시).
곧 **평가사가 파는 것이 아니라 거래소가 공시하는 것**입니다.

```
문       https://www.nseindia.com/api/credit-rating-sdd-reg30?index=equities
         (?index=sme 도 있다 · ?index=debt 은 지금 비어 있다)
지면     https://www.nseindia.com/companies-listing/corporate-sdd-credit-rating-reg30
robots   User-agent: *  Allow: /      ⭐ 막은 것이 /market-data-test 하나뿐이다
```

### 실측 (2026-09-15)

```
equities   50,986줄 · 상장사 1,683곳 · 32.5MB
sme          약 1MB 더
칸 18개    creditAgencyName · symbol · companyName · isin · classOfAction ·
           ratingAssigned(무엇에 매긴 등급인가) · typeOfRating(장기/단기) ·
           creditRating · outlook · dateOfCurrentCredit · amount ·
           currentAction · detailsOfRatingLink · broadcastDateTime · disseminationDate …
전망(outlook) 이 붙은 줄 37,044
등급 움직임  Re-affirm 29,960 · Other 16,643 · Upgrade 2,389 · New 1,362 · Downgrade 599
평가사 7곳  CRISIL 26,707 · ICRA 10,251 · CARE 9,600 · India Ratings 3,295 ·
           Infomerics 589 · Acuite 485 · Brickwork 53
```

⭐ **이 자료의 값어치는 「등급」이 아니라 「올리고 내린 것」에 있습니다.**
  올린 2,389건·내린 599건은 날짜가 박혀 있어 **주가와 맞대어 볼 수 있습니다.**
  남들은 「지금 등급이 무엇인가」를 팔지만, 우리는 「언제 바뀌었나」를 가질 수 있습니다.

### ⚠ 그대로 쓰면 안 되는 것 — 실측하다 나온 흠

```
날짜에 2205-12-04 가 있다     신고자가 잘못 친 것이다. 고쳐 넣지 말고 «못 믿는 날»로 표시한다
currentAction 글자가 제각각   Downgrade/Downgraded · Re-affirm/Reaffirmed · Other/Others ·
                             New/new/Assigned — 묶어야 세어진다. 묶은 규칙을 지면에 적는다
```

### 🔴 아직 안 읽은 것

NSE 지면의 **이용약관**을 아직 안 읽었습니다. robots 가 열려 있는 것과 재배포가 되는 것은
다릅니다(바로 아래 일본이 그 본보기입니다). **약관을 읽기 전에는 상품으로 내지 않습니다.**

## 2. 🇯🇵 일본 JCR — **보는 것은 공짜, 다시 파는 것은 «금지»**

```
robots   User-agent: *  Disallow:        ← 아무것도 안 막는다
지면     https://www.jcr.co.jp/en/ratinglist/  (회사·금융·공공·구조화·국가 다섯 갈래)
          회사 갈래만 17쪽 × 약 45곳 = 약 750곳. 이름·코드·장기등급/전망·단기등급
```

⛔ **그런데 약관이 막습니다.** JCR 문서와 지면에 이렇게 박혀 있습니다 —
> JCR retains all rights pertaining to this document, including JCR's rating data.
> Any reproduction, adaptation, alteration, etc. of this document, including such
> rating data, is prohibited, whether or not wholly or partly, without prior consent of JCR.

⇒ **robots 가 열렸다고 재배포가 되는 것이 아닙니다.** 이 한 줄이 이 문서를 쓴 까닭입니다.
  일본을 하려면 ① JCR 에 허락을 청하거나 ② 도쿄증권거래소(TDnet) 공시 쪽 문을 재야 합니다.

## 3. 🇰🇷 한국 — **아직 문을 못 찾았습니다.** 못 찾았다고 적습니다

```
한국신용평가 kisrating.com     robots: User-agent: *  Disallow: /     ⛔ 막혔다
한국기업평가 korearatings.com  robots.txt 가 없다(지면이 나온다)      ⬜ 약관을 아직 안 읽었다
NICE신용평가 nicerating.com    닿지 못했다(코드 000)                  ⬜ 다시 재야 한다
금투협 채권정보센터            옛 프레임 지면이라 겉만 봐서는 모른다   ⬜ 크롬으로 열어 봐야 한다
공공데이터포털                 「신용등급」으로 나오는 것은 공공기관·국가등급뿐  ⛔ 상장사 것이 아니다
DART 속보 공시                 최근 734건에 「신용·등급」 제목 0건     ⛔ 주요사항보고 항목이 아니다
```

⇒ 한국은 **사업보고서·증권신고서 본문의 「신용평가에 관한 사항」** 을 파야 할 가능성이 큽니다.
  그건 구조화 API 가 아니라 문서 파싱이라 인도보다 훨씬 비쌉니다.
  **그래서 인도를 먼저 합니다.** 싸고 열린 곳부터 엽니다.

## 4. 🇦🇪 UAE — 지금은 길이 없습니다

ADX·DFM 상장사는 대개 S&P·Moody's·Fitch 가 매깁니다. 셋 다 유료이고 재배포를 막습니다.
지역 평가사(예: 이슬람국제평가기관)도 무료 목록을 내지 않습니다. ⬜ 더 재 봐야 합니다.

## 5. 그래서 무엇을 파나

⛔ **「지금 등급이 무엇인가」를 팔지 않습니다.** 그건 평가사의 상품이고, 우리가 낼 자격도 없습니다.
✅ **「누가 언제 올리고 내렸나」를 팝니다.** 그것은 거래소가 공시한 «사건»이고,
   우리 강령이 이미 그 자리에 서 있습니다 — 사실만 놓고 판단은 손님이 합니다.

```
1. 등급 변경 이력 (인도 1,683곳 · 올림 2,389 · 내림 599)   ← 날짜가 박혀 있다
2. 평가사끼리 «같은 회사»를 다르게 본 곳                    ← 남들이 안 세는 축
3. 등급이 «빠진» 곳 — 철회(Withdrawn 1,736건)              ← 말없이 사라지는 것을 우리가 센다
```

⛔ 「이 등급이면 사라/팔라」를 말하지 않습니다. 투자자문이 아닙니다.

# 🟢 [2026-09-20 · 5번] 인도를 이어받아 다시 쟀다

사장님이 아시아 확장 주인을 다시 정하시면서 인도가 제 몫이 됐습니다.

## 6-1. 위 2번의 「소급이 되는지 모른다」에 답이 나왔다 — **된다**

쌓아 둔 세 벌을 열어 보니 창이 셋 다 **2025-01-10** 에서 시작하고 건수만 늡니다.

```
받은 날    사건      변경 사건   창(가장 이른 ~ 가장 늦은)
09-15    21,956     4,898     2025-01-10 ~ 2026-11-09
09-18    22,295     4,975     2025-01-10 ~ 2026-11-09
09-20    22,344     4,993     2025-01-10 ~ 2026-11-09
```

⇒ 굴러가는 창이 아니라 **누적**입니다. 그러니 —

```
✅ 하루 빠뜨려도 잃는 것이 없다 (검사에 「누적」 딱지를 붙여 자가 그렇게 말해 준다)
✅ 오늘 받은 «한 벌»에 이미 20개월치 등급 변경 4,993건 · 회사 1,320곳이 들어 있다
   — 「1년을 쌓아야 상품이 된다」가 아니다. 상품은 이미 손에 있다
⛔ 그래도 감시에서 빼지 않는다 — 출처가 창을 언제 자를지 모른다
```

`scripts/build-india-rating-moves.mjs` 를 돌려 보면 이미 이런 것이 나옵니다 —
달마다 올림÷내림 비율(2026-04 는 16배), 거듭 내려간 곳 132곳, 등급이 «사라진» 곳 1,884건·315곳.

## 6-2. 남은 것은 오직 «어디서 받은 것을 내도 되나»

NSE 약관이 재배포를 막습니다(위 인용). 그러면 우리 규칙대로 **다른 열린 우물**을 찾습니다.
인도는 SEBI 가 평가사에게 공개를 의무로 지우므로 **평가사 제 사이트가 1차 출처**이고
NSE 는 그것을 모은 2차입니다. 오늘 두드린 결과 —

```
CRISIL        지면 200 · robots 가 뿌리째 막음                ⛔
ICRA          지면 200(297KB) · robots 뿌리는 안 막음          ✅ 다음에 약관을 읽는다
CARE          목록 주소가 404 — 주소를 다시 찾아야 한다          ⬜
India Ratings 200 · robots 뿌리는 안 막음                      ✅ 다음에 약관을 읽는다
Acuite        403 — 맨 요청을 막는다. 크롬으로 다시 잰다          ⬜
Infomerics    404 — 주소를 다시 찾아야 한다                     ⬜
data.gov.in   200 — 다만 검색이 화면에서 그려져 맨 글에는 안 보인다  ⬜ 크롬으로 다시
SEBI          맨 요청 실패                                    ⬜ 크롬으로 다시
```

⚠ **robots 가 열렸다고 약관이 열린 것이 아니다.** NSE 도 robots 는 열려 있었고 약관이 막았습니다.

## 6-3. 그 약관을 그 자리에서 읽었습니다 — **평가사도 막습니다**

ICRA 이용약관 원문(2026-09-20 읽음) —

> 「…you may not modify, create derivatives of, copy, distribute, broadcast, transmit,
>  reproduce, publish, license, transfer, sell, mirror, frame, "deep link", **"scrape"**,
>  data mine, or otherwise use any information…」

**NSE 조문과 같은 자리입니다.** 「scrape」를 낱말로 못박은 것만 더 셉니다.

크롬(9222)으로 막힌 문도 다시 쟀습니다 —

```
data.gov.in   200 · 「Searched Item: Credit Rating」까지 뜨고 결과가 «0»       ⬜ 자료 자체가 없어 보인다
SEBI          크롬으로도 net::ERR_TIMED_OUT                                  ⬜ 「못 쟀다」
Acuite        Cloudflare 가 막는다(403 · "you have been blocked")             ⛔ 막힘
```
