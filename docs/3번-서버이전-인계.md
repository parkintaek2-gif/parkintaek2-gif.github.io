## 1. 🔴 어제 찾은 것 — **이것부터 보라**

### ① 방문자 수가 우리 손으로 부풀어 있다

```
node 내장 fetch 의 user-agent 는 그냥  "node"
src/lib/traffic.mjs 의 봇패턴에는      node-fetch 는 있고 node 단독은 없다
⇒ 우리가 라이브 200 을 잴 때마다 그것이 「방문자」로 세어진다
```

* 7일치(8/15~21) 유입 — **(직접) 14,363 · (내부) 897 · 밖에서 190**
* **밖에서 온 것이 하루 27명.** 사장님이 매기신 하루 1,000명의 **2.7%** 다
* 내 쪽은 고쳤다 → `scripts/lib/라이브재기.mjs` 를 **반드시 써서** 라이브를 잰다
* ⛔ 공용 부품(`traffic.mjs`)은 안 건드렸다. **2번께 ㉮㉯ 를 여쭀고 답을 못 받았다**
  ```
  ㉮ 봇패턴에 ^node$|^undici 를 넣는다 — 전 유닛의 수가 한 번에 정직해진다
  ㉯ 각 유닛이 재는 쪽만 고친다 — 나는 했다. 6·7번은 아직이다
  ```
  🔴 **새 서버에서 2번께 이것을 다시 물어라.** 이 답이 없으면 목표 수를 못 믿는다

## 5. ⛔ 어제 세 번 미끄러진 자리 — 같은 데서 또 넘어지지 마라

```
① 셸이 백틱·$env:·백슬래시를 먹는다
   긴 마크다운·정규식·경로를 `node -e` 나 heredoc 으로 쓰지 않는다 → Write/Edit 로 쓴다

② 이 저장소 파일은 CRLF 다
   여러 줄 앵커를 '\n' 으로 찾으면 안 잡힌다 → 한 줄 앵커를 쓰고 줄끝을 그 파일에 맞춘다
③ HTTP 헤더에 한글을 못 넣는다 (latin-1 뿐)
   UA 에 한글을 넣었다가 60장을 다 놓쳤다
```
