## ⛔ 답을 적는 법 — 이것부터 지킨다

```
수를 적는다        ⛔ 「진행 중」·「검토했다」·「곧 됩니다」는 답이 아니다
0 과 ? 와 벽을 가른다
   0    재 봤는데 없다        ← 우리 잘못이다
   ?    못 쟀다               ← 자를 안 댔다
   벽   계정·권한이 없어 못 했다 ← 우리 잘못이 아니다. 자산은 준비된 채로 둔다
● 과 ○ 을 가른다
   ●    본 것 (남의 요금표·실제 발주·화면에서 잰 것)
   ○    우리가 정한 것
   ⛔ ● 이 하나도 없는 매출 줄은 「근거 있는 수」로 안 센다
```

⚠ **모르면 「모름」이라 적는다.** 채우려고 지어내면 그게 8/8 의 「373억을 근거 없이 얹었다」다.
