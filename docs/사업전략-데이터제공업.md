2. **컨센서스** — 증권사 리포트를 20년간 모아 만든 것. 공공데이터에 없다

이 중 **1·3 은 지금부터 만들 수 있고, 2 는 진입장벽이 높으며, 4 는 시간이 필요하다.**

## 1. 우리가 이길 수 있는 지점 — 네 가지

### ① 영문화 — 가장 큰 빈칸

한국 공공데이터는 **전부 한국어다.** 법정동코드, 계정과목명, 공시 유형명, 업종분류
모두 한글이다. 외국 기관이 쓰려면 사람이 번역해야 한다.

Bloomberg·Refinitiv 는 한국 대형주는 커버하지만 **중소형주, 부동산 실거래, 공시 세부,
사모펀드 통계는 얇다.** 한국 특유의 데이터일수록 비어 있다.

**이미 우리 것이다.** SeoulMarkets 가 영문 매체다. 데이터 정규화도 영문 기준으로 하면
미디어와 데이터가 같은 자산을 쓴다.

### ② 금융 × 부동산 결합 — 아무도 안 하는 것

FnGuide 는 금융, 부동산원·KB 는 부동산이다. **둘을 잇는 곳이 없다.**

그런데 실제 인과는 이어져 있다.

```
기준금리 → 대출금리 → 거래량 → 실거래가 → 건설사 실적 → 회사채 스프레드
                                    ↘ 가계부채 → 소비 → 내수주
```

한 화면에서 이 사슬을 보여주는 데이터셋은 국내에 없다.
**우리는 양쪽 원천을 「제한 없음」으로 이미 확보했다.**

### ③ 개발자 친화 — 공공 API 는 쓰기 나쁘다

공공데이터포털 API 의 실제 문제:
XML 기본 · 인증키 URL 인코딩 이슈 · 데이터셋마다 응답 구조가 다름 ·
법정동코드를 따로 구해야 함 · 페이지네이션 제각각 · 문서가 부실함 ·
**T+1 인데 화면에는 "실시간"이라 적혀 있음**

한국판 Alpha Vantage / Polygon 이 없다. **깨끗한 JSON REST 하나가 곧 제품이다.**

### ④ 아카이브 — 지금 시작해야 하는 유일한 것

**공공 API 는 과거를 소급해 주지 않는다.** 조회 기간이 제한된 데이터셋이 많고,
개편되면 옛 형식이 사라진다.

FnGuide 의 진짜 해자가 이것이다. 20년치는 돈으로 못 산다.

> **가장 시급한 실행 항목은 이것이다. 오늘부터 매일 수집해 저장한다.**
> 기사를 안 쓰는 날에도 데이터는 받는다. 1년 뒤 이 아카이브가 자산이 된다.

## 1.5 확장 — 실물 경제데이터 (2026-08-01 추가)

금융 데이터는 이미 붐비는 시장이다. **실물 경제데이터는 비어 있고, 우리가 이미 쓸 수 있다.**

### ⭐ 최우선 상품 — 관세청 수출입 데이터

이번 조사에서 나온 **가장 큰 발견**이다.

**확인한 사실**

| 항목 | 내용 |
|---|---|
| 데이터셋 | 관세청_품목별 국가별 수출입실적(GW) 외 5종 |
| **이용허락범위** | **제한 없음** |
| **갱신주기** | **실시간** |
| 항목 | 기간·국가명·국가코드·품목명·**HS코드**·수출중량·수출금액·수입중량·수입금액·무역수지 |
| 발표 주기 | **매월 1일(전월 확정), 11일·21일(10일 단위 잠정) 오전 9시** |

**왜 이게 최고의 상품인가 — 세 가지 사실**

1. **세계에서 가장 빠르다.** 월간 무역통계를 다음 날 내는 나라가 세계에 거의 없다.
   UN Comtrade 는 최대 1개월 지연이고 개도국은 더 늦다.
2. **블룸버그가 이미 「세계 12대 경제지표」로 선정했다.** 우리가 가치를 주장할 필요가 없다.
   이미 세계가 인정한 지표다.
3. **한국 경제 구조상 글로벌 공급망 변화가 여기 제일 먼저 찍힌다.** 원자재를 수입해
   가공해 재수출하는 구조라서다. 반도체·자동차·화학 수출이 곧 세계 수요의 선행 신호다.

**그런데 비어 있는 것**

| 있는 것 | 없는 것 |
|---|---|
| 관세청이 한국어 보도자료로 총액 발표 | **HS코드 단위 시계열을 영문 API 로** |
| 로이터·블룸버그가 총액을 기사화 | **품목×국가 교차 조회** |
| 총액 중심 | **"미국향 반도체가 몇 % 꺾였나"** |

> **이게 우리의 첫 유료 제품이다.** 해외 매크로 헤지펀드·원자재 트레이더·공급망 리서치가
> 실제로 돈을 내고 볼 데이터다. 그리고 **원가가 0원이다.**

**연결 효과** — SeoulMarkets 기사와 K-컬처 매체가 같은 데이터를 쓴다.
"음반 수출액"도 HS코드다. **엔터 산업 기사의 근거 데이터가 여기서 나온다.**

### 이 확장이 만드는 것 — 「선행지표 데이터셋」

금융 데이터는 **결과**다. 실물 데이터는 **원인**이다. 그리고 원인이 먼저 나온다.

```
관세청 10일 수출 (T+1)          →  분기 실적 (T+45일)      →  주가
오피넷 유가 (실시간)            →  정유·항공 원가          →  실적
전력 사용량                      →  산업 가동률            →  생산지수
등기 법인 설립·해산              →  경기 사이클
상권 점포 개·폐업                →  소비·자영업 체감
벤처투자 집행                    →  스타트업 사이클
조달 발주                        →  건설·IT 기업 수주
```

**국내 어느 벤더도 이 사슬을 하나의 스키마로 안 판다.** FnGuide 는 금융, 부동산원은 부동산,
통계청은 통계다. **잇는 자리가 비어 있고, 원천이 전부 공짜다.**

## 2. 우리가 못 이기는 지점 — 정직하게

| 영역 | 이유 | 대응 |
|---|---|---|
| **실시간 시세** | KRX 유료 라이선스. 재배포 불가 | 하지 않는다. T+1 로 승부 |
| **컨센서스·목표주가** | 증권사 리포트 수집 필요. 관계·비용·저작권 | 3단계 이후 판단 |
| **기관 영업** | 자산운용사·연기금 구매는 관계 기반 | 개발자·해외 먼저 |
| **예탁결제원 데이터** | 상업적 이용금지 정황 | 확인 전 사용 금지 |

**실시간을 포기하는 것이 전략이다.** 실시간은 거래 목적이고, 거래 목적 데이터는
정확성 책임(SLA·배상)이 따라온다. 우리는 **분석·리서치·연구 목적**으로 간다.

## 3. 제품 계층 — 4단

```
L0  미디어 (SeoulMarkets)          무료      신뢰·유입·SEO·브랜드
     ↓ 같은 데이터 파이프라인을 공유
L1  데이터 API                     종량제    개발자·핀테크·퀀트·학계
     ↓
L2  대시보드/터미널                 구독      리서치·중소 운용사·언론
     ↓
L3  커스텀·벌크·라이선스            계약      기관·해외 벤더
```

**미디어가 마케팅이다.** 기사마다 "이 숫자는 우리 API 에서 나왔다"가 붙는다.
FnGuide 는 미디어가 없어서 개발자에게 알려지지 않았다. 우리는 반대로 간다.

### L1 데이터 API — 첫 유료 제품

**엔드포인트 설계 원칙**
- JSON only. XML 안 준다
- 종목코드·법정동코드를 사람이 안 찾아도 되게 — 이름으로 조회 가능
- **모든 응답에 `as_of` 와 `source` 를 넣는다.** 미디어에서 하던 것과 같은 원칙
- 무료 티어를 넉넉히 — 개발자가 써보고 결정하게

**초기 셋**
```
── 금융
/v1/equities/{code}/prices        일별 시세 (T+1)
/v1/disclosures?since=            공시 스트림
/v1/financials/{code}             재무제표 (표준화)
/v1/fx/krw                        환율
/v1/rates/curve                   국고채 커브
/v1/funds/{code}/returns          펀드 수익률·보수

── 부동산
/v1/housing/transactions?region=  실거래 (국토부)
/v1/housing/index?region=         지수 (부동산원)

── 실물경제  ★ 2026-08-01 확장
/v1/trade/exports?hs=&partner=    ⭐ 품목×국가 수출입 (관세청, HS코드)
/v1/trade/flash                   ⭐ 10일 단위 속보 (1·11·21일 09:00)
/v1/energy/fuel-prices            주유소 유가 (오피넷)
/v1/energy/power                  전력 수급·SMP (전력거래소)
/v1/corporates/registrations      법인 설립·해산 (대법원 등기)
/v1/retail/storefronts?region=    상권 점포 (소상공인공단 · 국세청·카드사 원천)
/v1/vc/investments                벤처투자 집행 (KVIC)
/v1/fiscal/budget                 예산·집행 (열린재정)
/v1/stats/{indicator}             KOSIS 표준화 시계열
```

**차별점은 세 층에 다 있다.**
- 금융 API 와 부동산 API 가 같은 스키마·같은 인증으로 나오는 곳은 없다
- **`/v1/trade/flash` 는 세계에서 가장 빠른 무역 지표다.** 이게 단독 상품이 된다
- `/v1/retail/storefronts` × `/v1/housing/transactions` 결합은 국내 최초다

## 4. 단계별 실행

### 1단계 (0~6개월) — 파이프라인과 아카이브

- [ ] **수집기 구축.** 매일 전 데이터셋을 받아 원본 그대로 저장(raw) + 정규화(clean)
- [ ] **아카이브 시작.** 이게 최우선. 하루 늦으면 하루치를 영영 못 얻는다
- [ ] **관세청 10일 속보 수집을 최우선 배치** — 매월 1·11·21일 09:00 자동 수집.
      놓치면 그 회차는 잠정치라 나중에 확정치로 덮여 **원본이 사라진다**
- [ ] 미디어(L0) 발행 계속 — 신뢰 축적
- [ ] 영문 정규화 사전 구축: 계정과목·업종·공시유형·법정동 · **HS코드 품목명**
- 비용: 스토리지 정도. 원천이 공짜다

### 2단계 (6~12개월) — API 공개

- [ ] 무료 티어로 공개. 개발자 확보가 목적
- [ ] 문서·SDK. 한국 데이터인데 **문서는 영문**
- [ ] 미디어 기사에 API 링크 삽입 — 자연 유입
- [ ] 유료 티어 도입 (종량제)
- 이 시점에 **1년치 아카이브**가 무기가 된다. 공공 API 로는 못 얻는 구간

### 3단계 (12~24개월) — 대시보드·기관

- [ ] 금융×부동산 결합 대시보드

## 5. 법적 정리 — 게이트는 걷는다 (2026-08-01 지시 반영)

**개정 전:** 「공공데이터 유료 재판매 가능 여부를 서면 질의로 확인하기 전에는 유료화하지
않는다」는 차단 조건을 걸어 두었다.

**개정 후:** **걷어낸다. 유료화를 막지 않는다.**

근거는 두 가지다.

1. **「이용허락범위 제한 없음」은 문언 그대로 제한이 없다.** 공공데이터법의 원칙 자체가
   영리 목적 이용 허용이다. 제한을 두려는 데이터셋은 「제2유형(상업적 이용금지)」처럼
   따로 표기한다. 표기가 없는 것을 두고 우리가 제한을 상상할 이유가 없다.
2. **인터넷신문으로 등록한다** (사장님 지시). 언론사 지위가 생긴다.

> ⚠ **다만 두 가지는 서로 다른 법이라는 점만 기록해 둔다.**
> 인터넷신문 등록은 「신문 등의 진흥에 관한 법률」이고, 데이터 재판매 근거는
> 「공공데이터법」이다. 언론사 등록이 데이터 판매 권리를 만들어 주지는 않는다.
> **그래도 결론은 같다 — 「제한 없음」이 이미 근거이기 때문이다.** 게이트를 걷는 판단에
> 무리가 없다.
>
> **인터넷신문 등록이 실제로 크게 이로운 곳은 따로 있다:** 저작권법의 시사보도 이용·
> 인용 규정, 그리고 기획사·기관의 **보도자료·사진 수신 자격**이다.
> → 한류 매체의 사진 문제에 직접 효과가 있다. `신규사업/한류매체-동남아-시장조사.md` 참조

### 언론사 지위는 데이터 쪽에도 유리하다 (2026-08-01 지시)

사장님 지시: *「연예기획사, 정부/공공기관 데이터를 가공하는 건 한국에선 언론사들은 할 수 있어」*

**데이터 가공·보도는 언론의 본령이다.** 한국 언론이 수십 년간 통계청·한국은행·금감원
자료를 받아 가공해 기사로 내 왔고, 그게 문제가 된 적이 없다. 기관들도 그러라고
데이터를 개방한다 — **보도되는 것이 개방의 목적**이다.

여기에 「제한 없음」 표기까지 붙어 있다. **근거가 두 겹이다.**

| 층위 | 근거 |
|---|---|
| 데이터 자체 | 「이용허락범위 제한 없음」 — 영리 이용 포함 |
| 이용 주체 | **등록 언론사** — 보도·가공이 업(業)의 정의 |
| 이용 목적 | 데이터저널리즘 — 개방 취지에 정면으로 부합 |

실무 효과도 있다.

- **기관 담당자 응대가 달라진다.** API 증량·데이터 문의·오류 정정 요청에서
  언론사 회신은 개인 개발자 문의와 처리 속도가 다르다
- **보도자료 수신 목록 등재** — 관세청·한국은행·금융위 배포를 발표 시각에 받는다.
  10일 수출 속보를 09:00 정각에 받는 것이 곧 상품이다
- **기관 통계 공표 일정 사전 공유** — 엠바고 자료 접근

> **정리:** 유료화의 근거는 「제한 없음」이 만든다. 언론사 지위는 그 위에서
> **취재·수집 속도**를 만든다. 둘이 다른 층에서 각각 일한다.

### 남는 것 — 확인이 아니라 운영 항목

법적 관문이 아니라 **엔지니어링·계약 실무**로 내린다.

- [ ] 트래픽 한도 — 운영계정 증액 상한 (기술 제약)
- [ ] 데이터 정확성 면책 조항 설계 — **B2B 는 배상책임이 따라온다.** 이건 남는다
- [ ] `제한 없음` 이 **아닌** 데이터셋을 파이프라인에서 물리적으로 차단
      (KSD·KRX 등. 이건 표기가 실제로 다르므로 계속 지킨다)
- [ ] 출처 표기 — 「제한 없음」도 출처 표시는 관례이자 신뢰 자산이다

**유료화를 막는 조건은 이제 없다. 남은 건 만드는 일이다.**

## 6. 수익 구조 (가설 — 미검증)

| 티어 | 대상 | 가격 가설 |
|---|---|---|
| Free | 개발자·학생 | 월 1만 콜 |
| Dev | 개인·소규모 | 월 3~5만원 |
| Business | 핀테크·리서치 | 월 30~100만원 |
| Enterprise | 기관·해외 | 연 계약 |

**국내 기관 데이터 시장은 작고 관계 중심이다.** 대신 **영문·해외向이 TAM 이 크다.**
한국 익스포저를 가진 해외 헤지펀드·자산운용사·리서치가 1차 타깃이다.

⚠ 위 가격은 **가설이다.** 경쟁사 실제 가격을 확인하지 않았다.
