# S 를 무엇의 약어로 쓸 것인가 — 후보군

> 사장님 지시: **「브랜드를 S마켓츠로 바꾼다. S 단어를 찾아 회사소개에 넣어라」**
> **「s를 약어로 쓰는 좋은 단어 후보군도 만들라고 했는데」** (2026-09-15)

작성 2026-09-15 · 5번
⚠ 앞서 `docs/사장님지시-2026-09-14-추적.md` Ⅱ절에 초안 한 덩어리를 적어 뒀는데,
  추적표 안에 묻혀 있어 «후보군»으로 쓸 수가 없었습니다. 따로 세워 다시 냅니다.

---

## 고르는 잣대 — 이 셋을 통과해야 후보다

```
1. 우리가 «실제로 하는 일»인가        — 안 하는 것을 이름에 넣지 않는다
2. 재서 보일 수 있나                 — 숫자로 뒷받침되지 않는 말은 과장이다
3. 투자자문 선을 안 넘나             — 우리는 신호·추천을 팔지 않는다
```

⛔ 오늘 두 번 겪었습니다 — 「아부다비를 후보 표에 넣은 것」과 「손금 아닌 걸 손금으로 판 것」.
  **이름은 내용물과 같아야 합니다.** 브랜드 약어도 같은 규칙에 걸립니다.

| S | 시장 | 지금 상태 |
|---|---|---|
| **Seoul** | 한국 KRX / DART | ✅ 라이브 |
| **Shanghai** | 중국 A주 | ▶ 6번 작업 중 |
| **Shenzhen** | 중국 A주 (상하이와 한 벌) | ▶ 6번 작업 중 |
| **Saudi** | Tadawul | ▶ 1번 배정 (2026-09-16) |

| Sydney | ASX | ⬜ 주소를 아직 못 찾았다 |

⭐ **다섯 개가 S 로 시작합니다 — 이건 우연이 아니라 아시아 시장의 생김새입니다.**
  「S Markets」가 억지로 지어낸 이름이 아니라는 근거가 여기 있습니다.

⛔ 다만 **Singapore·Sydney 는 아직 쓰면 안 됩니다.** 안 여는 문을 이름에 넣는 것은
  오늘 사장님이 「손금이 아닌데 손금을 팔면 안되지」라고 하신 것과 같은 잘못입니다.

⚠ 그리고 지명 S 는 **시장이 늘 때마다 바뀝니다.** 회사소개의 «부제»로만 쓰고,
  고정 약어로는 삼지 않는 것이 낫습니다.

## Ⅱ. 상품 — 우리가 파는 것 (이쪽이 «고정 약어» 후보다)

| S | 뜻 | 우리가 가진 근거 |
|---|---|---|
| **Statements** | 재무제표 | 🔴 주력. 한국 2,709개사 · UAE 398행 · ADX 대차대조표 121건 |
| **Standards** | 같은 규격 | 나라가 늘어도 칸 이름이 같다 — 「한 계약」이 여기서 나온다 |
| **Sources** | 출처 | 모든 수치가 어디서 왔는지와 언제 받았는지를 달고 나간다 |
| **Shareholders** | 지분·대량보유 | 공시에서 뽑는다 (한국 + UAE) |
| **Succession** | 대표·지배권 변경 | 오늘 UAE 에 태그 100건을 붙였다 (ceo-change · control-change) |
| **Series** | 시계열 | 소급이 안 되는 스냅숏을 매일 쌓는다 — 쌓일수록 값이 커진다 |
| Screens | 스크리너 | ⬜ 아직 안 만들었다 |

## Ⅲ. 태도 — 우리가 약속하는 것

```
Same        같은 규격 · 같은 라이선스 · 같은 값 (이미 첫 화면에 적혀 있다)
Sourced     모든 수치에 출처와 시각이 붙는다
Straight    남의 완성된 표를 받아 쓰지 않는다 — 원자료에서 우리가 만든다
Silent      ⛔ 쓰지 않는다. 「못 잰 것은 못 쟀다고 적는다」가 우리 원칙인데
            Silent 는 그 반대로 읽힌다
```

## Ⅳ. ⛔ 쓰면 안 되는 S — 까닭까지 적습니다

```
Signals      🔴 매매신호. 「투자자문 아님」을 모든 지면에 고정 노출하는 회사가
             이름에 Signals 를 쓰면 그 고지가 거짓말이 된다
Speculation  🔴 같은 까닭
Stocks       ⬜ 우리는 증시만이 아니다 — 외환·채권·커머디티·거시가 다 있다
             이름이 범위를 좁히면 파는 것도 좁아 보인다
Smart        ⬜ 잰 것이 없는 자랑이다. 우리는 재서 말한다
Superior     ⬜ 같은 까닭
Scoop        ⬜ 언론사 말이다. 우리는 아직 언론사가 아니다(CLAUDE.md)
Secrets      ⬜ 공개 공시를 다루는 회사가 쓸 말이 아니다
```

## Ⅴ. 제 추천 — **Statements · Standards · Sources** 셋으로 고정

```
S Markets — Statements, Standards, Sources.

  Statements  우리가 다루는 «것»      — 상장사가 «낸 것»을 다룬다
  Standards   우리가 하는 «일»        — 나라가 달라도 한 규격으로 만든다
  Sources     우리가 지키는 «선»      — 모든 수치가 어디서 왔는지 말한다
```

**왜 이 셋인가**

```
· 셋 다 «지금 하고 있는 일»이다 — 오늘 잰 수로 뒷받침된다
· 셋이 서로 안 겹친다 — 무엇을 / 어떻게 / 어디까지
· 시장이 늘어도 안 바뀐다 (지명 S 는 인도·대만이 들어오면 깨진다)
· 투자자문 선을 넘지 않는다
⭐ 그리고 «S 로 시작하는 시장»은 부제로 따로 쓴다 —
  Seoul · Shanghai · Shenzhen · Saudi. 시장이 늘면 이 줄만 고친다
```

### 회사소개에 넣을 꼴 (초안)

```
S Markets — Statements, Standards, Sources.

We compile what listed companies file — financial statements, shareholders,
and changes of control — into one standard, in English, across Asia and the Gulf.
Seoul, Shanghai, Shenzhen, Saudi. Every figure names its source and the moment
we took it. What we could not measure, we say we could not.
```

## Ⅵ. ⚠ 언제 바꾸나 — 아직은 아니라고 봅니다

```
지금  로고만 SMarkets · 그 밖은 전부 SeoulMarkets (도메인·제목·구조화데이터·결제창)
⭐ 이 «반만 바꾼 상태»는 사실 안전한 자리입니다 —
   검색 색인이 붙은 이름(seoulmarkets.com)을 안 잃고 새 이름을 먼저 걸어 보는 것

🔴 다만 한 곳은 지금 손봐야 합니다 — 아래 Ⅶ
```

## Ⅶ. 🔴 브랜드로만 써도 «한 곳»은 손봐야 합니다 — 결제창

사장님 물음: **「브랜드로만 쓰면 문제되나?」** — 재 봤습니다.

```
괜찮은 곳 (그대로 둬도 된다)
  도메인 seoulmarkets.com        검색 색인 자산이다. 안 건드린다
  <title> · 구조화데이터          구글이 부르는 이름. 브랜드와 달라도 벌점이 없다
  법인명                         원래 브랜드와 다른 것이 정상이다

🔴 손봐야 하는 곳 — 손님이 «내가 산 그곳이 맞나»를 확인하는 자리
  결제창    src/lib/paypal.mjs  brand_name: 'SeoulMarkets'
  영수증 설명 같은 파일 84줄     description: 'SeoulMarkets — …'
  영업 편지 서명                 SeoulMarkets
```

⛔ **지면 로고는 SMarkets 인데 결제창이 SeoulMarkets 이면 손님이 결제 직전에 멈춥니다.**
  그리고 나중에 카드 명세서에 모르는 이름이 찍히면 «이의제기»로 갑니다.
  값이 실제로 새는 자리는 여기 하나뿐입니다.

✅ 고치는 법은 이름을 «둘 다» 보이는 것입니다 — 한쪽을 버리지 않습니다.

```
결제창 brand_name   SMarkets (seoulmarkets.com)
영수증 description  SMarkets — <상품 이름>
편지 서명           SMarkets · seoulmarkets.com
```

⚠ 이건 돈이 오가는 자리라 제가 값을 건드리지는 않았습니다. **이름 표기만** 바꾸는 것이고,
  사장님이 「그렇게 해」 하시면 그 자리에서 고치겠습니다.
