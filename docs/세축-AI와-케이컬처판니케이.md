## Ⅰ. 먼저 — 사장님의 다섯 말씀이 **한 구조**를 가리킨다

「감이 안 선다」고 하신 것이 셋인데, 오늘 니케이를 뜯어 보니 셋이 같은 그림이었다.

```
니케이가 하는 일           우리가 가진 것
─────────────────────────────────────────────────────────
신문 (닛케이신문)      →   영문 매체 (SeoulMarkets · K Culture Wire)
지수 (닛케이 225 외 50종) →  ⬜ 없다. **여기가 비어 있다**
데이터 (NEEDS)         →   원자료 아카이브 (오늘 첫 상품 파일을 냈다)
라이선스 (표시·비표시·상품조성) → ⬜ 없다
자체 추정 (기자 추정치)   →   우리가 세는 것 (목표주가 변경·열람수·근속·급여)
```

🔴 **비어 있는 칸이 「지수」와 「라이선스」다. 그리고 그 둘이 같은 것이다.**
사장님이 말씀하신 **빌보드도 지수**다. 「케이컬쳐스 판의 니케이」는 곧
**「우리가 만든 차트를 무료로 내고, 그 차트를 라이선스한다」**는 뜻이다.

⭐ 그래서 세 답이 하나다 —
```
K컬처 B2B      =  우리 차트와 그 기초자료를 파는 것
빌보드 같은 것   =  그 차트
자체 AI        =  그 자료에 «영어로 묻고 답하는» 층
```

## Ⅱ. 🔴 사장님 다섯째 말씀에 대한 답 — **연간 구독은 «목적지»로 맞고 «첫걸음»으로는 틀리다**

> 「투자AI 솔루션과 케이라이프맵 상담 AI 솔루션을 연간 구독 상품으로 팔 수 있을 것 같다만…」

방향은 맞다고 봅니다. 다만 재 보니 **막는 것이 셋**이고, 그 가운데 하나는 규제입니다.
사장님이 못박으신 「근거는 너의 추측이 아니야, 데이터로 갖고」에 따라 잰 것만 적습니다.

### 2-1. 🔴 막는 것 하나 — **투자AI 를 «남에게 팔면» 규제가 달라진다. 이것은 아직 못 쟀다**

우리 저장소가 이미 그은 경계는 이렇습니다(`docs/투자AI-설계.md` 1절).

| | 우리가 확인해 둔 판정 |
|---|---|
| **자기 자금으로 자기 계산 매매** | **등록 불요** |
| 남의 돈을 굴린다 | 투자운용업 등록 · 자본금 · 인적 요건 |
| 알고리즘 고속거래 + 직접전자접근 | 고속거래행위자 등록 대상일 수 있다 |

⛔ **그런데 이 표에 「남에게 신호를 팔아 구독료를 받는다」가 없습니다.**
그것은 위 셋 중 어느 것도 아니고, 한국에서는 **유사투자자문업(신고제)** 또는
**투자자문업(인가제)** 쪽에 걸리는 행위입니다. 갈리는 지점은 대체로
「일방적·비개별적 정보 제공인가」 ↔ 「개별 고객에게 맞춘 자문인가」입니다.

🔴 **저는 이것을 아직 읽지 않았습니다. 그러니 「된다」고도 「안 된다」고도 말하지 않습니다.**
✅ 다음에 제가 할 일로 못박습니다 — **자본시장법상 유사투자자문업 신고 요건과 금지행위를
읽고 `docs/연구-AI운용사와-관할권.md` 에 붙인다.** 값을 매기기 전에 이것이 먼저입니다.
⚠ 값을 매긴 지면을 먼저 올리면, 읽고 나서 내려야 할 수도 있습니다. 순서를 바꾸지 않습니다.

### 2-2. 막는 것 둘 — **우리는 아직 «한 건도» 팔아 본 적이 없다**

1번이 오늘 08:34 에 올린 수입니다.

```
klifemap  결제 33건 — **전부 pending · paid 0건** · 누적 회원 8명 · 매출 0원
토스 빌링  2026-09-09 계약 완료 · 카드사 심사 접수 (오늘 붙었다)
```
⛔ **연간 선불 구독은 «세상에서 가장 어려운 첫 판매»입니다.** 처음 보는 회사에
1년치를 미리 내는 손님은 없습니다. 니케이의 Premium Data Package 가 「연 계약 · 선불」인
것은 **70년 이력이 있기 때문**입니다(1949년부터 · 사장님이 주신 가이드 5쪽).

### 2-3. 막는 것 셋 — 오늘 발견이 정확히 반대를 가리킨다

```
니케이 NEEDS SPOT   「비구독 · 과거 자료를 한 번 사는 것」  ← 우리 자리
FnGuide             연간 = 월×12 (할인 0)
                    ⇒ 연간권은 값을 깎아 주는 상품이 아니라 «해지를 막는 장치»다.
                      약관도 그렇게 짜여 있다 — 「서비스 변경은 월간에 한하여 가능」
```
⇒ **연간 구독은 손님을 «묶는» 도구이지 «얻는» 도구가 아닙니다.** 아직 묶을 손님이 없습니다.

### 2-4. ✅ 그래서 제 제안 — 층을 셋으로 두고 «순서»만 바꿉니다

사장님 구상을 버리는 것이 아니라 **도착 순서를 바꾸는 것**입니다.

| 층 | 무엇 | 값의 꼴 | 왜 이 순서인가 | 언제 |
|---|---|---|---|---|
| **1. 한 번 쓰기** | 감명 1건 · 리포트 1편 · 자료 한 벌 | 건당 | 신뢰가 필요 없다. **파는 것을 처음으로 증명한다** | 지금 |
| **2. 짧은 구독** | 월 단위 | 월 | 1층에서 «다시 사는 손님»이 보이면 연다 | 재구매가 보인 뒤 |
| **3. 연간 B2B** | ⭐ **여기가 사장님이 말씀하신 것** | 연 · 선불 | ⇒ 아래 2-5 | 통합 손님이 생긴 뒤 |

### 2-5. ⭐ 연간 구독이 «실제로» 맞는 자리 — B2B 이식(embedding)

연간이 정당해지는 조건은 하나입니다 — **손님이 붙이는 비용을 치렀을 때.**

```
Wind 이 그렇게 판다   손님 사내 DB 에 직접 밀어 넣고 · Server API 로 지표·모델을 복제해 준다
                   ⇒ 한 번 붙이면 한 달만 쓰고 뗄 수 없다. 그래서 연 단위가 성립한다
니케이도 그렇게 판다  NEEDS BULK — 「손님 사내 DB 로 정기 공급 · 기존 DB 와 통합」
QUICK 도 그렇게 판다  TORF 를 Refinitiv·Bloomberg 코드로 실어 준다
```
⇒ **우리 AI 를 «화면»으로 팔면 월 구독이고, «API·엔진»으로 팔면 연 구독입니다.**
```
투자AI       B2B 손님 = 증권사·자문사의 «리서치 보조». 그들 시스템 안에서 돈다
             ⚠ 다만 2-1 규제를 읽기 전에는 값을 매기지 않는다
상담AI       B2B 손님 = 사주·점성 앱·타로 서비스·결혼정보·심리상담 플랫폼.
             ⭐ 여기는 **금융 규제가 없다.** 그래서 «먼저 열 수 있는 쪽»이다
```

### 2-6. 🔴 그러니 순서를 이렇게 정합니다 — 규제가 없는 쪽부터

```
1순위  KLifeMap 상담AI 를 B2B API 로 낸다   금융 규제가 없다. 점성학이 가장 큰 사업이라 하셨다
       ⚠ 단 카드사 심사가 끝날 때까지 /pricing.html 을 건드리지 않는다(오늘 동결 걸었다)
2순위  SeoulMarkets 자료 상품               오늘 첫 파일을 냈다. 한 벌 판매부터
3순위  투자AI 구독                          ⛔ 2-1 규제를 읽은 뒤에만. 읽기 전에 값을 안 매긴다
```

## Ⅲ. 「케이컬쳐스 판의 니케이」 — B2B 가 무엇인가

### 3-1. 🔴 우리가 «이미» 쥔 것 — 남이 못 가진 자료

⚠ 아래는 전부 오늘·최근에 재서 확인한 실측치다. 짐작이 아니다.

| 자료 | 크기 | 누가 가졌나 |
|---|---|---|
| 위키백과 열람수 — 한국 연예인 | **9,249명** (생년 100%) | 우리 |
| 성별(P21) | 9,249명 (남 4,603 · 여 3,944 · 미확인 694) | ⭐ 오늘 받았다 |
| 그룹·멤버 | 그룹 **428** · 서로 다른 멤버 **1,464** | 우리 |
| 넷플릭스 주간 국가별 차트 | **269주** 아카이브 | 우리 |
| 음반사 ↔ 상장 모회사 | 음반사 197곳 · 사람 1,321명 | ⭐ 우리만 (5번↔6번 이음자리) |
| 커뮤니티·뉴스 제목 | 하루 **645건**(커뮤니티) + **380~400건**(신문) | 우리 |
| 별자리·생일·출생지·학교 | 별자리 1,047 · 학교 4,535 | 우리 |

### 3-2. ⭐ 그래서 차트를 만들 재료가 이미 있다 — 「빌보드 같은 것」

빌보드가 파는 것은 노래가 아니다. **순위를 만드는 «방법»과 그 순위의 «이름»**이다.
그리고 니케이 지수와 구조가 같다 — 무료로 보여 주고, 쓰임새로 값을 받는다.

| 우리 차트 (가칭) | 무엇으로 세나 | 우리가 쥔 원자료 | 남이 못 하는 까닭 |
|---|---|---|---|
| **K-Culture Attention Chart** | 위키백과 열람수 주간 순위 | 9,249명 · 월별 | 명부와 이름 대응을 우리가 만들었다 |
| **Korean Title Travel Chart** | 넷플릭스에서 «몇 나라»에 들었나 | 269주 · 국가별 | 주 단위로 269주를 쌓아 뒀다 |
| **Rookie Momentum Chart** | 데뷔 N년 이하의 열람수 증가 | 그룹 428 · 생년 | 생년·그룹 결성연도를 둘 다 갖고 있다 |
| ⭐ **K-Culture Equity Link** | 아티스트 주목도 ↔ 상장 기획사 재무·시가총액 | 음반사 197 ↔ 상장사 | **양쪽을 한 회사가 쥔 곳이 우리뿐이다** |

🔴 넷째가 「케이컬쳐스 판 니케이」의 핵심이다. 닛케이가 **Japan Entertainment Content
Stock Index** 를 이미 만들었다(사장님이 주신 지면). **일본에 있고 한국에 없다.**
⚠ 다만 사장님이 못박으신 「사이트를 헷갈리지 않는다」는 지킨다 —
**지면은 각자 낸다.** 이어 붙이는 것은 «상품·자료»에서만 한다.

### 3-3. B2B 손님이 누구인가 — 이름으로 적는다

⛔ 「기획사에 팔면 된다」처럼 뭉개지 않는다. 무엇을 왜 사는지 적는다.

```
1. 해외 배급·플랫폼 (동남아·중동 OTT·음반 유통)
   왜 사나 — 「어느 한국 작품·아티스트가 우리 나라에서 뜰까」. 우리 국가별 차트가 그 답이다
2. 광고·브랜드 대행사
   왜 사나 — 앰버서더를 고를 때 «주목도의 추세»가 필요하다. 우리는 월별 열람수를 갖고 있다
3. 상장 기획사·IR 담당
   왜 사나 — 자기 아티스트 주목도를 «제3자 수»로 인용해야 한다. 자기 발표는 근거가 안 된다
4. 자산운용·리서치
   왜 사나 — 엔터 종목을 볼 때 «콘텐츠 지표»가 없다. 3-2 넷째 차트가 그 칸이다
5. 학계·정책기관 (KOCCA 등)
   왜 사나 — 한류 통계를 «영문·시계열»로 쓸 자료가 부족하다
```

### 3-4. 라이선스는 니케이 꼴로 세 겹 (사장님이 주신 원문 그대로 옮긴다)

```
display usage        차트를 화면에 보여 주는 것 — 싸다
non-display usage    남의 시스템 «안»에서 계산에 쓰는 것 — 비싸다
기초자료 제공          순위를 만든 «구성·비중·원수치»를 파는 것
⛔ 상품 조성(ETF 등)   우리 갈래가 아니다. 안 한다
```
⭐ 그리고 차트 값 자체는 **무료로 지면에 낸다.** 그것이 검색 유입이고 신뢰다.
  닛케이도 Nikkei 225 값을 지면에 그대로 찍어 놓는다.

### 3-5. ⭐ 지수·차트에 반드시 붙는 것 — 니케이 가이드에서 배운 규율

```
✅ 규칙 문서(Governance)를 «따로» 낸다 — 어떻게 뽑고, 바꿀 때 어떻게 정하나
   ⇒ 규칙 없는 순위는 아무도 인용하지 않는다
✅ 계산의 «함정»을 스스로 적는다 — 니케이는 「월간 시가는 첫 거래일의 종가이고 시가가 아니다」를
   가이드에 적어 뒀다. 우리도 그렇게 한다
✅ 접을 때도 공지한다 — 닛케이는 Climate PAB 지수 «계산 중단»을 공지했다
⛔ 점수·등급으로 만들지 않는다 — 우리 강령 「우리가 바늘을 세우지 않는다」.
  순위는 «분포를 요약한 수»이지 좋고 나쁨이 아니다
```

## Ⅳ. 「훨씬 좋은 데이터가 어딘가에 있을 것 같다」 — 🔴 사장님 짐작이 맞았다. 재서 확인했다

### 4-1. 우리가 무엇을 «안 찾아봤나»

우리는 2026-09-04 에 공공데이터포털 카탈로그를 훑어 **자료 3,206건**을 목록으로 갖고 있다.
그런데 **훑은 낱말이 20개뿐이었고, 그 안에 K컬처 핵심 낱말이 없었다.**


## Ⅴ. 자체 AI — 「감이 안 선다」에 대한 답

### 5-1. 🔴 우리 AI 의 해자는 «모델»이 아니라 «자료»다

```
⛔ 모델로는 못 이긴다   우리가 GPT·Claude 보다 좋은 모델을 만들 수 없다
✅ 자료로 이긴다        우리가 쥔 것을 «그들이 못 읽는다» —
                     근속·급여·성별격차 2,879사 · 목표주가 변경 이력 ·
                     한국 연예인 9,249명 열람수 · 넷플릭스 269주
                     이 자료는 웹에 없다. 우리가 만든 것이다
```
⇒ **우리 AI 는 「똑똑한 모델」이 아니라 「아무도 못 가진 자료에 답하는 창구」다.**
  그리고 그것은 사장님이 이미 정하신 3층 구조와 같다 — **판단은 규칙이 하고 LLM 은 읽고 말한다.**

### 5-2. 그래서 팔 수 있는 AI 상품 셋 (규제 문턱 순)

| 상품 | 무엇 | 규제 | 언제 |
|---|---|---|---|
| **상담 AI API** (klifemap) | 사주·점성 감명을 API 로. 규칙은 서버에, 말은 LLM 이 | ✅ 없다 | 1순위 |
| **자료 질의 AI** (SeoulMarkets·KCW) | 「우리 자료에만」 답한다. 근거 행을 같이 낸다 | ✅ 없다 — 사실 조회다 | 2순위 |
| **투자 리서치 보조 AI** | 신호·해석 | 🔴 유사투자자문 갈래. **읽기 전에 값 안 매긴다** | 3순위 |

⭐ 둘째가 사장님이 「감이 안 선다」 하신 자리의 답이라고 봅니다 —
**우리 자료 위에서만 답하는 AI.** 밖의 지식으로 답하면 그건 남의 모델이고, 우리 자료로만
답하면 **그 자료를 못 가진 사람은 그 답을 못 얻습니다.** 그것이 팔리는 이유가 됩니다.
```
⛔ 우리 자료에 없는 것은 「없다」고 답하게 만든다. 지어내면 상품 전체가 죽는다
✅ 답마다 «근거 행»을 함께 낸다 — 손님이 검산할 수 있어야 기관이 쓴다
✅ 「투자자문 아님」을 답마다 고정한다
```
