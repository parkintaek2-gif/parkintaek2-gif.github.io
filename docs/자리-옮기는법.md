## 4. 계정을 붙인다

```bash
SP=".../scratchpad"; : > "$SP/codeN.txt"
tail -f -n +1 "$SP/codeN.txt" | \
  CLAUDE_CONFIG_DIR="C:\\Users\\USER\\.claude-uN" \
  claude auth login --claudeai --email uN@klifedesign.net > "$SP/outN.txt" 2>&1
```
🔴 **`tail -f` 로 먹인다. mkfifo 는 안 된다** — 도구 호출이 끝나면 쓰는 쪽이 죽어 EOF 가 나고 로그인이 멎는다.

`outN.txt` 에 나온 `https://claude.com/cai/oauth/authorize?...` 를 브라우저에 연다.
「조직 선택(Klifedesign)」이 먼저 뜨면 그것부터, 그 다음 「승인」 —

```js
// ⭐ 클릭이 아니라 «초점 + Enter». 두 번에 나눠 하지 말고 한 묶음으로.
const b = [...document.querySelectorAll('button')].find(x => x.textContent.trim()==='승인');
b.focus();
// → 이어서 computer 도구로 key: Return
```
⚠ 초점은 쉽게 풀린다. **초점 주기와 Enter 를 같은 묶음에서** 해야 한다.

나온 코드(`코드#상태`)를 파일에 붙이면 로그인이 끝난다 —
```bash
printf '%s#%s\n' "<코드>" "<상태>" >> "$SP/codeN.txt"
CLAUDE_CONFIG_DIR="C:\\Users\\USER\\.claude-uN" claude auth status   # email 확인
```

## 12. ⚠ 창을 제목으로 고를 때 — **정확히 일치**로만 잡는다

```
오늘 일꾼 기록에 이렇게 찍혔다 —   closed HWND 5 :: 번
제목이 「번」인 헛것을 집었다. 창 여섯은 멀쩡했으나 «집을 수 있다»는 것을 봤다
```
⛔ `-match '번'` 처럼 **부분 일치**로 잡지 않는다. `Trim() -eq '2번'` 처럼 정확히 일치로 잡는다.
⛔ 그리고 닫기 전에 **닫을 목록을 로그에 먼저 찍는다.** 무엇을 닫았는지 뒤에 알 수 있어야 한다.
