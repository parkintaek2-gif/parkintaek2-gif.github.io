# 남의 판매망 조사 — 영업 없이 기관에 파는 길 (6번, 사장님 66292 ③)

> 사장님 제약: **「인력은 나 하나 · 내가 영업하지 않음」.** 그래서 영업이 있어야 팔리는 후보는 탈락.
> 살아남는 넷: ①인바운드 ②셀프서브 ③**남의 판매망** ④공고. ③은 우리가 한 번도 안 본 자리.
> ⛔ 이 조사는 「지면 몇 장」이 아니라 **「그 채널이 얼마를 벌게 하나」**로 판정한다(0절).

## 🔴 우리 매출계획의 흠 — 자료판매가 영업을 전제했다
```
지금 /data 지면: 「업무 이메일 주면 샘플·라이선스 조건을 보냅니다」
= 사람이 응대·협상해야 함 → 사장님 「영업 안 함」에 걸린다. 이 모델로는 안 팔린다.
```
→ 고칠 방향: **셀프서브(지면에서 값 보고 바로 결제·다운로드)** + **남의 판매망(장터에 얹기)**.

## ③ 남의 판매망 후보 — 영업 없이 기관이 스스로 사는 곳

### ⭐ 1순위 (한국·우리 해자와 정확히 겹침)
```
· 금융데이터거래소(FinDX, findatamall)  — KRX·금융보안원. 한국 기관이 한국 금융데이터를 사는 장터.
   우리 니치(한국 금융·노동데이터)와 정확히 겹침. 기관 셀프서브. 우리는 등록만, 영업 0.
· KDX 한국데이터거래소(데이터스토어)     — 범용이나 기관·공공 구매층. 셀프서브 판매.
```
⭐ 사장님 「한국 금융·경제데이터 유일 벤더」 전략에 **가장 온-전략**. 여기부터 본다.

### 2순위 (글로벌 퀀트·클라우드 기관)
```
· Nasdaq Data Link(옛 Quandl)  — 퀀트가 금융데이터 사는 표준 장터. 승인되면 Nasdaq이 과금·배포.
· Snowflake Marketplace         — 기관이 자기 Snowflake로 바로 소비. 등록 무료급·셀프서브 구독.
· AWS Data Exchange             — AWS 기관 대상. 우리가 값 정하면 셀프서브 구독.
· Databricks Marketplace        — Delta Sharing. 데이터사이언스·퀀트층.
```

### 인바운드 보조 (직접 매출은 약하나 유입·평판)
```
· Hugging Face Datasets · Kaggle — 무료 샘플 얹어 「검색·평판」으로 /data 유료로 끌어옴.
```

### ⛔ 탈락 (영업·파트너십 필요)
```
Bloomberg Enterprise Access Point · LSEG/Refinitiv · FactSet — 등록에 파트너십·영업 필요. 우리 인력 0이라 제외.
Datarade 류 리드젠 — 결국 사람이 응대(리드→상담). 셀프서브 아님. 후순위.
```

## 우리가 준비돼 있나 (파는 물건 관점)
```
✅ 데이터는 있다 — 7종(JSON/CSV). provenance·정정이력·섹터태깅이 차별점.
✅ 라이선스 문제 없음 — 원천이 data.go.kr 「이용허락범위 제한 없음」(재배포 가능).
⛔ 아직 없는 것 — ① 장터별 「패키지」(스키마·샘플·데이터시트) ② 셀프서브 결제(값 확정 필요·사장님)
   ③ 장터 계정(사장님/2번 손) ④ FinDX·KDX 등록요건 실제 확인(계정 필요)
```

## 매출계획 보정 (자료판매 칸)
```
전: 자료판매 = 기관에 직접 라이선스(영업 전제) — ⛔ 탈락
후: 자료판매 = (a)셀프서브 결제 + (b)남의 판매망 구독료. 곳수는 「우리가 영업해 딴 계약」이 아니라
    「장터에서 스스로 구독한 기관 수」로 다시 잡는다. 영업 0 가정과 일치.
```
