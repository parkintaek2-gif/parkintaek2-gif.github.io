# 정기 업무 자동화 — 무엇을 기계에 맡기고 무엇을 남기나

> 2026-09-20 · 5번(총괄) · 사장님 지시 「**손으로 치는 나머지 정기업무도 다 자동화해**」

---

## Ⅰ. 가른 선 — 이것이 이 문서의 요점이다

```
기계가 할 몫    재는 것 · 모으는 것 · 받아 쌓는 것 · 빠진 것을 세는 것
사람이 할 몫    읽는 것 · 판단하는 것 · 보내는 것 · 만드는 것
```

⭐ 사장님이 소통 자동화를 물으실 때 **「소통 내용까지 다 확인하는 걸 전제로 함」**을 함께
말씀하셨다. 그 전제가 이 선이다. **내용을 안 본 것이 저절로 나가면 그것이 제일 나쁘다.**

---

## Ⅱ. 정본은 문서가 아니라 코드다

```bash
node scripts/정기업무-예약.mjs          무엇이 걸렸고 무엇이 빠졌나 잰다
node scripts/정기업무-예약.mjs --설치     빠진 것을 건다 (겹치는 것은 스스로 건너뛴다)
```

일과표는 `scripts/정기업무-예약.mjs` 의 `일과` 배열에 있다(자가시험 26개).
⛔ **이 문서에 목록을 옮겨 적고 사람이 맞추게 하지 않는다.** 그렇게 두면 갈라진다 —
`걸리는자리` 목록이 그렇게 갈려 배포를 사흘 막은 적이 있다.

### 2-1-1. 🔴 ADX 시총은 «안» 건다 — 멈춰 세운 자다

CLAUDE.md 아카이빙 목록에 「매일 한 번 ADX 시가총액·시세」가 있어서 걸었다가 바로 뺐다.
그 자는 **일부러 세워 둔 자**였다 — ADX 이용약관이 «systematic retrieval … to compile a
database» 를 금지한다. 예약이 돌아도 자는 「멈춰 세운 수집기다」만 찍고 **끝값 0** 을 낸다.



### 2-2. 일부러 «안» 거는 것 넷

```
16시 업무보고 «발송»       네 칸을 읽고 채우는 일이다
23시 전 유닛 점검 «보고»    재료는 22:50 에 기계가 만든다. 읽고 판단해 보내는 것은 세션
소통 «읽음 도장»           도장을 기계가 찍으면 대장이 거짓말을 한다
콘텐트 생산·감수           만드는 일이다. 자로 셀 수는 있어도 대신 쓸 수는 없다
```

⚠ 이 넷은 **「빠뜨린 것」이 아니라 「안 거는 것」**이다. 자가 까닭과 함께 보여 준다 —
그래야 다음 세션이 「왜 이건 자동이 아니지」 하며 잘못 걸지 않는다.

## Ⅲ. 왜 CronCreate 가 아니라 윈도 작업 스케줄러인가

```
CronCreate   세션 «메모리»에만 있다 — 세션이 바뀌면 사라지고, 7일 뒤 만료되며,
             세션이 바쁘면 그 시각에 안 뜬다
작업 스케줄러  PC 가 켜져 있으면 세션과 무관하게 돈다
```

🔴 **오늘 실측이 그 증거다.** 결제 점검이 손 예약에 기대다가 토스 4시각(1·8·13·14시),
페이팔 7시각(0·3·5·7·8·10·11시)이 빠졌다. 작업 스케줄러로 옮긴 뒤 17:05·18:05 은
사람이 손대지 않았는데 제 시각에 돌았다.

## Ⅳ. 겪어서 고친 것 둘 — 되풀이하지 말 것

### 4-1. 🔴 이미 걸려 있는 것을 또 걸 뻔했다

「아카이빙-신문제목」을 걸려는데 **이미 `KLifeDesign-신문제목수집-0530` 이 있었다.**
앞선 세션이 걸어 둔 것이고, 이름이 달라 눈으로는 안 보였다.

```
⛔ 작업 «이름»으로 겹침을 보지 않는다 — 짓는 사람마다 이름이 다르다
✅ «부르는 자»(파일 이름)로 맞춘다 — 그것이 같으면 같은 일이다
```

자가 이제 스스로 건너뛴다. 같은 까닭으로 KRX시세·지수·채권·증권사·커뮤니티·백업도
내 일과표에 넣지 않았다 — **이미 돌고 있다.**

### 4-2. 🔴 로그 한 파일에 열둘이 몰려 «있지도 않은 빨간불»이 켜졌다

두 자를 같은 초에 돌리니 하나가 끝값 1 로 떨어졌다. 윈도에서는 두 프로세스가 같은
파일에 `>>` 로 붙을 때 하나가 파일을 못 연다.

```
⇒ 자마다 제 로그를 쓴다 — .정기업무-<이름>.log (커밋하지 않는다)
   고친 뒤 셋을 같은 초에 돌려 다 끝값 0 을 봤다
⛔ 한 파일로 되돌리지 말 것
```

## Ⅴ. 세션이 지킬 것

```
✅ 깨어나면 한 번 잰다 — node scripts/정기업무-예약.mjs
   🔴 가 있으면 --설치 로 건다. 겹치는 것은 자가 알아서 건너뛴다
✅ 새 정기 업무가 생기면 «문서가 아니라» 일과 배열에 한 줄 더한다.
   자가시험이 자·시각·겹침·로그를 다 잡아 준다
⛔ 자동으로 사장님께 메일이 나가게 만들지 않는다 — 자가시험이 `--보낸다` 를 막는다
⛔ 배포 명령(ctype·deploy)을 예약에 걸지 않는다 — 자가시험이 막는다
⛔ 「예약을 걸었다」를 「돈다」로 세지 않는다. 한 번 돌려 끝값 0 을 눈으로 본다
⛔ 그리고 «끝값 0» 을 「자료가 들어왔다」로 세지 않는다 — 아카이빙은 폴더에 오늘 날짜가
   섰는지까지 본다. 2026-09-20 에 ADX 가 끝값 0 을 내면서 아무것도 안 받고 있었다
```
