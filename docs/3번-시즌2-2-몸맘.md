## 원문 (8/10 기획서 §3, 그대로 옮김)

### 사장님 말씀
> 「백년지도 > 무엇을 파나 > 몸 > **몸/맘**이다. **현대는 맘도 엄청 중요하다.**
>  맘을 다루는 것이 **심리학, 정신분석학, 정신건강의학**이다」

### 갈래 여섯이 이렇게 바뀐다
```
배움 · 일 · 돈 · 삶의 자리 · 몸/맘 · 쉼      (기존: … · 몸 · …)
```

### 이미 우리 안에 있는 것
```
KLifeMap 심리검사 4종 ●  Big Five(Mini-IPIP) · RIASEC(O*NET) · 일 가치관
   → 심리학에서 검증된 표준 검사다. 사장님이 말씀하신 「심리학」이 이미 있다
```
🔴 다만 **정신분석학·정신건강의학은 없다.** 이 둘은 새로 받아 와야 한다.

### ⛔ 조심할 것 — 이 시리즈 전체의 원칙
```
✅ 우리가 하는 것   「이 나이대 사람들이 실제로 어떤 어려움을 겪나」를 통계로 보여준다
⛔ 우리가 안 하는 것 「당신은 이렇습니다」라고 판정하는 것(진단하지 않는다)
```
⭐ 이것이 사장님의 「서열을 매기지 마라」 강령과 같은 자리다 — 순위+문제제기 시리즈의
"판정하지 않는다"와 원칙이 같다.

## 100yearmap에 어떻게 반영하나

| 항목 | 결정 |
|---|---|
| 갈래(카테고리) | 기존 「몸」 계열 지면(`/care`, `/breakfast` 등 건강 축)을 「몸/맘」으로 넓힌다. HundredAgeWalk·klifemap.ts 등 갈래 dict에 반영 시점은 실제 지면이 생길 때 |
| 데이터 출처 후보 | 정부 통계 우선(KOSIS) — 지역사회건강조사(우울감 경험률)·국민건강영양조사(스트레스 인지율)·사회조사(정신건강 관련 문항) 등, 연령대별로 있는 표부터 찾는다 |
| 톤 | 「몇 %가 겪는다」이지 「당신도 그렇다」가 아니다. 진단 어휘(우울증입니다 등) 금지 — 유병률·경험률 «통계»로만 |
| KLifeMap 연계 | Big Five·RIASEC·일가치관 4종 검사는 이미 있음 — 100yearmap이 이 검사 자체를 재만들 필요 없음. 필요하면 결과 통계(연령별 분포 등)를 인용하되 개인 진단 결과는 안 씀 |
