# 데이터 라이선스 대장 — **팔 수 있는 것만 재고다**

> 2026-08-05 시작 · 3번 제안 (「우리가 일하는 법」 2장-3)
> **신청하기 전에 이것부터 본다.** 못 파는 재료에 시간을 쓰면 정지작업도 아니고 **손실**이다.
>
> ⚠ 이 표는 **상품 재고표**이기도 하다 — 「지금 팔 수 있는 데이터가 무엇인가」가 한 장에 나온다.

---

## 0. 왜 만드나 — 실제로 손실이 났다

```
3번   고용24·워크넷 직업코드 492건을 반나절 걸려 뚫었다
      **뚫고 나서 공공누리 4유형(상업 이용 금지)인 걸 알았다.** 통째로 버렸다
      1번에게 이미 넘긴 자료도 「버려 달라」고 해야 했다
```

**경로를 바꿔도 라이선스는 안 바뀐다.** data.go.kr 로 우회해도 같은 4유형이었다.

---

## 1. 판정 기준 — 세 칸만 보면 된다

| 표기 | 뜻 | 우리에게 |
|---|---|---|
| 🟢 **판매 가능** | 상업 이용·변형 허용, 출처 표시 조건 | **재고다.** 가공해서 판다 |
| 🟡 **발행만** | 상업 이용은 되나 **재배포·원본 제공** 제한 | 기사에는 쓰되 **표로 안 판다** |
| 🔴 **못 쓴다** | 상업 이용 금지(공공누리 4유형 등) | **손대지 않는다.** 뚫려도 안 쓴다 |
| ⬜ **미확인** | 아직 안 봤다 | **쓰기 전에 확인한다** |

⚠ **「일단 모으고 나중에 확인」을 하지 않는다.** 그게 3번이 겪은 일이다.

## 3. ⚠ 지금 상태 — **재고라고 부를 수 있는 게 하나뿐이다**

```
🟢 판매 가능   대학알리미 1건
🟡 발행만     증권사 리포트 · Riot
🔴 못 쓴다     고용24 · 워크넷 · KESS · 가상자산
⬜ 미확인      **나머지 전부** — 금융 데이터 8백만 건이 여기 있다
```

**우리가 8백만 건을 모아 놓고 「팔 수 있다」고 말할 수 있는 건 아직 없다.**
전략 Ⅷ 의 「물건이 됐다」가 **아직 아닐 수도 있다는 뜻**이다.

## 4. 할 일 — 이 순서로

```
1  DART 인력 데이터        **이미 CSV 로 공개했다.** 확인이 제일 급하다
2  공공데이터포털 금융 7종   포털 상세화면의 「이용허락범위」를 그대로 옮긴다
3  Netflix Top10          공개 페이지 기준을 확인한다
4  NEIS                   백년지도가 쓸 것
```

⚠ **확인은 「아마 될 것이다」로 채우지 않는다.** 근거 조문과 확인일을 같이 적는다.
못 찾으면 ⬜ 로 남긴다 — **빈칸이 틀린 값보다 낫다.**

## 5. 규칙

```
· 새 API 를 신청하기 **전에** 이 표에 줄을 만들고 라이선스부터 적는다
· 🔴 이면 **뚫지 않는다.** 뚫을 수 있다는 것과 쓸 수 있다는 것은 다르다
· 🟡 을 표로 팔지 않는다. 기사에 **사실만** 쓴다
· 판정을 바꿀 때는 **근거 조문과 확인일**을 같이 바꾼다
```
