# 데이터 라이선스 대장 — **팔 수 있는 것만 재고다**

> 2026-08-05 시작 · 3번 제안 (「우리가 일하는 법」 2장-3)
> **신청하기 전에 이것부터 본다.** 못 파는 재료에 시간을 쓰면 정지작업도 아니고 **손실**이다.
>
> ⚠ 이 표는 **상품 재고표**이기도 하다 — 「지금 팔 수 있는 데이터가 무엇인가」가 한 장에 나온다.

---

## 0. 왜 만드나 — 실제로 손실이 났다

```
3번   고용24·워크넷 직업코드 492건을 반나절 걸려 뚫었다
      **뚫고 나서 공공누리 4유형(상업 이용 금지)인 걸 알았다.** 통째로 버렸다
      1번에게 이미 넘긴 자료도 「버려 달라」고 해야 했다
```

**경로를 바꿔도 라이선스는 안 바뀐다.** data.go.kr 로 우회해도 같은 4유형이었다.

#### 2-1-1. ⭐ 근거 — 왜 「제한 없음」을 믿어도 되나

포털 표기 하나만 보고 판정하지 않았다. **법 조문까지 내려가서 확인했다.**

```
OpenDART 이용약관 제16조 ④
  「약관에 명시되지 않은 저작권과 관련된 사항은 저작권법 및 공공데이터법에 따릅니다」
  → 약관 자체에는 상업이용·재배포 조항이 **없다.** 공공데이터법으로 넘긴다

공공데이터법 제3조 ④                                    ← 결정적 조문
  「공공기관은 다른 법률에 특별한 규정이 있는 경우 또는 제28조제1항 각 호의 경우를
   제외하고는 **공공데이터의 영리적 이용인 경우에도 이를 금지 또는 제한하여서는 아니 된다**」

공공누리 제1유형 (kogl.or.kr)
  「출처표시 · **상업적, 비상업적 이용가능** · **변형 등 2차적 저작물 작성 가능**」

공공누리 제3유형
  「출처표시 + **변경금지** — 상업적 이용은 되나 **2차적 저작물 작성 금지**」
  → 우리는 가공해서 파는 회사다. **3유형은 사실상 못 쓴다.**
```

**즉 「제한 없음」과 「제1유형」은 둘 다 팔 수 있다.** 1유형은 **출처를 적어야** 한다.

#### 2-1-2. ⚠ 데이터셋 번호를 어떻게 우리 API 와 맞췄나 — **이름으로 짐작하지 않았다**

```
금융위 7종   포털 상세화면에 적힌 엔드포인트를 **우리 코드의 URL 과 문자열 대조**했다
             예) 15094808 → GetStockSecuritiesInfoService = scripts 가 부르는 그것

DART        상세화면에 엔드포인트가 안 적혀 있었다. 그래서 **그룹 목록으로 대조**했다
             OpenDART 개발가이드 DS002 그룹 이름 = 「사업보고서 주요정보」
             그 안의 19 소액주주 · 20 임원 현황 · 21 직원 현황 · 22 미등기임원 보수현황
             ↕ 포털 데이터셋 15036725 · 15060612 · 15060615 · 15087424
             **네 건이 이름·순서까지 일대일로 맞는다**
```

⚠ 그래도 남는 것 — 포털 등록본과 OpenDART 실시간 API 가 **완전히 같은 산출물이라는
문서상의 확언은 못 찾았다.** 같은 기관·같은 그룹명·같은 API 목록이라는 정황까지다.
「그럴 것이다」가 아니라 **여기까지 봤다**로 적어 둔다.

### 3-1. ⚠ 그래도 「팔 수 있다」가 「팔린다」는 아니다

라이선스는 **못 파는 이유 하나를 지운 것**이다. 살 사람이 있는지는 별개다.
전략 Ⅷ 이 가르는 두 가지 중 **「물건 없음」이 풀렸을 뿐, 「살 사람 없음」은 그대로**다.

### 3-2. 🔴 출처표시가 필요한 것 — **화면과 파일 양쪽에 넣는다**

1유형은 출처를 적어야 한다. **적는 자리가 두 군데**다.

```
지면      기사 하단 출처 줄
파일      CSV 를 내려받아도 출처가 따라가야 한다 → 머리말 주석 또는 별도 열
```

CSV 만 손에 남았을 때 출처를 알 수 없으면 표시한 것이 아니다.
