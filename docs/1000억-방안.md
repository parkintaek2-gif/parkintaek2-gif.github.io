>

## 1. 먼저 — **왜 지금까지 방안이 안 나왔나**

우리는 계속 **「우리가 가진 것으로 무엇을 팔까」**만 셌습니다. 그래서 늘 천장이 나왔습니다.

```
3번  구독 84만 명 = 한국 인구 1.65%   → 이탈까지 보면 해마다 수십만을 새로 모아야 합니다
5번  B2B 207곳 × 곳당 값(전부 ○)      → 44.7억이 천장
6번  기관 3,324곳 × 300만원           → 99.7억이 천장
```

🔴 **셋 다 「사람에게 소매로 파는 꼴」입니다.** 이 꼴에서 1,000억은 산술로 안 나옵니다.

### ⭐ 그리고 사장님 제약이 답을 좁혀 줍니다

```
「인력은 나 하나야」 · 「내가 영업하지 않음」 · 비용 0
```

⛔ **1인·무영업으로 1,000억을 만든 꼴은 세상에 셋뿐입니다.**

```
① 콘텐츠 × 광고        🔴 1,000억이면 연 330억 PV. **불가**
② 소비자 구독          ⚠ 가능하나 84만 명은 인구 1.65%. **주력으로는 무리**
③ **셀프서브 데이터·API**  ⭐ **한 고객이 연 수천만원. 영업이 0.**
                       사는 쪽이 검색해서 알아서 옵니다
```

🔴 **①②를 주력에 놓았던 것이 지금까지의 잘못입니다.**
