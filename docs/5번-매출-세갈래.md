## 1. B2B 판매 — **손님을 이름으로 셀 수 있다**

### 누구에게 — 세었다. 지어내지 않았다

우리가 열쇠(Q번호)를 든 한국 작품 **901편**에 대고 위키데이터에 제작사(P272)·방송사(P449)를 물었다.

```
이름이 나온 회사        **172곳**      (측정 2026-08-09 · 회사가 붙은 작품 421 / 901편)
  A  10편 이상  **12곳**   Netflix 77 · tvN 75 · JTBC 59 · SBS TV 35 · SLL 30
                          KBS 2TV 29 · Studio Dragon 27 · MBC TV 13 · ENA 13
                          Filmmaker R&K 12 · Studio N 11 · Seoul Broadcasting System 11
  B  5~9편     **14곳**
  C  1~4편    **146곳**

넓은 우주 — 한국 공급사 **523곳**   영화·배급 111 · 음반 레이블 288 · 방송사 129
                                 (위키데이터 P17=Q884 · 겹침 뺀 합 · 측정 2026-08-09)
```

⚠ **480편에는 회사가 안 붙었다.** 위키데이터에 그 칸이 비어 있다. 이건 우리 일감이다 —
   붙이면 손님 명단이 172곳에서 더 는다. **모르는 것을 아는 척하지 않고 그대로 적는다.**

### 무엇을 — 우리만 들고 있는 것

```
「당신 작품이 **93개 시장 · 265주** 동안 어떻게 다녔나」
  · 나라별 자리·순위·머문 주 (37,962자리)
  · 들어온 뒤 오르나 내리나 (108,403런)
  · 같은 값을 든 다른 작품과 나란히 — ⛔ 순위표가 아니라 「왜 다른가」
```

⛔ **취향을 평가하지 않는다.** 「좋은 작품」을 팔지 않는다. **다닌 자취**를 판다.

### 얼마에

| 등급 | 우리 자료 속 작품 | 연 구독 | 원화 |
|---|---:|---:|---:|
| A | 10편 이상 | **$60,000** | 8,400만원 |
| B | 5~9편 | **$24,000** | 3,360만원 |
| C | 1~4편 | **$6,000** | 840만원 |

⚠ 값의 근거는 **같은 것을 파는 곳**이다 — Parrot Analytics·Ampere Analysis 가 작품 수요 자료를
   기관에 연 단위로 판다. 우리 A등급 $60,000 은 그쪽 기업 요금의 아래쪽이다.
⛔ 「우리가 작으니 싸게」로 정하지 않았다. **파는 물건이 같으면 값도 같은 자리에서 시작한다.**

### 손님 수 × 값

| 해 | A | B | C | 합 |
|---|---|---|---|---:|
| 2027 | 0 / 12 | **1** / 14 | **6** / 523 | **0.84억** |
| 2029 | **4** / 12 | **6** / 14 | **31** / 523 | **7.98억** |
| 2032 | **10** / 12 | **14** / 14 | **165** / 523 | **26.96억** |

### 🔴 무너지는 조건

```
2032 의 C 165곳은 우주 523곳의 **31.5%** 다. 이것이 이 표에서 제일 센 가정이다.
⛔ 31.5% 가 안 되면 이 갈래가 통째로 흔들린다.
⭐ 그래서 2027 을 **7곳**으로 잡았다 — 되는지 안 되는지가 첫해에 드러난다.
```

## 2. 광고 — **손님을 이름으로 못 세는 유일한 갈래다**

### ⛔ 못 하는 것을 먼저 적는다

```
프로그래매틱 광고주는 **이름으로 못 센다.** 2번이 못박은 기준을 이 갈래는 못 맞춘다.
⛔ 「아직 방법을 못 찾았다.」 금액(1.8 / 10.1 / 23.0억)은 **안 내린다.**
```

### 무엇이 있으면 셀 수 있나

```
① 직접 스폰서로 바꾸면 센다 — 한국 문화 기관·기업은 이름이 있다
   ⛔ 다만 오늘 그 명단을 **못 만들었다.** 만들려면 근거가 될 목록이 있어야 한다
② 오픈 뒤 리퍼러·유입원을 석 달 모으면 「누가 우리 독자인가」가 이름으로 나온다
   → **2026년 안에 그 명단을 만드는 것이 이 갈래의 일**이다
```

### 지금 잴 수 있는 것 — 재고(인벤토리)

```
지면 30장 · 기사 50편 = **광고 자리를 놓을 수 있는 주소 80개**
오늘 PV **0** — 오픈이 8/15 다. 2026년 광고 매출은 계획에도 **0.00억**이다
계획의 근거: 월 4,167만 PV × 1,000PV당 6,000원
```

### ⛔ 강령이 막는 것 — 이건 안 푼다

```
Riot Production(App 866800) 승인 전 **e스포츠 지면에 광고 자리를 만들지 않는다**
광고를 넣더라도 **집계와 출처가 밀리면 안 된다** — 자료가 광고 아래로 내려가면 파는 물건이 죽는다
```

### 🔴 무너지는 조건

```
트래픽이 안 오면 0 이다. 광고는 우리가 **손님을 고를 수 없는** 갈래라 가장 늦게 확실해진다.
그래서 이 갈래에 회사 계획의 40%(2032 23/57억)를 걸어 둔 것이 위험하다 — 그 몫을 1번 갈래로 옮겼다.
```

## 3. 콘텐츠(기사) 제공 — **오늘은 손님을 못 센다. 그 명단을 만드는 것이 올해 일이다**

### ⛔ 먼저 — 못 센다고 적는다

```
영어권에서 K컬처를 다루는 매체를 **이름으로 세는 목록을 오늘 못 만들었다.**
⛔ 기억으로 열 곳을 적을 수는 있다. 그건 **찾은 것이 아니라 떠올린 것**이라 안 적는다.
```

### 무엇이 있으면 셀 수 있나

```
① 우리 기사가 인용될 때 **리퍼러**로 잡힌다 — 오픈 뒤에만 가능하다
② 넷플릭스 Top10 을 인용하는 영어 기사를 검색으로 모아 매체별로 접는다 — 자를 만들면 된다
   ⭐ 이건 오늘 밤 할 수 있는 일이 아니고, **오늘 중에 자를 만들 수 있다**
```

### 무엇을 팔 수 있나 — 세 가지가 이미 있다

```
① 기사 그대로 (신디케이션)      50편 · 영어 · 출처와 방법이 붙어 있다
② 표 하나 (임베드)             지면 30장의 표를 그대로 실을 수 있게
③ 「그 주의 숫자」 한 줄 (피드)   매주 넷플릭스 표에서 자동으로 나온다
```

⛔ ②를 **스크린샷으로 주지 않는다.** 그러면 우리 자료가 남의 지면에서 늙는다. 살아 있는 자리로 준다.

### 손님 수 × 값 — **금액은 두고 손님 칸을 비워 둔다**

| 해 | 매출 | 손님 | 값 |
|---|---:|---|---|
| 2027 | **0.2억** | ⬜ 아직 못 셈 | 매체당 월 $100~300 (①+③) |
| 2029 | **2.0억** | ⬜ 아직 못 셈 | 위 + 표 임베드 월 $300~800 |
| 2032 | **7.0억** | ⬜ 아직 못 셈 | 위 + 주간 피드 연 계약 |

⛔ **손님 칸을 지어내서 채우지 않았다.** 채우는 날짜를 대신 적는다 — **2026-08-31까지 명단 자를 만든다.**

### 🔴 무너지는 조건

```
매체가 우리 기사를 **사지 않고 그냥 인용**하면 0 이다. 숫자는 인용해도 값을 안 낸다.
⭐ 그래서 파는 것은 **기사가 아니라 표**여야 한다 — 표는 살아 있어야 쓸모가 있고, 살아 있으려면 우리에게 붙어야 한다.
```
