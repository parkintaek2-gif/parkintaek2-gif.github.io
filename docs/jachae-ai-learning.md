## 2. 🔴 .cmd 파일에 한글을 쓰지 않는다 — 조용히 실패한다

2026-09-24 에 이 예약을 처음 걸 때 `--적는다`(한글 인자)를 썼다.

```
작업 스케줄러 결과   exit 0  ← 성공이라고 말한다
실제로 한 일        아무것도 없다. 로그 파일조차 안 생겼다
```

cmd.exe 가 UTF-8 한글을 CP949 로 읽으면서 **뒤따르는 글자까지 먹었고**, 그 줄 다음이
전부 어긋났다(`'cal' is not recognized`·`'G' is not recognized`).

```
⛔ .cmd 안에서 한글 «인자»를 쓰지 않는다. 주석의 한글도 위험하다
✅ 스크립트에 영문 별칭을 둔다 — `--save` 는 `--적는다` 와 같다
✅ 걸어 놓고 끝내지 않는다. **한 번 돌려서 로그와 산출물을 눈으로 본다**
```

⭐ exit 0 을 「됐다」로 읽지 않는다. 우리 저장소에는 같은 교훈이 이미 두 번 적혀 있다
(`ctype undeploy` 가 종료코드 0 으로 아무 일도 안 한 것 · 자가시험이 절반만 돌던 것).
