### 🏠 부동산 — 7번째 카테고리로 도입 예정

**결론: 한다. 다만 금융 6개가 자리 잡은 뒤.**

| 데이터셋 | ID | 내용 |
|---|---|---|
| 국토부 아파트 매매 실거래가 | 15126469 | 법정동·계약년월 단위 전건 |
| 국토부 아파트 전월세 실거래가 | 15126474 | 임대차 신고분 |
| 국토부 분양권 전매 실거래가 | 15126471 | |
| 국토부 상업업무용 매매 실거래가 | 15126463 | |

**이용범위 제한 없음, 무료, 자동승인.** 개인정보 보호를 위해 층 정보만 제공되고
동 정보는 소유권 이전등기 완료분에 한해 추가 공개된다.

**왜 해야 하는가**
- 공공데이터가 압도적으로 잘 열려 있다. **실거래 전건**이 나온다. 시세가 아니라 실제 계약이다
- 외국인 독자 수요가 크다. 서울 아파트값은 국제 뉴스거리다
- **T+1 제약이 없다.** 신고 기반이라 월·주 단위이고 시세 지연과 무관하다
- 금융시장과 연결된다. 금리 → 대출 → 거래량 → 가격. Rates 카테고리와 물린다

**왜 지금은 아닌가**
- 카테고리가 이미 6개다. 7개는 내비게이션 한계
- 부동산은 별도 전문성이 필요하다. 금융 쪽이 안정된 뒤 붙인다

#### 부동산 데이터 3사 비교 (2026-08-01 확인)

| 출처 | 이용허락 | 판정 |
|---|---|---|
| **국토교통부 실거래가** | 「제한 없음」·무료·자동승인 | ✅ **주력** |
| **한국부동산원 (R-ONE)** | 「제한 없음」·무료 (포털 15134761) | ✅ **주력** |
| KB부동산 (KB Land) | 공개 API 없음. 약관 미확인 | ❌ 사용 안 함 |
| 아실(asil) | 민간 서비스. 자체 데이터 아님 | ❌ 사용 안 함 |

**국토부와 한국부동산원 둘 다 쓴다. 성격이 다르다.**

- **국토부 = 실거래**. 실제로 체결된 계약 전건. "무엇이 얼마에 팔렸나"
- **한국부동산원 = 지수·동향**. 표본 조사 기반 가격지수. "시장이 어느 방향인가"

두 개를 대조하는 것 자체가 기사가 된다. **실거래는 오르는데 지수는 내리는 구간**이
주기적으로 생기고, 그 괴리가 나오는 이유(표본 구성, 조사 방식, 거래 절벽)가
부동산 보도에서 늘 논쟁거리다. 우리는 둘 다 「제한 없음」으로 갖고 있으므로
**나란히 놓고 보여줄 수 있다.**

한국부동산원 R-ONE 제공 통계:
전국지가변동률조사 · 전국주택가격동향조사 · **공동주택 실거래가격지수** ·
상업용부동산 임대동향조사 · 오피스텔가격동향조사 · 부동산거래현황
그리고 **주간 아파트가격동향** — 주간 단위라 **주말 기획에 최적**이다.

**KB부동산은 쓰지 않는다.** KB시세는 은행권 담보대출 기준으로 널리 쓰이지만,
공개 API가 없고 데이터허브는 자체 이용 조건이 붙는다. 크롤링은 KRX 건과 같은
문제가 된다. 인용이 꼭 필요하면 **기사 안에서 사실로 언급**하는 선까지만 한다.

**아실은 데이터 출처가 아니다.** 국토부 실거래가 등을 가공해 보여주는 민간 서비스다.
우리가 원 데이터를 직접 갖고 있으므로 경유할 이유가 없다.

## 3. 요일별로 무엇이 나오나

| 요일 | 새로 들어오는 데이터 | 편성 |
|---|---|---|
| **월** | **금요일 시세** (T+1 규칙상 이날 도착) + 주말 누적 공시 | 4건. 금요일 종합 + 주간 전망 |
| **화** | 월요일 시세 + 공시 | 6~8건. 정상 편성 |
| **수** | 화요일 시세 + 공시 | 6~8건 |
| **목** | 수요일 시세 + 공시 + **금통위(해당 주)** | 6~8건. 금통위 날엔 Rates 집중 |
| **금** | 목요일 시세 + 공시 | 6~8건. 주간 정리 초안 작성 |
| **토** | **없음** | 3~4건. 주간 종합 (평일에 미리 작성) |
| **일** | **없음** | 3~4건. 해설·기획 (시의성 없음) |

**핵심 — 월요일이 가장 두껍다.** 금요일 데이터가 월요일에 도착하고, 주말 사이
쌓인 공시가 함께 풀린다. 반대로 **토·일은 데이터가 0이다.**

**주말 콘텐츠는 평일에 미리 쓴다.** 데이터가 필요 없으므로 언제 써도 된다.
검색에서 가장 오래 사는 유형이기도 하다 — 방법론, 제도 해설, 용어 설명.
