## Ⅰ. GEO 가 무엇인가 — 한 줄

```
SEO   구글 결과 «목록»에 오른다          → 사람이 눌러서 들어온다
GEO   생성형 AI 의 «답» 안에 인용된다     → 그 답에 우리 이름과 링크가 박힌다
```

**Generative Engine Optimization** — 「생성형 엔진 최적화」. 2023년 논문에서 나온 말이다.

## Ⅴ. ⛔ 하지 않을 것 — **봇 차단 · 화이트리스트**

USA 투데이는 「기본 차단 + 승인된 봇만 허용」으로 간다. **우리는 반대로 간다.**

| | USA 투데이 | 우리 |
|---|---|---|
| 목적 | 라이선스 협상 | **방문자** |
| 지금 규모 | 월 수천만 명 | 하루 한 자리 수 |
| 그래서 | 막고 값을 받는다 | **연다** |

방문자가 하루 한 자리 수인 단계에서 AI 봇을 막는 것은
**유일하게 늘고 있는 유입 통로를 스스로 닫는 일**이다.

⚠ 우리 콘텐츠가 라이선스로 값이 나갈 만큼 커지면 그때 다시 잰다. **지금은 아니다.**

## Ⅵ. 지키는 법 — 문장이 아니라 **검사**로 둔다

말로 된 지시는 잊힌다. 그래서 재는 자를 둔다.

```
node scripts/measure-geo-all.mjs            네 사이트의 llms.txt·robots·봇 이름별 갈래를 한 번에 잰다
node scripts/measure-geo-all.mjs --자가시험

⚠ 이름이 check- 가 아니라 measure- 다 — 네트워크를 타므로 «막는 자»로 두지 않았다.
   인터넷이 흔들리는 날 전원의 배포가 막히면 안 된다. 대신 **못 잰 것은 「못 쟀다」로 낸다.**
```

**진척은 16시 보고에 각자 자기 칸으로 적는다.** (보고는 16시 한 번 — 2026-09-02 고정지시 수정)

## Ⅶ. 개인정보 — 넘지 않는 선

```
✅ 남긴다     봇이 스스로 대는 제품 이름 한 토막 (GPTBot·PerplexityBot·semrushbot …)
⛔ 안 남긴다  UA 원문 · IP · 쿠키 · 세션
⛔ 사람 쪽    손대지 않는다. 이름표는 «봇으로 가려진 뒤»에만 붙인다
```

봇은 사람이 아니라 개인정보가 아니다. **그 선을 넘지 않는 한에서만 잰다.**
