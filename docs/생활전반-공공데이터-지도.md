# 생활 전반 공공데이터 지도 — 3번(100yearmap)

사장님 지시(2026-09-03): 「질병청, 소방청만 찾지 말고 사람들의 생활 전반(문화, 건강,
여가, 학습 등)에 걸쳐 해당 정부기관과 공공기관이 무엇이 있는지 리스트를 뽑은 뒤 자료를
수집해 — 스스로 발전하는 게 이런 거다」

**규칙 — 이 문서는 이 안:**
- 여기 적힌 orgId·tblId는 **KOSIS Open API로 실제 호출해 확인한 것만 「✅ API 됨」**으로 적는다.
- 검색 목록(`statisticsSearch.do`)에는 뜨지만 아직 실제 데이터 호출을 안 해 본 것은 「⬜ 후보」.
- 호출했는데 `err30`(데이터 없음)·`err21`(objL 안 맞음, 1~5단계 다 실패)이 난 것은
  「⛔ API 막힘」 — 검색엔 걸리지만 이 창구로는 못 받는 표다(웹 UI 전용일 수 있음, 성급히
  포기하지 않되 재확인 없이 쓰지 않는다).
- `/100y`는 **생애주기(몇 살에)** 서사다 — 연령별(C1/C2에 나이 칸)이 있는 표를 우선한다.
