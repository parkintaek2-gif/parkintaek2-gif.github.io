### ✅ Riot — 수집은 이미 돌고 있다 (2026-08-02 23:30 KST)

「승인 대기」로만 적혀 있었는데, **승인 없이도 되는 것이 있었다.** 갈라 두었다.

```
✅ 지금 돈다   랭크 사다리 일일 스냅샷 — 6개 지역 · Windows 작업 「SeoulMarkets-Riot사다리」
              매일 22:00 KST · npm run collect:riot · 로그 archive/log/riot-ladder.log
              첫 스냅샷 2026-08-02. 로컬 + R2 양쪽 저장 확인
✅ 승인 불필요  Data Dragon — 챔피언 233개 다국어 · 버전 496개(과거 소급 가능)
⛔ 승인 필요   광고 게재 · 실시간 픽밴(spectator)
❌ 애초에 없음  프로 e스포츠 경기 데이터 — 개발자 API 의 범위가 아니다(403 실측)
```

**사다리는 소급이 안 된다.** 오늘의 챌린저 분포는 내일 다시 못 받는다.
그래서 승인을 기다리지 않고 **오늘부터 뜬다.** 관세청 10일 잠정치와 같은 성격이다.

⚠ **Personal Key 는 24시간마다 만료된다.** 만료되면 그날 수집이 실패하고
`archive/log/riot-ladder.log` 에 「인증 실패」로 남는다(조용히 넘어가지 않는다).
`developer.riotgames.com` 에서 REGENERATE 해 `.env` 의 `RIOT_API_KEY` 를 갈아 끼운다.
**Production Key 를 받으면 이 만료가 없어진다** — 그것이 승인 신청의 첫 번째 이유다.

**대기가 많다. 그래서 스케줄을 「대기하지 않는 일」로 채운다.**

# 지키는 원칙

**① 아카이브는 하루도 안 빠뜨린다.**
다른 것은 늦어도 따라잡지만 이것만 못 한다. **매일 도는지 확인한다.**

**② 발행이 끊기지 않는다.**
검색이 유일한 유통 경로다. 새 사업을 시작해도 기존 매체가 멈추면 안 된다.

**③ 대기 중인 것을 기다리며 놀지 않는다.**
막힌 것이 있으면 **안 막힌 것으로 채운다.** 이 스케줄이 그렇게 짜여 있다.

**④ 분기마다 계획을 실측으로 고친다.**
`ASSUMPTIONS` 를 감이 아니라 결과로 바꾼다.
