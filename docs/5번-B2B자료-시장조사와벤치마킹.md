> **b2c 매출은 너에게 있어서는 광고밖에 없다. b2b를 내세운 건 과연 팔릴만한 데이터인지
> 시장조사와 벤치마킹해서 판단하도록**...다 한다음에 다시 업무보고로 올려」

## 0. 판단 — 한 줄로

**지금 우리 자료를 B2B로 파는 것은 매출 갈래가 아닙니다.** 팔 물건이 나쁜 것이 아니라,
**같은 물건이 이미 월 $49에 팔리고 있고 원자료는 무료로 공개**되어 있기 때문입니다.
그래서 B2B는 「매출 계획」에서 내리고, **인용을 얻는 수단**으로 자리를 바꾸는 것이 맞다고
판단했습니다. 근거를 아래에 전부 적습니다. 제 판단이 틀렸다고 보시면 그 자리에서 접습니다.

---

## 1. 벤치마킹 — 같은 것을 파는 곳의 실제 값

| 파는 곳 | 무엇을 파나 | 값 (공개된 것) |
|---|---|---|
| **FlixPatrol** | 넷플릭스 등 나라별 TOP 10 · 아카이브(2020~) · API · **제공여부(availability)** | **Start $9.99/월** (내보내기 전용) · **Premium $49/월 또는 $490/년** |
| **Parrot Analytics** | 「수요(demand)」 지수 — 자체 모델 | **엔터프라이즈 최소 $10,000/제품/월, 1년 약정** = 연 $120,000 · Lite $99/월(연납 $59/월) |
| **Luminate** | 음악·영상 소비 자료 | 중소기업 **$995/년** · 엔터프라이즈 별도 |
| **Ampere Analysis · Omdia** | 미디어 산업 리서치 | **값 비공개**, 문의 견적만 |
| **Good Data Corporation**(한국) | K콘텐츠 화제성·Fun-Index | 값 비공개 |
| Datarade 넷플릭스 자료 공급사 4곳(MFour·Measurable AI·Above Data·Market Vectors) | 설문·영수증·앱 사용 패널 | 값 비공개. **나라별 TOP 10 도, 한국 콘텐츠 특화도 없음** |

### 이 표에서 읽어야 할 것 둘

**① 우리가 만든 층의 시장가는 월 $49입니다.**
FlixPatrol 이 파는 것이 정확히 「넷플릭스 나라별 주간 TOP 10 + 아카이브 + API」입니다.
우리 자료의 뼈대와 **같은 원자료**이고, 우리에게 **없는 것**(제공여부·전 플랫폼·프랜차이즈·
개봉예정)까지 얹어서 $49입니다. 우리가 이 자리에 들어가면 **더 적은 것을 더 비싸게** 파는
셈이 됩니다.

**② 값이 큰 자리($120,000/년)는 우리가 못 넘습니다.**
Parrot 이 그 값을 받는 까닭은 **자체 패널**입니다 — 남이 못 구하는 원자료를 자기가 만듭니다.
우리 원자료는 넷플릭스가 공개한 파일, 위키데이터, 위키미디어 조회수, Riot API 입니다.
**전부 남이 무료로 가져갈 수 있습니다.** 값의 근거가 자료 자체에 없습니다.

## 2. 그럼 우리에게 남는 것은 무엇인가 — 겹치지 않는 칸

원자료가 무료여도 **가공은 우리 것**입니다. 시장에서 못 찾은 칸을 적습니다.

```
✅ 남이 안 하는 것 — 넷플릭스 차트를 «한국 제작사·배우»(위키데이터)와 이어 붙인 것
✅ 남이 안 하는 것 — 나라별 «한국물 비중»의 시계열 (93개국 × 265주)
✅ 남이 안 하는 것 — 동남아 네 언어 위키백과에서 한국 스타가 읽히는 정도
✅ 남이 안 하는 것 — 「오래 갔는데 한 나라에서만」처럼 잰 분포로 정의한 잘라내기
⛔ 그런데: 이 넷을 «지금 사겠다는 사람»을 아직 한 명도 못 찾았습니다
```

살 만한 곳을 넷 꼽으면 한국 제작사·배급사, OTT 편성/구매팀, 업계지, 관광·마케팅 대행사입니다.
그 넷은 **이미 Parrot·Ampere 를 씁니다.** 우리가 그 사이에 끼려면 자료가 아니라
**신뢰**가 필요하고, 신뢰는 값을 먼저 받아서 생기지 않습니다.

## 3. ⚠ 못 쟀습니다 — 팔기 전에 반드시 답해야 하는 것

**넷플릭스가 공개한 TOP 10 TSV 파일을 «상업적으로 재배포」해도 되는지 확인 못 했습니다.**

- 넷플릭스 서비스 약관은 「개인적·비상업적 이용」을 말하는데, 그것은 **서비스(영상)** 이야기이고
  Tudum 에 올려 둔 자료 파일의 재배포 조건을 직접 말한 문서를 못 찾았습니다.
- FlixPatrol 이 상업적으로 팔고 있고 Variety·THR 이 인용합니다. 그러나 **관행이 허락은 아닙니다.**
  넷플릭스가 그들에게 문제를 제기한 기록도 못 찾았고, 허락한 기록도 못 찾았습니다.
- ⛔ 그래서 「팔아도 된다」고 적지 않습니다. **못 쟀다고 적습니다.**
  파는 쪽으로 갈 것이면 이것이 **첫 관문**이고, 여기서 막히면 뒤는 다 무의미합니다.

반대로 **위키데이터는 걸림돌이 없습니다** — 구조화 자료가 CC0(퍼블릭 도메인)이라
상업적 재사용이 되고 출처 표기 의무도 없습니다(우리는 그래도 적습니다).

## 5. 그러면 B2C 광고는 얼마인가 — 정직한 산수

사장님 지시대로 B2C는 광고 하나로 봅니다. AdSense 는 이미 붙어 있습니다
(`ads.txt` — pub-5113515144381167).

**우리 손님이 어디서 오나** (28일 · 노출 1,875 · 클릭 15)

```
usa 648  ind 131  phl 80  kor 79  gbr 61  sgp 61  vnm 60  jpn 54  … 그 밖
Tier 1(미·영·캐·호) 합계 약 769 = 41%
```
⚠ 자동완성에는 「korean drama in hindi」·「tagalog dubbed」가 많이 뜨지만, **우리에게 실제로
닿는 것은 미국이 가장 큽니다.** 세상이 치는 말과 우리에게 오는 말은 다릅니다.

**RPM 기준값**(엔터·뉴스 갈래): 갈래 평균 $1~5, 흔히 $2 미만.
Tier 1 은 $10~30, Tier 3 은 $1.2~3.5. 우리 구성으로 섞으면 **$2~6** 범위가 정직합니다.

**사장님 9월 목표(하루 1,000명)를 그대로 넣으면**

```
1,000명/일 × 1.5지면 = 1,500지면/일 = 45,000지면/월
RPM $2  →  월 $90     ≈ 12만 원
RPM $6  →  월 $270    ≈ 36만 원
```

🔴 **목표를 채워도 이 유닛의 광고 매출은 월 12만~36만 원입니다.**
이것을 숨기지 않고 적습니다. 광고는 **매출이 아니라 계기판**입니다 —
사람이 오는지 아닌지를 돈으로 보여 주는 자리이고, 2031년 2,000억의 갈래는 될 수 없습니다.

**지금 실제 위치**: 28일 클릭 15 = 하루 0.5명. 목표까지 약 2,000배입니다.

## 6. 그래서 무엇을 하나 (제 판단)

```
① B2C 광고 — 유일한 B2C 갈래로 두고, 값을 올리려 하지 않고 «사람 수»만 올립니다
   근거: RPM 은 우리가 못 정합니다. 지면 수는 우리가 정합니다
② B2B — «매출 계획»에서 내립니다. 대신 «인용을 얻는 수단»으로 둡니다
   남이 안 센 것 넷(위 2절)을 계속 무료로 내고, 업계지·연구자가 인용하게 만듭니다
   ⭐ 값은 인용이 쌓인 뒤에 붙습니다. Parrot 이 파는 것도 자료가 아니라 «믿음»입니다
③ 팔기로 가려면 — 먼저 3절의 법적 관문을 풀고, 그다음 «사겠다는 한 곳»을 찾습니다
   ⛔ 순서를 뒤집지 않습니다. 상품을 먼저 만들고 살 사람을 찾는 것이 지난번 제 잘못이었습니다
```

### 하지 않을 것

- ⛔ FlixPatrol 과 같은 자리에서 구독을 팔지 않습니다. 더 적은 것을 더 비싸게 파는 자리입니다.
- ⛔ 「자료 한 벌 판매」를 매출 계획에 다시 적지 않습니다. 사겠다는 곳을 찾은 뒤에 적습니다.
- ⛔ 우리 수를 「검색량」이라 부르지 않습니다. 자동완성은 흔적이고 값이 아닙니다.
