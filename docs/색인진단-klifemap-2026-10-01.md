# 케이라이프맵 색인 진단 — 2026-10-01 · 5번

> 사장님 지시 — 「**케이라이프맵 색인**」 (보안점검 다음 차례)
> 그전 지시 — 「**검색유입 관련한 히스토리부터 확인후 일하라고**」

## 🔴 먼저 — 우리 자가 틀려 있었다

```
색인 검사자(check-색인-왜안되나.mjs)가 재던 것   도구 지면 11장
사이트맵에 실제로 들어 있는 주소                  2,892개
그중 「글」(/content/…)                          2,847개
```

⇒ **검색 자산의 98%를 한 번도 안 물어보고** 「색인이 1장뿐」이라고 보고해 왔다.
⛔ 「자를 먼저 의심한다」가 바로 이 자리다. 수가 이상하면 자부터 본다.
✅ `--글표본 N` 을 붙여 글도 묻도록 고쳤다.

## 재서 나온 것 — 기술은 «전부 멀쩡하다»

| 무엇 | 결과 |
|---|---|
| robots.txt | `Allow: /` · 막힌 지면은 로그인·결제뿐 ✅ |
| 사이트맵 등록 | 구글이 **오늘** 받아 갔다 (klifemap /sitemap.xml) ✅ |
| 안쪽 링크 | 홈 → `/content` → 쪽넘김 **141쪽** → 글. 길이 끊긴 데가 없다 ✅ |
| 글 길이 | 표본 24편 중 18편(75%)이 1,800자를 넘는다. 가운뎃값 2,170자 ✅ |
| 겹침 | 지면마다 66~100%가 그 지면만의 글자다. **중복이 아니다** ✅ |
| 비밀값 유출 | 0곳 ✅ |

## 그런데 실제 색인은 이렇다

```
도구 지면 11장   색인 1 · 왔는데 색인 안 함 6 · 한 번도 안 옴 4
글 표본 14편     🔴 14편 «전부» 구글이 한 번도 안 왔다
```

⇒ **글이 모자란 것도, 길이 막힌 것도 아니다.**
구글이 이 사이트를 **깊이 훑을 값어치가 없다고 판정**하고 있다.
홈 한 장만 넣고 나머지는 보러 오지 않는다.

## 🟡 내가 짚을 수 있는 까닭 — 하나는 숫자로 보인다

글 주소의 꼴이 이렇다.

```
/content/star-q487897-saju-ja      /content/star-q487897-astro-ja
/content/star-q60870265-saju-zh    /content/star-q60870265-astro-zh
```

위키데이터 번호(Q…) × (사주·점성) × 네 말로 **곱해서 만든 틀**이다.
2,847 ≈ 712명 × 4. 구글은 2024년부터 이런 «대량 생산 지면»을
스팸 정책에 직접 적어 두고 있다.

⛔ **이것은 제 짐작이고, 어떻게 할지는 제 자리가 아니다.** 숫자만 적어 둔다.
   사장님이 정해 주시면 그대로 한다.

## 사장님께 — 길은 셋으로 보입니다

```
① 수를 줄이고 하나하나를 두껍게    2,847편 → 사람이 찾는 주제 수십 편으로
                                  (「손님이 검색하는 말로 만든다」)
② 틀로 만든 것을 사람 손으로 덧쓴다  틀은 두되 각 편에 그 사람만의 내용을 더한다
③ 그대로 두고 밖에서 링크를 만든다   밖에서 들어오는 길이 생기면 구글이 다시 본다
```

⚠ 어느 쪽이든 **사이트맵을 다시 내는 것으로는 안 바뀐다.** 오늘 구글이 이미 받아 갔다.

## 함께 고친 것


⚠ 세 자 모두 자가시험이 붙어 있다(11개 · 8개). 「냈다」를 「됐다」로 읽지 않기 위한 자들이다.
