# 같은 사이트인데 색인율이 100% 와 24% 로 갈린다 — 무엇이 다른가

**2026-09-07 · 5번(K Culture Wire) 실측 · 전 유닛 공용**

> ⚠ 이 문서는 **표본으로 잰 것**이다. 전수가 아니다. 그리고 색인 여부는 **구글의 판단**이지
> 사실 그 자체가 아니다. 아래 수는 그렇게 읽는다.

---

## Ⅰ. 무엇을 쟀나

GSC URL 검사 API 로 사이트맵에서 **고르게 뽑은** 지면에 「구글이 이걸 색인했나」를 물었다.
자는 `scripts/check-index-verdict.mjs` 다. 오늘 갈래로 거르는 자(`--걸러=`)를 붙였다.

```bash
node scripts/check-index-verdict.mjs --사이트=kcw --걸러=title/   --몇장=25
node scripts/check-index-verdict.mjs --사이트=kcw --걸러=born-on/ --몇장=25
```

⚠ **깃배시에서는 `--걸러=/title/` 이 윈도 경로로 바뀐다.** 앞 슬래시를 빼고 `title/` 로
주거나 `MSYS_NO_PATHCONV=1` 을 앞에 붙인다. 이 자는 걸린 것이 0장이면 **멈춘다** —
통째로 재고 「/title/ 을 물었다」고 믿는 일이 없게 해 뒀다.

## Ⅱ. 갈린 결과

| 갈래 | 사이트맵 | 표본 | 색인됨 | 기다림 | 크롤 지난 날수(중앙값) |
|---|---:|---:|---:|---:|---:|
| `/born-on/*` | 366장 | 25 | **25장 · 100%** | 0 | 16일 |
| `/title/*` | 546장 | 25 | **6장 · 24%** | 18 | **3일** |
| KCW 전체(갈래 섞음) | 2,830장 | 30 | 13장 · 43% | 17 | — |

### 🔴 이것이 「아직 안 기어갔다」가 아니다

`/title/*` 은 크롤이 **더 최근**이다(중앙값 3일 · 그중 하나는 오늘). 구글이 와서 읽고
**「Crawled – currently not indexed」로 두고 간 것**이다. 반대로 `/born-on/*` 은
16일 전에 한 번 기어간 뒤 25장이 전부 색인돼 있다.

⛔ 그러니 「시간이 더 필요하다」로 설명되지 않는다. 같은 사이트·같은 자료·같은 서버인데
   한 갈래는 다 들어가고 한 갈래는 넷 중 셋이 안 들어간다.

## Ⅲ. 두 갈래가 무엇이 다른가 — 잰 것만 적는다

| | `/born-on/*` (100%) | `/title/*` (24%) |
|---|---|---|
| 장수 | 366 | 546 |
| 본문 낱말 | 672 | **1,723~1,866** |
| 표 | 2 | **4~5** |
| 제목끼리 겹침 | 47% | **60%** |
| 설명끼리 겹침 | 57% | 58% |
| 제목 보기 | `36 Korean stars born on 1 January — 5 K-pop idols` | `12.12: The Day: Netflix country by country, every week it charted` |
| | `20 Korean stars born on 16 January — 7 in K-pop groups` | `Agent Kim Reactivated: Netflix country by country, every week it charted` |

### ⭐ 눈에 걸리는 것 하나

**두꺼운 쪽이 안 들어갔다.** `/title/*` 이 낱말도 두 배 반, 표도 두 배인데 색인율은 4분의 1이다.
⛔ 그러니 「얇아서 안 들어간다」는 흔한 설명은 **여기서는 안 맞는다.**

**제목에서 갈린다.** `/born-on/*` 제목은 장마다 **수가 다르다**(36명·5명 / 20명·7명).
`/title/*` 제목은 **작품 이름 하나만 바뀐다.** 나머지 여섯 낱말이 546장에서 같다.

⚠ **이것을 「제목 겹침이 색인을 정한다」로 읽지 않는다.** 갈래 넷을 잰 것이고, 겹침 47%
와 60% 사이에 다른 것도 많이 다르다. **인과를 못 쟀다.** 다만 방향은 넷이 다 같았다 —

```
제목 겹침 60%  /title/*    색인 24%
제목 겹침 49%  /person/*   색인 29% (표본 7장 — 작다)
제목 겹침 47%  /born-on/*  색인 100%
제목 겹침 39%  /week/*     표본 2장 — 못 쟀다
```

## Ⅳ. 🔴 그리고 우리 노출의 4분의 1은 **눌릴 수 없는 노출**이다

이것은 위와 별개로 오늘 나온 것인데, 함께 알아야 한다. 안 그러면 **엉뚱한 것을 고친다.**

28일(2026-08-08~09-05) 검색어 443개를 갈라 보니 —

| | 검색어 | 노출 | 클릭 | 10위 안 노출 |
|---|---:|---:|---:|---:|
| 넷플릭스 **자기 주소**를 찾는 말 | 21 | **262 (26.4%)** | **0** | 258 |
| 그 밖 (우리를 찾는 말) | 422 | 732 | 3 | 268 |

그 21개가 이런 꼴이다 —

```
"https://www.netflix.com/tudum/top10?week=2024-11-03"      노출 36 · 자리 8.9 · 클릭 0
"netflix.com/tudum/top10?week=2024-11-03"                  노출 15 · 자리 6.7 · 클릭 0
"all-weeks-countries.tsv" netflix                          노출  3 · 자리 2.0 · 클릭 0
```

**그 손님은 netflix.com 에 가려는 사람이다.** 우리 지면이 그 파일 주소를 본문에 적어 뒀기
때문에 7~10위에 뜬다. 그 사람은 우리를 안 누른다 — 누르면 안 된다.

⛔ 그래서 「10위 안 노출이 2,188 인데 클릭이 34 다 ⇒ 제목만 고치면 딴다」로 읽지 않는다.
   그 노출의 절반이 애초에 우리 손님이 아니다.
⚠ 나도 오늘 그렇게 읽으려다 갈라 보고 고쳤다.

※ 재는 축을 섞지 않는다 — 같은 28일인데 **지면 축은 노출 5,124, 검색어 축은 994** 다.
  검색어 축은 구글이 드문 검색어를 빼고 준다. **두 수를 나란히 놓고 몫을 내지 않는다.**

## Ⅴ. 9/05 에 끝난 제목 실험 — 재서 **그대로 두기**로 끝냈다

`src/pages/wikitip/title/[slug].astro` 에 8/26 부터 자물쇠가 걸려 있었다.
자물쇠가 적어 둔 순서 그대로 밟았다.

```
① 바꾸기 전 파일   src/data/gsc-kcw-2026-08-26.json  (창 7/26~8/23 · 검색어 116개)
② 다시 잰 것       src/data/gsc-kcw-2026-09-07.json  (창 8/08~9/05 — 8/25 를 덮는다)
③ 같은 116개 검색어끼리 짝지어 견줬다 (창 길이가 달라 총합끼리는 못 견준다)
```

| | 전 (7/26~8/23) | 후 (8/08~9/05) |
|---|---:|---:|
| netflix 든 검색어 41개 · 노출 | 329 | **367** |
| 같은 41개 · 노출가중 평균순위 | 8.94 | **8.59** |
| 같은 41개 · 클릭 | 2 | **2** |
| 짝 지은 116개 전부 · 노출 | 445 | 515 |
| 자리 움직임 | — | 오름 6 · 내림 0 · 그대로 35 |

**나빠지지 않았다 ⇒ 되돌릴 까닭이 없다. 제목을 그대로 둔다.**

⚠ 그러나 「좋아졌다」고도 안 적는다. 못 잰 것이 셋이다.
- 두 창이 28일 가운데 **16일을 겹친다.** 깨끗한 전/후가 아니다
- 노출이 오른 것이 이 제목 몫인지 사이트가 커진 탓인지 **갈라내지 못했다**
- 🔴 **클릭이 2 에서 2 로 안 움직였다.** 자리 8.6 · 노출 367 에 클릭 2 다

## Ⅵ. 다른 유닛이 지금 할 수 있는 것

**자기 사이트에서 갈래별로 재 보십시오.** 한 줄이다.

```bash
node scripts/check-index-verdict.mjs --사이트=100y      --걸러=school/ --몇장=25
node scripts/check-index-verdict.mjs --사이트=seoulmarkets --몇장=25
node scripts/check-index-verdict.mjs --사이트=klifemap  --몇장=25
```

⭐ 갈래를 갈라 재면 **「우리 사이트 색인율 43%」보다 훨씬 쓸모 있는 수**가 나온다.
   43% 는 100% 인 갈래와 24% 인 갈래를 섞어 놓은 값이고, 그 평균으로는 고칠 데를 못 찾는다.

⛔ 그리고 **한 갈래 표본 6장으로 「0%」라고 말하지 않는다.** 나는 오늘 30장 표본을 갈래로
쪼개 `/title/*` 이 0/6 인 것을 보고 「0%」라고 적으려 했다. 25장으로 늘려 재니 24% 였다.
**갈래별로 물으려면 갈래별로 표본을 다시 뽑는다.**

## Ⅶ. 남은 물음 — 아직 못 쟀다

- 제목을 장마다 다르게(수를 넣어) 만들면 `/title/*` 색인율이 오르나 —
  **못 쟀다.** 재려면 546장 중 일부만 바꿔 A/B 로 걸고 2~3주 기다려야 한다.
  `/born-on/*` 이 8/28 에 홀짝으로 갈라 A/B 를 건 본보기가 있다(`kcw-title-experiments.json`).
- `/person/*` 634장의 진짜 색인율 — **표본 7장으로는 못 쟀다.** 25장으로 다시 잰다.
- 넷플릭스 주소 검색어를 우리가 안 받게 할 수 있나 — **안 재 봤다.** 다만 해가 되는지도
  못 쟀으므로, 재기 전에 손대지 않는다.
