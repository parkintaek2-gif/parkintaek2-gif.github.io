# 사장님 한글 입력 — 원인과 고친 것

> 사장님 말씀(2026-08-21): **「한글입력이 안된다, 내가 말이다」**
> 조직 지침 3 — 「나의 손을 빌리지 말고 스스로 해결하라」. 그래서 제가 재고 고쳤습니다.

## 원인 — 짐작이 아니라 레지스트리를 읽어 확인했습니다

```
LayerDriver KOR          = kbd101a.dll     ← 한국어 101키 «Type 1»
OverrideKeyboardIdentifier = PCAT_101KEY
OverrideKeyboardType       = 7
OverrideKeyboardSubtype    = 0             ← Type 1 이라는 뜻

붙어 있는 키보드   ① LG 노트북 내장 (ACPI\LGEX0001)
                 ② Logitech USB (VID_046D&PID_C548)

입력 언어         ko 하나뿐  → Win+Space 도 바꿀 상대가 없습니다
```

**Type 1 은 한/영이 «전용 키»에만 있습니다.** 로지텍 외장 키보드에는 그 키가 없어서
**누를 데가 없습니다.** 이것이 전부입니다.

## 지금 당장 되는 것 (재부팅 없음 · 위에서부터)

| | 방법 | 비고 |
|---|---|---|
| ① | **노트북 내장 키보드의 한/영 키를 한 번** | 한 번 누르면 그 뒤엔 로지텍으로 계속 한글입니다. IME 모드는 시스템 상태라 키보드를 안 가립니다 |
| ② | **Shift+Space** | MS 한국어 IME 기본. 키보드 종류와 무관 |
| ③ | **화상 키보드** — Win 키 → `osk` 엔터 → 스페이스 오른쪽 한/영 클릭 | 관리자 권한·재부팅 없음. `osk.exe` 있는 것 확인했습니다 |

## 영구히 고친 것 — 다음 재부팅 때 **오른 Alt = 한/영**

```
바꾼 자리   HKLM\SYSTEM\CurrentControlSet\Services\i8042prt\Parameters
바꾼 값     LayerDriver KOR :  kbd101a.dll  →  kbd101c.dll
```

* `kbd101c.dll` 이 `System32` 와 `SysWOW64` 에 **둘 다 있는 것을 먼저 확인**했습니다.
  없는 dll 을 지정하면 부팅 뒤 키보드가 깨집니다.
* **재부팅 전에는 아무 변화가 없습니다.** 부팅 때 한 번 읽는 값입니다.
  그래서 제가 재부팅하지 않았습니다 — 재부팅은 창 아홉을 다 닫습니다.
* 재부팅 뒤 **오른 Alt = 한/영**, **오른 Ctrl = 한자** 가 됩니다.
  노트북 내장 키보드의 전용 한/영 키는 그대로 동작합니다.

### ⛔ 되돌리는 법 (한 줄)

관리자 PowerShell 에서 —

```powershell
Set-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Services\i8042prt\Parameters' 'LayerDriver KOR' 'kbd101a.dll'
```

재부팅하면 예전 상태(Type 1)로 돌아갑니다.

## ⚠ 제가 못 한 것

**「지금 이 순간 한글로 바꿔 드리기」** 는 못 했습니다.
키 주입(`keybd_event` 로 VK_HANGUL 보내기)이 이 세션의 안전 장치에 막혔습니다.
우회하지 않았습니다 — 위 ①②③ 이 그 자리를 대신합니다.
