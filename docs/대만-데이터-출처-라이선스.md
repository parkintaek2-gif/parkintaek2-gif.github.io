## ✅ 판정 — TWSE OpenAPI 는 **상업적 이용 가능**. 조건 셋을 지킨다

```
✅ 쓴다   openapi.twse.com.tw  (OpenAPI · 열쇠 없음 · JSON)
⛔ 안 쓴다 www.twse.com.tw 를 «긁는» 것 — 使用條款이 자동화 수집을 금지한다
조건 ①   출처를 밝힌다 (顯名聲明). 안 하면 «처음부터 허락을 못 받은 것»으로 본다
조건 ②   원자료를 왜곡하지 않는다 (不得任意增刪)
조건 ③   자료 오류에 대해 TWSE 는 책임지지 않는다 — 우리가 검산한다
```

## 1. 무엇을 근거로 이렇게 판정했나 — 받아서 읽은 글

### 1-1. TWSE OpenAPI 자신이 라이선스를 가리킨다

`https://openapi.twse.com.tw/v1/swagger.json` 의 `info.description` 원문 —

> 本平臺提供臺灣證券交易所服務API，歡迎各位介接使用。
> [使用條款](https://www.twse.com.tw/zh/page/terms/use.html) [授權說明網址](https://data.gov.tw/license)

⭐ **API 명세가 스스로 「授權說明」으로 政府資料開放授權條款을 가리킨다.** 짐작이 아니다.

### 1-2. 政府資料開放授權條款 第1版 (OGDL-Taiwan 1.0) — 조문 원문

| 조 | 원문 요지 | 우리에게 뜻하는 것 |
|---|---|---|
| 二(一) | 「授權使用者**不限目的**、時間及地域、非專屬、不可撤回、**免授權金**進行利用…包括但不限於**開發各種產品或服務型態之衍生物**」 | 🔴 **목적 제한이 없다 = 상업적 이용 가능.** 제품·서비스로 만드는 것을 명시로 허락 |
| 二(二) | 「使用者得**再轉授權**他人」 | 우리가 파일·API 로 되팔 수 있다 |
| 二(三) | 「**無須另行取得**…書面或其他方式授權」 | 따로 허락을 받을 필요가 없다 |
| 二(四) | 「授權範圍**不包括專利權及商標權**」 | TWSE 로고·상표를 쓰지 않는다 |
| 三(二) | 「**應以符合附件所示「顯名聲明」要求之方式**…未盡顯名標示義務者，**視為自始未取得**開放資料之授權」 | 🔴 출처표시가 «의무»다. 빠뜨리면 허락 자체가 없던 것이 된다 |
| 四(二) | 「本條款與「**創用CC授權 姓名標示 4.0 國際版本**」**相容**」 | CC BY 4.0 호환 — 한국 공공누리 1유형과 같은 성격 |
| 六 | 오류·누락에 배상 책임 없음 | 우리가 검산한다. 「그쪽 자료라서 맞다」로 넘기지 않는다 |
| 七 | 준거법은 중화민국 법 | — |

### 1-3. 🔴 使用條款 — **한정구를 끝까지 읽는다**

두 문장이 걸린다. 둘 다 한정구가 붙어 있다.

**① 자동화 수집 금지 — 「本網站」에 걸린 말이다**

> 非依臺灣證券交易所同意之方式或經臺灣證券交易所同意者，禁止透過…自動化裝置、指令碼、
> 自動程式、蜘蛛程式、爬蟲程式或擷取程式等方式**下載本網站之軟體或資料**

```
⛔ 막는 것   www.twse.com.tw 를 크롤러로 긁는 것
✅ 안 막는 것 openapi.twse.com.tw — TWSE 가 «기계가 부르라고» 연 API 다.
             명세가 「歡迎各位介接使用」(마음껏 연동해 쓰십시오)이라 적혀 있다.
             곧 「臺灣證券交易所 동의한 방식」 그 자체다
⇒ 그래서 우리는 **웹지면을 긁지 않는다.** OpenAPI 만 부른다. 이 구분이 이 문서의 핵심이다
```

**② 지식재산권 — 개방자료는 «예외»라고 스스로 적어 두었다**

> 任何人除非事前取得…書面同意，不得逕自使用、修改、重製…
> **但臺灣證券交易所已授權「政府資料開放平臺」提供公眾使用之本網站資料，不在此限。**
> 您如要引用或轉載本網站內容，請以適當方式**清楚註明資料來源**，並確保資料完整性，**不得任意增刪**。

```
⭐ 「但…不在此限」 — 개방플랫폼으로 낸 자료는 그 금지에서 «빠진다». 우리 자료가 그것이다
⚠ 「不得任意增刪」은 «원자료를 손대지 말라»는 뜻이다. 우리가 하는 비율 계산은
  원자료를 바꾸는 것이 아니라 «파생물»이고, OGDL 二(一)이 改作·編輯을 명시로 허락한다
```

## 2. 그래서 지면에 이렇게 적는다 (顯名聲明)

```
Source. Taiwan Stock Exchange (TWSE) OpenAPI, released through Taiwan's Open Government
Data platform under the Open Government Data License, version 1.0 — commercial use
permitted with attribution.
```

⛔ 이 줄을 빠뜨리면 **허락 자체가 없던 것이 된다**(三(二)). 지면 각주·꼬리말·About 셋 다에 넣는다.
✅ 자가 잰다 — `node scripts/check-country-sources-disclosed.mjs` 의 나라표에 한 줄을 더한다.

## 3. 무엇을 받을 수 있나 — 실측 (2026-09-23)

| 무엇 | 길 | 잰 것 |
|---|---|---|
| 상장사 일별 시세 전종목 | `/v1/exchangeReport/STOCK_DAY_ALL` | 200 · JSON |
| 상장사 기본정보(회사명·업종) | `/v1/opendata/t187ap03_L` | 200 · JSON · **항목명이 중국어** |

⭐ **바로 이 중국어가 우리 자리다.** 한국 DART 와 똑같은 「언어 장벽형 기회」이고,
  우리는 그 일을 이미 두 번(한국·일본) 해 봤다. 틀(회사 지면·주소·업종)을 그대로 쓴다.

## 4. ⛔ 안 하는 것

```
⛔ www.twse.com.tw 지면을 긁지 않는다 — 使用條款이 막는 바로 그 자리다
⛔ 대만 지수·상표·로고를 쓰지 않는다 (二(四))
⛔ 「TWSE 가 보증한다」는 뜻으로 읽힐 글을 쓰지 않는다 (六(一))
⬜ 公開資訊觀測站(MOPS) 의 재무제표는 아직 안 쟀다 — 그것은 별도 판정이 필요하다.
   이 문서는 **TWSE OpenAPI 에 한한다**
```
