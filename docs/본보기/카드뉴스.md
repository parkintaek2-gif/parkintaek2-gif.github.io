```

크기    1080 × 1350 (인스타·스레드가 세로로 제일 크게 보여 주는 비율)

```

## 다섯 장이 하는 일 — **순서가 뜻입니다**

```
1장   무엇을 보는 건지 한 줄       「고등학교 14곳, 한 눈에」
2장   🔴 제일 센 숫자 하나          「두 학교 사이가 39.8%p 벌어져 있습니다」
3장   그 숫자를 풀어 주는 표·그림
4장   ⚠ **여기에 없는 것**          우리가 모르는 것을 우리가 먼저 말합니다
5장   어디로 가면 되나 (주소 한 줄)
```

⭐ **4장이 이 카드의 핵심입니다.** 자랑만 다섯 장 하면 광고가 됩니다.
   「여기에 없는 것」을 우리가 먼저 적으면 손님이 나머지 넷을 믿습니다.

## 말 — 사장님이 직접 골라 주신 것

```
✅ 「같은 구에도 이만큼 다릅니다」        ← 사장님이 고르신 쪽
⛔ 「이 구는 이렇게 퍼져 있습니다」       ← 무슨 뜻인지 안 통했습니다
```

**규칙 하나** — **통계 낱말을 손님 말로 바꿉니다.**

```
⛔ 표준편차 · 사분위 · 중앙값 · 분포
✅ 「두 학교 사이가 39.8%p 벌어져 있습니다」
✅ 「한가운데는 66.4%」
✅ 「숫자가 있는 곳 12곳」
```

⚠ 숫자는 **반드시 그 지면에 실제로 있는 값**이어야 합니다. 카드용으로 새로 계산하지 마십시오 —
   지면과 카드가 다른 숫자를 말하면 어느 쪽이 거짓말인지 손님이 못 가립니다.
