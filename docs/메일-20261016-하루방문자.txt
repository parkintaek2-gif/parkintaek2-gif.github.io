사장님께

「왜 자꾸 하루방문자가 아닌 28일치를 언급하나. 앞으론 절대 금지」 하셨습니다.
28일 합을 전부 걷어내고 하루 단위로 다시 지었습니다.
나눗셈 평균도 안 썼습니다. 사람은 소수점이 될 수 없습니다.

  첨부   하루방문자_20261016_2010.html   (두 번 누르시면 열립니다)
  주소   https://claude.ai/artifact/HDXd8xENvuJLcHSjyeXYaZ
  원드라이브 업무보고 폴더에도 같은 것을 넣었습니다.

주소는 제 계정으로 올린 것이라 안 열릴 수 있습니다. 그러면 첨부를 보십시오.


1. 어제 하루, 네 사이트에 온 바깥 손님 53명

목표는 사이트마다 하루 1,000명입니다.

  100yearmap.com          17명    목표의 1.7%
  klifemap.ai             14명    목표의 1.4%
  www.kculturewire.com    14명    목표의 1.4%
  seoulmarkets.com         8명    목표의 0.8%

우리가 누른 것과 봇을 뺀 수입니다.
가장 많은 백년지도도 목표의 1.7%입니다.
지면을 더 찍어서 메울 거리가 아닙니다.


2. 어제 Direct 94명을 갈랐습니다

사장님이 「확인도 안 하고 우리가 누른 거라고 한 거지?」 하셨습니다.
맞습니다. 재지 않고 썼습니다. 어제 하루로 다시 재니 이렇습니다.

  우리            28명 (29%)
  봇.클라우드      37명 (38%)
  진짜 손님        32명 (33%)

우리를 가려낸 증거입니다.
세종시로 잡히는 덩어리 안에 localhost 와 127.0.0.1 이 들어 있습니다.
손님이 열 수 없는 주소입니다. 이 PC 의 공인 IP 는 청주인데
구글이 세종시로 읽습니다.

봇을 가려낸 증거입니다.
싱가포르 27, 암스테르담 6, 더블린 3, 프라하 1.
전부 데이터센터 도시이고 한 사람이 1장만 보고 나갑니다.

손님의 증거입니다.
서울 6, 부산 2, 창원 2, 대전 2, 오사카 2, 청두, 다롄, 선전 등
열아홉 도시로 흩어집니다. 휴대폰이 가장 많습니다.
우리는 휴대폰으로 점검하지 않습니다.


3. 오늘 구글 애널리틱스가 0명인 까닭

사이트 문제가 아닙니다. 네 가지를 쟀습니다.

  네 사이트 태그가 살아 있고 HTTP 204 로 받아들여집니다
  실시간 보고에 지금 사람이 잡힙니다
  측정 ID 와 속성이 짝이 맞습니다
  설정은 8월 8일 이후 바뀐 적이 없습니다

결정적인 것은 이것입니다.
같은 자리를 두 번 쟀더니 어제 수치가 118명에서 142명으로 늘어 있었습니다.
어제치도 아직 차는 중입니다. 구글이 오늘치를 아직 안 붙였습니다.
내일 아침에 다시 재겠습니다.


4. 구글이 검색을 막은 것도 아닙니다

구글에게 직접 물었습니다. 세 사이트 홈이 모두 색인에 있고
최근 크롤됐습니다. 사이트맵도 흠 0 으로 받았습니다.
막기는커녕 노출이 늘어 10월 13일에 458회로 최고였습니다.
제재가 걸리면 이 줄이 절벽처럼 0 으로 떨어집니다.

진짜 까닭은 자리입니다. 하루치로 보면 이렇습니다.

  seoulmarkets.com    10-13  노출 458  클릭 6   자리 9.7
  kculturewire.com    10-13  노출  26  클릭 0   자리 7.5
  100yearmap.com      10-13  노출   5  클릭 0   자리 6.2
  klifemap.ai         10-13  노출   0  클릭 0

서울마켓츠는 노출이 가장 많은데 자리가 10위 밖입니다.
사람이 2페이지를 안 넘깁니다.
케이컬처와이어는 반대입니다. 자리는 좋은데 노출이 적습니다.
그 말을 찾는 사람이 적다는 뜻이라 병이 다릅니다.
케이라이프맵은 노출이 0 입니다. 색인 자체가 거의 안 됐습니다.


5. 메일 - 네이버로 다시 못 가게 막았습니다

사장님이 「앞으론 네이버로 보내지마」 하셨습니다.

확인해 보니 저장소는 9월 27일부터 이미 gmail 을 정본으로 두고
네이버를 옛 주소로 적어 두고 있었습니다. 장치는 멀쩡했습니다.
제가 손으로 네이버 주소를 쳐서 그 장치를 건너뛴 것입니다.
오늘 아침 중복 기사와 똑같은 꼴입니다.

그래서 관문을 보내는 길목으로 옮겼습니다.
이제 네이버 주소를 손으로 쳐도 한 통도 안 나갑니다.
실제로 쳐 봤고 막혔습니다. 자가시험 81개가 통과합니다.


6. 못 잰 것

서버 로그로는 순방문자를 셀 수 없습니다. IP 도 쿠키도 안 남기기 때문입니다.
그래서 서버 로그의 수는 조회수이지 사람 수가 아닙니다.

서버 로그의 「하루」는 서버 시계가 UTC 라 한국시간 09:00 부터입니다.
오늘 00~09시 치는 어제 파일에 섞여 갈라낼 수 없습니다.

어제 Direct 안에 (not set) 3명이 남았습니다.
도시가 안 잡혀 우리인지 손님인지 못 갈랐습니다.

네이버 애널리틱스는 아직 못 열었습니다.
네 사이트가 각각 다른 ID 로 따로 집계되는 것은 확인했습니다.
