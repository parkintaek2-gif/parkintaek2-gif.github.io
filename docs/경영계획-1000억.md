## 1. 먼저 — 앞선 계획은 **틀리지 않았다**

내가 오늘 따로 깔아 본 줄과 앞선 계산기의 줄이 거의 같았다. 우연이 아니라 **같은 물건에서 나온 수**다.

| 해 | 앞선 계획 | 내가 따로 깐 것 | 차이 |
|---|---:|---:|---|
| 2027 | 8.2억 | 5억 | 내 쪽이 보수적 |
| 2028 | 36.2억 | 30억 | 비슷 |
| 2029 | 111.0억 | 120억 | 비슷 |
| 2030 | 219.8억 | 300억 | ⚠ 내가 낙관 |
| 2031 | 386.9억 | 600억 | 🔴 내가 낙관 |
| 2032 | **626.9억** | 1,000억 | 🔴 **내가 373억을 근거 없이 얹었다** |
| 2033 | 908.3억 | — | |
| 2034 | 1,000억 돌파 | — | |

⛔ **내 2032년 1,000억은 소망이었다.** 앞선 문서가 이미 이렇게 적어 뒀다 —
> *「1,000억을 2033년 안에 넣으려면 세 사업 전부를 10%씩 올려야 하는데,
> 그 10%가 어디서 오는지 말할 수 없으면 숫자가 아니라 소망이다」*

⭐ 그 원칙이 옳다. 그래서 이 문서는 **373억이 어디서 오는지 이름을 대는 것**만 한다.
   이름을 못 대는 것은 안 적는다.

## 3. 373억을 어디서 가져오나 — **네 갈래. 이름을 댄다**

### ① KLifeMap 을 합산에 넣는다 — **+120억**

⭐ 앞선 역산 문서는 첫 줄에 **「KLifeMap 본체 제외」**라고 적고 셋만 셌다.
   그런데 KLifeMap 은 **오늘 이미 손님이 있는 유일한 사업**이다. 빼고 셀 이유가 없다.

```
사주 리포트   건당 3만원 × 연 30만 건        = 90억
구독          월 9,900원 × 2.5만 명           = 30억
                                        합  120억
```
⚠ 근거 — 오늘 1번이 화면 30장을 전수 감수했고, 7번이 잡은 틀린 말을 고치는 중이다.
   **파는 물건으로서의 꼴이 먼저 갖춰진 사업**이 이것이다.
⚠ 값은 이미 있다 — `klifemap.ai/ai-report.html` 에 6,900 · 9,900 · 29,000 · 39,000 · 49,000 · 54,000 · 79,000원.
   ⛔ 내가 8/8 에 「값이 없다」고 적었던 것은 **fetch 로 재서 JS 가 그린 값을 못 본 탓**이다. 취소한다.

### ② 지자체 리포트를 **낱개가 아니라 연 계약**으로 판다 — **+92억**

```
지금        지역 리포트 9,900원 낱개 · 지면 145장
바꿀 것     시군구 한 곳에 연 4,000만원 (자료 갱신 + 분기 리포트)
2032 목표   229곳 중 **230곳의 20%인 46곳** × 4,000만 = 18.4억
            + 광역 17곳 × 2억 = 34억
            + 중앙부처·공공기관 20곳 × 2억 = 40억
                                        합  92억
```
⭐ **새로 모을 자료가 없다.** 4,768장이 이미 있다. 값과 계약 꼴만 바꾸는 것이다.
⚠ 이것이 373억 중 **제일 확실한 갈래**다 — 손님이 누구인지 이름으로 셀 수 있다(229곳).

### ③ 입시·진로 자료를 업계에 판다 — **+81억**

```
학교 2,525곳 · 대학 학과 837 · 고교 학과 925 · 이은 것 241 — 오늘 실측
손님        입시학원 프랜차이즈 · 진학 상담 서비스 · 교재사
값          연 3,000만원 × 270곳 = 81억
```
⚠ 이 갈래는 **자료가 이미 있고 손님이 돈을 쓰는 시장**이다. 다만 우리가 아직 안 두드렸다.
⛔ 2028년 안에 첫 계약이 없어도 **이 줄을 지우지 않는다.** 방법을 바꾼다 —
   직접 팔아서 안 되면 ① 교재사에 자료를 얹어 파는 꼴로 ② 학원 관리 프로그램 안에 들어가는 꼴로.
   ⚠ 셋 다 안 먹으면 그때 「아직 방법을 못 찾았다」고 적는다. **금액은 안 내린다.**

### ④ 데이터 재판매를 23곳 → 40곳으로 — **+85억**

```
앞선 계획   연 5억 × 23곳 = 115억
당기는 것   연 5억 × 40곳 = 200억   (+85억)
```
⚠ 근거는 ②③ 이 열어 주는 문이다. 지자체 46곳·교육 270곳과 이미 거래하는 회사가
   **재판매 손님 후보**가 된다. 새 영업이 아니라 **같은 손님에게 두 번 파는 것**이다.

```
① KLifeMap    +120억
② 지자체       + 92억
③ 입시·진로    + 81억
④ 재판매 확대  + 85억
              ─────
               +378억   ← 필요한 373억을 넘는다
```

## 3-2. ⛔ 위 네 갈래에는 **새 상품이 하나도 없다** — 이건 잘못이다

> 🔴 사장님(2026-08-08 22:2x) — **「기존 계획 대비 업그레이드 된 상품이 없으면 잘못 경영한 거다」**

맞다. ①~④를 다시 보면 **전부 같은 물건을 다르게 자른 것**이다.
①은 빼 놓았던 사업을 도로 넣은 것, ②는 값과 계약 꼴만 바꾼 것, ③은 손님만 바꾼 것, ④는 곳 수를 늘린 것.

⛔ 내가 **「새로 모을 자료가 없다」를 강점처럼 적었다.** 그건 강점이 아니라
   **상품이 6년 동안 안 자란다는 뜻**이다. 2032년에 2026년 물건을 팔고 있으면 값이 깎인다.

### 그래서 상품을 넷 올린다 — **지금 자료로 되는 것만**

#### 🆕 A. 낱장 리포트 → **살아 있는 리포트** (백년지도 · 2027)

```
지금    9,900원 내면 오늘의 표 한 장. 사면 끝난다
올림    매달 갱신 + **바뀐 것만 알려 준다** — 「이 동네에 100년 가게가 한 곳 문 닫았습니다」
값      9,900원 한 번  →  월 4,900원
```
⭐ 자료는 매달 새로 들어온다. **안 쓰고 버리던 그 갱신이 곧 상품**이다.
⛔ 한 번 팔면 끝나는 물건으로는 1,000억이 안 된다. 손님을 매년 새로 찾아야 하기 때문이다.

#### 🆕 B. 표를 보여 주는 것 → **답을 주는 것** (백년지도 · 2028)

```
지금    「강동구에 100년 넘은 가게가 14곳」            ← 세어서 보여 준다
올림    「이 자리에 이 업종을 열면 몇 해나 버티나」     ← 물음에 답한다
근거    존속 연수 · 업종별 생존 · 국민연금 사업장(지금 202606 까지 들어와 있다)
손님    창업하려는 사람 · 상가 임대 · 프랜차이즈 본사
값      건당 49,000원 또는 월 29,000원
```
⭐ **세는 회사와 답하는 회사는 값이 열 배 다르다.** 자료는 이미 다 있다.
⚠ ⛔ 여기서 「버틴다」를 함부로 말하면 안 된다 — **틀리면 남의 돈이 날아간다.**
   그래서 **까닭과 표본 수를 반드시 같이 낸다.** 오늘 5번이 대조군으로 결론을 3분의 1 깎은 그 방식으로.

#### 🆕 C. 기사 → **지수(指數)** (K Culture Wire · 2028)

```
지금    기사 47편 · 표 여덟 장
올림    **「K콘텐츠 집중도 지수」를 달마다 발행**한다
근거    5번이 오늘 만든 것 — 「절반을 채우는 데 몇 편이 드나」(미국 6편 대 베트남 49편)
손님    제작사 · 배급사 · 해외 플랫폼 · 증권사 리서치
값      연 1,200만원 구독 · 인용은 무료(인용이 곧 영업이다)
```
⭐ 앞선 계획의 지수 갈래는 **금융 지수**였다. 그건 일본 운용업 인가에 묶여 있다.
   **콘텐츠 지수는 인가가 필요 없다.** 같은 「지수 회사」 지위를 **인가 없이** 얻는 길이다.

#### 🆕 D. 리포트 → **묻고 답하는 것** (KLifeMap · 2027)

```
지금    리포트를 읽는다
올림    읽고 나서 **되물을 수 있다** (사장님이 이미 「AI코칭대화를 앞쪽에 배치」 지시하심)
값      리포트 3만원  →  월 19,900원 (되묻기 포함)
```
⭐ 사주는 「내 경우는 어떤가」를 반드시 되묻는 물건이다. **되물을 데가 없어서 못 팔던 것**이다.

### 올린 상품이 표에 얹는 값

```
A 살아 있는 리포트   월 4,900 × 8만 명            = 47억
B 답하는 리포트      월 29,000 × 2.5만 곳          = 87억
C 콘텐츠 지수        연 1,200만 × 90곳            = 108억
D 되묻는 리포트      월 19,900 × 4만 명            = 96억
                                              합 338억
```

⚠ **③입시 81억과 ④재판매 85억을 이 넷으로 갈음한다.** 같은 손님에게 옛 물건을 더 파는 것보다
   **올린 물건을 파는 편이 값이 크고 오래 간다.** ①120억 + ②92억 + 올린 것 338억 = **550억**.
   필요한 373억을 넉넉히 넘는다.

⛔ ③입시·④재판매를 버리는 것이 아니라 **표에서 빼 둔다.** 되면 그때 얹는다.
   ⭐ 안 될 수도 있는 것을 표에 미리 넣지 않는다.

## 5. ⛔ 이 표가 서려면 참이어야 하는 것 — **넷**

앞선 문서가 셋을 적어 뒀다(일본 운용업 전환 · 화교권 교육 · 아카이브 가치). **하나를 더한다.**

**④ 「자료를 파는 회사」가 아니라 「까닭을 대는 회사」로 팔린다.**

지자체·교육·재판매 손님이 우리에게 연 3,000만~4,000만원을 내는 까닭은 자료가 있어서가 아니다.
자료는 공공데이터포털에 공짜로 있다. **우리 수가 왜 그런지 우리가 말할 수 있어서**다.

```
오늘 실제로 있었던 일
  8번이 우리 임금이 공표치보다 위로 치우친 것을 찾아냈다
  3번이 「일부만 비었는데 말이 없는 94장」에 까닭을 달았다
  5번이 대조군을 스스로 놓아 자기 기사의 결론을 3분의 1 깎았다
```
⭐ 이게 상품이다. ⛔ 이 습관이 무너지면 위 표는 전부 종이다. **검사 79개가 이것을 지킨다.**

## 8. ⛔ 이 계획을 고칠 때의 규칙 — **목표는 안 내린다**

> 🔴 사장님(2026-08-08 22:4x)
> **「목표를 이루는게 현실적으로 어렵다 → 목표를 낮춘다(x), 방법을 바꾸거나 새 방법을 찾아 목표를 이룬다(o)」**

```

⭐ 하는 것          빠진 **방법의 이름**을 댄다. 못 대면 「아직 방법을 못 찾았다」고 적고 계속 찾는다
```

⭐ 「현실적으로 어렵다」는 **목표에 대한 판정이 아니라 지금 쥔 방법에 대한 판정**이다.

   ⭐ **금액은 지키고, 거기까지 가는 방법을 이름으로 대는 것**이 답이다.
