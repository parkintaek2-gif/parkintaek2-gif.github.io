## Ⅰ. 무엇을 팔 것인가 — 일본·중국 업체가 준 힌트

### 1-1. 🔴 QUICK(닛케이)이 파는 것 중 **한국에 그대로 있는 것**

`corporate.quick.co.jp/data-factory/en/` 은 영문 **장터**다(콘텐트 45종 · QUICK + 파트너).
그들이 파는 상품 가운데 **우리 원자료로 그대로 만들 수 있는 것**을 골라 냈다.

| QUICK 이 파는 것 (일본) | 한국의 같은 자료 | 우리 상태 (2026-09-09 실측) |
|---|---|---|
| **Large Shareholding Report News (EDINET)** — 대량보유보고를 뉴스 꼴로 | DART `majorstock`·`elestock` | 🟡 열쇠로 됨 확인 (삼성 41행 / 3,399행) · 수집기 없음 |
| **Daily Total Net Assets of MRF** — 개인 대기자금을 «자기가 계산해» 판다 | 증시주변자금 · 투자자예탁금 | ✅ `archive/raw/credit-balance` 있음 |
| **TOPIX Inclusion / Exclusion Criteria** — 지수 편출입 «규칙 자료» | KOSPI200·KRX 지수 편출입 기준 | ⬜ 아직 안 만듦 — **아무도 영어로 안 판다** |
| **QUICK Macroeconomic Consensus** — 이코노미스트 설문 | 한경컨센서스 매크로(EC 8 · MA 183) | ✅ 목록 받고 있음 |
| **Equity / Derivatives Comment** — 자기 논평을 뉴스 꼴로 | 우리 기사 | ✅ 이미 내고 있다 |

⭐ 배울 점 셋 —
```
1. 배달 방식이 곧 상품이다   장터 필터가 «Delivery: REST API / File(SFTP) / Others» 다
2. 자료를 «자기가 계산»한다   MRF 12개를 스스로 합산해 판다. 남의 표를 옮기지 않는다
3. 무료 영문 지면이 깔때기다  QUICK 은 **Japan Markets View** 라는 영문 콘텐트 사이트를
                          «따로» 운영한다 (equity · ESG · 금리 · 거시)
```
🔴 **셋째가 우리가 이미 하고 있는 것이다.** SeoulMarkets 이 그 자리다. 상품이 없었을 뿐이다.

### 1-2. Wind(중국)이 파는 것 — **결과물 형식**을 여기서 배운다

`wind.com.cn/portal/en/` 은 **영문 포털에 상품 28종**을 그대로 갖고 있다(robots `Allow: /`).

```
WDS(Wind Data Service) 의 배달 채널 다섯 — 이것이 「데이터 사업」의 실체다
   Data Synchronization   손님의 SQL Server·Oracle·MySQL 에 «직접 밀어 넣는다»
   Server API             API 게이트웨이로 지표·모델·로직까지 복제해 준다
   Real-Time Quotes       실시간 (⛔ 우리 갈래가 아니다)
   HTML Widget            손님 지면에 꽂는 조각 (PC·모바일·앱)
   Excel plug-in          엑셀에서 바로 당긴다
Data Customization        맞춤 가공을 «따로 판다» — 금지종목 풀 · 규제 보고서 · 맞춤 지수
Commercial/Enterprise     기업 2억 곳 · 임원 2.7억 명 ⭐ **사람 축을 실제로 판다**
Alternative Data          ESG 등급 · 온라인 판매 · PE/VC · 정책·규제 · 토지 경매 · 탄소배출
EDB(경제DB)               중국 3,000개 지역을 시·군·구까지 · 발표 후 5분 반영 ·
                          거시지표 20개의 «기관 전망치와 실제치를 함께»
```
⭐ **임원·기업 자료를 파는 회사가 실제로 있다.** 우리 「사람 축」이 공상이 아니라는 증거다.
⭐ **「기관 전망치 + 실제치」를 함께 파는 꼴** — 우리 목표주가 변경 105건/30일이 같은 물건이다.

> 「Korea Screener API … **개발이 어려운 것 아니지?**」

**질의 층은 어렵지 않습니다. 어려운 것은 «자료를 한 표로 붙이는 일»입니다.** 재서 말합니다.

### 2-2. 그래서 어려운 것은 이 셋이다

```
🔴 1. KOSDAQ 시세가 «없다»       스크리너에 코스닥이 빠지면 상품이 아니다
🔴 2. 조인이 87.8% 다             12%가 안 붙는 까닭을 종목마다 봐야 한다.
                               스팩·우선주·리츠·외국주가 섞여 있을 것으로 «짐작»되지만
                               ⬜ 아직 안 쟀다. 짐작으로 버리지 않는다
🔴 3. 매일 새로 붙이는 일이 없다   지금은 사람이 생각날 때 돌린다.
                               상품이 되면 «빠진 날»이 곧 환불 사유다
🟡 4. 영문 이름·업종 사전이 없다   업종명이 한국어다. 손님이 영어권이다
```

⛔ **질의 층(스크리너)은 이 넷이 끝난 뒤에 «며칠»이면 된다.** 순서를 거꾸로 하면
   화면은 있는데 답이 틀린 스크리너가 나온다. **그것이 가장 나쁘다.**

### 6-2. P4 배달 — **목표일 2026-09-30** · P6 API — **2026-10-15** · P8 스크리너 — **2026-10-31**
