# SeoulMarkets 방향성 — 해외 개인 투자자

## 1. 사장님 지시 (2026-10-27 새벽, 원문)

> 「**투자는 쉽게, 정보는 자세히**」

> 「**에스마켓츠의 방향성에 참조**」 — 함께 보내 주신 기사(김나경 기자, 10월 26일)의 요지

```
· 외국인 이탈이 증시 급락의 직접 원인으로 꼽힌다
· 홍콩·뉴욕 등에서 한국 기업 투자 수요는 느는데 거래 인프라와 정보 접근성이 못 따라간다
· 반도체에 관심이 많은 홍콩·대만 등 아시아권 개인 투자자의 수요가 크다
· 대형 투자은행은 자체 리포트가 있지만 «개인 투자자는 정보 접근성이 낮다»
· 해법으로 외국인 통합계좌 활성화와 «영문 기업 리서치 제공»이 꼽힌다
· 코스닥 기술기업 정보 접근성을 높이는 방안도 제시된다
```

⭐ 기사가 지목한 빈자리 둘 중 하나는 **우리가 할 수 있는 것**이다.
통합계좌는 증권사와 금융당국의 일이지만, **영문 기업 리서치 접근성은 우리 일이다.**

## 2. 실측 — 왜 안 오는가

구글 서치콘솔, 2026-09-26 ~ 10-24 (29일간)

```
전체          노출 685회 · 클릭 6회
한국 관련     질의 43개 · 노출 92회 · 클릭 0회 · 평균 순위 70~87위
반도체 관련   질의 1개  · 노출 1회
일본 기업     질의 77개 · 노출 170회      ← 한국의 약 2배
```

🔴 **두 가지가 동시에 틀어져 있다.**

```
① 우리가 상위에 뜨는 말을 아무도 찾지 않는다
   139개 질의가 이미 10위 안에 있다. 그런데 클릭은 6회다.
   「kusuri no aoki holdings co., ltd. earnings results」 9위 — 검색하는 사람이 없다

② 사람이 찾는 말에서는 우리가 8페이지에 있다
   korean companies 81위 · korea market 74위 · biggest korean companies 84위
```

⇒ 「서울마켓츠」라는 이름을 달고 **일본 기업명으로 발견되고 있으며**,
   한국 기업을 찾는 사람에게는 사실상 존재하지 않는다.

## 3. 🔴 가장 큰 것 — 가진 것을 보여 주지 않고 있다

기사가 「없다」고 지목한 영문 기업 리서치를 **우리는 이미 가지고 있다.**

```
/v1/research    1,139건 · 한국 기업 496개사 · 증권사 21곳 · 2026-06-29 이후
                증권사·애널리스트·투자의견·목표주가, 기업명 영문 병기
/v1/consensus   1,087건 · 예: 삼성전자(005930) 목표주가 460,000원, IBK투자증권
```

그런데 **종목 페이지에는 이것이 한 줄도 없다.** 실측으로 확인했다.

```
seoulmarkets.com/company/sk-hynix
  있는 것   2025년 매출·영업이익·자산·자본, 3개년, 대표이사, 업종
  없는 것   목표주가 · 투자의견 · 증권사 · 애널리스트 — 전부 없다
```

종목 페이지는 2,582개가 이미 있다. **자료는 API 주소로만 나간다.**
API는 기관과 개발자가 쓰는 창구다. 기사가 말한 손님인 홍콩·대만의 **개인 투자자는
API 열쇠를 쓰지 않는다.** 검색에 걸리는 것도 API가 아니라 사람이 읽는 페이지다.

⇒ **가진 것을 안 보여 주는 것이 지금의 가장 큰 손실이다.** 새로 모을 것이 아니라
  이미 모아 둔 것을 사람이 읽는 자리로 옮기는 일이다.

## 4. 방향 — 사장님 말씀을 그대로 옮기면

> 「투자는 쉽게, 정보는 자세히」

```
투자는 쉽게    한 종목을 열면 한 화면에서 끝난다 — 목표주가·투자의견·실적·지분
               API 열쇠도, 가입도, 한국어도 필요 없다
정보는 자세히  수치마다 증권사·애널리스트·발표일·출처를 붙인다
               모르는 것은 「미확인」이라 적는다. 0으로 채우지 않는다
```

### 바꿀 것 셋

```
① 손님        기관·개발자  →  해외 «개인» 투자자 (홍콩·대만·아시아권)
② 보여줄 것   제출 서류 중심  →  목표주가·투자의견을 종목 페이지 맨 위로
③ 축          아시아·걸프 전체  →  «한국», 그중 반도체와 코스닥 기술기업 먼저
```

⚠ ③은 다른 나라 자료를 지우라는 말이 아니다. **먼저 보여 줄 순서를 정하는 것**이다.
   지금은 한국을 찾는 사람에게 일본 기업이 먼저 걸리고 있다.

## 6. 무엇으로 성공을 재는가

```
지금          한국 관련 노출 92회 · 클릭 0회 · 평균 70~87위
4주 뒤 목표   한국 관련 클릭 0회 → 유의미한 수, 평균 순위 30위 안
매주 화요일   node scripts/fetch-gsc.mjs --사이트 seoulmarkets 로 다시 잰다
```

⚠ 이 목표는 노출이 아니라 **클릭**으로 잰다. 노출 685회에 클릭 6회를 겪었으므로
  노출은 사람이 왔다는 증거가 되지 못한다.
