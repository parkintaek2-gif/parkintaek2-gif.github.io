## 내가 다섯을 고른 기준

연중기획은 **열두 번을 버텨야 한다.** 그래서 「좋은 주제」가 아니라
**「열두 달치 자료가 이미 세상에 있는가」**로 골랐다.

```
① 자료가 «이미» 공개돼 있나      — 없으면 둘째 달에 멈춘다
② 달마다 «다른 각»이 나오나      — 같은 말을 열두 번 하면 연중기획이 아니다
③ 충북·청주의 «고유한» 이야기인가 — 전국 어디에나 해당하면 지역지가 쓸 까닭이 없다
④ 남을 섭외하지 않고 굴러가나    — 사장님 지시: 사람을 거치는 계획을 세우지 않는다
⑤ 수로 말할 수 있나             — 「활성화가 필요하다」는 사설이지 보도가 아니다
```

## ① 충북 학교체육 12년 추적 — 「그 많던 학교 운동부는 어디로 갔나」

| | |
|---|---|
| **요지** | 충북의 학교 운동부가 12년 동안 어떻게 줄었고, 줄어든 자리에 무엇이 남았나 |
| **달마다** | 종목별로 나눈다 — 1월 축구, 2월 야구, 3월 육상… 종목마다 팀 수·학생 수·대회 성적의 12년 곡선을 그린다 |
| **자료** | 교육부 학교알리미(학교별 운동부 현황·공시) · 대한체육회 등록선수 통계 · 충북교육청 공시 |
| **왜 심층인가** | 한 해 수치가 아니라 **12년 추세**를 잇고, 폐지된 운동부의 학생들이 어디로 갔는지를 진학·전학 자료로 따라간다 |
| **강점** | 자료가 전부 공개돼 있어 섭외 없이 열두 달을 채운다 |

## 다섯을 내가 매긴 순위 (규정 확인 전 잠정)

```
1위  ③ 충북 출신 프로선수 지도   — 자료가 확실하고 선수 이름이 들어가 읽힌다
2위  ① 학교체육 12년 추적        — 12년 곡선이라 심층의 모양이 가장 뚜렷하다
3위  ④ 생활체육 인구            — 분포로 쪼개는 우리 방식과 맞고 사회 축과 겹친다
4위  ② 공공체육시설             — 돈 이야기라 세지만 정보공개 청구가 필요할 수 있다
5위  ⑤ 스포츠 예산              — ②와 겹친다. 둘 중 하나만 한다
```

⚠ ②와 ⑤는 겹친다. 둘을 하나로 합쳐 **「체육에 쓴 돈」** 한 갈래로 묶는 편이 낫다.
  그러면 다섯이 아니라 넷이 되고, 빈자리는 중부매일 계정이 낸 열 건에서 채운다.
