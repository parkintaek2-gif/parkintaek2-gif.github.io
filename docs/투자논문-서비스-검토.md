## Ⅰ. 결론 — 팔린다. 다만 「논문」을 팔면 안 팔린다

### 1-1. 경쟁사가 이미 하고 있다 (Quantpedia · 라이브 실측)

```
900+  논문에서 뽑은 전략 (Premium)          ← 이것이 «상품»이다
1000s 연구 논문                             ← 이것은 «끼워 주는 것»이다
~800  코드 포함 · ~400  매달 백테스트 갱신
10~15 매달 새 전략 추가
40    Pro 리포트 (「100yrs Portfolio Analysis」 · 「100yrs Market States Analysis」 등)
3단   Prime(100+ 전략) / Premium(900+ 전략 + 논문) / Pro(+리포트)
```

⭐ **논문은 재료이고 상품은 「전략 + 코드 + 백테스트」다.** 사장님이 못박아 두신
「우리는 raw data 를 가공하는 회사다」가 정확히 이 꼴이다.
⛔ 논문 자체는 OpenAlex·SSRN 에 무료로 있다. 그것만 모아 파는 것은 값이 안 붙는다.

### 1-2. 못 쟀은 것

```
⬜ 요금   플랜을 골라야 값이 뜬다. 다음에 브라우저로 다시 잰다
⬜ OpenAlex 데이터 라이선스   문서 페이지가 JS 라 글자로 못 잡았다 (CC0 로 알려져 있으나 안 적는다)
```

## Ⅲ. 우리가 남과 다를 자리 — 한국 × 사람

### 3-1. 한국 조각 — 복제해 주는 곳이 없다

```
"Korean stock market"  1,643      "KOSPI"  2,727      "KOSDAQ"  1,321
"Korean won"           1,206      Korea+ESG   882     "Korean bond market"  58
```

Quantpedia 는 미국·글로벌이다. **한국시장에 복제해 주는 곳이 없다.**
그리고 우리는 복제할 재료가 있다 — 공공데이터포털 시세 2,873종목/일(제한 없음) ·
DART 공시 · 한경 목표주가.

### 3-2. 🔴 사람 축 — 우리 말고 못 하는 것

| 논문 축 | 편수 | 한국 복제에 필요한 자료 |
|---|---:|---|
| "gender diversity" × firm performance | 1,335 | 성별 비중 |
| "human capital" × stock returns | 158 | 근속·학력 |
| "executive compensation" × stock returns | 139 | 임원 급여·재직기간 |
| "employee satisfaction" × stock returns | 48 | (대리지표 필요) |
| "employee turnover" × stock returns | 11 | 근속·이직 |
| **합** | **1,691** | **People Panel — 회사 2,879 · 사람 1,872,028** |

⭐ 사장님이 정해 두신 **「그들은 재무를, 우리는 사람을 한다」**가 여기서 그대로 상품이 된다.
⭐ 그리고 이것이 **투자 AI 셋의 애널리스트 AI 재료**다 — 논문이 신호의 «근거»가 된다.
  ⚠ 리스크관리 AI 의 몫도 여기 있다: 논문 하나가 틀렸을 때 무엇을 잃는지를 적는 칸.
