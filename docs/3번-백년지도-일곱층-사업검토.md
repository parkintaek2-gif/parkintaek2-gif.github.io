## 0. 먼저 — **「행복을 찾아가는」이 사업에 하는 일**

간판 문구가 아니다. **팔 물건의 경계선**이다.

```
⛔ 이 말이 지우는 것   「좋은 대학 보내 드립니다」 · 「이 길이 정답입니다」 · 「올해 입시 전략」
                      → 입시 컨설팅과 같은 물건이 되면 우리는 진다. 그쪽은 사람이 판다
⭐ 이 말이 여는 것     대학 안 가는 길도 같은 무게로 · 층이 바뀌어도 **같은 손님**
                      → 한 사람에게 **일곱 번** 팔 수 있다. 이게 1,000억의 유일한 길이다
```

🔴 ③에서 우리가 이미 적어 둔 말 — *「한 번 팔면 끝나는 물건으로는 1,000억이 안 된다」*.
**일곱 층은 그 답이다.** 10대에 한 번 팔고 끝나던 것을, 같은 사람에게 40년 판다.

⚠ 그래서 이 문서는 층마다 **「이 층에서 얼마」**가 아니라
   **「이 층이 다음 층으로 손님을 넘기나」**를 같이 본다.

## 2. ⭐ 5·6층 — **자료가 이미 있다. 오늘 지면이 0장이다**

`age-axis.json` 을 열어 보니 50·60대 칸이 **이미 채워져 있다.**

```
월급여(고용노동부 2025)     50~54  456만원 · 근속 10.9년 · 152만 명
                           55~59  422만원 · 근속 11.1년 · 132만 명
                           60세~  319만원 · 근속  6.4년 · 173만 명
살림(국가데이터처)          50~59세  자산중앙 3억 8,005만 · 부채중앙 7,500만 · 소득중앙 7,805만
                           60세 이상 자산중앙 2억 8,060만 · 부채중앙 5,000만 · 소득중앙 3,978만
                           65세 이상 자산중앙 2억 4,400만 · 부채중앙 4,000만 · 소득중앙 3,198만
```

🔴 **이 숫자 하나가 곧 상품이다.**

```
60세부터 월급여가 422만 → 319만으로 **103만원 떨어진다**(-24%)
근속은 11.1년 → 6.4년.   같은 자리에 못 있는다는 뜻이다
그런데 그 나이의 가구 소득중앙은 7,805만 → 3,978만, **절반**이 된다
```

⛔ 지금 우리는 이 자료를 **10대 진로 지면에만** 쓰고 있다.
   `/age` 한 장이 있지만 **「나이로 보기」 한 장**이고 팔 물건이 아니다.

⚠ 그리고 이 층의 손님은 **1층 손님의 부모가 아니라 그 손님 자신**이 된다 —
   지금 40대인 학부모가 10년 뒤 5층 손님이다. **떠날 이유가 없는 손님**이다.

## 3. 층마다 — 무엇을 얼마에

⛔ ③에서 찾은 어긋남(9,900이 단건인지 월인지 · 구독료 4,900/6,900/9,900 셋)을
   여기서 **하나로 정한다.** 두 벌을 두면 또 갈라진다.

### 정하는 것 — **단건은 미끼, 돈은 구독에서**

```
지역 한 벌 9,900원      그대로 둔다. ⛔ 다만 이것이 매출의 기둥이 아니다.
                        ③ 우리 말 그대로 「사면 끝나는」 물건이다 — **미끼로 쓴다**
구독 월 9,900원          역산(249억)이 선 값으로 맞춘다. 4,900·6,900 은 버린다
                        ⚠ 근거: 21만 명 × 9,900 × 12 = 249억. 값을 내리면 사람 수가 두 배 필요하다
                        ⛔ 금액을 안 내린다는 지시에 따라 **9,900으로 못 박는다**
```

| 층 | 파는 것 | 값 | 오늘 되나 |
|---|---|---|---|
| 1 | 지역 한 벌(단건) | 9,900원 | ✅ 지면 114곳 · ⛔ 결제 없음 |
| 1~7 | **백년 구독** — 층이 바뀌면 보는 것이 바뀐다 | 월 9,900원 | ⛔ 지면 0장 |
| 2 | 대학 학과 한 벌 | 구독에 포함 | ⛔ 지면은 있는데 묶음이 없음 |
| 3·4 | 업종·지역 한 벌 | 구독에 포함 | ⛔ 자료 있음 · 지면 0장 |
| 5 | **제2직업 한 벌** — 내 업종에서 50대가 얼마 받나·얼마나 버티나 | 구독에 포함 | ⛔ 자료 있음 · 지면 0장 |
| 6 | **은퇴 한 벌** — 60세 넘어 얼마 · 자산/부채 중앙값 | 구독에 포함 | ⛔ 자료 있음 · 지면 0장 |
| 1~7 | **기관 자료** (교육청·지자체) | 별도 | ⛔ 값 없음 · §5 |

### 🔴 왜 구독인가 — 층이 답이다

```
단건    한 사람에게 9,900원 한 번        → 21만 명을 **해마다 새로** 찾아야 249억
구독    한 사람에게 월 9,900원 × 40년    → 21만 명을 **한 번** 찾으면 된다
```
⭐ 일곱 층은 **구독을 유지시키는 이유**다. 10대가 끝나도 볼 것이 남는다.

## 5. 🔴 유료 판매가 되는가 — **진지하게**

### ⓐ B2C — **된다. 다만 오늘 물건이 아니다**

```
✅ 되는 근거   ③ ⑨의 「정부가 공짜로 준다」는 **한 층에만 맞는 말**이다.
              대학알리미가 주는 것은 **대학 학과 숫자**(2층)다.
              ⛔ 대학알리미는 **한 구의 고등학교를 한 표에** 놓아 주지 않는다.
              ⛔ 50대 임금과 60대 자산을 **한 사람의 시간축**으로 이어 주지 않는다.
              우리가 파는 것은 숫자가 아니라 **묶는 방식**이다
⛔ 안 되는 것  결제가 없다. 오늘 아홉 갈래 중 결제 붙은 것 **0개**
```

### ⓑ 값이 셀 것인가 — **오늘은 못 잰다. 그대로 적는다**

```
⬜ 못 쟀다   9,900원에 살 사람이 몇인지 우리는 아직 모른다.
            알림 신청이 0건이다(메일 mailto 라 세는 자리도 없다)
⭐ 잴 수 있다 알림 신청을 **서버로 받으면** 그날부터 세진다.
            여는 날 전에 이것부터다 — **살 뜻을 세는 것이 값을 정하는 유일한 길**
```

### ⓒ B2B·기관 — **오늘 근거가 하나 생겼다**

8번이 2026-08-09 01:31 에 지역 축을 공표치와 맞대 봤다.

```
전국 -1.4% · 상관 r = 0.935 · 15개 시도 중 12개가 ±2.5% 안
⛔ 서울만 -7.0% 이고 **까닭을 못 밝혔다**(8번이 그대로 적었다)
```
⭐ 기관에 파는 물건은 **「우리 수가 공표치와 맞는다」는 증거**가 값이다. 그게 생겼다.
⚠ 다만 값도 손님 명단도 없다. ⛔ 여기서 금액을 지어내지 않는다.

### ⓓ 🔴 오늘 매출이 0인 진짜 까닭

```
물건이 없어서가 아니다.   지역 한 벌 114곳이 서 있다
손님이 없어서도 아니다.   검색·유튜브로 오는 길이 뚫렸다(두 번 안에 닿는 지면 100%)
⛔ **받을 자리가 없어서**다.  결제가 0개다
```
