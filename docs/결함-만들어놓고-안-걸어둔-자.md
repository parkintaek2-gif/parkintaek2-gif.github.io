# 결함 — 「만들어 놓고 안 걸어 둔 자」

> 처음 적은 날 2026-10-09 · 5번
> 겪은 곳 klifemap(158곳) · 100yearmap(115 → 133)

## 한 줄로

**자를 만들었고, 그 자는 맞았고, 그런데 아무도 안 불러서 넉 달치가 조용히 쌓였다.**

## 무슨 일이 있었나

```
10-03 09시   사장님 「순한글 쓰지 말라」 → scripts/check-순한글조어.mjs 를 만들었다
             그날 잰 값 — klifemap/public 42개 파일 중 0개.  ⭐ 이 수는 참이었다
             (10-09 에 커밋 트리를 꺼내 다시 재서 확인했다)
10-05 01시   일주 페이지 60장을 틀로 찍었다 → 「지면」이 120곳 들어갔다
             ⛔ 그 커밋 글에도 「일주 지면 60장 … 지면 수가」라고 적혀 있다
10-09 15시   라이브를 손으로 눌러 보다가 바닥글에서 「다른 지면」을 봤다 → 재 보니 158곳
```

**나흘 동안 아무 자도 울지 않았다.**

## 까닭이 둘이었다 — 하나만 고치면 또 샌다

```
① 아무 데서도 안 불렸다        → 「안 불리는 자는 자가 아니라 도장이다」
② 빨간불을 찍고도 exit 0 이었다 → 관문에 걸어도 «언제나 초록»이다
```

⭐ **②가 ①보다 나쁘다.** ①은 「안 돌았다」가 언젠가 드러나지만,
②는 **돌았는데 초록**이다. 다음 사람이 「검사가 돌았으니 괜찮다」고 읽는다.
「**거짓 초록은 빨강보다 나쁘다**」가 정확히 이 자리다.

## 어떻게 알아보나

새 검사를 만들었을 때 **이 둘을 같이 묻는다.**

```
묻기 ①   이 자를 «누가» 부르나?        → 아무도 안 부르면 그것은 도장이다
묻기 ②   흠이 났을 때 끝값이 몇인가?   → 0 이면 관문에 걸어도 안 막는다
```

⛔ 「나중에 관문에 걸겠다」로 미루지 않는다. 그 「나중」이 나흘이었다.

## 어떻게 막나

```
✅ 만든 그 자리에서 배포 관문에 건다 — 다음 걸음으로 미루지 않는다
✅ 걸기 전에 «일부러 깨뜨려» 끝값 1 이 나오는지 본다. 안 깨뜨려 보면 모른다
✅ 다 막으면 배포가 멈출 때는 «못 박은 수»를 두고 늘 때만 운다
   ⚠ 「고칠 수 없게 우는 검사는 결국 꺼진다」 — 꺼지면 없느니만 못하다
   ⚠ 줄었으면 못 박은 수도 함께 줄인다고 화면에 적는다. 안 줄이면 다음에 늘어도 안 운다
⬜ 일부러 «안 막는» 알림용 자는 그렇게 적어 둔다 — 「⛔ 막지 않는다」
   그래야 다음 사람이 그것을 흠으로 오해하지 않는다
```

## 곁따라 나온 것 — 내 잣대도 틀렸다

이 결함을 훑으려고 `check-울지못하는자.mjs` 를 만들었다.
🔴 첫 잣대가 「배포 관문의 **15개가 못 막는다**」고 했는데 **전부 틀렸다.**
`process.exit(` 뒤에 숫자 1~9 가 바로 오는 것만 봤는데,
실제 코드는 `process.exit(실패 ? 1 : 0)` 이고 `process.exitCode = 재고알리기()` 였다.

⭐ 「**급히 만든 잣대는 자료 모양을 짐작한다**」 — 열어 보면 10초인데 안 열어 봤다.
잣대를 고쳐 다시 재니 저장소 전체 136개 중 못 우는 것 **63 → 8**,
**배포 관문 23개 중 흠은 0개**였다. 여덟은 전부 일부러 안 막는 알림용이었다.

⇒ **못 박는 수를 적기 전에 그중 몇을 열어 본다.** 어림으로 수를 적지 않는다.
