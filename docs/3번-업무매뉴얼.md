## 🆕 새 지면 하나 만들 때 (KOSIS 등 실측 콘텐츠)

1. **검증**: KOSIS `statisticsSearch.do`로 표 찾기 → `node scripts/lib/kosis-probe.mjs <orgId> <tblId>`로
   **objL 단계 수부터 잰다**(짐작 금지 — 2026-09-01 사고: 단계 수를 잘못 짚어 err21을
   "표가 없다"로 오판, 검증된 자료를 갈아엎을 뻔했다) → `statisticsParameterData.do`로 실측 →
   보도자료·뉴스 인용값과 대조해 "일치" 확인. 안 맞으면 짐작하지 말고 "못 쟀다"로 적는다.
   ⚠ `objL2=ALL`은 1,000행에서 조용히 잘릴 수 있다 — 항목을 쪼개서 받고 몇 칸 받았는지 센다.
2. **자료**: `src/data/100yearmap/{slug}.json` (출처·받은때·보도자료대조 필드 필수)
3. **지면**: `src/pages/100y/{slug}/index.astro` — FAQPage(있으면), "이것은 통계이지 당신이
   아닙니다" 포함, 판정 어휘(많다/적다/좋다/나쁘다/심각하다/등수/순위) 금지 — **부정문도 걸린다**
4. **배선 6곳** (하나라도 빠지면 지면이 "떠 있어도 안 이어진" 상태가 된다):
   - [ ] `src/pages/100y/sitemap.xml.ts`
   - [ ] `scripts/build-100y-lastmod.mjs` (갈래 dict)
   - [ ] `src/lib/klifemap.ts` (붙일수있는갈래 · 어른갈래)
   - [ ] `src/components/HundredAgeWalk.astro` (나이 축이면 차례, 아니면 온줄)
   - [ ] `src/pages/100y/ages/index.astro` (나이 축 지면만 — 문들 배열)
   - [ ] `src/data/100yearmap/_provenance.json` (한 줄만 추가, 전체 재작성 금지)
   - [ ] `src/pages/100y/llms.txt.ts` — **2026-08-30부터 필수.** 빠지면 AI가 그 지면을 모른다
5. 매 라운드 즉시 커밋 (모아서 한 번에 하지 않는다)

## 🚀 배포 (순서 고정 — 순서 바꾸면 사고난다)

1. `node scripts/build-once.mjs`
2. `node scripts/check-100y-broken-links.mjs`
3. `node scripts/check-100y-banned-words.mjs`
4. `node scripts/check-100y-llms-freshness.mjs`
5. `.cloudtype-deploy-lock.json` 없는지 확인(있으면 대기)
6. `node scripts/deploy-key.mjs` → 물어보는 줄 번호의 「무엇이」 칸을 **정확히** 옮겨 답한다
7. `node scripts/check-deploy-ready.mjs --열쇠 <키>`
8. `node scripts/deploy.mjs --열쇠 <키>` — ⛔ **열쇠 받은 뒤 커밋 절대 금지**(하면 열쇠가 죽는다).
   커밋이 필요하면 처음부터 다시(6번부터)
9. 배포는 10분+ 걸릴 수 있다 — 백그라운드로 돌리고 기다린다
10. **라이브를 직접 curl로 재서 확인** — 자가시험 통과·exit 0은 "만들었다"이지 "맞게 나갔다"가
    아니다. 핵심 수치가 실제 화면에 보이는지 본다(공통규칙10)

- 짐작으로 답하지 않는다 — 확인하고 말한다([[feedback_verify-before-speaking]])

- 영상엔 실제 목소리를 얹는다 — anullsrc(빈 소리) 금지, 스틸이미지 슬라이드쇼 금지
- 유튜브 업로드는 매일 필수 아님(2026-08-30 확정) — 자체 mp4+VideoObject+영상사이트맵이 표준
- 순방문자 셀 때 **Direct는 안 센다** — Organic Search·AI Assistant·Organic Social만
  "진짜 손님"이다(2번 정본, 2026-08-29)
- 사장님이 직접 지시한 일을 끝내면 `node scripts/tell-owner.mjs "제목" "본문" --보낸다`로
  완료 이메일. 정기 업무보고는 이것과 별개로 2번 경유만(직접 보고 금지)
- 응답은 **존댓말**로(2026-08-31)
