# 1. 증권사 · 자산운용사

**사장님 착안 — 하고 싶은 것 (2026-08-02)**

> 증권사와 자산운용사를 만들고 싶다.

## 왜 이게 중요한가 — 지금 계획의 숫자를 바꾼다

매출계획은 **지수를 만들어 남의 ETF에 라이선스**하는 것으로 짜여 있다.
그런데 **같은 AUM에서 우리가 직접 운용하면 8.3배다.**

```
AUM 5조 · 남의 ETF가 우리 지수를 추종   →  15억   (라이선스 요율 0.03%)
AUM 5조 · 우리가 운용사로 직접 굴린다   → 125억   (총보수 0.25%)
```

| 총보수 | 직접 운용 시 (AUM 5조) | 라이선스만 |
|---:|---:|---:|
| 0.15% | 75억 | 15억 |
| **0.25%** | **125억** | 15억 |
| 0.35% | 175억 | 15억 |

**전략 문서 §5.5 의 「지수 150억」은 야심이 틀린 게 아니라 방식이 틀렸다.**
라이선스로는 15억이 한계고, **운용사면 150억이 나온다.**
그러니 그 150억은 폐기할 숫자가 아니라 **경로를 바꿔 되찾을 숫자**다.

## 그런데 전부 허가·등록업이다 — 사다리로 오른다

한꺼번에는 못 간다. **자본 요건이 낮은 것부터 올라가고, 앞 단계의 매출로 다음 단계를 연다.**

| 단계 | 무엇 | 자본 요건 | 우리 조건에서 |
|---|---|---|---|
| **0** | **지수 산출** (지금 계획) | **없음** | **오늘 시작 가능.** 12년 백테스트 보유 |
| 1 | 투자자문업 | 낮음 | 지수 기반 자문. 매출로 자본 마련 |
| 2 | **전문사모 집합투자업** | 중간 | **우리 지수 추종 상품을 직접 운용** |
| 3 | 공모 자산운용사 | 높음 | ETF 를 직접 낸다 |
| 4 | 증권사(투자매매·중개) | 매우 높음 | 가장 나중 |

> ⚠ **자본금·인적·물적 요건의 구체 수치는 확인 안 했다.** 금융투자업 인가·등록
> 요건은 업종별로 다르고 개정도 잦다. **2026년 4분기 법률 검토에서 지수 라이선스
> 문제와 **같이** 확인한다** — 어차피 같은 자리에서 묻는 질문이다.

## 세 기준으로 재보면

| | 판정 | 근거 |
|---|---|---|
| 사람을 더 안 쓰나 | **△** | 등록업은 인적 요건이 있다. 단 **운용은 지수 규칙이 하므로 소수로 가능** |
| 돈을 먼저 안 쓰나 | **✗** | 자본금이 선투자다. **그래서 단계를 나눈다** |
| 지금 가진 것에 붙나 | **◎** | 12년 아카이브 · 지수 · 영문 매체 — **전부 이 방향의 준비물이다** |

**2번이 유일한 걸림돌이고, 사다리가 그 답이다.** 0단계(지수 산출)는 오늘 되고,
거기서 나온 돈과 실적이 1단계의 자본과 명분을 만든다.

## 이 관점이 바꾸는 것 — 지수의 위치가 또 올라간다

지수를 「매출 15억짜리 항목」으로 보면 우선순위가 낮다.
**운용사로 가는 사다리의 0단계**로 보면 이야기가 다르다.

```
지수 산출 실적  →  자문업 등록의 근거  →  사모운용 상품의 기초자산  →  공모 ETF
```

**12년 백테스트가 이 사다리 전체의 출발점이다.** 오늘 백필을 돌리는 이유가 여기 있다.

## 사장님께 여쭐 것

1. **어느 칸을 먼저 노리십니까.** 자문업부터인지 사모운용부터인지에 따라
   2027년에 준비할 것이 완전히 달라진다
2. **증권사(중개)는 자산운용과 성격이 아주 다르다.** 중개는 규모·전산·자본 싸움이고,
   운용은 상품과 실적 싸움이다. **우리 자산은 명백히 운용 쪽**인데, 증권사도 같이
   보시는 이유가 있으신지 (예: 자체 판매 채널 확보)
3. 금융투자업 쪽에 닿는 선이 있으십니까 — 20년 보신 판이면 있을 것 같다

# 2. 교육 어드바이즈 — 「대입 다음」을 보는 라이프맵

**사장님 착안 (2026-08-02)**

> 획일적·선행학습 위주로 아이들을 지옥에 빠뜨리지 않고, 자기 삶을 주도하게 하는 교육.
> 뇌과학·심리학·교육학·철학(명리학 포함)을 아울러 **진짜 교육**을 할 수 있게 하는
> 어드바이즈 비즈니스. 사교육 시장에 획기적·학생친화적 모델을 낸다.
> 진로적성코칭과 연계하고, 목표가 오직 대입이 아니라 **그 이후를 보고 라이프맵**을 짜는
> 자기주도학습 프로그램. **여러 관련 학문이 결합해야 한다.**

## 세 기준으로 재보면 — 셋 다 통과한다

| | 판정 | 근거 |
|---|---|---|
| 사람을 더 안 쓰나 | **○** | 코칭 자체는 자체 AI 가 한다 |
| 돈을 먼저 안 쓰나 | **○** | 결제·구독·리포트·다국어가 KLifeMap 에 이미 있다 |
| 지금 가진 것에 붙나 | **◎** | **새로 만드는 게 거의 없다** |

이미 있는 것 (KLifeMap · 실측)

```
careerCoach          19,000원      진로코칭
parentCoaching       29,000원      부모코칭
childCareerCoaching  29,000원      자녀진로코칭
sajuAiReport         39,000원      AI 종합리포트
화면                 ai-coach.html · coaching.html
```

**부품은 다 있고 조립과 이름이 없다.** 1인 회사에서 이보다 싼 신사업은 없다.

## ① 핵심 — 「그 학과 나오면 실제로 어떻게 됐는가」

이 회사가 잘하는 일은 **아무도 아카이빙 안 하는 공공데이터를 상품으로 만드는 것**이다.
SeoulMarkets 의 본편과 정확히 같은 구조를 교육에 적용한다.

```
증권   애널리스트가 목표주가를 말한다  →  맞았는지 아무도 안 센다   →  우리가 센다
교육   어른들이 이 과에 가라고 한다    →  가서 어떻게 됐는지 안 본다 →  우리가 본다
```

| 출처 | 무엇이 나오나 |
|---|---|
| **대학알리미** | 학과별 **취업률 · 유지취업률 · 중도탈락률** |
| 한국교육개발원 교육통계 | 진학·졸업·계열별 추이 |
| 고용노동부 임금구조 | 직업별·학력별 실제 임금 분포 |
| 교육부 사교육비 조사 | 과목·지역·소득별 지출 |

**「유지취업률」이 특히 크다.** 취업률은 학교가 관리하는 숫자지만 **1년 뒤에도 그 자리에
있는 비율**은 다른 이야기를 한다. 학과 단위로 학부모가 읽게 만든 것이 없다.

> 코칭의 부속물이 아니라 **그 자체로 팔리는 물건**이고, **기사 소재가 무한히 나온다.**
> 발행 파이프라인이 이미 도니 유입 비용이 0이다.

## ② 포지션 — 학원을 안 파는 유일한 조언자

한국의 진로·입시 조언은 **전부 무언가를 파는 사람에게서 나온다.**
조언과 판매가 같은 주머니에 있으면 조언이 휘어진다. 학부모도 안다.

> **"우리는 학원을 팔지 않습니다. 그래서 안 다녀도 된다고 말할 수 있습니다."**

## ③ 「여러 학문 결합」을 구호가 아니라 구조로

이름만 나열하면 사교육 업계 문구와 구별이 안 된다. **무엇을 대는지**를 못 박는다.

| 학문 | 실제로 대는 것 | 증거 수준 |
|---|---|---|
| **인지심리 · 학습과학** | 자기주도학습의 **방법** — 인출 연습, 간격 반복, 교차 연습 | **가장 탄탄** |
| **동기 이론** | 「자기주도」의 뼈대 — **자율성 · 유능감 · 관계성** | 탄탄. 측정 도구 있음 |
| **발달 인지신경** | 청소년기 자기조절·계획 능력이 **아직 자라는 중** | 개괄은 견고. **개인 예측 불가** |
| **교육학** | 형성평가 · 메타인지 · 스캐폴딩 | 실무 검증 |
| **철학 · 명리** | 기질을 **말할 수 있게 하는 언어**. 예측 아님 | 근거 아님. **틀로만** |
| **우리 데이터** | 그래서 **실제로 어떻게 됐는가** | 1차 공공데이터 |

### 뼈대 — 자율성 · 유능감 · 관계성

「자기주도학습」이 왜 한국에서 안 되는지가 이 셋으로 설명된다.

```
자율성   무엇을 언제 할지 내가 정한다  →  사교육 스케줄이 이걸 0으로 만든다
유능감   할 만하다고 느낀다            →  선행학습은 늘 「아직 못 함」을 만든다
관계성   나를 믿는 사람이 있다         →  성적이 관계의 조건이 되면 사라진다
```

**의지의 문제가 아니라 구조의 문제다. 이게 진단이 되고, 진단이 상품이 된다.**
「우리 아이가 왜 스스로 안 하는가」에 셋 중 어디가 무너졌는지로 답하는 것은 시장에 없다.

### ⚠ 폐기된 통설을 쓰지 않는다 — 이것 자체가 차별화다

교육은 **뇌과학이 가장 많이 오용되는 곳**이다. 사교육이 파는 것 중 폐기된 것이 많다.

```
✗ 좌뇌형·우뇌형     ✗ 학습유형(시각/청각/운동)별 수업
✗ 「뇌의 10%만 쓴다」  ✗ 결정적 시기가 지나면 늦다 (과장)
```

> **"폐기된 뇌과학 통설을 쓰지 않습니다. 무엇을 근거로 하는지 전부 밝힙니다."**

사교육이 근거를 안 대는 시장이라 **근거를 대는 것만으로 차별화된다. 돈이 안 든다.**

## ④ 유통 — 1인이 파는 게 아니라 학교에 들어간다

| 경로 | 왜 |
|---|---|
| **진로진학상담교사** | 전국 중·고교에 배치돼 있고 **쓸 도구가 마땅치 않다** (확인 필요) |
| 지자체 청소년상담복지센터 | 예산이 있고 대상이 명확 |
| 기업 임직원 복지 | 자녀 진로 상담은 복지 항목이 된다 |

**학원에 파는 게 아니라 「학원에 안 가도 되는지 판단하는 도구」를 학교에 넣는다.**

## ⑤ 라이프맵의 실제 형태

```
지금(중2) → 고교 선택 → 전공 계열 → 첫 직업 → 10년 뒤 갈래
              │            │           │
              │            │           └ 유지취업률·임금 (공공데이터)
              │            └ 학과별 중도탈락률 (공공데이터)
              └ 기질·인지 특성 (검사 + 명리 기질 프레임)
```

**공공데이터가 오른쪽을, 검사·코칭이 왼쪽을 채운다.** 지금은 왼쪽만 있어서
「적성은 알겠는데 그래서 뭐」가 된다.

## ⚠ 반드시 지킬 선

**① 명리는 예측이 아니라 기질의 틀로만.**
「너는 이런 사주니 이 길이 맞다」는 아이에게 해롭고, **자기주도를 기르겠다는 사업이
선택지를 좁히는 도구가 되면 정반대의 일**이다. 브랜드도 즉시 죽는다 —
**「사교육 점집」 소리를 들으면 학교에 못 들어간다.**

```
✗  관성이 강하니 공무원이 맞다
○  규칙이 분명할 때 안정되는 아이다 — 그런 환경을 먼저 시험해 보자
```

**② 미성년자 데이터는 규제가 다르다.** 법정대리인 동의·보관·파기.
성인 서비스 구조를 그대로 쓰면 안 된다 (요건 확인 필요).

## 어떻게 시작하나 — 돈 안 드는 순서

| 순서 | 할 것 | 왜 이 순서인가 |

## 매출 계획에 넣을 것인가 — 아직 아니다

**2~3번의 반응을 보고 숫자를 넣는다.** 지금 넣으면 근거 없는 숫자가 하나 더 늘 뿐이다.

## 적는 방식

- 사장님이 말씀하시면 **내가 여기 적는다.** 사장님이 문서를 여실 일 없다
- 판단이 갈리는 것만 여쭌다. 명백한 것은 바로 실행 항목으로 옮긴다
- 실행에 들어간 것은 여기서 빼고 매출계획으로 옮긴다
- **접은 아이디어도 이유를 적어 남긴다.** 조건이 바뀌면 살아나는 것이 있다
