# 아이디어 보관함

**대화 중에 나온 아이디어가 여기 쌓인다.** 말로만 하고 지나가면 없어진다.
사장님이 던지시면 내가 여기 적고, 판단이 필요한 것만 따로 여쭌다.

> 사장님은 오픈뱅킹을 **2003년**에, 데이터 사업을 **20년 전**에, 사주를 **5년 전**에
> 하려 하셨다. 전부 「직접 프로그래밍을 못해」 미뤄뒀던 것이다.
> **그 제약이 지금 없다.** 그래서 옛 아이디어도 새 아이디어와 같은 자격으로 여기 들어온다.

## 거르는 기준 — 셋만 본다

인력 1명, 자금 0원이라는 조건은 아이디어를 고르는 기준을 아주 단순하게 만든다.

| | 묻는 것 | 안 되면 |
|---|---|---|
| **1** | 사람을 더 안 쓰고 되는가 | 계획의 본체가 못 된다. 파트너에게 넘길 방법을 찾는다 |
| **2** | 돈을 먼저 안 쓰고 되는가 | 벌린 뒤로 미룬다. 순서만 바꾸면 되는 경우가 많다 |
| **3** | **지금 가진 것에 붙는가** | 처음부터 만드는 것은 1인 회사에서 가장 비싸다 |

3번이 실제로 제일 중요하다. **지금 가진 것**이 무엇인지 적어 둔다 — 여기 붙는 아이디어가 싸다.

```
리서치 아카이브   목록 66,071건 · 2014~2026 연속 12년 · 목표주가와 투자의견
종목코드 대응     58,000건 · 종목 2,445개
발행 파이프라인   마크다운 넣으면 배포·색인·RSS·OG 까지 자동
공공데이터 수집기 덮어쓰지 않고 개정 이력을 남기는 구조
영문 매체         seoulmarkets.com · 미국 독자 대상
```

### 1. 오픈뱅킹 — 2003년에 하려 했던 것

사장님이 2003년에 제안하셨던 것. 한국이 실제로 오픈뱅킹을 시행한 것은 **2019년**이니
16년 빨랐다. **지금 무엇을 하려 하셨던 것인지 듣지 못했다.**

23년 전 구상이라 그때의 「오픈뱅킹」과 지금의 제도가 같은 것을 뜻하지 않을 수 있다.
**무엇을 하려 하셨던 것인지 말씀해 주시면 여기 적고 세 기준으로 재보겠다.**

지금 자산과 붙는 지점이 있을 수는 있다 — 금융 데이터를 영문으로 가공해 파는 것이
이 회사의 본업이고, 오픈뱅킹 API 는 그 자체가 데이터 소스다. 다만 **개인 금융정보는
재배포 근거가 전혀 다른 영역**이라, 지금 사업의 라이선스 구조와 같이 볼 수 없다.

## 적는 방식

- 사장님이 말씀하시면 **내가 여기 적는다.** 사장님이 문서를 여실 일 없다
- 판단이 갈리는 것만 여쭌다. 명백한 것은 바로 실행 항목으로 옮긴다
- 실행에 들어간 것은 여기서 빼고 `docs/매출계획-2026-2029.md` 로 옮긴다
- **버리는 아이디어도 이유를 적어 남긴다.** 조건이 바뀌면 살아나는 것이 있다
