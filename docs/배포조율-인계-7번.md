## 2. 두 저장소, 두 관문 — 다릅니다

### ⓐ dataeconomics (백년지도 · KCW · SeoulMarkets)
```
C:/Users/USER/Documents/GitHub/dataeconomics
```

🔴 **열쇠 관문이 있습니다. 그리고 열쇠가 자꾸 죽습니다.**
```
① 물음이 실행마다 바뀝니다 — 「되돌아간것.tsv 의 N번째 줄」에서 N 이 매번 다릅니다 ●
   (오늘 본 것: 3 → 6 → 7 → 3 → 7)
② 열쇠는 **커밋이 바뀌거나 날이 바뀌면 죽습니다** ●
```
✅ **그래서 「물음 읽기 → 답하기 → 배포」를 한 번에 해야 합니다.** 나눠서 하면 그사이에 죽습니다.

```bash
cd /c/Users/USER/Documents/GitHub/dataeconomics
Q=$(node scripts/deploy-key.mjs 2>&1)
N=$(echo "$Q" | grep -oE '[0-9]+번째 줄' | grep -oE '^[0-9]+' | head -1)
A=$(grep -v "^#" docs/되돌아간것.tsv | sed -n "${N}p" | cut -f3)
OUT=$(node scripts/deploy-key.mjs --답 "$A" 2>&1)
K=$(echo "$OUT" | grep -oE '\b[0-9a-f]{10}\b' | head -1)
node scripts/deploy.mjs --열쇠 "$K"
```
⚠ `&&` 로 잇지 마십시오. `deploy-key.mjs` 가 답 없이 돌면 종료코드가 1이라 거기서 끊깁니다 ●.
   `;` 로 잇거나 위처럼 줄을 나눕니다.

⚠ **배포는 2~5분 걸립니다.** 백그라운드로 돌리고 기다리십시오.
