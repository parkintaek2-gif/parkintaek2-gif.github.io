## 1. ⬜ 그러면 6번의 40초는 무엇이었나 — **못 쟀다**

재현되지 않는다. 그러니 원인을 «지어내지 않는다». 잰 것과 못 잰 것을 가른다.

```
잰 것     포트 /json/version 200 · 탭 19개 · about:blank 7개가 쌓여 있었다
잰 것     지금 puppeteer.connect 는 0.1초에 붙는다
잰 것     한경컨센서스 지면은 그때 이미 열려 있었고 로그인도 되어 있었다
못 잰 것   6번이 겪은 그 40초. 나는 그 자리에 없었고 다시 만들지 못했다
```

⭐ 짐작하지 않고 말할 수 있는 것은 이 하나다 — **6번은 「connect 단계」라고 보고했지만,
그 다음 걸음에서 멈춘 것을 그렇게 읽었을 수도 있다.** ⚠ 이것도 짐작이다. 6번 코드를 안 봤다.

⛔ **원인을 모르면 모른다고 적는다.** 내가 그러지 않아서 이 문서가 몇 시간 만에 거짓을 실었다.

### 그래도 확실히 남는 것 하나

```
6번은 「사장님이 크롬을 다시 띄워 주셔야 한다」로 일을 넘겼다.  ← 이것은 필요 없었다
```

포트가 200 이고 탭이 열려 있었으므로 크롬은 멀쩡했다. **원인을 모른 채로도
「사장님 손이 필요하다」는 결론은 틀렸다는 것을 알 수 있었다.** 그 판정이 이 문서의 값이다.

## 2. 증상으로 가르는 표 — **여기서 먼저 갈라라**

```bash
curl -s -m 8 http://127.0.0.1:9222/json/version
curl -s -m 8 http://127.0.0.1:9222/json/list
```

| 증상 | 무엇인가 | 무엇을 하나 |
|---|---|---|
| `/json/version` 이 **연결거부** | 크롬이 디버깅포트 없이 떠 있다 | 크롬을 완전히 닫고 `--remote-debugging-port=9222` 로 다시 띄운다 |
| `/json/version` **200** · `/json/list` **200** | 크롬은 멀쩡하다. **사장님 손은 필요 없다** | 우리 쪽에서 뚫는다 — 3번으로 간다 |
| 그런데도 어딘가에서 «멈춘다» | ⬜ **원인은 그때그때 다르다. 단정하지 마라** | 걸음마다 시간을 «재라» (아래 3-a) |
| `about:blank` 탭이 여러 개 쌓였다 | 앞선 시도가 탭만 만들고 끝을 못 냈다 | 쌓인 탭을 치우고 다시 잰다 |
| API 가 `인가되지 않은 접근입니다` | 로그인은 됐는데 토큰이 필요한 자리다 | 4번 — **토큰을 만지지 않고** 받는 길이 있다 |

⛔ **「연결이 안 된다」를 한 낱말로 쓰지 않는다.** 「거부」와 「멈춤」은 원인이 정반대다.
거부는 크롬 쪽이고, 멈춤은 대개 **우리 쪽**이다.

⛔ 그리고 **사장님께 「크롬을 다시 띄워 주십시오」를 올리기 전에 위 두 줄을 재라.**
200 이 뜨면 사장님이 하실 일이 없다.

### 3-a. 멈추면 «어디서» 멈추는지 걸음마다 잰다

이것이 오늘 얻은 진짜 교훈이다. 6번도 나도, 「멈췄다」를 한 덩이로 보고 원인을 지어냈다.

```js
const 잰다 = async (이름, 하는일) => {
  const t0 = Date.now();
  try { const r = await 하는일(); console.log(`✅ ${이름} ${((Date.now()-t0)/1000).toFixed(1)}초`); return r; }
  catch (e) { console.log(`⛔ ${이름} ${((Date.now()-t0)/1000).toFixed(1)}초 · ${e.message}`); return null; }
};
```

⭐ 걸음을 갈라 재면 **connect 냐 newPage 냐 goto 냐**가 바로 갈린다. 나는 이 열 줄로 내 오진을 잡았다.

## 3. `scripts/lib/cdp.mjs` — puppeteer 없이 붙는 길

⛔ **판 어긋남을 고치는 자가 «아니다».** 그 값은 셋이고, 판 문제와 무관하다.

```
1. 모든 명령에 «제한 시각»이 있다 — 멈추지 않고 「몇 ms 안에 안 왔다」며 죽는다
   ⭐ 6번이 잃은 것은 시간이 아니라 «판정»이었다. 멈춘 자는 원인을 말해 주지 않는다
2. klifemap 의 node_modules 를 빌리지 않는다 — Node 20 부터 WebSocket 이 내장이다
3. 인가가 걸린 API 를 «토큰을 만지지 않고» 읽는다 (4번 절)
```

⚠ **puppeteer 를 쓰던 자를 억지로 옮기지 않는다.** `check-ad-fill.mjs` 는 잘 돌고 있다.
새로 짓는 자는 cdp 쪽이 가볍고 제한 시각이 있어 낫다 — 그 정도로만 말한다.

```js
import { 새탭에서, 자리잡기, 재기 } from './lib/cdp.mjs';

const 답 = await 새탭에서('https://markets.hankyung.com/consensus', async (붙음) => {
  await 붙음.보내기('Network.enable');
  await 자리잡기(붙음);                       // 요청이 멎을 때까지 (최대 25초)
  return 재기(붙음, 'document.title');        // 그 탭에서 자바스크립트를 돌린다
});
```

### 이 자가 지키는 것

```
✅ 언제나 «새 탭»을 만들어 쓰고, 끝나면 «그 탭만» 닫는다
✅ 모든 명령에 제한 시각이 있다 — 「몇 ms 안에 안 왔다」고 말하고 죽는다
⛔ 브라우저를 닫지 않는다 — 사장님이 쓰시던 창이 통째로 사라진다
⛔ 비밀번호·토큰을 읽거나 어디로 보내지 않는다
```

## 4. 인가가 걸린 API 를 **토큰을 만지지 않고** 읽는다

한경컨센서스가 이 꼴이었다.

```
밖에서 curl        →  {"message":"인가되지 않은 접근입니다."}
탭 «안»에서 fetch  →  같은 답 (403)
성공한 요청의 머리글 →  Authorization 이 붙어 있었다 (길이 75)
```

⛔ **그 값을 읽어 옮기지 않는다.** 강령에 「비밀번호·토큰을 읽거나 어디로 보내지 않는다」가 있다.

✅ 대신 **지면이 스스로 낸 요청의 «응답 몸»**을 받아 온다. 토큰을 만질 일이 아예 없다.

```js
import { 새탭에서, 자리잡기, 응답몸받기, 줄들로 } from './lib/cdp.mjs';

await 새탭에서(목록주소, async (붙음) => {
  await 붙음.보내기('Network.enable');
  const { 모은것 } = 응답몸받기(붙음, /\/api\/v2\/.*page=(\d+)/, (u) => Number(RegExp.$1));
  await 자리잡기(붙음);
  // 쪽 단추를 눌러 «지면이» 부르게 하고, 그 답을 주워 온다
});
```

### ⚠ 여기서 조용히 자료를 잃는 함정 둘

**하나 — 1쪽과 2쪽의 자료 꼴이 달랐다.**

```
1쪽    data: [ {...}, {...} ]              ← 배열
2쪽    data: { "50": {...}, "51": {...} }  ← 번호를 키로 쓴 객체
```

⛔ `Array.isArray(data)` 로만 재면 **2쪽부터 0줄로 읽힌다.** 오류도 안 난다.
623건 가운데 50건만 받고 「받았다」로 넘어갈 수 있었다.
✅ `줄들로(data)` 가 두 꼴을 다 받는다. 자가시험에 두 꼴이 다 들어 있다.

**둘 — 「지금 보고 있는 쪽」은 링크가 아니다.**

```
누르기 전       처음,2,3,…,10,다음,끝          부른 쪽 1
「다음」 누른 뒤  처음,이전,4,…,10,12,13,끝      부른 쪽 1,11
「11」 찾기      11 없음
```

⭐ 「다음」은 창만 넘기는 것이 아니라 **11쪽을 실제로 불러온다.** 그런데 지금 쪽은 링크가
아니어서 「11」 단추가 없다. ⛔ 「단추를 눌렀나」로 성공을 판정하면 **이미 받은 쪽을
못 받았다고 적는다.** ✅ 판정은 «자료가 들어왔나»로만 한다.

## 5. 이 길로 실제로 무엇을 했나 (2026-09-08)

```
node scripts/collect-seoulmarkets-hankyung-consensus.mjs
```

```
목록 총 623건 · 13쪽 · 쪽당 50 — 받은 건수 623 · 못 받은 쪽 0
받는 법  CDP 직결 — 토큰을 만지지 않는다
아카이브 archive/raw/hankyung-consensus/consensus-YYYY-MM-DD.json
```

⚠ **못 받은 쪽은 「못 받았다」고 적는다.** 빈 배열로 채우지 않는다 —
빈 값은 「그날 리포트가 없었다」로 잘못 읽힌다.

⚠ 목표주가 `"0"` 은 **0원이 아니라 「안 냈다」**다. `null` 로 둔다.
`Number("0") === 0` 이 「못 잼」을 「0원」으로 바꾸는 자리다.
