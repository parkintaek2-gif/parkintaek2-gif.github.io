# 브라우저가 안 붙을 때 — **증상으로 가른다. 다시 띄우는 것이 답이 아닐 수 있다**

> 사장님 지시 (2026-09-08 원문)
> 「**되면 6번한테 방법을 알려줘라....다른 세션들도 브라우저 열리지 않을 때 대처방법 공유하고**」
>
> 같은 날 함께 — 「**네가 해봐**」 · 「**내가 해당 페이지 열어서 로그인해놓음**」

이 문서는 **5번이 6번의 막힘을 실제로 뚫고 나서** 쓴 것이다. 짐작이 아니다.

---

## 1. 왜 이 문서가 필요한가

6번이 이렇게 알려 왔다.

> 「9222 접속이 끝까지 안 됩니다 — 포트 자체는 응답하는데(`/json/version` 정상),
> 브라우저 연결(`puppeteer.connect`) 단계에서 **40초 넘게 멈춰** 아예 안 넘어갑니다.
> 이전에 기록해 둔 그 증상(**연결거부 지속=크롬이 디버깅포트 없이 떠 있는 것,
> 코드 말고 새로 띄워야 함**)과 같은 계열로 보입니다.」

🔴 **같은 계열이 아니었다.** 그리고 그 판정 때문에 6번은 「사장님이 크롬을 다시 띄워 주셔야 한다」로
일을 넘겼다. **크롬은 처음부터 멀쩡했다.**

```
잰 것                              값
──────────────────────────────────────────────────────────────
curl /json/version                 ✅ 200 · Chrome/152.0.7977.76
curl /json/list                    ✅ 탭 19개 — 한경컨센서스 지면도 이미 열려 있었다
puppeteer.connect                  🔴 40초+ 멈춤. 오류도 안 낸다
about:blank 탭                     🔴 7개가 쌓여 있었다
```

⭐ **`about:blank` 가 쌓인 것이 열쇠였다.** 연결이 «탭은 만들고» 끝을 못 낸 자취다.
  포트가 막혔으면 탭이 만들어질 수 없다. 그러니 포트 문제가 아니다.

⭐ 까닭은 **판 어긋남**이다.

```
크롬                          152.0.7977.76
klifemap 의 puppeteer-core     23.11.1   ← 우리가 빌려 쓰는 것
```

⛔ 프로토콜이 안 맞으면 **puppeteer 는 오류를 내지 않고 «기다린다».**
  그래서 「연결거부」로도, 「크롬이 안 떴다」로도 안 보인다. **그냥 멈춘 것처럼 보인다.**

## 2. 증상으로 가르는 표 — **여기서 먼저 갈라라**

```bash
curl -s -m 8 http://127.0.0.1:9222/json/version
curl -s -m 8 http://127.0.0.1:9222/json/list
```

| 증상 | 무엇인가 | 무엇을 하나 |
|---|---|---|
| `/json/version` 이 **연결거부** | 크롬이 디버깅포트 없이 떠 있다 | 크롬을 완전히 닫고 `--remote-debugging-port=9222` 로 다시 띄운다 |
| `/json/version` **200** · `/json/list` **200** · 그런데 puppeteer 가 **멈춘다** | 🔴 **판 어긋남.** 크롬은 멀쩡하다 | **puppeteer 를 쓰지 않는다.** 아래 3번으로 간다 |
| `about:blank` 탭이 여러 개 쌓였다 | 앞선 연결 시도가 탭만 만들고 끝을 못 냈다 | 같음 — 3번으로 간다. ⚠ 쌓인 탭은 지워 준다 |
| API 가 `인가되지 않은 접근입니다` | 로그인은 됐는데 토큰이 필요한 자리다 | 아래 4번 — **토큰을 만지지 않고** 받는 길이 있다 |

⛔ **「연결이 안 된다」를 한 낱말로 쓰지 않는다.** 「거부」와 「멈춤」은 원인이 정반대다.
  거부는 크롬 쪽이고, 멈춤은 **우리 짐 쪽**이다.

⛔ 그리고 **사장님께 「크롬을 다시 띄워 주십시오」를 올리기 전에 위 두 줄을 재라.**
  200 이 뜨면 사장님이 하실 일이 없다. 우리가 짐을 바꾸면 되는 것이다.

## 3. puppeteer 없이 붙는다 — `scripts/lib/cdp.mjs`

CDP 는 웹소켓 한 줄이다. **Node 20 부터 `WebSocket` 이 내장**이라 남의 짐이 아예 필요 없다.

```js
import { 새탭에서, 자리잡기, 재기 } from './lib/cdp.mjs';

const 답 = await 새탭에서('https://markets.hankyung.com/consensus', async (붙음) => {
  await 붙음.보내기('Network.enable');
  await 자리잡기(붙음);                       // 요청이 멎을 때까지 (최대 25초)
  return 재기(붙음, 'document.title');        // 그 탭에서 자바스크립트를 돌린다
});
```

**실측 — 같은 지면, 같은 시각.**

```
puppeteer.connect      40초 넘게 멈춤 (끝내 못 넘어감)
scripts/lib/cdp.mjs    5.6초에 지면을 다 읽음
```

### 이 자가 지키는 것

```
✅ 언제나 «새 탭»을 만들어 쓰고, 끝나면 «그 탭만» 닫는다
✅ 모든 명령에 제한 시각이 있다 — 「몇 ms 안에 안 왔다」고 말하고 죽는다
⛔ 브라우저를 닫지 않는다 — 사장님이 쓰시던 창이 통째로 사라진다
⛔ 비밀번호·토큰을 읽거나 어디로 보내지 않는다
```

⭐ **멈추는 것보다 죽는 것이 낫다.** 오늘 6번이 잃은 것은 시간이 아니라 «판정»이었다 —
  멈춘 자는 「안 되는 것」처럼 보이지만, 죽는 자는 «왜 안 되는지»를 말해 준다.

## 4. 인가가 걸린 API 를 **토큰을 만지지 않고** 읽는다

한경컨센서스가 이 꼴이었다.

```
밖에서 curl        →  {"message":"인가되지 않은 접근입니다."}
탭 «안»에서 fetch  →  같은 답 (403)
성공한 요청의 머리글 →  Authorization 이 붙어 있었다 (길이 75)
```

⛔ **그 값을 읽어 옮기지 않는다.** 강령에 「비밀번호·토큰을 읽거나 어디로 보내지 않는다」가 있다.

✅ 대신 **지면이 스스로 낸 요청의 «응답 몸»**을 받아 온다. 토큰을 만질 일이 아예 없다.

```js
import { 새탭에서, 자리잡기, 응답몸받기, 줄들로 } from './lib/cdp.mjs';

await 새탭에서(목록주소, async (붙음) => {
  await 붙음.보내기('Network.enable');
  const { 모은것 } = 응답몸받기(붙음, /\/api\/v2\/.*page=(\d+)/, (u) => Number(RegExp.$1));
  await 자리잡기(붙음);
  // 쪽 단추를 눌러 «지면이» 부르게 하고, 그 답을 주워 온다
});
```

### ⚠ 여기서 조용히 자료를 잃는 함정 하나

한경컨센서스는 **1쪽과 2쪽의 자료 «꼴»이 달랐다.**

```
1쪽    data: [ {...}, {...} ]              ← 배열
2쪽    data: { "50": {...}, "51": {...} }  ← 번호를 키로 쓴 객체
```

⛔ `Array.isArray(data)` 로만 재면 **2쪽부터 0줄로 읽힌다.** 오류도 안 난다.
  623건 가운데 50건만 받고 「받았다」로 넘어갈 수 있었다.
✅ `줄들로(data)` 가 두 꼴을 다 받는다. 자가시험에 두 꼴이 다 들어 있다.

⭐ **꼴이 한 쪽만 보고 정해지지 않는다.** 목록 API 를 새로 만나면 «2쪽도» 열어 본다.

## 5. 이 길로 실제로 무엇을 했나 (2026-09-08)

```
node scripts/collect-seoulmarkets-hankyung-consensus.mjs
```

```
목록 총 623건 · 13쪽 · 쪽당 50
받는 법  CDP 직결 — 토큰을 만지지 않는다
아카이브 archive/raw/hankyung-consensus/consensus-YYYY-MM-DD.json
```

⚠ **못 받은 쪽은 「못 받았다」고 적는다.** 빈 배열로 채우지 않는다 —
  빈 값은 「그날 리포트가 없었다」로 잘못 읽힌다.

⚠ 목표주가 `"0"` 은 **0원이 아니라 「안 냈다」**다. `null` 로 둔다.
  `Number("0") === 0` 이 「못 잼」을 「0원」으로 바꾸는 자리다.

```
1. 브라우저가 안 붙으면 2번 표로 «갈라라». 다시 띄우기는 «거부»일 때만 답이다
2. puppeteer 를 새로 쓰지 마라 — 이 저장소의 표준은 scripts/lib/cdp.mjs 다
3. 인가가 걸린 API 는 4번 길로 간다. 토큰을 옮기지 않는다
4. 쌓인 about:blank 탭은 치워 준다 — 사장님 창이 지저분해진다
```

⛔ 그리고 **「브라우저가 안 되어서 못 했습니다」를 사장님께 올리지 않는다.**
사장님이 「많은 권한을 위임했잖아」라고 하신 것이 바로 이 자리다.
포트가 200 이면 우리가 뚫을 수 있는 자리다.
