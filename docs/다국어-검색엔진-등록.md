# 다국어 검색엔진 — **어디에 등록해야 하나** (2026-08-06 조사)

> 사장님 지시(2026-08-06): 「좀 지나면 **KLifeMap 은 다국어로 다** 하잖아. 그러면
> **중국어, 일본어** 그것들은 **어디서 검색 등록을 해야 되는지, 색인해야 되는지**
> 그거를 조사를 해서 나한테 보고를 해」

---

# 결론 먼저 — **일본은 공짜, 중국은 큰 결정이다**

```
🟢 일본     **추가로 할 일이 거의 없다.** 지금 구글·빙 등록으로 이미 덮인다
🔴 중국     바이두를 하려면 **중국 내 호스팅과 ICP 비안(备案)** 이 사실상 필요하다
            — 이건 SEO 문제가 아니라 **법인·인프라 결정**이다
🟢 대만·홍콩 구글이 지배적. 중국 본토와 완전히 다르다. 번체 페이지만 있으면 된다
```

---

# Ⅰ. 일본 — **이미 덮여 있다**

## 1-1. 점유율 (2026년 4월 기준)

```
PC      구글 59.6%  ·  빙 31.6%  ·  야후재팬
모바일   구글 84.0%  ·  야후재팬 12.3%  ·  빙 0.9%
```

⭐ **야후재팬은 자체 검색엔진이 없다. 구글 엔진을 쓴다.**
   → **구글에 색인되면 야후재팬에도 같이 나온다.** 따로 등록하는 곳이 없다.

⭐ 빙은 **IndexNow 로 이미 통보하고 있다.** 우리가 쓰는 그 경로가 그대로 일본에도 간다.

## 1-2. 그래서 할 일

```
✅ 이미 함    Google Search Console 등록 · IndexNow(빙·얀덱스) 통보
⬜ 해야 할 것  **`hreflang` 태그**  — 어느 언어판인지 검색엔진에 알린다
              일본어판 URL 구조를 정한다 (`/ja/…` 또는 `ja.` 서브도메인)
⛔ 안 해도 됨  야후재팬 별도 등록 — **그런 창구가 없다**
```

**즉 일본은 「등록」 문제가 아니라 「사이트 구조」 문제다.** 돈도 서류도 안 든다.

---

# Ⅱ. 중국 — **바이두는 SEO 문제가 아니다**

## 2-1. 무엇이 필요한가

```
바이두 웹마스터툴 (ziyuan.baidu.com)   해외 호스팅이어도 **등록 자체는 된다**
ICP 비안(备案)                        **중국 내 서버를 쓰면 법적으로 필수**
                                      해외 호스팅이면 없어도 되지만 **순위가 확실히 약하다**
```

⚠ **ICP 비안은 외국 법인이 단독으로 못 받는다.** 중국 내 법인·주소·담당자가 있어야 한다.
   대행을 쓰면 되지만 **비용과 기간이 든다.** 이건 마케팅 결정이 아니라 **법인 결정**이다.

## 2-2. 더 큰 장벽 — **속도와 접근성**

```
우리 서버는 Cloudtype(한국)이다. 중국에서 열면 느리거나 끊긴다
바이두는 **느린 사이트를 잘 안 올린다.** 등록만 해서는 순위가 안 나온다
→ 제대로 하려면 중국향 CDN 이 필요하고, 그것도 비안이 있어야 제대로 붙는다
```

## 2-3. 그래서 내 판단

```
⏸ **지금은 하지 않는다.** 등록만 해 두는 것은 값이 거의 없다
✅ 대신 **중국어(번체) 로 대만·홍콩을 먼저 잡는다** — 거기는 구글이다. 공짜로 된다
   중국어 콘텐츠는 어차피 만들어야 하고, 본토는 나중에 인프라가 정해지면 붙인다
```

**「중국어를 한다」와 「중국 본토를 한다」는 다른 일이다.** 콘텐츠는 같아도 인프라가 다르다.

# Ⅳ. ⚠ 다국어보다 먼저 — **한국이 지금 0이다**

2026-08-06 11:2x 실측 (`npm run check:index`)

```
사이트            사이트맵   robots   네이버   빙
백년지도 🇰🇷        3,752장   있음      **0**    0
서울마켓               24장   있음      **0**    0
K Culture Wire         6장   있음      **0**    0
KLifeMap 🇰🇷          73장   있음        1      0
```

**원인** — 구글은 `robots.txt` 의 `Sitemap:` 줄을 보고 **스스로 오지만**,
네이버는 **서치어드바이저에 사이트맵을 제출해야** 수집이 시작된다. 소유확인만으로는 안 온다.

```
할 일   searchadvisor.naver.com → 사이트 선택 → 요청 → **사이트맵 제출**
        → 그다음 「웹페이지 수집」으로 대표 주소를 한 번 밀어 넣는다
```

**다국어를 논하기 전에 한국어부터 0 을 벗어나야 한다.** 순서가 그렇다.
