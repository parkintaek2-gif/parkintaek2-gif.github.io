```

```

```
✅ 본문과 비교를 **같은 자리수로** — 「취업률 62.7%입니다. 전국 평균 62.8%보다 0.1%p 낮습니다」
⛔ 「100명 가운데 63명」은 친절하지만 **바로 옆에 소수점 비교가 오면 못 씁니다**
```
