## 0. 먼저 — **이 사이트는 「키우는 곳」이 아니라 「지키는 곳」이다**

사장님이 이미 두 번 정하셨다.

```
「백년지도는 «지면 유지» — 새로 크게 벌이지 않는다」        (조직전환 지침)
「열심히 하는 것 좋은데 «우선순위 밖»에 힘을 쓰고 있는 것 같다」 (2026-09-17 15:0x, 3번에게)
```

⛔ **그러니 내가 받아서 지면을 더 늘리면 그것이 바로 지시를 어기는 것이다.**
  내 90%는 돈 버는 두 사이트(서울마켓츠·케이라이프맵)에 간다. 백년지도는 **살아 있게만** 한다.

⭐ 판별법 — 백년지도에서 내가 «새 지면»을 만들고 있으면, 그때가 잘못 가고 있는 때다.

## Ⅲ. 날마다 / 손댈 때마다 하는 것

```bash
npm test                                  # 43개 전용 검사가 여기 다 걸려 있다
node scripts/check-100y-broken-links.mjs  # 깨진 링크
node scripts/check-100y-provenance.mjs    # 지면의 수가 자료와 맞나
node scripts/check-100y-live-numbers.mjs  # 라이브 지면의 수가 우리 자료와 맞나
node scripts/check-domains.mjs            # 주소 일곱이 다 사나 (www 포함)
```

⚠ **`www.100yearmap.com` 을 반드시 함께 본다.** 2026-09-17 에 이것이 **404** 였다 —
  DNS 는 우리 서버를 가리키는데 Cloudtype 콘솔에 도메인이 안 붙어 있었다.
  손님이 www 를 붙여 치면 사이트가 없는 것으로 보였다. 지금은 301→200 이다.

### 배포

이 저장소는 `ctype apply` 로 배포한다(klifemap 과 «반대»다).

```bash
ctype apply -f .cloudtype/app.yaml -t @parkintaek2/seoulmarkets:main
```

⚠ 백년지도는 **서울마켓츠와 같은 서버**를 쓴다. 호스트를 보고 `/100y` 접두를 붙인다
  (`server.mjs` SITE_PREFIX). 그래서 **백년지도만 따로 배포할 수 없다** — 셋이 같이 나간다.

### ⚠ 검사를 돌릴 때 — **맨몸으로 돌리면 거짓으로 깨진다**

파일은 `scripts/check-100y-*.mjs` 로 **43개**인데, `npm test` 가 부르는 것은 **26개**이고
그중 여럿은 `--자가시험` · `--selftest` 를 **줘야** 돈다.

```
맨몸으로 그냥 돌린 결과   🔴 11개 깨짐    ← 인자를 안 줘서다. 진짜 고장이 아니다
npm test 가 부르는 대로   ✅ 0개 깨짐
```

⛔ **「검사를 돌렸더니 11개가 깨졌다」로 적지 않는다.** 그건 내가 잘못 돌린 것이다.
✅ 언제나 `scripts/run-all-checks.mjs` 가 적어 둔 «그 줄 그대로» 돌린다.

⛔ 「인계서를 받았다」가 아니라 **「내 손으로 돌아갔다」가 판정이다.**
