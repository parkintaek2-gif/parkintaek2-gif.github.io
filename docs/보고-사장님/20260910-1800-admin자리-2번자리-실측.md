# admin 자리를 2번이 쓰는가 · 원래 2번 자리는 무엇인가 — 실측

5번(총괄) · 2026-09-10 18:09 KST
사장님 물음: 「**admin 2번이 쓰나? 원래 2번 자리는?**」

⛔ 짐작으로 답하지 않았습니다. 일곱 개 설정 방의 로그인 계정 칸을 직접 읽었습니다. **토큰은 읽지도 찍지도 않았습니다** — 계정 이름·자리등급·역할 칸만 봤습니다.

# Ⅰ. 답 셋

## 1-1. admin 을 2번이 씁니다 — 맞습니다

| 설정 방 | 로그인 계정 | 자리등급 | 조직 역할 |
|---|---|---|---|
| `.claude` | **admin@klifedesign.net** | team_standard | **primary_owner** |
| `.claude-u2` | **admin@klifedesign.net** | team_standard | **primary_owner** |

두 방이 **같은 계정**입니다. 즉 2번은 사장님의 **소유자 계정**으로 돌고 있습니다.
조직 이름은 `Klifedesign` 이고, admin 이 그 조직의 primary_owner 입니다.

## 1-2. 원래 2번 자리는 `u2@klifedesign.net` 입니다

우리 문서 두 곳에 그렇게 적혀 있습니다.

```
tools/write-seat-entries.mjs   자리 2 · 계정 u2@klifedesign.net · 설정 .claude-u2
docs/자산-대장.md               u2@klifedesign.net | 2번 | 총괄
```

그리고 그 계정은 **실재합니다** — X(트위터) `@klifedesignx` 의 로그인 이메일입니다(대장 120행).

## 1-3. 🔴 그런데 그 계정으로 클로드에 로그인한 흔적이 «한 자리에도 없습니다»

일곱 개 설정 방을 다 뒤졌습니다 — `u2@klifedesign.net` 흔적 **0건**.

즉 **`u2@` 는 회사 메일 계정으로는 살아 있으나, 클로드 자리로 쓰인 적이 없습니다.**
2번은 처음부터 admin 자리를 빌려 돌았습니다.

# Ⅱ. 그래서 지금 자리는 여섯입니다

| 설정 방 | 계정 | 자리등급 | 한도 등급 | 누가 씁니까 |
|---|---|---|---|---|
| `.claude` / `.claude-u2` | admin@ | team_standard | default_raven | 사장님 · **2번** (같은 계정) |
| `.claude-u1` | u1@ | team_standard | default_raven | 1번 |
| `.claude-u3` | u3@ | team_standard | default_raven | 3번 |
| `.claude-u4` | u4@ | team_standard | default_raven | 4번 |
| `.claude-u5` | u5@ | **team_tier_1** | **default_claude_max_5x** | 5번 (프리미엄) |
| `.claude-u6` | u6@ | team_standard | default_raven | 6번 |

```
스탠다드 다섯 (admin·u1·u3·u4·u6) + 프리미엄 하나 (u5) = 여섯 자리
```

⭐ 오늘 오후 제 보고서에서 이 사실을 「겹친 계정 1」로 며칠째 불이 켜져 있었는데 제가 안 열어 봤다고 적었습니다. 사장님이 물으셔서 열었습니다.
