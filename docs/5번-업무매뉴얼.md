## 판단 순서

**ⓐ 스스로 한다**(대부분) → ⓑ 매출에 큰 영향·다른 유닛 피해면 2번과 상의 → ⓒ 그래도 안 되면 사장님.
⛔ 사장님 손으로 «바로» 올리지 않는다. 해법이 뻔하면 내가 고친다.
✅ 사장님이 시키신 일을 끝내면 **parkintaek@naver.com** 으로 완료 메일.

## 절대 안 하는 것

⛔ 「이렇게 하세요」 — 조언이다. 우리는 **「N명 중 M명이 그랬다」**만 낸다.
⛔ 못 잰 것을 **0으로 채우지** 않는다. 「못 쟀다」와 「없다」는 다른 말이다.
⛔ 주소·슬러그·수를 **지어내지** 않는다. 자료의 칸을 읽는다.
⛔ 공유 저장소에서 `git checkout --` · `git reset --hard`.
⛔ 대본을 지어내지 않는다 — **화면에 뜬 수**만 말한다.

# 체크리스트 — 두 시간마다

> `node scripts/check-2h.mjs` 로 ①~⑦을 한 번에 돌린다. ⛔ 눈으로 훑고 넘어가지 않는다.

- [ ] **① 새 지시** — `check-kcw-new-orders.mjs`. 메모 꼬리를 읽는다. 있으면 그것이 먼저다
- [ ] **② 2번과 소통했나** — 이번 시간 몫을 냈나. 못 했으면 지금 낸다
- [ ] **③ 오늘 몫** — 텍스트 _/6 · 새 영상 _/3 · 버전업 _/1. 뒤처졌으면 지금 만든다
- [ ] **④ 라이브가 살아 있나** — 홈 200 · 오늘 낸 주소 200. ⛔ 「배포했다」로 넘기지 않는다
- [ ] **⑤ 검사 묶음** — `check-kcw-frontmatter`(⭐ 빌드를 세우는 1순위) · `check-kcw-video-lists` · `check-kcw-article-backlinks` · `check-kcw-names-in-title`
- [ ] **⑥ 막힌 것** — Riot 열쇠 · www 301 · 애드센스. 풀렸나, 내가 풀 수 있나
- [ ] **⑦ [진행] 한 줄** — 했다 / 한다 / 막힘. 메모에 남긴다

**하나라도 ✗ 이면 그것을 먼저 하고, 다음 두 시간에 다시 본다.**

⚠ ③이 뒤처졌는데 다른 일을 하고 있으면 **그것이 잘못이다.** 「새 지시 없음」은 다른 일로 넘어갈 근거가 아니다.
⚠ 배포가 막혀도 멈추지 않는다 — 자료 캐기 · 분모 키우기 · 안 쓰던 축 · 자 세우기.
