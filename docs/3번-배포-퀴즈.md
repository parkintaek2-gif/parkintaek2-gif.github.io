# 3번 배포 퀴즈 — **통과해야 그날 일이 시작된다** (사장님 지시 2026-08-09)

> 사장님 — 「점수를 매기려고 만드는 게 아니라 **그날 할 일의 순서를 바꾸려고** 만드는 것이다.
> 통과 못 하면 그날은 새 지면을 만들지 말고 **그 구멍부터 채워라**」

```
node scripts/deploy-quiz-100y.mjs      매일 아침 · 자가시험 8건이 먼저 돈다
```

⚠ 6번 것(`docs/6번-배포-퀴즈.md`)을 먼저 읽고 만들었다. 6번은 콘텐츠 **한 편마다 9문**이다.
   ⭐ 우리는 콘텐츠가 4,967장이라 한 편씩 못 센다. 그래서 **갈래마다** 묻는다.

## ⛔ 먼저 목적을 정했다 — 형식을 다 만들라는 것이 아니다

```
지면 4,967장     목적 **광고수입**   검색에 잡혀야 뜻이 있다. ⛔ 밖으로 안 나가도 된다
og 카드 2,783장  목적 **외부유입**   밖으로 나가야 뜻이 있다
숏영상(유튜브)    목적 **외부유입**   ⭐ 우리는 **문이 있는 유일한 자리**다(@100yearmap)
카드뉴스         목적 **외부유입**   아직 0장
```

### ⚠ 숏영상을 「많이」 만들 것인가 — **내가 판단해 적는다**

사장님: *「목적이 광고수입이면 영상을 많이 만들 필요는 없다. 그건 네가 판단해서 적어라」*

```
⭐ 우리 영상의 목적은 **광고수입이 아니라 외부유입**이다.
   지면은 검색이 데려오지만, 검색이 아직 안 붙었다(구글 문 11장 중 6장 · 네이버 0).
   그동안 **밖에서 사람을 데려올 수 있는 문이 유튜브 하나뿐**이다.
🔴 그래서 「많이」의 기준을 이렇게 정한다 — **하루 1편**.
   ⛔ 「주에 몇 편」으로 두면 문이 있는 날에도 안 쓴다.
   사장님: **「문이 있는데 안 쓰는 것이 문이 없는 것보다 나쁘다」**
```

## 🔴 그리고 이 칸 — **「이 콘텐츠는 몇 살 손님 것인가」**

> 사장님 — *「나는 0살~100살이 다 고객이라 했는데 네 지면은 한 층에만 있다.
> **자를 안 대면 습관이 이긴다. 이 칸이 없으면 내일도 대입을 만든다**」*

```
잰 것 (2026-08-09)   대입·진학 쪽 **4,864장 (99.6%)**  ·  그 밖 **21장 (0.4%)**
                     30~40대 지면 **0장**
```
⛔ 이 칸은 **오늘 만든 것**을 본다. 쌓인 것을 보지 않는다 —
   쌓인 것으로 보면 4,864장에 묻혀 오늘의 습관이 안 보인다.
```
통과   오늘 만든 것 중 **대입(10·20대) 밖이 하나라도** 있다
구멍   오늘 만든 것이 전부 대입이거나 · 오늘 만든 것이 없다
```

## 오늘 관문 — 열세 칸

| 목적 | 묻는 것 | 통과 기준 |
|---|---|---|
| 광고수입 | 지면이 섰나 | 라이브 200 |
| 광고수입 | 사이트맵에 있나 | URL 수 |
| 광고수입 | noindex 가 아닌가 | 파는 지면이 열려 있다 |
| 광고수입 | 🔴 **구글에 잡혔나** | 콘솔에서 센 수 |
| 광고수입 | 🔴 **네이버에 잡혔나** | 등록 · 크롤러가 왔나 |
| 외부유입 | og 카드가 있나 | 장수 |
| 외부유입 | 채널마다 **다른 글**이 있나 | `docs/3번-채널글-본보기.md` |
| 외부유입 | 🔴 스레드·X·인스타에 **나갔나** | 나간 장수 |
| 외부유입 | 🔴 **유튜브에 나갔나** | **오늘 1편** |
| 외부유입 | 카드뉴스가 있나 | 생성기 · 장수 |
| 외부유입 | 숏영상 만드는 자가 있나 | 스크립트 |
| 둘 다 | 9,900원·KLifeMap 으로 가는 길 | 지면에 링크 |
| 🔴 나이 | **오늘 만든 것이 몇 살 것인가** | 대입 밖이 하나라도 |

⛔ **계정이 없는 칸을 「못 함」으로 적지 않는다.**
   ⭐ 「준비됐다 · 계정만 열면 오늘 나간다」로 적고 **자산은 미리 만들어 둔다.**
   그래서 이 자는 **자산이 있나**와 **나갔나**를 갈라 센다 — 자산이 없으면 그건 우리 잘못이다.

### 17:0x — **통과 9 · 내 몫 구멍 2 · 계정 몫 3 · 못 쟀다 0**

2번 — *「「못 쟀다 1」이 이번 시간의 전부입니다. 구멍 4 를 **내 몫 / 계정 몫**으로 가르십시오」*

**① 「못 쟀다」를 닫았다 — 물음을 둘로 갈라서**

```
전   「구글에 잡혔나」                  ⬜ 못 쟀다 (콘솔이 없다)
후   「구글이 **읽었나**」               ✅ 우리 로그 — 6일 **2,097건** · 오늘 **98건**
     「구글이 **몇 장 담았나**」          🖐 계정 몫 (서치어드바이저 안에서만 보인다)
```
⛔ `site:` 로 세지 않았다. `google.com/robots.txt` 가 `Disallow: /search` 다.
⭐ **우리 서버 로그는 우리 것이다.** 「못 쟀다」가 아니라 잰 것과 계정 몫으로 갈렸다.

**② 구멍을 갈랐다 — 남은 것이 진짜 오늘 할 일이다**

```
⛔ 내 몫 2
   유튜브에 오늘 0편        ← ⭐ **문이 있는데 안 썼다.** 제일 먼저
   카드뉴스 생성기 없음      ← 0장
🖐 계정 몫 3
   구글이 몇 장 담았나 · 네이버 등록 · 스레드·X·인스타 업로드
   ⚠ 셋 다 **우리 준비물은 다 돼 있다**(robots·사이트맵·소유확인·채널글 본보기)
```
⚠ 계정 몫을 구멍과 섞으면 **우리가 게을렀는지 안 보인다.** 그래서 갈라 센다.
⛔ 그렇다고 지우지 않는다 — 계정이 열리는 날 이게 그대로 할 일 목록이 된다.

**③ 그 자리에서 닫은 것**

```
✅ 「채널마다 다른 글이 있나」  → docs/3번-채널글-본보기.md 를 만들어 닫았다
```

🔴 6번이 첫날 0% 였던 것처럼, 우리도 **밖으로 나가는 칸이 전부 비어 있다.**
   ⭐ 지면(광고수입)은 서 있고 구글도 읽고 있다. **비어 있는 것은 외부유입뿐**이다.

### 18:0x — **통과 10 · 내 몫 구멍 1 · 계정 몫 3 · 못 쟀다 0**

2번 — *「**내 몫 하나를 닫으십시오**」*

**닫은 것 — 카드뉴스 0장 → `63벌 · 369장`**

```
scripts/make-cardnews-100y.mjs   새로 만들었다 · 자가시험 10건
출력                             public/100y/cardnews/<slug>-N.png · <slug>.근거.json
한 벌 6장                        표지 / 잰것·못잰것 / 퍼짐 / 갈래 / 출처 / 강령·값
```

🔴 **이 자의 전부는 자가시험 ⑨ 다 — 「카드에 적힌 수가 근거에 다 있나」.**
   카드 글에서 수를 **도로 캐내어** 근거 목록과 맞춰 보고, 하나라도 못 대면 **그림을 안 만든다.**
   ⭐ 실제로 첫 판에 걸렸다 — 「2024년」과 「제1유형」의 **1** 이 근거에 없었다.
     손으로 적은 수였다. 자료(`school-career.json` 출처)에서 읽어 오게 고쳤다.
   ⛔ 「대 봤다」고 말로 적지 않는다. **자가 대 본다.**

```
114곳 중 63벌만 만들었다
⛔ 51곳은 건너뛰었다 — 학교는 있는데 **진학률을 잰 곳이 10곳 미만**이다
   (경주시 19곳 중 8곳 · 동대문구 14곳 중 8곳 · 미추홀구 17곳 중 8곳)
⚠ 잰 곳이 열 곳이 안 되면 퍼짐이 퍼짐이 아니다. 억지로 그리지 않는다
```

**⚠ 그리고 이 칸을 고치다 또 같은 데 데었다 — 오늘 여섯 번째**

```
처음 적은 칸    「카드뉴스가 있나」  → 생성기 파일이 있으면 통과
그 순간         369장을 만들어 놓고 자는 **「0장」**이라고 적었다
까닭            내가 쓴 `ROOT` 가 이 파일엔 없다(`뿌리`다). 빈 catch 가 그 오류를 삼켰다
고친 것         ① 칸 이름을 **「몇 장 있나」**로 바꿔 **장을 센다**
               ② catch 가 까닭을 적는다 — ENOENT 가 아니면 「못 셌다: …」로 낸다
```
⛔ **빈 `catch {}` 는 거짓말을 만든다.** 통을 재고 칸을 안 재는 잘못과 같은 뿌리다.
