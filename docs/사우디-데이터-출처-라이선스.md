## 무엇을 확인했나

`docs/세션간-메모.md`「[5번 → 1번·3번·5번·6번] 2026-09-14 19:2x」로 사우디(Tadawul)를
배정받아 첫 산출물(상장사 목록)을 만들려고 했다. `saudiexchange.sa` 의 Main Market Watch
지면(로그인 없이 공개)에서 실제로 272개사(부문 22개, `noOfSymbolsListedMain: 272`와 일치)를
받는 데까지는 **기술적으로 성공**했다 — 다만 이 사이트가 plain curl·fetch 를 403 으로 막아,
CLAUDE.md 「9222 로 붙는다」 절대로 실제 크롬(원격 디버그)으로 열어야 했다.

**저장하기 전에 약관을 봤다** (WebSearch 로 saudiexchange.sa 의 legal_notice 를 찾음):

> 「You must not reproduce or store any part of the website or its content in any other
>  website or include it in any public or private electronic retrieval system or service
>  without the prior written consent of Tadawul.」

**정확히 이 자가 하려던 일을 금지한다.** `docs/UAE-데이터-출처-라이선스.md` 1-1절의 ADX 판정
(「재배포·조직적 수집(scraping)·파생물 제작을 명시적으로 금지한다… 이 경로는 쓸 수 없다」)과
글자까지 닮았다 — 같은 종류의 사이트(거래소 자체 시황 화면)는 같은 종류의 약관을 쓴다.

⛔ robots.txt 는 직접 못 읽었다(그 요청도 403) — 「robots.txt 는 열려 있다」로 짐작하지 않는다.

## 어떻게 풀었나 (UAE 선례) — 사우디도 같은 길을 따라간다

UAE 는 거래소(ADX) 자체 웹사이트가 막히자, **거래소가 아니라 «규제기관»의 오픈데이터**로
갈아탔다 — UAE CMA(Capital Market Authority)·CBUAE(중앙은행)가 `open-data` 정책을 공개
운영하고 있었고, 그중 실제로 종목 단위 데이터가 있는 CBUAE FX/EIBOR 축으로 착수했다.

사우디에서 같은 자리에 있을 만한 곳(**확인 안 됨, 다음 사람이 확정한다**):

```
사우디 CMA           cma.gov.sa — UAE 의 CMA 와 «이름만 같고 다른 기관»이다. 헷갈리지 않는다.
                     오픈데이터 정책·상장사 데이터셋이 있는지 아직 못 봤다.
Saudi Open Data      open.data.gov.sa — SDAIA(사우디데이터인공지능청) 운영.
Platform             2025-06 기준 289개 기관·11,439개 데이터셋(WebSearch로 확인, 사이트 직접 확인 아님).
                     자본시장 관련 데이터셋이 있는지, 종목 단위인지는 아직 못 봤다.
```
