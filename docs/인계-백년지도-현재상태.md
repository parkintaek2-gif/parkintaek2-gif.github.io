## 1. 백년지도가 무엇인가 — 이걸 놓치면 방향이 틀어진다

> 「무한 경쟁으로 아이들을 **줄세우는** 불행한 공교육·사교육 >> **행복한 진짜 교육**,
>  아이들이 하고 싶은 일이 뭔지 찾아주고 그 길을 자세히 안내하는 **진짜 스승**」
> 「교육은 **백년지계**이고 우리는 **백년지도**가 된 거야」 — 사장님, 2026-08-04

**「계획」이 아니라 「지도」다.**

### ⛔ 절대 하지 않는 것

| | 왜 |
|---|---|
| **화면에 「몇 위」를 쓰지 않는다** | 그게 줄세우기다. 데이터에 `전국순위` 가 있지만 **정렬용**이다 |
| 「인기 TOP 10」·「명문」·「상위」 표현 | 같은 이유 |
| 계열 수치를 학과 수치처럼 보이게 하는 것 | 숫자로 거짓말하는 것이 된다 |
| 아이가 혼자 AI 와 대화하는 경로 | **보호자 동석이 구조다** |
| 「우리는 언론사다」 | 인터넷신문 미등록. 자료 요청·소개·고지 어디에도 쓰지 않는다 |

**규모의 사실(개설 학교 몇 곳, 전체 평균과의 차이)은 쓴다. 등수는 안 쓴다.**

### 3단계 구조 (사장님 정의)

```
1단계  적성 파악    KLifeMap(명리학+심리검사) → 하고 싶은 걸 찾아준다
2단계  실제와 전망  그 일의 실상을 적나라하게        ← ⚠ 여기가 제일 비어 있다
3단계  진로 선택    그 직업으로 가려면 어떤 길인가
```

### 비즈니스

> 「우린 디지털저널리즘을 운영하는 회사야. **raw data 를 가공해 유료서비스로 파는 게 전략.**
>  너도 콘텐트를 만들어야 해. 검색 SEO 에 맞춰서.
>  **우리의 유일한 마케팅은 콘텐트를 통한 검색 유입**, 우리가 운영하는 다른 사이트를 통한 유입.
>  이를 바탕으로 B2B, B2C 거래를 일으키는 거야」

⚠ 「무료로 공개된 데이터라 팔 수 없다」는 결론을 낸 적이 있는데 **틀렸다.** 가공이 상품이다.

## 3. 오늘 알아낸 것 중 **다시 알아내면 손해인 것**

### ⭐ 「키 하나가 서비스 하나만 연다」 — KDI·고용24 둘 다

| | |
|---|---|
| **KDI** | `KDI_API_KEY`→`cd=A` 838건 · `KDI_API_KEY_F`→`cd=F` 179건. 나머지는 전부 null |
| **고용24** | `WORK24_KEY_MAJOR`→`213L01` · `_JOB`→`212L01` · `_STRONGSME`→`216L01` |

다른 코드를 부르면 `신청하신 OpenApi 서비스가 존재하지 않습니다` 가 온다.
**카테고리마다 따로 신청해야 한다.**

### ⭐ 고용24 호출 꼴 — 하루를 쓴 끝에

```
https://www.work24.go.kr/cm/openApi/call/wk/callOpenApiSvcInfo{코드}.do
  ?authKey={키}&returnType=XML&target={대상}

212L01  target=JOBCD    ✅ 492건 나온다 (jobClcd·jobClcdNM·jobCd·jobNm)
213L01  target=MAJORCD  → 010 srchType 이 바르지 않다   ← 여기까지 왔다
213L01  target=MAJORDTL → 023 계열ID/학과ID 없음  (막다른 길이었다)
```

⚠ `MAJORDTL` 에 파라미터 이름 **34개**를 시도했지만 전부 023 이었다. **이름 문제가 아니었다.**
`target` 이 틀렸던 것이다. `MAJORCD` 로 바꾸자 오류가 달라졌다.
⚠ 고용24는 **HTTP 200 에 자체 오류코드**를 싣는다. 상태코드만 보면 성공으로 착각한다.

### ⭐ server.mjs 크래시 (고쳤다)

`/%` 같은 잘못된 인코딩 하나에 `decodeURIComponent` 가 URIError 를 던져 **프로세스 전체가 죽었다.**
세 사이트가 한 프로세스라 서울마켓·위키팁도 같이 내려갔다.
→ `resolveFile()` 에 try/catch, 요청 핸들러 전체를 `.catch()` 로 감쌈. **되돌리지 말 것.**

### ⭐ 주소 체계 — 링크에 `/100y` 를 붙이지 않는다

파일은 `dist/100y/…` 에 있지만 방문자 주소는 `100yearmap.com/major/조리과` 다.
`server.mjs` 가 Host 헤더를 보고 붙인다. 링크에 박으면 **같은 페이지가 두 주소로 색인**된다.
→ `src/lib/hundredyear.ts` 의 `href()` 는 일부러 그냥 통과시킨다. 레이아웃에 canonical 을 박아 뒀다.

### ⚠ 원자료 함정 4가지 (수집 스크립트에서 이미 처리함 — 되돌리지 말 것)

| 문제 | 증상 |
|---|---|
| 학과명에 `/` (「S/W디자인과」) | URL 이 쪼개져 **빌드가 죽는다** |
| 개교 전 학교 5곳 | 학교코드가 **빈 문자열** → 주소 충돌 |
| 학교코드 중복 (고양송암고 3년제/2년제) | 한쪽이 조용히 사라진다 |
| `각종학교(고)` 등 누락 | 학과→학교 링크 **406개가 404** 였다 |

### ⚠ NEIS 고교유형에 **마이스터고 항목이 없다**

일반고·특성화고·특목고·자율고 넷뿐. 마이스터고 32곳이 흩어져 있어 KOSIS 마이스터고 수치가
한 곳도 안 붙고 있었다. → 학교 **이름**에 「마이스터」가 있으면 마이스터고로 판정한다.
화면에 「학교 이름으로 판단했다」고 밝힌다.

### ⚠ JSON BOM

PowerShell 로 저장한 JSON 에 BOM 이 붙어 `JSON.parse` 가 죽는다.
→ `t.charCodeAt(0) === 0xfeff ? t.slice(1) : t`
