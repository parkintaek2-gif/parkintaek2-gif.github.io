## 0. 이 명단이 앞의 것과 «무엇이 다른가»

`docs/영업/데이터-고객-명단.md` 는 **유형**을 적어 두고 이렇게 닫아 두었다 —

> ⚠ **구체 회사명은 아직 안 적는다.** 확인 안 하고 적으면 그 명단이 거짓이 된다.

그 조심이 옳았다. 그래서 **짐작하지 않고 캤다.**

```
우물   archive/raw/dart-ownership/ownership.ndjson
       대량보유(5%룰) 공시 — 2,547 종목 · 21,785 건
고른 것 보고자 이름에 라틴 문자가 있고 «기관 꼴»인 것만
       (capital · asset · invest · fund · management · partners · holdings · ltd · llc …)
⛔ 사람 이름은 뺐다 — 우리 손님은 기관이고, 실제 사람의 사적인 것은 공용 저장소에 안 적는다
결과   110곳
```

**이들은 「한국 주식을 5% 넘게 들고 있다」고 스스로 공시한 곳이다.**
추측한 명단이 아니라 **공시 사실**이다. 그리고 이것이 잠재고객의 정의와 정확히 겹친다 —

```
· 한국 주식에 실제로 큰돈이 들어가 있다   → 한국 자료가 «필요하다»
· 한국어를 못 읽는다                      → 영문 자료가 «없다»
· 우리는 그들이 든 종목의 영문 자료를 판다 → 파는 물건이 그들의 보유와 겹친다
```

⭐ **첫 줄을 이렇게 쓸 수 있다** — 「귀사가 공시로 보유를 알린 한국 상장사 N곳이
우리 데이터에 들어 있습니다」. 콜드메일에서 이만한 첫 줄이 없다.
이것이 우리 강령의 「raw data 를 가공하는 회사」가 뜻하는 자리다 —
**우리 데이터로 우리 고객을 찾았다.**

## 3. 접촉 — 5번·6번 역할 분담

```
5번(총괄·리드)   ① 명단 생성·갱신(이 문서)  ② 우선순위  ③ 메일 문안  ④ 실제 발송·회신 관리
6번(서울마켓츠)  ⑤ 각 기관 «공개» 접촉 주소 수집  ⑥ 6종 데이터시트(스키마·샘플·갱신주기)
```

### 6번이 할 것 — 주소 수집 규칙

```
✅ 공개된 곳에서만 얻는다 — 회사 웹사이트의 Contact / Institutional / Client Service 지면
✅ 얻은 주소는 «어느 지면에서 얻었는지»를 함께 적는다. 출처 없는 주소는 명단에 안 올린다
⛔ 주소를 «짐작으로» 짓지 않는다 (info@<회사>.com 따위로 채우지 않는다)
⛔ 개인 담당자의 사적인 주소를 캐지 않는다. 기관의 «공개 창구»만 쓴다
⚠ 못 찾으면 「못 찾았다」로 적는다 — 그것도 결과다
```

### 접촉 원칙 (앞 문서 8절을 그대로 잇는다)

```
· 첫 메일에 파일을 붙이지 않는다. 링크 하나
· 무엇을 파는지 «세 줄 안»에 쓴다
· 답이 없으면 «한 번만» 더. 그 뒤로는 안 보낸다
· 보내는 곳은 admin@klifedesign.net — 답장이 «우리가 읽는» 편지함으로 온다
  (klifemap/auth/mailer.js · 구글 도메인 위임 · 2026-09-12 실측 발송 확인)
```

## 4. 앞 문서에서 «이미 풀린» 전제 둘 — 갱신해 둔다

`docs/영업/타깃과-아웃리치.md` 와 `데이터-고객-명단.md` 는 8월 초에 쓰였다. 그 사이 바뀌었다.

```
그때  「팔 물건이 아직 없다 · /v1/trade/* 는 503」
지금  데이터셋 라이브 · REST API 8개 · RapidAPI 상장 완료 (BASIC $0 ~ MEGA $399)
      ⇒ 순서표의 1·2·3 이 끝났다. «4번(기관 접촉)» 차례다

그때  「대외 발송은 사장님 승인 뒤에 누른다」
지금  사장님이 직접 지시하셨다 — 「잠재 고객리스트를 만들고 접촉해라」
      ⇒ 승인은 났다. 남은 것은 «스팸이 되지 않게» 하는 것뿐이다

그때  「지금 막힌 것 — 적중률 계산에 주가가 없다」
지금  archive/raw/stocks 가 있고 /data/target-price-accuracy 가 라이브다 ⇒ 풀렸다
```

⚠ 다만 목표주가 적중률 데이터셋은 **출처가 네이버 경유**라 나스닥 제출에서 뺐다
  (`docs/데이터-출처-라이선스.md` 269·270줄: robots 위반 · 데이터베이스권 미검토).
  **이 명단에 보내는 메일에도 그 데이터셋은 넣지 않는다.** 한경컨센서스로 다시 지은 뒤에 넣는다.
