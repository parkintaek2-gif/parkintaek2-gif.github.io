# 가격표 초안 — 데이터 API

작성 2026-08-01 · **⚠ 이 문서의 숫자는 가설이다. 경쟁사 실제 가격을 확인하지 않았다.**
근거: `docs/사업전략-데이터제공업.md` §6 (목표 300억)

---

## 0. 가격을 정하기 전에 — 우리가 파는 것이 무엇인가

**우리는 데이터를 팔지 않는다. 데이터를 쓸 수 있게 만든 것을 판다.**

원천은 「이용허락범위 제한 없음」이라 누구나 공짜로 받을 수 있다. 고객이 돈을 내는 이유는
따로 있다.

| 고객이 사는 것 | 안 사면 치러야 할 비용 |
|---|---|
| 영문 정규화 | 한국어 읽는 엔지니어 1명 |
| 발표 시각 수집 | 09:00 KST 에 사람이 대기 |
| 개정 이력 보존 | 잠정치를 놓치면 영영 못 얻는다 |
| 아카이브 | 공공 API 는 소급해 주지 않는다 |
| JSON·안정된 스키마 | XML 파서 유지보수 |

**가격의 상한은 「고객이 직접 하면 드는 비용」이다.** 한국어 가능 데이터 엔지니어 1명의
연간 인건비가 우리 Business 티어의 기준선이 된다.

---

## 1. 티어

| 티어 | 대상 | 월 호출 | 이력 | 가격(가설) |
|---|---|---|---|---|
| **Free** | 평가·학생·분류 조회 | 분류 무제한 / 시계열 1만 | 최근 12개월 | **0원** |
| **Dev** | 개인·소규모 | 10만 | 3년 | **월 5만원** |
| **Business** | 핀테크·리서치 데스크 | 200만 | 전체 | **연 1,200만원** |
| **Institutional** | 자산운용·헤지펀드·벤더 | 무제한 | 전체 + 벌크 | **연 3~10억** |
| **Academic** | 대학·연구기관 | Business 급 | 전체 | **0원** (인용 조건) |

### 왜 이렇게 나눴는가

- **분류(HS·국가) 조회는 영구 무료로 둔다.** 이게 미끼이자 명함이다. 개발자가 코드를 짜다
  우리 엔드포인트를 한 번 부르면, 시계열이 필요해질 때 다시 온다. 여기서 돈을 받으면
  그 흐름이 끊긴다.
- **Free 에 12개월 이력을 준다.** 짧게 주면 평가 자체가 안 된다. 아카이브가 쌓일수록
  「전체 이력」의 가치가 커지므로, 시간이 우리 편이다.
- **Academic 은 무료다.** 논문 인용이 곧 신뢰 자산이고, 그 학생이 3년 뒤 기관에서 산다.
- **Institutional 이 매출의 본체다.** 300억 중 200억이 여기서 나온다(연 5억 × 40곳).

---

## 2. Institutional 가격을 어떻게 부를 것인가

**정가표를 먼저 내밀지 않는다.** 기관 계약은 쓰는 방식에 따라 가치가 10배 차이 난다.
아래 축으로 견적한다.

| 축 | 낮음 | 높음 |
|---|---|---|
| 이용 범위 | 리서치 내부 참고 | **투자 판단 입력값** |
| 재배포 | 내부만 | 고객 리포트에 재수록 |
| 전달 | API 조회 | 벌크·Snowflake·S3 적재 |
| SLA | 없음 | 발표 시각 수집 보장 + 지연 통지 |
| 이력 | 최근 3년 | 전체 아카이브 |
| 배타성 | 없음 | 업종·지역 독점 |

**연 3억이 하한, 10억이 상한**으로 잡고 시작한다. 첫 3~5곳은 **레퍼런스 확보가 우선**이므로
하한 근처로 간다. 대신 계약서에 **사명 공개 동의**를 넣는다 — 첫 고객의 이름이 다음 20곳을
데려온다.

---

## 3. 하지 않을 것

- **실시간 시세 판매.** 거래 목적 데이터는 정확성 배상 책임이 따라온다. 우리는
  분석·리서치 목적으로 간다. 그래서 SLA 도 「발표 시각 수집」까지이고 「데이터 정확성」이 아니다
- **무제한 재배포 허용.** 고객이 우리 데이터를 자기 상품으로 되파는 것은 별도 라이선스다
- **가격 후려치기.** 데이터 상품은 한 번 깎으면 그 가격이 시장가가 된다.
  깎아 줄 자리는 가격이 아니라 **범위**다 — 이력을 줄이거나 호출을 줄인다

## 4. 결제·계약 실무 (확인 필요)

- [ ] 해외 법인과의 계약 통화·세금 (부가세 영세율 적용 여부)
- [ ] AWS Data Exchange 유료 판매 — **비미국 판매자는 W-8 + VAT/GST + 미국 은행계좌**.
      대체 수단이 있는지 확인 전까지는 RapidAPI 로 간다
- [ ] 데이터 정확성 면책 조항 문안 — B2B 는 배상책임이 따라온다
- [ ] 표준 계약서 1종 (Business) + 협상용 1종 (Institutional)

## 5. 첫 12개월 시나리오 (가설)

| 시점 | 목표 | 매출(가설) |
|---|---|---|
| 0~3개월 | 아카이브 축적. 분류 API 무료 공개. RapidAPI 등재 | 0원 |
| 3~6개월 | Dev 티어 유료화. 개발자 100명 확보 | 월 100만원 |
| 6~9개월 | Business 첫 계약 3곳. **1년치 아카이브가 무기가 된다** | 연 3,600만원 |
| 9~12개월 | Institutional 첫 계약 1~2곳 (레퍼런스 가격) | 연 3~6억 |

**1년차에 300억은 나오지 않는다.** 1년차의 목표는 매출이 아니라
**아카이브 12개월치와 레퍼런스 고객 1곳**이다. 그 둘이 있으면 2년차부터 자릿수가 바뀐다.

> 공공 API 는 과거를 소급해 주지 않는다. **오늘 안 받은 데이터는 1년 뒤에 돈을 줘도 못 산다.**
> 지금 이 문서에서 제일 중요한 문장이다.
