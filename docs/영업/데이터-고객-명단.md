작성 2026-08-02 KST · **담당: 나.** 사장님은 영업을 하지 않으신다

> 사장님(2026-08-02): 「자산운용사에 제안은 해야지. 요즘은 **핀테크, 인터넷은행,

## 0. 이 명단의 핵심 — **국내에 뿌리는 것이 해외 영업이다**

```
매경이 「SeoulMarkets 집계」라고 쓴다
  → 그게 우리 레퍼런스가 된다
  → 해외 벤더·운용사가 우리를 검증할 근거가 생긴다
  → 광고비 0원
```

**국내 매출을 0으로 두는 대신 해외의 문이 열린다.**
우리 이름을 넣는 것은 가격이 아니라 **이용 조건**이다. 이름을 빼려면 제값을 받는다.
훈장을 주는 것과 같은 논리다 — **상대가 자랑할수록 우리 지표가 표준이 된다.**

## 1. 축이 둘이다 — **국내는 뿌리고, 해외에 판다**

> 사장님(2026-08-02 KST): 「**필요하면 무료로 뿌려**」
> 「**우리가 해외에 팔 수 없는 거를 무료로 줄 수 있다**」
> 「**우리는 주로 해외 업체랑 거래해야 한다**」

이 세 줄이 명단의 구조를 결정한다. 처음에 나는 국내 매출을 잡고 있었는데 **축이 틀렸다.**

```
국내 경제신문   뿌린다   →  레퍼런스 · 브랜드      ← 무료는 여기까지만
국내 그 밖      판다     →  핀테크·은행·운용사는 국내라도 유료
해외            판다     →  매출의 본체
```

**무료는 국내 경제신문에만이다.** 신문은 우리 이름을 실어 노출을 만들어 주지만,
핀테크·은행·운용사는 **우리 데이터로 자기 사업을 한다.** 같은 국내라도 자리가 다르다.

### 왜 국내에서는 못 파는가 — 이길 이유가 없다

| | 국내 | **해외** |
|---|---|---|
| 경쟁 | 에프앤가이드·코스콤·인포맥스가 이미 있다 | **한국 데이터를 영문으로 정리한 곳이 없다** |
| 언어 | 한국어면 충분 — 우리 강점이 안 통한다 | **영문이 아니면 못 쓴다** |
| 단가 | 낮다 | **높다** |
| 우리 위치 | 후발 | **유일** |

**국내에서 우리는 후발이고 해외에서는 유일하다.** 같은 데이터인데 자리가 다르다.
`docs/사업전략-데이터제공업.md` 가 처음부터 영문 매체로 간 이유가 이것이다.

### 그래서 무료의 기준이 생긴다

사장님 말씀대로다 — **해외에 팔 수 없는 것을 국내에 무료로 준다.**

| | 국내 **경제신문** 무료 | 그 밖 (국내 상업·해외 전부) |
|---|---|---|
| 월 1회 집계본 (한국어) | **○** | 안 판다 |
| 상위 애널리스트 발표 | **○** | 안 판다 |
| **영문 정규화 데이터** | ✗ | **○ 이게 상품이다** |
| **원자료 API · 시계열** | ✗ | **○** |
| **지수 라이선스** | 국내 ETF 는 별개 | **○** |
| 선공개권 | 유료(국내도) | **○** |

**한국어 집계본은 해외에서 값이 0이다.** 그러니 국내에 무료로 줘도 잃는 것이 없다.
**영문 정규화·원자료·지수는 해외에서만 값이 나온다.** 그건 안 뿌린다.

### 무료라도 조건은 있다

**「SeoulMarkets 집계」 출처 표기.** 이건 가격이 아니라 이용 조건이다.
표기 없이 쓰려면 유료다.

가격이 아니라 **「결재가 필요한가」가 확산 속도를 정한다.**

```
월 40만원   기자가 데스크 결재를 올려야 한다   →  안 쓴다
무료        기자가 그날 쓴다                   →  퍼진다
```

한 번 무료로 뿌리면 나중에 못 판다. 그래서 위 표로 선을 먼저 그었다.

| Free | 평가·학생 | 0원 |

## 5-2. ⭐ 해외 — **여기가 매출의 본체다**

> 사장님: 「**우리는 주로 해외 업체랑 거래해야 한다**」

앞의 국내 명단(2~5절)은 **레퍼런스를 만드는 자리**다. 돈은 여기서 나온다.

### 왜 해외가 사는가 — 대체재가 없다

```
한국 기관투자자   한국어 데이터가 이미 있다.  우리는 후발
해외 기관투자자   한국 데이터를 영문으로 정리한 곳이 없다.  우리가 유일
```

한국 증시에 투자하는 해외 자금은 크고, 그들은 **한국어를 못 읽는다.**
지금은 브로커 리포트나 벤더 요약에 의존하는데, **12년치 목표주가 적중률 같은 것은 아무도 안 준다.**

### ① 데이터 마켓플레이스 — **가장 먼저. 영업이 필요 없다**

| | 왜 |
|---|---|
| **AWS Data Exchange** | 셀프 등재. 구독·과금·전달을 아마존이 처리한다 |
| **Snowflake Marketplace** | 기관 데이터팀이 여기서 찾는다 |
| Databricks Marketplace | |
| **Nasdaq Data Link** | 금융 데이터 전용. 심사가 있으나 노출이 크다 |

**1인 회사에 이보다 맞는 채널이 없다.** 사람도 협상도 계약서도 없다.
**등재만 하면 판매 경로가 열린다. 그래서 1순위다.**

### ② 글로벌 데이터 벤더 — 재판매 (매출계획의 「재판매」가 이것이다)

| | 접근 |
|---|---|
| **LSEG (Refinitiv)** | 파트너 프로그램이 있다 |
| **FactSet** | 콘텐츠 파트너를 상시 모집한다 |
| Bloomberg | 문턱이 가장 높다. 레퍼런스가 쌓인 뒤 |
| S&P Global · MSCI | 지수 사업과 겹친다 — 경쟁자이자 고객 |
| **Quandl / Nasdaq Data Link** | 대안데이터 진입로 |

**계약은 1인이 해도 판매는 그쪽이 한다.** 마진은 절반 이하지만 선투자가 0원이다.

### ③ 해외 운용사·헤지펀드 — 한국 익스포저가 있는 곳

| | 왜 |
|---|---|
| 아시아 전문 헤지펀드 (홍콩·싱가포르) | **한국 비중이 크고 현지 정보가 부족하다** |
| 신흥국·아시아 ETF 운용사 | 지수 라이선싱 대상 |
| 퀀트 펀드 | 대안데이터를 상시 사들인다 |
| 일본 운용사 | **우리가 법인을 세울 나라다.** 접점이 자연히 생긴다 |

⚠ **구체 회사명은 아직 안 적는다.** 확인 안 하고 적으면 그 명단이 거짓이 된다.
마켓플레이스 등재 뒤 **누가 조회하고 누가 문의해 오는지가 실제 명단**이 된다.
**추측한 명단보다 그게 정확하다.**

### ④ 영문 미디어 — 국내와 같은 논리, 다만 파는 쪽

Bloomberg · Reuters · Nikkei Asia · SCMP · FT 등은 **국내 경제지와 달리 유료다.**
한국어 집계본은 해외에서 값이 0이지만 **영문 정규화본은 값이 있다.**

### 해외에 팔 때 준비할 것

| | |
|---|---|
| **영문 정규화** | 종목명·업종·기관명. **이게 상품의 실체다** |

| 시차 | 문의 대응. **AI 가 하므로 문제가 아니다** |

| 순서 | 대상 | 왜 이 순서인가 | 필요한 것 |

| 1 | **해외 마켓플레이스 셀프 등재** | 사람도 협상도 없다. **해외 매출의 입구** | 영문 정규화 |
| 2 | **국내 경제신문 (무료)** | 결재가 아예 없다. **그 기사가 곧 레퍼런스** | 적중률 집계 |
| 3 | 국내 핀테크·증권앱 | 기능 하나로 붙는다 | 위 둘 |
| 4 | **해외 벤더 재판매** (LSEG·FactSet) | **판매를 넘긴다.** 매출계획의 「재판매」 | 실사용 사례 |
| 5 | 해외 운용사·헤지펀드 | 데이터가 곧 수익률 | 벤더 레퍼런스 |
| 6 | ETF 운용사 (지수) | 가장 크고 가장 느리다 | 백테스트 + 산출 실적 |

**1번과 2번이 나머지를 연다.** 마켓플레이스는 오늘 시작할 수 있고,
국내 신문에 「SeoulMarkets 집계」가 반복되면 해외 벤더가 우리를 검증할 근거가 생긴다.
**국내 매출을 0으로 두는 대신 해외의 문이 열린다.**

## 7. 지금 막힌 것 — 적중률 계산에 **주가가 없다**

명단은 다 만들었는데 **팔 물건이 아직 안 만들어졌다.**

```
있는 것   목표주가 55,709건 · 2007~2026 · 종목 2,782개 · 기관 44곳
없는 것   그 종목들의 실제 주가 시계열
```

**목표주가가 맞았는지를 계산하려면 주가가 필요하다.**
공공데이터포털 시세(T+1, 재배포 가능)로 되는지 확인 중이다. **이게 1순위다.**

## 8. 접촉 원칙 — 이걸 어기면 스팸이다

기존 `docs/영업/타깃과-아웃리치.md` 의 원칙을 그대로 따른다. 요약하면 —

- **무엇을 파는지 세 줄 안에** 쓴다
- 답이 없으면 **한 번만** 더 보낸다. 그 뒤로는 안 보낸다
- **대외 발송은 사장님 승인 뒤에 누른다** — 문안은 내가 쓴다
