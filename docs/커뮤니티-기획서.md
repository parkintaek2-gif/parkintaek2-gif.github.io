## 0. 한 줄로

**방은 다 지었고 라이브다. 그런데 오늘 오후까지 «현관»이 없어서 아무도 못 들어왔다.**
그것을 오늘 고쳤다 — 첫 화면에서 두 번 안에 못 닿던 지면 **23장 → 0장**.


## 2. 🔴 왜 방문자가 0명이었나 — 재서 알았다

```
kculturewire.com/community   이틀 동안 읽은 사람   0명
seoulmarkets.com/community   같은 이틀           18명   ← 그쪽은 첫 화면에 문이 있었다
```

`check-two-clicks` 가 **23장**을 「첫 화면에서 두 번 안에 못 닿음」으로 셌다
(커뮤니티 1 · 띠 방 12 · 일간 방 10). 방은 있었고 **현관이 없었다.**
오늘 첫 화면에 문을 내서 **741/741 장(100%)** 이 두 번 안에 닿는다.

### ⚠ 그리고 더 큰 사실 — 우리 사이트 전체에 «밖에서 오는 손님»이 거의 없다

이틀치 유입 경로(전 유닛 합계)다.

```
(직접)      7,618   ← 대부분 우리 자신의 점검·수집이다. 손님으로 셀 수 없다
(내부)        212
google.com     27
bing.com        2 · chatgpt.com 2 · baidu.com 2 · yahoo.com 1
────────────────
검색에서 온 것  **34명 / 이틀**
```

⛔ 그래서 「유닛당 하루 1,000명」을 자동 집계 수(5번 2,030명)로 말하지 않는다.
**정직한 수는 검색에서 온 34명(이틀)** 이고, 커뮤니티의 다음 단계는
「기능을 더 붙이는 것」이 아니라 **사람이 도착하게 만드는 것**이다.

## 3. 사이트맵

### ㉮ 지금 (라이브 · 23장 + 표 2장)

```
/                                   첫 화면 ← 오늘 여기에 현관을 냈다
├─ /community                       커뮤니티 첫 화면 · 카드 12장
│   └─ /room/{rooster, dog, rat, pig, ox, tiger,
│             rabbit, dragon, snake, horse, goat, monkey}
│                                   띠 방 열두 장 · 이름 1,047개
│                                   (방마다: 이름·생년·읽힘 + 새 축으로 가는 문)
├─ /day-pillar                      일간·일지 셈 표 (9,249명 · 카이제곱)
│   └─ /stem/{gap, eul, byeong, jeong, mu, gi, gyeong, sin, im, gye}
│                                   일간 방 열 장 · 이름 7,003개 표기
├─ /netflix-top10-data              넷플릭스 두 파일 설명서 (오늘 신설 · 잰 검색수요로 냈습니다)
├─ /most-read                       이번 달 가장 많이 읽힌 스타 100명
├─ /born-on                         생일 366장으로 가는 첫 장
│   └─ /born-on/{월-일}             같은 생일의 스타 (366장 · 오늘 신설)
├─ /star-signs                      띠 × 이름 (셈 + 명단)
└─ /zodiac                          띠 분포가 우연인지 (카이제곱 7.77 / 문턱 19.68)

⛔ 없는 것: 로그인 · 글쓰기 · 댓글 · 피드 · 순위 · 알림 · 중재
```

### ㉯ 계획 (단계마다 «넘어가는 조건»을 둔다)

```
2단계 — 읽을 것을 늘린다 (서버 없이 · 자료만으로)
  /branch/{열두 일지}          같은 자료로 열두 방이 더 나온다
  /element/{다섯 오행}         다섯 방
  ✅ /born-on/{월-일}          냈습니다(366장). 다만 표본에서 18/18 이 「구글이 모른다」입니다 —
                              어제 낸 것이라 색인 전입니다. 4주 뒤 다시 잽니다
  넘어가는 조건: 방 하나라도 **검색에서 하루 10명**이 들어오는 것을 실측할 때

3단계 — 참여의 «흔적»을 만든다 (여전히 글쓰기 없음)
  방마다 받아보기(이미 있는 /subscribe 재사용) · 방마다 새 기사 알림
  넘어가는 조건: 받아보기 신청이 **한 방에서 20건**을 넘을 때

4단계 — 글쓰기 (서버·로그인·중재)
  ⛔ 이 단계는 사람 손과 돈이 든다. 스팸·개인정보·중재가 같이 온다
  넘어가는 조건: 3단계 조건을 넘고, **2번과 상의**해서 서버 비용과 중재 책임을 정한 뒤
```

⚠ 단계를 건너뛰지 않는 까닭 — **사람이 없는 방에 글쓰기를 붙이면 빈 방이 더 크게 비어 보인다.**
2번 지시(8/21)도 「읽는 자리까지」였고, 그 판단이 지금 수로도 맞다(도착한 사람 0명).

## 5. 🔴 저녁에 다시 재서 나온 것 — 「못 쟀다」 두 칸이 답이 됐습니다

### ㉠ 손님이 우리 안에서 걷는가 — **처음으로 수가 나왔습니다**

GA4 는 프로젝트에서 API 가 꺼져 있어 못 썼고, **우리 서버가 이미 재고 있던 것**을 찾아
같은 날 안에 답을 냈습니다(경로별·유입도메인별 하루치가 R2 에 쌓입니다. 쿠키·IP 는 안 남깁니다).

```
8/21 하루    지면 열림 3,991 · 우리 안에서 걸어온 것 81 (2.0%)
이레(8/15~21) 열림 5,026 · 안쪽 296 (5.9%) · **걸어서 닿는 지면 0장**
```
🔴 제가 이 문서 앞에서 「741/741 장(100%)이 두 번 안에 닿는다」를 성과로 적었습니다.
**닿는 것과 걷는 것은 다른 말이었습니다.** 100%는 문이 있다는 말이고, 2.0%는 눌린다는 말입니다.
⚠ 이 이레 수는 봇패턴 고침(8/22 02:08) 전이라 **부풀어 있습니다.** 상한으로만 읽어야 합니다.

### ㉡ 왜 아무도 안 걷나 — **들어오는 링크가 하나뿐이었습니다**

구글에 직접 물었습니다(URL Inspection API). 표본 60장 —
```
들어갔다 26 (43.3%) · 구글이 모른다 24 (40.0%) · 발견만 하고 안 넣음 10 (16.7%)
```
「발견만」은 안쪽 링크가 얇을 때 납니다. 세어 보니 작품 지면 528장의 **들어오는 링크 중간값이 1**
이었습니다. 고아는 0장인데도 그렇습니다 — **고아가 아닌 것과 잘 이어진 것은 다른 말입니다.**

그래서 두 곳을 고쳤습니다.
```
나라 지면 → 작품 지면 링크          93장 × 20편 (전에는 이름을 글자로만 실었습니다)
작품 지면 → 작품 지면 (배우·제작사)   528장 중 468장이 이 축으로 이어집니다
결과: 링크 1개뿐인 지면 519장 → 97장 · 6개 이상 0장 → 226장 · 중간값 1 → 4
```
⭐ 이 하나가 **색인**(구글이 걸어갈 길)과 **머묾**(손님이 이름에서 이름으로 걷기)을 같이 풉니다.
⛔ 지어내지 않았습니다 — 같은 배우가 나온 작품·같은 회사가 크레딧에 있는 작품만 잇고,
   **까닭을 옆에 적습니다**(「Jung Kyung-ho, tvN」). 「비슷한 작품」이라고는 말하지 않습니다.

### ㉢ 그리고 커뮤니티보다 먼저 고칠 것이 나왔습니다

같은 4주를 갈라 보니 **우리 병이 순위가 아니라 클릭**이었습니다.
```
노출 2,322 · 클릭 15 (0.65%)
1~10위에 지면 210장 · 노출 1,069 · 클릭 8
그중 83장은 1페이지에 있으면서 클릭 0 (노출 824)
```
⇒ 커뮤니티에 기능을 붙이는 것보다 **이미 받는 노출을 클릭으로 바꾸는 것**이 먼저입니다.
자세한 것은 함께 올린 «5번_방문자매출전략_0822.md» 에 있습니다.
