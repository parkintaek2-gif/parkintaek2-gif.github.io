# 제휴 폼 · 1:1 문의 게시판 — **3번이 만드는 한 벌**

2번 지시(2026-08-13 · 사장님). ⛔ **전부 8/16 이후다. 오늘은 적어만 둔다.**
적는 이 **3번(백년지도)**. 이 저장소에 세 사이트가 있으니 **한 번 만들면 5·6번은 걸기만 한다.**

> 사장님: 「제휴 form, 1:1 문의 게시판은 **구축 후 모든 사이트에 같이 적용**하도록」

---

## 0. 누가 무엇을 — ⛔ 내가 넘지 않을 선

```
1번   ⭐ **설계를 낸다** — 받을 칸 · 화면 꼴 · 답글 자리 · 알림이 어디로 가나. klifemap 에 본보기를 먼저 세운다
3번   그 설계대로 이 저장소에 **한 벌** 만든다   ← 내 몫
5·6번 ⛔ 만들지 않는다. 3번 것을 자기 지면에 건다
2번   받는 주소 · 값 기준 · 답하는 규칙
```
🔴 **1번 설계가 먼저다.** 내가 먼저 지어 놓고 「이대로 씁시다」 하지 않는다 —
   그러면 넷이 다르게 생기는 것을 막자는 지시가 뒤집힌다.
🖐 **1번에게 청할 것** — 설계가 나오면 알려 달라. 나는 그때 시작한다.

## 1. 문이 **둘**이다 — 섞지 않는다

```
B2B 제휴   ▸ 전용 «폼»          → 우리가 판단해 값·기간을 정해 **메일로 답한다**
B2C 문의   ▸ «1:1 문의 게시판»   → 우리가 판단해 **답글**을 단다
```
🔴 **사장님을 거치지 않는다. 우리가 판단해서 답한다.** 그것이 이 지시의 핵심이다.

---

## 2. B2B 폼 — 받을 칸 (2번이 잡았다 · ⛔ 늘리지 않는다)

```
회사 이름 · 담당자 이름 · 회신 메일(필수) · 연락처
무엇을 쓰시려나 — 우리 자료 중 어느 것인가
어디에 쓰시나  — 사내 · 상품에 · 연구 · 재판매(⛔ 재판매는 값이 다르다)
언제까지 필요하신가 · 얼마나 자주(한 번 · 매달 · 매일)
```
⛔ **값을 폼에 적지 않는다.** 우리가 보고 정한다.
⛔ 받는 곳은 **대표 메일 하나**. 유닛마다 따로 만들지 않는다.
⚠ 길면 아무도 안 쓴다. 칸을 늘리자는 말이 나오면 2번에게 올린다.

```
⚠ 우리 쪽에서 미리 짚어 둘 것 — **백년지도 손님의 큰 몫이 중·고등학생**이다.

  **1:1 문의가 로그인을 요구하면 그 아이들은 물어볼 길이 없다.**
  🖐 1번·2번에게 물어야 한다 — 「로그인 없이 묻는 길」을 둘 것인가.
  ⛔ 내가 정하지 않는다. 8/16 에 올린다.

```

  ⚠ 지면마다 손으로 적으면 한쪽만 고쳐져 조용히 갈라진다. 오늘까지 그 흠을 세 번 봤다.

## 5. 답할 때 지킬 것 — 「우리가 판단한다」는 마음대로 한다는 뜻이 아니다

```
① 근거 없는 것은 답하지 않는다 — 모르면 「모릅니다」라고 쓴다
② 값을 깎아 주겠다고 먼저 말하지 않는다. 기준 값을 대고, 다른 조건이면 왜 다른지 적는다
③ 재판매 · 독점 · 우리 이름을 쓰는 것 → ⛔ **우리가 못 정한다. 2번에게 올린다**
④ 답장 보낸 것을 대장에 남긴다 — 누가 · 언제 · 무엇을 물었고 · 얼마로 답했나
```
⚠ ④의 대장을 **어디에 둘지**가 아직 안 정해졌다. 2번에게 물을 것.
