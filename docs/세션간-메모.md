404 와 인증서 오류 → **그 페이지를 색인에서 버립니다.** 색인이 안 되는 게 정상입니다.

**애드센스도 같은 이유로 막힙니다.** 색인되지 않은 사이트는 심사를 통과하지 못합니다.

### 해결은 DNS 한 번입니다

호스팅은 Cloudtype 으로 확정됐습니다(사장님 지시 「나중에 옮길 생각 하지 마」).
그러니 **GitHub Pages A 레코드 2개를 지우고 Cloudtype 으로 CNAME** 하면 끝납니다.

    이름   @ (또는 seoulmarkets.com)
    값     seoulmarkets-com-web-ms8nmh0n689e433f.sel3.cloudtype.app
    등록처 Spaceship (klifemap.ai 와 같은 곳)

**GitHub Pages 커스텀 도메인 설정은 이제 하지 마십시오.** 이 파일 위쪽에 그 요청이
적혀 있는데 **무효입니다.** Pages 로 가면 Cloudtype 의 server.mjs(클린 URL·admin·
파트너 피드)가 통째로 죽습니다.

DNS 를 바꾸실 수 있는 세션이 처리해 주시면 됩니다. 저는 콘솔 접근이 없습니다.

## ★ [통보] 메모리 배분 — 여유가 0 이 됩니다 (2026-08-01)

**사장님 판단입니다: 「0.25씩 나눠서 써 — 서울마켓/위키팁」.**
신규 한류매체(wiki-tip.com)가 남은 0.25GB 를 씁니다.

    klifemap-app      0.5GB   ← 건드리지 않았습니다. 그대로입니다
    seoulmarkets/web  0.25GB
    wiki-tip (신규)   0.25GB
    여유              0GB

**여유 0 에서는 롤링 업데이트가 못 뜹니다.** 새 컨테이너를 띄우고 옛 것을 내리는
방식이라 순간적으로 두 배가 필요합니다. 실제로 오늘 09:35 경 klifemap-app 이
`ready=1 / unavailable=1` 로 멈춰 있었습니다(그때는 여유 0.25GB 로 스스로 풀렸고,
지금 running·klifemap.ai 200 입니다).

배포는 CLAUDE.md 대로 **내리고 올리십시오.** 두 배가 필요 없습니다.

    ctype remove <이름> -t @parkintaek2/klifemap:main
    ctype apply -f <파일> -t @parkintaek2/klifemap:main

**`-t` 를 절대 빼지 마십시오.** 7/31 에 그것 때문에 klifemap 에 `web` 이 잘못 생겼습니다.

여유가 필요하시면 klifemap-app 0.5GB 의 실사용을 재 보십시오. 저는 못 잽니다
(`ctype` 에 사용량 조회가 없습니다). 0.25 로 내려도 되는 값이면 여유가 생깁니다.
**제가 임의로 내리지 않았습니다.**

## ⚠ ctype 함정 두 개 — 제가 밟았습니다 (2026-08-01)

1. **`ctype apply -p`(prepare) 를 검증 수단으로 믿지 마십시오.**
   메모리 0.125 를 넣고 `-p` 를 돌렸더니 오류 없이 "deployed" 를 출력했습니다.
   실제 `apply` 에서야 `memory is only allowed in increments of 0.25` 가 났습니다.
   **-p 는 검증이 아닙니다.**

2. **`ctype ls -o json` 은 환경변수를 통째로 뱉습니다.**
   klifemap 의 R2 키·API 키가 그대로 출력됩니다. 자원만 볼 때는
   `$j[0].resources` 처럼 필요한 필드만 뽑으십시오.
   (제가 이 세션에서 두 번 노출시켰습니다. 사장님께 키 교체를 권해 두었습니다.)
