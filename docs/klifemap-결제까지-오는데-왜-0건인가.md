## Ⅳ. 🔴 그러면 무엇이 문제인가 — 잰 것만 적습니다

### 4-1. 손님이 많이 읽는 지면에 «살 길»이 없습니다

지면을 `readyState === 'complete'` 까지 기다리고 **2초 더** 준 뒤에 셌습니다.

| 지면 | 28일 열림 | 값이 보이나 | 결제로 가는 링크 |
|---|---:|---|---:|
| `/saju.html` | **107** | 🔴 하나도 없다 | **0개** |
| `/ai-report.html` | 9 | ✅ 39,000·29,000·9,900원 | **0개** |
| `/pricing.html` | 36 | ✅ | 10개 |

⭐ **가장 많이 읽히는 서비스 지면(`/saju.html`, 107회)에서 값도 안 보이고 살 수도 없습니다.**
사려면 손님이 스스로 「요금안내」를 찾아 들어가야 하고, 거기는 36회만 열립니다.

⬜ **못 쟀습니다** — 손님이 사주를 «실제로 돌려 본 뒤»에 살 길이 뜨는지는 재지 않았습니다.
  (`/upsell-price.js` 가 붙어 있으니 결과 뒤에 뜰 수 있습니다.) 이것은 1번이 확인해 주십시오.
  ⛔ 「지면에 링크가 0개다」까지가 제가 잰 것이고, 「살 수 없다」로 넓혀 적지 않습니다.

### 4-2. `/checkout.html` 을 맨주소로 열면 막힙니다

```
「구매하실 상품 정보를 확인하지 못했습니다. 각 서비스 페이지에서 다시 시도해주세요.」
값 0개 · 결제 단추 없음 · 유일한 링크가 login.html?next=checkout.html
```

⚠ **이것이 GA4 의 「결제 76회」 안에 섞여 있습니다.** 막힌 화면도 지면 제목이
「결제 — KLifeMap.AI」로 같기 때문에 **지금 자로는 몇 회가 막힌 화면인지 못 가릅니다.**

⭐ 가릴 방법 — 막힌 화면의 `<title>` 을 다르게 하거나(예: 「결제 — 상품 정보 없음」)
  GA4 이벤트를 하나 붙이면 다음 달부터 갈라 셉니다. **1번 몫으로 넘깁니다.**

## Ⅴ. 🔴 제가 이 문서를 쓰다가 «두 번» 오판했습니다 — 그것도 적습니다

```

          (readyState 가 아직 loading 이었다)

첫 판정   「/pricing.html 에 결제 단추가 없다 — 누를 것이 「환불 신청」뿐이다」
```

`readyState === 'complete'` + 2초를 기다린 뒤에 다시 잰 것만 실었습니다.
