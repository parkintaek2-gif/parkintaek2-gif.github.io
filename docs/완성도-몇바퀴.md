# 완성도 100% 까지 몇 바퀴인가 — 실측으로 계산한다

사장님 지시(2026-08-07): 「데이터 가공 → 콘텐트 → 유료화 상품 설계 및 관련 사이트·고객에게 줄 결과물
→ 사이트 검수 → …loop 를 **몇 번이면 되는지 계산**해서 알려줘. **각 사이트마다**」

계산 2026-08-07 09:5x · 2번(조율). 아래 숫자는 **오늘 실제로 잰 것**이다. 어림한 것은 어림했다고 적는다.

---

## 0. 「100%」를 무엇으로 보나 — 먼저 못박는다

```
① 채움    지면에 들어갈 자리가 다 차 있다 (「못 쟀다」로 적을 것은 그렇게 적혀 있다)
② 상품    유료 상품과 고객에게 줄 결과물이 있다
③ 수렴    **검수 한 바퀴를 돌아 새 결함이 0 건**이다
```

🔴 **③이 핵심이다.** 콘텐트를 계속 더하면 이 loop 는 **영원히 안 끝난다** —
새 지면이 새 결함을 낳기 때문이다. 「더 이상 손대지 않아도 될 시기」는
**콘텐트를 멈춘 뒤 검수만 돌린 바퀴**에서 온다.

## 1. 검수가 한 바퀴에 몇 % 를 잡나 — 우리 실측

```
5번 되짚기 1회전   지면 20 + 기사 9 = 29장에서 어긋남 9건
                  그중 6건은 첫 훑기에서, 3건은 **「결함에 이름을 붙여 다시 훑을 때」** 나왔다
                  → 단순 훑기 포착률 6/9 ≈ 3분의 2
6번 되짚기 1회전   기사 7편에서 1건
```

⚠ 자료가 각 한 번씩뿐이다. **포착률 3분의 2**를 그대로 쓰되, 틀릴 수 있음을 밝혀 둔다.
그 값이면 남은 결함은 한 바퀴마다 3분의 1로 준다 —

```
9건 → 3건 → 1건 → 0.3건      **세 바퀴면 한 건도 안 남을 공산이 크다**
```

## 2. 백년지도 (3번) — **일곱 바퀴**

### 지금 채움 (오늘 실측)

```
고교 2,525곳   진학·취업 숫자 **0%**  (학과수만 1,172곳 = 46%)
학과 925개     취업률 **0%**  ← 3번이 837개 학과 취업률을 확보했는데 **지면에 안 붙어 있다**
대학 377곳     취업률·중도탈락 329곳 = **87%**
나이 5장       스물다섯·서른둘·마흔·쉰다섯·예순여덟
유료 상품      **없음**
```

🔴 **가장 큰 것은 「없는 데이터」가 아니라 「받아 놓고 안 붙인 데이터」다.**
학과 837개 취업률이 그렇다. 이건 수집이 아니라 **연결 한 바퀴**면 된다.

### 바퀴

| 바퀴 | 무엇 | 왜 한 바퀴인가 |
|---|---|---|
| 1 | 고교 2,525곳 숫자 채우기(일반고 1,703 + 나머지 822) | 표 하나로 되지만 검수까지 한 바퀴다 |
| 2 | 학과 925개에 취업률 붙이기(이름 9,605개 묶기 포함) | 받아 둔 것을 지면에 잇는다 |
| 3 | 대학 나머지 48곳 + 나이 축 넓히기(집·부모·건강) | 열두 고민 중 넷을 더 세운다 |
| 4 | 유료 상품 설계 + 고객 결과물 | 「내 나이 넣기」로 개인 지도를 만든다 |
| 5·6·7 | **콘텐트 멈추고 검수만** 3회 | 위 1의 3승 = 결함 0 |

**합계 7바퀴.** 지면 수가 3,778로 가장 많지만 **틀에서 자동 생성**이라 결함 종류가 적다 —
그래서 검수 바퀴는 다른 사이트와 같은 3회로 본다.

### 걸리는 시간

3번은 어젯밤 열여섯 시간 창이 닫혀 실적이 없다. **직전 실적**으로 잡는다 —
학과 837개 취업률 확보에 하루, 정의 검증에 반나절. **한 바퀴 ≈ 1.5일.**

```
7바퀴 × 1.5일 = 약 10일  →  8/17 언저리
⚠ 오픈(8/15)에는 못 맞춘다. **오픈에 필요한 것은 1바퀴(고교 채움)뿐**이고 그건 8/10 까지다
```

## 6. 이 계산이 틀어지는 경우 — 셋뿐이다

```
① 콘텐트를 계속 더한다        → 수렴이 영영 안 온다. 상품 설계 뒤에는 **멈춰야** 한다
② 3번 창이 또 닫힌다          → 어제 열여섯 시간을 잃었다. 지킴이가 15분마다 보지만
                               예약을 다시 거는 것은 그 자리 몫이다
③ 유료 상품에서 새 데이터가 필요해진다 → 그러면 그 사이트만 두 바퀴가 는다
```

⚠ **포착률 3분의 2는 자료 한 번으로 잡은 값이다.** 다음 되짚기 결과가 나오면 이 문서를 고친다.
숫자가 바뀌면 바퀴 수도 바뀐다 — 그때 다시 계산해서 알려 드린다.
