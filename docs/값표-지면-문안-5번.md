# /data 값표 — 지면에 들어갈 **영문 문안** (5번이 씁니다 · 2번이 얹습니다)

> 나눔에서 제 몫은 「값표 지면 문안」입니다. 아래 영문을 **그대로** 쓰십시오.
> ⛔ 화면에 한국어를 내지 않습니다. 아래 한국어는 «지시»이지 지면 글이 아닙니다.
> ⛔ 제가 지면을 직접 고치지 않습니다 — 얹는 것은 2번 몫입니다.

---

## Ⅰ. 지면 머리 — 지금 제목 아래를 이렇게 바꿉니다

### 1-1. 지금 이렇게 돼 있습니다

```
Data for licence
… 그리고 모든 줄이  Free page · Free page · Free page …
```

제목은 「빌려주는 자료」인데 **값이 한 줄도 없습니다.** 사려는 사람이 와도 살 수가 없습니다.

### 1-2. 이 문단을 제목 바로 아래에 넣습니다 (영문 그대로)

```html
<p class="lede">
  Every dataset below has a free page and a free sample. The full file —
  every row, as CSV and Parquet, with a data dictionary — is licensed.
  Prices are listed. You will not be asked to request a quote.
</p>
```

⭐ 마지막 문장이 이 지면의 성격입니다. Nasdaq 이 「Contact sales」로 값을 감추는 자리에서
우리는 **값을 적습니다.** 물어봐야 아는 값은 우리 것이 아닙니다.

## Ⅲ. 「어떻게 삽니까」 — 값표 바로 밑

```html
<h2>How to buy</h2>
<ol class="buy-steps">
  <li>Email <a href="mailto:admin@klifedesign.net">admin@klifedesign.net</a> with the dataset
      name and your organisation.</li>
  <li>We send an invoice. Korean businesses receive a tax invoice (세금계산서).</li>
  <li>Pay by bank transfer. Invoiced in KRW.</li>
  <li>You receive a download link within one business day. Links do not expire.</li>
</ol>
<p class="fine">
  No account, no subscription, no card on file. A single-dataset licence is a one-time
  purchase — we do not bill you again unless you ask for the renewing option.
</p>
```

⚠ 결제 레일을 새로 만들지 않습니다. B2B 는 계좌이체가 정상이고 그게 제일 빠릅니다.
⛔ 입금 확인은 사람이 합니다 — 돈이 오가는 것은 사장님 승인 영역입니다.

## Ⅳ. 각 무료 지면 밑에 붙이는 한 줄 — **문이 없으면 값표도 못 만납니다**

지금 `/data` 에 sales·quote·문의 글자가 **0줄**입니다. 무료 지면을 읽고 마음이 동한 사람이
갈 곳이 없습니다. 아래 한 줄을 **모든 무료 데이터 지면 하단**에 넣습니다.

```html
<aside class="licence-cta">
  <p>
    This page shows a slice. The full dataset —
    <strong>{{ROWS}} rows, {{COLS}} columns, {{RANGE}}</strong> —
    is available as CSV and Parquet.
    <a href="/data#licence">See licence options</a>.
  </p>
</aside>
```

⭐ `{{ROWS}}` 들은 **지면마다 실제 수로 채웁니다.** 「full dataset available」로 뭉뚱그리지
않습니다 — 사는 사람이 알고 싶은 것은 「얼마나 크냐」입니다.
⛔ 채울 수를 모르면 그 지면에는 붙이지 않습니다. 빈칸을 지어내지 않습니다.

## Ⅴ. 라이선스 조건 — 값표 아래 접은 글로

```html
<details>
  <summary>Licence terms</summary>
  <ul>
    <li>Use inside your organisation, including in client deliverables and research output.</li>
    <li>Redistribution of the file itself, or resale as a dataset, is not included.</li>
    <li>Attribution: <em>SeoulMarkets</em>, with the release date.</li>
    <li>Source data is public. We license our compilation, normalisation and coverage work —
        not the underlying facts, which nobody owns.</li>
  </ul>
</details>
```

⭐ 마지막 줄이 정직한 대목입니다. **사실 자체에는 값을 매기지 않습니다.** 우리가 파는 것은
모으고 · 맞추고 · 빠진 곳을 적어 둔 일입니다. 공공자료는 세금으로 만든 것이니 공개가 원칙이고,
그 원칙과 우리 값은 부딪히지 않습니다.

---

## Ⅵ. ⛔ 이 문안에서 하지 않은 것

```
⛔ 「Contact sales」 · 「Request a quote」 · 「Starting from」 — 값을 감추는 말을 안 씁니다
⛔ 「Trusted by leading firms」 — 아직 한 곳도 안 팔렸습니다. 지어내지 않습니다
⛔ 카운트다운·한정할인 — 사람을 밀어붙이는 것입니다. 우리 강령에 어긋납니다
⛔ 무료 지면 가리기 — 지면과 표본은 계속 무료입니다. 사장님 지시입니다
```

## Ⅶ. 얹고 나서 잴 것

```
1. 390px 로 띄워 «눈으로» 봅니다 — 값 세 개가 한 화면에 들어오는지
2. 「KRW 390,000」 글자가 라이브 HTML 에 실제로 있는지 grep 합니다
3. 붙인 날부터 메일 문의 수를 셉니다. ⬜ 그 수가 첫 실험 결과입니다
   ⚠ 안 오면 «안 온다»고 적습니다. 재 보고 안 된다고 적는 것도 결과입니다
```
