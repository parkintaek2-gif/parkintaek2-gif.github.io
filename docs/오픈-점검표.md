## Ⅲ. 세 사이트가 각자 확인할 것

### 3-1. 그릇 — 🔴 **만들었으면 렌더해서 눈으로 본다**

사장님 지시: 「**그릇이 내용물을 결정한다.** 고객이 보는 시작과 결과는 엔진보다 더 치밀해야 한다」

```
⬜ 첫 화면      처음 오는 사람이 **3초 안에** 여기가 뭐 하는 곳인지 아는가
⬜ 모바일       실제 폭 375px 에서 가로 스크롤이 없는가. 표가 안 깨지는가
⬜ 다크모드     둘 다 읽히는가 (지원한다면)
⬜ 표           숫자 정렬 · 천단위 · 단위 표기 · 넘칠 때 가로 스크롤이 표 안에서만 나는가
⬜ 인쇄·PDF     리포트를 낸다면 페이지 나눔이 맞는가
⬜ 빈 상태      데이터가 없는 지면이 「비어 있음」으로 보이는가, 「고장」으로 보이는가
⬜ 로딩·오류    느릴 때·실패할 때 사람이 뭘 해야 하는지 알 수 있는가
```

**「기능을 붙이고 됐다」고 하지 않는다.** 스크린샷을 남긴다.

### 3-2. 신뢰 — YMYL

세 사이트 전부 YMYL 이다(금융·교육·소비). 발행 주체가 흐리면 검색에 안 올라온다.

```
⬜ About        법인명 · 주소 · 연락처 · 발행 목적
⬜ 푸터         발행 주체가 모든 지면에 있는가
⬜ JSON-LD      Organization · 기사면 Article
⬜ 출처 표기    지면마다 **출처와 기준시각**이 있는가
⬜ 한계 표기    자료의 한계를 지면에 못 박았는가
                (예: 백년지도 「같은 시·도라는 뜻일 뿐」)
⬜ 정정 이력    수치가 바뀌면 화면에 남기는가. 조용히 고치지 않는가
⬜ 고지         SeoulMarkets 는 「투자자문 아님」 · AI 고지
⛔ 「언론사」    **아직 등록 전이다.** 언론사·보도 목적·기자 표현을 쓰지 않는다
```

### 3-3. 검색 — 유일한 마케팅 채널

```
⬜ robots.txt · sitemap.xml 이 실제로 200 인가
⬜ noindex 가 의도한 곳에만 있는가
⬜ 사이트 간 링크          자사 사이트끼리 걸려 있는가 (⭐ 두 축 중 하나다)
⬜ canonical               중복 지면에 걸려 있는가
⬜ title·description       지면마다 다른가. 잘려도 뜻이 통하는가
⬜ OG 카드                 카카오톡·트위터에서 빈 카드가 안 나가는가
⬜ Search Console          ⬜ 아직 셋 다 미등록 (사장님 손 목록)
⬜ IndexNow                발행 뒤 보내는가
```

### 3-4. 숫자 — **틀린 수치 하나가 매체를 죽인다**

```
⬜ 표본 수와 채움률을 지면에 적었는가
⬜ 분모가 「우리 한계」인지 「그쪽 미공시」인지 구분해 적었는가
   ⚠ 2026-08-05 에 이걸 틀렸다. 「1,066곳이 신고했다」→ 실제로는 1,837곳이 신고했고
     우리 파서가 1,066곳만 읽었다
⬜ 합계·평균을 손으로 한 건 검산했는가
⬜ 「없는 선택지」를 내밀고 있지 않은가
   ⚠ 3번이 2026-08-05 에 48곳을 잡았다. 등록 뒤에는 정정보도 사유가 된다
```

```

⬜ 배포 전에 실제로 렌더해 봤는가
```
