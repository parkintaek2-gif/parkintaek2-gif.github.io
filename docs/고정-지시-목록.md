3-b. [**9/3 신설**·상시 · **총괄(대행) 몫**] **매일 23시 — 전 유닛 점검 보고 + 이메일 전송.**
     사장님 원문: 「매일 23시에 공격형(이슈에 반응, 이슈를 만드는), seo, geo 맞춤형 콘텐트 생산 여부,
     외부 반응 등에 대한 보고를 해라. 전 유닛 꺼 네가 체크한 결과를 토대로 업무보고(이메일 전송 포함)해」
     ⚠ 3-a 의 「16시 한 번」은 **각 유닛의 자기 실적 보고**다. 이 23시 것은 **총괄이 전 유닛을 «점검»한 결과**로,
        서로 다른 보고이며 둘 다 산다. ⛔ 커밋 수를 콘텐트 수라고 부르지 않는다. ⛔ 어제(완결된 하루)를 센다.
     자: `node scripts/report-unit-content-check.mjs` · 예약: 매일 22:50
3-c. [**9/3 신설**·상시 · **총괄(대행) 몫** · 🔴 **사장님: 「이게 제일 중요해」**]
     **매시 소통마다 «매번» 공격형·SEO·GEO 콘텐트 생산을 독려한다.**
     사장님 원문: 「공격형(이슈에 반응, 이슈를 만드는), seo, geo 맞춤형 콘텐트 생산을 독려해,
     나도 지금 지시할테니, 소통할 때 마다(1시간마다)마다 얘기해. 이게 제일 중요해.
     내가 "좋은 상품도 고객이 찾아오면 가치가 없다"라는 식으로 말한 것을 명심해라」
     ⚠ 가리키는 앞선 말씀(기록 원문): 「방문자가 없는 것 = 찾는 고객이 없는 것 =
        아무리 좋은 상품도 팔 수 없는 것 = 비즈니스 폭망」(8/26) · 「사람이 안 오면
        아무리 좋은 상품도 의미가 없다」(8/23)
     ⛔ 빈 독려를 하지 않는다. **그 유닛의 지금 수를 재서 함께 낸다** —
        어제 발행 몇 편 · llms.txt 살았나 · 마지막 커밋이 몇 시간 전인가.
     ⛔ 커밋 수를 발행 수라고 부르지 않는다.
3-d. [**9/3 신설**·상시 · **총괄(대행) 몫**] **매시 소통마다 «유닛별로» 셋을 반드시 확인한다.**
     사장님 원문: 「너는 매시간 소통할 때마다, **(1) 콘텐트 발행 (2) 자체AI 학습 (3) 개발 진행** 등을
     꼭 체크해, **각 유닛별로**」
     ```
     (1) 콘텐트 발행   텍스트·영상·기타 각각 몇 개 «나갔나» (커밋 수 아님)
     (2) 자체AI 학습   우리 엔진·모델이 무엇을 더 배웠나 (자료·규칙·판정층)
     (3) 개발 진행     그 유닛이 무엇을 짓고 있나 · 막힌 것은 무엇인가
     ```
     ⛔ 셋 다 **유닛별로** 낸다. 못 들은 칸은 「답 없음」이라고 적는다 — 빈칸으로 두지 않는다.
     **>>> 같은 날 사장님이 뜻을 더 좁혀 주셨다 (원문):**
     「**그래서 하루의 미션을 달성한다 …… 콘텐트발행 = 이슈만들기, 이슈 좇기, GEO, SEO 충족 포함**」
     「**개발진행은 현재 케이라이프맵만 있지? 그러면 케이라이프맵을 챙겨**」
     ```
     ⛔ 「콘텐트 발행」은 편수만이 아니다. 한 편이 넷을 다 채워야 «발행»으로 친다 —
        1. 이슈 만들기(제목이 관심을 끌고, 방문이 평균보다 많은가)
        2. 이슈 좇기(바깥 발행에서 12시간 안 · 우리 «배포» 기준)
        3. GEO 충족(llms.txt·마크다운 판·구조화 데이터에 실렸나)
        4. SEO 충족(제목·본문·내부 링크·사이트맵)
     **>>> 사장님이 2.의 «어디를» 좇는지도 정하셨다 (원문):**
     「**이슈 좇기 = 뉴스, 커뮤니티, sns의 이슈 좇기**」
     ```
     ⛔ 뉴스만이 아니다. **뉴스 · 커뮤니티 · SNS** 셋을 다 좇는다.
     🔴 [2026-09-03 실측] 우리가 지금 받아 오는 것은 **뉴스 4곳뿐**이다 —
        매일경제·동아일보(6번·3번 몫) · 스타뉴스·텐아시아(5번 몫).
        **커뮤니티와 SNS 를 받는 자는 하나도 없다.** 그래서 지금은 셋 중 하나만 좇고 있다.
     ✅ 채울 것: 커뮤니티·SNS 수집기. 열쇠 없이 되는 곳부터 — 우리 손님이 영어권이므로
        Reddit 공개 JSON(r/kpop·r/KDRAMA 등)이 첫 자리다. 위키백과 열람 급등도 이미 있다.
     ```
     ✅ 그 넷을 다 채운 날이 «하루 미션을 달성한 날»이다.
     ✅ 개발 진행은 지금 **KLifeMap 한 곳**이다 — 거기를 챙긴다.
     ```
