# 고정 지시 목록 (6번 SeoulMarkets) — 터미널 맨 아래(상태줄)에 항상 뜬다
# ⛔ 전체 이력은 docs/사장님-지시-대장.md · docs/6번-사장님말씀-대장.md 에 있다. 여기는 "지금 상시 신경 쓸 것"만 짧게.
# 사장님이 "N번 고정해제"라 하면 그 줄을 지운다. #으로 시작하는 줄은 무시된다.

1. [9월·상시] 방문자 올인 — 유닛당 하루 평균 1,000명(9월 목표). 업무 50%+ 를 방문자 늘리기에. 병목=순위→신규 롱테일 우선(2번 승인)
2. [8/29·상시] 매일 뉴스체크 스스로 → 사장님 말하기 前에 알아서 데이터/콘텐트로 (예산·국민연금처럼). ⛔ 짐작·보도자료 베끼기 금지, 재현 가능한 원자료만
3. [8/29·상시] 소통은 1번식 — 상대별 완료확인→판단(재작업 요/불요)→다음. 매시 2번(총괄)과. [진행]만 찍지 말 것
3-a. [8/29·상시 · **9/2 수정**] ⛔ 사장님께 **직접 업무보고·메일 금지.** 보고는 2번 통해 **16시 한 번만** 한다. (옛 지시 「10:00·15:30·23:00 세 번」 → 사장님 9/2 「16시 한번만 보고 함」)
3-b. [**9/3 신설**·상시 · **총괄(대행) 몫**] **매일 23시 — 전 유닛 점검 보고 + 이메일 전송.**
     사장님 원문: 「매일 23시에 공격형(이슈에 반응, 이슈를 만드는), seo, geo 맞춤형 콘텐트 생산 여부,
     외부 반응 등에 대한 보고를 해라. 전 유닛 꺼 네가 체크한 결과를 토대로 업무보고(이메일 전송 포함)해」
     ⚠ 3-a 의 「16시 한 번」은 **각 유닛의 자기 실적 보고**다. 이 23시 것은 **총괄이 전 유닛을 «점검»한 결과**로,
        서로 다른 보고이며 둘 다 산다. ⛔ 커밋 수를 콘텐트 수라고 부르지 않는다. ⛔ 어제(완결된 하루)를 센다.
     자: `node scripts/report-unit-content-check.mjs` · 예약: 매일 22:50
3-c. [**9/3 신설**·상시 · **총괄(대행) 몫** · 🔴 **사장님: 「이게 제일 중요해」**]
     **매시 소통마다 «매번» 공격형·SEO·GEO 콘텐트 생산을 독려한다.**
     사장님 원문: 「공격형(이슈에 반응, 이슈를 만드는), seo, geo 맞춤형 콘텐트 생산을 독려해,
     나도 지금 지시할테니, 소통할 때 마다(1시간마다)마다 얘기해. 이게 제일 중요해.
     내가 "좋은 상품도 고객이 찾아오면 가치가 없다"라는 식으로 말한 것을 명심해라」
     ⚠ 가리키는 앞선 말씀(기록 원문): 「방문자가 없는 것 = 찾는 고객이 없는 것 =
        아무리 좋은 상품도 팔 수 없는 것 = 비즈니스 폭망」(8/26) · 「사람이 안 오면
        아무리 좋은 상품도 의미가 없다」(8/23)
     ⛔ 빈 독려를 하지 않는다. **그 유닛의 지금 수를 재서 함께 낸다** —
        어제 발행 몇 편 · llms.txt 살았나 · 마지막 커밋이 몇 시간 전인가.
     ⛔ 커밋 수를 발행 수라고 부르지 않는다.
4. [9/9·대기] 금융위 제4유형 — 주식·채권·지수 시세 API 상업·변경 금지. 6번 데이터 근간 직격, 사장님 결정 대기. 안전원천=관세청·KOSIS(노동·물가·무역)
5. [8/29·상시 · **9/2 수정**] 콘텐트 주기 — 텍스트 **하루 6번**, 영상 **하루 1개**. (옛 지시 「텍스트 6 : 영상 3」 → 사장님 9/2 「영상 1개/일 생산」) ⚠ 「하루 6번」은 텍스트 몫이지 영상이 아니다.
6. [8/29·상시] 영상은 캐릭터·애니 **자체 영상**+**소리 직접 제작**(목소리·배경음). ⛔ 무성 영상 금지·스틸(카드·그래픽)만 금지. 기존 무성영상은 안 내리고 소리 얹어 추가배포. (제작 파이프라인 확보 후, 그전엔 텍스트 집중)
