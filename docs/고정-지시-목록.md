# 사장님이 "N번 고정해제"라 하면 그 줄을 지운다. #으로 시작하는 줄은 무시된다.

1. [9월·상시] 방문자 올인 — 유닛당 하루 평균 1,000명(9월 목표). 업무 50%+ 를 방문자 늘리기에. 병목=순위→신규 롱테일 우선(2번 승인)
2. [8/29·상시] 매일 뉴스체크 스스로 → 사장님 말하기 前에 알아서 데이터/콘텐트로 (예산·국민연금처럼). ⛔ 짐작·보도자료 베끼기 금지, 재현 가능한 원자료만
3. [8/29·상시] 소통은 1번식 — 상대별 완료확인→판단(재작업 요/불요)→다음. 매시 2번(총괄)과. [진행]만 찍지 말 것
3-a. [8/29·상시 · **9/2 수정**] ⛔ 사장님께 **직접 업무보고·메일 금지.** 보고는 2번 통해 **16시 한 번만** 한다. (옛 지시 「10:00·15:30·23:00 세 번」 → 사장님 9/2 「16시 한번만 보고 함」)
4. [9/9·대기] 금융위 제4유형 — 주식·채권·지수 시세 API 상업·변경 금지. 6번 데이터 근간 직격, 사장님 결정 대기. 안전원천=관세청·KOSIS(노동·물가·무역)
5. [8/29·상시 · **9/2 수정**] 콘텐트 주기 — 텍스트 **하루 6번**, 영상 **하루 1개**. (옛 지시 「텍스트 6 : 영상 3」 → 사장님 9/2 「영상 1개/일 생산」) ⚠ 「하루 6번」은 텍스트 몫이지 영상이 아니다.
6. [8/29·상시] 영상은 캐릭터·애니 **자체 영상**+**소리 직접 제작**(목소리·배경음). ⛔ 무성 영상 금지·스틸(카드·그래픽)만 금지. 기존 무성영상은 안 내리고 소리 얹어 추가배포. (제작 파이프라인 확보 후, 그전엔 텍스트 집중)
7. [상시] 홍익인간 — 나침반을 준다. "이것은 통계이지 당신이 아닙니다." 못 잰 건 못 쟀다고 적는다. 고치면 인용한 곳까지 따라간다
