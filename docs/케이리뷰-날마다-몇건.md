# 케이리뷰 — 날마다 몇 건을, 어느 분류로 내나

## 🔴🔴 사장님 지시 (2026-10-29, 원문)

> 「**하루에 한 건씩 카테고리별로 작성해…모두 7개/일**」
> 「**드라마 안에 영화리뷰도 써서 넣어…영화리뷰도 ott에 공개된 것을 주로 해**」
> 「**쇼 리뷰는 한 건도 없잖아…**」
> 「**배구는 개막 후부터 쓰면 되겟네…숨겨놓을 필요없다…
>   배구 개막 후에는 8건/일, 배구 개막 전에는 7건/일**」

⬜ 앞서 「스포츠종합은 잠시 숨겨놔」라고 하셨다가 **그 자리에서 거두셨다**(「취소」).
  까닭은 사장님이 바로 적어 주셨다 — **스포츠종합에 배구가 들어 있다.**
  ⛔ 숨기지 않는다. 배구가 개막하면 그 칸이 날마다 한 건을 맡는다.

## 날마다 내는 수

```
2026-10-30 까지   7건/일
2026-10-31 부터   8건/일   ← 프로배구 V-리그 개막 (2026-10-31 토)
```

V-리그 2026-27 개막은 **2026년 10월 31일(토)**이다. KOVO 가 2026-08-18 에 일정을 냈고,
남자부 개막전은 10/31 14:00 인천 계양체육관 대한항공 : 현대캐피탈이다.
정규리그는 2027-04-02 까지 — 그 사이는 8건/일이다.

## 어느 분류가 날마다 한 건을 맡나

| 분류 | 코드 | 10/30까지 | 10/31부터 |
|---|---|:---:|:---:|
| K-POP | `kpop` | ✅ | ✅ |
| 드라마 — **영화 리뷰를 여기 함께 넣는다** | `drama` | ✅ | ✅ |
| 쇼 | `show` | ✅ | ✅ |
| 야구 | `baseball` | ✅ | ✅ |
| 축구 | `football` | ✅ | ✅ |
| 농구 | `basketball` | ✅ | ✅ |
| e스포츠 | `esports` | ✅ | ✅ |
| 스포츠종합 — **배구** | `sports` | ⬜ 개막 전이라 쉰다 | ✅ |
| 골프 | `golf` | ⬜ | ⬜ |
|  | **합** | **7건** | **8건** |

⚠ **골프를 뺀 것은 수를 맞추려는 셈이 아니다.** 사장님이 7과 8을 수로 못 박으셨고,
  아홉 분류 가운데 날마다 쓸 거리가 가장 얇은 칸이 골프다 — KLPGA·KPGA 는
  주말에 대회가 몰리고 주중에는 경기가 없다. 날마다 한 건을 맡기면 억지 기사가 나온다.
  ⭐ 대신 **대회가 열리는 주말에는 골프를 넣고 그 자리를 다른 칸이 쉰다.**
  ⛔ 사장님이 골프를 짚으시면 이 줄을 고친다. 내가 정한 것이지 지시가 아니다.

## 드라마 칸 — 영화를 함께 쓴다 (사장님 2026-10-29)

- 드라마 리뷰와 **영화 리뷰가 같은 칸**을 쓴다. 날마다 그 칸에서 한 건이 나온다.
- 영화는 **OTT 에 공개된 것을 주로** 쓴다 — 극장 개봉작이 아니라 넷플릭스·티빙·쿠팡플레이·웨이브·디즈니플러스에 올라온 것.
  ⚠ 까닭은 사장님이 말씀하신 그대로다. 손님이 **지금 볼 수 있는 것**이라야 리뷰가 쓸모 있다.
- ⛔ 사진은 OTT 가 제공한 것만 쓴다 — 타사 기사에 「제공: 넷플릭스」로 실린 것
  (`제공처유형: ott`). 분류별 사진 규칙은 `src/lib/리뷰분류.mjs` 가 정본이다.
- `subject.유형` 은 영화도 `episode` 가 아니라 **`release`** 로 적는다 — 회차가 없다.
