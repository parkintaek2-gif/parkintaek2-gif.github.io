# 1. ⭐ 전략 — **우리가 이길 수 있는 자리**

> 사장님: **「겪은 것보다 아이디어, 전략이 중요해」** · **「비즈니스 성공이 목표」**
>
> ## 🔴 이 문서의 판정 기준
>
> **모든 규칙은 「그래서 돈이 되는가」로 판정한다.**
> 안 그러면 이 문서는 잘 지켜지는 결벽증 목록이 된다. 그건 우리 목표가 아니다.
>
> ```
> 규칙 하나를 넣을 때마다 묻는다 —
>   「이걸 지키면 **뭐가 팔리나**」 「안 지키면 **뭘 잃나**」
> 둘 다 답이 안 나오면 그 규칙은 뺀다.
> ```
>
> 아래 2~6장은 전부 이 장을 **실행하는 방법**이다. 방법이 목적이 되면 안 된다.

## 1-0. ⚠ 지금 우리 위치 — **네 매체 중 매출이 있는 건 하나뿐이다**

```
KLifeMap    매출 있음. **PG 승인 대기**로 확장이 멈춰 있다
SeoulMarkets 기사 14편 · 데이터 8백만건. **매출 0**
백년지도      지면 3,450장. **매출 0**
WikiTip      대기
```

**우리에게 제일 부족한 것은 데이터도 기술도 아니라 「첫 결제」다.**
이 문서의 전략은 전부 거기로 수렴해야 한다.

## 1-7. ⭐ **첫 매출까지 가장 짧은 경로** — 여기에 자원을 몬다

우리가 가진 것 중 **지금 당장 팔 수 있는 모양**인 것부터 센다.

```
① 완성돼 있고 팔 수 있다        KLifeMap 리포트 — **PG 만 풀리면 된다**
② 물건은 됐는데 살 사람이 없다   SeoulMarkets 데이터 — **명단과 아웃리치가 없다**
③ 트래픽이 먼저 필요하다        백년지도 무료도구 → 고1~2 결제
④ 아직 물건이 아니다            WikiTip
```

> **전략 ⑦ — 「물건이 없다」와 「살 사람이 없다」를 구분한다.**
> ②는 **더 만들 게 아니라 팔러 가야 한다.** 데이터를 더 모아도 매출은 안 생긴다.
> 지금 SeoulMarkets 는 ②인데 계속 ①처럼 일하고 있다 — 이게 제일 큰 낭비다.

⚠ **못 잰 것을 적어 둔다** — 우리는 아직 **유입 수치를 한 번도 안 봤다.**
검색 유입이 얼마인지, 어느 기사가 무엇을 데려오는지 모른다.
**모르면 어디에 자원을 몰지 못 정한다.** 이건 다음 주 안에 재야 한다.

## 1-1. 우리가 파는 것은 **조인**이다

원자료는 공짜다. 4,368,788건을 모아 둔 것 자체는 **누구나 할 수 있고 팔리지 않는다.**
**값은 두 자료를 붙일 때 생긴다.**

```
경쟁사(CEO스코어·CEO랭킹)   재무 × 기업        이미 다 한다
우리                       **사람 × 주가**    아무도 안 한다
                           근속·급여·성별격차 × 시총·수익률
```

이건 이미 증명됐다 — 2,552곳을 붙여 **「여성이 많은 회사가 나빴다」가 업종 착시**임을 보였다.
**그 기사는 조인 없이는 존재할 수 없다.** 이게 우리 상품의 모양이다.

> **전략 ①** 새 데이터를 받을 때 「무엇과 붙일 수 있나」를 먼저 적는다.
> 붙일 데가 없으면 **수집 순위를 내린다.** 안 붙는 데이터는 창고 비용이다.

## 1-2. 한 번 모아 **네 곳에 판다**

```
수집 1회  →  SeoulMarkets(투자자) · 백년지도(학부모) · WikiTip(해외독자) · KLifeMap(개인)
```

같은 원자료를 매체별로 다르게 써는 것이 **우리 구조의 이점**이다.
매체를 늘려도 **수집 비용이 안 는다.**

> **전략 ②** 수집기를 만들 때 **한 매체만 보고 설계하지 않는다.**
> 「이 자료를 다른 세 곳에서 쓸 수 있나」를 그 자리에서 묻는다.

## 1-3. 결정론이 **해자**다 — 남이 못 따라오는 이유

경쟁자가 LLM 하나로 만들면 **같은 질문에 매번 다르게 답한다.** 그건 상품이 못 된다.

```
판정   규칙 엔진   같은 입력 → **언제나 같은 결과**
설명   LLM        판정을 바꾸지 않는다
검증   **독립**    판정에 없는 말을 하면 잡는다
```

**이 셋을 나눠 놓는 것 자체가 진입장벽이다.** 붙여 놓으면 하루면 흉내 내지만,
나눠 놓으면 **엔진을 만들어야** 따라온다. 그리고 엔진은 도메인 지식이다.

> **전략 ③** 「LLM 이 더 잘하니까」로 판정을 LLM 에 넘기지 않는다.
> 넘기는 순간 **우리 해자가 사라진다.**

## 1-4. 사람을 안 거치는 것이 **비용 우위**다

```
경쟁사   기자·에디터·디자이너 → 기사 한 편에 인건비
우리     수집·가공·발행·검증이 전부 자동 → **한 편의 한계비용이 0에 가깝다**
```

그래서 **경쟁사가 안 쓰는 주제**를 쓸 수 있다. 조회수가 안 나올 주제도 낼 수 있고,
그게 쌓이면 **검색에서 우리만 있는 자리**가 된다.

> **전략 ④** 「이건 사람이 붙어야 한다」가 나오면 **그 일을 접는 게 아니라 자동화 방법을 찾는다.**
> 접으면 경쟁 우위가 아니라 그냥 못 하는 일이 된다.

## 1-5. **검증이 곧 영업**이다

금융·교육·명리는 전부 YMYL 이다. **신뢰가 없으면 검색에도 안 올라오고 팔리지도 않는다.**
그런데 신뢰는 말로 못 만든다 — **보여야** 만들어진다.

```
분모를 같이 적는다        우리가 계산했으면 그렇게 적는다
출처와 기준시각을 붙인다   못 쟀으면 「못 쟀다」고 쓴다
안 다룬 것을 적는다       (excluded 절)
```

이건 **결벽이 아니라 판매 자료**다. B2B 로 데이터를 팔 때 상대가 보는 것이 정확히 이것이다.

> **전략 ⑤** 5장(검증)은 품질 관리가 아니라 **상품 사양서**다. 화면에 드러나게 만든다.

## 1-6. 무료 발행은 **카탈로그**다

```
기사·무료 도구  →  검색 유입  →  데이터·리포트 판매
```

유일한 마케팅이 검색과 **우리 사이트끼리의 유입**이다. 그래서 네 매체가 서로 링크된다.

> **전략 ⑥** 기사를 낼 때 **그 기사가 어떤 상품을 가리키는지**를 정하고 쓴다.
> 가리키는 데가 없으면 트래픽만 남는다.

# 2. 병렬형 구조 — 전략 ③을 **어떻게** 만드나

> **읽기·조사·검증은 여럿이 동시에. 고치는 책임은 하나.**

```
① 애널리스트    신호를 만든다               ← 조사 (병렬)
② 펀드매니저    포지션을 정한다              ← 제작 (편집 책임 하나)
③ 리스크관리자   한도를 감시하고 멈춘다 **독립**  ← 검증 (병렬)
```

## 1-2. ⭐ 이 구조가 **실제로 결함을 잡았다** (1번)

> 2026-08-01, 상담 AI 가 「상관 대운이 정관격과 어긋난다」고 답했다.
> **검증 AI 가 「그 판단은 엔진이 준 것이 아니다」**라고 잡았다.
> 원인은 프롬프트가 아니라 **데이터 파이프라인**이었다. **셋이 붙어 있었으면 아무도 못 잡았다.**

리포트도 같다 — `자료 수집·사실 확인(병렬) → 초안(하나) → 숫자 대조·렌더 확인(병렬)`

# 3. 협업

## 3-1. 우리가 낸 사고 셋

```
① 1번이 `git add -A` 로 **4번이 편집 중이던 파일**을 쓸어갔다
② 2번이 3번 파일을 고치고 **24분 뒤에** 알렸다 — 통보였지 협업이 아니었다
③ 3번이 잘못 진단한 것을 2번에게 넘겼고, 2번이 **같은 도구로 재서 같이 틀렸다**
```

## 3-2. 그래서 정한다

| | 규칙 |
|---|---|
| **편집 책임** | 파일마다 주인이 하나. 남의 파일은 **고치기 전에 말하고** 결과를 보고 |
| **급하면** | 고치되 메모에 남긴다. ⛔ **단 상대가 지금 작업 중인 파일은 급해도 손대지 않는다** |
| **커밋** | `git add -A` 금지. **경로를 지정한다** — 저장소를 나눠 쓰므로 남의 작업이 딸려 간다 |
| **읽기·검증** | 누구나 언제든. 병렬이라야 빨라진다 |
| **원인을 넘길 때** | ⭐ **무엇으로 쟀는지를 같이 적는다.** 틀린 진단을 넘기면 **두 배가 된다** |

## 3-3. ⭐ 받은편지함은 **하나다** — 4번 질문에 2번이 답한다

4번이 물었다: 세션간-메모(`npm run inbox`)와 `바탕화면\4번_작업함\inbox\` 둘이 경쟁한다.
**둘 다 남기되 용도를 가른다. 겹치지 않으므로 사고가 안 난다.**

```
세션 ↔ 세션      **docs/세션간-메모.md 하나뿐이다.**  git 에 남고 넷이 다 본다
사장님 → 세션     바탕화면 폴더도 쓴다 (사장님이 파일을 놓기 편하시다 — 사장님 지시로 만든 것)
```

⚠ **폴더에 세션이 세션에게 남기지 않는다.** 폴더에 그런 게 오면 **메모로 옮기고 폴더에서 지운다.**
판단 기준은 **「누가 보내는가」**이지 도구가 아니다.

## 3-4. 24시간 이어가기 — ⚠ **스케줄이 둘이다. 섞지 않는다** (4번)

```
클라우드 예약(CronCreate)   세션이 바뀌면 사라짐 · recurring **7일 만료**
로컬 예약(작업 스케줄러)     **앱이 꺼져 있으면 안 돈다** ← 「무인 24h」의 진짜 구멍
```

**「진짜 24시간」이 필요한 것은 클라우드 쪽에 둔다.** 만료 규칙이 다르므로 두 시스템을 섞어 세지 않는다.
세션을 시작하면 **`CronList` 부터** 본다.

## 3-5. 규칙은 파일에 — ⚠ **남겼다고 걸리는 게 아니다** (1번)

```
· 공통 부품을 만들었는데 화면마다 **그릇 이름이 셋**이라 두 화면에 안 걸렸다
· 지적을 반영했는데 프롬프트가 **두 갈래**라 **절반만** 반영됐다
· CSS 를 고쳤는데 **같은 셀렉터가 뒤에 또 있어** 계속 덮고 있었다
```

→ **「부품을 실제로 쓰는가」를 기계로 센다.** 「공통이니까 다 바뀌었겠지」가 제일 위험하다.

# 4. 반복 업무는 시스템으로

## 4-1. 승격 순서 — ⚠ **검증 없이 예약에 걸지 않는다** (1번·4번 둘 다 어겼다)

```
1번째  손으로   ·   2번째  스크립트   ·   3번째  예약
```

> ⭐ **예약으로 올리기 전에**: 서로 다른 **정상 입력 3건**을 통과하고
> **멈춰야 할 예외 1건**에서 안전하게 중단하는지 확인한다.
> **운영 중인 것을 바로 덮어쓰지 않는다** — 실행 루프와 개선 루프를 분리한다.

## 4-2. 자동화에는 안전장치를 함께

```
· 결과는 `.new` 에 쌓고 **다 끝난 뒤** 바꿔치기      (재수집 중 본 파일이 비었다)
· 이어받기를 만든다                                (백필이 94%에서 죽어 전부 날렸다)
· 다시 계산할 때 **「없어진 값」 카운터**             (42건이 조용히 사라질 뻔했다)
```

⭐ **1번·3번 둘 다 이 문서에서 이걸 가장 크게 가져갔다.**
채움률만 보면 **올라간 숫자에 가려 사라진 값이 안 보인다.**

## 4-3. ⭐ 고치는 것보다 **못 만들게 하는 것**이 오래 간다 (3번)

```
⛔ 404 를 찾아 고친다            원자료가 바뀌면 또 생긴다
✅ **페이지가 있는 것만 링크한다**   다시는 안 생긴다
```

**「검증으로 잡는다」보다 「구조로 못 나게 한다」가 먼저다.**

## 4-4. 설정 함정은 문서가 아니라 **실측 1건**으로 잡는다 (4번)

```
thinkingBudget:0    → 이 모델은 400 으로 거부
방치(기본)          → 사고 토큰 7,860 이 출력 한도를 먹어 **밀집 페이지가 잘렸다**
thinkingBudget:128  → 깨끗이 완결        ← 한 페이지에 4개 설정을 재서 찾았다
```

**「문서에 있다」와 「이 키·이 모델에서 통한다」는 다르다. 전부 돌리기 전에 1건으로 잰다.**

# 5. 검증 — 「했다」가 아니라 「봤다」

```
자료  폴더·문서·원자료·화면   기준  권한·완료 조건·금지   증거  **렌더링·테스트·스크린샷**
```

## 5-1. ⚠ 그다음 층 — **엉뚱한 걸 봤을 수 있다** (1번, 하루 다섯 번)

```
① 뽑는 폴더와 검사하는 폴더가 달랐다  「감수용 리포트」 vs 「리포트-감수용」
   → 「33종 통과」가 전부 **하루 전 PDF** 기준이었다
② 렌더 도구가 ok=true 를 무조건 줬다   글자 하나까지 같은데 ✅
③ 명암비 검사가 SVG 를 잘못 읽었다     **거짓 경보 40건** (밑에 진짜 한 건이 깔려 있었다)
④ 넓은 정규식이 **틀린 진단명**을 붙였다
```

```
· 거짓 경보는 진짜 한 건을 **묻는다**
· 틀린 진단명은 없는 것보다 **나쁘다** — 엉뚱한 데를 고치게 만든다
· **검사가 헛도는지 먼저 확인한다** — 일부러 틀린 값을 넣어 **실제로 실패하는지** 본다
```

## 5-2. ⚠ **도구가 입력을 바꾼다** (3번 → 2번, 둘이 함께 틀렸다)

```
3번이 curl 로 404 를 봤다 → 원인과 패치를 2번에게 넘겼다
2번이 「재현했다」고 답했다  → **같은 도구로 쟀으니 같이 틀렸다**
Node 로 다시 재니 **처음부터 200** 이었다
```

원인은 **Windows 셸이 한글을 CP949 로 바꾼 것.** 주소가 아니라 **도구가 주소를 깨뜨렸다.**
⛔ **한글·백틱·긴 글을 셸로 넘기지 않는다.** 파일에 써서 Node 로 읽는다.

## 5-3. ⭐ **넘겨받은 좌표도 내 환경에서 다시 맞춘다** (4번)

인계에 「규장각본은 믿어도 돼」, 주석에 「OCR 1.4%」가 적혀 있었다. 그대로 갔으면 며칠 헛돌 뻔했다.

```
· 그 451MB PDF 는 스캐너 원본이 아니라 **크롬으로 저장된 파일**이었다 (Producer: Skia/PDF)
· 「1.4%」는 **다른(작은) 하위 PDF 로 잰 값**이었다
```

**「믿을 수 있다」는 남의 판단이다. 측정은 지금 이 파일·이 키로 다시 한다.**

## 5-4. ⭐ 도구가 통과시켜도 **고객에게 나가는 인용은 원본과 직접 대조** (4번)

OCR 이 「못 읽은 글자 0」을 줬다. 그런데 옛 판에는 **같은 조문이 「宜出行 ↔ 忌出行」 정반대 두 판**이
섞여 있었고 **둘 다 「정상」으로 통과**했다. 택일은 결혼·이사 날짜 근거다 — 한 글자가 사고다.

→ 스캔을 **확대 크롭해 글자 단위로** 대조해 정본을 확정했다. **도구의 통과는 「봤다」가 아니다.**

## 5-5. fixture 테스트는 **거짓 안심**이다 (1번, 같은 사고 두 번)

```
8/1  상담 AI 에 데이터가 안 갔다. 고쳤다
8/4  감수본을 눈으로 보니 **8/1 수정이 운영에서 한 번도 동작한 적이 없었다**
     함수는 맞았다. **데이터가 거기까지 안 갔다.** 두 번 다 테스트는 통과했다
```

⛔ 실제 저장 경로를 한 번도 안 거친 테스트는 **없는 것보다 나쁘다.**

## 5-6. ⭐ 숫자가 맞아도 **분모를 안 밝히면 거짓말** (3번)

```
강릉원주  졸업 1,656명 → 취업대상 1,476명 → 취업 887명 = 60.1%
```

취업률의 분모는 졸업자가 아니라 **취업대상자**다. 분모를 안 밝히면 독자는
**「나머지는 놀고 있다」**로 읽는다. **독자가 틀리게 읽으면 우리가 거짓말한 것이다.**
→ **모든 비율에 분모를 같이 적는다.**

## 5-7. 우리 숫자와 발표 숫자를 **섞지 않는다** (3번)

```
✅ 공식값이 있으면 그것을 쓴다. 우리가 계산했으면 **「우리가 계산했다」고 화면에 적는다**
```

## 5-8. 권한은 좁게

```
⛔ .env 읽기 · rm -rf · git push --force
⛔ ctype 에 `-t` 없으면 훅이 막는다 (klifemap 을 죽일 뻔했다)
⛔ 저장소가 공개다. **키 값을 커밋하지 않는다**
```

# 6. 감각적인 웹디자인 — 원문에 없어 우리가 채운 장

## 6-1. 감각은 **틀린 걸 알아보는 눈**이고, 그건 잴 수 있다

```
제목이 첫 화면의 **56%** 를 먹었다          → 재서 알았다 (253px / 450px)
표 스타일이 **통째로** 죽어 있었다           → 재서 알았다 (글자 크기·색이 같았다)
「본문이 너무 넓다」고 진단했다가 취소했다    → 재보니 **이미 정상**이었다
```

**셋 다 눈대중으로는 반대로 판단했다.** → `만든다 → 렌더한다 → **잰다** → 고친다`

## 6-2. 매번 재는 여덟

```
첫 화면     제목이 화면의 몇 %인가 · 본문 첫 줄이 보이는가
글줄        한 줄에 몇 글자인가 (60~75)
활자 종류수  ⭐ **몇 종인가** (3번: 8화면에 **23종**, 한 장에 16종)
            0.5px 차이는 다른 단이 아니라 **어긋난 것** → 네 단으로 줄였다
            `제목 19 > 부제1 15 > 부제2 13 > 본문=표 11.5` (+주 10) · 비율 1.28
            ⚠ **본문과 표를 같은 크기로.** 표만 작으면 부록처럼 보인다
모바일      **360px 에서 먼저.** 데스크톱을 줄이지 않는다
다크모드     배경·글자·표 경계선이 다 살아 있는가
인쇄        ⚠ **「보면 안다」가 안 통한다. 반드시 PDF 로 뽑는다** (6-4)
같은 옷     ⭐ **새 지면이 기존과 같은 스타일을 입었는가** (3번: 377장이 빈손으로 나갔다)
무게        외부 스크립트 몇 개 · 몇 KB
```

## 6-3. 트렌드는 베끼지 말고 **원칙으로 옮긴다**

```
⛔ 「요즘 이게 유행」  → 다음 유행이 오면 다시 만든다
✅ 「왜 좋아 보이나」  → 여백·대비·정렬·**서열**. 안 바뀐다
```

⭐ **크기만으로 세운 위계는 흑백 인쇄에서 약하다.** 제목에 **명조**를 주면 크기가 비슷해도 층이 산다.
같은 서체에서 **색만 바꾸면 「강조」**, **서체가 갈리면 「다른 것」**으로 보인다.
⭐ **브랜드는 글자만으로 세울 수 있다** — 메일·요약·저사양처럼 **이미지가 안 뜨는 자리**를 위해.

## 6-4. ⚠ 인쇄는 화면으로 **원리적으로 못 잡는다** (3번)

```
· 점수 막대가 인쇄에서 **통째로 사라졌다** — 배경색으로만 그렸다
· 금색(#c9a84c)이 종이에서 **대비 2.1** — 화면에서는 멀쩡하다
· `md:grid-cols-2` 는 **화면 폭**에 반응한다 — 인쇄에서 꺼져 **종이에서만** 무너졌다
```

## 6-5. 연습법

```
1. 잘 만든 데이터 지면을 **하나** 고른다 (FT · Bloomberg · Our World in Data)
2. 베끼지 말고 **잰다** — 글줄, 여백, 색 몇 개, 굵기 몇 단계, **활자 몇 종**
3. 우리 지면을 같은 자로 재고 **숫자 차이를 적는다**   4. **하나만** 고치고 다시 잰다
```

# 7. 한 장으로

## 전략 (이것부터) — **판정 기준은 「그래서 돈이 되는가」**

```
Ⅰ  파는 것은 **조인**이다. 안 붙는 데이터는 창고 비용이다
Ⅱ  **한 번 모아 네 곳에** 판다. 수집기는 한 매체만 보고 설계하지 않는다
Ⅲ  **결정론이 해자**다. 판정을 LLM 에 넘기는 순간 해자가 사라진다
Ⅳ  사람을 안 거치는 것이 **비용 우위**다. 「사람이 붙어야 한다」면 자동화 방법을 찾는다
Ⅴ  **검증이 곧 영업**이다. 5장은 품질관리가 아니라 **상품 사양서**다
Ⅵ  무료 발행은 **카탈로그**다. 기사가 **무엇을 가리키는지** 정하고 쓴다
Ⅶ  ⭐ **「물건이 없다」와 「살 사람이 없다」를 구분한다.**
    물건이 된 것은 **더 만들지 말고 팔러 간다.** 우리에게 제일 부족한 것은 **첫 결제**다
```

## 방법 (전략을 굴리는 법)

```
①  나눌 수 있는 일은 나란히. **고치는 사람은 하나.**
②  검증하는 쪽은 만드는 쪽과 **독립.** 타협하지 않는다.
③  시작 전에 **「끝」의 정의**를 적는다. 배포가 아니라 200 이고 눈으로 본 것.
④  규칙은 **파일**에 남기고, **실제로 걸렸는지 기계로 센다.**
⑤  2번째면 스크립트, 3번째면 예약. **단 예약 전에 정상 3건·예외 1건을 통과시킨다.**
⑥  자동화에는 **안전장치를 함께** — 임시파일·이어받기·손실 카운터.
⑦  **검사도 틀린다.** 일부러 틀리게 넣어 **실제로 실패하는지** 본다.
⑧  내가 쟀다는 것이 근거가 아니다. **무엇으로 쟀는지**가 근거다.
⑨  **넘겨받은 좌표도 내 환경에서 다시 맞춘다.** 「믿어도 된다」는 남의 판단이다.
⑩  고치는 것보다 **못 만들게 하는 것**이 오래 간다.
⑪  모든 비율에 **분모**를 적는다. 독자가 틀리게 읽으면 우리가 거짓말한 것이다.
⑫  디자인은 눈대중하지 않는다. **렌더하고, 재고, 하나씩.** 인쇄는 **반드시 PDF 로.**
⑬  이 전부는 **상품을 위한 것**이다. 못 파는 데이터는 정지작업조차 아니다.
```

> 편집자 자리에만 있으면 제 사고가 문서에 안 들어갑니다. 이틀치에서 뽑았습니다.

### ⓐ 【5-2 에 보탬】 **내가 「재현했다」고 말한 것이 남의 오류를 굳혔다**

3번이 5-2 에 적은 그 건의 **반대편이 저입니다.** 3번은 진단을 냈고, 저는 그걸 받아
「재현했습니다, 진단이 정확합니다」라고 **확인해 줬습니다.** 그 확인 때문에 3번은
자기 진단을 의심할 이유가 없어졌습니다.

```
남의 진단을 검증할 때 **그 사람이 쓴 도구를 그대로 쓰면 검증이 아니다.**
반드시 **다른 경로**로 잰다. 같은 도구로 재고 「재현됐다」고 말하면 오류를 굳힌다.
```

→ 5-2 에 이 한 줄을 더하면 좋겠습니다. 지금 문장은 「둘이 함께 틀렸다」까지만 있습니다.

### ⓑ 【5장에 신설 제안】 **그럴듯한 인과를 세 번 말했고 세 번 다 틀렸습니다**

하루에 셋입니다. 공통점이 하나입니다 — **말이 되니까 거기서 멈췄습니다.**

```
① 축 분류        「달러선물이니 fx」  → 실제로는 정반대로 분류돼 있었다 (세 번 만에 고침)
② ETF 괴리       「기초시장이 닫혀서」 → **미국도 닫혀 있는데 정상**이었다. 가설이 죽었다
③ 본문 줄 길이    「110~124글자로 넓다」 → 좁혀 재니 **65~71로 이미 정상**이었다
```

②를 죽인 것은 **대조군 하나**였습니다. 미국을 재는 데 **40초** 걸렸습니다.

```
인과를 말하기 전에 **그 설명이 틀렸다면 무엇이 달라야 하는지**를 적고, 그것부터 잰다.
대조군 없이 말한 원인은 **의견**이지 발견이 아니다.
```

### ⓒ 【4-2 에 보탬】 **안전장치를 만들고 그 안전장치는 안 쟀습니다**

「없어진 값 카운터」를 만들어 42건을 잡았습니다. 좋았습니다. 그런데 **그 카운터가
제대로 도는지는 안 봤습니다** — 1번 ①의 「검사가 헛도는지 확인」을 제가 안 한 겁니다.

```
안전장치도 **일부러 틀리게 해서 실제로 걸리는지** 본다. 안 그러면 「카운터가 0이라 안전하다」가
「카운터가 고장나서 0」과 구별되지 않는다.
```

### ⓓ 【4-2 에 보탬】 **완료 판정을 행 수로 세서 두 번 오판했습니다**

```
「3,034 / 2,921 받았으니 끝」  →  실제 고유 회사는 **2,334**. 중복 700
백그라운드가 죽어 본 파일이 **두 번 비었다**. `.bak` 이 없었으면 상품 데이터를 날렸다
```

**세는 단위를 틀리면 「끝났다」가 거짓이 됩니다.** 행이 아니라 **고유 키**로 셉니다.

### ⓔ 【0-2 에 보탬】 **앞 세션이 이유까지 적어 둔 결정을 안 읽고 뒤집을 뻔했습니다**

영문명 커버리지를 98.0% → 99.56% 로 올릴 수 있어 올렸습니다. 그런데
`/v1/meta` 에 **이미 이용자에게 공개한 문장**이 있었습니다 —
*"a 2014 report on Daewoo Shipbuilding is not relabelled with the 2026 corporate name"*.
코드 주석에도 앞 세션이 같은 판단을 **이유까지 적어** 뒀습니다. 되돌렸습니다.

```
**공개한 명세는 약속이다.** 지표를 올리려고 조용히 바꾸지 않는다.
바꾸려면 **별도 필드로 내고 명세를 갱신**한다.
그리고 **고치기 전에 그 자리에 왜 그렇게 돼 있는지부터 읽는다.**
```

### ⓕ 【제안】 이 문서에서 **뺄 것 하나**

**2장(일을 굴리는 다섯)은 지금 우리에게 안 쓰입니다.** 원문 명령을 표로 옮겼을 뿐이고,
실제로 우리가 쓰는 건 2-1(「끝」의 정의)뿐입니다.

→ **표를 지우고 2-1 만 3장 앞으로 올리자**고 제안합니다. 문서가 짧아야 읽힙니다
(사장님: 「너무 길게는 하지 마라」). 반대 있으면 남겨 주십시오.
