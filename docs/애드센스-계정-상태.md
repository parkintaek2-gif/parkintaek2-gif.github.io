# 애드센스 — **기존 계정에 붙이면 안 된다** (2026-08-05 실측)

> ⚠ **이 문서를 안 읽고 애드센스를 붙이려 하면 헛일을 한다.**
> 저(2번)도 오늘 「계정이 이미 있으니 유리하다」고 사장님께 말씀드렸다가 **뒤집었다.**

---

## Ⅰ. 무엇을 알아냈나

### 1-1. 기존 계정에 **광고 게재 제한**이 걸려 있다

```
게시자 ID   pub-5113515144381167
붙어 있는 곳 a.intellitv.net(69편) · 2023.intellitv.net(289편) · korea.intellitv.net(49편)
            ads.txt 200 으로 실제 서빙 중

2025-08-15  Google AdSense → parkintaek2@gmail.com
            「게시자님의 애드센스 계정에 **광고 게재 제한**이 적용되었습니다」

사장님 증언  「한 달에 100달러는 들어왔는데, 아무것도 안 해도.
             구글이 뭐라고 하더니 완전히 이렇게 됨」
```

**「광고 게재 제한(Ad Serving Limit)」은 계정 정지가 아니다.** 구글이 무효 트래픽을
의심할 때 **광고 노출 수 자체를 줄인다.** 광고는 나가는데 아주 적게 나가서 수익이 0에 가까워진다.
기간이 명시되지 않고, 트래픽 품질이 정상으로 판단되면 자동 해제된다. **1년 가까이 걸려 있다.**

### 1-2. 🔴 제한은 **사이트가 아니라 계정 단위**다

```
그 계정에 seoulmarkets.com 을 추가한다
  → 심사를 통과해도 **같은 제한을 그대로 물려받는다**
  → 광고가 거의 안 나간다. 승인받은 의미가 없다
```

**그래서 그 계정은 자산이 아니라 부채다.**

### 1-3. 콘솔에 못 들어간다

```
adsense.google.com/u/0/home
  parkintaek2@gmail.com        「액세스 권한이 없습니다」
  intelligentsiatv@gmail.com   「액세스 권한이 없습니다」
  user109@cloud4.co.kr         「액세스 권한이 없습니다」
adsense.google.com/start/      「로그인」·「가입하기」 버튼 — 구글이 「애드센스 안 쓰는 사람」으로 본다
Gmail 앱 메뉴                   애드센스 아이콘 **없음** (사장님 확인)
```

**메일은 parkintaek2 로 정상 수신된다**(2026-07-06 마케팅 메일). 계정은 존재하는데 콘솔만 막혔다.
왜인지는 **못 쟀다.** 들어가는 방법을 찾는 데 며칠 쓸 값이 없다고 판단했다.

## Ⅱ. 그래서 어떻게 하나 — **법인 명의로 새로 만든다**

```
① 상호 변경등기 완료           2026-08-05 신청 · 8/8~8/12 예상   ← 여기가 먼저다
② 워크스페이스 대표 계정 생성   예: admin@seoulmarkets.com
③ 그 계정으로 애드센스 신규 신청 수취인 = **주식회사 K라이프디자인**
④ seoulmarkets.com 부터 심사    3~14일
⑤ 통과하면 `ADS.client` 에 한 줄  작업 1분. 코드는 이미 다 있다
```

### 2-1. 왜 개인 계정으로 다시 안 만드나

```
· 같은 구글 계정에 애드센스 계정 둘은 안 된다
· 제한 이력이 붙은 계정과 엮이면 새 계정도 같이 본다
· 어차피 세 사이트는 법인 소유다. 인터넷신문 등록도 법인 명의다
· **수취인 이름이 법인으로 일치해야 지급이 깨끗하다**
```

### 2-2. 왜 상호 변경을 기다리나 (사장님 지시 「상호명 바뀌면 하자」)

애드센스 수취인 변경은 **세금 정보를 다시 내는** 절차다. 옛 상호로 만들면 두 번 일한다.

## Ⅲ. ⚠ 8/15 오픈에 광고는 **없을 것이다. 그래도 된다**

```
산수    등기 완료 8/12 + 심사 3~14일 = 빨라야 8/15, 늦으면 8/26
```

**실질 손실이 거의 없다.**
```
· 오픈 직후 트래픽은 0 에 가깝다.
  서울마켓은 7/31 발행 시작 → **구글 첫 크롤이 8/5** 였고 검색 유입은 아직 0 이다
· 독자가 없는데 광고를 붙여도 수익은 0 이다
· 우리 매출 계획에서 광고는 본체가 아니다 — 돈은 **B2B 데이터 판매**에서 난다
```

**지급은 더 뒤다** — $10 도달 → 주소확인 PIN 우편(2~4주) → $100 도달 시 첫 지급.
**8월 안에 돈이 들어올 일은 없다.** 광고를 붙이는 것과 돈이 도는 것은 다른 일이다.

## Ⅳ. 그 대신 지금 해야 하는 것 — **콘텐츠 편수**

애드센스 심사는 **분량과 독창성**을 본다.

```
서울마켓  기사 15건 (2026-08-05)
```

**15건으로 통과할지 못 쟀다** — 우리가 신청해 본 적이 없다.
등기가 끝나 신청할 때 분량이 모자라면 **반려되고 재신청은 더 오래 걸린다.**

**6번·5번에게 「오픈까지 기사 편수」를 우선순위로 내렸다.** 오픈 준비이자 심사 준비다.
