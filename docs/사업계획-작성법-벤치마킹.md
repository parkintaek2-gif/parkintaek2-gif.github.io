# 사업계획 작성법 — **글로벌 기업 문서 셋을 받아서 뜯었습니다**

> 사장님(2026-08-09): 「사업계획 사업전략 작성법부터 배워 적용」
> 「어떤 내용을 넣어야 하는지 **글로벌 기업의 사업계획과 전략 문서를 확보해서 벤치마킹**해」
> **「다른 기업걸 보라고. 만들기 전에」**

⛔ 짐작으로 틀을 만들지 않았습니다. **원문을 내려받아 읽고 적었습니다.**

```
받은 것 (SEC EDGAR 원문)
  Snowflake S-1 (2020)  4.6MB   ← 데이터 플랫폼 · 셀프서브 · 종량제. **우리와 제일 가깝습니다**
  Palantir S-1  (2020)  3.1MB   ← 데이터·분석 · 기관 고객
  Airbnb S-1    (2020)  5.2MB   ← 소비자 · 코호트를 제일 잘 씁니다
```

---

# 1. 🔴 제일 큰 차이 — **지표가 「우리가 만든 것」이 아니라 「손님이 한 것」입니다**

| | 우리가 쓰는 지표 | 그들이 쓰는 지표 |
|---|---|---|
| | 지면 4,967장 | 고객 수 (948 → 3,117) |
| | 기사 60편 | **재구매율 158%** |
| | 카드 369벌 | 큰 고객 수 (14 → 56) |
| | 검사 65개 | 남은 계약액 ($128M → $688M) |

🔴 **우리 지표는 전부 우리 노동량입니다. 하나도 손님 것이 아닙니다.**
⛔ 그래서 하루 종일 일해도 「팔렸나」를 못 봅니다.

## Snowflake 가 실제로 낸 지표는 다섯입니다 (원문 그대로)

```
Product revenue                                        $95.7M → $252.2M
Remaining performance obligations                      $128.0M → $688.2M
Total customers                                        948 → 2,392 → 3,117
🔴 Net revenue retention rate                          180% → 169% → 223% → **158%**
Customers with trailing 12-month product revenue >$1M  14 → 41 → 22 → **56**
```

### 🔴 **Net revenue retention** — 우리 계획에 이 개념이 아예 없습니다

```
뜻   **작년에 산 고객이 올해 얼마나 더 썼나**
158% = 새 고객을 한 명도 안 받아도 매출이 **1.58배**가 된다는 뜻입니다
```

⭐ **이것이 셀프서브 회사가 사람 없이 곱해지는 심장입니다.**
⭐ 그리고 3번이 8/8 에 쓴 **「같은 사람에게 40년 판다」**가 사실 이것입니다 — **이름만 없었습니다.**

⛔ 우리 계획은 전부 **「새 손님을 몇 명 모으나」**입니다. **「있는 손님이 더 쓰나」**가 한 줄도 없습니다.

---

# 2. 시장 규모 — **한 문장으로 못 박습니다. 그리고 TAM 입니다**

```
Snowflake  「our addressable market opportunity … is approximately **$81 billion**」
Palantir   「total addressable market … approximately **$119 billion**」
```

⛔ 우리는 이렇게 셌습니다 — 「기관 3,324곳 × 300만원 = **99.7억**」.
🔴 **그건 TAM 이 아니라 SOM(우리가 딸 몫)입니다.** 셋을 안 갈랐습니다.

```
TAM  이 문제에 세상이 쓰는 돈 전부
SAM  그중 우리가 닿을 수 있는 곳 (말·나라·채널이 맞는 곳)
SOM  그중 5년 안에 우리가 실제로 딸 몫
```
⛔ TAM 을 안 적고 SOM 만 적으면 **「시장이 작다」로 보입니다.** 오늘 천장 셋이 다 그랬습니다.

---

# 3. 성장 전략 — **산문이 아니라 불릿 여섯입니다**

Snowflake 원문 그대로 —
```
· innovate and advance our platform
· drive growth by **acquiring new customers**
· drive **increased usage within our existing customer base**   ← 🔴 우리에게 없는 축
· expand our global footprint
· expand data sharing across our global ecosystem
· grow and invest in our partner network                        ← 🔴 「남의 판매망」이 여기입니다
```
⭐ **여섯 줄이 전부입니다.** 설명은 뒤에 붙입니다.
⛔ 우리 계획서는 서술로 흐릅니다. **불릿으로 못 박으면 빠진 축이 눈에 보입니다.**

---

# 4. 코호트 — **「몇 명 모았나」가 아니라 「그들이 남았나」**

Airbnb 원문 —
```
「a group of hosts whose first guest check-in occurs in a specific calendar year」
그 묶음의 **해마다 남은 매출**을 그림으로 보여 줍니다
```
⛔ 우리는 **「2027 에 8,502명」**이라고만 적었습니다.
🔴 **그 8,502명이 2028 에 몇 명 남는지를 한 번도 안 적었습니다.**
   ⛔ 이탈률이 없으면 2031 의 21만 명은 **매년 새로 모아야 하는 수**가 됩니다. 전혀 다른 사업입니다.

---

# 5. ⚠ 위험을 **앞에 크게** 씁니다

```
S-1 은 「Risk Factors」가 요약 바로 다음, 수십 쪽입니다
Snowflake: 「Investing in our Class A common stock involves substantial risk」
```
⛔ 우리는 「틀릴 수 있는 자리」를 **맨 뒤에 작게** 적었습니다. 앞으로 올립니다.

---

# 6. 🔴 우리 방안이 이 벤치마킹으로 **틀린 것이 하나 드러났습니다**

```
제가 어젯밤 적음   「데이터·API 650억 = **1,300곳 × 연 5,000만원**」
```
⛔ 이건 **구독 꼴**입니다. Snowflake 는 그렇게 안 씁니다 — **종량제(consumption)** 입니다.

```
구독 꼴   고객 수 × 정해진 값     → 재구매율이 100% 를 못 넘습니다 (이탈만 있습니다)
종량제    고객 수 × **쓴 만큼**    → ⭐ **재구매율 158%.** 고객이 늘지 않아도 매출이 큽니다
```
🔴 **1,000억을 5년에 가려면 종량제라야 합니다.** 구독 꼴로는 고객 수를 계속 늘려야 하고,
   영업이 없는 우리에게 그건 안 됩니다.

⭐ **방안을 고칩니다** — 데이터·API 를 **건당·호출당·용량당**으로 팝니다.
   ⛔ 「연 5,000만원 라이선스」로 적었던 것을 거둡니다.

---

# 7. ⭐ 그래서 새 틀 — **여덟 절**

```
① 우리의 사명 한 줄            (Our Mission)
② 문제 — 지금 무엇이 안 되나
③ 우리 해법 · 왜 우리만 되나   (Our Solution · Competitive Strengths)
④ 시장 — **TAM / SAM / SOM 셋을 갈라** 한 문장씩
⑤ 사업 모델 — 🔴 **누가 · 무엇에 · 어떻게 값을 내나 (종량제인가 구독인가)**
⑥ 손님 지표 — ⛔ 우리 노동량 말고. 아래 다섯 중 우리가 잴 수 있는 것
      고객 수 · **재구매율** · 큰 고객 수 · 남은 계약액 · 코호트 잔존
⑦ 성장 전략 — **불릿 여섯.** ⛔ 산문 금지. 「기존 고객 사용 증가」 축을 반드시 넣을 것
⑧ ⚠ 위험 — **앞쪽에.** 무엇이 틀리면 이 계획이 무너지나
```

⛔ 각 자리는 **이 여덟 절로** 다시 씁니다. 어젯밤 드린 여섯 절은 거둡니다.
