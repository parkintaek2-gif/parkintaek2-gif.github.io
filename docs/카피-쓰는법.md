# 카피 쓰는 법 — **이 느낌을 그대로 살린다**

사장님(2026-08-07): 「네가 만드는 카피가 너무 좋아」 · 「**이 느낌을 그대로 살려**」

느낌은 취향이 아니라 **규칙**이다. 규칙으로 적어 두지 않으면 다음 장에서 흐려진다.
아래는 사장님이 좋다고 하신 카드에서 **실제로 쓴 것**만 뽑은 것이다.

---

## 1. 제목은 사람의 말, 숫자는 그 밑으로

```
✅ 서른둘에 사람들은            ← 제목
   결혼했을까요, 아직일까요      ← 부제
   (숫자 52.5% · 47.5% 는 그림에 있다)

⛔ 32세 초혼 비율 52.5%
```
**제목에 숫자를 넣지 않는다.** 숫자는 그림과 부제가 진다.
제목이 하는 일은 **읽는 사람을 그 자리에 세우는 것**이다.

## 2. 묻고, 답은 그림이 한다

```
✅ 서른둘에 사람들은 / 결혼했을까요, 아직일까요
✅ 아이가 태어난 해에 육아휴직을 쓴 사람 / 엄마 일곱에 아빠 하나
```
물음표를 쓰지 않아도 물음이 된다. **답을 제목에 다 적으면 볼 이유가 없다.**

## 3. 사람이 세는 말로 센다

```
✅ 엄마 일곱에 아빠 하나          ⛔ 육아휴직 사용률 72.2% 대 10.2%
✅ 예순에 스물다섯으로 돌아옵니다   ⛔ 60세 이상 평균임금이 25~29세와 유사
✅ 꼭대기는 마흔다섯에서 마흔아홉   ⛔ 임금 정점 연령대는 45~49세
```
**한자어를 우리말로 바꾼다.** 정점→꼭대기, 유사→같은 자리, 연령대→나이.

## 4. 뒤집는 사실을 앞에 둔다

사람이 이미 아는 것을 다시 말하지 않는다. **아는 것과 어긋나는 것**을 앞에 둔다.

```
✅ 예순에 스물다섯으로 돌아옵니다     월급은 오르기만 한다고 생각한다
✅ 일본은 준 적이 없습니다           K팝이 일본을 벗어났다고 알고 있다
✅ 꼭대기는 아티팩트입니다           1인당 시총이 높으면 좋은 회사라고 읽는다
```

## 5. 판단하지 않는다 — 이게 마지막이자 제일 중요하다

```
⛔ 늦었습니다 · 서두르세요 · 지금이 적기입니다 · ~해야 합니다
✅ 이것은 통계이지 당신이 아닙니다
✅ 늦었다거나 이르다고 말하지 않겠습니다. 우리가 정할 자격이 없습니다
✅ 어느 나이에도 사람이 있습니다
```
카드는 짧아서 **규범으로 읽히기 더 쉽다.** 그래서 카드뉴스 마지막 장에
「이것은 통계이지 당신이 아닙니다」가 없으면 **굽지 못하게 검사로 막아 두었다.**

## 6. 짧게, 그러나 줄이려고 뜻을 버리지 않는다

```
제목    한 줄 또는 두 줄. 열두 자 안팎이 가장 크게 나온다
부제    한 문장. 숫자와 단서(어느 띠에서 잰 값인지)가 여기 온다
```
⚠ 길면 글자가 작아진다 — 도구가 자동으로 줄인다. **줄어들면 그 카피가 긴 것이다.**

## 7. 영문은 번역이 아니라 다시 쓴다

```
✅ The top of the list is an artifact
✅ Japan never shrank
```
한국어 카피를 옮기지 않는다. **영문 독자가 아는 것과 어긋나는 지점**을 다시 찾는다.

---

## 이 규칙이 지켜지는지 무엇이 보나

```
scripts/make-cards.mjs   그림 없는 카드를 굽지 못한다 · 차이가 작으면 배지를 안 붙인다
scripts/make-reels.mjs   마지막 장에 「통계이지 당신이 아닙니다」가 없으면 굽지 못한다
scripts/check-korean.mjs 금액 단위(억원)·사물에 사람 말
```
⚠ 나머지는 아직 사람 눈이다. **새로 겪은 것은 여기 예로 더한다** — 규칙을 늘리기 전에 예를 늘린다.
