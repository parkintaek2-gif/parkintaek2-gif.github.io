## Ⅱ. 브랜드 — SeoulMarkets → **S마켓츠**

> 사장님: 「어느 정도 만들었으면 우리 브랜드는 서울마켓츠에서 **S마켓츠**로 바꾼다.
>  **S로 시작하는 관련 단어를 생각해서 회사소개할 때 추가해라.
>  단순히 stock 한 개만 잡지 말라는 뜻이야**」

### Ⅱ-1. 🔴 S 는 «우리가 여는 시장»의 첫 글자다 — 이게 이야기의 뼈대다

```
Seoul · Shanghai · Shenzhen · Singapore · Saudi
```

⭐ 다섯이 다 S 다. **「서울」에서 출발해 S 들로 넓어진다**는 이야기가 저절로 선다.
  이름을 줄이는 것이 아니라 **넓히는** 것이 된다 — 사장님 말씀의 핵심이 여기에 맞는다.

### Ⅱ-2. S 는 «우리가 파는 것»의 첫 글자이기도 하다

```
Statements     재무제표 — 주력이다. 맨 앞에 둔다
Standards      같은 규격으로 여러 나라. 한 번 붙이면 나라가 늘어난다 (구매 사유 그 자체)
Shareholders   대주주 · 지분 이동
Stakes         지분
Succession     지배권·CEO 변경   ← 사장님이 짚으신 「주인·CEO 가 바뀔 때」가 이 단어다
Stewardship    지배구조
Securities     증권 일반
Structured     정형화된 자료 (덩어리가 아니라 표로)
Sources        출처를 반드시 밝힌다 (우리 강령)
Sukuk          걸프 이슬람 채권 — UAE·사우디에서 바로 쓰인다
```

⛔ **쓰지 않는 S**
```
Signals        「매매신호를 팔지 않는다」와 정면으로 부딪힌다. 투자자문 아님 고지와도 충돌
Speculation    같은 까닭
Stock «만»     사장님이 금지하신 것 — 주식 하나로 좁히지 않는다
```

### Ⅱ-3. 언제 바꾸나 — 「어느 정도 만들었으면」의 기준을 이렇게 잡는다

```
바꾸는 조건   시장 «셋» 이 쓸 수 있게 차면 바꾼다 — 한국 · UAE · 중국(홍콩 포함)
              「쓸 수 있게」란 재무제표와 공시가 그 시장 전수로 서 있는 것이다
지금          한국 ✅ · UAE ▶(오늘) · 중국·홍콩 ⬜
⇒ 중국·홍콩이 붙는 날이 브랜드를 바꾸는 날이다
```

⚠ 도메인 `seoulmarkets.com` 은 **그대로 둔다.** 이름만 바꾸고 주소를 바꾸면
  지금까지 쌓은 검색 색인을 통째로 잃는다. 브랜드 표기와 도메인은 다른 문제다.

### Ⅱ-4. 회사소개에 들어갈 꼴 (초안)

> We compile what listed companies file — **statements, shareholders, succession** —
