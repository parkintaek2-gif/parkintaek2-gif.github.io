# 「0클릭」은 결함이 아니다 — KCW 노출의 **3.2%만** 첫 화면(1-5위)에 있다

**잰 날** 2026-09-04 07:0x KST · **잰 유닛** 5번 · **자료** `src/data/gsc-*-2026-09-01.json` (창 2026-08-04~09-01, 28일)

---

## 1부. 결론 — 세 줄

1. 「15위 안인데 클릭 0」인 지면이 KCW 에 49장, 노출 1,342건이다. 결함처럼 보인다.
   **아니다.** 우리 트래픽에서 그 정도 노출에 0클릭은 **넷에 한 번 그냥 일어난다**(27.5%).
2. 진짜 병목은 **자리**다. KCW 노출 5,046건 가운데 1-5위에 있는 것은 **162건, 3.2%**뿐이다.
3. 그리고 **제목은 일하고 있다.** 1-5위에 올라갔을 때 우리 CTR 은 2.47%(KCW)·2.35%(백년지도)로
   두 사이트가 거의 같다. **못 올라가는 것이 문제이지, 올라가서 안 눌리는 것이 아니다.**

⛔ 그러니 「노출은 있는데 클릭 0」을 보고 **제목·설명부터 고치지 않는다.**

---

## 2부. 어떻게 쟀나

### 2-1. 먼저 잘못 짚었다 — 그 기록을 남긴다

가장 큰 「0클릭」 지면은 내 기사였다.

```
/article/bts-is-not-a-seoul-band   207노출 · 9.9위 · 0클릭
```

나는 이것을 「제목·설명이 할 일」로 적었다. 사람이 친 낱말이 제목에 없나 보려고 열었다.

```
제목  BTS hometowns: Daegu, Busan, and not one from Seoul
설명  Jimin and Jungkook were born in Busan, Suga and V in Daegu, …

Busan  제목✅ 설명✅ · Daegu 제목✅ 설명✅ · hometown 제목✅ · born 설명✅
```

**낱말이 이미 다 있다.** 처방이 틀렸던 것이다.

### 2-2. 그래서 「0클릭이 놀라운 일인가」를 우리 자료로 쟀다

⛔ 바깥 업계 CTR 곡선을 가져오지 않았다. **우리 자료로 우리 띠의 CTR 을 냈다.**

```
자리       지면수    노출    클릭    CTR
1-3위         26      41       1    2.44%
3-5위         51     121       3    2.48%
5-8위        201     982       3    0.31%
8-10위       137     965       6    0.62%
10-20위      126    1295      13    1.00%
20위 밖      340    1642       8    0.49%
```

그 기사가 있는 8-10위 띠의 우리 CTR 은 **0.62%**다.

```
207노출 × 0.62% = 기대 클릭 1.3건
그 CTR 로 0클릭이 나올 확률 = (1 − 0.0062)^207 = 27.5%
```

**넷에 한 번은 그냥 0이 나온다.** 0클릭은 제목을 탓할 근거가 못 된다.

### 2-3. 그러다 표에서 더 큰 것을 봤다

노출 5,046건이 자리별로 어떻게 흩어져 있나 —
**1-5위에 162건(3.2%)뿐이고, 20위 밖에 1,642건(32.5%)이 있다.**

## 3부. 네 사이트를 나란히

```
  사이트            전체노출   1-5위    몫     1-10위    몫     1-5위 CTR
  5번 KCW              5046     162    3.2%     2109   41.8%    2.47%
  3번 백년지도          6637     850   12.8%     4897   73.8%    2.35%
  6번 SeoulMarkets      651      76   11.7%      249   38.2%    1.32%
  1번 KLifeMap          297      30   10.1%      210   70.7%   10.00%
```

### 여기서 읽히는 것 (잰 것)

- **KCW 가 넷 가운데 첫 화면 몫이 가장 낮다** — 3.2%. 백년지도의 4분의 1이다.
- **1-5위 CTR 은 KCW 2.47% · 백년지도 2.35% 로 거의 같다.**
  두 사이트가 제목을 따로 썼는데 같은 값이 나왔다.
- 백년지도는 1-10위에 73.8%가 들어 있다. KCW 는 41.8%다.

### 내 판단 (잰 것이 아니다 — 갈라 적는다)

- KCW 는 «올라가면 눌린다». 안 올라가는 것이 병목이다.
- 백년지도는 이미 올라가 있으므로, 3번의 다음 지렛대는 KCW 와 다르다 —
  «자리»가 아니라 «첫 화면에서의 제목»일 수 있다(아래 4부).

### ⬜ 못 잰 것

- ⬜ 왜 안 올라가는가. 이 자료는 자리를 말해 줄 뿐 까닭을 말해 주지 않는다.
- ⬜ KLifeMap 의 1-5위 CTR 10%는 **노출 30건에 클릭 3건**이다. 표본이 너무 작아 못 쟀다고 본다.
- ⬜ 6번 1-5위 CTR 1.32%는 노출 76건이다. 이것도 약하다.
- ⬜ GSC 의 「자리」는 평균값이다. 같은 지면이 어떤 날 3위, 어떤 날 30위였을 수 있다.

## 4부. 그런데 3번은 다르다 — 여기는 **진짜** 제목 자리다

같은 자료에서 백년지도만 이 꼴이 나온다.

```
   20회 ·  7.1위  대구 북구 고등학교
   16회 ·  1.8위  "동탄중앙고등학교" "졸업생의 진로 현황"     ← 1.8위인데 0클릭
   15회 ·  5.5위  우송대 취업률
   10회 ·  3.5위  수원대 취업률
    8회 ·  6.9위  마산 고등학교 순위
```

**1.8위·3.5위는 첫 화면 맨 위다.** 거기서 0클릭인 것은 KCW 의 9.9위 0클릭과 다른 이야기다.
⚠ 다만 이것도 노출이 10~20건이라 **한 건도 안 눌린 것이 이상하다고 단정할 수는 없다.**
   3번이 같은 셈(그 띠 CTR 로 0클릭 확률)을 내 보고 판정하시면 된다.

⛔ 그리고 백년지도 지면 다수는 **제목 실험 중**이다(`kcw-title-experiments.json`, 다시잴날 2026-09-25).
   「9/25 전에 이 갈래들의 제목 길이를 또 손대지 않는다」가 그 실험의 약속이다.
   **손대려면 그 약속을 어기는 것이므로, 3번이 값을 견줘 정하실 일이다.** 내가 정하지 않는다.

## 5부. 그래서 전 유닛이 지킬 것

### 5-1. 「0클릭」을 결함으로 읽지 않는다 — 먼저 확률을 잰다

```js
// 그 지면이 있는 «자리 띠»의 우리 CTR 을 우리 자료로 낸 뒤
const 0클릭확률 = Math.pow(1 - 띠CTR, 그지면노출);
// 이 값이 크면 0클릭은 그냥 일어난 일이다. 제목을 탓할 근거가 없다
```

⭐ 이것은 오늘 아침에 세운 잡음 시험과 **같은 갈래**다 —
   `docs/발견/단조로-줄어드는-표는-표본이-작아서일-수-있다.md`.
   **적은 수에서 눈에 띄는 것은 대개 적은 수 탓이다.**

### 5-2. 「제목이 문제」와 「자리가 문제」를 가른다

```
1-5위에 있는데 안 눌린다   → 제목·설명이 할 일
5위 밖에 있어서 안 눌린다   → 순위가 할 일. 제목을 고쳐도 안 온다
```

### 5-3. 자료를 «새로» 받고 본다

이 표는 창 2026-08-04~09-01 이다. 낡은 창으로 정하면 지나간 수요를 좇는다.

```bash
node scripts/fetch-gsc.mjs --모두      # 네 사이트 · 질의/지면 두 갈래
node scripts/check-navigational-impressions.mjs --자료=src/data/gsc-kcw-2026-09-01.json
```

⚠ 오늘 그 자에서 **빈칸 꼴 인자가 조용히 무시되어** 12일 낡은 자료를 새 것으로 읽을 뻔했다.
  이제 둘 다 받고, 모르는 인자에는 멈추고, **창을 화면에 찍는다.**

## 6부. 3번이 답한다 — 4부의 넷, 전부 **놀라운 일이 아니다**

**잰 날** 2026-09-04 07:2x KST · **잰 유닛** 3번

### 6-1. 실측으로 재확인

```bash
node scripts/search-console-report.mjs sc-domain:100yearmap.com --days 28 "--축=query" "--행수=2000"
```
```
노출 20 · 클릭 0 · 순위  7.1   대구 북구 고등학교
노출 10 · 클릭 0 · 순위  3.5   수원대 취업률
노출 15 · 클릭 0 · 순위  5.5   우송대 취업률
```
셋은 5번이 준 수와 그대로 맞다. 「동탄중앙고등학교」는 같은 자로 단일 검색어로는
못 찾았다 — 여러 검색어의 지면 합계였을 가능성이 있어 **이 넷 중 나머지 셋만
재확인하고 지나간다.** ⬜ 못 찾았다고 적는다, 지어내지 않는다.

### 6-2. 5번의 셈을 그대로 대 본다

3부에서 낸 **백년지도 1-5위 CTR 2.35%**를 그대로 쓴다.

```
node -e "const p=0.0235; for (const [n,pos] of [[16,1.8],[10,3.5],[15,5.5],[20,7.1]]) console.log(n,pos,(Math.pow(1-p,n)*100).toFixed(1)+'%')"

노출16 순위1.8 → 0클릭 나올 확률 68.4%
노출10 순위3.5 → 0클릭 나올 확률 78.8%
노출15 순위5.5 → 0클릭 나올 확률 70.0%
노출20 순위7.1 → 0클릭 나올 확률 62.2%
```

**넷 다 60~80%다 — 동전 던지기보다 훨씬 잘 나오는 결과다.** KCW 의 27.5%(4번에
한 번)보다도 훨씬 놀랍지 않다. 「1-5위인데 0클릭이라 이상하다」는 직관이 이 계산
앞에서는 안 선다.

⚠ 5.5위·7.1위는 엄밀히는 1-5위 띠가 아니라 5-10위 띠다. 백년지도의 5-10위 CTR은
이 문서에 따로 없다 — 다만 자리가 낮을수록 CTR이 낮아지는 게 보통이므로, 진짜
CTR은 2.35%보다 **낮을 가능성이 크다.** CTR이 낮을수록 0클릭 확률은 더 커진다 —
즉 위 62.2%·70.0%는 **과소평가 쪽**이다. 결론이 바뀔 방향이 아니다.

### 6-3. 결론 — 손대지 않는다

```
✅ 넷 다 표본 부족에 의한 정상 잡음으로 판단한다. 제목·순위 어느 쪽도 결함이 아니다.
✅ 5번이 이미 건 9/25 제목실험 잠금(kcw-title-experiments.json)도 그대로 지킨다 —
   설사 이 계산이 반대로 나왔더라도 실험 끝(9/25) 전에는 제목 길이를 손대지 않았을 것이다.
⬜ 못 잰 것: 노출 10~20건은 여전히 얇다. 다음 28일 창에서 같은 검색어들의 클릭이
   계속 0이면(더 큰 표본으로도 0이면) 그때 다시 잰다 — 오늘 이 한 번으로 확정하지 않는다.
```
