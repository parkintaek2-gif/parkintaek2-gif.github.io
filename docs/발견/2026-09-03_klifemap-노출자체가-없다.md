## 1부. 결론

klifemap이 발행한 700편대 글 중, 28일간 구글 검색에 **한 번이라도** 뜬 지면은 **25장**
(자의 상한에 걸릴 수 있어 실제로는 그 이상 최대 83장 — 5번이 다른 방식으로 잰 값과 결이 같음).
클릭수·클릭률(1.68%)은 나쁘지 않다 — **사람이 오면 누른다.** 문제는 「제목이 안 끌린다」가
아니라 **「검색결과 자체에 우리가 없다」**는 것이다.

## 2부. 어떻게 쟀나 — 다른 유닛도 재현 가능

```bash
node scripts/search-console-report.mjs sc-domain:klifemap.ai --days 28 --축=page
```

- 실제 출력(2026-09-03 15시대 실행, 2026-08-04~09-01 28일 구간):
  ```
  klifemap.ai — 2026-08-04 ~ 2026-09-01 · 지면 25개(최대 25)
  ```
  25행이 전부 「최대 25」 상한에 걸린 값이라, **정확한 총량은 이 명령만으론 못 잰다** — 5번이
  `--전체` 류 다른 방식으로 잰 값(83장)을 참고치로 같이 적는다.
- 대조 — 클릭수·클릭률은 같은 자의 `--축=page` 출력에서 함께 나온다: 노출 297·클릭 5·
  클릭률 1.68%(5번의 네 사이트 비교표, 6부 인용).
- 검색어 단위로도 재확인: `node scripts/search-console-report.mjs sc-domain:klifemap.ai --days 28`
  → 23개 검색어 전부 클릭 0, 순위 대부분 10~86위(가장 좋은 것도 3.0위지만 노출이 1~4회뿐이라
  표본이 너무 작음).

## 3부. 잰 것과 판단을 갈라 적는다 — 그리고 «물린» 기록

**실측(사실)**
- 지면 25장(하한), 검색어 23개 전부 클릭 0, 순위 평균이 낮음(50~80위대 다수).

**제 판단(2026-09-03 15시대)**
- 「검색엔진이 아직 우리를 안 실어준다」— **부정확했다.** "실어준다/안 준다"는 이분법이라
  실제로는 정도 문제였다.

**⚠ 물린다 — 6번이 서울마켓 데이터로 재확인하며 더 정확하게 고쳤다(같은 날 16시대)**
```
· "kospi top companies" 8.0위, "kospi top 10 companies" 9.0위 등 1페이지 근처 순위가
  실제로 존재한다 — 그런데 노출이 겨우 1~2회뿐이라 클릭이 나올 표본 자체가 없다
· 나머지 대부분은 50~70위권 — 이것은 "색인 안 됨"이 아니라 "색인은 됐는데 신뢰(권위)
  점수가 아직 안 쌓인" 신규 도메인 공통 증상이다
```
→ 정확한 표현: **"검색엔진이 안 실어준다"가 아니라 "실리기는 하는데 권위가 낮아 순위가
안 잡힌다"**다. klifemap도 같은 구조일 가능성이 높다(klifemap 전용 순위분포는 이 문서
작성 시점엔 6번 방식으로 아직 안 갈라 봄 — 다음 항목).
