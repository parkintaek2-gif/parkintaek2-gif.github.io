# 「네이버에 우리 사이트가 없다」는 이제 틀렸다 — 넷 다 색인에 있다

발견 2026-09-03 19:0x KST · 5번(총괄대행) · **26일 묵은 「사장님 손 · 10분」 항목을 다시 쟀다**

> `docs/사장님-손.md` (2026-08-08 자)에 이렇게 적혀 있다 —
> 「🔴 오늘 · 0. **네이버에 우리 사이트 내밀기** · 10분 · ⛔ 제가 못 하는 자리입니다」
> 그 아래 표: 「백년지도 **0건** · 서울마켓 **0건** · K Culture Wire **0건** · KLifeMap 1건」

---

## 1부. 결론

**넷 다 네이버 색인에 있다.** 2026-08-08 의 「0건」은 더 이상 사실이 아니다.

```
                    site: 검색 정상 웹문서   브랜드 이름으로 검색
www.kculturewire.com        12 블록          「K Culture Wire」 →  1개
seoulmarkets.com            10 블록          「SeoulMarkets」   → 17개
100yearmap.com               2 블록          「백년지도 취업률」  →  7개
klifemap.ai                  2 블록          —
```

⛔ **26일 동안 아무도 다시 재지 않았다.** 그 사이 사장님은 「🔴 오늘 10분」짜리 일을
계속 보고 계셨다. 이미 해결됐거나 저절로 된 일일 수 있는데도.

## 2부. 어떻게 쟀나

```
curl -s -A '<보통 브라우저 UA>' 'https://search.naver.com/search.naver?query=site%3A<도메인>'
```

⚠ **도메인 글자 수를 세는 것으로는 판정할 수 없다.** 첫판에 그렇게 셌더니 넷 다
7~27회로 나왔는데, 그 대부분은 **검색창에 되비친 내 질의문**이었다.

✅ 그래서 두 가지를 갈라 봤다.

```
1. 「검색결과가 없습니다」가 뜨나        → 넷 다 안 뜬다
2. 결과 링크가 «정상 웹문서 블록» 안에 있나 → 있다
   마크업으로 확인: class 에 `fds-web-normal-doc-root`
   (사이트 소개 카드가 아니라 «보통 웹문서 결과»라는 뜻이다)
3. site: 가 아니라 «사람이 실제로 치는 말»로도 나오나 → 나온다
```

3번이 특히 중요하다. `site:` 는 「색인에 있나」만 말해 주고 「사람이 찾을 때 나오나」는
말해 주지 않는다. 브랜드 이름으로 쳐 봐야 그것이 갈린다.

## 3부. 잰 것과 «제 판단»을 갈라 적는다

```
실측    넷 다 「검색결과가 없습니다」가 아니다
실측    정상 웹문서 블록 — KCW 12 · 서울마켓 10 · 백년지도 2 · klifemap 2 (첫 쪽)
실측    브랜드 이름 검색 — SeoulMarkets 17개 · 백년지도 취업률 7개 · K Culture Wire 1개
실측    잡힌 주소에 속지면이 섞여 있다 (/climb · /spread · /equities · /fx · /age · /price)
        → 첫 화면만 잡힌 것이 아니다

제 판단  「네이버 손대기의 값은 사이트마다 다르다」는 제 판단이다.
        네이버는 «한국 손님» 엔진이고, 백년지도(학부모·수험생)와 klifemap(한국 손님)은
        거기에 손님이 있다. KCW 는 사장님이 「영어뉴스 + 해외 대상」으로 못박으신 자리라
        네이버에서의 순위가 방문자에 미치는 몫이 작다.
        ⛔ 그러니 KCW 가 「K Culture Wire」로 1개뿐인 것을 급한 일로 올리지 않는다.
제 판단  백년지도·klifemap 이 «2 블록»뿐인 것이 더 아프다 — 손님이 네이버에 있는 쪽인데 얇다.

⛔ 안 말한 것  「그래서 네이버에서 방문자가 온다」고는 말하지 않는다. 유입은 GA4 로 따로 봐야 하고
              이 문서에서는 안 쟀다.
```

## 4부. ⬜ 못 쟀다

```
⬜ 몇 «장»이 색인됐나 — 네이버가 총 건수를 지면에 안 적는다. 첫 쪽 블록 수만 셌다.
   ⛔ 「12장이 색인됐다」고 적지 않는다. 「첫 쪽에 12블록」이 내가 본 전부다.
⬜ 서치어드바이저 «등록» 여부 — 사장님 네이버 계정으로 들어가는 자리라 제가 못 본다.
   ⚠ 색인에 있는 것과 등록된 것은 «다른 것»이다. 등록 없이 크롤러가 와서 잡을 수도 있다.
   그래서 이 발견은 「등록이 끝났다」는 말이 아니다.
⬜ 언제부터 잡혔나 — 8/08 과 오늘 사이 어느 날인지 모른다. 그 사이 아무도 안 쟀다.
⬜ 네이버 유입 수 — GA4 를 이 문서에서 안 봤다.
```

## 5부. 그래서 무엇을 하나

```
✅ 사장님께 알린다 — 「0건」은 지났다. 10분짜리 일이 아직 필요한지부터 다시 보셔야 한다
   ⛔ 다만 「등록이 됐다」고 말하지 않는다. 내가 잰 것은 «색인»이지 «등록»이 아니다
⬜ docs/사장님-손.md 는 2번의 파일이라 내가 고치지 않는다 — 알린다
   (남의 것이면 고치지 말고 알린다)
✅ 백년지도·klifemap 이 2블록뿐인 것을 3번·1번·4번에게 수와 함께 넘긴다
```

⭐ 이 발견의 값은 「네이버에 잡혔다」가 아니다.
**「사장님 손이 필요하다고 적어 둔 것을 26일 동안 아무도 다시 재지 않았다」**는 것이다.
오늘 같은 자리에서 이미 한 번 걸렸다 — 인계 문서의 「사장님 손」에 27일 전에 끝난 항목 셋이
살아 있었고, 그것도 같은 병이다. **적어 두면 낡는다. 낡은 것은 사장님 시간을 먹는다.**
