## 5부. 재는 법 — 다음 사람이 다시 잴 수 있게

```bash
node scripts/collect-culture-portal.mjs --재기      # 자가시험 25가지
node scripts/collect-culture-portal.mjs            # 목록 여덟 갈래를 받는다
node scripts/collect-culture-portal.mjs --pages=400 # 쪽 상한을 연다

node scripts/collect-bigdata-culture.mjs --재기     # 자가시험 18가지
node scripts/collect-bigdata-culture.mjs           # 마켓 1,344건 · 224쪽
```

### 재면서 밟은 덫 다섯 — **다음 사람은 안 밟게 적는다**

1. **광장의 쪽 칸은 `pageNo` 다.** `pageIndex`·`currentPage`·`page` 를 넣으면
   **오류 없이 1쪽을 그대로 돌려준다.** 모르고 돌리면 「다 받았다」고 믿는다.
2. **총 건수는 태그 사이에 끼어 있다** — 「총 `<span>466</span>` 건」.
   태그를 지운 «뒤의 글»에서 재야 잡힌다.
3. **화면 꼴이 갈래마다 여덟 가지로 다르다.** 파서를 하나로 두면 **0건을 받고도 성공한 척한다.**
   실제로 첫 판이 그랬다 — 「✅ 총 466건 · 받은 0건」.
4. **bigdata-culture.kr 은 HTTP 로 받으면 「총 0건」이다.** 브라우저로 열어도 **7건**만 그려진다.
   더보기가 부르는 자리(`process.ajax.do`)를 잡아야 한다. `pagePerBlock` 을 50으로 올려도
   **서버가 6건만 준다** — 224번을 부른다.
5. 🔴 **`<li>` 로 항목을 자르면 아이디를 다 잃는다.** 한 항목 안에 안쪽 `li` 가 여럿이라
   「가격」이 든 조각과 `data-id` 가 든 조각이 갈린다. **값은 다 있는데 이어 붙일 열쇠만 없어진다.**
   `data-id` 를 경계로 삼는다.

⚠ 다섯 가지 모두 **조용히 성공한 척하는 실패**다. 종료코드 0, 오류 없음, 그런데 0건.
   그래서 두 자 모두 **자가시험에 「빈 화면에서 항목을 지어내지 않는다」를 넣어 두었다.**
