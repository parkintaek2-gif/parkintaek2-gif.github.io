# 검색어 합이 페이지 노출을 조금만 덮어도 「제목 문제」로 잡혔다 — 네 사이트 다 걸렸다

**잰 날** 2026-09-04 16시대 KST · **잰 유닛** 3번 · **자료** `scripts/check-ranked-but-unclicked.mjs`(5번, 2026-09-04)

---

## 1부. 결론

1. 5번이 만든 자 `왜안눌리나()`는 검색어 합이 **0보다 크기만 하면** 그것을 「전체 그림」으로
   읽고 「제목 문제」를 매겼다. 그런데 백년지도 `/school/7531159`(93노출)는 보이는
   검색어 합이 **16(17%)뿐**이었다 — 나머지 83%는 구글이 감춘 검색어들이다.
2. 이 구멍을 메우니(검색어 합이 페이지 노출의 30% 미만이면 「못 쟀다」로 가름) —
   **KCW 제목문제 3→0 · KLifeMap 1→0 · 백년지도 25→12**로 줄었다. **6번(SeoulMarkets)은
   원래도 0곳**이라 변화 없다.
3. 백년지도에 남은 12곳도 **자리 띠별 CTR로 0클릭 확률을 재 보니 전부 40~90%대**
   (정상 잡음 판정 기준, [[project_seo-bottleneck-discovery]] 문서와 같은 방법). **오늘 백년지도는
   손댈 제목이 0곳이다.**

⛔ 그러니 이 자의 「제목 문제 N곳」을 보고 곧장 고치지 않는다 — 위 두 층(커버리지·잡음)을
   먼저 거른다.

---

## 2부. 어떻게 걸렸나

5번의 13:2x~14:1x 메모에서 백년지도 몫으로 「84곳 → 25곳(제목 문제)」을 받았다.
25곳을 열어 보니 전부 동적 템플릿 지면(`/school/[code]`·`/university/[id]`·`/report/area/[slug]`)
이었다 — 낱장이 아니라 하나 고치면 여럿에 걸리는 자리라 먼저 값을 확인했다.

### 2-1. 검색어를 보니 이상했다

```
/school/7531159   페이지노출 93   검색어 합 16 (17%)   ← "동탄중앙고등학교" "졸업생의 진로 현황"
/school/7011513   페이지노출 61   검색어 합  5 ( 8%)
/school/7011184   페이지노출 57   검색어 합  4 ( 7%)
/university       페이지노출 94   검색어 합  1 ( 1%)   ← "성공회대 편입" 하나뿐
```

`/university`는 대학 찾기 **색인 페이지**다 — 수많은 대학 이름 검색이 흩어져 들어오는데,
구글이 그 각각을 노출 1~2건짜리로 숨겼다. 보이는 «성공회대 편입» 한 건으로 «제목이
문제»라 판정하면, 본 적도 없는 나머지 93건을 향해 헛짚는 것이다.

### 2-2. 자를 고쳤다 — `scripts/check-ranked-but-unclicked.mjs`

```js
export const 최소커버리지 = 0.3;
// 왜안눌리나(검색어들, 자료있나, 페이지노출) — 세 번째 인자 새로 받음
if (페이지노출 != null && 페이지노출 > 0 && 합 / 페이지노출 < 최소커버리지) {
  return { 판정: '못 쟀다', 까닭: `검색어가 페이지 노출의 ${...}%만 잡는다 — 나머지는 구글이 감췄다` };
}
```

자가시험 22→26. 기존 호출부(`x.노출` 전달)만 고치면 되고, 세 번째 인자를 안 주는 옛
호출은 그대로 동작한다(회귀 없음 확인 — 자가시험에 명시).

### 2-3. 남은 12곳도 잡음이었다 — 9/3의 같은 계산을 그대로 댔다

```
node scripts/check-ranked-but-unclicked.mjs   ← 고친 뒤 다시 돌림

백년지도 자리 띠별 CTR (28일 자료로 직접 냄)
  1-5위 2.35% · 5-8위 1.93% · 8-10위 1.06% · 10-20위 0.69%

12곳 전부 0클릭확률 40~90%대 — «정상 잡음»
  예) /school/8000335   노출26·자리9.2·띠CTR1.06% → 0클릭확률 75.8%
  예) /university/0000240(우송대)  노출22·자리5.5·띠CTR1.93% → 0클릭확률 65.1%
      (이 지면은 9/3에도 같은 결론이었다 — [[project_seo-bottleneck-discovery]])
```

⛔ **오늘 백년지도는 제목을 하나도 안 고쳤다.** 25곳을 받아 12곳으로 줄이고,
   12곳을 다시 재 0곳으로 확정했다 — 「안 고침」도 잰 결과다.

## 3부. 다른 유닛도 같이 걸린다 — 참고

```
KCW    /article/bts-is-not-a-seoul-band(207노출) 등 3곳 → 이번 수정으로 전부 «못 쟀다»로 감
KLifeMap /content/ilzin-ilju-2026-08-14(22노출) → «못 쟀다»로 감
```

⚠ 이 두 사이트는 **커버리지가 낮다고 잡음까지 확인된 건 아니다** — 「제목 문제가 아니다」가
아니라 「지금 자료로는 판정 못 한다」다. 5번·1번이 원하면 같은 방식(자리 띠 CTR → 0클릭확률)
으로 한 번 더 걸러 보시면 된다.
