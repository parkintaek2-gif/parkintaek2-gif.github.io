# 단조로 줄어드는 표는 «표본이 작아서»일 수 있다 — 아홉 번에 한 번은 우연히 그렇게 된다

**잰 날** 2026-09-04 · **잰 유닛** 5번(K Culture Wire) · **자** `scripts/build-kcw-attention-steadiness.mjs`

---

## 1부. 결론

띠(구간)를 나눠 만든 표에서 어떤 수가 **단조로 줄거나 늘면** 규칙처럼 보인다.
그런데 띠마다 **사람 수가 다르면**, 그 단조로움이 규칙이 아니라 **표본 크기**일 수 있다.

실측 하나로 잰다 — 사람 446명인 띠에서 **106명씩 1만 번 다시 뽑았더니**,
가운데 절반의 폭이 「좁은 띠」의 값 이하로 떨어진 것이 **11.2%** 였다.
**아홉 번에 한 번은 아무 규칙 없이도 그렇게 좁아진다.**

⛔ 그러니 띠 인원이 크게 다른 표에서 「A 가 B 보다 고르다/좁다/촘촘하다」를 내기 전에
   반드시 이 시험을 돌린다. 5% 를 넘으면 **「못 쟀다」**로 적는다.

---

## 2부. 어떻게 쟀나 — 다음 사람이 다시 잴 수 있게

### 2-1. 무엇을 재다가 나왔나

넷플릭스 차트에 오른 한국 작품에 나온 배우 1,113명의, 영문 위키백과 한 달 열람수다
(`archive/raw/star-pageviews/actors-20260822.json`, 2026-07-24~08-22).
차트 출연 편수로 네 띠(1 / 2-3 / 4-6 / 7+)를 나누고, 한 달 동안 관심이 얼마나
흔들렸는지를 **가운데 절반의 폭**(75% 값 − 25% 값)으로 쟀다.

```
띠      인원    가운데 절반의 폭
1        446         0.31
2-3      362         0.27
4-6      199         0.26
7+       106         0.25      ← 네 띠가 «단조로» 줄었다
```

이 줄만 보고 「차트에 많이 나오면 관심이 고르게 된다」로 제목을 썼다. **그것이 틀렸다.**

### 2-2. 돌린 명령

```bash
node scripts/build-kcw-attention-steadiness.mjs            # 실측 + 잡음 시험
node scripts/build-kcw-attention-steadiness.mjs --자가시험   # 39개
```

### 2-3. 잡음 시험이 하는 일

**사람이 많은 띠에서, 사람이 적은 띠와 «같은 인원»을 되풀이해 뽑아 같은 수를 다시 잰다.**
그 값이 「적은 띠」의 값 이하로 떨어지는 비율을 센다.

```
띠1(446명)에서 106명씩 10,000번 다시 뽑았다 (씨앗 20260904)
  그때 폭: 중간 0.300 · 5% 0.240 · 95% 0.370
  띠7+ 폭(0.25) 이하로 떨어진 비율: 11.2%
```

⭐ **씨앗을 고정한다.** 매번 다른 수가 나오면 기사에 적은 수를 다시 못 잰다.
   ⚠ 실제로 여기서 한 번 어긋났다 — 씨앗 없이 던져 본 첫 판은 11.7%, 씨앗을 박으니 11.2% 였다.
   기사에는 **다시 잴 수 있는 11.2%** 만 적었다.

### 2-4. 그 시험이 «정말 불 수 있는지»도 시험했다

늘 통과만 하는 검사는 검사가 아니다. 세 갈래로 확인했다(자가시험에 들어 있다).

| 넣은 것 | 나와야 할 것 | 실제 |
|---|---|---|
| 같은 통을 «자기 폭»과 견줌 | 대략 반반 | 20~80% 안 |
| 터무니없이 좁은 폭(0.01)과 견줌 | 거의 안 떨어짐 | 5% 미만 |
| 터무니없이 넓은 폭(99)과 견줌 | 늘 떨어짐 | 100% |
| 같은 씨앗으로 두 번 | 같은 수 | 같음 |

## 3부. 잰 것과 판단을 갈라 적는다

### 3-1. 잰 것 (실측)

- 띠별 가운데 절반의 폭: 0.31 / 0.27 / 0.26 / 0.25 — 단조로 줄어든다
- 띠별 「크게 움직인 사람」 비율: 6.3% / 5.0% / **6.5%** / 3.8% — **단조롭지 않다. 되오른다**
- 띠1 에서 106명씩 1만 번 뽑았을 때 0.25 이하가 나온 비율: **11.2%**
- 띠별 중간값의 90% 구간: 0.96~1.00 / 1.00~1.05 / 1.00~1.05 / 1.00~1.09 — **넷이 서로 겹친다**
- 배우 1,113명 전원이 편수와 배수를 둘 다 갖고 있다 (빠진 사람 0명)

### 3-2. 판단 (내 생각)

- 폭의 단조로움은 **표본 크기로 설명할 수 있다.** 진짜 효과가 아니라고 «증명»한 것이 아니라,
  **가려낼 수 없다**는 뜻이다. 106명으로는 못 가른다
- 중간값 구간이 넷 다 겹치므로 **차트 출연 편수는 관심이 오르내리는 «방향»을 가르지 못한다**
- 어제 잰 「출연이 늘면 바닥이 7배 오른다」와 어긋나지 않는다 —
  출연은 **높이를 사고 방향은 사지 않는다**

### 3-3. ⬜ 못 잰 것

- ⬜ 「많이 출연하면 관심이 고르게 되나」 — 재 봤고 **가려낼 수 없었다.** 없다는 뜻이 아니다
- ⬜ 인과. 많이 나와서 고른지, 고른 사람이 많이 캐스팅되는지 못 가른다
- ⬜ 두 창 사이 16일. 배수는 두 7일 덩어리만 본다
- ⬜ 한국 안의 관심. 영문 위키백과만 센다

## 4부. 다른 유닛이 그대로 가져다 쓰는 법

```js
import { 잡음시험, 중간구간, 겹치나 } from '../scripts/build-kcw-attention-steadiness.mjs';

// 「적은 띠가 더 좁다」가 표본 탓인가
const r = 잡음시험(많은띠값들, 적은띠폭, 적은띠인원);
if (r.이하비율 >= 5) console.log('못 쟀다 — 표본을 줄인 것만으로 ' + r.이하비율 + '% 나온다');

// 두 띠의 중간값이 다르다고 말해도 되나
겹치나(중간구간(띠A값들), 중간구간(띠B값들))   // true 면 다르다고 말하지 않는다
```

## 5부. 내가 물린 것

이 문서는 **내가 오늘 쓰려던 제목을 내가 잰 것이 죽인 기록**이다.
「차트에 많이 나오면 관심이 고르게 된다」는 제목을 이미 썼고, 표도 만들어 두었다.
그것을 지우고 **「없었다」를 내는 기사**로 바꿨다 —
`content/kculturewire/chart-credits-buy-a-level-not-a-direction.md`.

기사 안에 **지운 제목과 지운 까닭을 그대로 실었다.** 강령이 그렇게 하라고 한다.

> 「재 보고 안 되면 안 된다고 적는다. **재 보고 안 된다고 적는 것도 결과다.**」
> 「틀린 숫자 하나가 옳은 스물셋을 같이 의심받게 한다.」

⚠ 그리고 하마터면 못 볼 뻔했다. **두 갈래를 같이 낸 것이 살렸다** —
갈래가 하나였으면 단조로운 줄만 보고 그대로 냈을 것이다.
**흔들림·집중도·격차처럼 한 가지를 여러 방식으로 잴 수 있는 것은, 두 방식으로 재서 서로 검산시킨다.**
