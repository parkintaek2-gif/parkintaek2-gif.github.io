# 「구운 것」을 「낸 것」이라 불렀다 — 카드 15장이 어느 지면에도 안 걸려 있었다

발견 2026-09-03 17:5x KST · 5번(총괄대행) · **같은 결함이 20일 만에 두 번째다**

> 사장님 지시 (2026-08-13): 「이건 **외부유입용** 콘텐트 역할도 하고, 우리를 알리는 거니까」
> → 그러면 사람이 **집어 갈 수 있어야** 한다. **서버에 있는 것과 걸린 것은 다르다.**

---

## 1부. 결론

K Culture Wire 의 폴더 꼴 카드뉴스 **25벌 가운데 3벌(15장)이 「고아」**였다.
서버에 떠 있는데 **어느 지면도 부르지 않아** 사람이 집어 갈 길이 없었다.
`counter` · `daystem` · `school` 셋이다.

⛔ **가장 나쁜 대목은 이것이다.** 그 가운데 `counter` 는 **오늘 08:56 에 내가 직접 구웠고**,
그 커밋 제목을 **「오늘 하루 몫을 채웠다」**로 달았다.
지면에 걸지 않았으므로 그 몫은 채워지지 않았다. **나는 「구운 것」을 「낸 것」이라 불렀다.**

## 2부. 이것이 두 번째다 — 문장으로 둔 규칙은 잊혔다

`src/components/KcwCardnews.astro` 머리글에 **2026-08-14 자로 이미 적혀 있었다.**

```
🔴 2026-08-14 에 세어 보니 카드뉴스 15장이 서버에 올라가 있는데
  사이트맵에도 어느 지면에도 안 걸려 있었다. 만든 값이 0이었다.
```

⛔ **장수까지 같다 — 그때도 15장, 이번에도 15장이다.**
그 부품을 오늘 여러 번 열어 읽으면서도 그 머리글이 지금의 나를 가리키는 줄 몰랐다.

⭐ 우리 강령이 「**규칙은 문장이 아니라 검사로 둔다**」인 까닭이 정확히 이것이다.
8/14 에 주석으로 뒀더니 9/3 에 또 났다. 이번에는 검사로 둔다.

## 3부. 어떻게 쟀나

```
1. 카드 폴더를 센다
   find public/wikitip/cardnews -maxdepth 1 -type d      → 25벌

2. 지면이 «부르는» 벌을 센다
   grep -rn 'KcwCardnews' --include='*.astro' src/        → 22벌
   ⚠ 인자가 «줄을 넘어» 적힌 지면이 있다(person/index.astro).
     줄 단위로 찾으면 놓친다 — 그래서 검사자는 여러 줄을 걸쳐 뜯는다.

3. 그 차이가 고아다
   node scripts/check-kcw-cardnews-orphan.mjs
   → 폴더 꼴 카드 벌 25벌 · 걸린 것 22벌(110장) · 🔴 고아 3벌(15장)
```

⛔ **손으로 목록을 적지 않았다.** 손으로 적으면 다음에 벌이 늘 때 또 어긋난다.
   검사자가 폴더와 지면을 «각각 세어» 차이를 낸다.

## 4부. 걸고 나서 «또» 나온 것 — 대체글이 조용히 벌 이름으로 떨어졌다

세 벌을 걸고 렌더해서 눈으로 보니 `/weeks-counter` 의 카드 대체글이 이랬다.

```
alt="counter — card 1 of 5"          ← 「counter」는 사람에게 아무 뜻이 없다
```

까닭을 재 보니 부품이 읽는 머리글 표(`src/data/wikitip-headlines.json`)가
**지면 97장에서 멈춰 있었고, 아무도 그 표를 다시 만들지 않고 있었다.**

```
표를 다시 만든 뒤   지면 97장 → 111장 (14장이 빠져 있었다)
그 14장 가운데 «카드가 걸린» 지면   1장 (/weeks-counter) — 그래서 상한 카드는 5장이다
```

⭐ **5장이다. 14장이 아니다.** 놀랄 수를 쓰지 않고 잰 수를 쓴다.
   나머지 13장은 카드가 없어 대체글과 무관했다.

⛔ 부품 자신이 그 머리글에 적어 둔 말이 이것이다 —
   「**대체글이 없는 것보다 나쁜 것은 «아무 뜻 없는 대체글»이다**」. 구글 이미지가 읽는 글자다.

## 5부. 고친 것

```
걸었다   weeks-counter ← counter · day-pillar ← daystem · school ← school
        ⭐ 새 지면을 짓지 않았다. 그 «자료를 이미 쓰는» 지면에 한 줄씩 붙였다
검사     scripts/check-kcw-cardnews-orphan.mjs · 자가시험 16가지 · npm test 에 물림
        고아 · 깨짐(지면은 부르는데 벌이 없음) · 어긋남(장수 불일치) · 대체글 떨어짐
스스로   build-once.mjs 가 빌드 뒤에 머리글 표를 다시 만든다
        ⚠ 표를 dist 에서 읽으므로 «다음» 빌드에 실린다. 새 지면은 한 걸음 늦다 — 그 한계를 적어 둔다
```

## 6부. 이 자가 정말 잡는지 «증명»했다

⛔ 못 잡는 자는 초록만 내는 안심이다. 그래서 일부러 고장을 내 보고 되돌렸다.

```
머리글을 일부러 뺐다     → 「대체글이 벌 이름으로 떨어진다」로 잡았다 (종료코드 1)
표를 아예 깨뜨렸다       → 「⬜ 못 쟀다」로 적었다. 0 으로 채우지 않았다
둘 다 되돌렸다           → 다시 초록
```

## 7부. 잰 것과 «제 판단»을 갈라 적는다

```
실측    카드 벌 25 · 고아 3벌 15장 · 걸린 뒤 25벌 125장
        [find + grep + check-kcw-cardnews-orphan.mjs]
실측    머리글 표 97장 → 111장 · 그 14장 중 카드 있는 지면 1장 · 상한 카드 5장
실측    걸린 뒤 세 지면 다 216×270 으로 다섯 장이 그려지고 대체글이 말이 된다
        [npm run build 뒤 dist 의 html 을 열어 눈으로 봤다]
실측    8/14 에 같은 결함이 15장 규모로 있었다 [KcwCardnews.astro 머리글 원문]

제 판단  「counter 는 weeks-counter 지면이 제집이다」는 제 판단이다.
        자료가 이어지는 것은 사실이지만, 어느 지면이 제집인지는 사람이 정한다.
제 판단  「구운 것을 낸 것이라 부르는 것」이 «한 번의 실수»가 아니라 «꼴»이라는 것도
        제 판단이다. 근거는 20일 사이 두 번이라는 사실뿐이고, 두 번은 적은 표본이다.

⛔ 안 말한 것  「이 카드가 방문자를 늘린다」고는 말하지 않는다 — 아직 안 쟀다(아래 8부).
```

## 8부. ⬜ 못 쟀다

```
⬜ 그 15장이 «누구에게라도 닿았나»   — 안 쟀다. 어느 지면도 안 걸었으니 우리 지면을 통한
   길은 없었지만, 이미지 검색으로 직접 닿았을 수는 있다. Search Console 이미지 노출을
   그 주소들로 뽑아 보지 않았다. **「0이었다」고 적지 않는다.**
⬜ 대체글을 고쳐서 이미지 검색이 늘어나나 — 몇 주가 걸린다. 지금은 판정하지 않는다
⬜ 기사 카드(평평한 `<벌>-sq-1.png` 꼴)의 색인이 온전한가 — 이 검사자는 폴더 꼴만 본다.
   평평한 꼴은 `build-kcw-cardnews-index.mjs` 몫이고 오늘 따로 재지 않았다
```

## 9부. 물린 것

⛔ **오늘 08:56 자 내 커밋 제목 「오늘 하루 몫을 채웠다」를 물린다.**
그때 나는 카드를 구웠을 뿐이고, 지면에 걸지 않았으므로 그 몫은 채워지지 않았다.

⭐ 그래서 앞으로 발행 수를 셀 때 이 기준으로 센다.

```
⛔ 구웠다 = 파일이 생겼다        ← 이것을 발행이라고 부르지 않는다
✅ 냈다   = 손님이 지면에서 집어 갈 수 있다   ← 검사자가 이것을 잰다
```

