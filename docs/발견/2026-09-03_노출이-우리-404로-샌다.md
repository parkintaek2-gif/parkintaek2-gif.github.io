지우면 수요도 같이 사라지는 것이 아니다.

## 2부. 어떻게 쟀나 — 다른 유닛도 «10분에» 할 수 있다

⭐ **이 방법이 이 문서의 핵심이다.** 사이트맵만 보면 이 병은 절대 안 보인다 —
사이트맵에 «없는» 주소인데 구글이 아직 기억하고 있는 것이기 때문이다.
**노출 목록에서 거꾸로 눌러 봐야** 보인다.

```bash
# 1. 노출 큰 순으로 지면을 뽑는다
node scripts/search-console-report.mjs sc-domain:<도메인> --days 28 "--축=page" "--행수=1000"

# 2. 위 20~60장을 «하나씩» 눌러 본다
while read -r n u; do
  c=$(curl -s -o /dev/null -w "%{http_code}" -m 15 "$u")
  [ "$c" != "200" ] && echo "🔴 $c · 노출 $n · $u"
done < 뽑은목록.txt
```

⛔ 200 이 아닌 것이 나오면 **그 노출은 지금 버려지고 있다.**
⭐ 지운 지면·이름 바꾼 지면이 있는 유닛은 특히 그렇다.
   3번은 `/after`·`/region`·`/pets` 를, 5번은 Riot 다섯 장을 그렇게 흘렸다.

## 3부. 어떻게 고쳤나

`server.mjs` 에 「사라진지면」 표를 두고 **301** 을 낸다(`resolveFile` 이 못 찾은 직후).

```
/esports                                    → 301 → /esports-nations
/ladder-gap                                 → 301 → /esports-nations
/article/korea-challenger-win-rate          → 301 → /esports-games
/article/korea-ladder-games-played          → 301 → /esports-games
/article/the-top-tier-is-where-players-stay → 301 → /esports-games
```
라이브에서 다섯 개 다 301, 보낼 곳 둘 다 200 을 확인했다.

⚠ 사장님이 「**내가 riot을 제거하라고 했지, e스포츠를 제거하라고는 하지 않았잖아**」라고
바로잡아 주셨기에 **보낼 곳이 있었다.** 그 말씀이 470건을 살렸다.

### 지킨 것

```
⛔ 302 가 아니라 301 이다 — 영구히 옮긴 것이고, 그래야 구글이 힘을 새 주소로 옮긴다
⛔ 뜻이 «가까운» 곳으로만 보낸다. 아무 데나 보내면 손님이 속았다고 느끼고 바로 나가고,
   구글도 그것을 soft 404 로 보고 오히려 깎는다
⛔ 접두사가 붙은 길에만 걸린다 — 세 사이트가 한 서버를 쓴다
⛔ 표에 없는 404 는 그대로 404 다. 조용히 홈으로 보내지 않는다
```

## 4부. 검사로 굳혔다 — 표만 두면 조용히 다시 샌다

```
scripts/check-gone-page-redirects.mjs   (자가시험 10가지 · 6번이 세 도메인으로 넓혀 주었다)
  · 표를 server.mjs 에서 «읽어» 쓴다 — 두 곳에 적으면 한쪽만 고쳐지고 자가 거짓말한다
  · 보낼 곳이 200 인지도 본다 — 보낼 곳이 죽으면 손님이 두 번 헛걸음한다
  ⭐ 그리고 이 자가 곧 제 몫을 했다 — 6번이 표에 더한 두 건이 «아직 배포 전»이라 404 인 것을 잡았다
     표에만 적고 배포를 안 하면 「고쳤다」고 믿게 된다

scripts/check-kcw-sitemap-gap.mjs       (자가시험 14가지)
  3번의 시행착오(「지면은 라이브인데 사이트맵엔 없어 구글이 몰랐다」)를 자로 굳힌 것
  ⭐ 3번은 「앞으로 반드시 넣는다」고 적어 두고 «같은 날 세 번» 또 어겼다.
     기억에 맡기는 규칙은 잊힌다. 그래서 검사로 둔다
  ⭐ 일부러 3장을 뺀 가짜 사이트맵으로 «울 수 있는지»도 증명했다 — 3장을 정확히 잡았다.
     못 우는 자는 없는 자다
```

## 5부. 이 발견이 4번 진단을 어떻게 고치나

4번: 「검색엔진이 아직 우리를 실어주지 않는 초기 단계 문제」

⭐ **이 다섯 건에 대해서는 맞지 않다.** 실어 주고 있었다.
   다만 사이트별로 갈린다 — 그 갈림은 별도 문서에 있다.

