# 증권사를 「목표주가 채움률」로 비교하면 왜곡된다 — 등급을 맞춰야 한다

작성 2026-09-04 04:4x KST · 5번(총괄) 발견 · 6번이 두 번 재서 확정 · **재서 확인한 것만 적었다**

---

## 1부. 결론을 먼저

`archive/raw/broker` 로 두 증권사의 **목표주가 채움률**을 견주면 한양증권이 부당하게
낮게 보인다. **리포트 등급이 다르기 때문이다.**

```
미래에셋증권   BUY 6건    →  목표주가 6건  (100%)
한양증권      NR 30건    →  목표주가  0건  (0%)
```

**NR(Not Rated)에는 목표주가가 원래 없다.** 파서가 못 집는 것이 아니라 원문에 값이 없다.
그러므로 견줄 때는 **등급을 맞추고** 견줘야 한다(BUY 대 BUY).

---

## 2부. 어떻게 쟀나 — 다음 사람이 다시 잴 수 있게

### 2-1. 5번이 처음 잰 것 (2026-09-03 23:42)

```
node scripts/collect-broker-direct.mjs
→ 미래에셋증권  1쪽 10건 →  0건 · 목표주가 0 · 애널리스트 0
→ 한양증권     1쪽 10건 → 10건 · 목표주가 0 · 애널리스트 9
```

저장된 파일을 등급으로 갈라 세었다.

```
한양증권 10건   NR 9건 · 등급표기 없음 1건  →  목표주가 있는 것 0건
```

### 2-2. 6번이 원인까지 찾아 고친 것 (커밋 b72714c4)

미래에셋이 0건이던 것은 **`categoryId` 가 틀렸던 것**이었다(1521 → 1800).
그 분류는 해외·매크로 위주여서 기업분석 리포트가 안 잡혔다.

고친 뒤 5번이 다시 돌려 확인했다.

```
2026-09-04 03:14
→ 미래에셋증권 6건 · 목표주가 6 · 애널리스트 6 · 실패 0
파일 한 건: SK바이오팜 · code 326030 · BUY · 목표 160,000 · 애널리스트 김승민
```

⭐ **목표주가와 애널리스트 이름이 둘 다 채워졌다.** 그것이 이 수집기의 존재 이유다 —
네이버 경로에는 애널리스트 이름이 없어서(66,093건 중 0.3%만) 이 자를 따로 만들었다.

### 2-3. 5번이 「파서 결함인가」로 헛짚은 것

5번이 「한양 목표주가가 0 이니 파서를 봐 달라」고 6번에게 물었다. **헛짚음이었다.**

⛔ **수가 0 이면 「자가 못 집었나」와 「원본에 없나」를 갈라서 재야 한다.** 5번은 안 갈랐다.
미래에셋이 6/6 인데 한양이 0/10 이라 대비가 커서 「깨졌다」로 읽었다.

### 2-4. 6번이 쪽을 넘겨 가설을 기각한 것 (커밋 c4c8da3f)

5번이 남긴 「1쪽에만 NR 이 몰린 것 아닌가」를 6번이 재서 기각했다.

```
node scripts/collect-broker-direct.mjs --only=hanyang --pages=3 --dry
→ 30건 · 목표주가 0 · 애널리스트 27 · 실패 0
```

최근 30건(대략 2026-07-22 ~ 09-02)이 **전부 NR** 이다. 1쪽 문제가 아니다.

## 3부. 잰 것과 판단을 갈라 적는다

### 3-1. 실측 — 잰 것

- 미래에셋증권 최근 6건은 BUY 이고 목표주가가 6건 다 있다
- 한양증권 최근 30건은 NR 위주이고 목표주가가 0건이다
- 한양증권은 애널리스트 이름은 30건 중 27건에 있다 — **이름은 잡히고 목표주가만 없다**
- 두 증권사 파일을 합쳐 「목표주가 채움률」을 내면 6/36 = 16.7% 가 된다

### 3-2. 여기부터는 «제 판단»이다 — 실측이 아니다

- 최근 한양증권 기업분석 게시판이 당분간 NR 위주로 나오는 것으로 «보인다» — 이것은 제 짐작이고,
  게시판 정책을 확인한 것이 아니다
- 「채움률」 하나로 증권사를 세우면 등급 구성이 다른 곳이 벌을 받는다.
  그래서 이 자료로 증권사를 견줄 때는 **등급을 층으로 두고** 견뎌야 한다

## 4부. ⬜ 못 잰 것

```
⬜ 한양증권이 «더 과거»에는 BUY 를 냈는지. 6번이 최근 30건까지만 확인했다.
   그 이상은 안 재 봤다 — 「안 낸다」가 아니라 「못 쟀다」다.
⬜ 왜 NR 위주인지. 게시판 정책인지 최근 리서치 방향인지 이 자료로는 모른다.
⬜ 두 곳 말고 다른 증권사를 더 넣을 수 있는지. 지금 수집기 목록은 두 곳뿐이다.
⬜ 5번이 2026-09-03 23:42 에 수집기를 다시 돌려 한양증권 세 파일의 «최초 수집 시각»을
   덮었다. 그 값은 못 되살린다. 이후 6번이 `firstCollectedAt` 를 붙여 재실행에 안 덮이게
   고쳤으므로, 앞으로는 이 손실이 안 난다.
```

## 5부. 우리가 틀렸던 것을 남긴다

```
5번  「미래에셋 파서가 깨졌다」        → ✅ 맞았다 (6번이 categoryId 로 원인까지 찾음)
5번  「한양 파서도 봐 달라」          → 🔴 틀렸다. 원문에 값이 없는 것이었다
5번  「1쪽에만 NR 이 몰렸을 수 있다」  → 🔴 틀렸다. 30건 다 NR 이었다
```

⭐ 두 번 다 6번이 «재서» 바로잡았다. 혼자 맞히는 것보다 서로 고쳐 주는 것이 빠르다 —
   그래서 발견을 메모 한 줄이 아니라 **문서로** 내놓는다.
