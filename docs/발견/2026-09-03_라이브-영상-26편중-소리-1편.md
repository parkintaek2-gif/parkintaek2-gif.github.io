# klifemap 라이브 영상 26편 가운데 «소리 있는 것이 1편»이었다

발견 2026-09-03 13:2x KST · 5번(총괄대행)

> 사장님: 「**무성 콘텐트 다신 만들지 말 것**」 · 「기존 무성영상은 **안 내리고 소리 얹어 추가배포**」

---

## 1부. 결론

klifemap 이 `videos.html` 로 **VideoObject 스키마와 함께 검색엔진에 내고 있는** 영상 26편의
음량을 하나씩 쟀다.

```
✅ 소리 있음         1편   07_개명하기-좋은-시기가-있나  −25.2dB
🔴 무음(빈 소리)    13편   전부 −91dB
⛔ 소리 트랙 «아예 없음»  12편   궁합 2 · 사주 4 · 성명학 6
────────────────────────────────────────
합 26편 중 «손님이 소리를 듣는 것»은 1편
```

## 2부. 어떻게 쟀나

```bash
# ffmpeg volumedetect 로 «음량»을 잰다. 26편을 하나씩 돌렸다
ffmpeg -hide_banner -i <파일> -af volumedetect -f null -
  → 출력의 mean_volume 을 읽는다
  → 무음판 −91dB · 우리 소리판 −23dB · 가르는 선 −60dB
```

⚠ **「소리 트랙이 있나」로 검사하면 13편이 통과한다** — 생성기가 빈 소리(anullsrc)를
일부러 붙이기 때문이다. **음량을 «재야» 드러난다.** 5번이 KCW 에서 같은 함정에 걸렸다.

## 3부. 함께 알아낸 것 — 검사자가 «부풀어» 있었다

KCW 쪽 자(`scripts/check-kcw-silent-video.mjs`)가 「무음 16편」이라 했는데
**진짜 할 일은 8편**이었다.

까닭 — 소리판(`<이름>-voiced.mp4`)을 이미 만든 편도 **원본은 그대로 −91dB 로 남는다.**
사장님이 「삭제하지 말고 소리만 입혀서 추가로 배포해」라 하셨으니 원본이 남는 것이 **맞다.**
⛔ 그런데 그 원본을 「할 일」로 세면 **다 해도 수가 안 줄어**, 다음 사람이 자를 안 믿는다.
✅ 「소리판 짝이 있는 원본」과 「없는 원본」을 갈라 세게 고쳤다.

## 4부. 4번이 이 발견으로 한 일 (같은 날)

원본을 안 지우고 소리판을 **추가**해 26편 → 27편, 소리 있는 것 1편 → 2편이 됐다.
git 추적 27/27, `videos.html` 이 소리판을 가리키도록 갱신, 라이브 200.
⭐ **사장님 지시 그대로다.** 그리고 5번이 «음량을 다시 재서» 확인했다 —
「붙였다」로 끝내지 않았다.

## 5부. 잰 것과 «제 판단»을 갈라 적는다

```
실측    26편 전부의 mean_volume · 소리 있음 1편 · 무음 13편 · 트랙 없음 12편
        [ffmpeg volumedetect 를 26번 돌린 것]
실측    검사자가 「무음 16편」이라 했는데 소리판 짝을 세어 보니 진짜 할 일은 8편

제 판단  「가르는 선을 −60dB 로 둔다」는 제 판단이다 —
        무음판 −91 과 우리 소리판 −23 사이를 가른 값이고, 표준이 있는 것이 아니다.
제 판단  「하루 한 편이면 25일」은 산술이지 계획이 아니다. 날짜는 아직 못 잡았다.
```

## 6부. ⬜ 못 쟀다

- 나머지 25편에 언제까지 소리를 입힐지 **날짜를 못 잡았다.** 하루 한 편이면 25일이다
- 그 영상들이 검색에서 실제로 열리는지(영상 노출)는 **안 쟀다.**
  Search Console 의 영상 보고를 봐야 한다
