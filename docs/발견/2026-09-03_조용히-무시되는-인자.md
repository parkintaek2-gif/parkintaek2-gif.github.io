# 보내는 자에 첨부 기능이 «아예 없었는데» `--첨부` 가 조용히 무시됐다

발견 2026-09-03 16:5x KST · 5번(총괄대행) · **사장님이 잡아 주셨다**

> 사장님: 「**pdf첨부 빠짐**」 · 「11시 보고 때 같이 줘」

---

## 1부. 결론

`scripts/send-mail.mjs` 에 **첨부 기능이 아예 없었다.** 그런데 나는 `--첨부=…` 를 붙여
보내고 **「첨부했다」고 믿었다.** 인자를 읽는 함수가 **모르는 인자를 조용히 버렸고**,
출력에 아무 말도 없었다.

⛔ **조용히 성공한 척하는 것이 제일 나쁘다.** CLAUDE.md 에 이미 같은 사고가 적혀 있다 —
`ctype undeploy` 가 「출력도 오류도 없이 종료코드 0」을 내서 **두 세션이 「지웠다」고 믿었다.**
이번 것은 그것과 같은 병이다.

## 2부. 얼마나 그랬나 — 실측

`docs/보낸메일.tsv` 를 봤다. 첨부가 있어야 했던 보고 메일 **셋**이 첨부 없이 갔다.

```

2026-09-03 16:30  [16시 업무보고]     ← 사장님이 이것을 잡아 주셨다
```

## 3부. 어떻게 쟀나

```
grep -n "첨부\|attach\|파일" scripts/send-mail.mjs
  → 「첨부」도 「attach」도 «한 줄도» 없었다. 기능이 없는 것이 확인됐다
grep -n "const 인자 = " scripts/send-mail.mjs
  → process.argv.find(a => a.startsWith(`--${이름}=`))  — 아는 이름만 찾고 나머지는 버린다
```

## 4부. 어떻게 고쳤나 — **두 가지를 같이** 고쳤다

⭐ 한쪽만 고치면 또 조용히 샌다.

```
1. 첨부를 «실제로» 붙인다 — multipart/mixed
   · --첨부=a.pdf,b.xlsx 로 여러 개
   · 파일이 없으면 «안 보낸다». 첨부가 빠진 채로 나가는 것이 제일 나쁘다
   · 25MB 를 넘으면 서고 알린다 — 잘라 보내지 않는다
   · 한글 파일이름을 MIME 으로 감싼다 (우리 보고서 이름이 다 한글이다)
   · 종류를 모르면 «모른다»고 두고 octet-stream — 지어낸 종류는 못 열린다
   · 첨부가 없을 때는 옛 꼴(text/plain) 그대로 — 여태 보낸 메일과 달라지지 않는다

2. **모르는 인자를 거부한다**
   --첨부파일=a.pdf 처럼 오타를 내면 «서고» 아는 인자 목록을 낸다.
   오타 하나로 첨부가 빠지는 것보다 아예 서는 것이 낫다.

3. 미리보기에 첨부를 낸다 — 「붙었나」를 눈으로 보게. 없으면 「⬜ 없음」이라고 적는다
```
자가시험 38 → **51**.

## 5부. ⭐ 다른 유닛도 같은 병을 앓고 있을 수 있다

**모르는 인자를 조용히 버리는 자가 우리 저장소에 몇 개나 있나?**
이 꼴은 자기 자신을 숨기기 때문에 «찾아야만» 보인다.

```
찾는 법 — 자기 자가 인자를 어떻게 읽나 본다
  grep -n "process.argv.find\|process.argv.indexOf" scripts/*.mjs tools/*.js
  → 그 함수가 «아는 이름 목록»과 견주는지 본다. 안 견주면 오타가 조용히 먹힌다
```

⛔ 특히 **「--적는다」·「--보낸다」처럼 «하는 일이 바뀌는» 깃발**이 위험하다.
   오타를 내면 «안 하고» 지나가는데, 자는 성공한 척한다.
