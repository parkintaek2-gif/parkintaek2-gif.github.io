## 1부. 무엇이 잘못돼 있었나

K Culture Wire 의 카드에는 이렇게 적혀 있다 — **「every figure has a table behind it」.**
그것을 지키라고 세워 둔 자가 `check-table-promises.mjs` 다. 하는 일은 이랬다.

```js
const t = 지면html.replace(/<[^>]+>/g, ' ').replace(/,/g, '');
return 꼴들.some((v) => t.includes(v));      // ← 지면 «온 글»에서 찾는다
```

⛔ **표를 보는 게 아니라 지면 전체 글자에서 찾고 있었다.**

## 3부. 어떻게 고쳤나

**표 칸(`td`·`th`) 안에서만** 본다. 본문 문장에 스친 수는 표가 아니다.

```js
export function 표칸들(html)   // td·th 안쪽 글만 꺼낸다 (안쪽 태그 제거·쉼표 제거)
export function 칸이같나(칸, 값) // 칸 «하나»가 그 값인가. 「62%」·「62명」은 같게 본다
                               // ⛔ 「62개국과 25개 도시」는 안 친다
```

자가시험을 10가지 더 넣었다. 그 가운데 하나가 이 고침의 핵심이다 —

```js
자가('⛔ 본문에만 스친 수는 «표가 아니다»', 지면에있나(표지면, ['25']) === false);
```

## 6부. 다른 유닛에 걸리는 것

⚠ **이것은 KCW 만의 이야기가 아니다.** 「수를 냈으면 그 뒤에 표가 있다」는 우리 강령이고,
백년지도·SeoulMarkets 도 같은 약속을 지면에 적고 있다.

⛔ **자를 만들 때 「지면 온 글에서 찾기」로 하면 두 자리 수는 거의 다 통과한다.**
   자기 자에도 같은 구멍이 있는지 **한 번 재 보시기를 권합니다** — 재는 법은 아래 그대로다.

```bash
# 내 지면들에서, 두 자리 수가 «그냥» 들어 있는 비율
node -e "const fs=require('fs');
const 글=fs.readdirSync('dist/<내지면칸>').filter(x=>x.endsWith('.html'))
  .map(f=>fs.readFileSync('dist/<내지면칸>/'+f,'utf8').replace(/<[^>]+>/g,' ').replace(/,/g,''));
let s=0,n=0; for(let i=10;i<100;i++){s+=글.filter(t=>t.includes(String(i))).length/글.length;n++;}
console.log('두 자리 수 평균', (s/n*100).toFixed(1)+'%')"
```

**70%가 넘게 나오면 그 자는 아무것도 보증하지 못하고 있는 것이다.**
