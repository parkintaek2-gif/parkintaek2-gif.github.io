# 신용거래융자잔고는 data.go.kr 15094809 「금융투자협회종합통계정보」의 오퍼레이션이다 — 연령별·반대매매는 API에 없다

## 1부. 결론을 먼저

사장님이 전달하신 신용거래융자잔고·반대매매 뉴스(금융투자협회 발표 인용) 관련해 원천을 찾았다.

```
전체 신용융자·코스피·코스닥 잔고    ✅ API로 받아진다 — data.go.kr 15094809
20·30대 연령별 신용융자 잔액        ⛔ API에 없다 — 못 쟀다
반대매매(월별 금액)                 ⛔ API에 없다 — 못 쟀다
```

이 API의 「신용융자 전체」 최신값(기준일 2026-09-02)은 **33.44조원**으로, 뉴스 원문의
"약 33조원"과 사실상 일치한다. 뉴스가 가리킨 원천 자체를 재현한 것으로 판단한다.

## 2부. 어떻게 쟀나 — 다음 사람이 다시 잴 수 있게

### 2-1. 데이터셋을 찾은 경로

`data.go.kr`에서 "신용융자"로 파일데이터·Open API를 검색하면 0건이다(단독 API는 없음).
WebSearch로 "금융투자협회 신용공여 잔고" 검색 → 데이터셋 `15094809`
(「금융위원회_금융투자협회종합통계정보」)의 8개 오퍼레이션 중 넷째가
「신용공여 잔고 추이 조회」임을 확인했다.

```
https://www.data.go.kr/data/15094809/openapi.do
End Point: https://apis.data.go.kr/1160100/service/GetKofiaStatisticsInfoService
오퍼레이션: /getGrantingOfCreditBalanceInfo
심의유형: 개발단계 자동승인 / 운영단계 자동승인
```

### 2-2. 활용신청·실제 호출 (CDP로 사장님 계정 사용)

`puppeteer-core`로 CDP(9222) 붙어 `selectDevAcountRequestForm.do`에서 활용신청서를
채워 제출했다(활용목적 8개 상세기능 전체선택, 이용허락범위 동의). `selectAcountList.do`에서
`[승인] 금융위원회_금융투자협회종합통계정보`(신청일 2026-09-04, 만료 2028-09-04) 확인.

발급된 「일반 인증키」는 계정 단위 공용키로, 기존 `.env`의 `DATAGO_KEY`와 **같은 값**이었다
(다른 데이터셋 승인분에서도 같은 키 문자열이 노출된 것으로 확인 — data.go.kr은 API마다
새 키를 안 준다).

```
node scripts/collect-credit-balance.mjs
→ ✅ 신용공여잔고추이 1,177건(신고 총 1,177) → archive/raw/credit-balance/series.json
   최신(20260902): 신용융자 전체 33.44조원 (코스피 26.42조·코스닥 7.02조)
```

새 수집기 `scripts/collect-credit-balance.mjs`(자가시험 10가지, `--자가시험`로 확인)를
만들었다. 응답 필드는 기준일 단위로 신용거래융자(전체·코스피·코스닥)·신용거래대주
(전체·코스피·코스닥)·청약자금대출·예탁증권담보융자 8개다.

### 2-3. 연령별·반대매매를 찾아본 것

`data.go.kr`에서 "반대매매", "연령별 신용융자"로 검색했으나 관련 API·파일데이터가
나오지 않았다. WebSearch로도 공개 API 형태의 원천을 찾지 못했다. 뉴스 원문의 해당
숫자들은 금융투자업계·금융감독원(FSS) 자료를 언론이 별도로 취재해 인용한 것으로
보이며(짐작 — 확인 안 됨), 공공 API로 재현할 방법은 이번 조사로는 못 찾았다.

## 3부. 잰 것과 판단을 갈라 적기

**잰 것**
- 데이터셋 15094809에 신용공여잔고추이 오퍼레이션이 있다(문서·Swagger에서 직접 확인)
- 자동승인이며 실제로 신청·승인까지 확인했다(선택 화면에 "[승인]" 표시)
- 실제 API 호출로 1,177건을 받았고 최신값이 뉴스 숫자와 사실상 일치한다

**판단(짐작 포함, 표시함)**
- 뉴스의 20·30대·반대매매 숫자는 공공 API가 아닌 별도 취재원(FSS 등)일 것이다 — **짐작**
- 이 API는 시세(가격)가 아니라 레버리지 잔고 통계라 FSC 제4유형(2026-09-09 제한) 밖일
  것이다 — **판단, 사장님·5번의 별도 확인 필요할 수 있음**
