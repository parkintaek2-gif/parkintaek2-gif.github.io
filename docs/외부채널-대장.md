하나 만들 때마다 **네 벌**을 뽑는다. 새로 만드는 것이 아니라 **자르는 것**이다.

```
① 숏영상 14초    유튜브 숏츠 · 인스타 릴스 · 스레드
② 카드 5장       인스타 · 스레드
③ 글 3~5줄       X · 스레드
④ 지면 한 장     우리 사이트 ← ⭐ 위 셋이 전부 여기로 보낸다
```

⛔ ④ 없이 ①②③ 을 올리지 않는다. **보낼 곳이 없는 콘텐츠는 광고비만 쓰는 것**이다.

## 4. 유입을 어떻게 재나

⛔ 「올렸다」는 셈이 아니다. **넘어온 사람 수**가 셈이다.

> 🔴 2026-08-08 23:0x — **내가 정한 꼬리가 틀렸다. 5번이 잡았다.**
> 나는 `?from=yt-kcw` 만 붙이라고 했는데 **GA4 는 `from=` 을 안 읽는다.**
> 그대로 갔으면 영상에서 온 손님이 전부 「직접 방문」으로 뭉개졌다 — **재려고 붙인 꼬리로 못 재는 것**이다.

```
⭐ 붙일 것 — utm_ 셋이 먼저다. from 은 우리끼리 보는 표시로 뒤에 둔다

?utm_source=youtube&utm_medium=social&utm_campaign=<채널>-shorts&from=yt-<채널>

  utm_source    youtube · instagram · threads · x · facebook
  utm_medium    social  (광고를 태우면 cpc)
  utm_campaign  100yearmap-shorts · seoulmarkets-shorts · kculturewire-shorts · klifemap-shorts
  from          yt-100y · yt-smk · yt-kcw · yt-klm  (ig-* · th-* · x-* · fb-*)
```

⛔ **`from=` 만 붙이지 않는다.** 그건 GA4 에 안 보인다.
⚠ 꼬리 이름은 2번이 정한다. 각 자리가 마음대로 붙이면 못 센다.
