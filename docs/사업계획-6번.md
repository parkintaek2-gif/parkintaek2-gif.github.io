## ① 사명 (한 줄)
한국 금융·노동·기업 데이터를, 기관이 **영업 없이 검색해서 호출당 사가는** 유일한 벤더가 된다.

## ② 문제 — 지금 무엇이 안 되나
```
대형 벤더(Bloomberg·FnGuide 등)는 한국 상장사의 「노동 지문」(급여·근속·성별·이직·이사회·리서치 쏠림·주도주 격차)을 안 판다.
퀀트·ESG·HR은 그 데이터를 조각조각 손으로 모은다 — 살 곳이 없어서다.
```

## ③ 우리 해법 · 왜 우리만 되나
```
이미 1차 데이터에서 정제·조인·**정정이력**까지 붙여 7종으로 만들어 뒀다(라이브 ●).
원천이 재배포 가능(data.go.kr 「이용허락범위 제한 없음」 ●) — 라이선스 걸림돌 0.
대형 벤더가 안 파는 축이라 경쟁이 없다 = 사장님 「유일 벤더」 해자.
```

## ④ 시장 — TAM(Total Addressable Market · 전체 시장) / SAM(Serviceable Addressable Market · 닿는 시장) / SOM(Serviceable Obtainable Market · 딸 몫)
```
TAM  글로벌 금융·대체데이터 시장 — 수백억 달러 규모(업계 공표치). ○(우리가 잰 것 아님, 업계 인용)
SAM  한국 금융·노동 데이터를 사는 기관 — 국내 운용사·증권·연기금 + 한국 노출 글로벌 퀀트·ESG. 수천 곳. ○
SOM  장터(FinDX·Nasdaq) 등록 후 우리가 초기 딸 몫 — 수십~수백 기관. ○
🔴 지난 6달 우리는 SOM(99.7억)만 세고 시장이 작다 믿었다 — TAM은 훨씬 크다.
```

## ⑤ 사업 모델 — 🔴 **종량제** (구독 아님. 2번 결정)

어떻게  FinDX/Nasdaq/자체 API 로 종량 과금 · 셀프서브(검색→호출→과금) · 영업 0.
왜 종량제  한 기관이 백테스트·리밸런싱마다 더 호출한다 → **고객이 안 늘어도 매출↑**(재구매율>100%).
          구독(정액)은 재구매율 100%를 못 넘어 1,000억에 산술로 안 닿는다.
