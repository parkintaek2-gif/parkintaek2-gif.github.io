사장님 지시 — 「프로스포츠의 검색량을 자세히 시장조사해. 어떤 키워드를 반드시
포함해야하는 지를 파악해. 그런다음에 스포츠기사 예약에 반영해.

🔴 **종목 이름만 쓰면 검색에 안 걸린다.** 아래 중 하나를 제목에 «반드시» 넣는다.

```
순위 · 일정 · 개막 · 중계 · 예매 · 결과
```

**③ 선수 이름이 종목 이름보다 크다**

```
손흥민   585,000      이강인   521,200      김민재   429,300
이정후   195,000      김혜성    91,500
```

⭐ 선수 이름은 그 자체가 검색어다. 기사를 쓸 때 **제목에 선수 실명을 넣는다.**

**④ 여기서 나오는 것**

- 프로야구가 나머지 전부를 합친 것보다 크다. 포스트시즌에는 더 쏠린다.
- ⭐ **배구는 여자부(161,300)가 남자부(63,080)의 2.6배다.**
  「프로배구」(24,210)보다 **「여자배구」가 여섯 배 크다.** 배구는 「여자배구」로 쓴다.
- ⭐ **농구도 여자부(168,900)가 남자부(60,260)의 2.8배다.**
  「프로농구」(130,500)보다도 「여자농구」가 크다. 여자부를 빼놓지 않는다.
- 「프로배구순위」(610)·「프로배구중계」(530)는 거의 0이다.
  배구에 「프로배구」를 붙이는 것은 검색에 도움이 안 된다.
- 박신자컵(44,100)은 작지 않다. 고유 행사명은 그 이름 그대로 검색된다.
- e스포츠는 32,980 이지만 LCK 는 68,500 이다. **「e스포츠」보다 「LCK」로 쓴다.**

**⑤ 그래서 이렇게 고른다**

```
✅ 제목에        종목 + (순위 | 일정 | 개막 | 중계 | 예매 | 결과) 중 하나를 반드시
✅ 선수가 있으면  선수 실명을 제목에 넣는다 — 종목 이름보다 크다
✅ 배구를 쓸 때   「여자배구」로 쓴다. 「프로배구」로 쓰면 6분의 1이다
✅ 농구를 쓸 때   남녀를 번갈아 쓴다. 여자부가 더 크다
✅ e스포츠        「LCK」로 쓴다 — 두 배 크다
⛔ 「스포츠뉴스」(4,790)·「프로배구중계」(530) 같은 말은 제목에 쓰지 않는다
```

⚠ **이 수치는 「지금」의 것이다.** 시즌이 바뀌면 순서가 바뀐다.
주제를 고정하지 않는다 — 그날 가장 큰 것을 고르되, 고를 때 이 수치를 근거로 삼는다.
