# 연구 — AI 가 운용하는 자산운용사, 그리고 어디에 세울 것인가

작성 2026-08-02 · 사장님 지시로 조사
전제: **인력 1명 · 자금 0원 · 한국이 아닌 아시아 · 영문 서비스 · 딸들이 일본 근무**

> ⚠ 이 문서는 공개 자료 조사다. **법률 자문이 아니다.**
> 실제 진행 전에 해당 관할권 변호사·행정서사의 확인이 반드시 필요하다.
> 요건은 개정이 잦다 — 확인 시점을 각 항목에 적어 둔다.

# 1부. AI 가 운용사를 운영할 수 있는가

## 결론 — 된다. 단 「AI 가 운영한다」가 아니라 **「AI 가 운용하고 사람이 책임진다」**로만 된다

이 구분이 전부다. 이걸 착각하면 등록 심사에서 바로 막힌다.

## 선례가 이미 있다 — AIEQ (2017년 상장)

| | |
|---|---|
| 이름 | AI Powered Equity ETF (AIEQ) |
| 운용 방식 | IBM Watson 기반 EquBot 모델이 **매일** 미국 상장 6,000종목을 분석 |
| 산출 | 12개월 상승 잠재력이 큰 **30~125종목**을 고른다 |
| 입력 | 규제 신고서 · 뉴스 · 소셜미디어 · 재무지표 · 10년치 과거 데이터 |
| 등록 | **SEC 등록 액티브 ETF.** investment adviser 는 라이선스 보유 법인 |

**AI 가 종목을 고르는 ETF 가 9년째 상장돼 있다.** 이게 안 된다는 말은 사실이 아니다.

다만 구조를 보라 — **AI 가 고르고, 라이선스를 가진 법인이 adviser 로 책임을 진다.**
AI 는 법인격이 없다. 등록의 주체도, 책임의 주체도 사람과 법인이다.

## 규제 당국이 실제로 요구하는 것

### IOSCO — 「상급 경영진」에게 감독 책임을 명시적으로 지정하라

AI 의 고도화·불투명성을 전제로 하면서도 **경영진의 직접적 설명책임을 무겁게** 본다.
AI·기계학습의 **설계·테스트·도입·감시·통제**에 대한 감독 책임자를 지정하고,
알고리즘이 낸 결과를 **계속 검증**할 것을 요구한다.

### 일본 금융청 — AI 디스커션 페이퍼 · AI 관민 포럼(2025)

논점으로 든 것: 모델리스크관리 · **설명가능성** · 공정성/편향 · **할루시네이션** ·
서드파티 관리 · 데이터 정비 · 거버넌스.

**그리고 여기에 우리에게 결정적인 문장이 있다.**

> 생성형 AI 는 **「같은 입력에 대해 다른 결과가 나올 수 있다」**는 특성을 갖기 때문에
> 종래와 같은 방법으로는 관리할 수 없다

**이 한 줄이 설계를 결정한다.**

## 그래서 갈림길은 여기다

```
❌  생성형 AI 가 매일 재량으로 종목을 고른다
    → 같은 입력에 다른 답. 재현 불가. 설명책임이 폭발한다
    → 모델리스크관리·검증 체계를 사람이 계속 돌려야 한다  →  1인으로 불가능

✅  AI 가 「규칙」을 설계하고, 운용은 그 규칙이 기계적으로 한다
    → 규칙이 공개돼 있고 결정론적이다. 누구든 같은 답을 재현한다
    → 감사 가능. 설명 가능. 사람은 감독만 한다  →  1인으로 가능
```

**우리 계획은 이미 아래쪽이다.** 지수를 만들어 그 지수를 추종하는 상품을 굴리는 것은
**재량이 거의 없는 운용**이다. 규칙이 공개돼 있고, 산출이 재현되고, 감사가 된다.
**규제가 가장 편해하는 형태를 우연히 이미 고른 셈이다.**

## 그러면 AI 는 어디에 쓰는가

| 단계 | 누가 | 왜 |
|---|---|---|
| 지수 **설계** · 후보 규칙 탐색 | **AI** | 12년 아카이브로 무수한 규칙을 시험한다. 여기가 AI 의 자리 |
| 규칙 **확정 · 공개** | 사람이 승인 | 확정된 순간 결정론이 된다 |
| 정기 **리밸런싱** | **기계** | 공개된 규칙을 그대로 적용. 재량 없음 |
| 오류 정정 · 예외 처리 | 사람 | 규정된 절차대로 |
| 컴플라이언스 · 감독 | **사람 (필수)** | 여기는 자동화 대상이 아니다 |

**AI 가 대체하는 것은 애널리스트이지 준법감시인이 아니다.**

## 자동화할 수 없는 것 — 정직하게

등록 요건에 **사람**이 들어간다. 이건 못 없앤다.

- 상근 임원 / 책임자 (관할권마다 인원과 거주 요건이 다름)
- 내부관리·컴플라이언스 담당
- 회계감사

**다만 이들은 「매일 종목을 고르는 사람」이 아니라 「감독하는 사람」이다.**
운용 자체가 규칙 기반이면 이 인원이 최소화된다. 그게 1인 회사가 노릴 수 있는 유일한 형태다.

# 2부. 어디에 세울 것인가 — 아시아 관할권 비교

## 요약 — **일본이 명확히 낫다**

| 관할권 | 최저 자본 | **실질 벽** | 1인 가능성 |
|---|---|---|---|
| **일본** 適格投資家向け投資運用業 | **자본금 1,000만엔** | 운용재산 **200억엔 상한** | **○ 이사회 불필요** |
| **일본** 投資運用業 (통상) | 자본금 5,000만엔 | 이사회 설치 필요 | △ |
| **일본** 投資助言・代理業 | 최저자본금 **없음**(영업보증금 500만엔 공탁) | **업계 경험자 요건** | △ |
| 홍콩 Type 9 (고객자산 미보유) | 납입자본 요건 없음 · 유동자본 HK$10만 | **책임자(RO) 2명**, 1명은 홍콩 거주 executive director | **✗** |
| 라부안(말레이시아) | 납입자본 RM30만 | **상근 직원 2명 + 연 MYR10만 지출 + 사무소 + 배상보험 MYR100만** | **✗** |

**자본금이 아니라 「사람 요건」이 갈랐다.** 홍콩은 책임자 2명, 라부안은 상근 2명이
법으로 박혀 있다. **1인 회사는 자본이 있어도 이 둘을 못 넘는다.**

## 일본이 나은 이유 넷

### ① 1인용 단계가 실제로 설계돼 있다

**適格投資家向け投資運用業(프로 대상 투자운용업)** 은 참여 촉진을 목적으로 만든 완화 제도다.

| | 適格投資家向け | 통상 投資運用業 |
|---|---|---|
| 자본금 | **1,000만엔** | 5,000만엔 |
| **이사회** | **불필요** | 필요 |
| 운용재산 총액 | **200억엔 이하** | 제한 없음 |
| 고객 | 「적격투자자」로 한정 | 제한 없음 |

**이사회가 필요 없다는 것이 핵심이다.** 홍콩·라부안이 사람 수로 막는 자리를
일본은 이 제도로 열어 놓았다.

### ② 계단이 촘촘하다 — 벌면서 오를 수 있다

```
투자조언·대리업     영업보증금 500만엔 (공탁금 — 자본이 아니라 맡기는 돈)
      ↓
適格投資家向け      자본금 1,000만엔 · 이사회 불필요 · AUM 200억엔까지
      ↓
投資運用業          자본금 5,000만엔 · 이사회 필요 · 상한 없음
```

**자금이 없는 회사에 필요한 건 낮은 첫 칸이 아니라 촘촘한 계단이다.** 일본에 그게 있다.

### ③ ETF 를 실제로 상장할 시장이 있다

라부안에는 ETF 시장이 없다. 지수를 만들어 상품으로 만드는 계획에서 **도쿄증권거래소가
있다는 것 자체가 조건**이다. 홍콩도 되지만 사람 요건에서 막힌다.

### ④ 딸들이 일본에 있다

거주·상근 요건이 있는 나라에서 이건 실질적 조건이다.

> ⚠ **다만 임원은 실제로 적합성 요건을 충족하고 실제로 그 역할을 해야 한다.**
> 이름만 올리는 것은 등록 취소 사유가 되고, 금융업에서는 특히 엄하게 본다.
> **가족이 있다는 것이 요건을 면제해 주지는 않는다** — 다만 「일본에 사람을 둘 수
> 없다」는 물리적 장벽이 없다는 뜻이다.

## ⚠ 200억엔 상한이 우리 계획과 충돌한다

매출계획은 **AUM 5조원**을 가정한다. 200억엔은 대략 **1,900억원**이다.

```
適格投資家向け 상한   200억엔  ≈  1,900억원
매출계획의 목표 AUM              5조원
```

**계획대로 크면 適格投資家向け 로는 못 담는다.** 통상 投資運用業(자본금 5,000만엔,
약 4.7억원)으로 올라가야 한다.

**이건 문제가 아니라 순서다.** AUM 1,900억원에 닿았다면 이미 매출이 나오는 상태이고,
5,000만엔은 그 매출로 낸다. **자금 조달이 아니라 성장의 결과로 다음 칸이 열린다.**

# 3부. 그래서 어떻게 하나

## 순서

| 시기 | 할 것 | 자본 |
|---|---|---|
| **2026 Q4** | 지수 규칙 설계 · 12년 백테스트 · **일본 행정서사/변호사에게 요건 확인** | 0 |
| 2027 | 지수 공개 · 실적 축적 · 일본 법인 설립 검토 | 법인 설립비 |
| 2027~28 | **適格投資家向け投資運用業 등록** (자본금 1,000만엔) | 약 1억원 |
| 2028~29 | 적격투자자 대상 사모 운용 → 실적 | |
| 2029~ | 통상 投資運用業 전환 (5,000만엔) → **TSE ETF 상장** | 약 4.7억원 |

**2026년 4분기에 돈 드는 일이 하나도 없다.** 규칙 설계와 백테스트는 이미 있는
아카이브로 하고, 요건 확인은 상담이다.

## 지금 당장 바뀌는 것 — 지수 설계의 기준

「나중에 일본에서 등록한다」가 정해지면 **지금 만드는 지수의 설계 기준이 달라진다.**

| | 이유 |
|---|---|
| **규칙을 처음부터 공개 전제로 쓴다** | 나중에 감사받을 것을 미리 만족시킨다 |
| **재현 가능성을 코드로 보장한다** | 같은 입력 → 같은 출력. 생성형 AI 를 산출 경로에 두지 않는다 |
| **모든 리밸런싱 이력을 남긴다** | 사후에 못 만든다. 오늘부터 남겨야 한다 |
| **오류 정정 절차를 문서로 미리 만든다** | 지수 사업의 신뢰 요건 |

**이건 나중에 못 고친다.** 지수는 「그때 그 규칙으로 그 값이 나왔다」가 증명돼야 하는데,
이력을 안 남기고 시작하면 그 증명이 영영 불가능하다.
**아카이브를 덮어쓰지 않는 원칙과 같은 이야기다.**

## 확인 못 한 것 — 다음에 물을 것

1. **適格投資家向け 의 인적 요건 구체 내용** — 상근 임원 몇 명, 어떤 경력을 요구하는지.
   자본금은 확인했으나 **사람 요건이 실질 벽인 것을 홍콩·라부안에서 봤다.** 이게 제일 급하다
2. **외국인(비거주자)이 일본 금융상품거래업자를 등록할 때의 추가 요건**
3. 投資助言・代理業의 「업계 경험자」 요건이 구체적으로 무엇인지 — 사장님 경력이 인정되는지
4. 한국 거주자가 일본 법인의 주주가 될 때의 외국환 신고·세무
5. **AI 를 지수 설계에 쓰는 것이 모델리스크관리 대상이 되는지** — 산출이 결정론적이면
   대상이 아닐 가능성이 높으나 확인이 필요하다

# 4부. 남의 돈이 아니라 **우리 돈으로 매매한다** (2026-08-02 추가 지시)

> 사장님: 「투자매매업, 남의 돈뿐만 아니라 **우리 돈을 갖고 투자하는 비즈니스**를 하고 싶다.
> AI 를 만들어서 전 세계에 흘러가는 것을 조합하고, 어느 시장에서 어떤 종목을 사면 될지를
> **실시간으로 추천받아 바로 매매**할 수 있게끔.」
> 그리고 — 「**사람한테 일을 맡기지 않을 거야.**」

## 이게 규제 구조를 통째로 바꾼다 — 좋은 쪽으로

**자기 돈으로만 매매하는 것은 금융상품거래업 등록 대상이 아니다.**

등록 의무가 붙는 기준은 「**출자를 받은 재산**의 자기운용을 업으로 하는 자」다.
즉 **남의 돈을 받았을 때** 규제가 시작된다. 자기 자금으로 자기 계산으로 사고파는 것은
법적으로 그냥 **투자자**다. 라이선스도, 최저자본금도, 상근 임원도 필요 없다.

```
남의 돈을 굴린다   →  投資運用業 등록 · 자본금 · 인적 요건 · 감사
우리 돈을 굴린다   →  등록 불요.  사람도 자본 요건도 없다
```

**「사람한테 일을 맡기지 않는다」와 정확히 맞는 유일한 형태다.**
1·2부의 운용업은 어떻게 설계해도 상근 임원과 컴플라이언스 담당이 들어간다.
자기자금 매매에는 그게 없다.

## ⚠ 단 하나의 예외 — 고속·알고리즘 거래는 별도 등록 대상이다

「자기 돈이니 자유」가 **알고리즘 고속거래에는 그대로 적용되지 않는다.**

일본에는 **高速取引行為者(고속거래행위자) 등록 제도**가 있고,
**자기 계산으로 직접전자접근(DEA)을 써서 알고리즘 거래를 하는 사업자도 대상**이다.
등록하면 내부 규정 정비·업무보고서 제출(사업연도 종료 후 3개월 내) 의무가 따른다.

```
자기자금 + 사람이 판단하는 속도의 매매        →  등록 불요
자기자금 + 알고리즘 · 고속 · 직접전자접근      →  高速取引行為者 등록 대상일 수 있다
```

**「실시간으로 추천받아 바로 매매」가 어느 쪽인지가 갈림길이다.**
분·시간 단위면 대개 문제가 안 되고, 밀리초 단위 자동 발주면 대상이 된다.
**설계 전에 이 선을 확인해야 한다** — 나중에 알면 시스템을 다시 만들어야 한다.

## 그리고 이 순서가 오히려 자연스럽다

```
① 우리 돈으로 매매        라이선스 불요 · 사람 불요 · 오늘 시작 가능
        ↓  여기서 나오는 것이
② 실거래 트랙레코드       ← 돈으로 못 산다. 시간으로만 쌓인다
        ↓  그것이 근거가 되어
③ 지수 · 전략 판매 · 운용업 등록 · ETF
```

**운용업 등록 심사도, 운용사와의 협상도, 결국 실적을 본다.**
자기 돈으로 먼저 굴려 실적을 만드는 것은 우회로가 아니라 **정공법**이다.

## 그런데 정직하게 — 이 계획에 정면으로 부딪히는 것이 셋 있다

### ① 자금이 0원이다

자기 돈으로 매매하려면 **자기 돈이 있어야 한다.** 이게 가장 큰 모순이다.
라이선스는 필요 없지만 **원금은 필요하다.**

원금은 미디어·데이터 매출에서 나올 수밖에 없다. 매출계획의 2027년 11.8억 중
일부가 매매 원금이 된다. **즉 이 사업은 3순위가 아니라 「매출이 난 다음」이다.**

**손실도 100% 우리 것이다.** 남의 돈이면 수수료만 잃지만 우리 돈이면 원금을 잃는다.
자금이 없는 회사에서 이건 가볍게 볼 조건이 아니다.

### ② 실시간 데이터는 유료다 — 지금 전략과 정면 충돌한다

이 회사의 데이터 전략 전체가 **「T+1 무료 공공데이터」** 위에 서 있다.
`docs/데이터-출처-라이선스.md` 와 첫 기사가 그것을 근거로 쓰였다.

```
지금       공공데이터포털 · 무료 · T+1        →  기사·API·지수 백테스트에 충분
실시간 매매  거래소 실시간 시세 · 유료          →  T+1 로는 매매를 못 한다
```

**실시간 매매를 하려면 실시간 시세를 사야 하고, 그건 돈이 든다.**
다만 구분이 있다 — **자기 매매용 시세는 재배포가 아니다.** 증권사 계좌를 열면
API 로 실시간 시세를 준다(재배포는 금지). **매매에 쓰는 것은 되고 기사에 쓰는 것은 안 된다.**
이 경계를 코드 수준에서 갈라 놓아야 한다. 섞이면 라이선스 위반이 된다.

### ③ 백테스트 성과는 실거래 성과가 아니다

12년 아카이브로 좋은 백테스트가 나와도 실거래는 다르다 —
슬리피지 · 수수료 · 체결 실패 · 유동성. **백테스트가 좋다는 이유로 원금을 넣으면 안 된다.**

**모의매매(페이퍼 트레이딩)를 먼저 충분히 돌린다.** 돈이 안 들고, 이 구간에서
설계 결함이 다 드러난다. 실적 기록은 그때부터 남긴다.

## 「전 세계에 흘러가는 것을 조합한다」 — 무엇을 조합하나

사장님 말씀의 핵심은 **한국 데이터 하나가 아니라 흐름의 조합**이다.
지금 가진 것과 붙일 수 있는 것을 적는다.

| 신호 | 출처 | 지금 상태 |
|---|---|---|
| 애널리스트 목표주가·의견 | 리서치 아카이브 12년 | **보유** |
| 수출 품목×국가 10일 속보 | 관세청 | 오늘 18시 키 |
| 공시 (실시간) | DART | 즉시 가능 |
| 환율·금리 | 공공데이터 | 가능 |
| 해외 지수·원자재 | 유료/무료 혼재 | 미확인 |
| 글로벌 자금 흐름 | 유료가 많다 | **미확인 — 여기가 비용이 큰 지점** |

**「전 세계 자금 흐름」이 이 목록에서 가장 비싸다.** 무료로 얻을 수 있는 범위를
먼저 확정해야 한다. 그게 안 되면 이 전략은 데이터 비용에서 막힌다.

# 5부. 순서 확정 — 투자업 먼저, 그 다음 증권사 (2026-08-02)

> 사장님: 「자산운용사 전 단계로 **투자업을 먼저** 하는 거야.」
> 「투자업이 잘되면 자산운용사를 **건너뛰고 바로 인터넷 증권사를 외국에 본사를 두고** 설립할 거야.」
> 「투자업은 **지금 법인**에서 해야겠지. **법인 자체 자금**으로 할 수밖에 없을 듯.」

## 1단계 — 투자업(자기자금 매매)은 지금 법인에서. 맞다

**별도 법인도, 등록도, 사람도 필요 없다.** 4부에서 확인한 대로 자기 자금·자기 계산의
매매는 금융상품거래업 등록 대상이 아니다. 지금 법인의 여유 자금으로 바로 할 수 있다.

### ⚠ 다만 처음부터 갈라 놓아야 하는 것이 있다 — 나중에 못 만든다

트랙레코드는 **나중에 라이선스 심사와 협상의 근거**가 된다. 그런데 매매 손익이
미디어 매출과 한 계정에 섞이면 **「우리 전략이 얼마를 벌었다」를 증명할 수 없다.**

| 처음부터 | 왜 |
|---|---|
| **매매 전용 계좌를 따로 연다** | 손익이 섞이면 성과 측정이 불가능해진다 |
| **회계 계정과목을 분리한다** | 세무·감사에서도 갈려야 한다 |
| **모든 주문·체결·판단근거를 로그로 남긴다** | 「그때 왜 샀는가」를 사후에 못 만든다 |
| **벤치마크를 먼저 정해 놓는다** | 나중에 정하면 유리한 것을 고른 것이 된다 |

**아카이브를 덮어쓰지 않는 원칙과 같다.** 오늘 안 남긴 기록은 2029년에 돈 주고도 못 산다.

## 2단계 — 「운용사를 건너뛰고 증권사」는 **건너뛰는 것이 아니라 더 높은 데로 가는 것**이다

확인한 숫자가 방향과 반대다.

| | 適格投資家向け **투자운용업** | **第一種**금융상품거래업 (증권업) |
|---|---|---|
| 최저 자본금 | **1,000만엔** | **5,000만엔** (PTS 운영 포함 시 **3억엔**) |
| 순자산 | — | 5,000만엔 이상 |
| 자기자본규제비율 | — | **120% 이상 상시 유지** |
| 이사회 | **불필요** | **필수** |
| **최소 인원** | 최소 | **외주를 써도 통상 5~6명** |
| 고객 자산 | 안 맡는 구조 가능 | **맡는다** → 분별관리·투자자보호 의무 |

**증권사는 자본금이 5배이고, 사람이 5~6명 필요하다.**
「사람한테 일을 맡기지 않는다」와 **정면으로 충돌하는 유일한 선택지**다.

그리고 5,000만엔은 **유지 요건**이다 — 밑돌면 등록 취소 사유이고,
신규 등록 때 **「앞으로도 이 기준을 안 깬다」를 당국에 설명**해야 한다.

### 그래서 두 갈래다. 사장님이 고르실 문제다

**갈래 A — 진짜 증권사를 세운다**
사람을 쓴다. 5~6명은 법이 요구하는 최소선이라 AI 로 대체할 수 없다.
컴플라이언스·고객대응·분별관리는 자동화 대상이 아니다.
**「사람을 안 쓴다」는 원칙을 여기서는 접어야 한다.**

**갈래 B — 증권사의 껍데기를 빌린다 (화이트라벨 · IB 구조)**
라이선스·체결·고객자산 보관은 **기존 증권사**가 하고,
우리는 **AI 와 화면(프론트엔드)** 만 제공한다.
요즘 네오브로커 상당수가 이 구조다.

```
갈래 A   우리가 라이선스를 갖는다   →  자본 5,000만엔 + 사람 5~6명 + 이사회
갈래 B   남의 라이선스에 얹는다     →  자본·인원 요건 없음. 마진을 나눈다
```

**갈래 B 가 지금 조건과 맞는다.** 그리고 이건 3부의 「재판매 파트너」와 같은 논리다 —
**라이선스가 필요한 자리는 남에게 맡기고, 우리는 라이선스가 필요 없는 것을 판다.**

### 순서를 다시 적으면

```
1단계  자기자금 매매        지금 법인 · 등록 불요 · 사람 불요        ← 오늘 가능
         ↓ 실적이 쌓이면
2단계  전략·지수 판매       라이선스 불요
         ↓ 둘 중 하나
3단계-B  화이트라벨 브로커   남의 라이선스에 AI 를 얹는다   ← 사람 없이 가능
3단계-A  適格投資家向け 운용업  자본 1,000만엔 · 이사회 불필요
         ↓ 규모가 커지면
4단계   第一種 (증권사)      자본 5,000만엔 · 사람 5~6명   ← 여기서 사람을 쓴다
```

**증권사는 마지막이지 지름길이 아니다.**

## 확인 못 한 것 — 5부

1. **화이트라벨/IB 구조가 일본에서 무등록으로 가능한 범위** — 「금융상품거래업자의
   대리·매개」에 해당하면 **金融商品仲介業** 등록이 필요할 수 있다. 이게 핵심이다
2. 외국 본사 + 일본 고객 대상 영업의 역외 규제 (일본 거주자를 상대하면 일본 규제가 붙는다)
3. 第一種 의 투자자보호기금 가입 의무와 부담금
4. 법인 자금으로 매매할 때의 **법인세·평가손익 처리** (한국 법인 기준)
