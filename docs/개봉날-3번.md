## ③ 🔴 되돌리는 것 — **제일 중요하다. 창이 죽어도 이 줄만 있으면 된다**

```
무엇이 잘못되면            어떻게 되돌리나
──────────────────────────────────────────────────────────────
값 화면이 이상하다          src/lib/price.ts 의 살수있나 를 **false** 로 되돌리고 배포
                          (자물쇠 순서 그대로. 열쇠는 커밋이 바뀌었으니 **다시 받는다**)
지면이 깨졌다              git revert <그 커밋> · git push · 배포
                          ⛔ git reset --hard 를 쓰지 않는다. 남의 커밋이 같이 날아간다
무엇이 나갔는지 모르겠다     git log --oneline -10 -- src/lib/price.ts
                          그리고 **라이브를 연다** — 저장소가 아니라 화면이 참이다
배포가 「못 쟀다」로 끝났다   실패가 아니다. ⛔ 다시 돌리지 말고 **라이브를 직접 잰다**
창이 죽었다                ⭐ 창이 열리면 **가장 먼저 매시 예약을 다시 건다**(:12 · :42)
                          그다음 이 문서를 연다
커밋 안 한 것이 있었다       ⛔ 창이 죽으면 커밋 안 된 것은 통째로 없어진다.
                          그래서 **켜기 전에 커밋부터** 한다
```
