> 2번 지시(04:1x) — *「그날 아침에 켤 것을 그날 정하면 반드시 빠뜨립니다.
> ③(되돌리는 것)이 제일 중요합니다 — **창이 죽으면 적어 둔 것만 남습니다**」*

⛔ 계획서가 아니다. **그날 아침에 그대로 따라 하는 차례표**다.
⛔ 오늘 켜지 않는다. 적어만 둔다.

## 🔴 먼저 — **「한 줄만 켜면 된다」가 틀렸다. 오늘 재서 알았다**

제가 어제부터 2번·1번께 *「`살수있나` 한 줄만 켜면 됩니다」*라고 여러 번 적었다. **틀렸다.**

```
grep -rn "살수있나" src/     →  **딱 한 곳** — src/lib/price.ts:52 에서 선언만 한다
                                읽는 곳이 **0곳**이다
```
⛔ 그 값을 `true` 로 바꿔도 **화면은 한 글자도 안 바뀐다.**
지금 `/price` 와 파는 지면은 `다음칸.머리/말/단추`(「곧 엽니다 · 열리면 알려 주세요」)를
**조건 없이** 그린다.

⭐ 그러니 개봉날 할 일은 「스위치 켜기」가 아니라 **「살 수 있을 때 보여 줄 화면을 만드는 것」**이다.
🔴 **그 화면이 지금 없다.** 이것이 이 문서에서 제일 중요한 한 줄이다.

⚠ 만드는 것은 **오늘 하지 않는다**(2번: 「오늘 켜지 마십시오」).
  다만 **D-5 안에 만들어 둬야 그날 켤 것이 생긴다.** 언제 만들지는 2번이 정한다.

## ② 재는 것 — **여섯 줄. 켠 뒤에 바로**

```
1  /price 가 200 이고 「아직 결제를 받지 않습니다」가 **사라졌나**
2  파는 지면 한 장(노원구)에 **사는 길**이 보이나 — 폰 375px 로 본다
3  값이 한 곳에서 오나 — 지면 두 곳의 값이 **둘 다 9,900원**인가
4  문 열일곱 갈래가 아직 200 인가            node (문 재는 자 · 오늘 쓴 것)
5  폰 첫 화면 — 메뉴가 아직 **59px 한 줄**인가
6  학교 설명에 숫자가 아직 **2,392장**에 있나
```
⛔ 「배포했다」로 ✅ 를 치지 않는다. **라이브에서 다시 재야** ✅ 다.
⚠ 자가 「못 쟀다」로 끝날 수 있다(새 지면 0장인 날). 그러면 **내가 라이브를 직접 재서** 적는다.

## ③ 🔴 되돌리는 것 — **제일 중요하다. 창이 죽어도 이 줄만 있으면 된다**

```
무엇이 잘못되면            어떻게 되돌리나
──────────────────────────────────────────────────────────────
값 화면이 이상하다          src/lib/price.ts 의 살수있나 를 **false** 로 되돌리고 배포
                          (자물쇠 순서 그대로. 열쇠는 커밋이 바뀌었으니 **다시 받는다**)
지면이 깨졌다              git revert <그 커밋> · git push · 배포
                          ⛔ git reset --hard 를 쓰지 않는다. 남의 커밋이 같이 날아간다
무엇이 나갔는지 모르겠다     git log --oneline -10 -- src/lib/price.ts
                          그리고 **라이브를 연다** — 저장소가 아니라 화면이 참이다
배포가 「못 쟀다」로 끝났다   실패가 아니다. ⛔ 다시 돌리지 말고 **라이브를 직접 잰다**
창이 죽었다                ⭐ 창이 열리면 **가장 먼저 매시 예약을 다시 건다**(:12 · :42)
                          그다음 이 문서를 연다
커밋 안 한 것이 있었다       ⛔ 창이 죽으면 커밋 안 된 것은 통째로 없어진다.
                          그래서 **켜기 전에 커밋부터** 한다
```

**되돌릴 수 없는 것 — ⛔ 미리 안다**
```
🖐 사장님이 유튜브에 올린 것 · 네이버에 등록한 것 — 우리가 못 되돌린다
⚠ 그래서 그 셋(⑤⑥⑦)은 **값 화면이 선 다음**에 부탁드린다. 순서를 바꾸지 않는다
```
