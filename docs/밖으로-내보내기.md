# 밖으로 내보내기 — **글자만으로는 안 된다** (1~6번 전부)

사장님 지시(2026-08-07): 「외부유입 콘텐트에 텍스트만 있으면 안 되겠지?
**콘텐트를 다양화**해서 서비스를 해. **스레드, 인스타, 유튜브, X** 등 유의미한 사이트에
콘텐트를 생산, 배포해」 · 「**1~6번 모두에게 해당**되니 잘 살펴」

---

## 1. 지금 우리 상태 — 먼저 사실부터

```
검색 유입   네 사이트 모두 **네이버 색인 0건**. 구글은 오지만 네이버는 제출을 안 했다
소셜 계정   **한 곳도 없다** — 스레드·인스타·유튜브·X 전부
내보낸 것   지면과 기사뿐. 전부 **글자와 표**다. 그림 한 장이 안 나갔다
```

⚠ 「콘텐트가 없어서」가 아니다. **모양이 하나뿐이라 나갈 곳이 없었다.**

## 2. 오늘 만든 것 — 카드 굽는 도구

`scripts/make-cards.mjs` (`--selftest` 있음). 사실 하나를 넣으면 **세 판을 한 번에** 굽는다.

```
1080×1350  인스타그램·스레드   타임라인에서 가장 크게 잡히는 세로
1080×1920  유튜브 쇼츠·릴스 표지
1200×675   X·카카오톡
```

### 카드에 반드시 들어가는 것 — 우리 강령이 그림에서도 지켜져야 한다

```
✅ 분포를 그린다        평균 하나만 크게 쓰지 않는다. 막대로 폭을 보여 준다
✅ 출처를 카드 안에      그림은 우리 지면을 떠나서도 혼자 서 있어야 한다
✅ 주소를 카드 안에      그림만 퍼지고 사람이 안 오면 유입이 아니다
⛔ 「해야 한다」를 쓰지 않는다   카드는 짧아서 규범으로 읽히기 더 쉽다
```

## 3. 무엇을 어디로 — 사이트마다 나갈 곳이 다르다

| 자리 | 사이트 | 말 | 맞는 곳 | 무엇을 |
|---|---|---|---|---|
| 1·4 | KLifeMap | 한국어 | 인스타 · 스레드 · 쇼츠 | 이름·사주 한 컷, 「같은 이름이 몇 명인가」 |
| 3 | 백년지도 | 한국어 | **스레드 · 인스타** | 나이 카드, 학과 취업률, 지역 비교 |
| 5 | K Culture Wire | 영문 | **X · 레딧** | 「아무도 안 센 숫자」 한 컷 |
| 6 | SeoulMarkets | 영문 | **X · 링크드인** | 시장 데이터 한 컷 · B2B 미끼 |

⚠ 한국어 사이트를 X 에, 영문 사이트를 스레드에 올리지 않는다. **독자가 다르다.**

## 4. 영상 — 지금 되는 것과 안 되는 것

```
✅ 지금 된다   카드 여러 장 = 쇼츠 표지 · 슬라이드(인스타 캐러셀). 도구가 이미 있다
⛔ 아직 안 된다 진짜 동영상 — ffmpeg 가 이 PC 에 없다
```
⚠ 영상은 **표지·슬라이드부터** 한다. 없는 도구를 기다리며 멈추지 않는다.

## 5. 🔴 사장님 손이 필요한 것 — 계정

```
스레드 · 인스타그램 · 유튜브 · X — **계정이 하나도 없다.**
계정 만들기는 본인 인증이 걸려 **저희가 할 수 없습니다.**
```
계정이 없으면 카드를 아무리 구워도 나갈 곳이 없다. **16:00 요청에 올린다.**

⚠ 그때까지 멈추지 않는다 — **카드를 미리 구워 쌓아 둔다.** 계정이 열리는 날 그날치가 아니라
**한 달치가 나간다.**

## 6. 몇 개를 만드나 — 지금 우리 데이터로 셀 수 있는 것

```
백년지도   나이 5장 × 축 4개 = 20장 · 학과 837 중 눈에 띄는 것 20장 · 지역 17장
KCW       기사 10편 × 각 1장 · 지면 20장 중 10장
SeoulMarkets 기사 23편 × 각 1장
KLifeMap   이름·사주 축 (1번 판단)
```
**셋을 합치면 100장 언저리다.** 하루 한 장씩 내보내도 석 달치다.
⛔ 한 번에 다 굽지 않는다. **한 자리가 하루 세 장**이면 충분하고, 그게 지면 만드는 일을 안 밀어낸다.

## 7. 순서

```
지금~오픈(8/15)   각 자리가 **하루 세 장**씩 굽는다. archive/cards/ 에 쌓는다
계정 열리는 날     쌓인 것을 날짜별로 내보낸다
오픈 뒤           반응을 재서(어느 카드가 들어왔나) 다음 것을 정한다
```
⚠ 카드에 넣은 주소로 들어온 유입을 잰다. **재지 않으면 다음 카드를 정할 근거가 없다.**
