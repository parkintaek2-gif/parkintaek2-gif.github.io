# 5번 — **재 보고 «안 짓기로» 한 것**

> 「재 보고 안 된다고 적는 것도 결과다.」 — `docs/모토와-철학.md`

이 문서는 **지어야 할 것을 적는 곳이 아니다.** 재 봤더니 **우리가 답할 자리가 아니어서
안 짓기로 한 것**을 적는 곳이다. 안 적어 두면 다음 창이 같은 것을 다시 재고 다시 짓는다.

두 걸음으로 판정한다 —

```
① 손님이 «치는 말»을 잰다            자동완성 가지 수(measure-keyword-demand.mjs)
② 그 말에 «우리가» 답할 수 있나를 잰다  ⛔ 「남이 이미 완벽히 답하고 있나」가 여기 들어간다
③ ①과 ②가 겹치는 자리만 짓는다
```

🔴 **②가 가장 자주 걸린다.** 수요가 큰 말이라도 구글이 지식패널로 즉시 답하면
우리가 이길 자리가 아니다. 그 말로 지면을 내면 지면만 늘고 손님은 안 온다.

---

## 1. 노래 제목 — **안 짓는다** (2026-08-25 판정)

사장님이 축 셋을 말씀하셨다 —
> 「특히 케이컬쳐는 **스타의 이름, 작품명, 노래제목** 등이겠지」

앞의 둘은 지었다(`/person` 636장 · `/title` 556장). 셋째를 재고 **안 짓기로 했다.**

### ① 재 본 것 — 노래 열 곡 × 다섯 꼴, 자동완성 가지 수 합

```
lyrics         97      0인 것 0/10
meaning        41      0인 것 0/10
release date   18      0인 것 0/10
chart           8      0인 것 4/10
countries       0      0인 것 10/10   ← 우리 축이다
```
(잰 곡: Dynamite · Butter · Gangnam Style · How You Like That · Fancy · Ditto ·
Cupid · Love Dive · Kill This Love · Next Level. 자료 —
`archive/keyword-demand/song-phrases-20260825.json`)

### ② 그래서 왜 안 짓나

```
lyrics 97      ⛔ 가사는 «남의 저작물»이다. 우리가 낼 수 없고, 내서도 안 된다
meaning 41     ⛔ 「이 노래는 이런 뜻이다」는 «해석»이다. 우리 강령이 조언을 금한다
release date 18 ⛔ 구글이 지식패널로 «즉시» 답한다. 우리가 이길 자리가 아니다
chart 8 / countries 0
               🔴 **우리 축에 수요가 0 이다.** 넷플릭스 나라별 톱10 은 «영상»이지 음원이 아니다.
                 곡별 음원 차트 자료를 우리는 **갖고 있지 않다.**
```

⚠ 그러니 노래 지면을 낸다면 **우리가 가진 것으로는 답이 안 되는 물음**에
**얇은 지면 수백 장**을 내는 일이 된다. 그것은 오늘 아침 `/title` 색인을 재며 본 함정 그대로다.

### ⭐ 뒤집힐 조건 — 이때는 다시 잰다

```
· 곡별 «나라별» 차트 자료를 손에 넣었을 때 (음원 차트를 쓸 수 있게 되면)
· OST 를 작품에 잇는 자료가 두꺼워졌을 때 — 「이 노래가 나온 드라마가 어디까지 갔나」는
  우리 축으로 답할 수 있는 물음이다. ⚠ 지금은 위키데이터 쪽 연결이 얇아 못 재 봤다
```

## 2. 키(신장) 지면 — **안 짓는다** (2026-08-24 판정)

`{그룹} members height` 수요는 나이보다 컸다. 그러나 위키데이터에 키가 적힌 한국
연예인이 **9,249명 중 320명(3.5%)**뿐이다. 96.5%를 「모름」으로 채운 표를 내는 것은
지면이 아니라 빈칸이다. `/group` 지면의 FAQ 에 「**We cannot tell you**」로 적어 두었다.

## 3. 넷플릭스 주소 검색 — **쫓지 않는다** (2026-08-24 판정)

검색 실측에서 노출 396건 중 **222건**이 `netflix.com/title/…` 꼴의 «길찾기» 검색이었다.
그 손님은 넷플릭스로 가려는 것이지 자료를 보려는 것이 아니다. 순위를 올려도 클릭이
우리에게 오지 않는다. ⛔ 노출 수만 보고 「기회」로 읽지 않는다.
`measure-click-gap.mjs` 의 `남의주소찾기` 가 이 줄을 걸러 낸다 — **거를 자가 이미 있다.**
