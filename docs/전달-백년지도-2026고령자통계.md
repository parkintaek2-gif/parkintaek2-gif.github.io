## 🔴 내가 보기에 백년지도에 **가장** 값어치 있는 축 — 「몇 살까지 일하나」

백년지도는 0~100세 지도이고, 지도의 뒷부분에서 사람이 가장 많이 묻는 것은
**「나는 언제까지 벌어야 하나」**다. 그 답이 이 자료에 숫자로 있다.

```
65세 이상 고용률           39.5%  (2025) — 열에 넷이 «지금» 일하고 있다
65~79세 「앞으로 일하고 싶다」  58.7%  (2026) — 열에 여섯이 더 일하려 한다
  남자 66.5% · 여자 51.8%
그 까닭  생활비 보탬 50.4%  ·  **일하는 즐거움 38.7%**
65세 기대여명              21.7년 (2024) — 남 19.5 · 여 23.7
```

⭐ **「일하는 즐거움 38.7%」가 이 자료에서 제일 센 수다.**
  통념은 「돈이 없어 어쩔 수 없이 일한다」인데, 열에 넷은 즐거워서라고 답했다.
  남이 이미 센 것(고용률)은 어디에나 있지만 **그 «까닭»을 센 것은 드물다.**

⛔ 그리고 이 수를 «판정»으로 쓰지 않는다.
  「65세에도 일해야 한다」로 쓰면 그 순간 규범이 된다.
  **「10명 중 4명이 그렇게 했다」로 놓고 판단은 보는 사람이 한다.**

## 사장님이 시키신 것 — 셋을 다 한다

### ① db 로 저장한다

보도자료 PDF 는 자료가 아니라 «종이»다. 해마다 나오는 통계이므로
**내년 것이 나와도 같은 자로 읽히게** 표로 만들어 둔다.

```
✅ 해마다 쌓이는 꼴로 둔다 — 연도 · 항목 · 값 · 단위 · 출처
✅ 시계열이 있는 것은 10년치를 다 넣는다 (본문.txt 에 표가 그대로 있다)
✅ 원자료는 KOSIS 에도 올라온다 — 보도자료 숫자를 손으로 옮기기 전에 KOSIS 를 먼저 본다
⛔ 「2026년 21.6%」 한 줄만 저장하지 않는다. 그러면 내년에 다시 처음부터 한다
⛔ 못 찾은 칸을 0 으로 메우지 않는다. 「미확인」으로 적는다
```

### ② 콘텐트를 만든다

```
✅ 손님이 «실제로 검색하는 말»로 만든다 — 「65세 정년」·「노후 생활비 얼마」·
   「국민연금 월 얼마」처럼. 「고령자 통계」로는 아무도 안 찾는다
✅ 제목에 수를 넣는다 — 「65~79세 10명 중 6명이 더 일하고 싶다고 답했다」
✅ 평균이 아니라 «분포». 그리고 지면마다 「이것은 통계이지 당신이 아닙니다」
⛔ 「65세에도 일해야 한다」 같은 조언을 쓰지 않는다. 사실만 놓고 판단은 본인이 한다
```

### ③ 페이지를 만든다

```

   JS 로만 그리는 표는 구글에 빈 화면이다
✅ 사이트맵·llms.txt 에 같은 커밋으로 등록한다 (지난번 OECD 건이 여기서 빠졌다)
✅ 낸 뒤 라이브에서 curl 200 과 색인 요청까지 해야 끝이다
```
