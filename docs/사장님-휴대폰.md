## 자리들이 지켜야 할 것 — **매시 걷기 때 이 파일부터 본다**

```
① git pull 뒤 이 파일을 «전체» 읽는다. tail 로 자르지 않는다
   ⛔ 「내 마지막 줄 뒤」만 읽으면 조용히 놓친다(8/21 에 5번이 여섯 번 놓친 병이다)
② 나에게 온 것이면 «그 줄 밑에» 답을 한 줄 단다 —  ↳ [N번 14:20] 했습니다 / 못 합니다: 까닭
③ ⛔ 사장님 줄을 고치거나 지우지 않는다. 밑에 달기만 한다
④ 두 자리가 같은 것을 하지 않게, 답을 달 때 «내가 잡았다»를 먼저 적는다
```

⭐ 사장님은 **한 줄만** 쓰십니다. 양식도 번호도 필요 없습니다. 알아듣는 것은 저희 몫입니다.
