## 🔑 자리별 로그인 차례 (2번이 적음, 2026-08-22 03:3x)

**바탕화면 `00_세션입구\자리로그인.cmd` 를 더블클릭 → 아래 순서대로 번호만 넣으시면 됩니다.**
한 자리에 1분 안팎입니다. 순서는 급한 것 먼저입니다 — 굳이 이 순서를 안 지켜도 됩니다.

```
1) 3번 백년지도(100yearmap) — 지금 열려서 돈 버는 지면이 여기다
2) 6번 서울마켓(seoulmarkets) — 관세청 API·유료지면 이어가야 함
3) 5번 케이컬처와이어(kculturewire) — 배포 대기 커밋이 있음
4) 1번 KLifeMap
5) 4번 KLifeMap 보조
```

**자리마다 이렇게 하십시오**
```
① 자리로그인.cmd 더블클릭 → 화면에 뜨는 번호(1~6 중 이번 차례 번호) 입력 → Enter
② 창이 열리면 /login 입력 → Enter
③ 뜨는 긴 인터넷 주소를 복사해서, 그 번호에 맞는 크롬 프로필(uN) 창에 붙여넣기
   (u1=KLifeMap 계정 · u3=백년지도 계정 … 프로필 이름에 번호가 있습니다)
④ 승인 화면에서 계정이 맞는지 한 번 보고 승인
⑤ 코드가 나오면 그 코드를 로그인 창에 붙여넣기
⑥ "로그인됨" 이 뜨면 반드시 /exit 로 나오십시오 (X 로 닫지 마십시오 —
   닫아도 다음에 이 도우미를 열면 스스로 고치지만, /exit 가 더 깨끗합니다)
⑦ 로그인이 끝났으면 00_세션입구 바탕화면에서 그 번호의 «N번_이름.cmd» 단추를 눌러
   실제 일하던 대화를 이어 엽니다 — 이게 진짜 그 자리입니다
⑧ 다음 번호로 ①부터 반복
```

⚠ ③에서 크롬 프로필을 잘못 고르면(예: 3번인데 1번 계정에 로그인) 자리가 서로의 계정을
쓰게 됩니다. 브라우저가 저절로 다른 계정으로 열리면 그 창은 닫고 맞는 프로필로 다시 여십시오.
