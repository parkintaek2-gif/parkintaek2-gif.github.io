# 판매대금 수취 방안 (외국계좌 없이) — 전사 공용

> 사장님 지시(2026-08-08): 「번 돈을 **외국계좌를 만들지 않고** 받을 수 있는지 파악하고 만들어. 만들면 **다른 세션에서도 쓰게** 해.」
> ⛔ 실제 계정 가입·판매 개시는 사장님/2번 게이트(법인 명의·계좌·법무). 6번은 **무엇을·어떻게·수수료·정산흐름**까지 준비한다.

## 결론 — Merchant of Record(MoR)를 쓴다
해외에 데이터/디지털 상품을 팔 때, **MoR가 법적 판매자가 되어** 글로벌 부가세·판매세·컴플라이언스를 대신 처리하고, **정산은 한국 원화 계좌로** 넣어준다. 해외 법인·해외 은행계좌가 **필요 없다.**

| 방식 | 외국계좌 필요? | 세금 처리 | 정산 → 한국 | 수수료(대략) | 적합 |
|---|---|---|---|---|---|
| **Lemon Squeezy** (MoR) | ❌ 불필요 | MoR가 전담 | 은행송금·PayPal(45+개국 은행 지원) | ~5% + $0.50 | 디지털/데이터 상품·구독. 셋업 간단 ⭐ |
| **Paddle** (MoR) | ❌ 불필요 | MoR가 전담 | Wire·Payoneer(→한국 계좌) | ~5% + $0.50 | 한국 로컬카드 22종 지원·SaaS ⭐ |
| Payoneer / Wise Business | ❌ 불필요(가상 수취계좌) | **직접** 처리해야 | 가상 USD 계좌 → 한국 원화 인출 | 수취 낮음 | 세금 직접이라 MoR보다 손 많이 감 |
| Stripe | 한국 지원 제한 | 직접 | | | 한국 사업자엔 제약 |

## 추천 — Lemon Squeezy 또는 Paddle 중 하나
- **데이터 CSV·리포트·API 판매가 주력이면 Lemon Squeezy** — 디지털 상품·구독에 최적, 셋업이 가장 간단, MoR로 세금 걱정 0.
- **한국 고객 카드결제·SaaS 구독이 크면 Paddle** — 한국 로컬카드(신한·현대·삼성·국민 등) 지원, 한국 사업자 가이드 있음.
- 둘 다 **한 계정으로 여러 상품·여러 사이트(세션)**를 판다 → 사장님 지시("다른 세션도 쓰게")에 맞다.

## 정산 흐름 (외국계좌 0)
```
해외 고객 카드결제 → MoR(Paddle/Lemon Squeezy)가 수금·세금처리 → 수수료 뗀 잔액을
   → 한국 원화 은행계좌(직접) 또는 Wise/Payoneer 경유 → 사장님 법인계좌
```

## 셋업 절차 (사장님/2번이 가입 — 6번은 연동 담당)
```
1. [사장님] Lemon Squeezy 또는 Paddle 가입 — 법인 정보·사업자등록·정산 계좌 입력
2. [사장님] 세금 정보(W-8BEN-E 등) 제출 — MoR가 안내
3. [6번] 상품 등록(CSV/리포트/구독) + 우리 사이트에 결제 링크·체크아웃 연동(코드)
4. [6번] provenance·라이선스 확인(팔아도 되는 데이터만 — docs/데이터-구매-검토.md)
5. [게이트] 실제 판매 개시는 사장님 승인 + 라이선스 정리 완료 후
```

## 전 세션 공용
한 MoR 계정으로 SeoulMarkets·K Culture Wire·백년지도 등 **전 세션 상품을 같은 결제·정산 파이프로** 판다. 세션별로 상품만 등록하면 된다. 계정·정산은 사장님 법인 하나로 통합.
