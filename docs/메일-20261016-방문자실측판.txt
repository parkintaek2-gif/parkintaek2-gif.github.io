1. 먼저 - 제가 틀렸던 것을 바로잡았습니다

사장님이 「내가 말했다고 확인도 안하고 우리가 누른거라고 한거지?」 하셨습니다.
맞습니다. 재지 않고 썼습니다. 지금 갈라 보니 반만 맞았습니다.

구글 애널리틱스 Direct 2,056명을 셋으로 갈랐습니다.

  우리가 누른 것        969명 (47%)
  봇.클라우드           318명 (15%)
  진짜 손님             734명 (36%)   <- 제가 통째로 버렸던 사람들입니다

우리를 가려낸 증거는 이것입니다. 세종시로 잡히는 덩어리인데,
그 안에 localhost 와 127.0.0.1 이 같이 들어 있습니다.
손님이 localhost 를 열 수는 없습니다. 이 PC 입니다.
98.5%가 데스크톱 크롬 한 기기이고 언어가 100% 한국어이며
날마다 25~75명으로 평평합니다. 사람은 이렇게 안 움직입니다.

봇을 가려낸 증거는 1인당 조회수입니다.
싱가포르.암스테르담.프라하.The Dalles(구글).Ashburn(아마존) 에서 오는데
한 사람이 정확히 1.0장을 보고 나갑니다.

진짜 손님의 증거도 같은 자입니다.
서울 253명은 거의 전부 휴대폰이고 한 사람이 2.3~3.0장을 봅니다.
우리는 휴대폰으로 점검하지 않습니다.

그래서 28일 바깥 손님을 다시 세면 1,339명입니다.
  진짜 손님(Direct)   734
  검색                 376
  AI 어시스턴트        193
  소셜                  28
  다른 사이트           8

전에 62명이라고 보고드렸습니다. 스무 배 넘게 깎아서 올린 것입니다.
채널 이름만 보고 통째로 버린 탓입니다. 다시는 그렇게 안 하겠습니다.


2. 구글 애널리틱스가 오늘 0명인 까닭

사이트 문제가 아닙니다. 네 가지를 재서 확인했습니다.

  네 사이트 모두 태그가 살아 있고 HTTP 204 로 받아들여집니다
  실시간 보고에 지금 사람이 잡힙니다
  측정 ID 와 속성이 짝이 맞습니다
  스트림 설정은 8월 8일 이후 바뀐 적이 없습니다

결정적인 것은 이것입니다.
같은 자리를 두 번 쟀더니 어제 수치가 118명에서 142명으로 늘어 있었습니다.
어제치도 아직 차는 중입니다. 구글이 오늘치를 아직 안 붙인 것입니다.

내일 아침에 오늘치가 채워지는지 다시 재서 말씀드리겠습니다.
안 채워져 있으면 그때는 다른 까닭입니다.


3. 구글이 검색을 막은 것이 아닙니다

구글에게 직접 물었습니다.

  seoulmarkets.com     색인에 있다  마지막 크롤 2026-10-08
  kculturewire.com     색인에 있다  마지막 크롤 2026-10-11
  100yearmap.com       색인에 있다  마지막 크롤 2026-10-14

사이트맵도 흠 0 으로 받았습니다. robots.txt 정상이고 막는 설정이 없습니다.

막기는커녕 노출이 늘고 있습니다.
seoulmarkets 는 9월 27일 9회에서 10월 13일 458회로 올랐습니다. 최고치입니다.
제재가 걸리면 이 줄이 절벽처럼 0 으로 떨어집니다. 반대로 가고 있습니다.

진짜 까닭은 자리입니다.
  seoulmarkets   29일 노출 3,072회  클릭 19회   평균 자리 13.3위
사람이 2페이지를 안 넘깁니다. 그래서 노출이 458회여도 클릭이 6회입니다.

kculturewire 는 반대입니다. 자리는 7~9위로 좋은데 노출이 하루 20~40회뿐입니다.
자리를 못 잡은 게 아니라 그 말을 찾는 사람이 적습니다.
병이 서로 다르니 처방도 달라야 합니다.

klifemap.ai 만 29일 노출이 4회입니다. 색인 자체가 거의 안 됐습니다.


4. 못 한 것 - 숨기지 않고 적습니다

서버 로그로는 순방문자를 셀 수 없습니다.
IP 도 쿠키도 일부러 안 남기기 때문입니다.
그래서 서버 로그의 수는 조회수이지 사람 수가 아닙니다.
사람 수가 필요하면 구글 애널리틱스를 봐야 합니다.

서버 로그의 「하루」는 서버 시계가 UTC 라 한국시간 09:00 부터입니다.
오늘 00~09시 치는 어제 파일에 섞여 있어 갈라낼 수 없습니다.

Direct 안에 (not set) 138명이 남았습니다. 도시가 안 잡혀
우리인지 손님인지 못 갈랐습니다. 그래서 734명은 위쪽 어림이고
아래쪽은 약 640명입니다.

네이버 애널리틱스는 아직 못 열었습니다. 화면이 멈춰서 다시 붙는 중입니다.
네 사이트가 각각 다른 ID 로 따로 집계되는 것은 확인했습니다.
