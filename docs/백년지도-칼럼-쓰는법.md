# 백년지도 칼럼 쓰는 법

사장님이 직접 쓰시는 칼럼 코너입니다. 이름은 「백년지도 칼럼」, 필자는 「백년지도」로 나갑니다.

## 1. 들어가기

1. 주소창에 `https://100yearmap.com/admin/column` 을 넣습니다.
2. 편집국 계정과 비밀번호를 넣습니다(지금 쓰시는 편집국 계정 그대로입니다).
3. 칼럼 목록이 나옵니다. 제목·카테고리·상태(공개/임시저장)·작성일이 보이고, 새 글이 맨 위에 있습니다.

## 2. 글쓰기

1. 「글쓰기」를 누릅니다.
2. 제목, 부제(적지 않아도 됩니다), 카테고리, 본문을 적습니다.
3. 아래 단추 가운데 하나를 누릅니다.
   - 「미리보기」 — 저장하지 않고 어떻게 보이는지만 봅니다.
   - 「임시저장」 — 편집국에만 남고 사이트에는 나가지 않습니다.
   - 「공개」 — 바로 사이트에 나갑니다. 백년지도 첫 화면의 최근 칼럼 칸과 칼럼 목록에 올라갑니다.

## 3. 본문 적는 법

| 이렇게 적으면 | 이렇게 보입니다 |
|---|---|
| 빈 줄 하나 | 문단이 나뉩니다 |
| `**중요한 말**` | **굵은 글씨** |
| `[학과 찾기](/major)` | 링크 (우리 사이트 안 주소는 `/` 로 시작) |
| `[통계청](https://kostat.go.kr)` | 바깥 사이트 링크 |
| `## 소제목` (줄 맨 앞) | 소제목 |

그 밖의 기호는 적은 그대로 글자로 나옵니다.

## 4. 고치기·내리기·지우기

- 목록에서 「수정」을 누르면 고칠 수 있습니다. 「공개」를 누르면 고친 글이 바로 나갑니다.
- 공개한 글을 「임시저장」하면 사이트에서 내려갑니다.
- 「삭제」는 확인창이 한 번 더 뜹니다. 지운 글은 되살릴 수 없습니다.
- 한 번 공개한 글은 주소가 바뀌지 않습니다(밖에 퍼진 링크가 깨지지 않게).

## 5. 어디에 보이나

| 자리 | 주소 |
|---|---|
| 칼럼 목록 | https://100yearmap.com/column |
| 카테고리별 목록 | https://100yearmap.com/column?c=edu (교육·진학) · work-money (일과 돈) · home-family (집과 가족) · aging (나이 듦) · society (사회와 통계) |
| 칼럼 한 편 | https://100yearmap.com/column/제목에서-만든-주소 |
| 첫 화면 | 본문 3분의 1쯤, 「학원을 팔지 않습니다」 표 바로 아래에 최근 칼럼 셋 |

칼럼이 한 편도 없으면 첫 화면에는 아무 칸도 나오지 않습니다.

## 6. 일하는 사람이 알아 둘 것

- 글은 R2 저장소에 있습니다 — `100y/columns/index.json`(목록), `100y/columns/posts/<id>.json`(글 하나). git 에는 없습니다.
- 카테고리를 늘리려면 `src/lib/column.mjs` 의 `카테고리` 목록에 한 줄을 더하고 배포합니다. 이미 쓴 key 는 바꾸지 않습니다.
- 시험은 `node scripts/check-100y-column.mjs` 로 합니다(R2 를 끄고 임시 폴더에서만 돕니다).
