# 6번 배포 퀴즈 — 매일 이걸 통과해야 그날 일이 시작된다 (사장님 지시 2026-08-09)

> 사장님: **「콘텐츠를 한 유형으로만 만들지 마. 숏츠도 카드도 카드뉴스도 만들고, 자체 사이트·유튜브·
> 스레드·인스타그램에 다 올려라. 그걸 퀴즈로 만들어. 통과되면 그날 일이 시작해.」**
>
> ⛔ 「기사 한 편 냈다」는 통과가 아니다. 아래 9문을 **콘텐츠 하나마다** 통과해야 한다.
> ⭐ 매출은 유입이 연료다 — 형식·채널을 늘리는 것이 곧 매출이다(자료판매·애드센스·임베드 전부).

## 콘텐츠 한 편당 9문 (◯/✕/게이트)
```
Q1 만들었나        기사가 있다(draft:false)
Q2 배포됐나        라이브 200
Q3 검색되나        사이트맵에 있다 · noindex 아님 · (Search Console 제출 = 사장님 계정)
Q4 og 카드         공유 카드 PNG 있다
Q5 숏츠            30초 영상 대본 + 렌더 파일 있다
Q6 카드뉴스        이미지 카드 묶음(캐러셀 5~8장) 있다
Q7 포스트 문안     스레드/X/인스타 캡션 있다
Q8 채널에 올렸나   자체사이트 / 유튜브 / 스레드 / 인스타 (각각)
Q9 매출에 걸었나   상품 CTA 링크 + (해당되면) 광고 자리
```

## 그날 관문 (매일 아침)
```
오늘·어제 낸 콘텐츠가 Q1~Q9 를 다 통과했나?
  통과 → 새 콘텐츠를 시작한다
  미달 → ⛔ 새 것 만들기 전에 그 구멍(형식·채널)부터 채운다
```
⭐ 「기사만 44편, 숏츠 0·카드뉴스 0·유튜브 0」이면 그날 일은 **새 기사가 아니라 그 44편의 형식·채널 채우기**다.

## 자동으로 재는 것 / 사람 손이 필요한 것
```
자동(scripts/deploy-quiz.mjs 가 잰다): Q1·Q2·Q3·Q4·Q9, 그리고 Q5~Q7 의 「파일이 있나」
사람 손(사장님 계정): Q3 Search Console 제출 · Q8 유튜브·스레드·인스타 업로드 · 애드센스(검토중)
⛔ 계정이 걸린 칸은 「못 함」이 아니라 「준비됐다 · 계정만 열면 오늘 올라간다」로 적는다(자산은 미리 만들어 둔다)
```
