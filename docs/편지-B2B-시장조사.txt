제목: [6번] B2B 거래 성사 조건 — 시장조사·벤치마킹 결과

사장님께,

지시하신 「B2B 거래가 이뤄지려면 무엇을 해야 하는가」 시장조사·벤치마킹을 마쳤습니다. 전문은 업무보고에 저장했습니다(OneDrive\업무보고\6번_B2B거래-시장조사벤치마킹_20260831.md).

■ 우리 B2B 상품 = 영문 한국 금융·경제 데이터 API(/v1) — 재현 가능·출처 명시.

■ 결론(한 줄): B2B는 «상품을 살 수 있게 만드는 것»에서 시작합니다. 지금 우리의 가장 큰 공백은 «살 방법 자체가 없다»(가격·무료체험·셀프 API키·라이선스 조항 없음)는 것입니다.

■ 벤치마크(가격): FactSet ~$12K/user/yr(대형 $150K+), ZoomInfo API ~$15K/yr, Intrinio는 «낮은 진입가→확장»(우리 모델 원형). API 대상은 좌석당이 아니라 요청당·크레딧당 + 무료 체험 티어가 필수.

■ 니치: 한국 데이터 영문+LLM용은 DeepSearch/Finorma가 한국어로 이미 하고 있고, «영어로, 재현·정직하게» 하는 자리가 비어 있습니다. AI/LLM 빌더가 1순위 손님.

■ 거래에 반드시 필요한 것: ①문서화된 API 스펙 ②품질 보증+측정방법(우리 강령 재현·«못 잰 건 못 잼»이 곧 이것) ③문서화된 라이선스·재배포 권리 ④SLA(가동률·지연; SOC2 인증은 큰손 요건이라 작은손·AI빌더부터) ⑤투명 가격+무료 체험.

■ 우리가 바로 할 것: (1) /data·/pricing에 가격 티어+무료체험+라이선스 붙이기 (2) API 문서·예제 정리 (3) 콘텐트→API 깔때기(기사·논쟁거리 끝에 "이 데이터를 API로") (4) [결정 필요] B2B 청구·계약 수단(현재 결제는 광고뿐).
