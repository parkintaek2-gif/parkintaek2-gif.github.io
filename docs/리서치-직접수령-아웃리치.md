# 증권사 리서치 **직접 수령** — 명단과 요청서

> 사장님 지시(2026-08-03 KST):
> **「최신 애널 리포트는 직접 받든지 갖고 와. 우린 인터넷신문으로 등록하니까」**

이 문서는 **내가 실행한다.** 사장님은 영업을 안 하신다 — 명단·초안·발송은 내 몫이다.
사장님께 넘기는 것은 **최종 확인 한 번**뿐이다.

## 1. 왜 이것이 다른 모든 경로보다 나은가 — 재 본 결과

2026-08-03 KST 에 세 경로를 다 실측했다.

```
① 네이버 금융 긁기
   robots.txt  User-agent:* → Disallow:/     ⛔ 위반이다
   데이터베이스제작자 권리(저작권법 §93)      ⚠ 미검토. 이쪽이 robots 보다 무겁다
   시점         T+1. 화면에 올라온 뒤에야 안다

② 증권사 사이트 개별 긁기
   robots       28곳 중 22곳 허용 ✅  (하나·신영·한국투자·LS 제외)
   그런데 실제로 받아 보니 **22곳 중 5곳만 평문 HTML** 이다
   나머지 17곳은 JS 로 그리는 SPA — 받으면 빈 껍데기가 온다
   ⛔ **스크래퍼 22개를 만들고 유지해야 한다.** 사이트 개편 한 번에 깨진다

③ 직접 수령 (언론 배포)  ← 이것으로 간다
   경로         이메일 수신 하나. 증권사가 보내 준다
   시점         ⭐ **발행 시각.** T+1 제약이 풀린다
   범위         PDF 원본까지 온다 (우리는 사실만 쓰지만 확인은 원본으로 한다)
   논쟁         없다. 배포받은 것을 인용하는 것이 언론의 정상 동작이다
```

**②는 ③이 안 되는 곳을 메우는 보조로만 쓴다.** ①은 최후다.

## 2. 이 요청이 통하는 이유 — 이해가 서로 맞는다

증권사 리서치센터는 리포트를 **팔려고** 만들지 않는다. **알려지려고** 만든다.

> 사장님(경제지 인터넷총괄에디터 20년):
> 「리서치는 시비 걸지 않는다. 언론사한테는. **자기들 리포트가 더 퍼지는 걸 좋아하지. 애널들이**」

그리고 우리는 **영문 매체**다. 국내 매체에 나가는 것과 **미국·싱가포르 독자에게 영문으로
나가는 것**은 리서치센터 입장에서 값이 다르다. **이것이 우리 협상력이다.**

요청서에 이 점을 앞세운다 — 「받게 해 달라」가 아니라 **「당신 리포트를 영문으로 내보내겠다」**.

### 🔴 이 표에서 나온 것 둘 — 요청서의 근거가 여기 있다

**① 1위가 막혀 있다.** 하나증권 9,338건은 전체의 15%인데 robots 가 전면 금지다.
   LS증권 5,965건도 마찬가지다. **둘을 합치면 15,303건 — 직접 수령 말고는 길이 없다.**

**② 대형사가 거의 없다. 이쪽이 더 중요하다.**

```
삼성증권    381건        한국투자증권  179건
KB증권       27건        NH투자증권     10건
```

한국 최상위 하우스들이다. 실제 발행량이 이럴 리 없다.
즉 우리 아카이브는 **「한국 증권사 리서치 전부」가 아니라 「네이버가 싣는 것」**이다.

**이것을 상품 설명에 밝힌다.** 안 밝히면 첫 이용자가 삼성증권을 조회하고 우리를 버린다.
(`/api` 페이지와 `/v1/research` 의 `coverage` 에 넣는다)

**그리고 이것이 직접 수령의 가장 큰 이유다.** 긁기로는 이 구멍을 못 메운다 —
네이버에 없는 것은 아무리 잘 긁어도 없다. **받아야 생긴다.**

   각 사 사이트에서 확인해 이 표에 적는다.

## 5. 실행 순서

```
1. 아카이브 건수를 증권사별로 뽑는다              ← 지금 할 수 있다
2. 22곳 + 제외 4곳의 리서치센터 연락처를 확인한다   ← 사이트에서 확인. 추정 금지
3. 요청서를 증권사별로 건수만 바꿔 넣는다
4. 발송 — ⚠ 사장님 최종 확인 뒤에 보낸다
   (대외 발송이라 내 판단으로 보내지 않는다. 준비까지가 내 몫이다)
5. 회신을 표에 적는다. 승낙한 곳부터 ②(긁기)를 끈다
```

⚠ **인터넷신문 등록이 진행 중이다.** 요청서에 「등록 중」이라 적었다 —
**등록증 번호가 나오면 그 줄을 번호로 바꾼다.** 있는 척하지 않는다.
