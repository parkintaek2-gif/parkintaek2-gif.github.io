# 네이버 https 등록 — 남은 한 걸음

🔴 사장님 2026-10-18 — 「네이버 등 검색엔진, AI에서도 유입되게 잘 해」

## 왜 하는 일인가

네 사이트 가운데 **klifemap 만 https 등록이 없었다.**

```
https://100yearmap.com        ✓ 26.08.26
https://seoulmarkets.com      ✓ 26.08.08
https://www.kculturewire.com  ✓ 26.08.08
http://klifemap.ai            26.07.30  ← 이것뿐이었다
```

네이버가 진단에 직접 적어 두고 있었다 —
「보안 인증서 ⚠ 서치어드바이저에 https 사이트로 등록 바랍니다」
「콘텐츠 노출/클릭 정보가 없습니다」

우리 사이트는 https 로 돈다. 네이버는 http 와 https 를 **다른 사이트로 본다.**

```
✅ https://klifemap.ai 를 목록에 등록했다      (26.10.18)

   https://klifemap.ai/naver0423c2906bae9ea02a5466d61b8bc908.html

     네이버는 그 파일에 한 줄만 있기를 바란다 ⇒ server.js 에 예외를 뒀다
🔴 소유확인이 «안 끝났다» — 목록에 「소유확인을 진행하세요」가 그대로다
```

## 무엇이 막나

누를 때마다 **보안 문자(캡차)**가 뜬다.
네이버가 대놓고 적어 둔다 — 「프로그램을 이용한 자동등록을 방지하기 위해」

한 번은 맞춰서 등록까지 갔다(LHE39P). 그 뒤 것들은 글자가 흐려 못 맞췄다.

## ⚠ 여기서 헛돌았던 까닭 — 적어 둔다

```
🔴 「소유확인」 단추가 y=848 인데 창 높이가 599 였다. 화면 «밖»을 누르고 있었다.
   ⛔ scrollIntoView 와 getBoundingClientRect 를 «같은» evaluate 안에서 하면
     스크롤이 반영되기 «전» 좌표를 읽는다. 나눠서 하고, 스크롤 뒤 다시 재야 한다.
🔴 탭이 44개까지 늘어 puppeteer 의 pages() 가 터졌다.
   ⇒ CDP 로 직접 정리한다 — http://127.0.0.1:9222/json/list · /json/close/{id}
```

## 다음에 할 것

1. `scratchpad/소유확인-스크롤후.mjs` 로 확인창을 열고 보안 그림을 찍는다
2. 그림을 눈으로 읽는다. 흐리면 「새로고침」을 눌러 다시 받는다
3. `scratchpad/보안넣기-스크롤후.mjs "글자"` 로 넣는다
4. 붙었으면 **사이트맵(sitemap-core.xml)을 넣고 수집을 요청한다**

⛔ 되풀이해 두드리지 않는다. 한 번에 두세 번까지만 하고 다음으로 미룬다.
⚠ http 등록은 지우지 않는다 — https 가 붙은 것을 눈으로 본 뒤에 정한다.
