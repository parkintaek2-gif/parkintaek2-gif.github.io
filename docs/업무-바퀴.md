# 업무 바퀴 — **사이트 › 콘텐트 › 검색색인 › 리포트**

> 🔴 **사장님 지시 (2026-08-09 01:4x)**
>
> **「사이트>콘텐트>검색색인>리포트>사이트>콘텐트>검색색인>리포트… 이렇게 하라고 업무지시 해라. 완벽할 때 까지.」**
> **「여기에 비즈니스(데이터판매, 콘텐츠(외부 유입용 포함)판매, 광고인벤토리판매…)도 해야 한다」**
> **「…>리포트>비즈니스 리뷰, 프리뷰>사이트>…」**
> **「완벽할때까지」**  **「모든 유닛」**

⛔ 이것은 권고가 아니다. **모든 유닛의 일하는 차례**다. 오늘부터 이 차례로 돈다.

---

## 한 바퀴 = 네 칸. ⛔ **네 칸을 다 밟아야 한 바퀴다**

```
① 사이트    그릇      살아 있나 · 폰에서 보이나 · 링크가 살았나 · 느리지 않나
② 콘텐트    채움      새 글/영상/카드 — ⭐ 밖에서 사람을 데려올 것으로
③ 검색색인  🔴 길      만든 것이 **검색에 잡히나** — 사이트맵 넣고, 잡힌 수를 센다
④ 리포트    돈        파는 물건 — 새로 내거나, 있는 것을 더 좋게
```

### ⭐ 차례가 이 순서인 까닭

```
그릇이 새면 채워도 샌다        → 사이트가 먼저
채우지 않으면 색인할 것이 없다  → 콘텐트가 둘째
🔴 색인이 안 되면 아무도 안 온다 → 검색색인이 셋째
사람이 와야 리포트가 팔린다     → 리포트가 넷째
```

## ⛔ 지금 우리가 빠뜨리고 있는 칸 — **③ 검색색인**

```
5번  기사 50편        ⛔ 검색에 잡힌 것이 몇 편인지 아무도 모른다
6번  기사 40편        ⛔ 모른다
3번  지면 다수        ⛔ 모른다
1번  지면 다수        ⛔ 모른다
```

⭐ **사장님이 셋째 칸을 넣으신 것이 이 구멍이다.** ①②④는 우리가 하고 있었고 ③은 비어 있었다.
⛔ 색인 안 된 기사는 **안 쓴 기사와 같다.** 만든 사람만 볼 수 있는 글이다.

---

## 🔴 세 바퀴마다 — **비즈니스 리뷰 · 프리뷰**

⚠ 다만 **첫 번째는 두 바퀴 뒤**에 한다. 사장님이 그렇게 적어 주셨다 — 일찍 한 번 보고 방향을 잡는다.

```
1바퀴 → 2바퀴 → 🔴리뷰·프리뷰 → 3·4·5바퀴 → 🔴리뷰·프리뷰 → 6·7·8바퀴 → 🔴리뷰·프리뷰 → …
```

### 리뷰 = 지난 바퀴를 **돌아본다**

```
· 지난 바퀴에 지면 몇 장 · 콘텐트 몇 개 · 색인 몇 개 · 리포트 몇 개가 늘었나
· ⭐ 그래서 **사람이 몇 명 더 왔나** — 안 늘었으면 바퀴가 헛돈 것이다
· ⛔ 「했다」로 안 적는다. **숫자가 얼마에서 얼마로**로 적는다
```

### 프리뷰 = 다음 세 바퀴를 **미리 건다**

```
· 다음 세 바퀴에 무엇을 낼지 이름째 적는다
· ⭐ 지난 바퀴에서 **안 늘어난 칸**을 다음 바퀴 첫째로 놓는다
```

### 🔴 리뷰·프리뷰에는 **비즈니스가 반드시 실린다** — 사장님이 못 박으신 것

```
① 데이터 판매        가진 자료 중 팔 것 · 누구에게 · 얼마에
② 콘텐츠 판매        ⭐ 사장님이 **「외부 유입용 포함」**이라 하셨다
                    ⛔ 파는 콘텐츠와 **사람을 데려오는 콘텐츠**를 갈라서 적는다. 둘 다 비즈니스다
③ 광고 인벤토리 판매  지면 몇 장 × 광고 자리 몇 개 = **팔 수 있는 재고**가 얼마인가
④ … 그 밖에 찾은 것   ⭐ 사장님이 「…」로 열어 두셨다. **새 갈래를 찾는 것도 일이다**
```

⭐ **③이 새 말이다.** 광고를 「붙인다」가 아니라 **「인벤토리를 판다」**로 보라는 것이다.
   지면 하나하나가 **재고**다. 재고가 몇 개인지 세지 않으면 팔 수가 없다.

---

## 「완벽할 때까지」 — ⛔ 이 말이 제일 무겁다

```
⛔ 한 바퀴 돌고 「했습니다」로 끝나지 않는다
⛔ 「이 정도면 됐다」는 없다
⭐ 바퀴는 **같은 자리를 도는 것이 아니라 나선이다.** 매 바퀴 지난 바퀴보다 나아야 한다
⛔ 나아지지 않은 바퀴는 **한 바퀴로 안 센다**
```

⭐ 사장님 원칙과 이어진다 — *「상품의 퀄리티를 높이거나 더 좋은 새 상품을 만들지 못하면 잘못 경영한 것이다」*

---

## 자리마다 「완벽」이 무엇인가 — ⛔ 각 유닛이 스스로 적는다

⚠ 2번이 정해 주지 않는다. 사장님 말씀 — *「처음에 가이드라인을 잡는 건 좋다. 지나치면 안 된다.
   실무조직을 존중해야 창의적 결과를 낸다」*

```
각 자리가 첫 바퀴에 **「우리 유닛의 완벽은 이것이다」를 네 칸마다 한 줄씩** 적어 올린다
그 줄이 곧 그 유닛의 자다. 바퀴마다 그 자에 대 본다
```

---

## 바퀴 적는 법 — 한 줄

```
[바퀴] N번 · K바퀴 · MM-DD HH:MM
  ① 사이트    …했다 (숫자 → 숫자)
  ② 콘텐트    …했다 (숫자 → 숫자)
  ③ 검색색인  …했다 (제출 N개 / 잡힌 것 N개)
  ④ 리포트    …했다 (숫자 → 숫자)
  ⛔ 못 밟은 칸: (있으면 적는다. 없으면 「없음」)
```

⛔ **못 밟은 칸을 비워 두지 않는다.** 비어 있으면 밟은 것으로 읽힌다.
⭐ 못 밟았으면 **왜 못 밟았는지**를 적는다. 그것이 다음 바퀴의 첫 일이 된다.
