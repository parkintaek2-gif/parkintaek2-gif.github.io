# 우리가 일하는 법 — 초안 v1

> **회람용.** 1·3·4번이 맨 아래 가감란에 적어 주면 **2번이 최종본으로 만든다.**
>
> ⚠ **이 문서의 주인은 2번이다.** (사장님: 「최종 문서는 네가 맡아야 함」)
>   — 「네 사이트 강령」은 사장님이 주인이고, **이 문서는 2번이 주인이다.** 둘을 헷갈리지 않는다.
>   — 가감란에 적은 것은 **지우지 않는다.** 반영 여부와 이유를 2번이 밝힌다.
>

```
「우리만의 AI (투자, 상담, 친절한 리포트 작성) = **병렬형 구조** 참조」
「업무 협업의 효율화 등」
「병렬, 협업에만 국한하지 말고 **응용해서 우리에게 적용하면 좋은 것들까지**」
「**트렌디하고 감각적인 웹디자인**을 할 수 있는 능력을 키우는 법도 찾아서 같이 담아라」
「우리(나 + 1~4번)가 하는 작업, 비즈니스에 적용할 수 있게. **너무 길게는 하지 마라**」
「1·3·4번에게 가감해보라고 할 거다. 최종적으로 2번에게 다시 준다」
```

```
🔴 정지작업과 상품을 구분한다
   「데이터 정리는 **가공을 위한 정지작업일 뿐**이다. 우리 비즈니스는 **가공된 데이터를 파는 것**이다」

🔴 저널리즘의 자리
   「사실에 기반해 보도해서, 뉴스와 데이터 소비자가 **판단하는 데 도움을 주는 것**」

🔴 그릇이 내용물을 결정한다
   「고객이 보는 시작과 결과는 **엔진보다 더 치밀해야** 한다」

🔴 사람을 거치는 계획을 세우지 않는다      채용·동업·중개·부탁 전제 금지. 도구와 자동화로 푼다

🟡 승인 요청을 하지 않는다                 판단해서 실행하고 보고. 할 일 목록을 사장님께 넘기지 않는다
🟡 아이디어를 무조건 수용하지 않는다        별로면 말하되 **근거는 데이터로.** 못 쟀으면 「못 쟀다」고 한다
🟡 업무보고 오전 9시 · 오후 9시            1. 한 것 2. 못한 것(**언제까지**)
```

# 1. 병렬형 구조 — 우리 AI를 이렇게 짠다

> **읽기·조사·검증은 여럿이 동시에. 고치는 책임은 하나.**

원문의 핵심은 「AI의 답을 하나씩 기다리지 말라」다. 그리고 **같은 파일을 둘이 고치면 충돌한다.**

## 1-1. 투자 AI 셋 — 이미 이 모양이다

```
① 애널리스트     뉴스·공시·리포트를 읽어 신호를 만든다     ← 조사 (병렬)
② 펀드매니저     신호를 받아 포지션을 정한다              ← 제작 (편집 책임 하나)
③ 리스크관리자   한도를 감시하고 멈춘다  **①②와 독립**    ← 검증 (병렬)
```

원문의 「조사 / 제작 / 검증」이 우리 셋과 정확히 겹친다.
**여기서 ③의 독립이 왜 타협 불가인지가 분명해진다** — 검증이 제작에 붙으면
「같은 것이 사고 같은 것이 괜찮다고 하는」 구조다. 그건 통제가 아니다.

## 1-2. 상담 AI(백년지도·KLifeMap)도 같다

```
판정   규칙 엔진        결정론. 같은 입력이면 같은 결과
설명   AI 가 읽어 말한다  판정을 바꾸지 않는다
검증   위기표현·금칙 감시  **설명 AI 와 독립.** 걸리면 상담을 끊는다
```

⚠ **설명하는 AI 가 스스로를 검사하게 두지 않는다.**

## 1-3. 리포트 작성

```
자료 수집·사실 확인  →  초안 작성  →  숫자 대조·렌더 확인
   (병렬로 여럿)        (하나가)       (병렬로 여럿)
```

# 2. 일을 굴리는 다섯 가지 — **응용해서 쓸 것**

원문은 슬래시 명령으로 설명하지만, 요점은 **「모든 걸 한 대화에 밀어 넣지 않는다」**이다.
도구가 달라도 그대로 쓴다.

| 원문 | 뜻 | 우리 식으로 |
|---|---|---|
| `/plan` | 고치기 전에 **관련 파일·순서·위험·검증법**을 먼저 정한다 | 큰 작업은 「아직 만들지 말고 계획부터」로 시작한다 |
| `/goal` | **잴 수 있는 완료 상태**를 두고 여러 단계를 추적한다 | 「끝」의 정의를 먼저 적는다 (아래 2-1) |
| `/side` | 본 작업을 안 건드리고 **잠깐 옆에서 확인** | 용어·보안·독자 관점만 따로 본다. 결론은 본 작업에 되돌린다 |
| `/fork` | 맥락을 복사해 **A안·B안** 비교 | 화면 시안, 기사 구성 두 가지를 나란히 |
| `/compact` | 긴 대화에서 **필요한 맥락만** 남긴다 | 이미 전역 설정으로 자동 압축 켜 뒀다 |

## 2-1. ⭐ 「끝」의 정의를 **시작 전에** 적는다

원문: *「"좋게 만들어줘"처럼 평가할 수 없는 문장만 넣으면 범위가 계속 커진다.
완료 기준, 산출물 위치, 멈출 조건, 검증 방법을 함께 쓴다」*

우리 식 완료 기준은 이렇다.

```
✅ 「그 주소가 200 이고, 렌더해서 눈으로 봤고, 숫자를 두 번 쟀다」
⛔ 「배포했다」 「고쳤다」 「좋아졌다」
```

**멈출 조건도 함께 적는다** — 「민감정보나 불확실한 사실을 만나면 추측하지 말고 먼저 보고」.

# 3. 협업 — 우리 다섯이 안 부딪히려면

## 3-1. 우리가 이미 낸 사고 둘

```
① 1번이 `git add -A` 로 4번 파일을 함께 커밋했다
② 2번이 3번 파일을 고치고 **24분 뒤에** 알렸다 — 통보였지 협업이 아니었다
```

원문의 「같은 파일의 최종 편집 책임은 하나」를 어긴 것이다.

## 3-2. 그래서 정한다

| | 규칙 |
|---|---|
| **편집 책임** | 파일마다 주인이 하나다. 남의 파일은 **고치기 전에 말하고** 결과를 보고한다 |
| **급하면** | 그냥 고치되 **세션간-메모에 남긴다.** 하루 기다려 사이트가 죽는 것보다 낫다 |
| **읽기·검증** | 누구나 언제든. 이건 병렬이라야 빨라진다 |
| **커밋** | `git add -A` 를 쓰지 않는다. **경로를 지정**한다 |
| **받은 편지함** | 움직이기 전에 세션간-메모 꼬리를 본다 (`npm run inbox`) |

## 3-3. 규칙은 프롬프트가 아니라 **파일**에 남긴다

원문: *「좋은 결과가 나오면 그 방식을 남기고, 실수가 나오면 같은 실수를 막는 규칙을 남긴다」*

`AGENTS.md` 자리에 우리는 **`CLAUDE.md`** 가 있다. 프로젝트마다 하나씩.

```
좋은 결과  →  「이 방식을 CLAUDE.md 에 남긴다」
실수      →  「이걸 막는 한 줄을 CLAUDE.md 에 넣는다」
```

⚠ **처음부터 완벽하게 쓰지 않는다.** 반복되는 실수가 보일 때 한 줄씩 는다.

## 3-4. 24시간 이어가기

```
예약   자동 이어가기 2시간 · 아침 9시 · 저녁 9시 보고
⚠ 세션이 바뀌면 사라진다 · recurring 은 **7일 뒤 만료**
→ 세션을 시작하면 **CronList 부터** 본다
```

# 4. 반복 업무는 **시스템으로** 바꾼다

원문의 「스킬과 자동화」다. 우리는 이미 이 형태로 갖고 있다.

```
npm run <이름>       한 번 짠 절차를 이름으로 부른다 (수집기 9종·시험·배포)
작업 스케줄러         시각에 맞춰 스스로 돈다 (18:00~18:40 수집 · 22:00 Riot)
npm test             지시 색인·파서 시험 84건. 규칙을 코드가 지킨다
```

## 4-1. 한 번 더 하게 되면 그때 스크립트로 만든다

```
1번 할 때   손으로 한다
2번 할 때   「또 하겠구나」 → 스크립트로 만든다
3번부터     예약에 건다
```

## 4-2. ⭐ 자동화에 **안전장치**를 함께 넣는다

우리가 실제로 겪은 것들이다.

```
· 결과 파일은 `.new` 에 쌓고 **다 끝난 뒤에** 바꿔치기한다
  (재수집이 중간에 죽어 **본 파일이 비었다**)
· 이어받기를 만든다 — 이미 받은 것은 건너뛴다
  (채권 백필이 94%에서 죽어 **전부 날렸다**)
· 다시 계산할 때는 **「없어진 값」 카운터**를 둔다
  (채움률만 보다가 **42건이 조용히 사라질 뻔했다**)
```

# 5. 검증 — 「했다」가 아니라 「봤다」

원문: *「Codex를 잘 쓰는 사람은 질문을 길게 쓰는 사람이 아니라, **볼 자료와 지켜야 할 기준을 잘 열어주는 사람**」*

```
자료   폴더·문서·원자료·화면
기준   권한·말투·완료 조건·금지 사항
증거   **렌더링·테스트·스크린샷·링크 확인**
```

## 5-1. 우리가 하룻밤에 세 번 걸러낸 것

```
「회사가 공시를 안 했겠지」   → 같은 표의 급여가 96%인 걸 보고 **원문을 열었다**
                              실제로는 내 파서였다. 63.5% → 97.0%
「고쳤다」                    → 「없어진 값」 카운터가 **42건 손실**을 잡았다
「이런 관계가 보인다」         → 업종을 통제하니 **관계 하나가 사라졌다**
```

**셋 다 한 번 더 재서 걸렀다.** 안 쟀으면 셋 다 틀린 채로 나갔다.

## 5-2. 권한은 **좁게 시작한다**

원문: *「전체 접근 권한은 편해 보이지만 의도하지 않은 파일 변경·삭제 위험이 커진다.
처음에는 기본 권한으로 시작하고 꼭 필요할 때만 짧게 켠다」*

우리 것으로는 이렇다.

```
⛔ 금지   .env 읽기 · rm -rf · git push --force
⛔ 훅     ctype 명령에 `-t` 없으면 막는다 (klifemap 을 죽일 뻔한 적이 있다)
⛔ 공개   저장소가 공개다. **키 값을 커밋하지 않는다**
```

# 6. 감각적인 웹디자인 — **원문에 없어서 우리 방식으로 채운다**

⚠ 원문은 Codex 사용법이라 **디자인 실력 자체는 다루지 않는다.**
다만 하나를 준다 — **「렌더링해서 눈으로 본다」**. 그게 출발점이다.

## 6-1. 감각은 타고나는 게 아니라 **틀린 걸 알아보는 눈**이다. 그건 잴 수 있다

```
하룻밤에 실제로 잡은 것
 · 제목이 첫 화면의 **56%** 를 먹고 있었다      → 재서 알았다 (253px / 450px)
 · 표 스타일이 **통째로** 죽어 있었다            → 재서 알았다 (글자 크기·색이 같았다)
 · 「본문이 너무 넓다」고 진단했다가 취소했다     → 재보니 **이미 정상**이었다
```

**셋 다 눈대중으로는 반대로 판단했다.** 그래서 순서가 이렇다.

```
만든다  →  렌더한다  →  **잰다**  →  그다음 고친다
```

## 6-2. 매번 재는 여섯

```
첫 화면   제목이 화면의 몇 %인가 · 본문 첫 줄이 보이는가
글줄      한 줄에 몇 글자인가 (60~75 가 읽기 좋다)
모바일    **360px 에서 먼저** 본다. 데스크톱을 줄이지 않는다
다크모드   배경·글자·표 경계선이 다 살아 있는가
인쇄      PDF 로 뽑아 잘리는 데가 없는가
무게      외부 스크립트 몇 개 · 몇 KB인가
```

## 6-3. 트렌드는 베끼지 말고 **원칙으로 옮긴다**

```
⛔ 「요즘 이게 유행이다」    → 다음 유행이 오면 다시 만들어야 한다
✅ 「왜 그게 좋아 보이나」    → 여백·대비·정렬·서열. 이건 안 바뀐다
```

우리 지면이 나아진 이유도 트렌드가 아니라 **서열**이었다 —
회사명이 크고 종목코드가 작고 흐려지자, 그것만으로 읽는 순서가 생겼다.

## 6-4. 연습법

```
1. 잘 만든 데이터 지면을 **하나** 고른다 (FT · Bloomberg · Our World in Data)
2. 베끼지 말고 **재 본다** — 글줄 길이, 여백, 색 몇 개, 굵기 몇 단계
3. 우리 지면을 같은 자로 재고 **숫자 차이를 적는다**
4. **하나만** 고치고 다시 잰다
```

⚠ 한 번에 여럿 고치면 **뭐가 좋아졌는지 모른다.**

# 7. 한 장으로 줄이면

```
① 나눌 수 있는 일은 나란히. **고치는 사람은 하나.**
② 검증하는 쪽은 만드는 쪽과 **독립.** 이건 타협하지 않는다.
③ 시작 전에 **「끝」의 정의**를 적는다. 배포가 아니라 200 이고 눈으로 본 것.
④ 규칙은 프롬프트가 아니라 **파일**에 남긴다. 실수가 보일 때 한 줄씩.
⑤ 두 번째 하게 되면 **스크립트**로, 세 번째부터 **예약**으로.
⑥ 자동화에는 **안전장치를 함께** — 임시파일·이어받기·손실 카운터.
⑦ 디자인은 눈대중하지 않는다. **렌더하고, 재고, 하나씩** 고친다.
⑧ 그리고 이 전부는 **상품을 위한 것**이다. 정지작업은 팔 수 없다.
```
