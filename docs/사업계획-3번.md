## ④ 시장 — TAM(Total Addressable Market · 전체 시장) / SAM(Serviceable Addressable Market · 닿는 시장) / SOM(Serviceable Obtainable Market · 딸 몫)

```
TAM  이 물건을 쓸 수 있는 사람 **12,230,048명** × 9,900원 = **약 1조 2,108억**
     ● 국민연금 가입자 11,564,692명 + ● 고3 졸업자 332,678명 × 2(부모)
SAM  그중 **우리가 이미 지면을 가진** 사람 **10,335,297명** × 9,900원 = **약 1조 232억**
     ● 한 벌로 파는 114지역 안 졸업자 255,747명 × 2 + ● 업종×시도 1,523칸이 덮는 9,823,803명
SOM  2027까지 우리가 실제로 딸 몫 **8,502명** × 9,900원 = **8,417만원**
```

```
TAM ÷ SOM = **14,394배**   ← 우리가 얼마나 안 먹고 있나
SAM ÷ TAM = 84.5%          ⭐ 3번은 **물건이 좁지 않다.** 자료가 전국을 덮는다
SOM ÷ SAM = **0.008%**     🔴 좁은 것은 물건이 아니라 **닿는 길**이다
```
⚠ ○ 「한 사람이 한 벌씩 산다면」으로 정한 것이다. 값을 두 벌 사는 사람은 안 셌다.

```
2027 목표   **NRR 120%**
```

**120% 가 무슨 뜻인가 — 건당이라 「이탈」이 없다. 「또 사나」다**

```
100명이 올해 9,900원씩 냈다 = 99만원
내년에 그 100명에게서 **118만 8천원**이 나면 NRR 120%
   → 100명 중 **20명이 한 벌 더** 사면 된다
```

**⭐ 다음 한 벌이 이미 있다 — 만들 것이 아니라 이어 붙일 것이다**

```
우리 동네 한 벌  →  아이 학년이 바뀌면 **다음 해 한 벌**
                 →  아이가 대학 가면 **학과 한 벌**
                 →  본인이 마흔이면 **나이 한 벌** · **업종 한 벌**
⭐ 이것이 「같은 사람에게 40년 판다」의 진짜 뜻이다. **한 사람이 층을 옮겨 간다**
🔴 그런데 지금 대입 밖 지면이 **12장뿐**이다. 층을 옮길 자리가 없다
   → 업종×시도 **1,523장**이 서면 NRR 의 밑돌이 깔린다
```
⛔ 120% 는 ○ **정한 것**이다. 재 본 적이 없다. 첫 결제 뒤 석 달이면 진짜 수가 나온다.
