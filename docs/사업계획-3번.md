### ① 지면 한 장이 몇 번 열리나 — **2.8번. 그런데 이 수를 그대로 믿으면 안 된다**

```
6일 동안   사람 요청 10,389번 · 한 번이라도 열린 지면 3,705장 → 한 장당 2.8번
           (봇은 따로 42,522번. 위 수에 안 들었다)
```

🔴 **그런데 10,389번 가운데 9,960번이 「(직접)」이다** — 어디서 왔는지 표가 없는 요청이다.

```
(직접)            9,960     ⚠ 아직 아무 데도 안 걸린 사이트에 하루 1,660번 직접 들어올 리가 없다
(내부)              425     우리 지면끼리 오간 것
google.com            3
com.all-url.info      1
```

⛔ 그래서 **「손님이 6일에 1만 번 열었다」로 안 적는다.** 우리 배포 확인·감시 요청이 섞여 있다고 본다.
⭐ 걸러 내고 남는 **진짜 밖에서 온 것은 6일에 네 번**이다. 이게 오늘의 참값이다.
⚠ 그리고 이건 **횟수**이지 사람 수가 아니다. 로그에 사람 표가 없어 같은 사람을 못 묶는다.
  ⛔ 「몇 명이 왔나」로 바꿔 적지 않는다. 오늘 반감에서 데인 자리와 같은 꼴이다.

```
언제부터 제대로 잴 수 있나 —
  ① 「(직접)」에서 우리 것(배포 확인·감시)을 빼는 표를 붙이면 그날부터
  ② 네이버·구글이 담기 시작하면 유입 도메인이 저절로 갈린다
```

### ② 카드 한 벌이 몇 명을 데려오나 — **0명**

```
만든 것   63벌 · 369장 (근거 63벌)
나간 것   0벌
데려온 것 0명
```
⛔ 「아직 안 만들어서 0」이 아니다. **만들어 놓고 안 나가서 0**이다. 자산은 다 있다.
⚠ 올리는 계정은 사장님 손이다. 우리 준비물(카드·채널글 본보기·근거 json)은 다 됐다.
⭐ 잴 자는 이미 있다 — 나가는 날부터 유입 도메인에 `threads.net`·`instagram.com` 이 뜨면 그게 답이다.

### ③ 유튜브 조회수 — ⭐ **227회**

```
@100yearmap  쇼츠 1편
227회  「종로구에 100년 넘은 고등학교가 여덟 곳 있습니다」  youtu.be/WlVJOninNGA
```

⭐ **오늘 회사에서 처음으로 잰 「손님이 한 수」다.** 우리가 만든 수가 아니다.
⭐ 계정 없이 쟀다 — 공개 채널 지면만 읽었다. 2번이 「3번만 오늘 잴 수 있다」고 한 그 칸이다.
⚠ **어디서 온 조회인지는 못 잰다.** 그건 스튜디오 안에서만 보이고 계정 몫이다.
⚠ 오늘 만든 둘째 편(서른둘)은 아직 안 올라갔다. 올라가면 이 수가 둘이 된다.

```
견줄 자리 하나 — 지면은 6일에 밖에서 4번 열렸고, 영상 한 편은 227번 보였다
⛔ 「그러니 영상만 만들자」로 안 읽는다. 영상은 남지 않고 지면은 남는다
⭐ 다만 **지금 밖에서 사람을 데려오는 문은 유튜브 하나뿐**이라는 것은 수로 확인됐다
```

### ④ 구독자 잔존 — **? (아직 코호트가 없다)**

```
결제      0건
구독자    0명
1년 잔존  ? — 셀 사람이 없다
```
🔴 2027 목표 8,502명은 **잔존 가정 위에 서 있는 수**다. 잔존을 모르면 매년 8,502명을 **새로 모아야 하는 수**가 된다.
```
언제부터 잴 수 있나 — **첫 결제 다음 달부터**. 월별 코호트로 넣고 1년을 기다린다
⚠ 1년을 기다려야 첫 값이 나온다. 그래서 3개월·6개월 잔존을 먼저 낸다
```

### 🔴 오늘 채운 것 중 **2027년에 한 명이라도 더 사게 하는 것**은 무엇인가

```
⭐ **227회** 하나다.
```

지면 4,967장도, 카드 369벌도 **아직 아무도 안 봤다.** 밖에서 온 것이 6일에 네 번이다.
227회는 **적은 수지만 0이 아닌 유일한 수**이고, 그 수가 난 곳이 우리가 문을 가진 유일한 자리다.

⛔ 그래서 「지면을 더 만든다」는 2027에 한 명도 못 늘린다. 지금 지면은 **손님이 못 찾는다.**
⭐ 늘릴 수 있는 것은 **문이 있는 자리에 계속 내는 것**과 **네이버·구글이 담게 하는 것** 둘뿐이다.
⚠ 둘째는 계정 몫이라 오늘 내 손으로는 못 한다. 그래서 **오늘 내가 할 수 있었던 것은 영상 한 편**이었고, 그것을 했다.
