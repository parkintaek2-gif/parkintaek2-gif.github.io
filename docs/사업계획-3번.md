### ① 지면 한 장이 몇 번 열리나 — **2.8번. 그런데 이 수를 그대로 믿으면 안 된다**

```

           (봇은 따로 42,522번. 위 수에 안 들었다)
```

🔴 **그런데 10,389번 가운데 9,960번이 「(직접)」이다** — 어디서 왔는지 표가 없는 요청이다.

```
(직접)            9,960     ⚠ 아직 아무 데도 안 걸린 사이트에 하루 1,660번 직접 들어올 리가 없다
(내부)              425     우리 지면끼리 오간 것
google.com            3
com.all-url.info      1
```

⛔ 그래서 **「손님이 6일에 1만 번 열었다」로 안 적는다.** 우리 배포 확인·감시 요청이 섞여 있다고 본다.
⭐ 걸러 내고 남는 **진짜 밖에서 온 것은 6일에 네 번**이다. 이게 오늘의 참값이다.
⚠ 그리고 이건 **횟수**이지 사람 수가 아니다. 로그에 사람 표가 없어 같은 사람을 못 묶는다.
  ⛔ 「몇 명이 왔나」로 바꿔 적지 않는다. 오늘 반감에서 데인 자리와 같은 꼴이다.

```
언제부터 제대로 잴 수 있나 —
  ① 「(직접)」에서 우리 것(배포 확인·감시)을 빼는 표를 붙이면 그날부터
  ② 네이버·구글이 담기 시작하면 유입 도메인이 저절로 갈린다
```

### ③-2 🔴 **그 227이 어디로 갔나** (2번 지시 06:2x)

```
유튜브 조회          227회        ●본 것
→ 우리 지면에 온 것   **0번**      ●본 것 — 6일 로그에 유튜브 도메인 유입이 **하나도 없다**
→ 값 지면(/price)    **0번**      ●본 것 — /price 는 6일에 13번 열렸는데 전부 유입 표가 없다
```

**어디서 잰 것인가** — 우리 서버 로그(R2). `node scripts/check-100y-customer.mjs 7`.
유입 도메인 전부: `(직접) 9,963 · (내부) 425 · google.com 3 · com.all-url.info 1`. **유튜브 계열 0.**

🔴 **그런데 이 0을 「아무도 안 눌렀다」로 읽으면 안 된다.**

```
✅ 영상 설명에 링크가 있다   확인했다 — 세 줄이 걸려 있고 `?from=yt-100y` 표까지 붙어 있다
⛔ 그런데 우리 로그가 **물음표 뒤를 안 적는다**
   server.mjs 가 `pathname` 만 넘긴다(446줄). `from=yt-100y` 가 통째로 버려진다
⚠ 그리고 **유튜브 앱**에서 누른 것은 유입 표 없이 오므로 「(직접) 9,963」에 섞인다
```
⛔ 그래서 「0번」은 **웹에서 누른 것 기준 0번**이고, 앱에서 누른 것은 **아직 못 가른다.**

```
언제부터 제대로 잴 수 있나 — **server.mjs 한 줄**이면 그 다음 날부터다
  센다({ … pathname: u.pathname, … })  →  pathname 에 `from` 값을 붙여 넘기면 된다
  ⛔ server.mjs 는 2번 소유라 제가 안 고칩니다. **한 줄 요청드립니다**
  ⭐ 붙는 순간 유튜브·스레드·인스타가 **한 자로 다 갈립니다**(카드가 나가는 날 바로 필요합니다)
```

### ③-3 🔴 **배수 — 「8,502명이 되려면 조회가 몇 배여야 하나」**

```

```
⚠ 유튜브를 줄이자는 말이 아니다. 유튜브는 **지금 유일하게 0이 아닌 문**이다.
  다만 **8,502를 유튜브 몫으로 잡아 두면 2027이 통째로 어긋난다.**

### ③-4 🔴 **검색 깔때기 — 층으로 두 줄** (2번 지시 08:2x)

**색인된 지면 수부터 — ⛔ 「?」로 안 둔다. 잴 수 있는 데까지 쟀다**

```

●본 것   손으로 잰 표본 — **문 11장 중 6장 색인**(2번이 콘솔에서 잼) = 54.5%
○정한 것 그래서 색인된 지면 ≈ 1,949 × 54.5% = **약 1,063장**
⬜ 못 잰 것  정확한 색인 장수. **서치어드바이저 안에서만 보인다**
   ⛔ `site:` 로 안 셌다 — google.com/robots.txt 가 `Disallow: /search` 다
```
⚠ **1,063은 위쪽 어림이다.** 표본 11장이 「문」(상위 지면)이라 색인이 잘 되는 쪽만 봤다.
⭐ 그래도 **「모른다」가 아니라 「1,949장은 확실히 읽혔고 그중 절반쯤 담겼다」**까지는 왔다.
⛔ 네이버가 가져간 지면은 **0장**이다. 이 줄은 통째로 구글 것이다.

**⭐ 「그 밖 19장」이 데려오는 사람 — 33명**

```

```
