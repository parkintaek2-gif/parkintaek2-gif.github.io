## 2. 무엇을 만들었나

### 주소 구조

| 주소 | 무엇 |
|---|---|
| `/` | **영어** — 스타·데이터 (종전 그대로, 손대지 않음) |
| `/ko` | **한국어 리뷰 초기화면** |
| `/ko/<분류>` | 분류별 목록 — kpop·drama·show·esports·baseball·football·basketball·volleyball·sports |
| `/ko/review/<슬러그>` | 리뷰 본문 |

⛔ 영어와 한국어를 `hreflang` 짝으로 걸지 않았다. **수록 내용이 서로 다르다**
(영어=스타, 한국어=리뷰). 짝이 아닌 것을 짝이라 선언하면 거짓 신호가 된다 —
KLifeMap 에서 거짓 hreflang 104장을 걷어 낸 것이 바로 오늘 아침이다.
대신 양쪽 꼬리말에 **눈에 보이는 길**을 냈다.

## 3. 사진 규칙을 어떻게 «강제»했나

사장님이 이 지시를 주신 계기는 분명하다 — **오늘 오전 중부매일로 나간 롤드컵 기사 4건이
전부 팀 엠블럼(`…GENGLOGO_GOLD.png`)을 사진으로 달고 나갔다.**
말로 적어 두면 또 난다. 그래서 검사로 박았다.

```
스포츠      구단·협회가 제공하는 경기 사진만. 엠블럼·로고는 적출해서 막는다
TV 프로그램  방송사 홈페이지 사진
OTT 프로그램 제공처가 그 OTT 로 명시된 사진
K-POP       소속사·방송사·OTT
```

그리고 모든 사진에 **출처가 반드시 들어간다**(사장님: 「사진 출처를 반드시 써줘야 한다」) —
빠지면 빌드가 선다.

| 필수 항목 | 어디에 나오나 |
|---|---|
| `제공처` | 사진 바로 밑 캡션 — `설명. / 라이엇 게임즈` (「제공」은 붙이지 않는다, 중부매일 v7 과 같게) |
| `출처주소` | 본문 하단 「사진 — 제공처. 입수 경로: <주소>」 |
| `대체텍스트` | 눈으로 못 보는 이용자를 위해 |
| `제공처유형` | 분류별 허용 목록에 있는 것만 |

⛔ 사진은 **내려받아 우리 서버**(`public/review/`)에 둔다. 외부 서버를 직접 걸면
어느 날 조용히 끊기고, 그 서버에 우리 방문자 수만큼 부하를 전가한다.
출처주소는 «원 소재지»를 그대로 적는다 — 내려받았다고 출처가 우리가 되지 않는다.

## 4. 「네티즌 댓글을 리뷰로」를 어떻게 다뤘나

평점을 매기지 않는다. 대신 **이용자가 실제로 쓴 문장을 원문 그대로** 싣는다.
이것은 회사 강령과도 맞는다 — 「우리가 바늘을 세우지 않는다. 지형을 그려 놓고,
바늘은 보는 사람이 세운다.」

⛔⛔ **창작 금지.** 댓글마다 **원 소재지 주소가 필수**다. 없으면 빌드가 선다.
기억으로 요약하거나 비슷한 말을 다듬어 적는 순간 그 지면의 나머지 전부가 불신된다.
그래서 `scripts/수집-인벤댓글.mjs` 가 원문·작성시각·주소를 기계로 가져온다.
**선별만 사람이 한다** — 욕설·비방·인신공격은 싣지 않는다.
⛔ 계정명은 적지 않는다. 옮기는 것은 문장이지 개인이 아니다.

## 5. 보도자료를 어떻게 쓰나

`src/lib/보도자료창구.mjs` 에 분류별 창구를 적어 두었다. 리뷰를 쓸 때 **거기서 출발한다.**
보도자료는 두 가지를 한 번에 해결한다 —

1. **사실**을 발표 주체에게서 직접 받는다. 포털 기사를 거치지 않으므로 중간에서 틀어지지
   않고, 타사와의 유사도 문제도 생기지 않는다.
2. **사진.** 사장님 사진 규칙이 요구하는 「제공처가 명시된 사진」이 바로 보도자료의 사진이다.

⛔ 열어 보지 않은 주소를 적지 않았다. 못 연 곳은 지우지 않고 「미확인」으로 남겼다 —
「재 보고 안 되면 안 된다고 적는 것도 결과다」. 실측(2026-10-26) 기준 14곳 중
**사진까지 받을 수 있다고 확인한 곳은 7곳**이다.
⚠ 아직 보도자료 전용 자리를 못 찾은 곳 — KBS·SBS·JTBC·K리그·KBO·TVING.
분기마다 `node src/lib/보도자료창구.mjs --잰다` 로 다시 재서 고친다.

## 6. 빈 분류를 어떻게 다루나

사장님: 「모든 카테고리에 기사 한 건을 매일 쓸 필요는 없다.」

메뉴에는 9종이 모두 걸린다. 그런데 수록분이 없다고 지면을 만들지 않으면 **클릭 시 404** 다.
⇒ **9종을 모두 생성하되, 수록분이 없는 분류는 `noindex`** 로 두고 사이트맵에서도 뺀다.
이용자에게는 「아직 등록된 리뷰가 없다」를 그대로 보여 준다 — 0을 은폐하지 않는다.
⛔ 「곧 게재됩니다」를 적지 않는다. 시점을 모르는 것을 약속하지 않는다.
