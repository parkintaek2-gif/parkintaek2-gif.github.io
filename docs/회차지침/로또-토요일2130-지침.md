### 0. 🔴🔴🔴 숫자가 틀리면 안 된다 — 이 기사의 전부다

로또 기사는 **번호 하나가 틀리면 신문이 사고를 낸다.** 다른 기사와 무게가 다르다.

```
✅ 동행복권 공식에서 «직접» 본다
✅ 언론 보도 «한 곳 이상»과 맞춰 본다 — 두 곳이 같아야 쓴다
⛔ 기억으로 쓰지 않는다. 지난 회차 숫자를 고쳐 쓰지 않는다
⛔ 두 곳이 다르면 **기사를 쓰지 않는다** — 「숫자가 안 맞는다」고 적고 멈춘다
```

⚠ 못 찾은 항목은 **빼고 쓴다.** 0으로 채우거나 어림하지 않는다.
  「총판매금액은 확인하지 못했다」 같은 취재 뒷이야기는 **본문에 쓰지 않는다** —
  그것은 데스크에 따로 알릴 말이다. 본문에서는 그냥 뺀다.

### 1. 🔴 키워드 — 「로또 당첨번호」를 제목과 본문에 넣는다

사장님이 콕 집어 주신 말이다.

```
✅ 제목에 「당첨번호」가 들어간다
✅ 본문 «첫 문단»에 「로또 당첨번호」가 통째로 한 번 들어간다
✅ 본문 가운데와 끝에도 자연스럽게 한 번씩 더 나오게 한다
⛔ 억지로 같은 말을 다섯 번 박지 않는다 — 읽기 나빠지면 검색에도 나쁘다
```

### 2. 제목 — 사장님이 주신 본보기

```

```

이 제목이 하는 일을 그대로 따른다 —

```
① 「로또」 + 회차 + 「당첨번호」      ← 사람이 실제로 검색하는 말
② 가운뎃점 세 개(···)로 끊는다
③ 작은따옴표 안에 «그 주에만 있는 수»를 넣는다
   보기) '1등 16명 중 11명 자동' · '1등 18억8102만원' · '1등 2명뿐'
```

```
⛔ 서술형으로 끝내지 않는다 — 「…당첨됐다」 ×. 명사로 맺는다
   ⚠ 메일 자물쇠가 이것을 잡아 «발송을 막는다». 고치기 전에는 안 나간다
```

### 4. 본문에 담을 것 (확인된 것만)

```
① 회차 · 추첨일
② 당첨번호 6개와 보너스번호
③ 1등 — 당첨 게임 수 · 1게임당 당첨금
④ 1등 가운데 자동·수동·반자동이 몇 건인지   ← 사장님 본보기가 이것을 제목에 올렸다
⑤ 2등~5등 — 당첨 게임 수 · 1게임당 당첨금
⑥ 총판매금액
⑦ 1등 배출 판매점 — 충청권이 있으면 밝힌다
⑧ 다음 회차 추첨일
```

⚠ **충청권은 억지로 끌어오지 않는다.** 1등 판매점에 충청권이 «실제로» 있으면
  밝히는 것이고, 없으면 없는 대로 둔다. 통과시키려고 고리를 만들어 붙이지 않는다.

### 5. 🔴 사실 나열로 끝내지 않는다 — 한 가지는 판다

사장님이 스포츠 기사에 이르신 것이 여기에도 걸린다. 숫자만 늘어놓으면 표지,
**왜 그런지를 한 대목이라도 파야 기사**다. 그 주에 실제로 있었던 것 하나를 고른다.

```
보기) 1등이 16명이나 나온 까닭 — 번호 배열이 흔한 꼴이었나
보기) 자동이 11명 — 최근 회차들과 견주면 높은가 낮은가
보기) 1등 당첨금이 지난 회차보다 왜 줄었나(당첨자 수 · 판매금액)
보기) 2등 당첨금이 1등의 몇 분의 일인가
```

⛔ 견줄 수를 «지어내지» 않는다. 지난 회차를 확인해서 견준다. 못 찾으면 안 쓴다.

### 6. ⛔ 우리가 하지 않는 것

```
⛔ 다음 회차 번호를 예측하거나 추천하지 않는다
⛔ 「많이 나온 번호」로 사라고 부추기지 않는다
⛔ 구매를 권하지 않는다. 「지금이 기회」 같은 말을 쓰지 않는다
⛔ 당첨자 신상을 캐거나 지어내지 않는다
✅ 숫자를 그대로 놓고, 판단은 읽는 사람이 한다
```

⚠ 이것은 회사의 강령이다 — **사람을 밀어붙이지 않는다.** 사실을 내고 거기서 멈춘다.

### 7. 사진

⛔ 로또 추첨은 우리가 쓸 수 있는 사진이 마땅히 없다. **사진 없이 낸다.**
  없는 사진 주소를 지어내지 않는다. 메일 자물쇠가 이 회차의 사진은 안 따진다.

### 8. 자체기사

```
자체기사 기준 — 선행보도 대비 유사도 60% (날씨와 같다)
```

⚠ 당첨번호·당첨금·인원은 **모든 매체가 똑같이 받는 숫자**다. 그 숫자가 같다고
  베낀 것이 아니다. 견주는 것은 **문장·구성·해석**이다.
⛔ 다른 매체가 이미 쓴 문장과 구성은 쓰지 않는다. 5번 절의 «파는 대목»이 우리 것이다.
적어 주실 것 — 「자체기사 여부: 충족 / 미충족 (선행보도 대비 유사도 N%)」

- 세 번째의 회차 번호는 그 주 숫자로 바꾼다.
- 한 줄에 하나씩, 사이에 빈 줄을 둔다(위 꼴 그대로).
