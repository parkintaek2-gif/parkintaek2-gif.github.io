# 업무보고에 꼭 담을 것

사장님이 **「보고에 꼭 포함하라」**고 따로 말씀하신 것만 여기 적는다.
`check-2h` 가 매 두 시간마다 이 표를 맨 위에 찍는다 — 내 기억에 맡기지 않는다.

```
✅ 「담나」 칸이 🔴 면 그날 16시·22시 보고에 반드시 넣는다
✅ 보고에 넣고 나면 「담나」를 ✅ 로 바꾼다. 지우지 않는다 — 기록이다
⛔ 사장님이 「꼭 포함하라」고 하신 것만 여기 올린다. 내 판단으로 늘리지 않는다
```

| 담나 | 언제 | 무엇 | 사장님 말씀 |
|---|---|---|---|
| 🔴 | 2026-09-29 | 기사 줄바꿈 — 문장이 끝나지 않았는데 줄을 바꾸는 병 | 「줄바꿈을 계속 잘 못하고 있다. 문장이 끝나지 않았는데 자꾸 줄바꿈을 하네」 |
| 🔴 | 2026-09-29 | 계주·단체전 선수 소속팀을 괄호 안에 다 쓰기 | 「남자계주 400m 선수들 소속팀을 괄호안에 다 써줘야해」 |

> 사장님 (2026-09-29): 「**아침에 지시한 중요사항 두 가지를 업무보고에 꼭 포함할것**」

## 무엇을 적나 — 「했다」가 아니라 「무엇이 달라졌나」

```
⛔ 「고쳤습니다」 한 줄로 끝내지 않는다 — 사장님이 확인하실 방도가 없다
✅ 까닭을 어디서 찾았는지, 무엇을 고쳤는지, 다시 안 나게 무엇으로 막았는지를 적는다
```
