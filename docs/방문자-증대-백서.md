# 방문자 증대 백서 — **잰 것만 적는다**

> 2026-08-26 00:2x · 5번(총괄) 씀 · 사장님 지시로 시작
> 「콘텐트가 차별화되고, 꾸준히 생산되는 거를 구글, 네이버가 감지할 때까지 어차피
>  시간이 걸려. **중간에 포기하지만 않으면 돼**」 — 사장님, 2026-08-25

## 이 문서가 다른 「SEO 문서」와 다른 점

⛔ **일반론을 안 적는다.** 「좋은 콘텐츠를 만들어라」·「키워드를 넣어라」는 여기 없다.
⛔ **안 해 본 것을 「효과 있다」고 안 적는다.**
✅ 우리가 **재 본 것**과, 재 봤더니 **안 듣던 것**만 적는다.

🔴 **가장 값진 절은 2절이다.** 우리가 이미 해 봤는데 **안 들은 것들**이 거기 있다.
다른 유닛이 그것을 다시 하지 않는 것만으로 이 문서는 값을 한다.

## 1. 우리가 지금 어디 서 있나 (2026-08-25 실측)

### 방문자 — 두 수를 갈라서 본다

```
                     GA4 순방문(하루)   읽은 흔적 있는 사람(하루)
3번 100yearmap            12.2              4.3
5번 K Culture Wire         4.6              1.1
1·4번 KLifeMap             2.0              1.9
6번 SeoulMarkets           1.5              0.8
────────────────────────────────────────────────
회사 전체                 20.9              8.1
```

⚠ 오른쪽이 **0초에 한 장만 보고 나간 세션을 뺀 수**다. 사장님께 올릴 때는 오른쪽을 같이 올린다.
🔴 9월 목표가 **유닛당 1,000명**이다. 지금 회사 전체가 8.1명이다. **120배가 남았다.**

### 체류 — 🔴 방문자가 가장 적은 유닛이 가장 잘 붙든다

```
유닛              세션    세션당      붙은세션   걸음
1·4번 KLifeMap     114   6분 38초      50%     3.24
6번 SeoulMarkets    48    3분 6초      40%     1.96
5번 KCW            143     34.8초      20%     1.23
3번 100yearmap     364     30.5초      20%     1.27
```

⭐ **이 표가 이 백서에서 가장 중요한 한 장이다.**
방문자가 가장 많은 3번과 둘째인 5번이 **붙드는 것은 가장 못 한다.** 반대로 KLifeMap 은
사람이 적게 오는데 온 사람의 절반이 붙어 3.24장을 걷는다.
⛔ **「오게 하는 것」과 「머물게 하는 것」은 다른 일이고, 지금 우리는 서로 다른 쪽이 약하다.**
그러니 같은 처방을 넷에 똑같이 내리면 안 된다 — 3·5번은 붙드는 쪽, 4·6번은 오게 하는 쪽이다.

### 들어오는 길 — **하나뿐이다**

```
구글 검색      사실상 우리의 유일한 길
유튜브         숏츠 10편 · 조회 166회 → 우리 사이트로 온 사람 «0명»
밖에서 걸어 준 곳   0
네이버         3번·4번(한글 사이트)만 해당. 등록은 했고 아직 유입은 못 쟀다
```

🔴 **한 줄기밖에 없는 것이 지금 우리의 가장 큰 구조적 약점이다.** 구글이 한 번 흔들리면
회사 전체 유입이 같이 흔들린다.

## 2. 🔴 해 봤는데 «안 들은» 것 — 다른 유닛은 여기서 시간을 아끼라

### ① 숏츠 설명란에 사이트 주소 넣기 — **0명**

10편 전부 설명 **첫 줄**이 우리 주소였다. 조회 166회. 유입 **0명**.
까닭: 숏츠는 설명이 두 줄만 접힌 채 보이고 **아무도 펼치지 않는다.**
⛔ 「설명에 링크 넣었다」로 이 일을 끝냈다고 하지 말 것.
⭐ 그래서 **화면 안에** 굽는 쪽으로 바꿨다(내내 작게 + 끝화면). **아직 결과는 모른다.**

### ② 영상 맨 끝의 작은 주소 — **0명**

원본 영상 끝에 이미 `kculturewire.com/<지면>` 이 작은 분홍 글자로 있었다. 그래도 0이었다.
⛔ 「주소를 넣었나」가 아니라 **「눈에 들어오나」**가 문제다. 작아서 안 보이는 것도 실패다.

### ③ 지면을 «내는 것»만으로는 아무 일도 안 일어난다 — 재서 알았다

같은 날 이런 것들을 찾았다.
```
/person 636장     첫 화면에서 «한 번도» 안 걸렸다            → 문을 냈다
/video           영상을 건 지면 20장 중 «0장»이 안 걸었다     → 부품 한 곳 고쳐 21장 열었다
카드 그림 105장   alt 가 「Card 1 of 5」 — 검색에 안 걸린다   → 머리글로 바꿨다
/data            「coverage.csv 있다」고 적고 «파일이 없었다» → 실제로 열었다
```
🔴 **만든 것과 닿는 것은 다른 말이다.** 넷 다 「만들었다」로 끝내고 있던 것들이다.

### ④ 얇은 지면을 수천 장 내는 것 — **하지 않기로 했다**

사람 이름 지면을 낼 때 9,249명이 자료에 있었다. 636명만 냈다.
문턱: **우리가 이미 지면을 낸 작품에 2편 이상 나온 사람**.
까닭: 얇은 지면 수천 장은 색인에서 서로를 갉아먹는다. 이건 다른 유닛도 같다.

### ⑤ 수요 1위 낱말을 그대로 쫓는 것 — **하지 않기로 했다**

자동완성 가지 수: `age 51` > `movies and tv shows 45` > `netflix 44`.
⛔ **`age` 를 버렸다.** 나이는 구글이 지식패널로 «즉시» 답한다. 우리가 이길 자리가 아니다.
노래 제목은 다섯 꼴을 다 재고 **아예 안 만들기로** 했다 — 우리 축(나라)에 수요가 **0**이었다.

🔴 **이것이 사장님이 말씀하신 「차별화」의 실무 뜻이라고 본다** —
**수요가 크다고 만드는 것이 아니라, 우리가 «이길 수 있는» 자리에 만든다.**

## 3. 아직 «모르는» 것 — 안다고 적지 않는다

```
· 화면에 구운 주소가 유입을 만드는가        영상을 올려야 잰다. 유튜브 한도로 막혀 있다
· 열어 둔 자료(CSV)가 인용을 부르는가       인용은 우리가 못 만든다. 생기는지 재는 수밖에 없다
· 사람 지면 636장이 색인에 들어가는가       지금 전부 「발견만」. 8/28 에 다시 잰다
· 네이버가 한글 사이트에 얼마나 보내는가    3·4번이 재야 한다
· 커뮤니티가 체류를 늘리는가               문은 냈고 걸음은 아직 안 쟀다
```

⛔ 이 다섯을 「했다」로 적지 않는다. 잰 뒤에 적는다.

## 4. 그래서 무엇을 하나 — 순서

### 넷째 유닛마다 처방이 다르다

```
3번·5번  «붙드는» 쪽이 약하다(붙은세션 20%)
         → 다음 걸음을 윗절반에 놓기 · 복도 지면 · 관련 콘텐트 잇기
4번·6번  «오게 하는» 쪽이 약하다(하루 2명·1.5명)
         → 잰 검색 수요에 답하는 지면 · 색인 · 네이버(4번)
```
⛔ 넷에 같은 처방을 내리지 않는다. 이 표를 먼저 보고 자기 쪽을 고른다.

### 회사 전체로는 — **둘째 줄기를 만든다**

들어오는 길이 구글 하나뿐인 것이 가장 큰 위험이다. 둘째 줄기 후보를 **재서** 고른다.
```
① 밖에서 걸리기(인용)   자료를 열어 두고 «인용될 만한 것»을 준다. 8/25 에 CSV 5개를 열었다
② 네이버               한글 사이트(3·4번) 전용. 등록됨. 유입은 아직 못 쟀다
③ 영상 플랫폼          지금 0명. 화면에 구운 주소로 다시 잰다
④ 커뮤니티             우리 안에 머물게 하는 쪽에 가깝다 — 유입 줄기로는 아직 못 쟀다
```

### 매일 하는 것 — 🔴 이것을 끊는 것이 가장 큰 손해다

사장님 말씀에서 감지 조건이 **둘**이다 — **차별화**와 **꾸준함**.
```
매일   카드 · 카드뉴스 · 숏영상 · 지면
```
⚠ 2026-08-25 에 나는 지면 636장을 낸 날 **카드 0장·영상 0편**으로 저녁까지 왔다.
큰 것을 한 번 낸 날이라 「했다」고 여겼는데, 둘 중 하나를 버린 것이었다.
🔴 **큰 것을 낸 날일수록 매일 내는 것을 빠뜨린다.** 세어 보기 전에는 모른다.

## 5. 어떻게 재나 — 자가 이미 있다

```
방문자        node scripts/ga4-report.mjs

체류시간      node scripts/measure-kcw-dwell.mjs --잰다
유입 경로     node scripts/measure-referrals.mjs
색인          node scripts/check-kcw-indexed.mjs --잰다 --n=40
검색 수요     node scripts/measure-keyword-demand.mjs --말파일=<파일>
이름 네 자리   node scripts/check-name-placement.mjs --지면=dist
들어오는 링크  node scripts/measure-page-inlinks.mjs
```

### ⛔ 재면서 틀리기 쉬운 것 넷 — 전부 2026-08-25 에 겪었다

```
① 비율이 움직이면 «분모»를 먼저 본다
   색인이 66.7%→52.5% 로 떨어졌는데 지면을 636장 늘렸기 때문이었다. 안 나빠졌다
② 「조용히 떨어지는 기본값」을 의심한다
   ?? 로 준 기본값이 «그럴듯한 화면»을 만들면 깨진 것을 아무도 못 본다. 두 번 당했다
③ 검사가 «몇 장을 봤는지» 본다
   빌드 중인 dist 를 읽어 「697장 봤다·통과」가 나왔다. 평소 2,036장이다
④ 배포 표식은 «이번에 새로 생긴 글자»로 준다
   옛 글자를 주면 배포가 안 나가도 늘 통과한다. 실제로 한 번 속았다
```
