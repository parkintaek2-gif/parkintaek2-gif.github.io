## Ⅰ. 다시 재고 나니 계획이 뒤집힌다 — **두 축이 이미 있었다**

FnGuide 의 본체는 다섯 축이다. 09-09 에 내가 적어 둔 상태와 **오늘 실측한 것**이 다르다.

| FnGuide 축 | 09-09 에 내가 적었던 것 | 🔴 2026-09-10 실측 | 원자료 |
|---|---|---|---|
| 컨센서스 (추정치·목표주가) | ✅ 있다 | ✅ 있다 — 매일 스냅숏 5일치, 624건·165종목 | 한경컨센서스 |
| 시세·시총 (밸류에이션 바탕) | ✅ 있다 | ✅ 있다 — **2,765종목** (KOSPI 943 + KOSDAQ 1,822) | 포털 15094808 |
| **지수** | ⬜ **「아직 없다」** | ✅ **있다 — 168지수 × 12일** | 포털·KRX 지수 |
| **펀드·ETF** | ⬜ **「승인 확인 중」** | ✅ **있다 — 마스터 183,351행** | 15094792 |
| **재무제표** | (축으로 안 세었다) | 🔴 **없다. 유일한 큰 구멍이다** | DART fnlttSinglAcntAll |

### 1-1. 지수 — 있다. 열어서 재 봤다

```
archive/raw/indices/20260902.ndjson  →  168행
칸: 일자 · 이름 · 계열(KOSPI시리즈) · 구성종목수 · 종가 · 전일비 · 등락률 ·
    시가 · 고가 · 저가 · 거래량 · 거래대금 · 시가총액 · 연최고/연최저(+일자) ·
    기준시점 · 기준지수
보기: 「IT 서비스」 KOSPI시리즈 · 구성 25종목 · 종가 1,193.86 · 등락률 -3.56%
```

⇒ FnGuide 의 지수 축에 필요한 칸이 **이미 다 있다.** 「없다」가 아니라 **내가 안 찾은 것**이었다.

### 1-2. 펀드 — 마스터가 있다

```
archive/raw/funds/all.ndjson  →  183,351행
칸: 코드부여일 · 코드 · 표준코드(ISIN) · 이름 · 분류 · 설정일 · 유형 · 상품분류코드 · 주제
보기: 교보악사Tomorrow장기우량증권투자신탁K-1호ClassA(채권) · 채권형 · 설정 2006-09-05
```

⚠ 이것은 **마스터(무엇이 있나)**다. **기준가·수익률(얼마가 됐나)은 아직 못 쟀다.**
  ⛔ 「펀드 축이 있다」를 「펀드 상품을 낼 수 있다」로 읽지 않는다. 한 칸 더 필요하다.

### 1-3. 🔴 재무제표 — 없었고, **오늘 열리는 것을 확인했다**

수집기를 찾아봤다. `fnlttSinglAcntAll` 을 부르는 자가 **저장소에 하나도 없다.**
그래서 열쇠로 직접 불러 봤다 (2026-09-10 07:5x).

```
opendart.fss.or.kr/api/fnlttSinglAcntAll.json
  corp_code=00126380(삼성전자) · bsns_year=2025 · reprt_code=11011 · fs_div=CFS
  → status 000 정상 · **229행**
     재무상태표   자산총계   566,942,110,000,000
     재무상태표   자본총계   436,320,337,000,000
     손익계산서   매출액     333,605,938,000,000
     손익계산서   영업이익    43,601,051,000,000
     손익계산서   당기순이익  45,206,805,000,000
```

⭐ **이 한 칸이 열리면 밸류에이션과 스크리너가 같이 열린다.**

```
PER  = 시가총액 ÷ 당기순이익        시총 ✅ 있다 × 순이익 ← 이 칸이 없었다
PBR  = 시가총액 ÷ 자본총계          시총 ✅ 있다 × 자본 ← 이 칸이 없었다
ROE  = 당기순이익 ÷ 자본총계        둘 다 ← 이 칸이 없었다
EV/EBITDA · 부채비율 · 영업이익률    같은 표에서 나온다
```

⇒ **재무제표가 병목이고, 병목이 하나뿐이다.** 계획의 첫 줄이 여기로 바뀐다.

## Ⅶ. 다음에 재야 할 것 — 못 쟀다고 적어 둔다

```
⬜ 펀드 기준가·수익률이 어느 우물에 있나 (마스터만 쥐고 있다)
⬜ 재무제표를 2,765종목 전부 받을 때 DART 하루 한도에 걸리나 (한도를 아직 안 쟀다)

⬜ 개별 채권 종목 자료가 어디 있나 (지금 쥔 것은 «금리»다)
```

⛔ 위 넷은 「없다」가 아니라 **「내가 아직 안 찾았다」**다. 오늘 두 축이 그렇게 뒤집혔다.
