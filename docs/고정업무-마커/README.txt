# 고정업무를 «끝냈다»는 증거를 여기 남긴다.
#
# 왜 — 깨움(cron)은 세션 메모리에만 있어 세션이 죽으면 안 터진다. 그래서
#   「예약을 걸었나」가 아니라 「오늘 몫을 했나」를 재야 한다.
#   2026-09-09 에 22시 방송이 안 나갔고 16시 보고가 한 시간 늦었다 — 이 마커가 그것을 잡는다.
#
# 꼴  <날>-<키>.txt        보기: 2026-09-10-22시방송.txt
# 키  16시업무보고 · 22시방송   (scripts/check-kcw-wakers.mjs 의 하루몫 목록)
#
# 재는 자   node scripts/check-kcw-wakers.mjs   → 「■ 오늘 하루 한 번짜리 몫」 칸
# ⛔ 안 한 것에 마커를 남기지 않는다. 그러면 이 자가 거짓말하는 자가 된다.
