# 2026-10-22 — 사장님이 고쳐서 내보내신 기사 네 편

사장님 — 「**내가 수정해서 내보낸 기사들이야 다음에 기사 작성시 참조해**」

⛔ 이 문서는 **사장님이 실제로 지면에 내보내신 글**이다. 내 원고가 아니다.
   본보기로 쓰되, 여기 적힌 사실을 다른 기사의 «근거»로 삼지 않는다.

## 🔴 가장 크게 배운 것 — 「길게」는 분량이 아니라 내용이다

사장님이 「**기사 너무 짧다...날씨 기사는 약간 더 길게 써**」 하셔서
내가 날씨를 **10문단 895자**로 늘렸다. 사장님은 그것을 **6문단으로 줄여** 내보내셨다.

```
내가 넣었다가 사장님이 덜어내신 것 ─────────────────────
  · 주말·다음 주 초 기온 흐름 (24일·25일·26일)
  · 일요일 오후 비 소식 (강수 확률 60 %)
  · 미세먼지 '좋음'
  · 일몰 시각 오후 5시 46분 · 「산행은 해가 지기 전에」
  · 「환절기에는 이런 기온 차가 호흡기 질환으로 이어지기 쉬운 만큼」
  · 대전 강수 확률 (청주만 남기셨다)
  · 「2~4도 높은 수치다」 → 「2~4도 높다」
```

⇒ **곁가지를 보태는 것은 「길게 쓰는 것」이 아니다.**
  반면 아시안패러게임은 446자 → 2천 자대로 늘린 것을 **그대로** 쓰셨다.
  거기서 늘린 것은 곁가지가 아니라 **없던 사실**이었다 —
  결승 상대가 누구인지, 그 선수가 어떤 사람인지, 어떻게 여기까지 왔는지.

```
✅ 늘려야 할 때   사실이 빠져 있다 — 상대가 누구인지, 왜 그렇게 됐는지, 그 사람이 누구인지
⛔ 늘리면 안 될 때  사실은 다 있다 — 거기에 설명·곁가지·조언을 붙이는 것
```

**소재마다 알맞은 길이가 다르다** (사장님이 내보내신 네 편 실측)

```
날씨            6문단    예보 수치와 어제 견주기. 그 이상은 덜어내신다
경기 결과        9문단    결과 · 기록 · 순위 · 다음 일정
사람·여러 종목   12문단   선수마다 한 문단씩
논란·국감        20문단 넘김  말과 반응이 많을 때는 길어도 좋다
```

## 🔴 제목과 부제 — 사장님이 바꾸신 꼴

### ① 제목 맨 앞에 **갈래를 밝히신다**

```
내 것   내일 충청권 낮 22도, 오늘보다 6도 올라
사장님  [날씨] 내일 낮 기온 오늘보다 6도 올라

내 것   삼성 개막 6연승, 23년 만의 구단 타이 기록
사장님  프로농구 삼성 개막 6연승 디펜딩 챔피언 KCC 97대 86 제압
```

- 날씨는 `[날씨]` 를 제목 앞에.
- 스포츠는 **종목 이름**(프로농구)을 제목 앞에.
- 대회 이름은 **부제 앞**에 — `[아시안패러게임] 66세 김옥금 양궁 2연패…`

### ② 제목에 핵심 사실, 부제에 나머지 — 내가 둘을 **거꾸로** 놓았다

```
내 것   제목  삼성 개막 6연승, 23년 만의 구단 타이 기록
        부제  디펜딩 챔피언 KCC 97대 86으로 제압하며 단독 선두, 칸터 30점… KCC는 4연패로 최하위

사장님  제목  프로농구 삼성 개막 6연승 디펜딩 챔피언 KCC 97대 86 제압
        부제  23년 만에 구단 타이 기록… 칸터 30점 앞세워 단독 선두
```

⇒ **누가 누구를 어떻게 이겼나가 제목이다.** 기록·의미는 부제로 내린다.
⇒ 부제에서 「KCC는 4연패로 최하위」를 **빼셨다** — 부제에 셋을 넣지 않으신다.

### ③ 제목에 쉼표를 덜 쓰신다

```
내 것   삼성 개막 6연승, 23년 만의…     ← 쉼표
사장님  프로농구 삼성 개막 6연승 디펜딩 챔피언 KCC 97대 86 제압   ← 붙여 쓰신다
```

### ④ 메달을 제목에 쓰는 것은 괜찮다

내가 「장애인 대회는 메달을 제목에 올리지 않는다」를 넓게 읽어 보강본에서 「금메달」을 뺐는데,
사장님은 **되살려** 내보내셨다 — 「14대 14에서 찌른 마지막 한 점, 휠체어펜싱 조은혜 금메달」.

```
⛔ 하면 안 되는 것   메달 «목표»와 종합 «순위»를 제목에 세우는 것
✅ 해도 되는 것     한 선수가 무엇을 이뤘는지 적는 것
```
[[지시의-범위를-넓게-잡는-것도-어기는-것이다]] — 또 같은 잘못을 할 뻔했다.

## 🔴 사진 — 긴 기사에는 여러 장, 해당 문단 «앞»에

패러게임 기사에 사장님이 사진을 **세 장** 넣으셨다. 그것도 맨 위에 몰지 않고 —

```
[사진1 조은혜]  ← 머리
  조은혜 문단들
[사진2 김옥금]  ← 김옥금 문단 «앞»
  김옥금 문단
[사진3 주정훈]  ← 주정훈 문단 «앞»
  주정훈 문단
```

⇒ **종목이 바뀌는 자리마다 사진을 놓으신다.** 나는 늘 한 장만 줬다.
⇒ 사진 제목(「끝까지 치열하게」·「환호하는 삼성」)을 캡션과 **따로** 다신다.

**출처는 거의 연합뉴스다.** 내가 KBL 공식 사진 주소 세 개를 찾아 드렸지만
사장님은 연합뉴스 사진(「21일 … 삼성 한호빈이 레이업을 성공하고 팀 동료들과 환호하고 있다」)을 쓰셨다.
⇒ 연합뉴스 사진이 이미 있는 경기는 그쪽이 쓰기 쉽다. 제공처 주소 찾기는 그것이 «없을 때» 할 일이다.

⚠ 다만 김옥금 사진 캡션은 「김옥금-이은희 조 … 컴파운드 여자 W1 더블 결승」인데
  본문은 「박홍조와 짝을 이뤄 혼성 W1」이다. 사진과 본문의 종목이 다르다.
  ⇒ **종목이 여럿인 선수는 사진 캡션과 본문의 종목이 맞는지 내가 먼저 맞춰 드려야 한다.**

## 🔴 손흥민 기사 — 내가 못 한 것

사장님이 가장 많이 손보신 기사다. 내 원고보다 훨씬 길어졌다.

### ① 기자의 판단 문장을 한 줄 세우신다

> **이 부회장은 그러나 본질을 회피하는 듯한 답변으로 일관했다.**

나는 이런 문장을 안 쓴다. 사장님은 답변 세 개를 늘어놓는 대신
**그것이 무엇이었는지 한 줄로 정리**하고 들어가신다.

### ② 묻고 답한 것을 짝으로 붙이신다

```
「선수들이 대표팀 운영 과정에서 어려움을 호소했느냐」  →  「그렇다」
「96라인의 문제 제기가 쌓여 온 것 아니냐」          →  「대답드리기가 좀 죄송하다」
```
⇒ 물음과 답을 **붙여** 놓으면 피한 답이 드러난다. 따로 적으면 안 보인다.

### ③ 배경을 뒤에 붙여 사건을 세우신다

10월 6일 우즈베키스탄전 → 황인범의 눈물 → 이강인이 다독인 것 →
「국감에서 과거 충돌 사례로 이름이 오른 선수가 이번에는 동료를 다독인 쪽에 있었던 셈이다」

⇒ **국감 하루를 적는 데서 멈추지 않고, 그 일이 어디서 왔는지를 뒤에 붙이신다.**

### ④ 댓글을 갈래로 묶으신다

내가 댓글을 늘어놓은 것을 사장님은 **다섯 갈래**로 묶으셨다 —
호칭 자체 · 주장이라는 직책 · 협회와 축구 행정 · 선발 기준 · 손흥민 개인.
각 갈래를 한 문장으로 열고(「비판은 선수에게만 향하지 않았다」) 그 아래 댓글을 붙이신다.

### ⑤ 마지막 한 줄로 사실의 한계를 적으신다

> 호칭을 둘러싼 주장이 사실인지는 협회도 선수도 아직 확인해 주지 않았다.

⚠ 이것은 「취재 뒷이야기」가 아니다. 주어가 **내가 아니라 협회와 선수**다.
  ⛔ 「확인해 보니 매체마다 달랐다」 — 주어가 나다. 쓰면 안 된다
  ✅ 「협회도 선수도 확인해 주지 않았다」 — 주어가 취재원이다. 써도 된다
