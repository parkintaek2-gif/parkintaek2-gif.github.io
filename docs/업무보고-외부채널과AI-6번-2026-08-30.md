# 업무보고 — 외부채널(유튜브·SNS)과 AI Agent · 6번 SeoulMarkets · 2026-08-30

> 사장님 지시(8/30): 유튜브·SNS·AI Agent 세 외부채널을 근거로 연구해 업무보고에 올리고 공유.
> 방식은 유튜브 때와 같이 «짐작 아니라 근거». 파일명에 외부채널+AI.
> 결론 요지: **우리 목적은 «우리 사이트 성장»** — 채널은 그 잣대로만 판단한다.

---

## 건①. 외부채널 — 유튜브

**결론: 필수단계에서 뺀다(안 올려도 된다).**
- 근거(실측): 전 유닛 GA4에서 유튜브발 세션 0~2명(90일). 100yearmap 0 · KCW 2. 유튜브 조회는 «유튜브 것», 우리 전환 <1%.
- 근거(구조): 구글은 유튜브 없이도 자체호스팅 영상을 색인한다(영상 사이트맵 + VideoObject). SeoulMarkets는 이미 갖춤(스키마 50 · 사이트맵 영상태그 32).
- 6번 실행: 유튜브 안 쫓음(브랜드채널 미설정으로 막혀있기도). 자체호스팅 유지.

## 건①. 외부채널 — SNS

**결론: 가볍게 «예» — 단 «유입»이 아니라 «색인 가속» 레버로.**
- 근거(실측): SeoulMarkets 소셜 유입 ≈0(공유카드는 있으나 아직 어디에도 안 올림 = 유튜브처럼 «안 해봄»).
- 근거(2026): 소셜은 «직접» 순위요인 아님·니치 유입 미미. **그러나 널리 공유되면 외부링크로 크롤·색인이 빨라진다.** X(트위터)는 구글이 색인함.
- 왜 우리에게 값: **6번 #1 병목 = 지면 색인**(‏/article 발견됐지만 색인·2페이지). SNS 공유가 여기에 정확히 듣는다.
- 6번 실행: 신규 기사마다 X(한국경제·데이터 커뮤니티)에 사실+수치+링크 공유(우리 AI인용형 톤). 가끔 Reddit/LinkedIn. 과투자 금지(엔진은 온페이지 SEO, SNS는 가속기). ⛔ 계정 «생성»·자동 «게시»는 제 규정(계정생성 금지)+브라우저 미연결로 막힘 — 계정만 서면 게시 방식 논의.

## 건②. AI (AI Agent / AI Assistant)

**결론: 니치 데이터 사이트에겐 «가장 강한» 외부채널. 이미 우리 강점과 정렬 — 더 키운다.**
- 근거(실측): 전 유닛 GA4 90일 chatgpt.com 21세션 — 유튜브(2)·SNS의 «10배». AI Assistant는 회사 정본 «진짜 손님»에 포함된 실재 유입.
- 근거(구조): AI 에이전트(ChatGPT·Perplexity·Claude)는 «단정적 사실 + 출처 + 재현 가능한 수치»를 인용한다. 우리 데이터저널리즘이 이미 그 형태다. robots 확인: AI 크롤러(GPTBot·PerplexityBot·ClaudeBot 등) 차단 없이 전부 허용(Allow: /).
- 🔴 갭/레버: **llms.txt 없음(404)** — AI에게 핵심 지면을 안내하는 신흥 규약. 큐레이션된 llms.txt를 두면 AI가 우리 최고 데이터·기사를 더 잘 집는다. (저비용 실행 후보)
- 6번 실행: ①AI인용형 작성 계속(단정 사실·출처·재현 수치 — 이미 함) ②llms.txt 신설 검토 ③기사 HTML을 AI가 읽기 쉽게(빠르고 구조적 — 이미 정적·경량).

## 종합(6번 관점) — 세 채널의 «우리 사이트 성장» 기여 순위
```
1위  AI Assistant/Agent   실측 최다(chatgpt 21) · 우리 강점과 정렬 · 저비용 → 최우선 육성
2위  SNS(특히 X)          유입은 미미하나 «색인 가속»이 내 병목에 적중 → 가볍게 도입
3위  유튜브                전환 <1% · 손 많이 듦 → 필수단계서 제외(채널만 유지)
```
⇒ **공통 진짜 병목은 «지면 색인/순위»** — 세 채널 모두 그 위에서만 효과. 일일 화력은 롱테일+클러스터 상호링크로 지면을 색인·순위 올리는 데 싣는다.
