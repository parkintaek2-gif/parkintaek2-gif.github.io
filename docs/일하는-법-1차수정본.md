# 1. 병렬형 구조 — 우리 AI

> **읽기·조사·검증은 여럿이 동시에. 고치는 책임은 하나.**

## 1-1. 투자 AI 셋

```
① 애널리스트    신호를 만든다              ← 조사 (병렬)
② 펀드매니저    포지션을 정한다             ← 제작 (편집 책임 하나)
③ 리스크관리자   한도를 감시하고 멈춘다 **독립**  ← 검증 (병렬)
```

검증이 제작에 붙으면 **「같은 것이 사고 같은 것이 괜찮다고 하는」** 구조다. 통제가 아니다.

## 1-2. 상담 AI — ⭐ **이 구조가 실제로 결함을 잡았다** (1번 제보)

```
판정   규칙 엔진        결정론
설명   AI 가 읽어 말한다  판정을 바꾸지 않는다
검증   **설명 AI 와 독립**
```

> 2026-08-01, 상담 AI 가 「상관 대운이 정관격과 어긋난다」고 답했다.
> **검증 AI 가 「그 판단은 엔진이 준 것이 아니다」**라고 잡았다.
> 원인은 프롬프트가 아니라 **데이터 파이프라인**이었다.
> **셋이 붙어 있었으면 아무도 못 잡았다.**

## 1-3. 리포트

```
자료 수집·사실 확인  →  초안  →  숫자 대조·렌더 확인
   (병렬)             (하나)      (병렬)
```

# 3. 협업

## 3-1. 우리가 낸 사고

```
① 1번이 `git add -A` 로 **4번이 편집 중이던 파일**을 쓸어갔다
② 2번이 3번 파일을 고치고 **24분 뒤에** 알렸다 — 통보였지 협업이 아니었다
③ 3번이 잘못 진단한 것을 2번에게 넘겼고, 2번이 **같은 도구로 재서 같이 틀렸다**
```

## 3-2. 그래서 정한다

| | 규칙 |
|---|---|
| **편집 책임** | 파일마다 주인이 하나. 남의 파일은 **고치기 전에 말하고** 결과를 보고한다 |
| **급하면** | 고치되 메모에 남긴다. ⛔ **단 상대가 지금 작업 중인 파일은 급해도 손대지 않는다** (1번) |
| **커밋** | `git add -A` 금지. **경로를 지정한다** — 저장소를 나눠 쓰므로 남의 작업이 딸려 간다 |
| **읽기·검증** | 누구나 언제든. 병렬이라야 빨라진다 |
| **받은 편지함** | 움직이기 전에 세션간-메모 꼬리를 본다 (`npm run inbox`) |
| **원인을 넘길 때** | ⭐ **어떤 도구로 쟀는지를 같이 적는다.** 틀린 진단을 넘기면 **두 배가 된다** (3번) |

## 3-3. 규칙은 파일에 남긴다 — ⚠ **남겼다고 걸리는 게 아니다** (1번)

`AGENTS.md` 자리에 우리는 **`CLAUDE.md`** 가 있다.

```
좋은 결과 → 그 방식을 남긴다      실수 → 막는 한 줄을 넣는다
```

**그런데 「남겼다」와 「적용됐다」는 다르다.** 1번이 겪은 것들이다.

```
· 공통 부품을 만들었는데 화면마다 **그릇 이름이 셋**이라 두 화면에 안 걸렸다
· 지적을 반영했는데 프롬프트가 **두 갈래**인 걸 몰라 **절반만** 반영됐다
· CSS 를 고쳤는데 **같은 셀렉터가 뒤에 또 있어** 계속 덮고 있었다
```

→ **「부품을 실제로 쓰는가」를 기계로 센다.** 「공통이니까 다 바뀌었겠지」가 제일 위험하다.

## 3-4. 24시간 이어가기

```
예약   자동 이어가기 2시간 · 아침 9시 · 저녁 9시 보고
⚠ 세션이 바뀌면 사라진다 · recurring 은 **7일 뒤 만료**  → 세션 시작하면 CronList 부터
```

# 4. 반복 업무는 시스템으로

```
npm run <이름>   한 번 짠 절차를 이름으로 (수집기 9종·시험·배포)
작업 스케줄러     시각에 맞춰 스스로 (18:00~18:40 · 22:00 Riot)
npm test         지시 색인·파서 시험. 규칙을 코드가 지킨다
```

## 4-1. 승격 순서 — ⚠ **검증 없이 예약에 걸지 않는다** (1번 지적, 원문 12장)

```
1번째   손으로 한다
2번째   「또 하겠구나」 → 스크립트로 만든다
3번째   예약에 건다
```

> ⭐ **예약으로 올리기 전에**: 서로 다른 **정상 입력 3건**에서 같은 기준을 통과하고,
> **멈춰야 할 예외 1건**에서 안전하게 중단하는지 확인한다.
> 그리고 **운영 중인 것을 바로 덮어쓰지 않는다** — 실행 루프와 개선 루프를 분리한다.

## 4-2. 자동화에는 **안전장치를 함께**

```
· 결과는 `.new` 에 쌓고 **다 끝난 뒤에** 바꿔치기한다   (재수집 중 본 파일이 비었다)
· 이어받기를 만든다                                  (백필이 94%에서 죽어 전부 날렸다)
· 다시 계산할 때는 **「없어진 값」 카운터**를 둔다       (42건이 조용히 사라질 뻔했다)
```

⭐ **1번·3번 둘 다 이 문서에서 「없어진 값 카운터」를 가장 크게 가져갔다.**
채움률만 보면 **올라간 숫자에 가려 사라진 값이 안 보인다.**

## 4-3. ⭐ 고치는 것보다 **못 만들게 하는 것**이 오래 간다 (3번)

학과→학교 링크 **406개가 404** 였다. 원인 셋을 다 고쳤지만, 값을 한 건 그게 아니었다.

```
⛔ 404 를 찾아 고친다          원자료가 바뀌면 또 생긴다
✅ **페이지가 있는 것만 링크한다**  다시는 안 생긴다
```

**「검증으로 잡는다」보다 「구조로 못 나게 한다」가 먼저다.**

# 5. 검증 — 「했다」가 아니라 「봤다」

```
자료   폴더·문서·원자료·화면
기준   권한·말투·완료 조건·금지 사항
증거   **렌더링·테스트·스크린샷·링크 확인**
```

## 5-1. ⚠ 그다음 층 — **엉뚱한 걸 봤을 수 있다** (1번, 하루에 다섯 번)

```
① 뽑는 폴더와 검사하는 폴더가 달랐다   「감수용 리포트」 vs 「리포트-감수용」
   → 「33종 통과」가 전부 **하루 전 PDF** 기준이었다
② 렌더 도구가 ok=true 를 무조건 줬다   글자 하나까지 같은데 ✅
③ 명암비 검사가 SVG 를 잘못 읽었다     **거짓 경보 40건**
④ 넓은 정규식이 **틀린 진단명**을 붙였다
```

```
· 거짓 경보는 진짜 한 건을 **묻는다**
· 틀린 진단명은 없는 것보다 **나쁘다** — 엉뚱한 데를 고치게 만든다
· **검사가 헛도는지 먼저 확인한다** — 일부러 틀린 값을 넣어 실제로 실패하는지 본다
```

## 5-2. ⚠ **도구가 입력을 바꾼다** (3번 → 2번, 둘이 함께 틀렸다)

```
3번이 curl 로 재서 404 를 봤다 → 원인과 패치를 2번에게 넘겼다
2번이 「재현했다」고 답했다      → **같은 도구로 쟀으니 같이 틀렸다**
Node 로 다시 재니 **처음부터 200** 이었다
```

원인은 **Windows 셸이 한글을 CP949 로 바꾼 것**. 주소가 아니라 **도구가 주소를 깨뜨렸다.**

```
⛔ 한글·백틱·긴 글을 **셸로 넘기지 않는다.** 파일에 써서 Node 로 읽는다
```

## 5-3. fixture 테스트는 **거짓 안심**이다 (1번, 같은 사고 두 번)

```
8/1  상담 AI 에 데이터가 안 갔다. 고쳤다
8/4  감수본을 눈으로 보니 **8/1 수정이 운영에서 한 번도 동작한 적이 없었다**
     함수는 맞았다. **데이터가 거기까지 안 갔다.** 두 번 다 테스트는 통과했다
```

```
⛔ 실제 저장 경로를 한 번도 안 거친 테스트는 없는 것보다 나쁘다
✅ 진짜 저장하고 진짜 조회를 거치게 짠다
```

## 5-4. ⭐ 숫자가 맞아도 **분모를 안 밝히면 거짓말**이다 (3번)

```
강릉원주  졸업 1,656명 → 취업대상 1,476명 → 취업 887명 = 60.1%
```

취업률의 분모는 졸업자가 아니라 **취업대상자**다. 대학원·군 입대·수험생은 빠진다.
분모를 안 밝히면 독자는 **「나머지는 놀고 있다」**로 읽는다.
**숫자는 맞는데 독자가 틀리게 읽으면 우리가 거짓말한 것이다.**

> 사장님의 「**판단하는 데 도움을 주는 것**」이 여기 걸린다. **모든 비율에 분모를 같이 적는다.**

## 5-5. 우리가 만든 숫자와 발표된 숫자를 **섞지 않는다** (3번)

```
⛔ 우리가 계산한 값을 「전국 평균」이라고만 쓴다
✅ 공식값이 있으면 그것을 쓴다. 우리가 계산했으면 **「우리가 계산했다」고 화면에 적는다**
```

## 5-6. 권한은 좁게

```
⛔ .env 읽기 · rm -rf · git push --force
⛔ ctype 에 `-t` 없으면 훅이 막는다 (klifemap 을 죽일 뻔했다)
⛔ 저장소가 공개다. **키 값을 커밋하지 않는다**
```

# 6. 감각적인 웹디자인 — 원문에 없어 우리가 채운 장

## 6-1. 감각은 **틀린 걸 알아보는 눈**이고, 그건 잴 수 있다

```
제목이 첫 화면의 **56%** 를 먹고 있었다      → 재서 알았다 (253px / 450px)
표 스타일이 **통째로** 죽어 있었다            → 재서 알았다 (글자 크기·색이 같았다)
「본문이 너무 넓다」고 진단했다가 취소했다     → 재보니 **이미 정상**이었다
```

**셋 다 눈대중으로는 반대로 판단했다.**

```
만든다 → 렌더한다 → **잰다** → 그다음 고친다
```

## 6-2. 매번 재는 여덟

```
첫 화면    제목이 화면의 몇 %인가 · 본문 첫 줄이 보이는가
글줄       한 줄에 몇 글자인가 (60~75)
활자 종류수 ⭐ **몇 종인가** (3번: 8화면에 **23종**, 한 장에만 16종이었다)
           0.5px 차이는 다른 단이 아니라 **어긋난 것**이다 → 네 단으로 줄였다
           `제목 19 > 부제1 15 > 부제2 13 > 본문=표 11.5` (+주 10) · 비율 약 1.28
           ⚠ **본문과 표를 같은 크기로.** 표만 작으면 부록처럼 보인다
모바일     **360px 에서 먼저.** 데스크톱을 줄이지 않는다
다크모드    배경·글자·표 경계선이 다 살아 있는가
인쇄       ⚠ **「보면 안다」가 안 통한다. 반드시 PDF 로 뽑는다** (6-4)
같은 옷    ⭐ **새로 만든 지면이 기존과 같은 스타일을 입었는가** (3번: 377장이 빈손으로 나갔다)
무게       외부 스크립트 몇 개 · 몇 KB
```

## 6-3. 트렌드는 베끼지 말고 **원칙으로 옮긴다**

```
⛔ 「요즘 이게 유행이다」   → 다음 유행이 오면 다시 만든다
✅ 「왜 좋아 보이나」       → 여백·대비·정렬·**서열**. 안 바뀐다
```

⭐ **크기만으로 세운 위계는 흑백 인쇄에서 약하다** (3번).
제목 계열에 **명조**를 주면 크기가 비슷해도 층이 산다.
같은 서체에서 **색만 바꾸면 「강조」**로, **서체가 갈리면 「다른 것」**으로 보인다.

⭐ **브랜드는 이미지 없이 글자만으로 세울 수 있다.** 메일·요약·저사양처럼
**이미지가 안 뜨는 자리**에서도 브랜드가 살아 있어야 한다.

## 6-4. ⚠ 인쇄는 화면으로 **원리적으로 못 잡는다** (3번)

```
· 점수 막대가 인쇄에서 **통째로 사라졌다** — 배경색으로만 그렸기 때문
· 금색(#c9a84c)이 종이에서 **대비 2.1** — 화면에서는 멀쩡하다
· `md:grid-cols-2` 는 **화면 폭**에 반응한다 — 인쇄에서 규칙이 꺼져 **종이에서만** 무너졌다
```

## 6-5. 연습법

```
1. 잘 만든 데이터 지면을 **하나** 고른다 (FT · Bloomberg · Our World in Data)
2. 베끼지 말고 **잰다** — 글줄 길이, 여백, 색 몇 개, 굵기 몇 단계, **활자 몇 종**
3. 우리 지면을 같은 자로 재고 **숫자 차이를 적는다**
4. **하나만** 고치고 다시 잰다
```

# 7. 한 장으로

```
① 나눌 수 있는 일은 나란히. **고치는 사람은 하나.**
② 검증하는 쪽은 만드는 쪽과 **독립.** 타협하지 않는다.
③ 시작 전에 **「끝」의 정의**를 적는다. 배포가 아니라 200 이고 눈으로 본 것.
④ 규칙은 **파일**에 남긴다. 그리고 **실제로 걸렸는지 기계로 센다.**
⑤ 2번째면 스크립트, 3번째면 예약. **단 예약 전에 정상 3건·예외 1건을 통과시킨다.**
⑥ 자동화에는 **안전장치를 함께** — 임시파일·이어받기·손실 카운터.
⑦ **검사도 틀린다.** 일부러 틀리게 넣어 **실제로 실패하는지** 본다.
⑧ 내가 쟀다는 것이 근거가 아니다. **무엇으로 쟀는지**가 근거다.
⑨ 고치는 것보다 **못 만들게 하는 것**이 오래 간다.
⑩ 모든 비율에 **분모**를 적는다. 독자가 틀리게 읽으면 우리가 거짓말한 것이다.
⑪ 디자인은 눈대중하지 않는다. **렌더하고, 재고, 하나씩** 고친다. 인쇄는 **반드시 PDF 로.**
⑫ 이 전부는 **상품을 위한 것**이다. 정지작업은 팔 수 없고, **못 파는 데이터는 정지작업도 아니다.**
```
