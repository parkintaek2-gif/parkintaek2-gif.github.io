라이선스 판단은 `데이터-출처-라이선스.md`, 편성은 `데이터-지도.md` 로 넘긴다. 여기는 **실측 기록**이다.

## 0. 결론 먼저

**쓸 만한 것이 나왔다. 다만 「데이터」가 아니라 「분석·전망」이다.**

우리가 지금 갖고 있는 것은 가격·수급 같은 **숫자**인데 전부 T+1 이다.
국책연구원이 주는 것은 **해석**이다 — 성장률 전망, 산업 진단, 유가 전망, 곡물 수급.
숫자가 하루 늦은 매체에 **해석은 늦은 게 아니다.** 여기가 T+1 제약을 우회하는 자리다.

그리고 결정적인 것 하나.

> **KDI·KIEP·KCMI 는 자기들이 영문판을 직접 낸다.**
> 우리가 번역하지 않아도 되고, 번역 오류로 신뢰를 깎을 일도 없다.
> KDI Open API 는 응답 필드에 `PUB_NM_ENG`(영문 제목)·`SUMM_ENG`(영문 요약)가 **아예 들어 있다.**

영문 데이터저널리즘 매체에 이건 그냥 좋은 게 아니라 **구조적으로 맞는** 소스다.

## 1. robots 판정 — RFC 9309 대로 `*` 그룹만 봤다

⚠ **네이버에서 한 번 틀린 자리다.** `yeti` 그룹의 `Allow` 를 보고 「허용」이라 했었다.
Allow/Disallow 는 **바로 앞 User-agent 그룹에 속한다.** 우리는 `*` 그룹만 따른다.

### ❌ 전면 차단 — 쓰지 않는다

| 기관 | robots |
|---|---|
| **KLI 한국노동연구원** | `User-agent: *` → `Disallow: /` (Yeti·Googlebot·Daum 만 허용) |
| **KEI 한국환경연구원** | `user-agent:*` → `disallow:/` (동일 구조) |

네이버와 **똑같은 패턴**이다. 검색엔진만 들이고 나머지는 막는다.
기술적으로 받아지는 것과 받아도 되는 것은 다르다. **안 쓴다.**

### ✅ 전면 허용

KDI · KDI 경제정보센터 · **KCMI 자본시장연구원**(`Allow: /`) · KREI(robots.txt 자체가 없음) ·
KESIS 국가에너지통계(`/aivorySearch` 만 차단) · ISTANS 산업통계(**`*` 그룹이 아예 없음 → 규칙 미적용**)

### ⚠ 부분 허용 — 경로를 지켜야 한다

| 기관 | 허용 | 주의 |
|---|---|---|
| **KIF 한국금융연구원** | `Allow: /kif4` | `/kif`·`/kif2`·`/kif3`·`/pub` 는 차단. **실서비스가 전부 `/kif4` 라 사실상 전면 허용이다** |
| **KIET 산업연구원** | `Allow: /` | `/kiet_web/`·`/part/`·`/common/file/`·**`/trends/futbriefList`** 차단 |
| **KMI 해양수산개발원** | `Allow:/` | `/globalnews` 차단 |
| **KIEP 대외경제정책연구원** | **거부 기본 + 허용 목록** | `Disallow: /` 아래 `/board.es`·`/gallery.es`·`/attachedFileDownload.es` 가 **명시 허용**. 발간물 경로는 열려 있다 |

> ⚠ KIEP 를 처음에 「전면 차단」으로 찍었다가 틀렸다. `Disallow: /` 만 보고 판정했는데
> 그 아래 허용 목록에 발간물과 첨부 내려받기가 들어 있었다. **거부 기본형은 허용 목록까지 읽어야 한다.**

## 2. 기계로 받을 수 있나

### RSS — **18곳 전수 확인. 한 곳도 없다**

추정 경로 7종(`/rss`, `/rss.xml`, `/rss/board.es`, `/rssList.do` …)을 던지고,
그것도 못 믿어 **홈페이지 HTML 에서 `rss` 가 들어간 링크를 직접 뽑았다.** 전부 0건이다.
갱신 감지는 목록 페이지를 직접 봐야 한다.

### ✅ KDI Open API — 유일한 정식 API

```
https://www.kdi.re.kr/KDIOpenAPI?type=json&apiKey={키}&cd={구분}
```

| cd | 내용 | 주기 |
|---|---|---|
| A | 기본연구보고서 | 수시 |
| B | 현안자료 | 수시 |
| C | **KDI 경제전망** | **연 2회(5·11월)** |
| D | **KDI 경제동향** | **매월 초순** |
| E | 학술지(JEP) | 분기 |
| F | 영상보고서 | 수시 |

응답 필드 — 우리에게 중요한 것만:

```
PUB_NM_KORN / PUB_NM_ENG      보고서명 국·영문
SUMM_KORN   / SUMM_ENG        요약   국·영문      ← 영문 요약을 준다
MAIN_AUT_NM / SUB / CO_AUT_NM 주·부·공저자        ← 저자 실명. YMYL 신뢰도에 직접 붙는다
ISSU_DT                       발행일
PUB_KEYWORD / TOPIC_ARR       키워드 · 연구분야
DETAIL_PAGE                   원문 링크           ← 출처 표기에 그대로 쓴다
```

검색 파라미터 `srhKey`(ALL/TITLE/NAME/CONTENT) + `srhValue` 로 주제 필터가 된다.

**키 없이 부르면 `null` 이 온다.** 실측했다.

## 4. ⚠ 라이선스 — 여기가 제일 조심할 곳

### 공공누리(KOGL) 표기가 **한 곳도 없다**

14개 기관 홈페이지를 훑었는데 공공누리 마크·유형 표기가 0건이다.
공공데이터포털 데이터셋과 달리 **「1유형이니 상업 이용 가능」 같은 근거가 없다.**

### KCMI 저작권정책 — 유일하게 명문이고, 제한적이다

> 「…**영리목적이 아닌** 보도, 교육, 연구 등 정당한 범위 안에서 특별한 제약 없이 활용할 수 있습니다.
>  다만 … 연구원의 허락 없이 **무단으로 수정이나 개작하는 것을 금지**합니다.」

우리는 **광고 매체(영리)** 이고 **영문 가공은 개작**이다. 두 조건에 다 걸린다.
→ **KCMI 보고서를 통째로 번역·요약해 싣는 것은 안 된다.**

### 그러면 무엇을 할 수 있나 — **사실과 표현을 가른다**

```
✅ 사실(숫자)      「KDI 는 2026년 성장률을 1.6%로 봤다」
                   숫자·전망치·판정은 저작권 대상이 아니다. 누가 언제 냈는지 밝히고 쓴다
✅ 짧은 인용       저작권법 제28조 — 보도·비평 목적, 정당한 범위, 출처 명시
                   우리는 인터넷신문으로 등록한다. 보도 목적이 성립한다
✕ 전문 번역        표현의 복제다. 분량이 커지면 인용이 아니라 전재다
✕ 요약문 통째 옮기기 SUMM_ENG 를 그대로 붙이면 그것도 복제다
```

**이건 증권사 리포트에서 이미 정한 원칙과 같다** —
「목표주가 ㅇㅇㅇ원, 투자의견 중립」 같은 **사실만 쓰고 구성·문장은 우리 것으로 짠다.**
국책연구원도 똑같이 간다. 다른 점은 **여기는 공공기관이라 인용에 더 관대하다**는 것뿐이다.

⚠ **다만 KDI Open API 는 별도다.** 신청·승인을 받고 쓰는 것이라 **이용 조건이 신청 화면에 붙는다.**
키를 받는 순간 그 조건 원문을 이 문서에 그대로 옮긴다. 받기 전에 「된다」고 적지 않는다.
