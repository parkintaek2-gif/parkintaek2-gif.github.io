## 3. AI Agent — 새로 조사: 이미 작동 중이나 손볼 곳이 있었음

| 항목 | 값 |
|---|---|
| 크롤러 구성(2026-08-05 실측, 이미 알려진 사실) | 우리를 찾아오는 크롤러의 **96%가 AI 크롤러**, 구글은 9건뿐 |
| robots.txt | 모든 크롤러 허용(`Allow: /`) — AI 크롤러(GPTBot·ClaudeBot·PerplexityBot 등) 차단 없음 |
| llms.txt(AI 답변엔진용 안내문) | 2026-08-22부터 이미 존재, 라이브 200 |
| 🔴 발견한 결함 | llms.txt가 **정적 문자열**이라 새 지면과 자동 동기화가 안 됨 — 이번 세션에 만든 3편(idle-youth·wealth-gap·youth-budget-2027)이 빠져 있었음 |
| 결함 수정 | ✅ 커밋 완료(다음 배포에 반영) — 지면 수 20→23으로 갱신 |
| 90일 GA4 실측 — "AI Assistant" 채널(chatgpt.com·perplexity.ai) 발 100yearmap.com 세션 | **18건**(chatgpt.com 15 · perplexity.ai 2 · perplexity 1) |
| 유튜브·SNS와 비교 | 유튜브 0건·SNS 0건보다 **훨씬 건강한 실측치** — 우리가 아무것도 "올리지" 않았는데도 AI가 실제로 사람을 데려온 유일한 외부 채널 |

**3번 결론**: AI 크롤러 유입은 이미 실측으로 검증된, 유일하게 "입구"로 작동 중인 외부 채널이다(18건/90일, 유튜브·SNS는 0건). robots.txt·llms.txt 구조는 맞게 돼 있었고, 발견된 결함(llms.txt 지면 목록 노후화)은 즉시 고쳤다. ⚠ llms.txt가 **수동 갱신** 방식이라 새 지면을 낼 때마다 또 빠질 위험이 있음 — 다음에 자동화(다른 지킴목록들처럼 스크립트로 자가시험)할지는 별도 판단 필요.
