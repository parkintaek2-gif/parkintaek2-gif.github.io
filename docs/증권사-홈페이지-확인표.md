## 「긁기」 칸이 무슨 뜻인가

각 사 `robots.txt` 를 RFC 9309 대로 **`User-agent: *` 그룹만** 보고 판정한 것입니다.

```
✅ 허용   우리가 그 사이트에서 자료를 받아도 되는 곳
⛔ 금지   Disallow: / — 받으면 안 되는 곳. 그래서 직접 수령이 유일한 길이다
⬜        사이트 도달 실패로 판정 못 함
```

⚠ **「긁기 ⛔」와 「직접 수령」은 완전히 별개입니다.** 배포받아 쓰는 것은
robots.txt 와 아무 상관이 없습니다. **금지된 곳일수록 직접 수령이 더 중요합니다.**
1·2위(하나·LS)가 합쳐서 15,303건인데 둘 다 ⛔입니다.
