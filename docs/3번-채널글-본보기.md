# 3번 — **채널글 본보기** (계정이 열리는 날 그대로 나간다)

> 사장님 — 「엑스·쓰레드에 맞는 텍스트, 페이스북에 맞는 텍스트 — **다 따로따로** 가야 되겠지」
> 사장님 — 「**「계정이 없어 못 했다」로 적지 마라.** 준비됐다 · 계정만 열면 오늘 나간다로 적고,
> 자산은 미리 다 만들어 둬라」

⛔ 같은 글을 세 곳에 복사해 붙이지 않는다. **길이가 아니라 「말 거는 방식」**이 다르다.

```
스레드   긴 글이 읽힌다   →  **왜 그런지**를 푼다
X       짧게 끊긴다     →  **숫자 둘과 반전 한 줄**. 설명은 링크로
인스타   글보다 그림     →  카드가 말하고 글은 **목록 세 줄**
                          ⛔ 본문 링크가 안 걸린다 → **「프로필 링크」**로 적는다
공통    9,900원이나 지면 주소가 **글마다** 들어 있다
⛔ 해시태그는 인스타에만. 스레드·X 에서는 잘 안 걸린다
```

🔴 **글에 쓰는 수는 그 지면에 있는 수여야 한다.** 어제 영상에서 없는 수를 말해 데었다.
   내기 전에 라이브에서 하나씩 대 본다.

## 본보기 ① — 지역 한 벌 (카드 `og/area-서울특별시-노원구.png`)

**대는 지면** `https://100yearmap.com/report/area/서울특별시-노원구`
**대 본 수** 26곳 · 55.5% · 86.2% · 17곳 · 일반고 17.3% · 자율고 26.2% · 9,900원 — **일곱 다 있음**

### 스레드
```
노원구에 고등학교가 26곳 있습니다.

그중 진학률을 잰 곳이 17곳이고,
가장 낮은 곳이 55.5%, 가장 높은 곳이 86.2%입니다.

그런데 가장 낮게 나온 학교가 나쁜 학교냐 하면 그렇지 않습니다.
갈래마다 「그 밖」 칸이 원래 다릅니다. 일반고 17.3%, 자율고 26.2%.
재수를 택한 학생이 그 칸으로 들어가고, 재수생은 진학률에서 빠집니다.

저희는 등수를 매기지 않습니다. 퍼짐 안에서 어디쯤인지만 보여드립니다.
26곳 한 장 → 100yearmap.com/report/area/서울특별시-노원구
```

## ⬜ 아직 안 쓴 것 — **여기가 구멍이다**

```
⬜ 학교 낱장 카드 2,525장   글 0벌   ← 제일 많은데 한 벌도 안 썼다
⬜ 나이·층 카드            카드 자체가 없다
⬜ 0~9세(초등) 카드         지면이 아직 없다
```
⚠ 본보기 하나로 **꼴은 정해졌다.** 남은 것은 수를 갈아 끼우는 일이다.
⛔ 다만 **수를 갈아 끼울 때마다 그 지면에서 다시 대 봐야 한다.**
