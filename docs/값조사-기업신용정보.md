### 4. CRISIL (CRISIL Ratings)

```
공개 가격표      없음 — «투자자가 사는 값»이 아니라 «발행사가 내는 값»(issuer-pays) 구조다.
                등급을 받으려는 회사가 CRISIL에 수수료를 내는 방식 — S&P·Moody's·Refinitiv와
                모델 자체가 다르다(그쪽은 열람자 구독제, CRISIL은 피평가사 지불제)
공개된 것        「MoU 은행 고객·업종단체 회원에게는 할인 수수료를 적용한다」는 원칙만 공개
못 쟀다          구체적 숫자(%, 최저금액)는 이번 조사에서 못 찾았다
출처            https://www.crisilratings.com/en/home/our-business/ratings/understanding-rating/rating-faqs.html
```

### 5. CARE Ratings (CareEdge Group)

```
공개 가격표      있음(수수료율표) — issuer-pays 구조, CRISIL과 같은 모델
수치            신규 등급 — 정기예금 0.10%(잔액 기준) · 회사채·CP 0.10%(발행액 기준) ·
                발행사등급 0.05%(잔액 기준), 최저 수수료 20만~30만 루피
                연차 사후관리(surveillance) — 잔액의 0.03~0.05%, 최저 10만~20만 루피
⚠ 출처 신뢰도    이 수치의 원출처가 오래된 스크립트(scribd) 업로드 문서라 **작성 시점이
                불명확**하다 — 지금도 유효한 요율인지 CareEdge 공식 지면에서 재확인이 필요하다.
                「공개된 값이 있다」는 사실과 「지금 값이다」는 사실을 같은 것으로 안 쓴다
출처            https://www.scribd.com/document/49070163/Care (2차 출처, 원본 미확인)
```

### 요약 — 1번이 본 것

```
✅ 다섯 곳 모두 공개된 «투자자용 구독료 정가표»는 없다 — 이 업계 관행이다
✅ 다만 CRISIL·CARE는 애초에 다른 모델(발행사가 내는 요율, %기반)이라 「가격이 없다」가

```
