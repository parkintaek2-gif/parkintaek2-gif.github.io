# 세션 입구 — 프로필 CLAUDE.md 의 사본

새 창이 열리면 Claude Code 가 **프로필 폴더의 `CLAUDE.md`** 를 자동으로 읽는다.
그 파일이 세션 입구다. 프로필 폴더는 저장소 밖이라 잃으면 못 되살리므로 여기 사본을 둔다.

| 유닛 | 정본 (프로필) | 사본 |
|---|---|---|
| 1번 | `C:\Users\USER\.claude-u1\CLAUDE.md` | `1번.md` |
| 2번 | `C:\Users\USER\.claude-u2\CLAUDE.md` | `2번.md` |
| 5번 | `C:\Users\USER\.claude-u5\CLAUDE.md` | `5번.md` |

⚠ `.claude`(사장님과 2번이 함께 쓰는 admin 기본 프로필)에는 두지 않는다 —
  사장님이 직접 쓰시는 창이라, 유닛 안내가 뜨면 사장님 화면이 어지러워진다.

## 고칠 때

**정본(프로필)을 고치고 여기로 복사한다.** 반대로 하면 다음 창이 옛 안내를 읽는다.

```bash
cp C:/Users/USER/.claude-u2/CLAUDE.md docs/세션입구/2번.md
```
