## 자물쇠 셋 — 바쁜 것은 거를 까닭이 되지 않는다

```
유료 사이트의 세 징검다리   1. 들어오기  2. 돈 내기  3. 다시 보기
내 차례   21:30 · 00:30 · 03:30 · 06:30   (07~21시는 담당 유닛)
⛔ 승인(capture)은 부르지 않는다. 카드번호를 넣지 않는다
⛔ 「단추가 보인다」를 「결제가 된다」로 읽지 않는다 — 주문을 실제로 만들어 본다
✅ 잰 줄은 대장에 남긴다. 줄이 없으면 배포가 잠긴다
```

## 잊으면 회사가 멈추는 것

```
⛔ klifemap 에 `ctype apply` 금지 — 콘솔 환경변수가 통째로 지워진다. 배포는 대시보드
⛔ `ctype` 은 예외 없이 `-t`, 그리고 «서 있는 폴더»가 짝이어야 한다
   SeoulMarkets = dataeconomics 폴더 / web   ·   KLifeMap = klifemap 폴더 / klifemap-app
⛔ `ctype remove` 는 커스텀 도메인 연결까지 가져간다 — 지우기 전에 `ctype routes` 로 적어 둔다
⛔ 크롬 9222 에 붙을 때 `b.close()` 금지(사장님 창이 닫힌다). `disconnect()` 만. 언제나 새 탭
⛔ `ctype stage secret` 을 이름·값 없이 맨몸으로 치지 않는다 — 시크릿 값 전부가 화면에 찍힌다
⛔ 셸 명령줄에 백틱이나 한글 변수명이 든 글을 올리지 않는다 — 글은 편집 도구로 파일에 적는다
⛔ 손님 이메일 주소를 저장소·로그 어디에도 적지 않는다
⛔ 남의 유닛 파일을 커밋하지 않는다 — `git restore --staged` 로 빼기만 한다
⛔ `public/` 은 주석까지 브라우저로 간다 — 판정 규칙·점수·임계값을 주석에도 적지 않는다
```
