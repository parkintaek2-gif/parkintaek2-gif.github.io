```
공공데이터는 공짜다. 그런데 **무엇을 못 보는지는 아무도 안 적는다**

· 교육부 「건강보험 직장가입자」에는 **교내취업자가 들어간다.** 모르고 세면 학과마다 몇 %p 씩 틀린다
⛔ 사는 쪽은 이걸 모른 채 쓰거나, 알아내느라 며칠을 쓴다
```
⭐ 우리 안에서도 같은 일이 났다 — 오늘 하루에 **기준·정의가 빠져 잘못 읽힌 수가 다섯**이었다.

## ③ 우리 해법 · 왜 우리만 되나

```
파는 것   자료 한 벌 + **네 칸이 값마다 붙은 것**
          출처(기관·데이터셋 번호·이용허락범위·받은 날·원본 경로)
          덮는범위(이 자료가 **못 보는 것**)
          대조(어느 공표치와 몇 % 다른가)
          ⛔경고문(이 수로 하면 안 되는 말)
```

**왜 우리만 되나 — 이미 해 놓았다. 오늘 잰 실적이다.**
```
학과 축      교육부 공표와 **0.03%** 안 (졸업 634,726/634,904 · 취업률 69.5% 일치)
취업 갈래 여섯 공표와 **0.04%** 안
규모 축      고용노동부 공표와 **-4.4% ~ +3.0%**
지역 축      시도 공표와 **r=0.935** · 업종을 맞추면 차례가 공표와 **똑같아짐**
업종 축      ⛔ **공표에 같은 칸이 없다** — 그렇게 적어 두었다
덮는 몫      사람 78.8% · 사업장 25.2% (둘 다 공표치와 견줌)
```
⭐ **못 맞춘 하나를 적어 둔 것**이 맞춘 셋보다 중요하다. 그게 이 물건의 정체다.

## ④ 시장 — TAM(Total Addressable Market · 전체 시장) / SAM(Serviceable Addressable Market · 닿는 시장) / SOM(Serviceable Obtainable Market · 딸 몫)

⛔ **원(₩) 으로 적지 않는다.** 값을 모르는데 곱하면 그건 가정×가정이다(오늘 그 잘못을 두 번 짚었다).
✅ **곳수로 적는다.** 곳수는 셌다.

```
TAM  **19,682곳**   자료를 살 수 있는 조직 전부
                    학교 밖 18,923곳(병원 13,097·요양병원 2,153·인력채용 2,111·보험 754·
                    복지 520·기업교육 288) + 대학 377 + 시군구 229 + 교육청·지원청 153
SAM  **3,392곳**    지금 우리 자료가 바로 쓸모 있는 곳 —
                    직원 300명 이상 사업장(복지·인사 예산이 있는 곳). 셌다
SOM  **10곳**       2027 에 닿을 수 있는 곳. ⚠ 근거는 「셀 수 있는 모집단」뿐이고
                    전환율 근거는 **없다**(유입 0). 가정이라고 적는다
```
⚠ 시군구 229 는 **행정 구역 수**다. 「자료를 사는 곳」을 센 것이 아니다.
⛔ 지자체·공공기관은 국민연금 파일로 **못 셌다**(공무원연금 소관).

**🔴 원(₩)으로 옮기면 — 어느 칸이 잰 것이고 어느 칸이 정한 것인지 밝힌다** (2026-08-10 추가)
```
곳수      3,392곳    ● **잰 것** (국민연금 사업장 300명 이상)
값        300만원/년 ○ **정한 것** (⑤ 참조 — 잰 눈금 위에 앉힌 값. 받아 본 값이 아니다)
────────────────────────────────────────────────
SAM       **101.8억원/년**   ⚠ 실측 × 가정이다. 한 칸이 가정이면 곱도 가정이다
SOM 2027  **3,000만원**      10곳 × 300만원. ⛔ 전환율 근거 없음(유입 0)
```
⛔ **101.8억을 「우리 매출」로 읽지 마라.** 3,392곳이 **전부** 산다는 뜻이 아니라 **살 수 있는 곳의 크기**다.

## ⑤ 사업 모델 — 🔴 **연 구독** (건당 아님)

```
누가    자료로 판단을 내리는 조직 — 지자체 정책부서 · 교육청 · 대학 기획처 ·
        요양·병원 체인 본부 · 보험 상품기획 · 인사/복지 담당(300명 이상 사업장)
무엇에  **검증된 자료 한 벌 + 해마다 다시 대조해 주는 것**에 값을 낸다
어떻게  연 단위 구독. 한 벌을 받고, 원자료가 갱신될 때마다 **다시 대조한 판**을 받는다
```

**⛔ 왜 건당이 아닌가 — 이 물건은 한 번 팔면 끝나는 물건이 아니다**
```
국민연금은 **달마다** · KEDI 는 **해마다** 바뀐다. 작년 판은 작년 이야기다
건당으로 팔면 사는 쪽이 **낡은 판을 그대로 쓴다** → 우리 이름이 붙은 틀린 수가 돌아다닌다
```
**⭐ 그리고 구독이라야 「있는 손님이 더 쓴다」가 선다** — 축을 늘리면(집·건강·기후)
같은 손님이 같은 값을 더 낸다. 새 손님 없이 매출이 는다(재구매율 > 100%).

### 🔴 값 — **곳당 연 300만원.** 근거를 잽니다 (2026-08-10 · 2번 지시)

> 2번: 「3,392곳 × 연 300만원이면 100억입니다. **그 300만원이 근거가 있어야 합니다**」

⛔ 나라장터는 두 번 막혔습니다(API 미등록 · 화면이 안 읽힘). **다른 길로 쟀습니다** —
지자체·공공기관이 **직접 올린 「계약현황」 파일데이터**입니다. 전부 이용허락범위 제한 없음, 활용신청 없이 받았습니다.

```
🔒 잰 자   scripts/measure-100y-service-price.mjs (자가시험 24 · 실패 0)
잰 것      조사·연구 용역 **계약 1건의 계약금액(원)**
           나눔: 계약금액 ÷ 계약 1건.  ⛔ 곳당이 아니라 **건당**입니다
표본       데이터셋 25벌 · 걸린 계약 **1,341건** · 받은날 2026-08-10
           (경기 고양 378 · 충남 논산 177 · 충남 예산 148 · 경북 영주 130 · 대구 달서 118 …)
```

**■ 사는 쪽이 실제로 낸 돈 — 순위가 아니라 분포입니다**
```
최소       145,160원
1사분위    **9,900,000원**   ← 넷 중 하나는 이보다 쌉니다
중앙값     **19,000,000원**
3사분위    26,189,000원
9분위      68,000,000원
최대       800,000,000원
```

**■ 그래서 300만원이 어디에 서 있나 — 기준을 적습니다**
```
300만원 ÷ 990만원(1사분위) = **30.3%**
👉 「한 번 만들어 주는 조사 용역의 **가장 싼 4분의 1**, 그것의 **3분의 1**」이 우리 자리입니다
```
⭐ **우리는 만들어 주는 게 아니라 이미 만들어 둔 것을 줍니다.** 그러니 그보다 싸야 팔립니다.
   300만원은 **비싸서 못 사겠다는 말이 안 나오는 자리**입니다.

⚠ **아직 가정인 것** — 값 자체는 **받아 본 적이 없습니다(결제 0건).**
   잰 것은 「사는 쪽이 *비슷한 일*에 이미 내던 돈」이고, 우리 값은 그 눈금 위에 **정한 것**입니다.
⛔ **못 잰 것** — 한 기관이 한 해에 몇 건을 내는지. 파일마다 담긴 기간이 달라 못 쟀습니다.

## ⑦ 성장 전략 (불릿 여섯)

```
· **첫 한 곳** — 값 없이라도 한 곳에 넣어 본다. 값은 그 뒤에 정한다(2번 결정 대기)
· 🔴 **있는 손님이 더 쓰게** — 축을 늘린다(지금 학과·업종·규모·지역 넷 → 집·건강·기후).
  같은 손님이 축마다 더 낸다. 이것이 재구매율 > 100% 의 유일한 길이다
· **달치를 쌓는다** — 국민연금을 매달 받아 둔다. 소급이 안 되므로 오늘 안 걸면 영영 못 낸다.
  1년 뒤에는 **아무도 못 파는 것**(달치 12개)을 우리만 갖는다
· **자를 상품에 붙인다** — 자료를 살 때 자(검사 스크립트)도 같이 준다.
  사는 쪽이 다음 판을 스스로 검사한다 → 갈아타기 비용이 생긴다
· **못 맞춘 것을 먼저 보여준다** — 업종 축은 공표에 같은 칸이 없다고 먼저 말한다.
  이것이 신뢰를 파는 유일한 방법이고, 경쟁자는 이걸 못 한다(적으면 자기 물건이 깎여 보이니까)
· **3·5·6번이 먼저 쓴다** — 세 자리가 이미 내 자료를 쓴다. 사내 사용이 첫 사례가 된다
```
