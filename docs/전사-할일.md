```
매일 0시   각 자리가 자기 칸의 ①②를 고친다. 끝난 것은 ①로 옮긴다
2번        빠진 것이 없는지 보고, 없으면 없다고 적는다
```
⛔ 여기 없는 일을 벌이지 않는다. 벌이려면 **먼저 여기에 적는다.**
