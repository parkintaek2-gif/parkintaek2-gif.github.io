```

   → 「u1님의 등급을 할당되지 않음(으)로 업데이트했습니다」

   → 체크상자 「예약된 시트 다운그레이드를 확인하려면 여기를 클릭하세요」

⇒ 예상 총액  US$192.50 → **US$165**  (= $150 + 부가세 10%)
```

### ⚠ 이 길에서 배운 것 셋

```
⛔ 좌석 수는 «배정된 멤버 수»보다 적게 못 준다 — 화면이 그렇게 말한다.
   「먼저 멤버를 제거해 주세요」. 그래서 좌석 해제가 «먼저»다
⛔ 「사용하지 않은 기간에 대한 일할 계산 크레딧」은 좌석을 «늘릴 때»만이다.
   줄일 때는 「감소는 청구 기간 종료 시 적용됩니다」 — 이번 달 $192.50 은 그대로다
⛔ 확정 단추가 «체크상자에 잠겨» 있었다. 안 켜고 누르면 아무 일도 안 일어나는데
   코드는 「눌렀다: true」로 센다. 누른 뒤 «화면의 수»가 바뀌었는지로 판정한다
```
