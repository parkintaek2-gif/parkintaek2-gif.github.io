## 0. 잣대는 어디서 왔나 — UAE 가 «된» 까닭

UAE 를 하루 만에 연 까닭은 셋이었다(`docs/UAE-데이터-출처-라이선스.md`).

```
1. 공시·재무제표가 «무료·법정 공개»다 — 투자자 보호용이라 거래소가 막지 않는다
2. «영문»이 있다 — 번역이 아니라 원문 병기
3. 열쇠·로그인 없이 «열려» 있다 — curl 로 바로 온다
```

⛔ 「시가총액이 크다」·「성장률이 높다」로 고르지 않는다. 그건 우리가 파는 것과 상관없다.
✅ **우리가 파는 것은 공시와 재무다. 그러니 「그 나라 공시가 열려 있나」가 유일한 첫 관문이다.**


## Ⅴ. 🔴 [사장님 정정] 「영어 금융데이터가 약한 곳」은 **가산점이지 관문이 아니다**

> 사장님 (2026-09-14): **「+금융데이터 영어 서비스가 약한 곳이었지. 근데 이거는 그러면 좋은
>  거고, 안 그러면 안 좋지만 그래도 해야지라고 받아들이자」**

UAE 를 고른 까닭 중에 「영문 금융데이터 업체가 약하다」가 있었다. 그래서 나는 그것을
**고르는 잣대**로 써 왔다. 사장님이 그 자리를 낮춰 주셨다.

```
⛔ 관문이 아니다   「경쟁자가 있으니 이 나라는 빼자」로 쓰지 않는다
✅ 가산점이다      비어 있으면 더 좋고, 차 있어도 «그래도 한다»
```

⭐ 까닭은 앞선 지시와 같은 줄기다 — **「경쟁사가 많든 적든 주요 아시아시장을 다 해」.**
  목적지가 «아시아 전부»이면, 경쟁 유무는 **순서**만 정할 뿐 **명단**을 줄이지 못한다.

### 그래서 위 Ⅲ 의 순서를 이렇게 읽는다

```
1순위 인도      경쟁이 «많다». 그래도 한다 — 살 사람이 가장 많으니까
2순위 대만      경쟁 중간. 자료가 가장 깨끗하다
3순위 필리핀    경쟁이 «적다» → 가산점. 게다가 가장 싸다
4순위 사우디    경쟁 적음 + 걸프 규격 재활용
보류  인도네시아·태국·말레이시아   ← 경쟁 때문이 아니라 «문이 막혀서»다
```

⚠ 보류의 까닭을 헷갈리지 않는다. **경쟁이 세서 미루는 나라는 하나도 없다.**
  미루는 것은 «문을 아직 못 연 곳»과 «못 잰 곳»뿐이다.

### 그리고 우리가 «경쟁자가 있어도» 다르게 낼 수 있는 것

경쟁이 차 있는 나라에서도 우리 축은 남들이 안 낸다 —

```
공시를 «무게»로 매긴다        미국 8-K 중대사건 기준. 1,992건 홍보와 75건 CEO 교체를 가른다
지배권·CEO 변경을 «태그»로    사장님: 「회사 주인이 바뀌거나 CEO/회장이 바뀌는 경우」
한 규격으로 여러 나라를        Same schema, same licence, same price
못 잰 것을 «못 쟀다»고 적는다   0 으로 안 채운다 — 큰 벤더가 가장 안 하는 일이다
```

⇒ **나라를 고를 때 「비었나」를 묻지 말고, 들어가서 「무엇을 다르게 낼까」를 정한다.**

## Ⅵ. 🔴 [사장님 지시로 재확인] 재무제표가 «수치»로 오나 — 확인했다

> 사장님: **「재무가 PDF면 UAE처럼 읽개를 또 만들어야 한다 >>> 확인해보면 되잖아」**

맞는 말씀이다. 「PDF 일 수 있다」로 적어 두고 넘어갔는데, 두드려 보면 되는 것이었다.
확인했고 **판정이 바뀌었다.**

### 6-1. 🥇🥇 인도 — **XBRL 로 완전한 수치가 온다. PDF 읽개가 필요 없다**

```
1단계  종목별 재무결과 목록      /api/corporates-financial-results?…&symbol=<종목>
       ⚠ 전체 목록으로 부르면 xbrl 주소가 «잘려서» 온다. 종목별로 불러야 온전하다
2단계  그 줄의 xbrl 주소를 연다   nsearchives.nseindia.com/corporate/xbrl/INDAS_….xml
3단계  수치가 태그로 들어 있다
```

실제로 받아 본 값(V.S.T Tillers Tractors, 19,935바이트) —

```
in-bse-fin:RevenueFromOperations                      2,191,000,000.00
in-bse-fin:OtherIncome                                  -88,500,000.00
in-bse-fin:Income                                     2,102,500,000.00
in-bse-fin:CostOfMaterialsConsumed                    1,478,800,000.00
in-bse-fin:EmployeeBenefitExpense                       254,200,000.00
in-bse-fin:FinanceCosts                                   4,800,000.00
in-bse-fin:DepreciationDepletionAndAmortisationExpense    63,800,000.00
```

⭐ **이건 UAE 보다 좋다.** UAE 는 PDF 를 읽어야 했는데 인도는 «표준 XBRL 태그»로 온다.
  태그 이름이 영문이라 우리 사전 작업도 거의 없다. 분기 목록만 3,816건이다.

⚠ 다만 «재무 XBRL» 이지 «공시 본문» 은 아니다. 공시는 따로 JSON 으로 온다(앞서 확인).

### 6-2. 대만 — 수치로 온다 (이미 확인)

```
營業收入 71,289,957 · 營業成本 58,298,233 … 1,048건이 바로 숫자다
⚠ 칸 이름이 한자라 사전이 필요하다 — 그러나 한국 DART 계정과목에서 이미 해 본 일이다
```

### 6-3. 필리핀 — **재무가 «수치»로 안 온다. 여기가 가장 손이 많이 간다**

```
공시 목록은 열린다     EDGE · 282개사 · 영어
그런데 재무제표는       공시 «첨부 문서» 안에 있다. 목록에 숫자 칸이 없다
⇒ UAE 와 같은 꼴 — 문서를 열어 읽어야 한다
```

⛔ **앞서 「필리핀이 가장 싸다」고 적은 것을 취소한다.** 영어라 사전은 안 드는데,
  재무를 꺼내는 일이 UAE 만큼 든다. 싼 것은 «공시»까지이고 «재무»는 아니다.

### 6-4. 그래서 순서를 고친다

```
0순위  중국 + 홍콩   사장님이 정하신 것. UAE 가 차면 바로
1순위  인도          수요가 가장 크고 + 재무가 XBRL 로 온다. 두 가지가 겹친 유일한 나라
2순위  대만          재무가 수치. 한자 사전만 붙이면 된다
3순위  사우디        걸프 규격 재활용 (UAE 수집기를 거의 그대로)
4순위  필리핀        공시는 싸고 재무는 비싸다. 뒤로 민다
보류   인도네시아·태국·말레이시아   문이 막혀 있다(403)
못 쟀음 베트남·카타르·파키스탄·카자흐스탄·스리랑카   주소를 못 찾았다
```

⭐ **인도가 1순위인 까닭이 두 개가 됐다** — 「살 사람이 가장 많다」에 「자료가 가장 깨끗하다」가
  붙었다. 앞서는 이 둘이 다른 나라에 갈려 있었는데(수요=인도, 자료=대만), 재 보니 한 나라였다.

⚠ **여전히 안 한 것** — 라이선스를 한 나라도 안 읽었다. 문이 열린 것과 써도 되는 것은 다르다.

⭐ **일본 EDINET 은 한국 DART 와 «같은 자리»다** — 금융청이 운영하는 법정 공시 시스템이고
  공개 API 가 있다. 오늘은 건수 0 이 왔는데 날짜·구분값을 잘못 준 탓으로 보인다. 다시 잰다.
⭐ **홍콩은 상장사 목록이 xlsx 로 그냥 떨어진다.** 중국 자료의 «공식 경로»이기도 하다.
⚠ 싱가포르는 공시 갈래가 막혔다(403). 종목은 열린다 — 다른 문이 있을 것이다.
