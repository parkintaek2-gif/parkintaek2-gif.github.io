## 0. 잣대는 어디서 왔나 — UAE 가 «된» 까닭

UAE 를 하루 만에 연 까닭은 셋이었다(`docs/UAE-데이터-출처-라이선스.md`).

```
1. 공시·재무제표가 «무료·법정 공개»다 — 투자자 보호용이라 거래소가 막지 않는다
2. «영문»이 있다 — 번역이 아니라 원문 병기
3. 열쇠·로그인 없이 «열려» 있다 — curl 로 바로 온다
```

⛔ 「시가총액이 크다」·「성장률이 높다」로 고르지 않는다. 그건 우리가 파는 것과 상관없다.
✅ **우리가 파는 것은 공시와 재무다. 그러니 「그 나라 공시가 열려 있나」가 유일한 첫 관문이다.**

## Ⅱ. 열린 곳 넷을 한 겹 더 파봤다

### 2-1. 🥇 대만 (TWSE) — **구조가 한국과 가장 닮았다**

```
✅ OpenAPI 가 «있다»           swagger.json 이 공개다. 한국 공공데이터포털과 같은 자리
✅ 재무제표가 «수치»로 온다     손익 1,048건 — 영업수익·영업비용이 숫자로 바로
✅ 상장사 기본정보 1,094건      업종·주소·설립일
⚠ 칸 이름이 «한자»다           出表日期 · 公司代號 · 營業收入 … 영문 0~12%
```

⭐ **그런데 이 한자 칸이 우리에겐 장애물이 아니다.** 우리는 이미 한국 DART 계정과목을
  손으로 영문에 맞춘 사전을 갖고 있다(`/v1/account-dictionary`). **같은 문제를 이미 한 번 풀었다.**
  營業收入 → Revenue, 營業成本 → Cost of sales 는 그 사전을 넓히는 일이다.

⚠ 다만 대만은 엄밀히는 신흥국이라기보다 «선진에 가까운 신흥»이다(MSCI 신흥지수에는 든다).
  사장님이 물으신 「신흥개발국」의 한가운데는 아니다.

### 2-2. 🥇 인도 (NSE) — **수요가 가장 크다**

```
✅ 공시 갈래가 JSON 으로 열린다   corporate-announcements · PDF 첨부 주소까지
✅ 영문이 원문이다               인도는 공시를 영어로 낸다
✅ 지수 목록도 열린다            allIndices 114 KB
```

### 왜 인도가 대만보다 앞인가 — 「유용성」으로 갈랐다

> 사장님: 「나라 숫자가 중요한 게 아니라, 얼마나 유용성 있냐가 핵심이다」

```
대만이 나은 점    자료가 더 깨끗하다 (재무가 수치로 온다)
인도가 나은 점    «살 사람이 많다». 우리 영업 명단이 전부 인도를 든다
⇒ 자료의 질보다 «그 자료를 살 사람이 있나»가 먼저다. 그래서 인도가 앞이다
```

## Ⅴ. 🔴 [사장님 정정] 「영어 금융데이터가 약한 곳」은 **가산점이지 관문이 아니다**

> 사장님 (2026-09-14): **「+금융데이터 영어 서비스가 약한 곳이었지. 근데 이거는 그러면 좋은
>  거고, 안 그러면 안 좋지만 그래도 해야지라고 받아들이자」**

UAE 를 고른 까닭 중에 「영문 금융데이터 업체가 약하다」가 있었다. 그래서 나는 그것을
**고르는 잣대**로 써 왔다. 사장님이 그 자리를 낮춰 주셨다.

```
⛔ 관문이 아니다   「경쟁자가 있으니 이 나라는 빼자」로 쓰지 않는다
✅ 가산점이다      비어 있으면 더 좋고, 차 있어도 «그래도 한다»
```

⭐ 까닭은 앞선 지시와 같은 줄기다 — **「경쟁사가 많든 적든 주요 아시아시장을 다 해」.**
  목적지가 «아시아 전부»이면, 경쟁 유무는 **순서**만 정할 뿐 **명단**을 줄이지 못한다.

### 그래서 위 Ⅲ 의 순서를 이렇게 읽는다

```
1순위 인도      경쟁이 «많다». 그래도 한다 — 살 사람이 가장 많으니까
2순위 대만      경쟁 중간. 자료가 가장 깨끗하다
3순위 필리핀    경쟁이 «적다» → 가산점. 게다가 가장 싸다
4순위 사우디    경쟁 적음 + 걸프 규격 재활용
보류  인도네시아·태국·말레이시아   ← 경쟁 때문이 아니라 «문이 막혀서»다
```

⚠ 보류의 까닭을 헷갈리지 않는다. **경쟁이 세서 미루는 나라는 하나도 없다.**
  미루는 것은 «문을 아직 못 연 곳»과 «못 잰 곳»뿐이다.

### 그리고 우리가 «경쟁자가 있어도» 다르게 낼 수 있는 것

경쟁이 차 있는 나라에서도 우리 축은 남들이 안 낸다 —

```
공시를 «무게»로 매긴다        미국 8-K 중대사건 기준. 1,992건 홍보와 75건 CEO 교체를 가른다
지배권·CEO 변경을 «태그»로    사장님: 「회사 주인이 바뀌거나 CEO/회장이 바뀌는 경우」
한 규격으로 여러 나라를        Same schema, same licence, same price
못 잰 것을 «못 쟀다»고 적는다   0 으로 안 채운다 — 큰 벤더가 가장 안 하는 일이다
```

⇒ **나라를 고를 때 「비었나」를 묻지 말고, 들어가서 「무엇을 다르게 낼까」를 정한다.**
