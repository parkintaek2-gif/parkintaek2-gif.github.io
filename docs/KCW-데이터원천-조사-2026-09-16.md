```

✅ 정확히 잡힌 것(성공한 응답 중)  BTS(KR)·Blackpink(KR)·Jung Kook(KR)·Jimin(KR, BTS)·

     "Special Purpose Artist – Do not add releases here" 특수 엔티티)로 잘못 매칭
     → `artist:V AND country:KR` 로 한정하면 BTS 의 V(disambiguation="BTS")가 정확히 잡힌다
   · "Cha Eun-woo" 를 그대로 검색 → 전혀 다른 사람("Baek Eun Woo")이 score100 으로 잡혔다
     — 로마자 표기가 비슷한 다른 실존 인물에 오매칭된 사례. country:KR 을 더해도
     이 경우는 이름 자체가 다른 사람과 겹쳐 추가 검증(생년·소속그룹 대조)이 필요하다

판정      ✅ 에서 🟡 로 내린다 — 라이선스는 여전히 깨끗하지만, ①재시도 로직 없이는
          절반이 실패하고 ②이름만으로 조회하면 오매칭이 실제로 난다(추정이 아니라
          이번 표본에서 관측). 수집기를 만든다면 country:KR 한정 + 생년/소속 교차검증 +
          "못 쟀다" 처리(빈 결과·오류를 0 이나 임의값으로 채우지 않는다)가 반드시 같이 간다
```
