# 광고·콘텐츠 판매·협찬 정책

작성 2026-08-02 KST · 사장님 결정

> 「증권사가 광고를 하거나 콘텐트를 사거나 협찬을 하거나 할 거야.
> **광고와 콘텐트(데이터 포함) 구매는 ok, 협찬은 no**」

---

## 0. 세 가지가 왜 다른가

| | 무엇을 사는가 | 편집과의 관계 | 판정 |
|---|---|---|---|
| **광고** | 지면 | 무엇을 쓸지와 **무관** | **받는다** |
| **콘텐츠·데이터 구매** | 우리가 이미 만든 것 | **거래가 끝난 뒤에도 자유** | **받는다** |
| **협찬** | 노출과 호의 | **거래가 곧 편집 조건** | **받지 않는다** |

앞의 둘은 **돈을 받고 나서도 그 회사에 불리한 기사를 쓸 수 있다.**
협찬은 그게 안 된다 — 「○○의 후원으로 제작」이라 적는 순간 그 기사에서 우리 판단이 사라진다.

**우리가 파는 것은 「아무것도 안 파는 사람의 판단」이다.** 협찬은 그 자산을 직접 판다.

---

## 1. ⚠ 진짜 문제 — 광고주의 적중률을 우리가 매긴다

증권사가 광고주가 되고, 우리는 그 증권사 애널리스트의 목표주가 적중률을 계산한다.
**이건 명백한 이해상충이고, 「안 봐줍니다」라는 말로는 부족하다.**

### 그래서 사람을 빼고 규칙만 남긴다

지수 사업과 같은 구조다.

```
적중률 산출   공개된 규칙이 기계적으로 계산한다
              같은 데이터 → 같은 결과. 누구든 재현할 수 있다
사람의 개입   산출 경로에 없다. 광고주라고 바뀔 자리가 없다
```

**「안 봐준다」가 약속이 아니라 구조가 되어야 한다.** 손으로 고칠 수 있으면
안 고쳐도 의심받고, 못 고치면 안 고쳤다는 걸 증명할 필요가 없다.

### 그 위에 네 가지를 더 건다

**① 산출 규칙을 먼저 공개하고 나중에 계산한다.**
결과를 보고 규칙을 바꾸면 그건 규칙이 아니다. 규칙 변경 이력도 남긴다.

**② 광고주 목록을 공개한다.**
독자가 「이 순위에 광고주가 있나」를 스스로 확인할 수 있어야 한다.

**③ 광고주가 등장하는 기사에 그 사실을 표시한다.**
숨기지 않는다. 「○○증권은 본 매체의 광고주입니다」 한 줄이면 된다.

**④ 광고 판매와 산출 규칙을 같은 날 만지지 않는다.**
1인 회사라 사람을 못 가른다. 대신 **시점을 가른다** — 규칙은 분기 초에만 손대고,
그 사이에는 광고 협의를 하더라도 규칙이 이미 굳어 있다.

## 2. 광고 — 받는다. 조건이 있다

| | |
|---|---|
| 표시 | **모든 광고는 광고임을 표시한다.** 기사처럼 보이는 형태를 쓰지 않는다 |
| 위치 | 본문과 시각적으로 분리한다 |
| 심사 | 투자 권유·수익 보장·개인 대출 광고는 받지 않는다 |
| 광고주 목록 | 공개한다 |
| 기사와의 관계 | **광고주도 기사 대상이 된다.** 그게 정상이다 |

### 받지 않는 광고

```
✗  「원금 보장」 · 「수익률 ○○% 보장」류
✗  무등록 투자자문 · 리딩방
✗  기사와 구분이 안 되는 네이티브 형식
✗  특정 종목 매수를 권하는 것
```

**우리는 투자자문이 아니고, 그렇게 보이는 광고를 옆에 두면 독자가 구분하지 못한다.**

---

## 3. 콘텐츠·데이터 판매 — 받는다

우리가 만든 것을 파는 것이다. **판 뒤에도 우리 편집은 그대로다.**

| 파는 것 | 사는 쪽 |
|---|---|
| 적중률 데이터·지수 | 자산운용사 · 헤지펀드 · 핀테크 |
| 기사 신디케이션 | 미디어 |
| API | 개발자 · 리서치 데스크 |

### 다만 못 박는다

**「우리가 판 데이터로 상대가 무엇을 하든, 우리 기사는 그것과 무관하다.」**
데이터를 산 회사가 그 데이터를 자기 마케팅에 쓰는 것은 자유다.
**우리가 그 마케팅을 기사로 거들지는 않는다.**

---

## 4. 협찬 — 받지 않는다

```
✗  「○○의 후원으로 제작」
✗  협찬사가 기사 주제·시점·논조에 관여하는 모든 형태
✗  대가를 받고 특정 기업·상품을 다루는 기획
```

**받지 않는 이유는 윤리가 아니라 사업이다.**
이 매체가 파는 것이 「아무것도 안 파는 사람의 판단」인데,
협찬은 그 판단을 직접 판다. **한 번 팔면 그 다음부터는 팔 것이 없다.**

### 협찬처럼 보이는 것도 안 한다

- 기업이 비용을 대는 「공동 기획」
- 취재비를 취재 대상이 부담하는 출장
- 대가를 받는 이벤트·세미나 공동 주최

---

## 5. 훈장은 주되 채찍은 쓰지 않는다

적중률 공개는 **상위만 이름을 낸다.** 하위는 순위를 밝히지 않는다.
전체 데이터는 우리가 보관하고, 판매 상품으로 쓴다.

### ⚠ 절대 하지 않는 것

**협조 여부에 따라 보도를 달리하지 않는다.**
광고를 안 사서, 데이터를 안 사서, 파트너십을 거절해서 —
**그 이유로 그 회사의 실패 사례를 모아 보도하지 않는다.**

한국에서 이 형태는 검찰이 실제로 기소해 온 유형이고,
무엇보다 **우리가 팔려는 것을 부순다.** 협조 여부로 기사가 달라지면
독자가 우리 기사를 믿을 이유가 없어진다.

### 다만 취재 거부는 다르다

「질의에 답하지 않았다」는 사실이고, 그건 기사에 적는다.
**답을 안 했다고 기사를 빼는 것이 오히려 이상하다.**
이건 상업적 협조와 무관한, 언론이 매일 하는 일이다.

### 회사명을 내는 기준을 미리 정해 둔다

나중에 「저 회사만 골라 팼다」는 말이 안 나오게, **발행 전에 기준을 공개한다.**

```
회사명을 낸다     상위 성적 · 업계 전체를 다루며 예시가 필요할 때 ·
                  공적 사안(제재·소송 등)
회사명을 안 낸다   하위 순위 · 개별 실패 사례
```
