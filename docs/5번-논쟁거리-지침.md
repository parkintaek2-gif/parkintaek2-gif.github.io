# 5번(K Culture Wire) 「순위 + 문제제기 + 논쟁」 지침

> 사장님 지시 원문. 이 시리즈를 만들 때마다 **먼저 다시 읽는다.**
> ⚠ 3번이 먼저 받아 적은 `docs/3번-순위콘텐트-지침.md` 와 «같은 지시»다. 거기 여덟 줄을 같이 읽는다.

## 원문 (그대로)

1. 「**논쟁꺼리를 우리가 만든다.** 거기에 댓글을 붙일 수 있는 기능을 2번이 만들기 시작했다」 *(→ 5번에게, 8/31)*
2. 「사람들이 관심이 많은 모든 것에 대해 순위를 매겨...**그 순위가 의미가 있는 지 생각해보게 해**」
3. 「내가 예시를 든 것만 찾지마...**너도 사람들이 뭘 궁금해 하는 지 찾아**」
4. 「콘텐트 제목도 사람들의 이목을 끌어 클릭할 수 있게 만들어, **그래프도 만들고**, 그 안에서 우리가 하고 싶은 얘기를 해, **데이터로**...댓글을 달 수 있게 해」
5. 「성격이 달라...결국 **부자가 되자고 얘기하는 게 아니잖아**」 — 동경·선망 조장 금지

## 규칙

| 항목 | 규칙 |
|---|---|
| 순위 출처 | **이미 공개된 3자 순위**를 인용하거나, **우리가 «센» 것**을 쓴다. ⛔ 사람·기관을 우리가 «평가»해 순위를 만들지 않는다 |
| 문제제기 | 순위를 사실로 보여 준 뒤, **「무엇을 재느냐에 따라 순서가 바뀐다」**를 우리 실측으로 보인다 |
| 톤 | ⛔ 「이게 진짜 1위다」로 바꿔치기하지 않는다. **둘 다 놓고 손님이 정하게 한다** — 우리는 바늘을 안 세운다 |
| 제목 | 클릭하고 싶게. ⭐ **스타 이름·작품명을 제목에 넣는다**(사장님: 「스타 이름이 이렇게 제목에 나와야해」) |
| 그래프 | 필수. **인라인 SVG**만 — 새 JS 라이브러리를 안 쓴다(사이트 관행) |
| 댓글 | **2번이 만들었다(2026-08-31).** 세 줄로 붙인다 — ⛔ 3자 추적 위젯은 안 쓴다<br>`<script src="/comments-widget.js" defer></script>` + `<div data-comments-page="<이 지면 주소>"></div>`<br>⚠ `data-comments-page` 가 그 지면 주소와 «같아야» 한다. 다르면 남의 방에 글이 쌓인다 |
| 논쟁 물음 | 지면 끝에 **답이 갈릴 물음 하나**를 둔다. ⛔ 우리가 답을 정해 두지 않는다 |

## K Culture Wire 가 쓸 수 있는 순위

```
✅ 넷플릭스 «시청시간» 세계 톱10       넷플릭스가 «직접 공개»한다. 우리가 원자료를 쥐고 있다
✅ 우리가 센 것 — 나라 수 · 주 수     같은 작품을 다른 자로 잰 것
✅ 동남아 위키백과 열람               사람·그룹을 «몇 명이 열어 봤나»
⚠ 브랜드평판·미남순위 같은 3자 순위    인용은 되지만 «원문을 실제로 봐야» 쓴다. ⛔ 내용을 지어내지 않는다
```
