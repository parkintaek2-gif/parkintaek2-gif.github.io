## Ⅲ. 공공데이터포털 (data.go.kr)

⭐ 이 포털은 데이터셋마다 키를 주지 않는다. **계정에 키가 하나**고, 승인된 데이터셋의
엔드포인트가 그 키로 열린다. 그래서 **API 를 직접 찔러 승인 여부를 안다.** 로그인이 필요 없다.

⚠ `.env` 의 `DATAGO_KEY`(100자)는 **이미 URL 인코딩된 값**이다.
`encodeURIComponent` 를 한 번 더 걸면 403 이고, 승인됐는데도 「미승인」으로 읽힌다.

### 3-1. ✅ 승인 · 실제로 열리는 것

| 데이터 | 축 | 신고 건수 | 오퍼레이션 |
|---|---|---|---|
| KRX상장종목정보 | 기준정보 | 4,142,074 | `GetKrxListedInfoService/getItemInfo` |
| 주식시세정보 | Equities | 4,365,916 | `GetStockSecuritiesInfoService/getStockPriceInfo` |
| 지수시세정보 | Equities | 249,297 | `GetMarketIndexInfoService/getStockMarketIndex` |
| 증권상품시세정보 | ETF·ETN·ELW | 1,167,940 | `GetSecuritiesProductInfoService/getETFPriceInfo` |
| ⭐ **채권시세정보** | **Rates** | **555,999** | `GetBondSecuritiesInfoService/`**`getBondPriceInfo`** |

| 공시정보 | 실시간 | — | 당일 발행의 유일한 경로 |

### 3-2. ⭐ 채권이 열렸다 — 2026-08-04

```
npm run collect:bonds                      어제치
npm run collect:bonds -- --from A --to B   기간
```
첫 수집 — 2026-07-27~31 **1,870건 · 수익률 100% 확보.**
필드에 `clprBnfRt`(종가 수익률)가 있어 **Rates 축이 그대로 선다.**

### 3-3. ⚠ `NO_OPENAPI_SERVICE_ERROR` 를 잘못 읽고 있었다

**2026-08-04 에 바로잡았다. 몇 주치 보고가 틀려 있었다.**

```
NO_OPENAPI_SERVICE_ERROR  =  그 경로에 서비스가 없다  ≠  미승인
```

채권시세를 계속 「대기」로 보고했는데 **실은 승인돼 있었다.**
서비스 주소는 맞았고 **오퍼레이션 이름을 내가 지어냈다.**
`getBondBasiInfo`(내가 지음·틀림) → `getBondPriceInfo`(실제·맞음)

**승인 판정 코드가 이 둘을 섞으면 안 된다.**

### 3-4. ⬜ 아직 못 연 것 — 미승인인지 경로 문제인지 모른다
