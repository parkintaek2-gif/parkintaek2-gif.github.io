## 1. 공공데이터포털 (data.go.kr) — 계정당 인증키 **하나**

⭐ **중요** — 이 포털은 데이터셋마다 키를 주지 않는다. **계정에 키가 하나**고,
승인된 데이터셋의 엔드포인트가 그 키로 열린다. 그래서 **승인 여부는 API 를 직접
찔러 보면 알 수 있다.** 웹사이트 로그인 없이 매일 자동 확인이 된다.

`.env` 의 `DATAGO_KEY` (100자). ⚠ **이미 URL 인코딩된 값**이다 —
`encodeURIComponent` 를 한 번 더 걸면 403 이다. 실제로 그래서 한 번 막혔다.
