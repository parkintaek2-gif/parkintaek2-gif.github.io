### 5-1. 🔴 「영문명 86.1% · 미커버 2,190」은 **옛 숫자다**

자동 이어가기 지시서에 「지금 가장 큰 병목」으로 적혀 있어 최우선으로 돌렸다. **이미 풀려 있었다.**

```
corpCode.xml 새로 받음   3.4MB → raw/dart-corpcode/2026-08-06T00-14-16.zip
현재 커버               **98.0%** (64,780 / 66,105)   ← 지시서의 86.1% 가 아니다
DART 로 추가            **0종목 · 0건**               ← 더 채울 것이 없다
끝내 못 찾음             374종목 · 1,325건
```

**남은 374종목은 DART 에 없는 것이 정상이다** — 사명 변경·합병·상장폐지된 이름들이다.

```
롯데제과 → 롯데웰푸드      SK C&C → SK주식회사      아주캐피탈 → 우리금융캐피탈
SK브로드밴드(합병)         테스나 → 두산테스나        지니뮤직 · 가온미디어 …
```

`corpCode.xml` 은 **현재 법인명만** 담는다. 옛 이름으로는 영원히 안 붙는다.
더 올리려면 **상장폐지·사명변경 이력**이 따로 필요하다. **98%에서 멈추는 것이 맞다.**

⚠ **지시서의 숫자를 믿고 시작하지 말고, 돌려서 지금 값을 먼저 본다.**
   안 그러면 이미 끝난 일을 「가장 큰 병목」으로 알고 시간을 쓴다.
