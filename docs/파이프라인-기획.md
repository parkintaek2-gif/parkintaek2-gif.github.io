## A. 이직·연봉·회사 — **1순위. 자료가 이미 있습니다**

```
왜 1순위   8번이 만든 것이 **바로 이것**입니다 —
           업종 × 시도 1,491칸 · 학과 837개 × 취업의 속 · 회사 축(6번)
           ⛔ 새로 모을 것이 없습니다. **지면만 만들면 됩니다**
누가 오나   20~40대. **KLifeMap 의 주 고객과 같은 사람**입니다
어떻게 보내나 「이 업종 사람들은 이렇게 산다」 → 「그럼 나는?」 → KLifeMap
딱지        ?from=smk&at=job  ·  ?from=100y&at=major
```
⭐ **이 사람이 KLifeMap 에서 사는 것** — 사주(직업운·이직 시기)·택일(이직일)

# 8/15 개봉 뒤 순서 — **한 번에 하나만 켭니다**

| 주 | 켤 것 | 확인 |
|---|---|---|
| 8/15~ | **개봉 + 첫 결제 1건** | 관문 ①② |
| 8/22~ | **A 이직·연봉** — 자료가 있으니 지면만 | 딱지 `at=job` 으로 온 사람 수 |
| 보류 | **B 스포츠** — ⛔ **Riot Production(App 866800) 승인 뒤**에 켠다 | 승인 전에는 수집·지면·광고 다 안 함 |
| 9월 | **C 건강** — 자료를 새로 받아야 함 | 딱지 `at=health` |
| 상시 | **D 진학** — 이미 서 있음. 손 안 댐 | 딱지 `at=major` |

⛔ **한 번에 하나만 켭니다.** 넷을 같이 켜면 **어느 문이 좋은 문인지 영영 모릅니다.**
⭐ 문 하나를 켜고 **일주일 재고**, 그다음 문을 켭니다.

# 재는 법 — ⛔ 이것이 없으면 기획이 아니라 소망입니다

```
한 주에 한 번, /admin JSON 의 「딱지별」에서
   at=job · at=sports · at=health · at=major 마다
   ① 몇 명이 왔나
   ② 그중 몇 명이 KLifeMap 에서 두 번째 지면까지 갔나
   ③ 그중 몇 명이 돈을 냈나
```
⭐ ③이 나오는 문이 **캐시카우로 가는 문**입니다. 나머지는 접습니다.
⛔ 「많이 왔다」로 판단하지 않습니다. **돈을 낸 사람 수**로 판단합니다.
