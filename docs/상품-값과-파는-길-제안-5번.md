# 서울마켓츠 — 무엇을 얼마에, 누구에게, 어떻게 파나 (5번 제안)

> 🔴 **왜 지금 이 문서인가** — 사장님 말씀 (2026-09-11, 원문)
>
> 「내가 원고 일부승소로 **2,000만원+상대방 소송비용+내 소송비용을 손해**보고 바로 지출처가 생겼다.
>  그래서 너희들에게 당부한다. **빨리 우리가 돈을 벌자** … 인간은 돈벌이로부터 해방되는 꿈을 꾼다.
>  나도 이 일을 돈벌이로부터 해방되는 꿈을 이루고, 이 일을 신나게 하고 싶다. **우리 할 수 있지?**」
>
> 사장님 권한 지시: 「**가격과 상품구성도 유닛끼리 협의해서 정한다**」 —
> 승인이 필요한 것은 입금·출금·결제·결제취소·환불 다섯뿐이다. **값 정하기는 우리 몫이다.**

---

## Ⅰ. 지금 무엇이 잘못돼 있나 — 재서 적는다

### 1-1. 🔴 「Data for licence」라는 제목을 달고 값이 하나도 없다

`seoulmarkets.com/data` 를 열어 세었다.

```
지면 제목        Data for licence   ← 「빌려주는 자료」라는 뜻이다
그런데 모든 줄이  Free page · Free page · Free page …
licence fee      0줄
quote            0줄
sales            0줄
「얼마」          0줄
```

**물건은 진열해 놓고 값표도 계산대도 없다.** 사려는 사람이 와도 살 방법이 없다.

⭐ 이것은 KLifeMap 결제창과 **같은 병**이다 — 같은 날 나는 결제 33건이 멈춘 자리도 찾았는데,
그 화면에도 「무엇을 얼마에」가 없었다. 우리는 **만드는 것은 잘하는데 파는 길을 안 낸다.**

### 1-2. 그런데 팔 물건은 이미 있다

```
표본 파일 16개 (CSV + Parquet) — 6번이 오늘 Parquet 까지 붙였다
People Panel        2,924개사 — 근속·급여·성별·임원
Ownership Ledger    지분 신고 · 임원주주
Mezzanine Book      메자닌
Consensus Tape      목표주가 이력 (⚠ 30일 창이라 우리만 쌓고 있다)
Company Master      회사 대장
Trade              243개국 × 12개월
```

## Ⅱ. 값 — 우리가 이미 조사한 경쟁사 값 위에서 정한다

`korea-trade-dataset.astro` 에 우리가 직접 열어 적어 둔 값이 있다(2026-08-21 실측).

| 파는 곳 | 값 | 무엇을 주나 |
|---|---|---|
| data.go.kr / KOSIS | 무료 | 한국어, 정규화 안 됨, 한 번에 한 질의 |
| Trading Economics — 웹 | $29–199 / 월 | 플랫폼 전체 구독, 이 자료 아님 |
| Trading Economics — API | $149–299 / 월 | 구독, 연 단위 청구 |
| Statista | $199+ / 월 (연 청구) | 단건 없음, 구독만 |
| Nasdaq Data Link premium | 영업 문의 | 값 공개 안 함 |

### 2-1. ⭐ 우리 자리는 「구독」이 아니라 「단건」이다

위 표에서 **비어 있는 칸이 보인다** — 아무도 «한 벌만 사고 끝내는 길»을 안 준다.
Statista 는 「단건 없음, 구독만」이고 Nasdaq 은 값을 안 밝힌다.

```
⛔ 우리가 월 구독으로 가면 Trading Economics·Statista 와 정면으로 붙는다. 못 이긴다
✅ 우리가 이길 자리는 «한 벌 사서 내 손에 두는 것» — 연구자·헤드헌터·노무법인이 원하는 꼴이다
```

### 2-2. 제안하는 값

| 상품 | 무엇 | 값(제안) | 까닭 |
|---|---|---|---|
| **한 벌** (single file) | 한 자료의 전량 CSV+Parquet, 그 판 하나 | **₩390,000** | Statista 월 $199 ≒ ₩27만의 1.5배. 한 번 내고 끝이라 그만큼 값이 선다 |
| **한 벌 + 갱신 1년** | 같은 자료를 1년 동안 판이 바뀔 때마다 | **₩1,200,000** | 월로 나누면 ₩10만. 구독 경쟁사의 3분의 1 |
| **모두 묶음** (all-access) | 위 여섯 자료 전부 + 1년 갱신 | **₩3,600,000** | 낱개 여섯 × 120만 = 720만 → 반값 |
| **연구·학생** | 한 벌, 논문·학위 용도 | **₩90,000** | 우리 강령의 「나침반」 쪽. 이름을 실어 준다 |

⚠ 이 값은 **제안**이다. 6번·2번이 다르게 보면 그 근거로 고친다 — 사장님께 여쭙지 않는다.

### 2-3. ⛔ 값을 정할 때 지킨 것

```
⛔ 「비싸게 불러 보고 깎아 준다」를 안 한다 — 값표를 지면에 «적는다». 물어봐야 아는 값은 우리 것이 아니다
   (Nasdaq 이 「Contact sales」인 것이 그들 방식이고, 우리는 그 반대로 간다)
⛔ 무료 지면을 가리지 않는다 — 사장님 지시다. 지면과 표본은 계속 무료다
✅ 파는 것은 «전량 파일»이다. 무료 지면은 그 파일로 가는 깔때기다
```

## Ⅲ. 누가 사나 — 짐작 말고 「그 자료가 없으면 곤란한 사람」으로 좁힌다

| 사는 곳 | 왜 사나 | 어느 자료 |
|---|---|---|
| 헤드헌팅·서치펌 | 어느 회사가 사람을 오래 두나, 급여가 어떤가 | People Panel |
| ESG 평가사·의결권 자문 | 성별 격차·임원 재직기간을 회사 단위로 | People Panel · Ownership Ledger |
| 자산운용·리서치 | 목표주가를 «언제 누가» 바꿨나 | Consensus Tape |
| 노무법인·노동연구 | 근속·급여 분포 | People Panel |
| 대학·연구소 | 논문용 패널 | 전부 (연구값) |

⭐ **블룸버그는 이걸 안 센다.** 오늘 사장님이 주신 기사에서 KB금융이 블룸버그와 MOU 를 맺었는데,
그들이 사는 것은 «시세와 리스크»다. 한국 상장사의 **사람**을 회사 단위로 쥔 곳은 국내에 거의 없다.
⛔ 그렇다고 블룸버그를 좇지 않는다 — 사장님: 「물론 우리가 블룸버그를 추구하는 것은 아니다」.

## Ⅳ. 어떻게 사게 하나 — 오늘 고칠 것 셋

```
1. /data 지면에 «값표»를 낸다
   지금: 모든 줄이 Free page
   바꿔: Free page(지면·표본) / ₩390,000(한 벌) / ₩1,200,000(1년) 이 나란히 보이게
   ⛔ 「문의하세요」로 끝내지 않는다. 값을 적는다

2. 「이렇게 받습니다」를 한 줄로 적는다
   메일 한 통 → 세금계산서 → 계좌 입금 → 파일 전달(R2 링크)
   ⚠ 결제 레일을 새로 만들지 않는다. B2B 는 계좌이체가 정상이고, 그게 제일 빠르다
   ⛔ 입금 확인은 사람이 한다 — 돈이 오가는 것은 사장님 승인 영역이다

3. 파는 자리로 가는 문을 낸다
   지금 /data 에 sales·quote·문의 글자가 0줄이다
   ⇒ 각 무료 지면 밑에 「이 자료의 전량 파일이 필요하십니까」 한 줄 + 메일 주소
```

⚠ 그리고 **`/articles` 404 를 먼저 고쳐야 한다**(기사 132편이 닿을 길이 없다).
사려는 사람이 우리를 믿는 근거가 그 기사들이다.

## Ⅵ. 정직하게 — 이 제안의 약한 곳

```
⬜ 「팔린다」를 아직 못 쟀다. 사겠다는 사람을 한 명도 못 만났다
   ⇒ 그래서 값표를 지면에 «적는 것»이 첫 실험이다. 물어보는 사람 수가 첫 수다
⬜ 경쟁사 값은 2026-08-21 에 잰 것이다. 한 달이 지났다 — 다시 재야 한다
⬜ 세금계산서·사업자 확인 절차를 아직 안 짰다
⚠ 우리 강령: 「재 보고 안 된다고 적는 것도 결과다」. 안 팔리면 안 팔린다고 적는다
```
