# 6번 상품설계 — 「한국 투자자플로우, 읽어서 판다」 (TradePulse보다 낫게)

사장님 지시(2026-08-22): 「이들보다 좋은 상품성, 차별화해 서비스하라.」
⚠ 추정 아님 — 벤치마크한 «그들의 약점»에 근거해 설계한다.

## 벤치마크 — 경쟁사가 파는 것과 «안 파는 것»
| 벤더 | 무엇을 | 값 | 약점(=우리 기회) |
|---|---|---|---|
| TradePulse | 투자자별 «실시간 raw» 주문흐름 | **$10,000/월** | raw만·기업전용·단일피드·해석 없음·블랙박스 |
| Apify KRX scraper | 외국인 flow 등 raw 스크랩 | 사용량제 | 회색 라이선스·raw·영문 정규화 없음 |
| FMP | 글로벌 펀더멘털 | $14~99/월 | 한국 특화 아님·flow 없음 |

**그들의 공통 빈칸: ① raw만 주고 «읽음»을 안 준다 ② 실시간 기업전용이라 롱테일을 버린다 ③ 단일 데이터라 «교차»가 없다 ④ 방법이 불투명하다.**

## 우리 차별화 — 속도가 아니라 «읽음 + 교차 + 투명 + 셀프서브»
속도(실시간)로는 못 이긴다. 그들이 «안 파는 네 가지»로 이긴다.

1. **읽음(read), not raw** — T+1 투자자플로우를 영문 데이터저널리즘으로 «해석»해 낸다. 우리 정체성(가공않은 사실 + 나침반)이 곧 상품.
2. **교차(cross-read) — 우리만 되는 것** — flow를 우리가 이미 쥔 다른 한국 데이터와 겹친다:
   · flow × **애널 목표주가**(DART) = 「외국인이 증권사가 방금 올린 종목을 파는가?」(스마트머니 vs 컨센서스)
   · flow × **지배구조·보수**(DART) = 「기관이 여성임원 많은/오래된 CEO 회사를 사는가?」
   · flow × **무역·수입물가**(관세청·한국은행) = 「반도체값 폭등에 외국인이 반도체주를 어떻게?」
   ⭐ 단일피드 벤더는 이 신호를 **원리상 못 만든다.** flow만 갖고 있기 때문. **이게 해자다.**
3. **투명(reproducible)** — 출처·기준시각·계산식을 매 응답에 박는다. alpha 블랙박스가 넘치는 판에서 «재현 가능·정직»이 차별.
4. **셀프서브 영문 롱테일** — TradePulse는 $10k 기업영업. 우리는 무료 T+1 집계(발견)+저가 API/CSV로 연구자·미디어·리테일퀀트·핀테크를 받는다. 그들이 버린 시장.

## 상품 층위 (벤치마크 앵커 가격)
```
무료   T+1 시장전체 투자자별 순매수 집계 + 영문 기사·차트   ← 발견·SEO·인용
저가   종목별 T+1 flow API/CSV (영문 정규화)                 ← 롱테일 (TradePulse $10k의 1/n)
상품   «교차 신호» API — flow×목표주가×지배구조             ← 우리만 되는 것, 마진 여기서
```
