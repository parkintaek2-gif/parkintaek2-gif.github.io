# 세션 입구 — 백업본

바탕화면 `C:\Users\USER\Desktop\00_세션입구` 의 사본이다. **바탕화면 것이 원본이다.**

## 왜 여기 두나
바탕화면은 저장소가 아니다. 디스크가 날아가거나 폴더를 지우면 여섯 자리의 정의가 통째로 사라진다.
여기 두면 `git` 이 지켜 준다.

## 되살리는 법
```
바탕화면에 00_세션입구 폴더를 만들고 이 폴더의 내용을 그대로 복사한다.
⚠ .cmd 는 **UTF-8 · CRLF** 라야 한다. 다른 인코딩으로 저장하면
   한글 경로(_현재·역할)를 못 읽고, LF 로 저장하면 goto·라벨이 깨진다. 둘 다 겪었다.
```

## 무엇이 들어 있나
```
0_여섯창_한번에.cmd     리부팅 뒤 이것 하나만 누른다
N번_*.cmd               자리별 단추. set CLAUDE_SEAT=N 로 번호를 심는다
역할/N.md               그 자리가 무엇을 하는 자리인지. **자리의 정의다**
_세션ID-찾기.mjs        마지막 수단. 적어 둔 ID 가 없을 때만 쓴다
```

⚠ `_현재\N.id`(창이 스스로 적는 세션 ID)는 백업하지 않는다. 그 PC 에서만 뜻이 있는 값이다.

## 고칠 때
**바탕화면 것을 고치고 여기로 복사한다.** 여기 것만 고치면 실제로 도는 것은 안 바뀐다.
