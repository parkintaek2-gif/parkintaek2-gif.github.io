```
⭐ 새 자료를 받으러 가기 전에 **쥔 자료의 안 쓰던 축**을 찾는다

⭐ 같은 자료로 **기사와 지면을 둘 다** 내면 서로 검산이 된다
```

```
✅ 모든 줄에 사례수 n 을 박는다. 표본이 얇은 칸은 비율만 크게 보인다
✅ 출처 줄을 지면에 둔다. 원자료는 archive/raw/ 에 원문 그대로 남긴다
✅ 라이브 200 까지가 끝이다. 커밋에서 멈추지 않는다 (배포는 2번이 넣는다)
⛔ 평균으로 설명하지 않는다. 분포를 보여 주고 판단은 독자가 한다
⛔ 억(1억)과 billion(10억)을 섞지 않는다. 8/7 에 10배로 나갈 뻔했다
```
