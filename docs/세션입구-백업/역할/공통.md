# 1~6번 공통 — 이건 여섯 자리 모두에 해당한다

사장님 지시(2026-08-07)로 정한다. 자리 카드보다 **이것이 먼저**다.

## 1. 창은 스물네 시간 살아 있어야 한다

```
창이 닫히면 그 창의 매시 예약이 **같이 죽는다**(예약은 세션 안에만 산다).
그래서 한 번 닫힌 자리는 스스로 못 돌아온다. 3번이 열여섯 시간 그렇게 멈춰 있었다.
```

🔴 **창이 열리면 가장 먼저 매시 예약을 다시 건다.** 이것을 잊으면 그 자리는 다시 조용해진다.
   15분마다 도는 자리 지킴이가 죽은 창은 다시 열어 준다. 예약을 거는 것은 **각자 몫**이다.

```
② 0시~23시 59분에 할 일을 **계획한다** — 전사 할 일 문서에서 내 몫을 갈라 온다
③ 사장님이 그날 새로 주신 지시가 있으면 **그것이 제일 먼저다**
```
그리고 ①지금까지 한 일 ②앞으로 할 일을 갈라 적는다. 매일 0시다.
