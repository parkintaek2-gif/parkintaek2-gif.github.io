  세션 입구 — 사장님이 창마다 번호를 말해 주지 않아도 됩니다
  2026-08-07 개정 (2번 조율)
══════════════════════════════════════════════════════════════

■ 리부팅한 뒤에는 이것 하나만 누르십시오

      0_여섯창_한번에.cmd

  여섯 창이 3초 간격으로 열립니다. 창마다 자기 번호를 알고 열립니다.
  ⭐ 창에 아무것도 붙여 넣지 않으셔도 됩니다.


■ 창 하나만 열려면 — 번호 단추를 누르십시오

      1번_KLifeMap.cmd          klifemap.ai
      2번_조율.cmd              전사 총괄 · 배포 · 보고 (3·5·6번의 리더)
      3번_백년지도.cmd          100yearmap.com
      4번_KLifeMap보조.cmd      1번 보조
      5번_케이컬처와이어.cmd    www.kculturewire.com
      6번_서울마켓.cmd          seoulmarkets.com


■ 창이 자기 번호를 어떻게 아는가 (2026-08-07 부터)

  단추가 창을 열 때 자리 번호를 심어 보냅니다(CLAUDE_SEAT).
  창이 열리면 자동으로 이 폴더의  역할\N.md  를 읽습니다.
  거기에 그 자리가 무엇을 하는지, 지금 무엇이 급한지가 적혀 있습니다.

      역할\1.md  …  역할\6.md      ← 자리마다 한 장

  ⭐ 그래서 세션 ID 가 바뀌어도, 리부팅을 해도, 새 대화가 열려도
     그 창은 자기가 몇 번인지 알고 바로 일을 합니다.

  ⚠ 자리가 하는 일이 바뀌면 역할\N.md 를 고치십시오. 말로 하면 잊힙니다.


■ 세션 ID 는 손대지 않으셔도 됩니다

  단추 안에 ID 가 적혀 있지만, 안 열리면 스스로 실물을 찾아 다시 엽니다.
  그래도 없으면 새 대화를 열고, 그 창도 자기 번호를 압니다.

  ID 를 파일에 굳혀 두고 싶으시면  0_ID새로고침.cmd  를 누르십시오.
  (안 눌러도 됩니다. 매번 스스로 찾습니다)


■ 손대지 마실 것

  · 단추 안의  cd  줄        저장소 위치입니다
  · 단추 안의  set CLAUDE_SEAT=N  줄
       이 줄을 지우면 그 창은 자기가 누구인지 모릅니다


■ 한 창을 오래 쓰다 대화가 길어지면

  창 안에서   /compact   를 치십시오.
  새 창으로 옮기지 않아도 됩니다. 하던 일과 맥락이 요약되어 그대로 이어집니다.

  ⚠ 새 대화를 여는 것은 마지막 수단입니다. 열더라도 번호와 역할은 따라옵니다.
