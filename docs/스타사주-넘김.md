## 가져가실 것

### ① 만세력 — 일주(日柱) 엔진  `scripts/lib/일주.mjs`

날짜 하나를 육십갑자 일주로 옮깁니다. 기준점 **1900-01-01 = 갑술(10번)**.

```
자가시험 8칸 초록 — node scripts/lib/일주.mjs
  · 2000-01-01 = 무오(戊午)   널리 적힌 날
  · 1949-10-01 = 갑자(甲子)   널리 적힌 날
  · 백 년(40,000일) 돌려도 안 어긋남 · 윤달 안 건너뜀
```
⛔ **일주까지만** 냅니다. 년주·월주는 절입 시각을 풀어야 하고, 시주는 태어난 시각이 있어야 섭니다.
⚠ 되돌려 쓰는 값 중 `일지동물` 을 **「띠」로 내보내지 마십시오.** 띠는 년지에서 나옵니다 —
   정국은 소띠(1997)인데 일지는 오(말)입니다. 그대로 「띠」라 적으면 화면이 거짓말을 합니다.
⚠ 야자시 — 밤 11시부터를 다음 날로 치는 학파가 있어, 시각을 모르면 일주가 하루 어긋날 수 있습니다.

### ② 공개 생년월일 수집기  `scripts/build-100y-star-birth.mjs`
→ `src/data/100yearmap/star-birth.json` (10명, 전원 확보)

위키데이터에서 P569(출생일)을 캡니다. 사람(P31=Q5)·대한민국(P27=Q884)·날까지(precision 11)만 씁니다.
사람마다 **Q번호와 주소**가 함께 남습니다 — 지면에 출처로 걸 수 있습니다.

```
⚠ 위키데이터는 빠른 조회를 막습니다. 처음 판은 그것을 「생년월일이 없다」로 적어
  10명이 2명으로 줄었습니다. 되묻기를 넣고 「못 물었다」와 「없다」를 다른 칸으로 갈라 두었습니다
```

### ③ 자동완성 실측기  `scripts/build-100y-star-saju-demand.mjs`
→ `src/data/100yearmap/star-saju-demand.json`

「(이름) 사주」가 자동완성에 떠 있는지 잽니다. **2026-08-20 20:49 기준 15명 중 14명**
(안 뜬 하나는 아이브). 사람 10 · 그룹 5로 갈라 두었습니다.
⚠ 검색량이 아닙니다. 자동완성에 떠 있나입니다. 때에 따라 바뀌므로 잰 때를 꼭 함께 내십시오.
