## Ⅰ. 세션·번호

**Q 네가 몇 번이니? 2번이지?**
A 처음에 「2번」이라 답했는데 **틀렸다.** 근거로 삼은 `npm run inbox` 는 메모에서 「→ 2번」을
찾아줄 뿐 내가 누구인지 못 본다. 입구 `.cmd` 의 세션 ID 로 확인하니 내 세션(`d80abf75`)은
1~6번 어디에도 없는 **번호 없는 창**이었다.
**→ 반영** 번호는 `00_세션입구\N번_*.cmd` 의 세션 ID 로만 정한다. 도구 출력으로 추정하지 않는다.

**Q 세션들에게 번호를 부여해라. 내가 아무 번호나 지정하면 되나?**
A 내가 옆 창에 번호를 심을 수 없다. **사장님이 그 창에 「너는 N번이다」 한 줄**이 유일하고 확실하다.
**→ 반영** `docs/세션간-메모.md` 에 「번호 없는 창은 스스로 선점하고 커밋으로 못 박는다」 규칙을
박았다. 빈 번호와 각 번호의 오늘 할 일도 같이 적었다.

**Q 탭번호 2번 지우지마**
A 아무 창도 지우지 않았다.
**→ 반영** 메모의 「2번 비어 있음」을 그 자리에서 철회하고 「임자 있음」으로 고쳤다.
남의 창·남의 번호는 건드리지 않는다.

**Q 네가 3번인거지?**
A 3번(백년지도)을 선점했다.
**→ 반영** 메모에 `[번호선점] 3번 · d80abf75` 를 남겼다. 그 전까지 2번 이름으로 한 일
(배포 2건·아카이브 백업·서버이전 꾸러미)은 전부 커밋과 메모에 남겨 인계했다.
