## 2. 그래서 무엇을 하나 — 순서대로 셋

### ① 이미 받는 노출을 클릭으로 바꾼다 *(가장 값싸고 가장 큼)*

같은 노출에서 클릭률이 0.65% → 3%(1페이지 평균의 하한)로만 가면 **클릭이 15 → 70** 입니다.
새 지면 한 장도 안 만들고 얻는 수입니다.

```
할 일    1페이지·클릭 0 인 83장의 제목·설명을 **손님이 친 말**에 맞춘다
         (오늘 작품 지면 528장에 「hit or flop」 칸을 넣은 것이 이 일의 첫 조각입니다)
재는 자  4주 뒤 같은 지면군의 클릭률을 다시 잰다. 오르지 않으면 이 길이 틀린 것이다
⛔ 낚지 않는다  제목이 약속한 것을 지면이 실제로 줘야 한다. 그게 안 되면 지면을 고친다
```

### ② 11~20위 61장을 1페이지로 밀어 올린다 *(노출 811개가 걸려 있다)*

가장 큰 둘이 e스포츠입니다 — `korea-challenger-win-rate` 150노출·15.1위,
`korea-ladder-games-played` 103노출·14.6위. 오늘 `/esports` 를 손님 말로 고쳤습니다.

```
할 일    그 지면이 답하는 물음을 제목·첫 문단·구조화 데이터에 일치시키고,
         우리 안에서 그 지면으로 가는 문을 늘린다(안쪽 링크가 순위를 만든다)
재는 자  같은 지면군의 평균 순위. 10 아래로 내려오나
```

### ③ 노출 0인 874장 — **왜 0인지부터 잰다** *(⛔ 더 만들지 않는다)*

```
먼저 할 일  색인 여부를 실제로 재는 자를 만든다 — Search Console **URL Inspection API**
            (하루 2,000건 · 지금 쓰는 서비스 계정으로 됩니다)
그 다음     색인이 안 됐으면 → 안쪽 링크·사이트맵·크롤 예산 문제다
            색인은 됐는데 노출이 0이면 → **아무도 그 말을 검색하지 않는 것**이다.
            그때는 지면을 지우지 않고 **문 이름을 손님의 말로 바꾼다**
⛔ 이 셋 중 어느 것도 「지면을 더 낸다」가 아니다. 71.5%가 안 보이는데 더 내면 그 몫만 커진다
```

## 3. 안 할 것 — 이것을 적는 것이 전략입니다

```
⛔ 지면 수 늘리기를 성과로 세지 않는다. 오늘 기준 71.5%가 노출 0이다
⛔ 「두 번 안에 닿는다 100%」 같은 도달 가능성을 성과로 닫지 않는다.
   이레 실측에서 걸어서 닿는 지면은 0장이었다 — 닿는 것과 걷는 것은 다른 말이다
⛔ 자료의 전문 용어로 문 이름을 달지 않는다. 「byeong day stem」은 자동완성에 0줄이었다
⛔ 낡은 수를 지금 수인 척 내놓지 않는다(자로 막아 두었습니다)
```

## 4. 매출

### B2B — 우리가 가진 것 중 남이 못 가진 것부터

```
쥔 것    넷플릭스 나라 파일 13,395개 제목 × 94개국 × 268주를 파싱해 둔 것.
         그중 **9,530개(71.1%)는 세계 파일에 줄이 없어 시청수가 어디에도 없다**
왜 값이 있나  「우리 작품이 어디까지 갔나」를 묻는 회사에게, 시청수가 없는 71%는
         지금 아무도 답을 못 주는 칸이다. 우리는 자리 수로 답할 수 있다
지금 상태  `/data` 에 문의 창구가 있고 값은 `src/data/wikitip-price.ts` 에 있습니다.
         ⚠ 4주간 `/data` 노출은 있었고 문의는 0건입니다
다음     ① 「작품 여정표」 견본 한 장을 공개 지면에 둔다(맛보기가 없으면 문의가 안 옵니다)
         ② 4주 뒤 문의 수를 잰다. 0이면 물건이 아니라 창구가 문제인지 가른다
```

### B2C

```
지금     0원. 결제 자리가 없습니다(읽는 자리까지입니다)
판단     B2C 는 방문이 먼저입니다. 하루 열림이 4,000 수준에서 유료 지면을 열면
         전환 0을 「물건이 나쁘다」로 잘못 읽게 됩니다. **①②③ 이 먼저입니다**
```

## 5. 9월 목표까지 — 정직한 셈

사장님 목표: 유닛당 하루 순방문자 1,000명.

```
지금 검색에서 오는 것    하루 노출 83 · 클릭 0.5
클릭률을 3%로 올리면      하루 클릭 2.5
노출이 10배 되면(색인 874장이 살아나면)  하루 클릭 25
```
🔴 **검색만으로는 9월에 1,000명에 못 갑니다.** 그것을 숨기지 않고 적습니다.
남는 길은 셋뿐이고, 셋 다 우리가 아직 안 한 것입니다.

```
① 색인 살리기      노출 0인 874장이 왜 0인지 재고 고친다 (위 ③)
② 밖에서 인용받기  레딧·커뮤니티에 우리를 인용할 자리. **계정이 아직 없습니다**
                  (한 번의 사람 손이 필요합니다 — CAPTCHA)
③ 다시 오게 하기   지금 안쪽 걸음이 2.0%입니다. 딱지(`?from=`)를 붙여 두었으니
                  며칠 뒤 어느 자리의 문이 눌리는지 갈라 나옵니다
```
⛔ 「곧」·「대략」을 쓰지 않겠습니다. 위 셋마다 재는 자가 있고, 4주 뒤 같은 자로 다시 재서
올리겠습니다. 오르지 않으면 그 길이 틀린 것이고 그때 바꿉니다.
