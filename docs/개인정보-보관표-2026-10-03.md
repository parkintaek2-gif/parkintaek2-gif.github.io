- 2026-09-11 사고(ADMIN_KEY 누락 시 "열쇠 없으면 통과"였던 결함)는 이미 고쳐져 **열쇠가 없으면 차단**(fail-closed)으로 바뀜. 라이브 재현 —
  - `POST /api/admin/astro/natal` 키 없음/틀린 키 → 401
  - `GET /api/admin/payments` · `GET /api/admin/signups` → 401
  - `GET /api/admin/partners` · `POST /api/admin/api-clients` → 403(키 없음)
- SeoulMarkets·100yearmap·KCW는 관리자 API 자체가 없음(정적/서버렌더 콘텐츠 사이트).
