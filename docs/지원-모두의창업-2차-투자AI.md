## 4. 아이디어 서술 초안 (평가지표=차별성·효과성)
**문제** — 개인투자자·대중이 시장에서 받는 건 «조언·예측»뿐이다. 무엇이 근거인지, 재현되는지, 틀리면 무엇을 잃는지가 안 보인다. 사후 감사도, 검증도 안 되는 «블랙박스 조언»이 신뢰를 깎는다.

**해결 — 투자AI(3-AI·2층 결정론)**
- ①애널리스트(LLM 판독층): 뉴스·공시·리포트를 읽어 «무슨 일이 있었나»를 구조화 신호로. 출력은 저장(아카이브). **매매 못 함.**
- ②펀드매니저(규칙·결정론): 신호→포지션. 같은 신호면 같은 답. **신호 못 만듦.**
- ③리스크관리자(규칙·결정론·독립): 한도 감시·정지만. **②는 ③을 못 멈춤.**
- **돈이 움직이는 자리(②③)는 전부 결정론 → 재현·백테스트·감사 가능.** LLM은 ①에서 «읽기»만.

**차별성**
1. 판정 100% 자체 엔진 — «같은 입력=같은 결과»(재현성). LLM은 말투·읽기만.
2. **리스크관리 독립** — 「그것이 틀렸을 때 무엇을 잃는가」를 별도 규칙이 감시(운용업 등록 내부통제 요건 선반영).
3. **조언하지 않는다, 사실·분포·리스크만 준다** — 투자자문업 아님. 사행·예측 상품과 다름.
4. 남이 안 센 것을 센다(자본집약도 등) + **영어권 대상 한국 금융·경제 데이터**(해외 K-투자 수요).

**효과성·트랙레코드(이미 있음)**
- 결정론 두 층(②③)+감사원장 **구현 완료·자가시험 20/20 통과**(`scripts/invest-ai/`).
- 무인 뉴스판독 장치(신호 저장소+일일 판독)와 첫 실제 신호(BOK 금리) 실증.
- SeoulMarkets(운영 중 데이터 저널리즘)가 **재현 가능한 데이터 기반·검증 인프라** 제공.

**GPU 활용계획(2R)** — ①LLM 판독층의 «대량 뉴스·공시·리포트 판독»에 GPU 가속(현재는 세션 판독이라 처리량 한계). ②③는 이미 결정론이라 GPU 불요 → GPU는 정확히 «AI 서비스구현 가속»에 쓰인다.

**MVP(최대 2천만원)** — 판독층 + 신호 저장소 + 백테스트/감사 대시보드(재현성 시연).

**진정성(문제해결)** — 홍익인간·«나침반»: 바늘을 우리가 세우지 않는다. 지형(사실·분포·리스크)을 그리고 판단은 사용자가. 「이것은 통계이지 당신이 아닙니다」가 곧 리스크관리다.

## 8. 푸터/발행주체 — 🔴 투자AI는 어디에도 라이브 노출 금지
사장님 지적(2026-08-30): 「서비스 중이면 안 된다며? 푸터에 넣으면 안 되는 것 아냐?」 — **맞다.**
- 🔴 **투자AI를 라이브 사이트(푸터·페이지)에 올리면 «이미 상용화(서비스) 중»이 되어 공고 p15 선정취소·상금환수 대상.** 그래서 **투자AI는 어떤 라이브에도 넣지 않는다.** 신청~심사 동안 «미출시 신규»로 유지.
  - 현재 상태 안전: 투자AI는 저장소 코드(`scripts/invest-ai/`)+내부 원장뿐, **공개 페이지 0**. 이대로 둔다. 배포·공개 링크 만들지 않는다.
- SeoulMarkets 사이트(데이터 저널리즘)는 **신청 대상 아이디어가 아니다** — «도전자가 가진 데이터 기반·트랙레코드»일 뿐. 그 사이트가 라이브인 것은 투자AI의 상용화가 아니다(문제 없음).
- 따라서 **SeoulMarkets 푸터의 발행주체(KLifeDesign Inc)는 신청과 무관** — 투자AI 노출 목적의 푸터 변경은 하지 않는다. (발행주체를 다른 이유로 바꿀지는 별개 사안이며, 그것도 ⛔ 내가 임의로 안 바꾸고 사장님 지시 시 반영.)
