## 우선순위 — 반전(통념과 다른 값)이 센 순서

**① 1인가구 — 「혼자 사는 사람」 하면 청년이 먼저 떠오르지만**
```
1인가구 8,244,308가구 중 나이가 가장 몰린 곳은 70세 이상(20.7%) — 20대(16.3%)보다 많다.
70세 이상 1인가구 170만 8,523가구 중 72%(123만 7,738가구)가 여성이다.
→ 100yearmap.com/oneperson
```

**② 어린이집 — 「어린이집 자리가 없다」는 걱정과 실제**
```
전국 어린이집 채움률(정원 대비 현원) 2006년 81.3% → 2025년 69.1%.
자리는 남는데, "어린이집 대기"를 검색하는 사람은 여전히 많다.
→ 100yearmap.com/nursery-fill (2026-08-24 신설)
```

**③ 동호회 — 「나이 들수록 더 활발해진다」는 절반만 맞다**
```
동호회 활동 참여율, 20대→50대까지는 오르다가(12.2%대) 그 뒤로 다시 내려간다.
70세 이상(6.3%)은 20대보다도 낮다.
→ 100yearmap.com/exercise
```

**④ 은퇴 — 소득이 실제로 얼마나 빠지나**
```
가구 경상소득 50대 941.6만원 → 60세 이상 576.7만원. -38.8% (라이브 지면 표기 그대로).
→ 100yearmap.com/retire-income
```

**⑤ 결혼 — 30대 초반, 아직 안 한 사람이 더 많다**
```
30~34세 가운데 67.4%가 아직 미혼(남자 74.8% · 여자 59.1%).
그런데 같은 해 평균 초혼 연령은 남자 33.9세 · 여자 31.6세 — 평균은 이미 결혼한 사람만의 값.
→ 100yearmap.com/marriage-age (숏영상도 있음 — age32.mp4, 14초)
```

**⑥ 평생학습 — 몇 살까지 배우나**
```
평생학습 참여율 20대 43.4% → 70대 26.4%. 계속 내려가지만 0이 되지는 않는다.
→ 100yearmap.com/lifelong
```

**⑦ 돌봄 — 몇 살부터 필요해지나**
```
2024년 장기요양 인정률 65~69세 1.9% → 85세 이상 43%.
85세 이상에서도 57%는 인정을 받지 않았다.
→ 100yearmap.com/care (숏영상도 있음 — 14초)
```
