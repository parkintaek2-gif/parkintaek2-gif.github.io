이 자가 하는 것 —
```

자리지킴이를 윈도 예약작업으로 등록 — 창이 죽어도 15분마다 우리를 깨운다
```

⚠ `04_대화록` 은 **아직 없다.** 그건 노트북 창을 닫기 직전에 싼다(지금 싸면 그 순간부터 낡는다).
   그러니 지금 짐풀기를 돌려도 **대화록 없다**는 말이 나온다 — 정상이다.

## ④ 🔴 일보다 먼저 — **매시 예약 넷을 다시 건다**

```
창이 닫히면 그 창의 예약이 같이 죽는다. 예약은 세션 안에만 산다.
그래서 새 창은 스스로 예약을 걸어야 한다. 이것을 잊으면 그 자리는 조용해진다.
```
2번의 예약은 넷이다 —
```
매시 :05  걷기      git pull → 메모 꼬리 → ① 배포 대기 있으면 즉시 배포(내 몫)
                    ② 2시간 무흔적 자리 기록 ③ [진행] 2번 HH:MM 한 줄
매시 :25  지시 걸기  3·5·6번에게 한 덩어리씩. 셋만 적는다 — 무엇을·왜·확인은 무엇으로
13:35     보고 독촉
15:00     업무보고 모으기   ⭐ 첫 칸은 «유닛별 하루 순방문자» (사장님 8/21 지시)
```
⛔ `git add -A` 금지 — 공유 워킹트리다. 내 파일 경로만 지정해 커밋한다.
   경로만 적어도 **색인에 남의 것이 올라 있으면 그것까지 커밋된다.**
   그래서 커밋 전에 `git diff --cached --name-only` 로 색인을 본다(8/21 에 5번이 잡아 준 것).

## ⑤ 노트북의 2번에게 「내가 섰다」를 알린다

메모에 이 한 줄을 적고 커밋·푸시하라 —
```
[진행] 2번(새 서버) HH:MM  했다: clone 둘 · 짐풀기 · npm ci · 메모리 N개 확인 · 예약 넷 걸었다 / 한다: … / 막힘: …
```
그 줄이 보이면 노트북의 2번이 물러난다. **그때까지 두 자리가 같이 도는 것은 정상이다** —
다만 **같은 일을 두 번 하지 마라.** 배포는 한쪽만 한다. 먼저 락을 잡은 쪽이 한다.
