# 벤치마킹 — 사람이 해야 하는 것, 그리고 니케이에 물을 것

2026-09-09 · 5번 · 사장님 「다른 벤치마킹 대상도 사람이 해야 하는 걸 구체적으로 알려줘」

---

## Ⅰ. 먼저 — 사람 손이 필요한 것은 **딱 두 갈래**입니다

제가 지금까지 조사한 것은 **전부 혼자 했습니다.** robots 를 읽고, 허용된 지면을 받아,
값과 상품을 전량 뽑았습니다. FnGuide 값 7종 · QUICK 상품 45종 · Wind 상품 28종.
**사람 손이 필요한 것만 골라 냈습니다.**

| 갈래 | 왜 사람이 해야 하나 | 몇 건 |
|---|---|---|
| **A. 회사 신분으로 말을 걸어야 하는 것** | 문의 폼·전화는 회사 이름으로 나가는 일이라 제가 임의로 못 합니다 | 3건 |
| **B. 돈이 오가는 것** | 사장님 승인 대상입니다 | 2건 |
| **C. 제가 하겠습니다** | 아래 목록은 참고로만 — 사장님 손 필요 없습니다 | 6건 |

---

## Ⅱ. 니케이(Nikkei NEEDS)에 무엇을 물으면 되나 — 사장님 물음

> 「니켓이에서 뭘 알아봐주면 되나」

문의 창구: `nkbb.nikkei.co.jp` 의 문의 폼 (일본어·영어 둘 다 있습니다).
⚠ 그 호스트는 크롤러 40종을 이름으로 막아 두었으므로 **제가 자동으로 물을 수 없습니다.**
사람이 폼을 채우는 것은 막지 않습니다.

### 2-1. 🔴 딱 하나만 물으신다면 이것입니다

> **「우리가 받은 데이터를 가공해 우리 이름으로 «다시 팔» 수 있습니까?
> 그것이 안 되면, 가공한 «파생 지표»는 팔 수 있습니까?」**

까닭 — 이 한 가지가 우리 사업의 전제입니다. 재판매·파생물이 막혀 있으면 남의 자료를
사서 하는 사업은 처음부터 성립하지 않고, **우리처럼 원자료를 직접 받는 쪽이 유일한 길**임이
확정됩니다. 지금 저는 그것을 「그럴 것이다」로만 알고 있고 **재 본 적이 없습니다.**

### 2-2. 이어서 물으실 것 다섯 (있으면 좋은 것)

```
1. 상품 목록과 데이터 항목표를 받을 수 있습니까 (dataset list · 항목 사전)
   ⭐ 이것이 가장 값진 자료입니다. 「무엇을 칸으로 파는가」가 상품의 절반입니다

2. 값이 어떻게 매겨집니까
   · 데이터 «항목»별입니까, 사용자 «좌석»별입니까, 아니면 통짜입니까
   · 최소 계약 단위와 기간은 얼마입니까 (연 단위입니까)
   ⭐ FnGuide 는 연간 할인이 0 이었습니다(연 = 월×12). 일본도 같은지 알고 싶습니다

3. 배달 방식이 무엇입니까 — 파일(SFTP) · API · DB 직결 · 엑셀 중 어느 것을 실제로 씁니까
   ⭐ Wind 은 다섯 채널을 다 팝니다. 일본에서 «실제로 많이 쓰이는 것»이 무엇인지가
     우리가 무엇을 먼저 만들지를 정해 줍니다

4. 한국 데이터를 취급합니까. 취급한다면 어디서 받습니까
   ⭐ 만약 니케이가 한국 자료를 사서 일본에 판다면 **우리가 그 공급자가 될 수 있습니다.**
     이것이 가장 큰 기회일 수 있는데 저는 아직 못 쟀습니다

5. 학술·스타트업·소규모 요금제가 있습니까
```

### 2-3. ⛔ 물으실 필요 «없는» 것

```
⛔ 상품 이름과 개요        제가 공개 지면에서 이미 뽑았습니다
⛔ 커버리지 연수            공개 지면에 있습니다 (50년 이상 · 일본 금융기관 95% 이상 구독)
⛔ QUICK 과의 관계          공개돼 있습니다 (QUICK 은 닛케이 자회사)
```

## Ⅲ. 다른 벤치마킹 대상 — 사람이 해야 하는 것만

### 3-1. QUICK (닛케이 자회사 · 일본)

```
상태   ✅ 상품 45종·분류축·배달방식을 제가 전량 뽑았습니다 (영문 장터가 열려 있습니다)
사람   🔴 1건 — 「QUICK Data Factory 에 «외부 제공자»로 들어갈 수 있습니까」
       그 장터는 QUICK + 파트너 상품을 함께 진열합니다. 지면에 이렇게 적혀 있습니다 —
       「데이터·애플리케이션 판매의 기획·지원, 데이터 분석, 당사 서비스와의 제휴 등
        다양한 협업이 가능하므로 꼭 상담해 주십시오」
       ⭐ 그 말 그대로면 **우리 한국 데이터를 그 장터에 올릴 수 있습니다.**
         영업망 없이 일본 기관에 닿는 길입니다 (사장님이 못박으신 「사람을 거치는 계획을
         세우지 않는다」에 걸리지 않습니다 — 남의 판매망을 쓰는 것이니까요)
       ⚠ 다만 이것은 «우리가 파는 쪽»이라 벤치마킹이 아니라 판로입니다. 우선순위는 니케이보다 높습니다
```

### 3-2. Wind (중국)

```
상태   ✅ 영문 포털 상품 28종을 제가 뽑았습니다 (robots Allow: /)
사람   ⬜ 없습니다. 다만 값은 문의 전용이라 ⬜ 못 쟀습니다
       ⛔ 중국 업체에 회사 이름으로 문의를 넣는 것은 지금 우선순위가 아니라고 봅니다 —
         상품 «구조»는 다 봤고, 값은 우리 가격 결정에 꼭 필요한 값이 아닙니다
```

### 3-3. Choice(East Money) · iFinD(동화순) — 중국

```
상태   ⬜ 아직 안 봤습니다. 제가 하겠습니다 (robots 부터 읽습니다)
사람   ⬜ 없습니다. 다만 중국 사이트는 해외 IP·실명인증에 막힐 수 있고, 막히면
       그때 「막혔다」고 적고 사장님께 올리겠습니다. 미리 부탁드리지 않습니다
```

### 3-4. FnGuide — 기관용(QuantiWise · DataGuide)

```
상태   ✅ 개인용 유료 7종 값 전량 확보 · 기관용 상품 이름과 개요 확보
사람   💰 1건 (돈이 오가는 것) — 기관용 값은 문의 전용입니다.
       ⛔ 유료 가입은 «돈이 오가는 것»이라 제가 못 합니다
       ⚠ 그런데 저는 이것이 **지금 필요하지 않다**고 봅니다. 상품 구성과 개인용 값을
         이미 다 확보했고, 기관 영업은 우리 단계가 아닙니다. 나중에 올리겠습니다
```

### 3-5. 글로벌 경쟁자 (MarketScreener · Koyfin · Stockopedia 등)

```
상태   ✅ 여섯 곳이 우리와 겹치는 것과 그 약점 넷을 확인했습니다
사람   💰 1건 (돈이 오가는 것) — 이들의 유료 층 «안»을 보려면 구독이 필요합니다.
       월 수십 달러 수준으로 보이지만 아직 정확히 못 쟀습니다.
       ⚠ 그런데 「안을 보는 것」보다 「밖에서 보이는 것」이 더 중요합니다 —
         손님이 결제 전에 보는 화면이 곧 상품 설명이니까요. 그건 제가 봤습니다.
       ⇒ 지금은 필요 없다고 봅니다
```

### 3-6. Koscom · KRX 정보데이터시스템

```
상태   ⬜ 아직 안 봤습니다. 제가 하겠습니다 —
       🔴 이쪽이 실은 니케이보다 중요합니다. **한국 시장 자료의 «권리자»**이고,
         우리가 재배포로 걸릴 수 있는 유일한 곳이기 때문입니다
사람   ⬜ 지금은 없습니다. 공개 이용약관·요금표부터 제가 읽습니다.
       읽고 나서 「사람이 물어야 하는 것」이 남으면 그때 구체적으로 올리겠습니다
```

## Ⅳ. 정리 — 사장님께 부탁드리는 것은 **둘뿐입니다**

| 순위 | 무엇 | 어디에 | 왜 사람이어야 하나 |
|---|---|---|---|
| **1** | **QUICK Data Factory 에 외부 제공자로 들어갈 수 있는지** | `corporate.quick.co.jp` 문의 | 회사 이름으로 협업 상담을 거는 일입니다. **영업망 없이 일본 기관에 닿는 길**이라 값이 가장 큽니다 |
| **2** | **니케이 — 재판매·파생물 허용 범위 + 상품 항목표 + 가격 체계** | `nkbb.nikkei.co.jp` 문의 | 크롤러 40종을 이름으로 막아 제가 자동으로 못 묻습니다 |

⛔ 그 밖은 전부 제가 하겠습니다. 못 하게 막히면 그때 「막혔다」고 적어 올리겠습니다.
⛔ 값을 내야 하는 것(FnGuide 기관용 · 글로벌 구독)은 **지금 필요하지 않다**고 판단했습니다.
  필요해지는 시점이 오면 액수와 까닭을 붙여 여쭙겠습니다.

## Ⅴ. ⬜ 제가 못 쟀다고 적어 두는 것

```
⬜ 일·중·FnGuide 기관용 상품의 «값» — 셋 다 문의 전용이라 공개 가격표가 없습니다
⬜ 니케이가 한국 자료를 취급하는가 — 취급한다면 우리가 그 공급자가 될 수 있습니다
⬜ Choice · iFinD 의 영어 상품 유무
⬜ KRX·Koscom 의 재배포 조건 — 제가 다음에 읽을 것 가운데 가장 중요합니다
⬜ 손님이 파일을 원하나 API 를 원하나 — 아직 물어본 손님이 한 명도 없습니다
```
