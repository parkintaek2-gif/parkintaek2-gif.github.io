### 8-2. 우리가 일·중 언어로 내야 하나 — 데이터로 답합니다

금융감독원 「외국인 증권투자 동향」 —

```
2026-01  외국인 상장주식 보유 1,701.4조원 = 시가총액의 32.0%
2026-05  보유 비중 — 미국 41.7% · 유럽 31.7% · 아시아 13.9%

미국 + 유럽 = 73.4%   →  영어 하나로 닿습니다
아시아 전체가 13.9%    →  일본·중국·싱가포르·홍콩이 그 안에서 나뉩니다
                        ⇒ 일본어·중국어 각각은 한 자릿수 %
```

⚠ 정직하게 붙입니다 — 이 수는 **보관국 기준**입니다. 룩셈부르크·아일랜드가 크게 잡히는 것은
펀드 설립지 때문입니다. 그래서 이 수로 말할 수 있는 것은 **「영어가 압도적으로 크다」까지**이고,
「일본 자금이 정확히 몇 %」는 **못 쟀습니다.**

### 8-3. 정한 것

```
지금   영어 하나에 힘을 모읍니다 — 73.4% 가 영어로 닿고, 그 자리가 비어 있습니다

       까닭: 일본은 QUICK 이 자리를 잡아, 우리는 「일본 투자자용 한국 자료」라는
            좁은 칸으로 들어가게 됩니다. 영어는 그 제약이 없습니다
⛔ 지금 세 언어로 벌리지 않습니다 — 힘이 흩어지면 영어 지면이 얇아지고,
   두께가 곧 검색 유입입니다
```

## Ⅸ. 콘셉트는 그대로, 구현·형식·내용은 다르게 (사장님 지시)

### 9-1. 그대로 가져오는 것 — 콘셉트

```
상품을 «축»으로 가른다 · 축마다 값이 다르다 · 정기결제로 판다 ·
맛보기 층을 둔다 · 개인용과 기관용을 나눈다
```

### 9-2. 반드시 달라야 하는 것

| 항목 | FnGuide | **우리 (SeoulMarkets)** |
|---|---|---|
| 언어 | 한국어 전용 | **영어** |
| 결과물 형식 | 로그인 단말 화면 | **파일과 API** — CSV·Parquet·JSON + 문서화된 REST |
| 무료 층 | 없음 (공개 5장) | **색인되는 무료 지면을 넓게**, 유료는 그 위 |
| 내용의 축 | 재무·주가 | **사람 축을 더한다** — 근속·급여·성별격차·임원·학력 |
| 원자료 | 제휴로 받은 완성 자료 | **원자료를 우리가 쪼갠다** |
| 리포트 본문 | 원문 열람을 판다 | **본문을 팔지 않는다.** 수만 뽑아 파생 지표를 판다 |
| 판정 | 값을 제시 | **분포를 낸다.** 평균을 규범으로 만들지 않는다 |
| 못 잰 것 | 표에 안 보임 | **「못 쟀다」를 칸에 적는다** |
| 연간권 | 월×12 (할인 0) | **연간에 실제 할인을 준다** |
| 환불 | 7일·무이용, 1일권 불가 | **더 넓게 준다** — 우리는 아직 이름이 없다 |
