# 3번 — **매일 0시에 되새기는 것**

> 🔴 사장님 지시 (2026-08-09 오후) — **「그거를 키즈로 만들어서 매일 영 시에 되새겨」**

⛔ 이 문서는 **0시에 제일 먼저 읽는다.** 다른 것을 하기 전이다.

---

## 사장님 원문 — 줄이지 않는다

> **「영 시에 키즈 풀지. 너 자체적으로 키즈를 만들어. 왜 자꾸 대입에 머물러있니?
> 영 세에서 백 세까지 그걸 다 컨텐츠를, DB를 갖고 오라고, 데이터를 가공하라고,
> 갖고 컨텐츠를 만들고. 지금 하는 자료를 네가 컨텐츠 한 거는 되게 잘 좋잖아. 잘 만들었어.
> 그렇게 잘 맞는 거를 똑같이 계속 다 만들라고. 너의 매출은 광고 매출도 상당히 많을 거야.
> B2B 판매보다 B2C 판매가 많을 것이고, 그걸 염두에 두고,
> 그거를 키즈로 만들어서 매일 영 시에 되새겨」**

---

## 0시에 스스로 묻는 네 줄

```
① 손님이 **0세~100세**인가 — 오늘 만든 것이 10대에만 걸려 있지 않은가
② 주고객이 **소비자(B2C)**인가 — 기관에 파는 쪽으로 기울지 않았는가
③ **새 자료를 가져와 가공**했는가 — 있는 것만 다시 만지고 있지 않은가
④ 지금 꼴(숫자 + 왜 그런지 + 못 잰 것을 밝히기)을 **그대로 넓혔는가**
```

⛔ 「우리가 만들 수 있는 것」에서 새것을 찾지 않는다. 그게 오늘까지 한 방식이고 천장이 나왔다.

## 🔴 2026-08-09 — 대입에 머물러 있었다는 **증거**

우리가 우리 손으로 적어 둔 줄이다. `src/data/100yearmap/summary.json` —

```json
"올리지_않는_것": {
  "초등학교": 6341,
  "중학교": 3328,
  "사유": "초등은 진로 검색어가 되지 않는다. 중학교는 다음 단계"
}
```

⛔ **자료가 없어서가 아니었다.** 8/4 에 NEIS 에서 **12,665곳을 다 받아 두고**
   「초등은 진로 검색어가 안 된다」는 까닭으로 **9,669곳을 접어 두었다.**
   그 까닭 자체가 **「진로(=대입)가 목적」**이라는 전제 위에 있다. 사장님이 짚으신 자리다.

```
원천   archive/raw/neis/school-info.json   12,665곳 (BOM 이 붙어 있다 — 파싱 전에 벗긴다)
       초등학교 6,341 · 중학교 3,328 · 고등학교 2,408 · 특수학교 202 · 그 밖
초등   주소 6,336 · 홈페이지 6,312 · 설립일 **6,341 전부**
```

### ⭐ 그리고 그 안에 백년지도 이름값이 그대로 있었다

```
초등학교 6,341곳 중 **문 연 지 100년이 넘은 곳 889곳**
가장 오래된 곳   계성초 1882 · 영화초 1892 · 서울교동초 1894 · 서울광희초 1895
```
⚠ 설립일은 NEIS 값이라 학교가 세는 개교기념일과 다를 수 있다. 「몇 년째」로 단정하지 않는다.

## 🔴 2026-08-14 0시 — **나흘이 지났는데 99.1% 가 그대로 대입 쪽입니다**

말로 되새기지 않고 **잤습니다**(`scratchpad/0시-네줄재기.mjs`).

```
① 손님이 0~100세인가 — 지면 4,970장
   10대(대입 쪽)   **4,927장 · 99.1%**   school · major · college-major · university · report
   나이 전체            9장 ·  0.2%      age · life · how-long
   일터·어른            2장 ·  0.0%      work · after
   그 밖               32장 ·  0.6%
```
🔴 **8/09 에 짚은 그대로입니다.** 지면을 4,970장 냈는데 **나이·일터 쪽은 열한 장**입니다.
⚠ 「그동안 개봉 준비를 했다」는 까닭이 됩니다만, **사장님이 물으신 것은 비율**입니다.

```
③ 새 자료를 가져왔나 — 오늘 것 넷
   src/data 에 3개(occupation-names · voc-series-outcomes · _provenance)
   작업공유\자료 에 1개 — **qnet**(국가기술자격 통계연보 · 엑셀→TSV 5장)
④ 접어 둔 것 — **그대로입니다**
   {"초등학교":6341,"중학교":3328,"사유":"초등은 진로 검색어가 되지 않는다"}
```

### ⭐ 그런데 오늘 **위쪽 나이를 열 자료**가 손에 들어왔습니다

```
Q-net 부록 4-1  **연령별 자격취득**  14세 이하 · 15~19 · … · 60~64 · 65세 이상  (누적 3,479만 건)
Q-net 부록 4-3  1인당 자격취득 현황
공공데이터포털   국가기술자격 취득 관련 현황 — **성별·연령별·학력별·행정구역별** · 이용허락 **제한 없음**
나이축          월급 꼭대기 45~49세 468만원 → 60세부터 319만원 (오늘 숏영상으로 냄)
```
⭐ **「자료가 없어서」가 아닙니다.** 8/09 과 같은 자리입니다 — 있는데 안 폈습니다.
⛔ 다만 2번이 **8/15 개봉까지는 새 지면을 내지 않는다**고 정했습니다.
   그래서 **8/16 에 제일 먼저 할 것**으로 둡니다. 미루는 것이 아니라 **날을 못 박는 것**입니다.

```
8/16 첫 일   Q-net 연령별 취득 + 나이축을 묶어 **/age 쪽 지면**을 넓힌다
             ⛔ school 쪽을 더 늘리지 않는다. 비율이 더 기운다
```
