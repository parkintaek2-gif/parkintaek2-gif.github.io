```

   무엇을 물으셨는지가 기록으로 남아야 다음에 같은 것을 두 번 여쭙지 않는다
```

## 1-1. 🔴 서울마켓츠 콘텐트 «엑셀 내려받기» — 아직 안 했습니다

사장님이 물으신 것을 제가 답만 하고 **만들지는 않았습니다.** 지금 상태를 그대로 적습니다.

```
지금 있는 것   /v1 데이터 API (갈래 아홉 · OpenAPI 3.1 · 열쇠 발급) — JSON 만 냅니다
              무료 영문 지면들 — 표를 «화면»으로만 보여 줍니다
없는 것       ⬜ 지면의 표를 «엑셀(xlsx)·CSV 로 내려받는 단추»
계획          F5 「파일 배달 + 내려받기 지면」(09-23 · 6번)이 바로 이것입니다
```

⚠ 다만 사장님 물음은 F5 를 기다리라는 뜻이 아닐 수 있습니다. **지금 있는 표에 CSV 단추를
붙이는 것은 하루 안에 됩니다.** 11시 보고에 그 갈래를 여쭙고, 「지금 붙여라」시면 그날 붙입니다.
⛔ 「F5 에 들어 있습니다」로 답하고 넘기지 않겠습니다 — 그것이 물음을 미루는 답입니다.
