## 보낼 곳 — **표본으로 재 봤다. 길은 있는데 결정이 없다** (2026-08-09 11:5x KST)

「자료는 다 됐고 막고 있는 것은 보낼 곳」이라 적어 두고, 실제로 찾아봤다. **다섯 곳 중 둘만** 봤다 —
길이 있는지 없는지를 가리는 데는 그것으로 충분했고, 더 파기 전에 걸리는 것이 나왔기 때문이다.

```
Studio Dragon   ✅ 공개 창구 있음 — 회사 홈페이지 Contact 에 일반 문의 메일이 적혀 있다
                   (17Fl, 75 Maebongsan-ro, Mapo-gu, Seoul · IR·제휴 전용 창구는 따로 없음)
SHOWBOX         ⬜ 못 읽음 — 영문 홈페이지가 자바스크립트로 그려져 본문을 못 가져왔다
```

⭐ **길은 있다.** 상장사(Studio Dragon·SHOWBOX·SBS·JTBC 등)는 공개 창구를 갖고 있다.
⚠ 다만 대개 **일반 문의 창구**이지 「자료를 사는 사람」 창구가 아니다. 그리로 보내면 담당자에게 갈지 모른다.

### 🔴 그런데 여기서 멈춘 까닭 — **이건 제 결정이 아니다**

```
⛔ 열일곱 곳에 회사 이름으로 먼저 메일을 보내는 것은 **바깥으로 나가는 행동**이다
⛔ 한 번 보내면 못 되돌린다. 우리가 누구인지, 무엇을 파는지가 그 회사 기록에 남는다
⚠ 사장님이 이미 아는 사람이 있을 수 있다. 제가 먼저 찬 문을 나중에 다시 두드리면 값이 내려간다
```

⭐ 그래서 **주소를 더 모으기 전에** 사장님 판단을 받는 것이 순서라고 봤다.
   판단만 나오면 열일곱 곳 창구를 모으는 것은 한 시간이면 된다. 자료는 이미 다 있다.

⛔ **제 판단으로 아무 곳에도 안 보냈다.** 보낸 곳 0 · 모은 주소 0(위 두 곳은 확인만 했다).
