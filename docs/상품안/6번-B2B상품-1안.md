## 3. 우리만 줄 수 있는 것 (한 줄)
**남은 재무를 판다. 우리는 사람을 판다** — DART 인력 공시를 우리가 파싱해(첫 행만 읽으면 482,227명이 사라지는 그 표), KRX 시총·KOSIS까지 이어, **틀렸던 것을 스스로 붙여** 판다. 완성된 남의 표를 받아 파는 회사는 여기까지 못 온다.

## 4. ⭐ 「과하다 싶을 정도」 = ②method + ③corrections (신뢰를 판다)
값을 많이 주거나 화면을 화려하게 하는 게 아니다(5번 판독에 동의). **파는 것은 숫자가 아니라 얼마나 믿어도 되는지**(전략 Ⅱ)다.
```
· method.md 에 정의를 우리 말로 바꾸지 않고 원문 인용 — 사는 쪽이 우리 판단을 감사할 수 있다
· corrections.csv 에 우리가 틀렸던 것을 **전부** 실는다 — gender-gap 78→76%, 삼성 50,817→128,881,
  NPS 554,570→553,978(8/7 되짚기). 숨기면 한 번은 팔리고 두 번은 안 팔린다
· coverage.csv 로 채움률을 먼저 밝힌다 — 「전수」인 척하지 않는다
```
