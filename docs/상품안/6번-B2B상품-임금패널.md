# 국민연금 임금 패널 — B2B 상품안 (SeoulMarkets)

> 사장님 지시(2026-08-08, 2번 경유): 「서울마켓·케이컬쳐와이어의 B2B 상품성을 높여라.」
> 기업은 「재미있다」로 안 산다. **「이 수를 내 보고서에 넣어도 되나」**로 산다.
> ⛔ **값(가격)은 이 문서에 적지 않는다** — 사장님 결정 대기.

## 다섯 줄 요약 — 처음 보는 사람용

1. **무엇** — 국민연금이 매달 사업장에 매기는 고지액(임금의 9%)을 사람 수로 나눠, 업종·지역·규모별 **1인당 임금 사다리**로 편 표다.
2. **왜 믿나** — 회사가 꾸며 낼 수 없는 수다. 세무·설문이 아니라 **연금이 실제로 걷는 돈**이라, 아무도 좋게 보이려고 부풀리지 않는다.
3. **크기** — 활성 사업장 **553,978곳**, 가입자 **약 1,156만 명**. 표본이 아니라 거의 전수다.
4. **한계** — 임금 상한(월 573,300원 고지)에 걸린 사람은 값이 눌린다. 그래서 **모든 수는 하한**이고, 우리는 **어느 칸이 얼마나 눌렸는지를 칸마다 붙여서** 판다.
5. **꼴** — 축별 CSV(업종 1,232·지역 16·규모 7) + 눌림 열. 월 1회 갱신. 재배포 제한 없는 원자료(국민연금).

| | 값 | 비고 |
|---|---:|---|

전수에 가깝다. 「1,000명 표본 설문」이 아니라 **거의 모든 사업장**을 센다.

## ② 상한 눌림 — 어디에 얼마나 (3번 검증본, 자 일치 확인)

임금이 상한(월 573,300원 고지)을 넘으면 연금은 상한까지만 매긴다. 그래서 그 사람의 값은 실제보다 낮게 눌린다.
**전체 1,156만 명 중 63만 4,927명(5.5%)이 상한에 걸려 있다.** 세 축 전부에서 셌다 — 이게 그대로 팔 거리다.

```
업종(1,232)   비디오·영상기기 제조 95.0% · 컴퓨터 제조 51.4% · 화물차 제조 42.7%   (상위)
              → 잘 버는 제조 업종일수록 우리 수가 실제보다 많이 낮다
지역(16)      경기 9.4% · 서울 6.1% · … · 대구 0.3%                              (경기가 서울보다 더 눌림)
              → 「서울이 경기보다 높다」로 읽으면 안 된다. 눌림을 안 걷은 순서다
규모(7)       1,000명 이상 21% · 300~999명 4.1% · … · 10~29명 0.3%              (큰 회사일수록 심함)
              → 대기업 칸이 가장 많이 눌린다. 대기업 임금을 이 표로 읽을 땐 특히 하한이다
```

## ③ 우리 수가 틀리는 방향 — **전부 하한이다** (한쪽으로만 틀린다)

이 자료의 오차는 **방향이 정해져 있다.** 그래서 안전하다.

```
① 상한은 위로만 자른다   → 눌린 칸의 1인당 값은 실제보다 낮다. 절대 높지 않다
② 세는 법도 덜 센다      → 「사업장 평균이 상한에 닿은 곳」만 눌림으로 세므로,
                          일부만 상한인 사업장은 안 잡힌다. 실제 눌린 사람은 63만보다 많다
∴ 결론                  모든 수는 **하한**. 산 사람은 「최소 이만큼」으로 안전하게 인용할 수 있다
```

**한계를 아는 자료가 한계를 모르는 자료보다 비싸다.** 경쟁 자료는 상한 눌림을 안 걷고 순위를 세운다.
우리는 눌림을 칸마다 붙여 판다 — 그래서 산 사람이 **자기 보고서에 넣어도 되는지**를 스스로 판단할 수 있다.
