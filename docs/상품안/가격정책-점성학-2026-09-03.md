# 점성학 가격정책 — 정본 (2026-09-03)

작성 5번(총괄대행) · 사장님 지시 「**가격정책을 아주 정치하게 짜. 정확하고 치밀하게.. 그래서 시장에서 확 뜨게**」

> 이 문서는 **재서 쓴 것**과 **사장님이 주신 것**과 **제 판단**을 갈라 적습니다.
> 갈라 적지 않으면 다음 사람이 어느 것이 사실인지 모릅니다.

## 1부. 먼저 — 무엇을 재서 알았나

### 1-1. 우리 원화 값표는 이미 층이 서 있다 (실측 · `billing/pricing.json`)

```
 9,900 ─ 14,900 ─ 19,900 ─ 29,000 ─ 34,000 ─ 39,000 ─ 49,000 ─ 54,000 ─ 68,000 ─ 79,000
 단품     관상      검사      사주      부모      리포트    궁합      택일      이별     성명·부부
                                      가운데 39,000원
```

상품 17개, 가장 싼 9,900원, 가장 비싼 79,000원.

### 1-2. ⭐ 달러 값과 원화 값이 «거의 정확히» 겹친다 — 이것이 이 정책의 뼈대다

환율 1,390원으로 옮겨 재 봤습니다.

| 점성학(달러) | 원화 환산 | 가장 가까운 우리 원화 상품 | 차이 |
|---|---:|---|---:|
| 기본형 $19.99 | 27,786원 | **사주 29,000원** | 1,214원 |
| 미끼 $34.99 | 48,636원 | **궁합 49,000원** | **364원** |
| 심화형 $39.99 | 55,586원 | **택일 54,000원** | 1,586원 |
| 플래너 $15.99 | 22,226원 | 심리검사 19,900원 | 2,326원 |
| Bundle Pro $119.99 | 166,786원 | 성명 79,000원 | **87,786원** |

**넷은 붙어 있고 하나만 떠 있습니다.** 즉 점성학 값은 우리 원화 사다리 위에 자연스럽게 얹히는데, **Bundle Pro 만 갈 곳이 없습니다.** 그 자리가 이 정책이 풀어야 할 첫 문제입니다.

### 1-3. 검산에서 나온 부딪힘 둘

**하나 — 낱개로 담는 게 번들보다 싸다**
```
기본형 $19.99 + 플래너 $15.99 + 심화형 $39.99 = $75.97
                          3건 담기 7% 할인      = $70.65
Bundle Pro                                     = $119.99   ← $49 더 비싸다
```
지금 다건할인은 2건 5% · 3건 7% · 4건 10% 입니다(`bundleDiscount.tiers`). 손님은 **번들을 안 사고 낱개로 담습니다.**

**둘 — 세 값이 20달러 안에 몰려 있다**
```
연 구독        $99
Bundle Pro     $119.99
월 구독 12개월  $120
```
연 구독이 제일 싼데 셋이 거의 같은 자리에 서 있습니다. **값이 촘촘하면 고민만 늘고 결제가 줍니다.**

## 2부. 그래서 값을 이렇게 놓는다

### 2-1. 사다리 — 여섯 칸

| 칸 | 이름 | 값 | 무엇을 주나 | 이 칸이 하는 일 |
|---|---|---:|---|---|
| 0 | 무료 | $0 | 원국 지도 15쪽 (지금 그대로) | 실력을 보여 준다 |
| 1 | 기본형 | **$19.99** | 원국 + 매년·매월 + 관계 **또는** 사업 · 약 22쪽 | 첫 결제의 문턱 |
| 2 | 미끼 | **$34.99** | 심화형에서 **전문가모드만** 뺀 것 | **3번을 팔기 위해 둔다** |
| 3 | 심화형 | **$39.99** | 위 + 매일 + 대운 + 관계·사업 둘 다 + **전문가모드** · 약 32쪽 | ⭐ 여기로 오게 한다 |
| 4 | 연 구독 | **$99** | 매일·매월이 1년 내내 갱신 | 계속 오게 한다 |
| 5 | Bundle Pro | **$149.99** | 연 구독 + 심화형 + 플래너 (+ AI 상담) | 위에서 눌러 3을 싸 보이게 |

### 2-2. 왜 2번 칸(미끼)을 두는가

손님이 $34.99 와 $39.99 를 나란히 보면 이렇게 읽습니다.

> **「$5 만 더 내면 왜 그렇게 판정했는지까지 다 보여 준다」**

2번은 **팔려고 두는 칸이 아니라 3번을 팔려고 두는 칸**입니다. 이 칸이 없으면 손님은 $19.99 와 $39.99 사이에서 **두 배 차이**를 보고 싼 쪽으로 갑니다.

⚠ 2번을 «없는 상품»으로 만들지 않습니다. 실제로 살 수 있어야 하고, 사면 실제로 받아야 합니다. 팔 생각 없는 가짜 칸을 두는 것은 손님을 속이는 것입니다.

### 2-3. 왜 Bundle Pro 를 $119.99 → **$149.99 로 «올리는가»**

내리면 연 구독($99)과 붙어 둘 다 죽습니다. 올려서 **연 구독과 30달러 이상 벌립니다.**

```
$99      연 구독            — 매일·매월만
$149.99  Bundle Pro         — 거기에 심화형(32쪽) + 플래너 + AI 상담
차액 $51 에 들어가는 것       심화형 $39.99 + 플래너 $15.99 = $55.98  →  손님이 남는다
```

**차액보다 주는 것이 커야 번들이 팔립니다.** $51 을 더 내고 $55.98 어치를 받으니 셈이 섭니다. 그리고 낱개 3건 할인가($70.65)와도 겹치지 않습니다 — 그쪽엔 1년 구독이 없기 때문입니다.

### 2-4. 다건할인과 부딪히지 않게

```
지금        2건 5% · 3건 7% · 4건 10%
그대로 둔다  ⛔ 번들 상품(4·5번 칸)은 다건할인 «대상에서 뺀다»
            까닭: 번들은 이미 묶음가다. 둘을 겹치면 할인이 두 번 먹는다
            (`bundleDiscount._note` 가 이미 부부/연인 코칭을 같은 까닭으로 빼 놓았다)
```

## 3부. 경쟁사와 어디서 견주나

### 3-1. 사장님 지시 — 광고가 주 매출인 곳은 뺀다

> 「**경쟁사 싼 쪽 >>> 광고가 주요 매출인 곳은 비교기준에서 제외**」

### 3-2. ⬜ 못 찾은 것 — 정직하게 적는다

사장님이 주신 문건 전부를 뒤졌습니다.

```
점성학_상품 포트폴리오(안).xlsx    칸 글자 133개 — 「광고」 든 칸 0개
점성학_상품 포트폴리오(안).md      「광고」 2곳 — 둘 다 «우리 상품이 광고를 없앤다»는 설명
saju_vs_astrology_..._market.txt  「광고」는 전부 «네이버 검색광고 API»(자료 출처) 이야기
```

**「어느 경쟁사가 광고로 먹고사나」라고 명기된 곳은 없었습니다.** 지어내지 않습니다.

### 3-3. 대신 문건에 있는 것 — 159줄이 기준을 준다

> 「**Nebula($5~50)는 사람, KLifeMap($0.99)은 AI**」

값이 갈리는 까닭이 **「사람이 하느냐」**로 적혀 있습니다. 그래서 이렇게 가릅니다.

| | 견주나 | 까닭 |
|---|---|---|
| Nebula 심화 **$49** | ✅ 견준다 | 사람이 쓰는 긴 리포트 — 우리 32쪽과 같은 결 |
| CHANI **$20~40** | ✅ 견준다 | 구독·리포트를 팔아서 먹고산다 |
| Nebula/CHANI 번들 **$99** | ✅ 견준다 | 우리 Bundle Pro 와 같은 자리 |
| Nebula **$5~9** | ⛔ 안 견준다 | 미끼용 짧은 것 — 사장님 지시의 「싼 쪽」이 이것이다 |

### 3-4. 그래서 우리 자리

```
심화형 $39.99  vs  Nebula 심화 $49        →  -18%
기본형 $19.99  vs  CHANI $20~40 하단      →  같거나 조금 싸다
Bundle $149.99 vs  CHANI/Nebula 번들 $99  →  +51% «비싸다»
```

⚠ **번들은 우리가 더 비쌉니다. 숨기지 않습니다.** 대신 그 값에 32쪽 리포트와 플래너가 들어갑니다. 「싸다」로 팔지 말고 **「이만큼 들어 있다」로 팔아야 하는 칸**입니다.

⚠ 경쟁사 값은 **사장님이 주신 표의 수**이고 제가 확인한 것이 아닙니다. 광고 문구로 쓰기 전에 제가 재겠습니다.

## 5부. 이 표가 「시장에서 확 뜨는」 까닭

값을 싸게 매기면 뜨는 것이 아니라 싸구려로 보입니다. 이 표가 노리는 것은 셋입니다.

```
1. 무료가 아깝지 않다   15쪽을 그냥 줍니다. 손님이 «실력»을 먼저 봅니다
2. 갈리는 자리가 분명하다 무료는 «지도»(안 바뀌는 원국), 유료는 «시계»(매년·매월·매일).
                       안 준 것이 «없는 것»이 아니라 «다음 것»이라 납득됩니다
3. 고르기 쉽다          $5 차이로 근거까지 여는 칸이 있어 손님이 3번으로 갑니다
```

⛔ 그리고 우리가 안 하는 것 — **「지금 결제하면」·「놓치면」 같은 말**. 우리 강령이 「사람을 밀어붙이지 않는다」입니다. 값표가 스스로 설명되면 밀어붙일 필요가 없습니다.
