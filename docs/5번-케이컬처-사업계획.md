## 2. 팔릴 만한 것 — **세 갈래**

### ㉮ 데이터 상품(B2B) — 지금 당장 팔 수 있는 것

`/for-industry` 지면은 이미 있고 **값이 없습니다.** 값을 붙이는 것이 첫 일입니다.

```
상품 A  동남아 4개국 × 12개월 인물 읽힘 패널 (배우 1,023 + 음악 1,701)
        사는 사람: 기획사 해외팀 · 캐스팅 · 광고주
        파는 각도: 「이 배우가 **어느 나라에서** 읽히나」 — 넷플릭스 시간은 나라를 안 알려줍니다
상품 B  한국 장소 2,219곳 읽힘 패널 (도시·궁궐·역·회사)
        사는 사람: 관광공사 지자체 · 여행사 · 면세/유통
상품 C  주문 조사 — 「우리 아티스트 열 명, 네 나라, 열두 달」 한 장 보고서
```
⚠ 값은 **6번이 낸 $29 one-time** 을 회사 안 견줄 값으로 씁니다(6번 지면 실측·2번 확인).
   ㉮A·㉮B 는 그보다 무겁습니다. **$49~$99 one-time** 을 제안드립니다 —
   ⛔ 이것은 잰 값이 아니라 **견준 값**입니다. 한 건이라도 팔리면 그때 진짜 수가 생깁니다.

## 3. 「팬들은 흥미롭게 볼까」 — **재서 답합니다**

⛔ 흥미로울 것이라고 **추측하지 않습니다.** 대신 우리가 이미 잰 것 둘이 답의 절반입니다.

```
① 우리 자료가 이미 「아니다」를 냈습니다
   넷플릭스 차트에 오른 한국 배우 1,047명의 띠 분포
   카이제곱 7.77   문턱 19.68   → **우연과 구분되지 않습니다**
   즉 「띠가 좋아서 떴다」는 우리 이름으로 못 씁니다. 우리가 그 반대를 실측해 냈습니다

② 개별 사주를 끝까지 못 냅니다
   사주 원국은 **태어난 시**가 있어야 섭니다. 공개 프로필에 시는 거의 없습니다
   4번이 넘길 수 있는 것은 시주를 뺀 **삼주**까지입니다
```

⭐ 그러면 파는 각도가 하나 남습니다 — **점괘가 아니라 「같은 것을 가진 사람들」**입니다.
```
✅ 「IU 와 같은 닭띠인 배우 스물아홉 명」   ← 셀 수 있고, 거짓이 아니고, 팬이 찾습니다
⛔ 「IU 는 재성이 강해 재물운이 좋습니다」  ← 우리가 못 세우는 문장입니다
```
⚠ 이미 남들이 스타사주를 합니다(타이트사주·스타지오·포스타입 — 2번 확인).
   똑같이 쓰면 다섯 번째입니다. **근거와 한계를 같이 말하는 것**만이 우리 자리입니다.
