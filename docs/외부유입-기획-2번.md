# 외부 유입 장치 — 기획 · 전략 (2번 · 2026-08-15)

> 사장님: 「사주도령 같은 **외부유입에 효과 있는 걸 기획**하고 **어떻게 퍼뜨릴지 전략**을 짜라. **지금 바로 시행**한다」

## 1. 사주도령이 왜 번지나 — 뜯어 본 것
```
① 무료 · 가입 없음 · **생일 하나만** 받는다           문턱이 거의 0
② 결과가 **나 혼자 것이 아니라 관계**다               ← 진짜 까닭
③ 내 링크를 뿌리면 친구가 들어와 **내 지도에 뜬다**    그 친구가 자기 지도를 또 만든다
④ 말이 쉽다                                       귀인 · 단짝 · 호랑이 선생
```
⛔ ③이 엔진입니다. **손님이 손님을 데려옵니다.** 우리는 만들어 내보내기만 했습니다.

## 2. ⛔ 그대로 베끼지 않습니다 — 두 가지 까닭
```
① 베끼면 2등입니다. 저쪽이 이미 유행 중입니다
② 「케미 79」처럼 **사람에게 점수를 매깁니다** — 우리 모토와 어긋납니다
   「우리가 바늘을 세우지 않는다」 · 「평균이 규범이 되면 나침반이 아니라 압박이 된다」
```

## 3. ⭐ 우리 것 — **「내 나이의 사람들은 지금」**
```
나이(또는 생년)만 넣는다  →  백년지도 실측 데이터로 답한다
```
```
서른둘에 사람들은 —
   결혼했을까요, 아직일까요        N명 중 M명
   첫 직장에 아직 있을까요          유지취업률 실측
   얼마를 벌까요                   분포로. 평균 하나로 안 찍습니다
   어디에 살까요                   수도권 61.2% 같은 실제 수치
```
⭐ **왜 이것인가 — 우리만 됩니다**
```
· 사주가 아니라 **데이터**입니다. 믿음이 필요 없어 거부감이 없습니다
· 「나만 이런가?」에 **숫자로** 답합니다  ← 우리 모토 그 자체
· 점수를 안 매깁니다. **분포만 보여 줍니다**
· 백년지도 데이터가 **이미 있습니다** — 새로 모을 것이 없습니다
· 남이 못 베낍니다. 국가 통계를 이미 정리해 둔 곳이 우리뿐입니다
```
🔴 이미 우리 카피가 있습니다 — 「**서른둘에 사람들은 / 결혼했을까요, 아직일까요**」

## 4. 퍼뜨리는 전략 — 네 갈래
```
① 결과 화면이 곧 **공유 카드**          이미지가 자동으로 만들어져 그대로 올릴 수 있게
② 친구 링크                            「너는 몇 살이야?」 → 친구도 자기 것을 본다
③ 카카오톡 공유                         한국은 카톡입니다. 첫 단추를 여기에
④ 검색                                 「서른두살 평균연봉」 같은 말로 검색해 들어오게
                                        나이별 지면을 만들면 **한 나이가 한 장**입니다
```
⭐ ④가 오래 갑니다. ①②③은 터졌다 식지만 검색은 쌓입니다.

## 5. ⛔ 오늘 만들 것 — **가장 작은 하나**
```
지면 하나   /age/32  꼴로. 나이를 넣으면 그 나이의 실측 넷을 보여 준다
공유 카드   그 지면의 OG 이미지 — 카톡·SNS 에 그대로 뜨게
링크        「나는 몇 살?」 단추 하나
```
⛔ 완성을 노리지 마십시오. **번지는 최소 단위**만 만듭니다.
✅ 만드는 자리 — **3번**(백년지도). 데이터가 거기 있고, 3번은 100% 로 손을 뗀 상태입니다.

## 6. 재는 법 — 이것이 없으면 다음이 없습니다
```
날마다  들어온 사람 · 공유 눌린 수 · 친구 링크로 들어온 비율 · 우리 유료 지면으로 넘어간 수
```
🔴 **친구 링크로 들어온 비율**이 핵심 숫자입니다. 그것이 1 을 넘으면 저절로 번집니다.
