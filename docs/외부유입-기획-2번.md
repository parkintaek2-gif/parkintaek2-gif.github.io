# 외부 유입 장치 — 기획 · 전략 (2번 · 2026-08-15)

> 사장님: 「사주도령 같은 **외부유입에 효과 있는 걸 기획**하고 **어떻게 퍼뜨릴지 전략**을 짜라. **지금 바로 시행**한다」

## 1. 사주도령이 왜 번지나 — 뜯어 본 것
```
① 무료 · 가입 없음 · **생일 하나만** 받는다           문턱이 거의 0
② 결과가 **나 혼자 것이 아니라 관계**다               ← 진짜 까닭
③ 내 링크를 뿌리면 친구가 들어와 **내 지도에 뜬다**    그 친구가 자기 지도를 또 만든다
④ 말이 쉽다                                       귀인 · 단짝 · 호랑이 선생
```
⛔ ③이 엔진입니다. **손님이 손님을 데려옵니다.** 우리는 만들어 내보내기만 했습니다.

## 2. ⛔ 그대로 베끼지 않습니다 — 두 가지 까닭
```
① 베끼면 2등입니다. 저쪽이 이미 유행 중입니다
② 「케미 79」처럼 **사람에게 점수를 매깁니다** — 우리 모토와 어긋납니다
   「우리가 바늘을 세우지 않는다」 · 「평균이 규범이 되면 나침반이 아니라 압박이 된다」
```

## 3. ⭐ 우리 것 — **「내 나이의 사람들은 지금」**
```
나이(또는 생년)만 넣는다  →  백년지도 실측 데이터로 답한다
```
```
서른둘에 사람들은 —
   결혼했을까요, 아직일까요        N명 중 M명
   첫 직장에 아직 있을까요          유지취업률 실측
   얼마를 벌까요                   분포로. 평균 하나로 안 찍습니다
   어디에 살까요                   수도권 61.2% 같은 실제 수치
```
⭐ **왜 이것인가 — 우리만 됩니다**
```
· 사주가 아니라 **데이터**입니다. 믿음이 필요 없어 거부감이 없습니다
· 「나만 이런가?」에 **숫자로** 답합니다  ← 우리 모토 그 자체
· 점수를 안 매깁니다. **분포만 보여 줍니다**
· 백년지도 데이터가 **이미 있습니다** — 새로 모을 것이 없습니다
· 남이 못 베낍니다. 국가 통계를 이미 정리해 둔 곳이 우리뿐입니다
```
🔴 이미 우리 카피가 있습니다 — 「**서른둘에 사람들은 / 결혼했을까요, 아직일까요**」

## 4. 퍼뜨리는 전략 — 네 갈래
```
① 결과 화면이 곧 **공유 카드**          이미지가 자동으로 만들어져 그대로 올릴 수 있게
② 친구 링크                            「너는 몇 살이야?」 → 친구도 자기 것을 본다
③ 카카오톡 공유                         한국은 카톡입니다. 첫 단추를 여기에
④ 검색                                 「서른두살 평균연봉」 같은 말로 검색해 들어오게
                                        나이별 지면을 만들면 **한 나이가 한 장**입니다
```
⭐ ④가 오래 갑니다. ①②③은 터졌다 식지만 검색은 쌓입니다.

## 5. ⛔ 오늘 만들 것 — **가장 작은 하나**
```
지면 하나   /age/32  꼴로. 나이를 넣으면 그 나이의 실측 넷을 보여 준다
공유 카드   그 지면의 OG 이미지 — 카톡·SNS 에 그대로 뜨게
링크        「나는 몇 살?」 단추 하나
```
⛔ 완성을 노리지 마십시오. **번지는 최소 단위**만 만듭니다.
✅ 만드는 자리 — **3번**(백년지도). 데이터가 거기 있고, 3번은 100% 로 손을 뗀 상태입니다.

## 6. 재는 법 — 이것이 없으면 다음이 없습니다
```
날마다  들어온 사람 · 공유 눌린 수 · 친구 링크로 들어온 비율 · 우리 유료 지면으로 넘어간 수
```
🔴 **친구 링크로 들어온 비율**이 핵심 숫자입니다. 그것이 1 을 넘으면 저절로 번집니다.

# 🔴 [고침 · 사장님 「베끼지 않되, 더 끌 수 있어야 한다」]

## 앞 기획의 약점 — **엔진이 없었습니다**
```
사주도령   내 지도가 비면 아쉽다  →  채우려면 친구를 부른다   ← 강제력
앞 기획    「서른둘은 이렇다」    →  한 번 보고 끝           ← 부를 까닭이 없다
```
🔴 사람이 링크를 뿌리는 까닭은 둘뿐입니다 — **㉠ 내가 채워야 해서 · ㉡ 보여주고 싶어서.**
   ㉠이 훨씬 셉니다. 앞 기획엔 ㉠이 없었습니다.

## ⭐⭐ 바꾼 것 — **「우리들의 인생 시계」**
```
내가 시계를 만든다  →  비어 있다
친구가 생일만 넣는다 →  시계 위에 점이 찍힌다
```
```
한 판에 보이는 것
   · 우리 넷이 지금 인생의 **어디쯤**에 서 있나
   · 그 나이엔 보통 무슨 일이 있나 — 백년지도 실측을 겹칩니다
   · 다음에 누가 어떤 고비를 지나가나
```

## 왜 사주도령보다 더 끄나 — 셋
```
① 채워야 하는 구조는 같습니다 — **엔진을 가져옵니다**
② 사주도령은 **나와 너 둘**만 봅니다.  우리는 **모임 전체**를 한 판에 봅니다
   → 동창회 · 가족 단톡 · 팀에서 훨씬 셉니다. 한 사람이 여럿을 부릅니다
③ 점수를 안 매깁니다. **시계 위의 위치**일 뿐 우열이 없습니다
   → 사주도령의 「케미 79」는 사람을 서열로 만듭니다. 우리는 안 합니다
```
⭐ ②가 결정적입니다. 사주도령은 **1:1**, 우리는 **1:N**. 링크 하나가 부르는 사람 수가 다릅니다.

## 우리만 되는 까닭
```
· 백년지도 실측이 있어야 「그 나이엔 보통 이렇다」를 말할 수 있습니다 — 남에겐 없습니다
· 명리(백년)와 결이 이어집니다. 「백년을 그리는 지도」가 회사 이름입니다
· 사주를 안 믿는 사람도 씁니다 — 문턱이 낮습니다
```

## 오늘 만들 최소 단위
```
① 시계 한 장            내 나이에 점 하나
② 친구 링크             생일만 넣으면 점이 더해진다
③ 공유 카드             그 시계 그림이 그대로 카톡에 뜬다
```
⛔ ②가 없으면 이 기획은 앞 것과 같아집니다. **②를 빼지 마십시오.**

# 🔴 [고침 2 · 사장님 「친구를 불러오면 포인트를 주던지, 더 좋은 방법을 찾아봐」]

## 부를 이유를 **세 겹**으로 쌓습니다
```
① 채워야 한다        빈 시계는 아쉽다                      ← 사주도령과 같은 힘
② 좋아진다          친구가 늘수록 **내 결과가 실제로 좋아진다**  ← 우리가 더 셉니다
③ 받는다            일정 수를 넘기면 **우리 상품**을 드린다      ← 실물 보상
```

## ⭐ ②가 핵심입니다 — 인위적 포인트보다 셉니다
```
혼자      「나는 지금 인생의 몇 시」          — 한 장
둘        「우리 둘은 어디서 부딪히나」        — 관계가 보인다
셋 이상   「이 모임은 **언제 흔들리나**」      ← 혼자서는 절대 못 보는 것
```
🔴 명리는 원래 혼자 보는 것이 아닙니다. **친구가 들어오는 것 자체가 값어치**입니다.
⛔ 포인트를 붙이면 「포인트 때문에 부른 사람」이 옵니다. **그 사람은 안 남습니다.**
⭐ ②는 **가짜로 부를 수 없습니다.** 진짜 아는 사람이어야 뜻이 있습니다.

## ③ 보상 — **포인트가 아니라 우리 상품으로**
```
친구 3명   사주 기본 리포트 1부      (정가 29,000)
친구 5명   관계 리포트 1부
친구 10명  전문가 모드 1회
```
```
⭐ PG 가 없어도 됩니다 — **우리 물건을 드리는 것**이라 돈이 안 움직입니다
⛔ 사장님이 내리신 「선착순 무료」와 다릅니다 — 그건 그냥 줬고, 이건 **데려온 값**입니다
⚠ 원가가 듭니다(AI 호출). **사람당 한 번씩만**. 무제한 금지
⛔ 같은 생일·같은 기기로 여럿 넣는 것을 막습니다. 안 막으면 값만 나갑니다
```

## 사주도령보다 나은 점 — 넷으로 정리
```
① 1:N        저쪽은 나와 너 둘. 우리는 **모임 전체**. 링크 하나가 부르는 수가 다릅니다
② 결과가 자란다  친구가 늘수록 **볼 수 있는 것이 늘어납니다.** 저쪽은 관계 목록만 길어집니다
③ 실물 보상    저쪽은 보상이 없습니다
④ 점수를 안 매긴다  저쪽의 「케미 79」는 사람을 서열로 만듭니다. 우리는 위치만 봅니다
```

## ⛔ 3번 — 오늘은 ①②만. ③은 나중
```
③ 보상은 **로그인·중복 막기**가 있어야 합니다. 오늘 만들면 값만 샙니다
✅ 오늘은 「친구가 늘수록 보이는 것이 늘어난다」를 **화면에서 보이게** 하는 데까지
   (친구 0명일 때 「친구 3명이 들어오면 이것이 열립니다」를 **미리 보여 줍니다**)
```
⭐ 그것만으로도 부를 이유가 생깁니다. **잠긴 것을 보여 주는 것**이 가장 싼 유인입니다.
