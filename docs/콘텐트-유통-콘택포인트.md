### A-2. 채널별 실제 진입 조건

#### ① Google — 신청이 필요 없다

**확인:** *"There's no application needed. Using Publisher Center is entirely optional,
and does not affect your site's eligibility for Google News."*

- 등록은 선택이지만 **하는 편이 낫다** — 게재 관리와 **Reader Revenue Manager** 수익화 설정 가능
- 콘택: `publishercenter.google.com`
- **Discover 가 진짜 물량이다.** 특히 한류 매체는 모바일 팬덤이라 Discover 의존도가 높다
- 요건: 대표 이미지 폭 1200px 이상, `max-image-preview:large` 메타
- ✅ **SeoulMarkets 는 이미 sitemap·robots·IndexNow 를 갖췄다**

#### ② MSN Partner Hub — 가장 현실적인 첫 파트너

| 항목 | 확인된 내용 |
|---|---|
| 콘택 | `support.microsoft.com/msn/partner-hub` → Partner Hub 계정 생성 |
| 필요물 | **RSS / ATOM / WordPress 피드**, 결제 계정, 프로필 이미지 **448×448 이상** (JPG/PNG) |
| 심사 | **신청 시 + 이후 주기적으로** 법규·가이드라인 준수 심사 |
| 수익 | 전문 콘텐츠 옆에 붙는 광고 수익 배분 |
| ⚠ 변경 | **2025년 9월 실적부터 페이지뷰가 아니라 「실제 광고 노출」 기준으로 배분 방식 변경** |

> **MSN 이 우리에게 특히 맞는 이유:** MSN 은 금융 섹션이 강하고 미국·영어권 트래픽이 크다.
> 「한국 시장 영문 데이터」는 MSN Money 에 빈 칸이다.

**✅ 준비 완료 (2026-08-01) — 파트너 전용 전문 피드를 만들었다**

피드가 두 개인 이유가 중요하다. **목적이 반대라서 하나로 못 겸한다.**

| 피드 | 내용 | 목적 |
|---|---|---|
| `/rss.xml` | 요약(dek)만 | 독자를 우리 사이트로 끌어온다 |
| **`/feeds/partners.xml`** | **본문 전문** + 이미지 + 저자 | **MSN·SmartNews 제출용** |

MSN 은 **「full-length content」 옆에 붙는 광고**의 수익을 나눈다. 요약만 주면 배분 대상이
아니다. 반대로 우리 사이트 유입용 피드에 전문을 넣으면 아무도 우리 사이트에 안 온다.

파트너 피드에 담은 것:
- `content:encoded` — 본문 전문 (상대경로를 절대 URL 로 치환)
- `media:content` / `media:thumbnail` — SmartNews 는 이미지 없는 항목을 걸러낸다
- `dc:creator` — 저자. YMYL 심사에서 저자 표기 누락은 감점
- 각 기사 끝에 **투자자문 아님 고지 자동 삽입** — 남의 화면에 실릴 때도 따라가야 한다

⚠ **파트너 피드는 `<head>` 에 노출하지 않았다.** 광고하면 일반 피드리더가 전문 피드를
가져가 버린다. **파트너에게 URL 을 직접 제출하는 용도다.**

**남은 준비:** 프로필 이미지 448×448.

#### ③ SmartNews — 수익이 예측 가능한 유일한 채널

| 항목 | 확인된 내용 |
|---|---|
| 콘택 | SmartNews Partner Program 신청 |
| 필요물 | **SmartFormat Validator** 를 통과한 피드 |
| 요건 | 정기 발행되는 오리지널 기사, 이미지·메타데이터가 갖춰진 피드, 편집 품질 |
| 수익 | **광고 배분이 아니라 앱 내 월 페이지뷰 기준 계단식 정액.** 연간 지급이 5자리 후반 ~ 6자리 달러 |

> **정액이라는 게 중요하다.** 광고 배분은 시장 상황에 흔들리지만 이건 예측 가능하다.
> 다만 **오리지널 기사**를 본다 — 번역·전재 위주로는 통과가 어렵다. 우리 방향과 맞다.

#### ③-2 ⭐ 중개사 경로 — 패스트뷰 (2026-08-01 추가)

**내가 빠뜨렸던 경로다.** 위 SmartNews 항목은 「직접 신청」만 적어 두었는데,
**한국 CP 를 대신 태워 주는 중개사가 따로 있다.**

| 항목 | 내용 |
|---|---|
| 회사 | 패스트뷰 (fastviewkorea.com) |
| 무엇 | 한국 콘텐츠 제공사(CP) → **일본 뉴스앱 1위 스마트뉴스** 유통 중개 |
| 실적 | 협력 시작 한 달 만에 CP 10여 곳 연동, **월 1,900만 PV** (자체 집계) |
| 확인된 CP | **위키트리** — 일본에서 `Starlight Report` 라는 이름으로 나간다 |

> *「한국 언론과 콘텐츠 기업은 별도 인력이나 현지 네트워크 없이 일본 시장에
> 진출할 수 있는 유통 경로를 확보」*

**왜 이게 직접 신청보다 현실적인가**

SmartNews 직접 신청은 「오리지널 기사 비중」·「정기 발행」 심사를 통과해야 한다.
발행 이력이 짧은 신생 매체는 그 자체가 벽이다.
**중개사를 통하면 CP 로 붙는 것이라 그 심사를 우리가 직접 받지 않는다.**

**우리 적합도** — WikiTip 이 정확히 이 카테고리(한류·연예)다.
일본은 동남아 타깃과 다르지만 **한류 콘텐츠의 유료 유통이 실제로 돌아가는 시장**이라는
증거이고, 같은 구조를 동남아로 확장할 때의 선례가 된다.

- [ ] 패스트뷰 CP 등록 조건·수익 배분 확인 (미확인)
- [ ] 동남아(인니·베트남·태국)에 같은 역할을 하는 중개사가 있는지 확인

#### ④ Flipboard — 문턱이 가장 낮다

- 콘택: `flipboard.com/publishers` → Sign Up → **RSS 제출 후 심사**
- 셀프서비스. 자동 인제스트
- 직접 수익은 작지만 **브랜드 노출과 백링크**를 얻는다

#### ⑤ Apple News — 지금은 못 한다

- **자발적 신청을 받지 않는다(초청제).**
- 수익 조건은 좋다: 자체 판매 광고 **100%**, 애플 판매분 **70%**
- 미국·영국·호주·캐나다만 서비스
- **대응:** MSN·SmartNews 에서 실적을 쌓은 뒤 재타진. 지금 시간 쓰지 않는다

## B. 데이터 유통 — 여기가 돈이 되는 쪽

**데이터 사업의 최대 난관은 영업이다.** FnGuide 는 영업조직으로 판다. 우리는 없다.
**마켓플레이스가 그 영업조직을 대신한다.**

### B-1. 채널 비교

| 채널 | 고객 | 진입 난이도 | 우선순위 |
|---|---|---|---|
| **RapidAPI** | 개발자·스타트업 | 낮음 | **1** |
| **AWS Data Exchange** | 기업·금융기관 | **높음** | 2 |
| **Snowflake Marketplace** | 기업 데이터팀 | 중간 | 3 |
| **Databricks Marketplace** | 데이터 엔지니어 | 중간 | 4 |
| Nasdaq Data Link | 퀀트·헤지펀드 | 미확인 | 5 |

### B-2. AWS Data Exchange — 조건을 정확히 확인했다

| 항목 | 확인된 내용 |
|---|---|
| **콘택 경로** | AWS Support 의 **Create case 마법사로 온보딩 요청** → AWS Data Exchange 팀이 연락해 자격심사·등록 진행 |
| 자격 | AWS Marketplace 판매자 약관 충족, 양호한 상태의 AWS 고객 |
| 법인 요건 | 적격 관할지의 거주자·시민 또는 그곳에 설립된 법인 |
| 운영 요건 | **고객지원 프로세스와 지원 조직을 갖출 것**, 데이터를 정기 갱신하고 취약점이 없게 유지 |
| **유료 판매 시** | 비미국 판매자는 **W-8 양식 + VAT/GST 등록번호 + 미국 은행계좌** |

> ⚠ **「미국 은행계좌」가 실무 장벽이다.** 이건 코드로 못 푼다.
> 확인 필요: 한국 법인이 미국 계좌 없이 AWS 유료 판매가 가능한지, 아니면
> Payoneer·Wise 등 대체 수단이 인정되는지. **유료화 전에 반드시 확인.**
>
> ⚠ **「고객지원 조직」요건도 있다.** 1인 운영으로는 심사 통과가 어려울 수 있다.
> → **그래서 RapidAPI 를 먼저 한다.**

### B-3. Snowflake Marketplace

- 프로바이더 프로필 설정이 리스팅 게시의 전제 조건
- **공개 리스팅에는 trial(체험) 제공이 필수**
- 문서: `docs.snowflake.com` → Data Exchange / becoming a provider
- 금융기관이 Snowflake 를 많이 쓴다 — **한국 데이터 수요처와 접점이 크다**

### B-4. Databricks Marketplace

- 문서: `docs.databricks.com` → marketplace → get-started-provider
- Delta Sharing 기반. 기술 진입은 어렵지 않다

### B-5. RapidAPI — 여기부터 시작한다

- 개인·소규모도 등록 가능. 결제·과금·문서·SDK를 대신 처리
- 우리 `/v1/...` 엔드포인트를 그대로 올리면 된다
- **미국 은행계좌·고객지원 조직 요건이 없다**
- 무료 티어를 넉넉히 열어 개발자를 모은다 → 사용 데이터가 곧 시장 검증

### B-6. 직접 판매 콘택 포인트 (마켓플레이스 밖)

| 대상 | 접근 |
|---|---|
| 한국 익스포저 있는 해외 헤지펀드·자산운용사 | SeoulMarkets 기사가 명함이다. 기사 하단 API 링크 |
| 대학·연구소 | 무료 학술 티어 → 논문 인용이 신뢰 자산 |
| 핀테크·로보어드바이저 | RapidAPI 에서 자연 발견 |
| 해외 데이터 벤더 | 리셀러 계약. 3단계 이후 |

## D-2. 선례 — 이 사업 모양은 25년 전에 이미 돈이 됐다

**1998~2001년, 머독의 STAR TV 가 한국 콘텐츠를 글로벌 위성망에 실었다.**

| 연도 | 일 |
|---|---|
| 1994 | Channel [V] 개국 — STAR TV + EMI·유니버설·소니뮤직 공동출자 |
| **1998** | **Channel [V], 한국 프로그램 개시. 엠넷 음악 프로그램에 영문자막을 입혀 송출** |
| 2001.6 | Channel [V] Korea 개국 — **도레미미디어 67% + STAR TV** |
| 2009 | tvN ASIA — STAR TV + CJ E&M (→2012 Channel M →2016 tvN ASIA) |

**우리가 하는 일과 구조가 같다.**

| 그때 | 지금 |
|---|---|
| 엠넷 프로그램에 **영문자막** | 관세청 HS코드·판정값에 **영문 정규화** |
| 머독 위성망에 태움 | MSN·SmartNews·패스트뷰·RapidAPI 에 태움 |
| 한국 콘텐츠 ↔ 글로벌 유통사 중개 | 같은 자리 |

### ⚠ 다만 결정적으로 달라진 것 — 해자가 옮겨갔다

**그때는 유통망에 들어가는 것 자체가 해자였다.** 머독 위성망에 태우려면 계약을 따야 했고,
딴 사람만 할 수 있었다. 도레미미디어가 지분 67% 를 들고 있던 이유다.

**지금은 유통망이 공짜다.** 신청만 하면 된다. 문턱이 사라진 것은 우리에게 유리하지만,
**그 문턱이 우리를 지켜 주지도 않는다.** HS코드 영문화는 누구나 할 수 있다.

|  | 1998년 | 2026년 |
|---|---|---|

| 진입 | 어렵다 | 쉽다 |
| 방어 | 계약이 막아 준다 | **시간만이 막아 준다** |
