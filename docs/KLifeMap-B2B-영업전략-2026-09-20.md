# KLifeMap B2B 영업 전략 — 「공짜로 주는 곳」을 판다

> 2026-09-20 · 5번(총괄)
> 사장님 지시: 「**케이라이프도 B2B 영업도 해라. 자기 고객들에게 공짜로 사주, 별자리를
> 서비스하는데가 의외로 많다**」 · 「**영업 첫 타겟 등 네가 판단해서 전략적으로 잘 해라**」

---

## Ⅰ. 사장님 말씀이 맞다 — 재서 확인했다

### 1-1. 실증 하나 — 신한라이프

```
주소   shinhanlife.sinbiun.com/unse/…
운영   신한라이프(보험)
값     「※ 본 운세는 무료 서비스입니다」 — 고객에게 공짜로 준다
차림   정통운세(2026 건강운·월간 종합운세·평생운세·신토정비결·부자되기)
       생활운세(오늘의 운세·주간 종합운세·오늘의 타로·프리미엄 로또운세)
       애정·궁합(내사랑 반쪽찾기·내 운명의 배우자·프리미엄 궁합)
공급   서브도메인이 말해 준다 — sinbiun.com 이라는 «다른 회사»가 대 준다
```

⭐ **이것이 우리 손님의 모습이다.** 보험사는 운세를 만들지 않는다 — 사 온다.
  곧 **이미 예산이 잡혀 있다.** 새 예산을 설득할 필요가 없고, 공급사를 바꾸면 된다.

### 1-2. 시장에 이미 값이 서 있다 (실측)

| 공급사 | 파는 꼴 | 값 |
|---|---|---|
| Ablecity | 사주·타로·관상·손금 모듈별 API · SaaS 또는 구축형 | **건당 10~100원** · 시험 100건 무료 |
| SAZU | 만세력·사주·운세 REST · 화이트라벨 노코드 빌더 | Pro **29,900원/월 10,000건** (≈건당 3원) · 월 500건 무료 |
| Un7 | 사주팔자·토정비결·주간·오늘의 운세 | 건별 과금 |
| IPAPAS | 오늘의 운세·띠별·만세력·사주·토정비결 · **데이팅 앱 궁합 제휴** | 범위 선택형 |

🔴 **값이 이미 바닥이다.** 건당 3~100원짜리 싸움에 들어가면 우리는 진다 —
  그들은 몇 해 먼저 시작했고 물량이 있다.

## Ⅱ. 그래서 우리가 설 자리 — 「싸게」가 아니라 「깊게」

### 2-1. 남들이 못 파는 것 셋

```
① 판정의 «깊이»    자평진전 격국용신 · 순용/역용 · 억부 — 규칙이 코드에 있고 근거가 남는다
                   경쟁사는 「오늘의 운세」 문장 생성이다. 우리는 «판정»을 한다
② 전문가모드       감명 근거(판정 과정·고전 출전)를 여는 층. 상담사·연구자가 쓰는 자리다
                   ⇒ B2B 손님이 «자기 상담사»에게 쥐여 줄 수 있는 유일한 물건이다
③ 다국어 넷        한국어·영어·일본어·중국어. 점성학은 다국어가 본판이다
                   ⇒ 해외 고객을 가진 곳(항공·면세·글로벌 커머스)은 여기서 갈린다
```

⛔ **성명학(작명·개명)은 한국어 화면에서만 판다** — 사장님이 「영구히」라고 못박으셨다.
  B2B 제안서에도 다국어 품목으로 올리지 않는다.

### 2-2. 값 매기는 꼴 — 건당이 아니라 «자리»로 받는다

```
⛔ 건당 과금으로 붙지 않는다 — 바닥값 싸움이라 이기지 못한다
✅ 화이트라벨 연 계약 — 그 회사 이름으로 나가고, 우리는 자리값을 받는다
✅ 전문가모드는 «별도 품목» — 상담사 좌석 수로 센다
✅ 다국어는 «언어당» 얹는다
```

⚠ 값의 실제 수는 유닛끼리 협의해 정한다(사장님: 「가격과 상품구성도 유닛끼리 협의해서 정한다」).
  이 문서는 «꼴»만 정한다.

## Ⅲ. 첫 타겟 — 내가 정한 순서와 까닭

```
1순위  보험·카드·은행   신한라이프가 실증이다. 같은 자리에 같은 것을 쓰는 곳이 여럿이다.
                      ⭐ 이미 공급사가 있으므로 «예산이 있다». 바꾸는 영업이다
2순위  데이팅·결혼정보   IPAPAS 가 이미 궁합으로 제휴하고 있다 — 수요가 검증된 자리다.
                      우리 궁합은 두 사람의 대운을 «함께» 그린다. 보여 주면 차이가 바로 보인다
3순위  통신·멤버십      고객에게 줄 거리가 늘 모자란 자리다. 물량이 가장 크다
4순위  운세 앱 자체     우리 엔진을 «뒤에» 넣는다. 그들은 앞단이 강하고 판정이 약하다
```

⛔ 포털(네이버·카카오)은 뒤로 미룬다 — 문턱이 높고 우리 레퍼런스가 아직 0 이다.
  한 곳이라도 뚫은 «뒤»에 간다.

## Ⅳ. 지금부터 할 것

```
09-21  ① 대상 명부 — 「지금 무료 운세를 주고 있는 곳」을 «화면으로 확인해» 적는다
          ⛔ 짐작으로 적지 않는다. 그 회사 지면에 운세가 떠 있는 것만 센다
       ② 팔 것 한 장 — 무엇을 주고 무엇을 안 주는지. 전문가모드·다국어를 앞에 세운다
       ③ 보여 줄 것 — 우리 감명서 실물 PDF(오늘 감수 끝낸 판)
09-22  첫 편지 20곳. 한국 회사이므로 «우리 업무시간»에 보낸다
       (사장님: 영업 메일은 받는 나라 업무시간에)
09-23  답장 응대 · 시연 요청이 오면 그 자리에서 띄운다
```

### 편지에 반드시 들어갈 것

```
✅ 첫 줄에 «그 회사 화면»을 짚는다 — 「귀사 ○○ 지면에서 운세를 무료로 주고 계십니다」
   (막연한 소개 편지는 안 읽힌다)
✅ 우리가 다른 점 한 줄 — 판정의 깊이 · 전문가모드 · 다국어 넷
✅ 실물 하나 — 감명서 PDF. 말로 설명하지 않는다
⛔ 값을 편지에 먼저 적지 않는다. 자리를 만들고 나서 맞춘다
⛔ 「우리는 언론사다」·「업계 최고」 같은 말을 쓰지 않는다
```

## Ⅴ. 왜 이것이 올해 «몇 억»의 유일한 길인가

```
KLifeMap B2C  입구 상품 5,000원 · 어제 방문 37명
              3억을 채우려면 6만 건 — 지금 물량으로 산술이 안 선다
KLifeMap B2B  한 곳이 여러 해를 산다. 서너 곳이면 억 단위가 선다
```

⭐ B2C 를 버리는 것이 아니다(사장님: 「케이라이프맵 B2C도 신경을 많이 쓰고」).
  **B2C 는 내년 이후의 규모이고, 올해의 수는 B2B 에서 나온다.** 둘을 같이 간다.
