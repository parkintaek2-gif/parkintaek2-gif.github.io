## 0. 호스팅을 어디로 할 것인가 — 짚고 갈 것

사장님 지시는 "klifemap.ai와 같은 데서". klifemap.ai는 현재 이렇게 돼 있다.

- 도메인 등록: **Spaceship**
- 네임서버: `launch1/2.spaceship.net`
- 웹서버 IP: `34.8.247.175` → Google Cloud 대역. **Cloudtype**(GCP 위에서 도는 한국 PaaS)로 보인다.

**도메인은 Spaceship에서 같이 등록하는 게 맞다.** 계정 하나에서 관리하는 게 편하다.

**호스팅은 Cloudtype으로 가면 손해다.** 이 사이트는 서버가 필요 없는 정적 HTML 묶음이라
Cloudtype에 올리면 아무 일도 안 하는 컨테이너를 24시간 켜두고 돈을 내게 된다.
Cloudflare Pages는 같은 결과물을 **무료·무제한 대역폭·전세계 CDN**으로 올려준다.
CLAUDE.md에도 "상시 서버·DB 없음"으로 못 박혀 있다.

→ **도메인 Spaceship, 호스팅 Cloudflare Pages.** 아래는 그 기준으로 쓴 절차다.
(그래도 Cloudtype으로 통일하고 싶으시면 말씀 주시면 그 설정으로 바꾼다.)

## 1. 도메인 등록 (Spaceship)

1. https://www.spaceship.com 로그인 (klifemap.ai 쓰던 계정)
2. `seoulmarkets.com` 검색 → 장바구니 → 결제
3. **Auto-renew 켜기.** 매체 도메인이 만료되면 검색 순위가 통째로 날아간다.
4. WHOIS 개인정보 보호는 기본 제공된다. 켜두면 된다.

> ⚠ 도메인 구매는 결제가 걸린 일이라 제가 대신 하지 않았습니다. 위 3단계만 직접 해주십시오.
> 등록만 끝내면 나머지 DNS·배포는 제가 마무리합니다.

## 2. GitHub 저장소 올리기

```bash
# 이미 로컬 커밋은 돼 있다. 원격만 연결하면 된다.
gh repo create seoulmarkets --private --source=. --remote=origin --push
# 또는 GitHub 웹에서 빈 저장소를 만든 뒤
git remote add origin https://github.com/<계정>/seoulmarkets.git
git push -u origin master
```

## 3. Cloudflare Pages 연결

1. https://dash.cloudflare.com → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**
2. 위 저장소 선택
3. 빌드 설정 — 이대로 넣으면 된다.

   | 항목 | 값 |
   |---|---|
   | Framework preset | `Astro` |
   | Build command | `npm run build` |
   | Build output directory | `dist` |
   | Node version (환경변수) | `NODE_VERSION` = `22` |

4. **Save and Deploy.** 2분쯤 뒤 `seoulmarkets.pages.dev` 로 뜬다.

이후로는 `git push` 할 때마다 Cloudflare가 알아서 다시 빌드해 올린다.
사장님이 서버에 파일을 올릴 일은 없다.

## 4. 도메인 연결

Cloudflare Pages 프로젝트 → **Custom domains** → **Set up a domain** → `seoulmarkets.com`

Cloudflare가 요구하는 DNS 레코드를 **Spaceship의 DNS 관리 화면**에 넣는다.
(Spaceship → Domains → seoulmarkets.com → Advanced DNS)

| Type | Name | Value |
|---|---|---|
| CNAME | `@` | `seoulmarkets.pages.dev` |
| CNAME | `www` | `seoulmarkets.pages.dev` |

Spaceship이 루트 도메인(`@`)에 CNAME을 안 받으면 **ALIAS/ANAME** 타입을 쓴다.
그것도 없으면 네임서버를 통째로 Cloudflare로 옮기는 편이 깔끔하다
(Cloudflare 대시보드가 알려주는 NS 2개를 Spaceship에 입력).

HTTPS 인증서는 Cloudflare가 자동 발급한다. 따로 할 일 없다.

## 5. 도메인이 바뀌면 고칠 곳

세 군데뿐이다.

- `src/consts.ts` → `SITE_URL`
- `public/robots.txt` → Sitemap 줄
- `scripts/ping-indexnow.mjs` → `HOST`

바꾼 뒤 `npm run og` 한 번 돌려 OG 카드의 도메인 표기도 갱신한다.
