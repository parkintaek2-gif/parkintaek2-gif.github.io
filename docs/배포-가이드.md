# 배포 · 도메인 연결 가이드

## 현재 상태 (2026-07-31)

| 항목 | 상태 |
|---|---|
| 사이트 | ✅ **살아 있음** — https://parkintaek2-gif.github.io/ |
| 호스팅 | GitHub Pages (무료, 요금제 없음) |
| 배포 방식 | `main` 푸시 → GitHub Actions 자동 빌드·배포 |
| 도메인 `seoulmarkets.com` | ✅ 등록됨 (Spaceship) · ❌ **아직 이 사이트를 가리키지 않음** |

**남은 건 DNS 레코드 4개뿐이다.** (아래 3번)

## 저장소 두 개를 쓰는 이유

| 저장소 | 역할 |
|---|---|
| `parkintaek2-gif.github.io` | **실제 서비스.** GitHub Pages 는 이 이름의 저장소만 사이트 **루트**에서 서비스한다 |
| `seoulmarkets` | 미러. 프로젝트 이름을 보존해 둔 것 |
| `seoulmarkets-private-archive` | 최초에 만든 비공개 저장소. 지워도 무방하다 |

푸시는 두 곳 모두에 한다.

```bash
git push origin main   # seoulmarkets (미러)
git push site main     # parkintaek2-gif.github.io (실제 서비스)
```

> **왜 루트 저장소여야 하는가** — 프로젝트 저장소로 올리면 사이트가
> `github.io/seoulmarkets/` 하위 경로에 뜬다. 그런데 빌드된 HTML 은
> `/_astro/…` 같은 **루트 기준 절대경로**를 쓰므로 CSS·자산이 전부 404 가 난다.
> `base` 를 넣어 우회할 수도 있지만, 도메인이 붙는 순간 다시 걷어내야 하는
> 임시 코드가 곳곳에 남는다. 루트 저장소를 쓰면 코드를 하나도 안 건드려도 된다.

## 1. 발행 흐름

```
기사 md 추가  →  git push origin main && git push site main
              →  GitHub Actions 자동 빌드·배포 (2~3분)
              →  npm run indexnow
```

관리자 화면은 없다. 파일 추가/삭제가 곧 발행/비공개다.

## 2. 저장소가 공개인 이유

GitHub Pages 는 **비공개 저장소를 무료 플랜에서 서비스하지 않는다.** 그래서 공개로 전환했다.
전환 전에 전체 커밋 히스토리를 시크릿 패턴으로 훑어 **`.env`·API 키·토큰이 하나도 없음을 확인**했다.
(`public/<키>.txt` 의 IndexNow 키는 원래 공개용 검증 파일이라 문제되지 않는다.)

앞으로도 이 저장소에는 **어떤 비밀값도 커밋하지 않는다.** 광고 클라이언트 ID 정도는 공개돼도
무방하지만, 그 외 키가 필요해지면 GitHub Actions 의 Secrets 에 넣는다.

## 3. 도메인 연결 — 남은 유일한 작업

**Spaceship** → Domains → seoulmarkets.com → **Advanced DNS** 에서 아래를 넣는다.

### 루트 도메인 (seoulmarkets.com)

`A` 레코드 **4개**, 호스트는 전부 `@`:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

IPv6 도 넣으려면 `AAAA` 4개(선택):

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

### www

| Type | Host | Value |
|---|---|---|
| CNAME | `www` | `parkintaek2-gif.github.io` |

⚠ CNAME 값 끝에 점(`.`)이 필요한 입력창도 있다. Spaceship 이 자동으로 붙여주면 그대로 둔다.

### 그다음

1. DNS 전파 확인: `nslookup seoulmarkets.com` 이 `185.199.x.153` 을 돌려주면 된다 (보통 수분~수시간)
2. GitHub → `parkintaek2-gif.github.io` 저장소 → Settings → Pages → **Custom domain** 에
   `seoulmarkets.com` 입력 → Save
   (DNS 가 먼저 가리키지 않으면 GitHub 이 이 값을 저장하지 않는다. 순서를 지킬 것)
3. 인증서 발급이 끝나면 **Enforce HTTPS** 체크

저장소에 `public/CNAME` 파일이 이미 들어 있어 빌드 결과에 `seoulmarkets.com` 이 따라간다.
DNS 만 맞으면 나머지는 자동이다.

## 4. 도메인이 바뀌면 고칠 곳

- `src/consts.ts` → `SITE_URL`
- `public/CNAME`
- `public/robots.txt` → Sitemap 줄
- `scripts/ping-indexnow.mjs` → `HOST`

바꾼 뒤 `npm run og` 로 OG 카드의 도메인 표기도 갱신한다.

## 5. Cloudtype — 보류

`.cloudtype/app.yaml` 과 `server.mjs` 를 남겨뒀다. 옮기고 싶어지면 그대로 쓸 수 있다.

중단 지점: 프로젝트·앱 정의까지 만들었으나 **리소스가 배정되지 않아 기동되지 않았다**
(`applied: null`, `cpu: 0`, `spot: true`). 요금제(메모리 구독) 결정이 필요하고,
2023년판 CLI 에는 리소스 배정 명령이 없어 콘솔에서만 가능하다.

참고로 하비 ₩6,600~/월이 커스텀 도메인 + 상시가동이 되는 최저 플랜이고,
klifemap 이 이미 0.5GB 를 쓰고 있어 메모리 추가 구독이 필요하다.
**지금 GitHub Pages 로 같은 결과를 무료로 얻고 있으므로 서두를 이유는 없다.**
