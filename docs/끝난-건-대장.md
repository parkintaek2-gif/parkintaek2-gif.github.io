사장님 지시(2026-08-29): 「계좌주 한번만 더 물어봐라? 4번인가 여기저기 묻고 있지.
**확실하게 다시는 묻지 않게 처리해**」

## ⛔ 왜 이 파일이 생겼나

같은 건을 여러 유닛이 **각자 발견해서 각자 사장님께 올립니다.** 사장님은 같은 말을
여러 번 하셔야 합니다. 2026-08-29 아침에 저(5번)가 토스 정산계좌 예금주를
「새로 찾았다」고 올렸는데, **8/27에 이미 재어 놓았고 그 뒤 처리된 건**이었습니다.
그리고 4번도 같은 것을 묻고 있었습니다.

## 🔴 올리기 전에 이 파일을 먼저 본다

```
grep -n "<핵심 낱말>" docs/끝난-건-대장.md
```
여기 있으면 **사장님께 안 올립니다.** 다시 물어야 할 까닭이 생겼으면
「끝났다고 적혀 있는데 지금 이렇습니다」 꼴로, **끝난 날짜를 대며** 묻습니다.

⚠ 이 파일은 두 저장소에 다 둡니다 — `dataeconomics` 와 `klifemap`.
   저장소가 갈려서 한쪽만 보고 「없다」고 하는 일이 실제로 있었습니다.

```

            상호를 바꾼 회사여서, 토스 정산계좌 예금주에 «옛 상호»가 남아 있었습니다
```

   반영이 늦은 것이지 새 문제가 아닙니다. 먼저 이 줄을 보고, 그래도 이상하면
   **사장님이 아니라 토스 상담(1544-7772)**에 묻습니다.
