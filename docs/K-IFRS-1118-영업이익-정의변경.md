# K-IFRS 제1118호 — 영업이익 정의가 바뀐다 (2027년 시행)

🔴 사장님 지시 (2026-10-14): 「**에스마켓츠에서 꼭 참조하도록**」
출처: 중앙일보 2026-10-14, 김도년 기자 「영업익 계산 바꾼 새 회계기준…27조 흑자가 661억 적자로」

---

## 왜 이것이 우리 일인가

SeoulMarkets는 **한국 기업 재무를 영문으로** 제공합니다. 영업이익(operating profit)은
우리가 파는 거의 모든 상품에 들어갑니다. 그 **정의 자체가 바뀝니다.**

재서 확인한 현재 상태 (2026-10-14):

```
영업이익을 쓰는 소스 파일        33개
영업이익을 쓰는 상품 페이지       8개 (financials · valuation · screener ·
                               largest-companies · company-credit · kospi-weights
                               · index · japan-listed-companies)
영업이익이 «실제로 찍히는» 페이지  2,530장   ← 빌드물에서 센 수입니다
K-IFRS 1118을 언급하는 곳        0개   ← 우리는 이 변경을 모르고 있었습니다
지분법 손익을 언급하는 곳         2개
외화환산손익을 언급하는 곳        1개
```

⛔ **우리가 지금 파는 영업이익 수치는 모두 「옛 기준」입니다.** 그런데 어디에도
그렇게 적혀 있지 않습니다. 2027년이 되면 같은 회사의 같은 해 수치가 달라집니다.

---

## 무엇이 바뀌는가 (기사에 적힌 사실만)

### ① 지분법손익이 영업이익에서 빠진다

지주회사는 자회사·관계회사가 번 몫(지분법이익)을 영업이익으로 잡아 왔습니다.
새 기준에서는 이것이 **투자손익(영업외손익)**으로 재분류됩니다.

```
                기존 영업이익      새 기준 영업이익     차이
SK스퀘어          27조 5,137억 흑자   661억 적자        흑자 → 적자
㈜LG              9,468억            3,473억          63% 감소
```
(중앙일보가 2026년 상반기 기준으로 계산한 값)

### ② 외화환산손익·환차손익이 영업이익에 들어온다

기존에는 영업외손익(금융손익)으로 처리하던 것이 **영업이익에 반영**됩니다.
달러로 대금을 받는 수출 대기업은 환율에 따라 영업이익이 요동칩니다.

```
                2026년 상반기 외환 관련 수익    비용
삼성전자          8조 9,903억                7조 5,439억
SK하이닉스        5조 804억                  2조 3,598억
```

### ③ 과거 재무제표도 재작성된다

금감원: 「과거 재무제표도 새 기준에 따라 재작성해야 하는 만큼, 기업들은 도입 준비를
체계적으로 수행해야 한다」

⛔ **이것이 우리에게 가장 큰 대목입니다.** 우리가 쌓아 둔 과거 수치가 기업이 다시
발표하는 수치와 어긋나게 됩니다.

### ④ 제도와의 엇박자

코스닥 「투자주의환기종목」은 5년 연속 영업적자면 지정됩니다. 회계 기준만 바뀌어
적자가 되는 기업이 생길 수 있습니다.

한국거래소: 「금융당국과 검토한 결과, 새 기준 적용으로 투자주의환기종목에 지정될
회사는 없었다」 — 다만 「그런 회사가 있다면, 그때는 제도 변경을 검토하게 될 것」

---

## 우리가 할 일

### 지금 (데이터 신뢰 문제)

```
① 영업이익을 내는 모든 상품 페이지에 기준을 밝힌다
   "Operating profit as reported under K-IFRS in effect before 1118 (effective 2027)"
   ⛔ 지금은 아무 표시가 없습니다. 2027년에 수치가 바뀌면 우리가 틀린 것처럼 보입니다.
② 지분법손익·외화손익을 따로 담고 있는지 확인한다
   담고 있지 않다면 새 기준 영업이익을 우리가 계산할 수 없습니다.
```

### 기사 소재 (우리만의 것)

⭐ **영문 매체가 이것을 다루지 않습니다.** 한국 회계 기준 변경이고, 영어로 설명된
자료가 거의 없습니다. SeoulMarkets의 자리가 정확히 여기입니다 —
「남들이 안 센 것을 세고, 못 재는 것은 못 잰다고 적는다」.

쓸 수 있는 것:
- 지주회사 몇 곳이 영업적자로 바뀌는가 (우리 재무 데이터로 계산 가능)
- 수출 대기업의 영업이익이 환율에 얼마나 흔들리게 되는가
- 5년 연속 영업적자 규정에 걸릴 위험이 있는 코스닥 기업은 몇 곳인가
  (거래소는 「없다」고 했습니다 — 우리가 세어서 대조할 수 있습니다)

⛔ 기사를 쓸 때는 **우리 계산임을 밝힙니다.** 기업이 발표한 수치가 아닙니다.
⛔ 중앙일보가 계산한 SK스퀘어·LG 수치는 **중앙일보 계산**이라고 출처를 답니다.

---

## 재서 확인한 것 (2026-10-14)

### ✅ 시행일 — 2027년 1월 1일 이후 개시 회계연도

조기적용이 허용됩니다. 소급 적용이므로 **비교 표시되는 과거 재무정보도 재작성**됩니다.
(출처: PwC 삼일회계법인 · 김앤장 · 중기이코노미 · 일간NTN)

기사에 없던 사실도 확인했습니다:

```
· 손익계산서의 모든 수익·비용이 «5개 범주»로 구분됩니다 —
  영업 · 투자 · 재무 · 법인세 · 중단영업
· 영업손익, 재무손익 및 법인세비용차감전손익 등 «중간합계» 표시가 신설·변경됩니다
· 경영진이 정의한 성과측정치(MPM) 공시가 새로 의무화됩니다
```

⭐ MPM 공시는 우리에게 기회입니다. 기업이 스스로 정의한 성과 지표를 공시해야 하므로,
**「회사가 말하는 이익」과 「기준이 말하는 이익」을 나란히 놓을 수 있게 됩니다.**

### 🔴 우리 데이터로는 새 기준 영업이익을 계산할 수 없습니다

`src/data/korea-financials-tape.json` 이 담고 있는 칸:

```
code · corp_code · name · name_en · market · sector · year · measured · basis
assets_krw · equity_krw · revenue_krw · operating_profit_krw · net_profit_krw
source_line_count
```

⛔ **지분법손익도, 외화환산손익도 없습니다.** 둘 다 없으면 새 기준 영업이익을
우리 손으로 계산할 수 없습니다 — 지금 할 수 있는 것은 「기준이 바뀐다」를 알리는
것까지입니다.

⇒ 하려면 **수집기를 늘려야 합니다.** DART 원자료에는 들어 있습니다
(지분법이익·외환차손익은 손익계산서 표준 계정입니다). 다만 그것은 별도 작업입니다.

