# 스타사주 영문 기사 — **자리만 파 둔 틀**

2번 지시(2026-08-21 10:2x): 「4번이 곧 넘길 **스타사주 한국어 감명 원고**를 받을 자리를
미리 만들어 두십시오. ⛔ 내용은 지어내지 마십시오. **자리만** 파 두는 것입니다」

🔴 **이 문서에는 결론이 하나도 없다.** 4번 원고가 오기 전에 쓴 수는 다 거짓이 된다.
   `«…»` 는 원고에서 채울 자리다. 채우기 전에는 절대 발행하지 않는다.

---

## Ⅰ. 왜 번역이 아니라 다시 쓰는가

사장님: 「번역이 아니라 **기사체로 바꿔서**」

```
한국어 감명   한 사람에게 말한다   「당신은 …」
영문 기사     읽는 사람에게 말한다  「이 사람의 사주를 이렇게 읽었고, 그 방법의 한계는 이것이다」
```
⛔ 감명문을 영어로 옮기면 **점괘가 우리 이름으로 나간다.** 우리는 그걸 못 한다 —
   우리가 이미 「띠 분포는 우연과 구분되지 않는다」(카이제곱 7.77 · 문턱 19.68)를 발행했다.
✅ 대신 **「klifemap 이 이 사람을 이렇게 읽었다」를 취재해 전한다.** 판정은 그쪽 제품이고
   우리는 그것을 **보도**한다. 그러면 우리 수와 안 부딪힌다.

---

## Ⅱ. 앞말(frontmatter) 틀 — 그대로 복사해 채운다

```yaml
title: "«스타 이름»«, 그룹이면 그룹명» — «감명이 짚은 한 가지»"
category: stars
dek: "«스타 이름» was born «생년월일». KLifeMap read «그 사람»'s chart and found «한 가지».
      The hour of birth is unknown, so this is a three-pillar reading, and we say what that
      leaves out."
pubDate: «내는 날»
dataAsOf: «감명을 돌린 날»T00:00:00+09:00
author: Newsroom
tags: ["saju", "stars", "klifemap", "method"]
pages: []            # ⛔ 우리 지면 자료를 안 썼으면 **빈 채로 둔다**
sources:
  - org: "KLifeMap"
    api: "«감명 판정기 이름/버전»"
    url: "https://klifemap.ai/«감명 주소»"
  - org: "Wikidata"
    api: "Date of birth (P569), CC0"
    url: "https://www.wikidata.org/"
crossChecks:
  - "«생년월일을 어디서 확인했는지 — 위키데이터 Q번호까지»"
  - "«감명을 몇 번 돌렸고 같은 답이 나왔는지»"
```

⚠ **제목에 이름이 없으면 안 나간다.** 사장님 상시 지시다 —
   `node scripts/check-kcw-star-names.mjs` 가 센다.
⚠ 제목 120자 · dek 240자를 넘으면 **빌드가 죽는다.** `check-kcw-frontmatter.mjs` 가 막는다.

## Ⅲ. 본문 틀 — 다섯 칸

### 1. 첫 문단 — 이름과 사실부터
```
«스타 이름» was born on «날짜» in «곳». That is the only thing in this article that is
not a reading.
```

### 2. 감명이 무엇을 말했나 — **인용이지 우리 주장이 아니다**
```
KLifeMap's saju engine reads that chart as «감명 요지».
«한두 문장 더 — 감명이 실제로 낸 말만»
```
⛔ 우리가 덧붙이지 않는다. 감명이 안 한 말을 문장 하나라도 보태면 그건 우리 점괘가 된다.

### 3. 🔴 한계 문장 — **이 칸이 비면 발행하지 않는다**
```
The hour of birth is not public, so this is a three-pillar reading rather than four.
Knowing the hour can change it. Public profiles carry dates and almost never hours,
which is why we cannot produce a full chart for anyone from the public record.

And a count we published ourselves: across 1,047 Korean actors who reached a Netflix
chart, the spread across the twelve zodiac years is indistinguishable from chance
(chi-square 7.77 against a threshold of 19.68). A birth year does not pick out who
becomes famous, and this article does not say otherwise.
```
⭐ 이 두 문단은 **거의 그대로 쓴다.** 편마다 새로 짓지 않는다 — 우리 수는 안 바뀐다.

### 4. 팬이 찾는 것 — 이름을 더 늘어놓는 자리
```
«스타 이름» shares a «띠» year with «같은 띠 스타 서넛».
The full room is at kculturewire.com/room/«띠 소문자».
```
⭐ 여기서 `/room/…` 과 `/star-signs` 로 이어 준다. 이미 있는 지면이다.

### 5. 끝 — 어디로 보내나
```
The reading itself is KLifeMap's. «주소»
What we can count — who shares a birth year with whom — is at
kculturewire.com/star-signs.
```
🖐 klifemap 으로 링크를 걸지는 **사장님 승인 대기**다. 승인 전에는 이 줄을 뺀다.

## Ⅳ. 낼 때 밟는 순서 (이미 도는 것들)

```
① node scripts/check-kcw-all.mjs      막는 검사 여섯
② npx astro build                     0건
③ 커밋은 파일로 — git commit -F       ⛔ 백틱이 셸에서 실행된다
④ 배포 → **실물을 직접 curl 로 재기**  자가 「나갔다」고 해도 안 믿는다
⑤ IndexNow 알림 → check-kcw-indexnow.mjs --적는다
```

## Ⅴ. 2번 확인 항목에 대한 답

```
① 틀 파일 경로     docs/스타사주-영문기사-틀.md  ← 이 파일
② 한계 문장 자리   Ⅲ-3 에 있다. 「출생 시간 미상 → 삼주」와 「시간을 알면 달라진다」
                  둘 다 문장으로 박아 뒀다. 그 칸이 비면 발행하지 않는다고 적었다
③ 원고 오면 몇 시간  **한 시간 안에 낼 수 있다.** 틀·검사·배포 절차가 다 서 있어서
                  채울 것은 이름·생년·감명 요지 세 가지뿐이다.
                  ⚠ 다만 klifemap 링크는 사장님 승인이 있어야 넣는다
```

⛔ 4번 원고를 기다리며 놀지 않는다. 틀은 여기까지고 다음은 콘텐트로 돌아간다.
