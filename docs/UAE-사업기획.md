## Ⅰ. 왜 UAE인가 — 상하이 대비 난도 비교

| | UAE | 상하이(중국 A주) |
|---|---|---|
| 시가총액 | 약 $1.02조 | 약 $17.5조 (8배 이상 크다) |
| 무료 데이터 경로 | **CMA(증권규제기관)** 오픈데이터 — 한국 금융위원회와 같은 조건(재사용·재배포·상업이용 허가, 출처표시만 요구) 확인됨 | SSE/SZSE·CNINFO 공시는 있으나 법 리스크 재검토·홍콩 경유 여부 논의 필요했음(현재는 "직접 가능"으로 판단이 정리됨) |
| 경쟁 | Mubasher(아랍어 주력, 속보형)뿐 — 우리 식 "가공형"은 없음 | **Caixin Global**(2009년 설립, Tencent 배경, 자본력 있음) — 강한 선점 경쟁자 |
| 법적 리스크 | 없음(미디어 규제는 범위에서 뺌, 데이터 자체는 저작권 문제만) | 데이터안전법 검토를 거쳤으나 결론적으로 낮은 리스크로 재판정 |
| 광고 단가 | CPM $5~20 — 걸프 최고 수준 | 별도 확인 필요(중국 CPM은 지역·검열 이슈로 변동 큼) |

**판정: UAE가 난도 낮음.** 시장은 작지만 데이터 경로가 깨끗하고(무료·확인됨), 경쟁자가 약하고,
법적 부담이 없다. 상하이는 시장이 압도적으로 크지만 Caixin이라는 자본력 있는 경쟁자가
이미 자리잡고 있어 후발주자로서 차별화 부담이 크다. **먼저 UAE로 검증하고, 되면 상하이는
그다음(Ⅴ 참고).**

## Ⅱ. 무엇을 팔 것인가 — 사람 데이터는 곁다리다

사장님 지시: 「비즈니스의 축에서 사람 관련은 차별화하는 곁다리일 뿐이다. 한국 시장 데이터
비즈니스와 마찬가지로」 — 즉 **핵심은 한국과 똑같다**: 정부/규제기관이 무료로 낸 시세·거시
데이터를 영문으로 가공해 낸다. 임원 재직기간·지분구조 같은 "사람 축" 콘텐츠는 나중에
차별화 요소로 얹는 것이지 처음부터 파는 물건이 아니다.

### 2-1. 1단계 — 핵심(한국과 같은 틀)

```
① 지수·거시     UAE 국가 지표(CBUAE 환율·통화정책·재정통계), DFM/ADX 종합지수 수준 데이터
② 상장기업 공시  ADX·DFM 공시포털(무료 공개) — 재무제표·공고를 영문 그대로 가공
③ CMA 오픈데이터 「Numbers and Statistics」·「UAE National Markets Summary Index」 —
                종목별 세부데이터 존재 여부는 ⚠ 아직 확인 안 됨(다음 단계에서 확인)
```

### 2-2. 2단계 — 차별화(곁다리, 나중)

한국 SeoulMarkets가 이미 하는 「임원 재직기간·성별격차·근속연수」류 가공을 UAE 공시자료에도
적용할 수 있는지는 **1단계가 자리잡은 뒤** 본다. 처음부터 이걸 팔려고 하지 않는다.

## Ⅲ. 어디에 놓는가 — 새 도메인 없음, SeoulMarkets 안에서

```
⛔ uaemarkets.com 같은 새 도메인 안 만든다 (사장님 지시)
✅ seoulmarkets.com 안에 넣는다
```

두 가지 구조를 놓고 5번과 확정해야 한다(`docs/세션간-메모.md` [6번→5번] 09-13 15:4x 에
이미 물어 둠) —

```
안 A. 기존 5개 카테고리(증시·외환·채권·커머디티·거시)에 국가 태그를 얹는다
      예: /equities/uae/... — 한국 기사와 같은 목록에 섞여 나온다
안 B. 국가별 섹션을 새로 둔다 — /uae 아래 5개 카테고리를 다시 둔다
      (WikiTip·100yearmap이 server.mjs SITE_PREFIX로 같은 서버에서 갈리는 것과 비슷한 구조,
      다만 도메인은 하나이므로 경로 접두사만 다르다)
```

「S마켓」이라는 이름을 사장님이 마음에 들어 하심 — **아직 확정은 아니다.** 브랜드를
"SeoulMarkets"에서 국가명을 뺀 더 넓은 이름("S마켓" 등)으로 바꿀지, 아니면 SeoulMarkets는
그대로 두고 그 «안»에 UAE 섹션을 얹을지는 사장님 확인이 더 필요하다(⚠ 확정 전 항목).

## Ⅳ. 실행 시점 — 서울마켓츠 개발 마무리 여부부터

사장님 지시: 「실행은 현재 서울마켓츠 개발이 마무리 안됐으면 마무리하고」

### 4-1. 확인 결과 — 2026-09-13 기준, 서울마켓츠(F7 API 사업) 핵심은 이미 마무리됨

```
✅ F7 API 일곱 엔드포인트(index-tape·people·mezzanine·ownership 등) 전부 라이브
✅ 데이터 품질 검사(3번) 완료 · npm test 171/176
✅ 애드센스 광고 단위 생성·연결(이 세션에서 처리) — 배포 진행 중
```

⚠ npm test 잔여 4건(check-wikitip-all 표약속·check-memo-marker 597·klifemap 애드센스
설명·페이팔)은 **SeoulMarkets 핵심 개발과 무관한 KCW·klifemap 항목**이라 이 판단에 영향 없음.

**결론 — UAE 착수를 막을 서울마켓츠 미완료 항목이 없다.** 다만 이건 "코드 착수"가 아니라
"기획"까지만이다 — 사장님 확인(도메인 구조 안 A/B, S마켓 브랜드 여부) 뒤에 실제 코드를 짠다.

### 4-2. 다음 단계 (사장님 확인 필요한 것 순서대로)

```
1. 도메인 구조 확정 (Ⅲ 안 A/B 중)
2. "S마켓" 브랜드 적용 여부 확정
3. CMA 오픈데이터 실제 종목별 세부데이터 존재 여부 확인(Bayanat.ae 직접 열람)
4. 위 셋이 정해지면 6번이 착수(예상 소요는 F7 만들 때와 비슷한 수준 — 데이터 파이프라인
   하나 뚫는 정도, 기존 SeoulMarkets 코드베이스를 그대로 재사용하므로 새로 짓는 부담은 적다)
```

## Ⅴ. 참고 — 상하이는 언제 볼 것인가

UAE로 이 틀(①규제기관 오픈데이터 확인 ②경쟁 확인 ③수요 확인 ④도메인 구조 결정 ⑤착수)이
검증되면, 상하이는 같은 틀을 그대로 돌리되 Caixin Global과의 차별화 지점(그들이 안 하는
축이 무엇인지)을 먼저 찾아야 한다 — 이건 UAE 검증 뒤로 미룬다.
