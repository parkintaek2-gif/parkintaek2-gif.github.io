## 쓰는 차례

```
경기 끝남 → 결과 확인 → 기사 → 순한글 검사 → 자체기사 데스킹 → 메일
```

| 건 | 무엇 | 언제 |
|---|---|---|
| 1~8 | 경기마다 1건. 결과와 «내용»을 상세하게 | 각 경기 종료 직후 |
| 9 | 일요일 2라운드 대진표 중심 일정 기사 | 8경기가 다 끝난 뒤 |

### 9번째 기사 — 일요일 일정
스위스 스테이지는 **같은 성적끼리 다시 붙는다.** 1라운드가 끝나면 1승 팀끼리,
0승 팀끼리 2라운드를 치른다. 그래서 8경기 결과가 나와야 일요일 대진이 정해진다.
⇒ 9번째 기사는 **8경기가 다 끝난 뒤**에 쓴다. 미리 못 쓴다.
