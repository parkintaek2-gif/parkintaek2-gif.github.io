### ★ 오늘 가장 큰 것 — 증권사 리포트 18년치가 남아 있다

신진호 대표가 6년 전 외주로 만들었다는 그 프로그램을 저녁에 직접 만들었다.
그리고 만들다 알게 된 것이 더 크다.

```
   1쪽  2026-07-31
 800쪽  2024-01-24
1500쪽  2019-05-10
3000쪽  2007-12-14   ← 끝
```

**약 9만 건, 18년치 목표주가 이력이 소급 가능하다.**
지수 사업이 요구하는 3~5년 백테스트를 훨씬 넘는다.
관세청 잠정치와 성질이 다르다 — 저쪽은 오늘 안 받으면 영영 없지만,
**이쪽은 지금 한 번 받으면 18년이 통째로 들어온다.**

파는 것은 리포트가 아니라 **「목표주가가 맞았는가」**다.
어느 증권사가 가장 근접했고 어디가 크게 빗나갔는지 — 국내에도 영문으로도 파는 곳이 없다.

### ⚠ 오늘 내가 잘못했던 것

1. **사진 라이선스를 「위험」으로 판정했다.**
   변호사 블로그의 일반 법리만 보고 배급사·방송사 공식 배포물을 「조건부/금지」로 분류했다.
   **한국 언론계 실제 관행을 보지 않았다.** 사장님 지적으로 전면 개정.

2. **샘플 기사 5건이 라이브에 나가 있는 것을 늦게 발견했다.**
   `draft:false` 라 사이트맵·RSS·**내가 만든 파트너 피드**에까지 들어가 있었다.
   지어낸 수치에 금융위 실제 API 주소가 붙고 티커가 삼성전자·SK하이닉스였다.
   MSN 에 그대로 낼 뻔했다.

3. **`/api` 페이지에 없는 npm 패키지를 설치하라고 적었다.**
   바로 아래 문단에 「문서와 실물이 다르면 첫 호출에서 들통난다」고 써 놓고 같은 짓을 했다.

4. **`ctype ls -o json` 으로 klifemap 환경변수를 두 번 노출시켰다.**
   R2·API 키가 화면에 그대로 찍혔다. **키 교체를 권한다.**

5. **수집기가 import 만 해도 실행되게 짰다.**
   상수 하나 가져다 쓰려다 수집기가 통째로 돌았다. 키가 있었으면 엉뚱한 호출이 나갔다.

> 1·3번은 **확인 전에 단정한 것**이고, 2·4·5번은 **만들면서 안 본 것**이다.
> 앞의 것은 사장님이 잡아 주셨고 뒤의 것은 검사를 붙여서 잡았다.

## ③ 매출 — 500억으로 상향

| 수익원 | 300억안 | **500억안** |
|---|---|---|
| 데이터 라이선스·API | 200억 | 220억 |
| **지수 라이선싱** | — | **150억** |
| 직접광고 + 프로그래매틱 | 50억 | 60억 |
| 커머스·제휴 | 30억 | 40억 |
| 신디케이션 배분 | 20억 | 30억 |

**추가 200억 중 150억이 지수다.** 지수 라이선스료는 95% 이상이 AUM 비례이고
그중 약 60%가 마크업이다. **AUM 이 늘어도 우리가 할 일이 없는 유일한 매출원**이다.

⚠ 다만 가장 늦게 온다. 운용사가 **3~5년 백테스트**를 요구한다.
그래서 오늘 리포트 18년치를 확보한 것이 크다.

**300억 도달은 2031~32년**으로 잡았다. 2028년에 300억을 적는 계획서는 신뢰를 깎는다.
