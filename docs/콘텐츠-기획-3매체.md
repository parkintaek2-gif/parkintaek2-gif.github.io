| 매체 | 남들이 하는 것 | **우리가 하는 것** |
|---|---|---|
| SeoulMarkets | 애널리스트가 목표주가를 말한다 | **맞았는지 센다** |

세 매체 × 다국어를 손으로 쓰면 못 한다.
**데이터 → 기사 초안 → 검토 → 발행**이 파이프라인이어야 하고,
사람이 하는 것은 **검토와 판단**뿐이다.

# 1. SeoulMarkets — 금융

## 지금 손에 있는 것

```
리서치 아카이브   66,071건 · 2007~2026 (연속 구간 2014~) · 20년
목표주가          55,709건 (84.3%)
기관              44곳 · 종목 2,782개
종목코드 대응     86,925건
```

## ⭐ 바로 쓸 수 있는 기사 — **검증 끝난 것부터**

### ① 매도 의견은 흩어져 나오지 않는다. **사건에 몰려 나온다** (검증 완료)

20년 전체 매도 **89건**. 그런데 **4개월이 그중 26건(29%)** 이다.

| 시기 | 건수 | 종목 |
|---|---:|---|
| **2015-08** | **11** | NHN엔터·한진해운·화인베스틸·에이블씨엔씨·게임빌·금호석유·삼성엔지니어링·금호타이어 등 |
| **2015-10** | **7** | 삼성엔지니어링×2 · **대우조선해양×2** · 금호석유 · 한전기술 · 넥센타이어 |
| 2020-08 | 4 | 제주항공 · 넷마블 · 이글루시큐리티 · 엠아이텍 |
| 2023-08 | 4 | 카카오뱅크 · **에코프로비엠 · 에코프로** · 제주항공 |

**2015년 하반기에 조선·건설이 몰려 있다.** 그해 대우조선해양·삼성엔지니어링에서
대규모 손실이 드러난 시기와 겹친다.

> **기사의 축** — 「매도 의견은 예측이 아니라 사후 확인에 가깝다.」
> ⚠ 다만 **인과를 단정하지 않는다.** 우리가 가진 것은 리포트 날짜뿐이고,
> 손실 공시와의 선후는 **공시 원본으로 따로 확인해야** 쓴다.

### ② 애널리스트가 숫자 대기를 그만두던 시기가 있었다 (검증 완료)

목표주가를 제시한 리포트의 비율.

| 연도 | 전체 | **증권사만** | 비증권 기관 |
|---|---:|---:|---:|
| 2014 | 99.8% | **99.8%** | 0건 |
| 2018 | 90.5% | **90.5%** | 0건 |
| **2021** | **65.9%** | **83.9%** | 515건 |
| 2026 | 82.7% | **88.3%** | 379건 |

**겉보기 하락(99.8%→65.9%)의 절반 이상은 비증권 기관(IR협의회·신용평가사) 유입 탓이다.**
그들은 원래 목표주가를 안 낸다.

**그런데 증권사만 봐도 99.8% → 83.9% 로 실제 하락이 있다.**
2021년 기준 **애널리스트 여섯 중 하나가 숫자 없이 리포트를 냈다.**

> **기사의 축** — 「검증을 피하는 가장 쉬운 방법은 숫자를 안 대는 것이다.」
> **검증 과정 자체가 기사의 절반이다.** 겉보기 숫자가 더 극적인데 그 절반이
> 다른 이유였다는 것을 보여주는 게 이 매체의 성격이다.

### ③ 리포트가 몰리는 종목 / 아무도 안 보는 종목 (계산만 하면 됨)

종목 2,782개 중 커버리지 분포. **한국 증시에 「아무도 안 쓰는 회사」가 몇 개인가.**

### ④ 조회수가 말하는 것 (계산만 하면 됨)

평균 조회수 — 2018년 2,001 → **2021년 9,918** → 2026년 11,272.
**개인투자자가 리서치를 읽기 시작한 시점이 데이터에 찍혀 있다.**

## 주가가 붙어야 되는 것 — **본편**

| 기사 | 필요한 것 |
|---|---|
| **목표주가는 얼마나 틀렸나** | 종목별 주가 시계열 |
| **적중률 상위 애널리스트** (= 훈장) | 〃 |
| 목표주가와 실제 주가의 괴리 추이 | 〃 |

**이게 상품이자 기사다.** 공공데이터포털 시세(T+1·재배포 가능) 활용신청이 1순위.

## 발행 리듬

```
주 2~3건   데이터 기사 (위 목록에서)
월 1건     정기 집계본 → 국내 경제신문에 무료 배포
분기 1건   특집 (적중률 연간 집계 등)
```

# 2. WikiTip — 한류 + 스포츠

## 성격이 다르다 — **독자가 많고 단가가 낮다**

동남아 영어권이 1차 시장(필리핀·말레이시아·싱가포르 + 미국 팬덤),
이어서 인도네시아어 → 베트남어 → 태국어.

## ⭐ 스포츠는 **e스포츠로 간다** (2026-08-02 조사 결과)

> 사장님: 「위키팁에 스포츠 데이터도 가공해서 콘텐트로 제공하자」

조사해 보니 **전통 스포츠는 우리가 손댈 자리가 아니다.**

| | 판정 | 왜 |
|---|---|---|
| KBO · K리그 | **✗** | 리그가 데이터를 독점 관리한다. 세계적으로 Sportradar·Genius Sports 가 독점 계약으로 판다. **우리 자리가 없고 긁으면 KRX 를 안 긁는 것과 같은 이유로 걸린다** |
| K리그 아세안쿼터 각도 | **✗** | **이미 지나갔다.** 2025년 아시아쿼터 폐지, **2026년 외국인 선수 제한 자체가 폐지** |
| **e스포츠 (LoL 등)** | **○** | **Riot 공식 개발자 API 가 있고 무료다** |

### 왜 e스포츠인가 — 한류와 **같은 독자**다

```
K리그    동남아 관심 낮다.  한류 독자와 겹치지 않는다
e스포츠   T1·페이커가 동남아에서 아이돌급이다.  같은 사람이 본다
```

**「한류 매체에 스포츠」가 억지가 아니라 e스포츠면 자연스럽다.**

### Riot API 조건 — 우리 모델과 맞는다

```
개인·비상업     자유
상업            신청 후 승인 필요
조건            무료 이용 층을 반드시 둘 것 (광고 포함 가능)
                과금하려면 「변형된(transformative)」 콘텐츠여야 함
```

**무료 도구로 유입, 광고로 수익 — 이미 WikiTip 모델이다.**
「변형」 요건도 맞는다. 우리는 경기 데이터를 그대로 파는 게 아니라 **집계·분석**한다.

> ⚠ **상업 승인 신청이 먼저다.** 승인 전에 광고를 붙이면 약관 위반이다.

### 낼 수 있는 콘텐츠

- **한국 선수·팀의 국제 대회 성적 집계** — 「한국이 왜 강한가」를 숫자로
- 동남아 팬이 궁금해할 각도: **자국 선수의 한국 리그 기록**
- 메타 변화 추이 (챔피언 픽·밴)
- e스포츠 ↔ 아이돌 팬덤의 겹침 — **WikiTip 의 두 축이 만나는 자리**

## 한류 본편 — 공공데이터로 되는 것

```
관세청 품목별 수출   8523 음반 · 3304 화장품 · 1902 라면 · 2103 소스류 · 9201 악기
→ 「어느 나라에 K-pop 음반이 얼마나 나갔나」  ← 아무도 안 세는 숫자
```

**⚠ 차트·팬덤 데이터(한터·서클차트)는 수집하지 않는다.** 재배포 근거가 없다.

## 발행 리듬

```
주 5건 이상   자동 발행 (트래픽이 곧 매출이라 양이 필요하다)
월 1건        수출 데이터 특집
```

# 3. 백년지도 — 교육

## 콘텐츠가 곧 유통이다

**영업도 인맥도 오프라인도 없다.** 들어오는 문이 검색 하나뿐이라,
**콘텐츠가 마케팅의 전부**다.

## ⭐ 무료 도구가 먼저다 — 기사보다

| 순서 | 무엇 | 왜 |
|---|---|---|
| **1** | **「이 학과 나오면 실제로 어떻게 됐나」 조회** | 회원가입 없이. **교사가 수업에 쓴다** |
| 2 | 그 데이터로 쓴 기사 | 검색 유입 |
| 3 | 무료 진단 1종 | 수요 검증 |

**도구가 기사보다 먼저인 이유** — 학부모는 「백년지도」를 검색하지 않는다.
**「○○학과 취업률」을 검색한다.**

## 기사 소재 — 대학알리미 데이터로

- **「취업률 90%인데 1년 뒤 남아 있는 비율은 절반인 학과들」** ← 유지취업률의 힘
- 학과별 중도탈락률 — **입학하고 그만두는 비율**
- 계열별 임금 분포 — 「그래서 얼마 버나」
- 사교육비 지출과 진학 결과의 관계

**전부 공공데이터이고 공공누리 제1유형이라 라이선스 위험이 없다.**

## ⚠ 이 매체만의 금지선

```
✗ 폐기된 뇌과학 통설 (좌뇌우뇌 · 학습유형별 수업)
✗ 시점 예측 (「언제 붙는다」)
✗ 단정 (「이 아이는 이과다」)
✗ 학원 권유 — 우리 자리를 버리는 것
```

기질 축(명리 3종) 문장은 **반드시 「먼저 시험해 보자」로 끝난다.**

## 다국어 — 한 → 일 → 화교권

기질 축은 그대로 쓰고 **결과 데이터 축만 나라별로 갈아 끼운다.**
