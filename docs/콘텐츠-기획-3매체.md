# 1. SeoulMarkets — 금융

> ⚠ **데이터 소스와 이벤트 캘린더는 `docs/데이터-지도.md` 가 원본이다.**
> 여기서 되풀이하지 않는다. 이 문서는 **그 데이터로 무엇을 쓰는가**만 다룬다.
> (처음에 이 절을 리서치 아카이브만 놓고 썼다가 고쳤다 — 사장님 지적.
>  SeoulMarkets 는 다섯 카테고리이고 아카이브는 그중 증시 하나의 한 갈래다.)

## 기사가 두 종류다 — 이 구분이 편성의 전부다

| | **캘린더 기사** | **아카이브 기사** |
|---|---|---|
| 무엇 | FOMC · 금통위 · CPI · 실적 · 공시 | 우리 아카이브로만 되는 것 |
| 언제 나올지 | **안다.** 미리 편성한다 | 우리가 정한다 |
| 남도 쓰나 | **쓴다.** 속도·정확도로 겨룬다 | **아무도 못 쓴다** |
| 역할 | **발행량을 채운다** | **브랜드를 만든다** |
| 비중 | 주 5~7건 | 주 2~3건 |

**캘린더가 매체를 굴리고 아카이브가 매체를 알린다.** 둘 다 있어야 한다 —
캘린더만 있으면 남과 같아지고, 아카이브만 있으면 발행이 끊긴다.

## B. 아카이브 기사 — **우리만 쓸 수 있는 것**

지금 손에 있는 것: **리서치 66,071건 · 2007~2026 · 목표주가 55,709건 · 기관 44곳 · 종목 2,782개**

### ⭐ 검증 끝나 오늘 쓸 수 있는 것

**① 매도 의견은 사건에 몰려 나온다**
20년 전체 89건인데 **4개월이 26건(29%)**. 2015-08 에 11건, 2015-10 에 7건 —
대우조선해양·삼성엔지니어링이 그 안에 있다.
⚠ 인과는 단정하지 않는다. 손실 공시와의 선후는 **공시 원본으로 따로 확인**해야 쓴다.

**② 애널리스트가 숫자 대기를 그만두던 시기**
목표주가 제시율 2014년 99.8% → 2021년 65.9%.
확인해 보니 하락의 절반 이상이 **비증권 기관(IR협의회·신용평가사) 유입** 탓이었고,
증권사만 보면 99.8% → 83.9%. **검증 과정 자체가 기사의 절반이다.**

### 계산만 하면 되는 것

- **커버리지 분포** — 종목 2,782개 중 아무도 안 쓰는 회사가 몇 개인가
- **조회수 추이** — 2018년 평균 2,001 → 2021년 9,918 → 2026년 11,272.
  **개인투자자가 리서치를 읽기 시작한 시점이 데이터에 찍혀 있다**
- 기관별 발행량·커버 종목 수 변화

### 주가가 붙어야 되는 **본편**

| 기사 | 상품으로도 팔린다 |
|---|---|
| **목표주가는 얼마나 틀렸나** | 적중률 데이터 |
| **적중률 상위 애널리스트** (= 훈장) | 국내 경제신문 무료 배포본 |
| 목표주가와 실제 주가의 괴리 추이 | |

**공공데이터포털 시세(15094808, T+1·재배포 가능) 활용신청이 1순위다.**

### 앞으로 쌓일 아카이브

| 무엇 | 언제부터 | 무엇이 되나 |
|---|---|---|
| **DART 공시** | 붙이는 즉시 | 실시간 + 이력. **소급이 안 되니 오늘 시작한다** |

# 2. WikiTip — 한류 + 스포츠

## 성격이 다르다 — **독자가 많고 단가가 낮다**

동남아 영어권이 1차 시장(필리핀·말레이시아·싱가포르 + 미국 팬덤),
이어서 인도네시아어 → 베트남어 → 태국어.

## ⭐ 스포츠는 **e스포츠로 간다** (2026-08-02 조사 결과)

> 사장님: 「위키팁에 스포츠 데이터도 가공해서 콘텐트로 제공하자」

조사해 보니 **전통 스포츠는 우리가 손댈 자리가 아니다.**

| | 판정 | 왜 |
|---|---|---|
| KBO · K리그 | **✗** | 리그가 데이터를 독점 관리한다. 세계적으로 Sportradar·Genius Sports 가 독점 계약으로 판다. **우리 자리가 없고 긁으면 KRX 를 안 긁는 것과 같은 이유로 걸린다** |
| K리그 아세안쿼터 각도 | **✗** | **이미 지나갔다.** 2025년 아시아쿼터 폐지, **2026년 외국인 선수 제한 자체가 폐지** |
| **e스포츠 (LoL 등)** | **○** | **Riot 공식 개발자 API 가 있고 무료다** |

### 왜 e스포츠인가 — 한류와 **같은 독자**다

```
K리그    동남아 관심 낮다.  한류 독자와 겹치지 않는다
e스포츠   T1·페이커가 동남아에서 아이돌급이다.  같은 사람이 본다
```

**「한류 매체에 스포츠」가 억지가 아니라 e스포츠면 자연스럽다.**

### Riot API 조건 — 우리 모델과 맞는다

```
개인·비상업     자유
상업            신청 후 승인 필요
조건            무료 이용 층을 반드시 둘 것 (광고 포함 가능)
                과금하려면 「변형된(transformative)」 콘텐츠여야 함
```

**무료 도구로 유입, 광고로 수익 — 이미 WikiTip 모델이다.**
「변형」 요건도 맞는다. 우리는 경기 데이터를 그대로 파는 게 아니라 **집계·분석**한다.

> ⚠ **상업 승인 신청이 먼저다.** 승인 전에 광고를 붙이면 약관 위반이다.

## ⚠ 정정 — **프로 e스포츠 경기 데이터는 개발자 API 에 없다** (2026-08-02 23:0x KST 실측)

위 「낼 수 있는 콘텐츠」는 **Riot 공식 API 에 프로 경기 데이터가 있다는 전제**로 적혀
있었다. 그 전제를 아무도 확인하지 않았다. **키를 받아 직접 찔러 봤더니 없다.**

`scripts/probe-riot.mjs` · 기록 `archive/probe/riot-2026-08-02.json`

```
✕ 403  /lol/esports/v1/leagues              프로 리그·경기 — 개발자 API 에 없다
✕ 403  /lol/tournament-stub/v5/providers    토너먼트 — Production 승인 필요
✕ 403  /lol/spectator/v5/featured-games     실시간 픽·밴 — Personal Key 로 안 열린다
```

**따라서 「한국 선수·팀의 국제 대회 성적 집계」와 「메타 픽·밴 추이」는 지금 못 만든다.**
Production 승인을 받아도 esports 는 애초에 개발자 API 의 범위가 아니다.

> ⚠ **`esports-api.lolesports.com` 은 쓰지 않는다.** lolesports.com 이 내부적으로 쓰는
> 문서화되지 않은 주소다. **접근은 되지만 그건 「되니까 쓴다」이고, 우리가 KRX 를
> 안 긁는 것과 같은 이유로 안 쓴다.** 오늘 관세청에서 배운 것과 같다 —
> **같은 데이터라도 경로에 따라 라이선스가 다르다.**

### ✅ 실제로 열린 것 — 여기서 콘텐츠를 짠다

15/19 가 200 이었다. **랭크 사다리가 전 지역 열린다는 것이 핵심이다.**

```
✅ 랭크 사다리   챌린저·그랜드마스터   KR · NA · EUW · SG(동남아) · VN(베트남) · JP
✅ TFT          챌린저 KR
✅ Clash        아마추어 토너먼트 KR (배열 2건)
✅ 발로란트      콘텐츠(맵·요원·스킨) AP
✅ Data Dragon  키 불필요 · 챔피언 233개 · 한국어/영어/베트남어 등 다국어 · 버전 496개
```

### 그래서 낼 수 있는 콘텐츠 — **다시 짠 것**

| 콘텐츠 | 재료 | 왜 되는가 |
|---|---|---|
| **「한국이 왜 강한가」를 랭크 사다리로** | 지역별 챌린저/GM 분포·LP 구간 | 프로 경기가 없어도 **모집단 수준**은 잴 수 있다. 오히려 아무도 안 세는 숫자다 |
| **동남아 독자의 각도 — 우리 서버 vs 한국 서버** | SG·VN vs KR 사다리 비교 | 「자국 선수의 한국 리그 기록」의 실현 가능한 대체물 |
| 챔피언 사전 다국어 | Data Dragon | **키도 승인도 필요 없다.** 지금 당장 된다 |
| 패치별 챔피언 변화 | Data Dragon 버전 496개 | 과거 버전이 다 남아 있어 **소급이 된다** |

**「한국이 왜 강한가」라는 각도 자체는 살아 있다.** 재료가 프로 경기에서
랭크 사다리로 바뀔 뿐이고, 우리 원칙(그대로 파는 게 아니라 집계·분석)에는 더 맞는다.

### 지금 순서

```
1. Data Dragon 부터 — 키·승인 없이 되고 소급도 된다     ← 막힌 게 없다
2. 랭크 사다리 수집기 — Personal Key 로 지금 검증한다    ← 키가 24시간이라 오늘 안에
3. Production 승인 신청 — 광고를 붙이려면 이게 먼저다     ← 미신청 상태
```

⚠ **승인 전에 광고를 붙이면 약관 위반이다.** 수집·검증은 비상업이라 지금 해도 된다.
Personal Key 는 24시간마다 `developer.riotgames.com` 에서 REGENERATE 해야 한다.

- e스포츠 ↔ 아이돌 팬덤의 겹침 — **WikiTip 의 두 축이 만나는 자리**
  (이건 우리 자체 데이터라 Riot 과 무관하게 된다)

# 3. 백년지도 — 교육

## 콘텐츠가 곧 유통이다

**영업도 인맥도 오프라인도 없다.** 들어오는 문이 검색 하나뿐이라,
**콘텐츠가 마케팅의 전부**다.

## ⭐ 무료 도구가 먼저다 — 기사보다

| 순서 | 무엇 | 왜 |
|---|---|---|
| **1** | **「이 학과 나오면 실제로 어떻게 됐나」 조회** | 회원가입 없이. **교사가 수업에 쓴다** |
| 2 | 그 데이터로 쓴 기사 | 검색 유입 |
| 3 | 무료 진단 1종 | 수요 검증 |

**도구가 기사보다 먼저인 이유** — 학부모는 「백년지도」를 검색하지 않는다.
**「○○학과 취업률」을 검색한다.**

## 기사 소재 — 대학알리미 데이터로

- **「취업률 90%인데 1년 뒤 남아 있는 비율은 절반인 학과들」** ← 유지취업률의 힘
- 학과별 중도탈락률 — **입학하고 그만두는 비율**
- 계열별 임금 분포 — 「그래서 얼마 버나」
- 사교육비 지출과 진학 결과의 관계

**전부 공공데이터이고 공공누리 제1유형이라 라이선스 위험이 없다.**

```
✗ 폐기된 뇌과학 통설 (좌뇌우뇌 · 학습유형별 수업)

✗ 단정 (「이 아이는 이과다」)

```
