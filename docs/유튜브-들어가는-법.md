## 5. 내 채널 ID 를 모를 때

```
① https://www.youtube.com/@<핸들>  을 연다   (예: youtube.com/@SeoulMarkets)
② 그 지면 소스에서 externalId 를 읽는다
   curl -s "https://www.youtube.com/@SeoulMarkets" | grep -oE '"externalId":"UC[A-Za-z0-9_-]+"'
③ studio.youtube.com/channel/<그 ID> 로 간다
```
또는 스튜디오 왼쪽 위 **「내 채널」**을 눌러 목록에서 고릅니다.
