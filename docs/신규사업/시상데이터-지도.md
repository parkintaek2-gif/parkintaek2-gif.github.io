## 0. 왜 이게 앞의 「평판 직종」보다 나은가

앞 문서(`평판직종-데이터지도.md`)에서 성립 조건 셋을 세웠다.
**시상은 그 셋이 저절로 다 만족된다.**

| | 조건 | 평판 직종 | **시상** |
|---|---|---|---|
| ① | 이름이 공개되는가 | 의사는 안 됨 | ✅ **상은 공표가 목적이다.** 안 알리면 상이 아니다 |
| ② | 명확한 정답이 있는가 | 변호사는 흐림 | ✅ **받았다/못 받았다.** 심사위원회가 이미 판정을 끝냈다 |
| ③ | 대조할 데이터 | 따로 찾아야 함 | ✅ **선정 사유가 정답과 함께 나온다** |

**그래서 우리가 적중률을 계산할 필요조차 없다. 남이 이미 판정했다.**
우리가 하는 건 **집계와 순위화**다.

### ⭐ 그리고 그걸 아무도 안 하고 있다

개별 수상은 뉴스가 안 된다 — 「A기자가 이달의 기자상 받았다」는 그 언론사만 쓴다.
그런데 **누적 순위는 어디에도 없다.**

```
「최근 10년 이달의 기자상, 언론사별 수상 순위」        ← 없다
「베스트 애널리스트 수상자의 실제 목표주가 적중률」      ← 없다. **우리만 만들 수 있다**
「적극행정 우수공무원, 부처별·사유별 분포」            ← 없다
```

각각은 다 공개돼 있다. **묶은 사람이 없을 뿐이다.** 그게 우리 자리다.

## 3. 실물 지면을 열어 본 결과

robots 통과는 시작일 뿐이다. **「왜 받았나」가 텍스트로 있어야 데이터다.**

### 3-1. 이달의 기자상 — ⚠ **원하는 지면이 딱 막혀 있다**

```
🚫 /mybbs/bbs.html    회차별 **선정 공고** — 전 부문이 한 장에 정리돼 있다
✅ /news/article.html 수상작 **한 편씩**
✅ /news/section1.html 이달의 기자상 목록 (p_num 최대 2020)
```

막힌 쪽에 정확히 우리가 원하는 게 있다. 실제 내용은 이랬다.

> 심사위원회(위원장 김춘식 한국외대 교수)는 **제430회**(2026년 6월) 이달의 기자상
> 수상작으로 **연합뉴스**의 「6·3 지방선거 투표용지 부족 사태」 보도 등 **7편**을 선정했다.
> ■ 취재보도1부문 △「…」 연합뉴스 이의진·최윤선·양수연·윤민혁·전성훈 기자 …

**회차·부문·언론사·기자명이 한 장에 다 있다.** 제430회 = 월 1회면 **약 36년치**다.

⚠ **우회하지 않는다.** `/mybbs/` 가 막혔으면 안 쓴다. 할 일은 둘.
1. 열린 `/news/article.html` 만으로 같은 표를 만들 수 있는지 — 목록 지면에서 링크
   추출이 안 됐다(0개). 지면 구조를 더 본다
2. **기자협회에 직접 문의한다** — 우리는 언론사다. 데이터 제공을 요청할 수 있는 위치다

### 3-2. 적극행정 — ✅ **열려 있고 심사평이 있다**

인사혁신처 `mpm.go.kr` 의 적극행정 지면에 **심사 관련 서술이 확인**됐다.
공공누리 표기가 있어 재배포 근거도 있다. **네 갈래 중 가장 먼저 될 축이다.**

### 3-3. 변협 우수법관 — ⚠ 원본이 막혔다

```
✅ 대한변협      「대한변협, 우수변호사 3인 선정」 보도자료 확인
🚫 서울변호사회   법관평가 원본. Disallow: /
```

⚠ 그리고 **여기는 관행을 반드시 지켜야 한다.**
법관평가는 **우수법관만 실명, 하위 평가는 익명**이 오랜 관행이다.
「같이 일하고 싶은 판사」는 실명이 나오지만 그 반대는 나오지 않는다.
**우리도 그 선을 그대로 지킨다.** 긍정만 실명으로 쓴다.

### 3-4. 애널리스트 — ⭐ **여기가 우리 것이다**

```
한경 베스트 애널리스트 · 매경 증권인상  →  수상자 + **소속 증권사**
우리 아카이브 66,105건               →  그 사람이 실제로 낸 목표주가
적중률 엔진 (이미 만들어 뒀다)          →  **맞췄나**
```

**「상 받은 애널리스트가 실제로 맞췄는가」** — 이건 세상에 없는 기사다.
그리고 **우리만 만들 수 있다.** 남의 데이터가 아니라 우리가 1년 모은 것이기 때문이다.
사장님이 물으신 **「애널 소속 증권사 순위」**도 여기서 바로 나온다.

## 4. 두 갈래로 쓴다 — 사장님이 정하신 대로

> 「**데이터 제공(백년지도) + 언론 보도(매체는 미정)** 이리 하면 되겠다」

### ① 백년지도 = 데이터 제공 · **「대학 이후」**

> 「**긍, 부정 다 공개돼야 대학 이후를 더 알차게 만듦**」
> 「**대학 이후 = 백년지도의 모토**」

여기가 핵심이다. 백년지도는 「무슨 과 가면 어디 취업하나」에서 끝나지 않는다.
**그 직업을 갖고 난 뒤 삶이 어떻게 흘러가는가**가 모토다. 그 답이 이 두 축이다.

```
긍정(시상)   그 직업에서 **무엇을 하면 인정받는가**
             적극행정 우수공무원은 무슨 일을 했나
             이달의 기자상은 어떤 취재가 받나
             베스트 애널은 무엇으로 뽑히나

부정(징계)   그 직업에서 **무엇을 하면 잘리는가**
             공무원 징계 사유 분포 — 금품·품위·직무태만
             기관별 발생 빈도
```

**둘 다 있어야 직업의 실상이 보인다.** 상만 보면 미화이고, 징계만 보면 험담이다.
그리고 **평가가 아니라 사실**이라 반발할 대상이 없다. 백년지도에 안전하게 들어간다.

### ② 언론 보도 = 순위와 사유

「누가 많이 받았나」다. **집계가 곧 기사다.**

```
✅ 한다   언론사별 기자상 순위 · 증권사별 애널 수상 순위 · 부처별 적극행정 순위
          — 개인이 아니라 **조직 단위**라 명예 문제가 작다
⚠ 조심    개인 실명은 **수상자만.** 못 받은 사람 이름은 쓰지 않는다
          「받은 사람 목록」과 「안 받은 사람 목록」은 완전히 다른 물건이다
```

⚠ **매체는 미정**이다. SeoulMarkets 는 영문 금융 매체라 국내 기자상·법관은 안 맞는다.
애널리스트 축만 SeoulMarkets 에 바로 들어간다. 나머지는 매체가 정해질 때까지 **데이터만 쌓는다.**

## 7. ⚠ 옥석 — **상 자체가 상품인 시장이 있다** (2026-08-04 08:2x KST)

> 「한국능률협회, 언론사(**서울의 유명 언론사만**)들이 **상을 만들어서 돈을 벌지.**
>  그래서 관련 기사에 **본사 기자가 없으면 광고라고 보면 됨.** 그런 건 잘 가려서 활용.
>  **광고성이라도 좋은 상도 있거든**」 · 「**옥석을 가려야 함**」

내가 몰랐던 것이고 **추정으로는 절대 못 알아냈을 것**이다. 앞의 모든 계산이 여기서 바뀐다.

### 7-1. 앞 절의 전제가 하나 무너졌다

3절에서 「심사위원회가 이미 판정을 끝냈다」를 조건 ②의 근거로 삼았다.
**돈을 받고 주는 상은 판정이 아니다.** 그걸 그대로 집계하면 우리가 광고를 유통시키는 게 된다.

그래서 **집계 전에 상을 먼저 판정해야 한다.** 단계가 하나 늘었다.

```
(원래)  수상 데이터 → 집계 → 순위
(고침)  수상 데이터 → **상의 등급 판정** → 집계 → 순위
```

### 7-2. ⭐ 사장님이 주신 판별법은 **기계로 돌아간다**

> 「**관련 기사에 본사 기자가 없으면 광고라고 보면 됨**」

바이라인 한 줄이면 갈린다. 이건 코드로 짤 수 있다.

```
그 언론사가 자기 상을 보도했는데
  ├ 바이라인에 **자사 소속 기자명**이 있다        → 취재해서 썼다.  기사
  └ 바이라인이 없거나 「○○부」·「보도자료」뿐    → 받아서 실었다.  ⚠ 광고 신호
```

우리는 이미 **66,105건 아카이브에서 기자·애널 이름을 뽑아 쓰고 있다.**
같은 파서를 그대로 쓴다. **새로 만들 게 없다.**

### 7-3. 지표를 합산해 등급을 매긴다 — 이분법이 아니다

> 「**광고성이라도 좋은 상도 있거든**」

그래서 ○/✕ 가 아니라 **점수**다. 하나로 단정하지 않는다.

| 지표 | 광고 신호 | 확인 방법 |
|---|---|---|
| ⭐ **바이라인** | 자사 기자 없음 | 기사 파싱 — **이미 있는 코드** |
| **참가비·심사비** | 응모에 돈을 낸다 | 공모 요강 |
| **수상 개수** | 「대상」이 수십 개 | 회차별 수상자 수 |
| **부문 세분화** | 「○○ 분야 △△ 부문 대상」 | 부문명 길이·개수 |
| **주최 구조** | 컨설팅사 주최 + 언론사 후원 | 주최·주관·후원 표기 |
| **반복 수상** | 같은 기업이 매년 | 연도별 수상자 대조 |
| **심사위원 공개** | 이름·소속이 없다 | 공고문 |
| **심사평** | 상투구뿐, 사실이 없다 | 텍스트 길이·고유명사 밀도 |

**반대로 「돈을 받아도 좋은 상」은 심사위원이 공개되고 심사평에 사실이 있다.**
그래서 지표를 한 개만 보면 틀린다. **합산해야 한다.**

### 7-4. 이게 오히려 **상품을 하나 더 만든다**

우리가 원래 만들려던 건 「수상 순위」였다. 그런데 옥석을 가리는 순간
**「상의 신뢰도 등급」이라는 데이터가 따로 생긴다.**

```
원래 상품   어느 언론사가 기자상을 많이 받았나
새 상품     ⭐ **이 상은 믿을 만한 상인가**
```

**세상에 없다.** 기업 홍보팀도, 취업준비생도, 기자도 이걸 알고 싶어 한다.
그리고 백년지도 모토(**「대학 이후」**)에 정확히 붙는다 —
「이 업계에서 진짜 인정받는 상이 뭔가」는 그 직업에 들어간 사람이 가장 궁금한 것이다.

### 7-5. ⚠ 다만 발행에는 선을 긋는다

특정 상을 **「광고다」라고 단정해 쓰지 않는다.** 그건 명예훼손 위험이 크고,
사장님 말씀대로 광고성이라도 좋은 상이 있어서 단정 자체가 틀릴 수 있다.

```
✅ 쓴다     지표를 그대로 보여준다 — 참가비 유무, 수상 개수, 심사위원 공개 여부,
            자사 기자 바이라인 유무. **사실만 늘어놓는다. 판단은 독자가 한다**
⛔ 안 쓴다   「○○상은 돈 주고 받는 상이다」 같은 단정
```

이건 우리 원칙과 같다 — **1차 데이터만, 출처와 기준시각 명시, 검증 안 된 건 안 쓴다.**
