# 데이터를 어느 사이트에 붙일 것인가

2026-08-04 KST · 사장님 지시

> 「**각각의 사이트에 적당한 데이터들을 잘 배분해.
>  배분할 수 없는 거는 어떻게 할지 조언해 줘.**」

---

## 0. 결론부터

**배분이 안 되는 데이터는 거의 없다.** 내가 축을 잘못 잡고 있었다.

매체(금융·K컬처·교육)로 가르려니까 기자상·법관평가·공무원징계가 어디에도 안 붙었다.
그런데 사장님이 주신 백년지도 모토 —「**대학 이후**」— 로 보면 **전부 「직업」 데이터다.**

```
기자상       기자라는 직업에서 무엇이 인정받나
법관평가     판사라는 직업에서 무엇이 좋은 판사인가
공무원 징계   공무원이라는 직업에서 무엇을 하면 잘리나
임원 학력     어느 대학을 나와 임원이 되나
근속연수     그 회사에 몇 년 다니나
```

**매체가 아니라 직업으로 보면 백년지도 하나에 다 들어간다.**
그리고 새 매체를 만들 필요가 없다 — 사이트 3개도 이미 벅차다.

**억지로 넣지 않는다.** 그게 매체를 흐린다.

## 2. ⭐ 「양쪽」이 있다 — 같은 데이터, 다른 질문

근속·급여·임원 데이터는 **한 벌로 두 매체에 다 쓴다.** 나누는 건 데이터가 아니라 **질문**이다.

```
SeoulMarkets   투자자에게    "Which Korean firms retain talent?"
               → 인적자본은 실적의 선행지표다. 영문. 회사가 주어
               → 지주사·업종 비교, 성별 격차, 이직 신호

백년지도        학생·학부모에게  「이 회사 가면 몇 년 다니나」
               → 국문. **직업이 주어**
               → 어느 대학 나와 임원이 됐나, 어느 직종이 오래 가나
```

**같은 NDJSON 한 파일로 화면 두 개를 만든다.** 수집을 두 번 하지 않는다.
`archive/raw/dart-employment/` · `archive/raw/dart-executives/` 가 공용 원천이다.

⚠ 이게 되는 이유는 우리가 **원자료를 갖고 있기 때문**이다.
남의 완성된 표를 받아 쓰면 이렇게 못 쪼갠다. 사장님 말씀대로 —
「우리는 **raw data 를 가공하는** 데이터저널리즘 + 서비스/컨설팅」이다.

## 3. 그래도 배분이 안 되는 것 — 셋뿐이다

| 안 붙는 것 | 왜 |
|---|---|
| **상의 옥석 판정** (「이 상은 믿을 만한가」) | 직업 데이터가 아니다. 시장 감시다 |
| **언론사별 기자상 순위** 를 「언론 비평」으로 쓸 때 | 진로가 아니라 매체 비평이 된다 |
| **로펌·회계법인 성적** | B2B다. 일반 독자가 아니다 |

### 조언 — 새 매체를 만들지 않는다. 셋 다 **발행이 아닌 경로**로 낸다

**⛔ 4번째 사이트는 만들지 않는다.** 지금 셋도 오픈 일정이 살아 있고,
`CLAUDE.md` 에 「사이트를 헷갈리지 않는다」가 🔴 로 박혀 있다. 넷이 되면 반드시 섞인다.

대신 셋을 이렇게 흘려보낸다.

```
① 보도자료로 배포한다   ⭐ 가장 현실적이다
   사장님이 가르쳐 주신 구조 그대로다 —「언론이 아닌 곳은 보도자료를 배포함」.
   **우리는 아직 언론사가 아니다.** 그러니 지금 우리 위치는 「내는 쪽」이다.
   백년지도에서 집계한 것을 뉴스와이어·정책브리핑 경로로 내면 매체들이 받아 쓴다.
   → 발행 지면이 필요 없고, 인용되면 백년지도로 링크가 돌아온다

② 데이터 판매·컨설팅으로 낸다
   로펌·회계법인 성적은 **일반 독자가 아니라 그 업계가 산다.**
   기업 홍보팀은 「이 상이 값이 있나」를 돈 내고 알고 싶어 한다.
   → 지면이 아니라 **리포트**다. 인쇄 지면 설계가 그래서 필요하다

③ 백년지도 안에 「직업」 섹션으로 흡수한다
   언론사별 기자상 순위도 「기자가 되려면」 안에 놓으면 진로 정보가 된다.
   **같은 표가 놓이는 자리에 따라 비평이 되기도 하고 진로가 되기도 한다.**
   → 우리는 진로 쪽에 놓는다. 그게 안전하고 우리 축이다
```

## 4. ⚠ 그 전에 먼저 정리해야 할 것

- [ ] **언론사 등록** — 사장님이 「아직은 언론사 아님에 유의」라고 하셨다.
      YMYL 신뢰도, 자료 요청 자격, KCMI 같은 「보도 목적」 라이선스 조건이 전부 여기 걸린다.
      **등록 전에는 「우리는 언론사다」를 어디에도 쓰지 않는다.** 내가 한 번 잘못 말했다
- [ ] 백년지도에 「직업」 축을 정식으로 넣는다 — 지금 스토리보드는 학과 중심이다
- [ ] 근속·임원 데이터의 **영문 지면**(SeoulMarkets)과 **국문 지면**(백년지도) 분리 설계
