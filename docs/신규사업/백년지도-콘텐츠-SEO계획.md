# 0. 목표 — 이 문서 전체가 여기에 걸린다

> 사장님 (2026-08-04):
> 「우린 **무한 경쟁으로 아이들을 줄세우는 불행한 공교육·사교육** >>
>  **행복한 진짜 교육**, 아이들이 **하고 싶은 일이 뭔지 찾아주고 그 길을 자세히 안내하는
>  진짜 스승**이 목표야」

**같은 데이터로 줄세우기도 만들 수 있고 길 안내도 만들 수 있다. 우리는 후자다.**

| ⛔ 줄세우기 | ✅ 길 안내 |
|---|---|
| 「정보처리과 전국 1위」 | 「전국 391개교에 있다 — 어디서든 갈 수 있는 길이다」 |
| 「취업률 순위」 | 「이 길로 간 사람들은 실제로 이렇게 됐다」 |
| 「중도탈락률 높은 학과 20곳」 | 「중간에 그만두는 사람이 많은 길 — 왜 그런지 같이 본다」 |
| 「좋은 학과 / 나쁜 학과」 | 「너에게 맞는 길인지 판단할 재료」 |

- ⛔ **「몇 위」를 화면에 쓰지 않는다.** 순위값은 정렬용 내부값으로만 쓴다
- ✅ 「전국 몇 개교에 있나」는 **길의 넓이**라 그대로 쓴다
- 모토 「긍·부정 다 공개」는 **줄을 세우려고**가 아니라 **아이가 스스로 판단하게** 하려는 것이다
- **보호자 동석이 구조다.** 아이가 혼자 AI 와 대화하는 경로는 만들지 않는다

⚠ 아래 Ⅲ-3, Ⅲ-4 에 「순위」로 쓴 대목이 있다. **2026-08-04 이 지시로 되돌렸다.**
데이터가 있으면 순위를 만들고 싶어진다. 그 유혹을 매번 확인한다.

# Ⅱ. 그래서 우리가 파는 것 — 「한 칸」이 아니라 「한 줄」

## 2-1. 남들이 주는 것

```
대학알리미    「A대학 간호학과 취업률 82.3%」          ← 한 칸
커리어넷      「간호사: 환자를 간호하는 직업입니다」      ← 한 칸
워크넷        「간호사 직무: 투약, 처치, 기록」          ← 한 칸
```

**세 기관이 각각 한 칸씩 준다. 아무도 잇지 않는다.**

## 2-2. 우리가 만드는 것

```
간호학과 (전국 ○○개 대학)
  → 취업률 82.3% · 유지취업률 71.1% · 중도탈락률 4.2%      대학알리미
  → 이어지는 직업: 간호사 · 보건교사 · 산업간호사            워크넷 직업정보
  → 그 직업이 실제로 하는 일                               워크넷 직무정보
  → 대학 안 가는 길: 특성화고 보건간호과 ○○개교             NEIS 학과정보
  → 그 직업에서 인정받는 법(시상) / 잘리는 법(징계)          전자관보·인사혁신처
  → 몇 년 다니나 · 평균 급여                               DART 근속·급여
```

**이 한 줄이 어디에도 없다.** 이게 상품이고, 동시에 **콘텐츠**다.

⭐ 그리고 이건 **수집을 한 번 해서 화면을 여럿 만드는** 구조다 —
`데이터-사이트배분.md` §2 「같은 데이터, 다른 질문」이 그대로 성립한다.

# Ⅲ. SEO 전략 — 기사가 아니라 「페이지」가 먼저다

## 3-1. 2번과 다른 점

2번(SeoulMarkets)은 **기사 단위 발행**이다. 백년지도는 다르다.

| | SeoulMarkets | 백년지도 |
|---|---|---|
| 언어 | 영문 | **국문** |
| 주 콘텐츠 | 기사(하루 여러 건) | **데이터 페이지(수만 장) + 기사(주 2~3건)** |
| 검색어 | "Korea bond yield" | **「간호학과 취업률」 「○○고등학교」** |
| 유입 경로 | Reddit·X·Benzinga | **네이버·구글 자연검색이 절대적** |
| YMYL | 금융 | **교육** — 신뢰도 요구가 더 세다 |

⚠ **네이버 비중이 완전히 다르다.** 2번은 「영문 사이트라 네이버 기대치는 낮다」고 적었지만,
**백년지도는 학부모가 네이버로 찾는다.** 네이버 서치어드바이저가 1순위다.

## 3-2. 우리가 만들 수 있는 페이지 수 — **이미 손에 있다**

오늘 받은 것만으로 이만큼이 나온다.

| 페이지 | 수 | 원천 | 상태 |
|---|---|---|---|
| 학교별 페이지 | **12,665** | NEIS 학교기본정보 | ✅ 확보 |
| 고교 학과 페이지 | **18,169** → 중복 정리 후 학과명 기준 수백 | NEIS 학교학과정보 | ✅ 확보 |
| 대학 학과 페이지 | 수천 | 대학알리미 | ⛔ **0건. 제일 큰 구멍** |
| 직업 페이지 | 수백~수천 | 워크넷 직업사전·직업정보 | ⚠ 키는 있는데 스펙 못 뚫음 |
| 직무 페이지 | 수백 | 워크넷 직무정보 | 〃 |

⭐ **「○○고등학교」는 검색어다.** 학부모가 실제로 친다. 12,665개 페이지가 각각 검색 진입점이 된다.

## 3-3. ⚠ 얇은 페이지를 대량으로 찍으면 색인이 안 된다

수만 장을 찍는 방식(프로그래매틱)은 **각 페이지에 고유한 가공값이 없으면 구글이 버린다.**
그래서 **페이지 1장마다 「우리만 있는 숫자」를 최소 하나씩** 넣는다.

| 페이지 | 우리만 있는 것 |
|---|---|
| 학교 페이지 | 그 학교 학과가 **어느 직업으로 이어지는지** · 같은 지역 같은 계열 학교 수 |
| 학과 페이지 | 취업률 **순위**(전국 몇 위) · 유지취업률과의 **격차** · 중도탈락률 |
| 직업 페이지 | 그 직업으로 가는 **학과 경로 전체** · 시상/징계 사례 수 |

⛔ 원자료 표를 그대로 옮긴 페이지는 만들지 않는다. **그건 대학알리미 복사본이고 색인도 안 된다.**

## 3-4. 기사 — 주 2~3건, 「순위」와 「격차」로 쓴다

데이터저널리즘 기사가 검색에 걸리는 형태는 정해져 있다.

```
「취업률은 높은데 3년 뒤에 안 남는 학과」        취업률 − 유지취업률 격차 순위
「중도탈락률이 가장 높은 학과 20곳」             중도탈락률 순위
「특성화고 학과 중 사라지고 있는 것」            NEIS 학과 연도 비교
「공무원은 무엇을 하면 잘리나 — 징계 사유 집계」   인사혁신처
「이 직업에서 상을 받는 사람들은 무엇을 했나」     전자관보
```

⚠ **긍·부정을 짝으로 낸다.** 모토 그대로 — 「상만 보면 미화, 징계만 보면 험담이다」.

## 3-5. 기술 항목 — 2번 것을 그대로 물려받는다

`문서\검색등록-콘텐츠유통.md` 에 이미 다 있다. **새로 만들 것이 거의 없다.**

| 사이트맵 카테고리 분리 | ✅ | 페이지가 수만 장이라 **분할이 필수** |
| RSS | ✅ | 기사에만 |
| JSON-LD | `NewsArticle` | **`FAQPage`·`Dataset`·`EducationalOrganization` 을 더 쓴다** |
| OG 이미지 | ✅ | |
| IndexNow | ✅ 키·스크립트 | 그대로 |
| Google Search Console | 등록 필요 | **네이버 서치어드바이저가 더 급하다** |

# Ⅳ. 유입 → 거래로 잇는 구조

> 「우리가 **운영하는 다른 사이트를 통한 유입.** 이를 바탕으로 **B2B, B2C 거래**」

## 4-1. 사이트 간 유입

```
KLifeMap(1번)   자녀진로 코칭 결과 끝  →  「그 길의 실제 결과는?」  → 백년지도
백년지도(3번)   학과 페이지 끝          →  「이 아이 성향은?」      → KLifeMap
SeoulMarkets(2번) 근속·급여 기사 끝    →  「그 회사 몇 년 다니나」  → 백년지도
백년지도        직업 페이지 끝          →  「그 회사 실적은?」      → SeoulMarkets
```

⭐ **근속·급여 데이터가 이미 양쪽 페이지에 다 쓰인다**(`데이터-사이트배분.md` §2).
링크가 자연스럽다 — 억지 배너가 아니라 **같은 데이터의 다른 질문**이다.

## 4-2. B2C — 무료 페이지가 유료 상품의 진입로

```
검색 유입 → 학과 페이지(무료) → 「이 학과 하나만 더 파보기」(유료) → 「우리 아이 진로 지도」(유료)
```

무료 페이지는 **미끼이자 SEO 자산**이다. 둘 다 한다.

## 4-3. B2B — 여기가 본체가 될 수 있다

| 고객 | 파는 것 |
|---|---|
| 고등학교·교육청 | 진로진학 상담 교사용 페이지·리포트 |
| 학원·컨설팅업체 | 학과·직업 데이터 API |
| 대학 입학처 | 경쟁 학과 대비 우리 학과 지표 |
| 기업 HR | 학과별 인재 풀 |

⭐ **경쟁 앱 메이저맵이 정확히 이 구조다** — B2C 앱은 무료, 돈은 학교 납품(시스메이트).
API 요금 구조는 KLifeMap `apiPlans`(월 기본료 + 초과 건당)를 그대로 쓸 수 있다.
