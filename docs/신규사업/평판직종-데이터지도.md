# 평판에 민감한 직종 — 데이터 지도

실측 2026-08-04 07:5x KST · 사장님 지시

> 「판결에서 승-패 각각 담당 변호사 데이터가 있을까?」
> 「의료/건강포털에서 각 질환별 진료건수가 많은 의사 Top5를 찾아낼 수 있을까?」
> 「**다 찾아. 평판에 민감한 직종으로**」
> 「**백년지도에서 쓸 수 있고, 별도로 언론사이트로 할 수 있어**」
> 「**개인 단위 또 집단(예: 병원의 신경과) 단위**」

## 0. 성립 조건 셋 — 이게 다 돼야 「누가 잘했나」가 만들어진다

우리가 이미 만들고 있는 **애널리스트 목표주가 적중률**이 되는 이유가 이 셋이다.
하나라도 없으면 못 만든다. **아이디어의 좋고 나쁨이 아니라 이 셋의 유무가 판정 기준이다.**

```
① 이름이 공개되는가      개인 또는 집단(병원의 신경과, 로펌, 회계법인) 단위로
② 명확한 정답이 있는가    맞았다/틀렸다가 갈리는가. 「부분승소」처럼 흐리면 안 된다
③ 대조할 공개 데이터      정답을 확인할 수 있는 별도 데이터가 있는가
```

- **의사 개인** → ①이 없다. 심평원 공개분은 **전부 요양기관 단위**다
- **변호사 개인** → ②가 약하다. 부분승소가 많아 이분법이 안 된다
- **애널리스트** → 셋 다 있다. 그래서 된다

## 2. ⭐ 셋 다 성립하는 것 — 여기부터 한다

### ① 펀드매니저 · 운용사 — **가장 깨끗하다**

```
① 이름     금투협 전자공시에 **운용역**이 공시된다
② 정답     수익률. 숫자 하나다. 해석의 여지가 없다
③ 대조     벤치마크 대비 초과수익. 공개 데이터로 계산된다
```

애널리스트와 **구조가 완전히 같다.** 우리가 이미 만든 적중률 엔진을 그대로 쓴다.
그리고 이건 **SeoulMarkets 본업**이다 — 새 매체를 만들 필요도 없다.

### ② 회계법인 · 감사인 — **DART 에 다 있다**

```
① 이름     감사보고서에 **감사인(회계법인)**이 반드시 적힌다
② 정답     감사의견(적정·한정·부적정·의견거절) → 그 뒤 **분식·상장폐지·재감사**
③ 대조     DART 공시로 사후 결과가 확인된다
```

「적정 의견을 냈는데 1년 뒤 분식이 드러난 회사가 몇 곳인가」 — **이건 셀 수 있다.**
법인 단위라 개인 평판 문제도 덜하다.

### ③ 신용평가 3사 — 등급 대 실제 부도

```
① 이름     한신평·NICE·한기평 — 3사뿐이라 표본이 작지만 이름은 완전 공개
② 정답     부도·워크아웃·회생
③ 대조     DART 공시 + 우리가 이미 받는 채권시세
```

⚠ 한신평은 robots 전면차단. **한기평·NICE 만으로는 비교가 기울 수 있다.**

## 3. 집단 단위 — 사장님이 말씀하신 「병원의 신경과」

**개인이 안 되면 집단으로 내리면 된다.** 여기서 의료가 다시 살아난다.

| 집단 단위 | 데이터 | 상태 |
|---|---|---|
| **병원 × 진료과** | 심평원 병원평가(질환별 등급) · 의료기관별상세정보(진료과목·전문의 수) | ✅ 열려 있음 |
| **로펌** | 판결문의 대리인(법무법인) | ⚠ 비실명화 범위 확인 필요 |
| **증권사 리서치센터** | 우리 아카이브 66,105건 | ✅ **이미 갖고 있다** |
| **회계법인** | DART 감사인 | ✅ |
| **건설사** | 시공능력평가 · 하자 | ✅ |

⚠ **의사 개인 Top5 는 여전히 안 된다.** 심평원이 개인 단위를 공개하지 않는다.
「이 질환은 어느 병원 어느 과가 잘하나」까지가 공개 데이터의 한계다.

## 4. 두 갈래로 쓴다 — 성격이 완전히 다르다

### 백년지도 = **진로 정보** (안전하고 데이터가 이미 많다)

「이 직업을 하면 어떻게 되나」다. **평판을 매기지 않는다.**

```
자격증 합격률·응시자 수     각 협회·큐넷
개업 대비 폐업률            국세청 사업자 통계
소득 분포                   국세청·고용정보원
자격 취득 후 진로           워크넷·고용정보원
```

**평가가 아니라 사실이라 반발할 대상이 없다.** 백년지도의 축과도 맞는다 —
「이 학과 나오면 어떻게 됐나」의 직업판이다.

### 언론사이트 = **평가** (강력하지만 대상이 반발한다)

「누가 잘했나」다. ⚠ **①②③ 이 완벽한 직종만 한다.**

```
✅ 한다    펀드매니저 · 회계법인 · 신용평가사 · 애널리스트
           — 공개 예측을 스스로 이름 걸고 냈고, 정답이 숫자로 갈린다
⛔ 안 한다  의사 개인 · 변호사 개인
           — 데이터가 없거나(의사), 정답이 흐리다(변호사)
```

⚠ **변호사 승률은 실제로 분쟁이 났던 영역이다.** 로톡과 변협이 몇 년을 다퉜다.
광고 규제와 명예 문제에 바로 닿는다. 데이터가 있어도 이건 뒤로 미룬다.

## 6. 추가 지시 반영 (2026-08-04 08:0x KST)

> 「**법무법인, 합동법률사무소(김앤장) 같은**」
> 「**특히, 비싼 비용이 들어가는 직종**」
> 「**공무원 징계 데이터도. 왜 징계받나**」

### 6-1. 「비싼 비용」이 가장 정확한 필터다

사장님이 주신 이 기준이 앞의 조건 셋보다 **먼저 와야 한다.**
수임료가 클수록 사는 쪽이 조사를 하고, **그 조사에 값이 붙는다.**
싼 것은 아무리 데이터가 좋아도 아무도 돈을 내고 찾아보지 않는다.

| 1건당 비용 | 직종 | 데이터 상태 |
|---|---|---|
| 수억~수십억 | **M&A·기업소송 로펌** | ⚠ 판결문 대리인 표기 확인 필요 |
| 수천만~수억 | **회계법인 감사·자문** | ✅ **DART 에 감사인이 다 있다** |
| 수백만~수억 | 특허 출원·소송(변리사·특허법인) | ⚠ KIPRIS 차단 · 특허청 API 확인 필요 |
| 수천만 | 신용평가 | ⚠ 한신평 차단 · 한기평/NICE 는 열림 |
| 수백만~수천만 | 감정평가 | ✅ 협회·공시가격알리미 열림 |
| 수백만~수천만 | 대형병원 비급여 수술 | ✅ 심평원 **비급여진료비 공시** |
| 공사비의 % | 건축설계 | ⚠ 세움터 조회 실패 |

**⭐ 최적점은 「비용 2위 × 데이터 1위」 — 회계법인이다.**
로펌이 비용은 1위지만 데이터가 가장 어렵고, 회계법인은 **DART 에 이미 다 들어 있다.**

### 6-2. 법무법인 단위 — 개인 변호사와 성격이 다르다

```
개인 변호사   ⛔ 로톡·변협 분쟁 영역. 광고 규제와 명예에 바로 닿는다
법무법인      △ 법인 평판이라 개인 명예 문제가 덜하다.
              다만 ②(명확한 정답)는 여전히 약하다 — 부분승소
```

⚠ **관건은 하나다 — 판결문에 대리인 법인명이 남는가.**
아직 확인 못 했다. 확인 경로 둘.
- 법제처 판례 API (`open.law.go.kr`) — robots 없음. **OC 발급이 필요하다**
- 케이스노트·엘박스 — robots 일부만 차단. 실물 판례를 열어 대리인 표기를 눈으로 본다

### 6-3. 공무원 징계 — **왜 징계받나**

실측 결과 **열려 있다.**

| | 사이트 | 상태 |
|---|---|---|
| ✅ | **인사혁신처** | 공공누리 · 통계 · **징계 항목 확인** · `/search/` 만 차단 |
| ✅ | 국민권익위 | 청렴도 · 징계 |
| ✅ | **공공기관 알리오** | `Allow: /` · 경영정보 + 징계 |
| ✅ | KOSIS · e-나라지표 | **OpenAPI** |
| 🚫 | 감사원 | `Disallow: /` — 감사결과·징계요구가 여기 있는데 막혔다 |
| 🚫 | 지방공공기관 클린아이 | `Disallow: /` |
| ⚠ | 정보공개포털 | `Disallow: /` + `allow: /$` — 사실상 차단 |

**개인은 비공개, 기관별·사유별은 공개**다. 그래서 이렇게 갈린다.

```
백년지도   「공무원이 되면 어떤가」 — 징계 사유 분포는 그 직업의 실상이다.
           평가가 아니라 사실이라 안전하다
언론       「어느 기관이 왜 징계받나」 — 기관 단위 비교. 성립한다
```

⚠ 감사원이 막힌 것이 아프다. **징계의 원인 쪽 자료가 거기 있다.**
KOSIS·e-나라지표에 같은 통계가 실려 있는지 먼저 본다 — 우회가 아니라 **정식 경로가 따로 있는지**를 보는 것이다.

### 6-4. 그래서 순서

```
1  회계법인 · 감사인      DART 에 이미 있다. 우리 본업이고 새 데이터가 필요 없다
2  펀드매니저 · 운용역    금투협 전자공시. 적중률 엔진을 그대로 쓴다
3  공무원 징계(기관별)    인사혁신처·알리오·KOSIS. 백년지도와 언론 양쪽에 쓴다
4  법무법인              대리인 표기 확인이 먼저다
5  변리사·특허법인        특허청 API 에 대리인 필드가 있는지 확인이 먼저다
```

1·2 는 **새 매체 없이 SeoulMarkets 에서 바로 된다.** 3 은 백년지도 축이다.
