# 백년지도 — 스토리보드 (화면 설계 전체)

작성 2026-08-03 KST · 착수 2026-09-01 · **오픈 가능한 상태를 목표로 한다**

> 사장님: 「인터넷홈페이지 모바일 홈페이지 리포트 코칭 다 완벽해야 돼. Open 할 수 있게」
> 「그릇이 내용물을 결정한다. 디자인, 또 디자인, UX, 또 UX」
> 「고객이 기꺼이 지갑을 열 수 있게」

**이 문서 하나로 화면을 만들 수 있어야 한다.** 빠진 화면이 있으면 여기에 더한다.

---

## 0. 이 스토리보드가 지켜야 하는 제약 — 앞선 설계에서 확정된 것

새로 정하지 않는다. **아래를 어기는 화면은 그리지 않는다.**

| | 제약 | 출처 |
|---|---|---|
| 1 | **아이 단독 로그인을 만들지 않는다.** 계정은 보호자 명의, 세션은 보호자가 연다 | 진로컨설팅AI-설계 §1 |
| 2 | **리포트가 먼저다.** 대화는 리포트에 있는 판정만 말한다 | 〃 §5 |
| 3 | **위기 표현은 규칙으로 감지하고 상담을 끊는다.** 위로로 넘기지 않는다 | 〃 §1 |
| 4 | 명리는 **신강신약·성향·격국 셋만.** 운세·대운·궁합·택일·합격예측 없음 | 사업계획 §1 |
| 5 | **초등은 무료.** 고1~2 가 결제 구간 | 〃 §3 |
| 6 | **가입 없이 쓰는 무료 도구가 입구다** | 〃 §4-① |
| 7 | 사교육이 아니라 **컨설팅.** 전부 인터넷으로만 | 〃 §2-2 |
| 8 | **판정은 규칙이 하고 LLM 은 읽고 말한다** | AI-아키텍처 |

⚠ **모바일이 기본이다.** 학부모는 휴대폰으로 본다. 데스크톱을 먼저 그리고 줄이지 않는다.
**360px 에서 먼저 그리고 넓힌다.**

## 1. 화면 목록 — 전체

```
공개 (가입 없음)
  P0  첫 화면
  P1  ⭐ 학과 조회 결과       ← 입구. 이것 하나로 유입이 만들어진다
  P2  학과 비교
  P3  기사 목록 · P4 기사 본문
  P5  소개(About) · P6 이용약관 · P7 개인정보처리방침

가입 후 (보호자 계정)
  A0  가입 · A1 로그인
  A2  아이 프로필 등록
  A3  ⭐ 진단 시작 (보호자 동석 확인)
  A4  진단 진행
  A5  ⭐ 리포트
  A6  ⭐ 1:1 코칭
  A7  내 서재(리포트 보관)
  A8  결제 · A9 계정 설정

시스템
  S0  빈 상태 · S1 오류 · S2 점검
  S3  ⭐ 위기 안내 화면        ← 어느 화면에서든 즉시 전환된다
  S4  리포트 인쇄/PDF
```

⭐ 표시가 **이 서비스의 값어치가 걸린 화면**이다. 나머지는 거들 뿐이다.

## 2. P0 — 첫 화면

### 목적 하나

**「이 학과 나오면 어떻게 됐나」를 3초 안에 검색하게 만든다.**
회사 소개가 아니다. 도구가 먼저 보여야 한다.

### 모바일 (360px 기준)

```
┌────────────────────────────┐
│ 백년지도 百年地圖          │  로고. 44px 이상 탭 영역
├────────────────────────────┤
│                            │
│  대학은 100년 중           │  h1 · clamp(1.7rem, 6vw, 2.3rem)
│  한 점입니다.              │  word-break: keep-all  ← 한글 필수
│                            │
│  그 길로 간 사람들이        │  리드. 2줄 넘기지 않는다
│  실제로 어떻게 됐는지.      │
│                            │
│ ┌────────────────────────┐ │
│ │ 🔍 학과 이름을 넣으세요 │ │  ← **화면 첫 화면에 보인다**
│ └────────────────────────┘ │     높이 52px. 모바일 키보드 대응
│   간호학과  기계공학과      │  ← 인기 검색어 칩. 탭 한 번에 결과
│   경영학과  컴퓨터공학과    │
│                            │
│  ─────────────────────     │
│  무료입니다. 가입도         │  ← **이 문장이 이탈을 막는다**
│  필요 없습니다.             │
└────────────────────────────┘
      ↓ 스크롤
┌────────────────────────────┐
│ 어른들은 「이 과에 가라」고  │  기존 100y/index.astro 문구 유지
│ 말합니다. 가서 어떻게       │  (이미 검증된 카피다)
│ 됐는지는 아무도 안 봅니다.  │
│                            │
│ [지금 vs 백년지도 비교표]   │  4행. 가로 스크롤 대신 세로 카드로
│                            │
│ 우리는 학원을 팔지 않습니다.│
│ 그래서 안 다녀도 된다고     │
│ 말할 수 있습니다.           │
├────────────────────────────┤
│ 출처 · 발행인 · 연락처      │  ⚠ YMYL. 비우면 검색에 안 올라온다
└────────────────────────────┘
```

### 데스크톱 (≥1024px)

같은 순서를 2단으로 편다. **검색창은 여전히 첫 화면 안에 있어야 한다.**
좌측 60% 카피 + 검색, 우측 40% 실제 데이터 미리보기(학과 하나의 그래프).

### 지켜야 할 것

- **가입 유도 배너를 첫 화면에 두지 않는다.** 도구를 쓰고 나서 권한다
- 광고는 첫 화면에 넣지 않는다. 신뢰가 먼저다
- 로딩 1초 이내. 검색창은 JS 없이도 동작(form submit)

## 3. ⭐ P1 — 학과 조회 결과 (이 서비스의 심장)

**교사가 수업에 쓰고, 학부모가 검색으로 오는 화면이다.** 여기가 곧 마케팅이다.

### 화면 구조

```
┌────────────────────────────┐
│ ← 간호학과                 │
│   4년제 · 전국 122개 학과   │  ← 모집단을 먼저 밝힌다
├────────────────────────────┤
│ ❶ 한 줄 답                 │
│ 「졸업 1년 뒤에도 그 자리에 │  ← **결론을 맨 위에.** 스크롤 안 해도 답이 보인다
│  남아 있는 비율 78.4%」     │
│  전체 학과 평균 61.2%       │  ← 비교 기준 없이 숫자만 주지 않는다
├────────────────────────────┤
│ ❷ 세 숫자                  │
│  취업률      유지취업률     │
│   86.1%        78.4%       │  ← 이 둘의 차이가 이 서비스의 존재 이유
│  중도탈락률    3.2%         │
│                            │
│  [막대 그래프 — 전체 평균과 │  가로 막대. 색 2개만.
│   비교. 우리 학과 강조]     │  ⚠ 빨강/초록 단독 구분 금지(색각)
├────────────────────────────┤
│ ❸ 「취업률은 높은데         │  ← 해석을 한 문단. 숫자만 던지지 않는다
│  1년 뒤 남는 비율이 낮은」  │     **규칙이 만든 문장이지 LLM 이 아니다**
│  학과와 비교해 보세요       │
│  [비교하기 →]              │
├────────────────────────────┤
│ ❹ 이 숫자는 어디서 왔나     │  ← 출처·기준연도·조사기관을 접어서 제공
│  대학알리미 2025년 공시     │     펼치면 정의까지 (유지취업률이 뭔지)
├────────────────────────────┤
│ ❺ 우리 아이는 어떤가요?     │  ← **여기서 처음 가입을 권한다**
│  [무료 진단 시작]           │     도구를 쓴 뒤라 전환율이 다르다
└────────────────────────────┘
```

### 상태별 화면

| 상태 | 무엇을 보여주나 |
|---|---|
| 데이터 있음 | 위 구조 |
| **학과는 있는데 공시가 없음** | 「이 학과는 2025년 공시에 유지취업률이 없습니다」 + 있는 항목만. **0%로 표시하지 않는다** |
| 학과 없음 | 「찾지 못했습니다」 + 비슷한 이름 3개 + 전체 목록 링크 |
| 검색어 없음 | 인기 학과 12개 |

⚠ **없는 숫자를 0 이나 평균으로 채우지 않는다.** 데이터 상품에서 그건 치명적이다.

### 공유·인쇄

- 카카오톡 공유 시 **학과명과 핵심 숫자가 보이는 og:image 를 서버에서 생성**한다.
  (학부모 유통 경로가 카톡이다. 빈 카드가 나가면 안 퍼진다)
- 인쇄하면 A4 한 장에 들어간다 — 교사가 수업 자료로 뽑는다

## 6. A4 — 진단 진행

### 학년대별로 다른 화면을 쓴다

| 학년 | 형태 | 문항 | 톤 |
|---|---|---|---|
| **초등** | 그림 선택 · 놀이에 가깝게 | 12~16 | 「어느 쪽이 더 재미있어?」 |
| **중학** | 문장 선택 | 20~24 | 「어느 쪽에 가까워?」 |
| **고1~2** | 문장 + 학과 선호 | 24~30 | 존댓말. 진지하게 |

### 공통 규칙

- **한 화면에 한 문항.** 진행률 막대 필수(이탈 방지)
- 뒤로 가기로 답을 고칠 수 있다
- **중간 저장.** 휴대폰에서 전화가 오면 끊긴다 — 그때 처음부터는 최악이다
- 소요 시간을 시작 전에 알린다 (「약 8분」)
- ⚠ **생년월일시는 명리 세 값에만 쓴다.** 왜 묻는지 그 자리에서 설명한다.
  안 밝히면 점집으로 오해받는다

## 7. ⭐ A5 — 리포트 (지갑이 열리는 화면)

**보호자가 저장하고 다시 보고, 아이에게 보여주는 물건이다.**
화면이 아니라 **문서**로 설계한다.

### 구성 — 순서가 곧 설득이다

```
표지        아이 이름 · 학년 · 발행일 · 백년지도 로고
            ⚠ 「합격 예측」류 문구 절대 금지

1. 한 장 요약   ← 여기만 읽어도 되게. 보호자는 바쁘다
   · 지금 이 아이의 강점 세 줄
   · 지금 단계에서 할 일 한 가지
   · 지금 하지 않아도 되는 것 한 가지   ← **이게 우리의 차별점이다**

2. 아이를 보는 네 축
   ① 흥미·적성    (진단 결과)
   ② 성향         (명리 세 값 중 성향)
   ③ 학습 방식    (학습과학)
   ④ 결과 데이터  (학과별 유지취업률)
   ⚠ ①②③ 이 ④와 만나는 자리를 보여준다. 축을 따로 나열하면 점집이 된다

3. 라이프맵
   [지금] ──→ [고교] ──→ [대학·전공] ──→ [그 다음 수십 년]
   ⚠ 하나의 길만 그리지 않는다. **최소 세 갈래**를 그린다.
     길이 하나면 그건 예언이지 지도가 아니다

4. 이 길로 간 사람들은 어떻게 됐나
   추천 계열의 유지취업률·중도탈락률 실제 숫자 + 출처

5. 보호자에게 드리는 말
   · 지금 시기에 흔한 오해 하나
   · 아이와 이야기할 때 피할 말 세 가지

6. 고지
   · 이것은 진로 참고 자료이며 진학·합격을 보장하지 않습니다
   · 판정은 규칙 기반이며 AI 가 문장을 씁니다
   · 데이터 출처와 기준연도
```

### 지켜야 할 것

- **인쇄가 1급 기능이다.** A4 4~6쪽. 페이지 나눔이 표·그래프를 자르지 않게
  `break-inside: avoid`. 흑백으로 뽑아도 그래프가 읽혀야 한다(패턴 병용)
- PDF 저장 · 링크 공유(만료 있는 비공개 링크)
- **다시 열면 같은 리포트가 나와야 한다.** 판정이 규칙이라 재현된다 — 그것이 신뢰다
- 모바일에서 세로 스크롤로 끝까지 읽히게. 좌우 스크롤 금지

## 8. ⭐ A6 — 1:1 코칭

### 리포트가 없으면 이 화면에 들어올 수 없다

```
┌────────────────────────────┐
│ 코칭  ·  민준이 리포트 기준 │  ← 어떤 리포트를 근거로 말하는지 항상 표시
├────────────────────────────┤
│                            │
│  [AI] 리포트에서 말씀드린   │
│  대로 민준이는 …           │
│                            │
│  근거: 리포트 2-①  ↗       │  ← **모든 답에 리포트 근거를 단다**
│                            │
│         [보호자] 그럼 간호  │
│         학과는 어떤가요?    │
│                            │
├────────────────────────────┤
│ 자주 묻는 것 ▸             │  ← 빈 화면에서 뭘 물어야 할지 모른다
│ · 이 성향이면 어떤 계열?    │
│ · 지금 학원을 늘려야 하나요?│
├────────────────────────────┤
│ [메시지 입력]              │
└────────────────────────────┘
```

### 규칙 — 화면보다 이게 중요하다

```
✅ 리포트에 있는 판정만 말한다. 새 판정을 대화에서 만들지 않는다
✅ 답마다 근거(리포트 몇 절)를 표시한다
✕ 합격 가능성·점수·등급을 말하지 않는다
✕ 특정 학원·강사·교재를 권하지 않는다   ← 우리는 사교육을 팔지 않는다
✕ 운세·궁합·택일로 넘어가지 않는다
⛔ 위기 표현이 감지되면 **즉시 S3 로 전환하고 상담을 끝낸다**
```

⚠ **대화 이력은 보호자 계정에 남고 보호자가 본다.** 숨김 대화가 없다.

## 9. ⭐ S3 — 위기 안내 화면

**어느 화면에서든, 어떤 단계에서든 즉시 이 화면으로 바꾼다.**
`src/ai/crisis.mjs` 가 규칙으로 감지한다(LLM 아님, 18건 시험 통과).

```
┌────────────────────────────┐
│                            │
│  지금 많이 힘드신 것 같아요.│  ← 위로로 상담을 이어가지 않는다
│                            │
│  전문 상담을 받으실 수      │
│  있습니다. 24시간 열려      │
│  있습니다.                  │
│                            │

│  ☎ 1388 청소년전화         │
│  ☎ 1577-0199 정신건강      │
│                            │
│  이 대화는 여기서           │

│                            │

- 광고·결제·다른 버튼을 **이 화면에 두지 않는다**

- **보호자 본인이 위기일 수도 있다.** 아이용 문구로만 쓰지 않는다

```

- **결제 전에 리포트 샘플 전체를 보여준다.** 뭘 사는지 모르고 사게 하지 않는다
- KLifeMap 결제 모듈 재사용(사업계획 §6-7)
- 환불 규정을 결제 버튼 옆에 둔다. 접어 놓지 않는다
- ⚠ **구독을 기본값으로 걸지 않는다.** 단건이 기본, 구독은 선택
