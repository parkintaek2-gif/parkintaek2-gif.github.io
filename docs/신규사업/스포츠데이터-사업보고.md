# 스포츠 데이터 사업 — 보고

작성 2026-08-03 00:0x KST · 지시: 「위키팁에 스포츠 데이터도 가공해서 콘텐트로 제공하자」

**이 보고서는 하루 안에 실제로 잰 것 위에 서 있다.** 2026-08-02 에 Riot 개발자 API 19개
엔드포인트를 직접 찔러 봤고(`scripts/probe-riot.mjs`), 첫 수집을 돌려 데이터를 받았다.
시장 숫자는 출처를 밝힌다. **확인 못 한 것은 「미확인」이라고 적는다.**

---

## 요약 — 결론 넉 줄

1. **전통 스포츠 데이터는 들어갈 자리가 없다.** Sportradar·Genius Sports 듀오폴리다.
   합쳐 연 20억 달러 규모이고, **권리 계약을 사서 독점한다.** 우리 체급의 문제가 아니다.
2. **e스포츠도 「프로 경기 데이터」는 못 판다.** Riot 개발자 API 에 아예 없다(403 실측).
   기획서가 이걸 전제하고 있었는데 사실이 아니었다.
3. **팔 수 있는 것은 하나 남는다 — 랭크 사다리의 시계열.**
   아무도 매일 세지 않고, **소급이 안 되므로 오늘 시작한 사람만 가질 수 있다.**
4. **이건 「데이터 판매」가 아니라 「콘텐츠·유입」 사업으로 봐야 한다.**
   숫자를 팔아 큰돈이 되지 않는다. 광고와 유입이 수익원이고 그건 WikiTip 모델 그대로다.

## 1. 전통 스포츠 — **안 한다.** 왜인지 숫자로

### 시장은 크다. 그런데 문이 닫혀 있다

| 스포츠 베팅 데이터 서비스 | 2025년 47.9억 달러 → 2035년 105억 | WiseGuy |

| **Genius Sports** 연매출 | 2025년 약 **6.2억 달러** · +21% (순손실 1.1억) | SportBusiness |

**두 회사가 공식 데이터 권리의 듀오폴리다.** Sportradar 는 2025년 11월 IMG Arena 를
인수해 **권리보유자 70곳 이상**을 추가했다.

### 그래서 우리 자리가 없다

```
이 사업의 진입 장벽은 기술이 아니라 계약이다.
리그가 데이터를 독점 관리하고, 그 권리를 사는 데 수억~수십억이 든다.
1인·무자본으로 살 수 있는 것이 아니다.

긁으면 되지 않나 → 안 된다. KRX 를 안 긁는 것과 정확히 같은 이유다.
```

KBO·K리그도 같다. 그리고 **K리그 아세안쿼터 각도는 이미 지나갔다** —
2025년 아시아쿼터 폐지, 2026년 외국인 선수 제한 자체가 폐지됐다.

> **판정: 전통 스포츠 데이터 사업은 하지 않는다.** 다시 검토하지 않는다.

## 3. ⚠ 실측 — **무엇이 실제로 나오는가**

2026-08-02 · Personal Key · 19개 엔드포인트. 기록 `archive/probe/riot-2026-08-02.json`

### 안 되는 것 — 기획서의 전제가 여기서 깨졌다

```
✕ 403  /lol/esports/v1/leagues              프로 리그·경기 — 개발자 API 에 없다
✕ 403  /lol/tournament-stub/v5/providers    토너먼트 — Production 승인 필요
✕ 403  /lol/spectator/v5/featured-games     실시간 픽·밴 — Personal Key 로 안 열린다
```

**「한국 선수·팀의 국제 대회 성적 집계」는 못 만든다.** Production 승인을 받아도
esports 는 애초에 개발자 API 의 범위가 아니다. 그건 미디어 파트너십의 영역이고
우리 체급의 일이 아니다.

> ⚠ `esports-api.lolesports.com` 은 **쓰지 않는다.** lolesports.com 이 내부적으로 쓰는
> 문서화되지 않은 주소다. 접근은 되지만 그건 「되니까 쓴다」이고,
> **오늘 관세청에서 배운 것과 같다 — 같은 데이터라도 경로에 따라 라이선스가 다르다.**

```
✅ TFT          챌린저
```

## 4. 그래서 상품은 무엇인가

### 상품 ① **랭크 사다리 시계열** — 유일하게 「우리만 가질 수 있는」 것

```
무엇   6개 지역 챌린저·그랜드마스터의 일별 분포
       인원 · LP 백분위 · 승률 · 1인 평균 판수
왜 우리만  소급이 안 된다. API 는 「지금」만 답한다.
          어제의 사다리를 되돌려 주는 엔드포인트가 없다.
          → 오늘 적기 시작한 사람만 1년 뒤에 1년치를 갖는다
```

**이것이 이 사업의 유일한 해자다.** 관세청 10일 잠정치를 오늘부터 받는 것과 같은 논리이고,
리서치 아카이브 66,071건을 2007년까지 채운 것과 같은 논리다.

**2026-08-02 부터 매일 22:00 KST 자동 수집 중이다.** 첫날 숫자만으로도 기사가 나온다 —
한국 챌린저 승률 53.64% 로 6개 지역 중 최저(= 가장 균질), EUW 는 중앙 LP 2,655 로 최고.

### 상품 ② **Data Dragon 기반 다국어 사전** — 승인도 키도 필요 없다

챔피언 233개가 한국어·영어·베트남어·인도네시아어로 다 있다. 버전이 496개 남아 있어
**패치별 변화를 소급해서 만들 수 있다.** WikiTip 의 다국어 전략과 정확히 맞물린다.

### 상품 ③ ~~프로 경기 데이터~~ — **없다.** 위 3장 참조

## 5. 라이선스 — 이 사업의 진짜 제약

```
개인·비상업     자유
상업(광고 포함)  Production 승인 필요 — ⚠ 아직 미신청
승인 조건       ① 무료 이용 층을 반드시 둘 것
                ② 「변형된(transformative)」 콘텐츠일 것 — 원본 응답 재판매 금지
표기 의무       Riot 이 문구를 지정한다. 그대로 쓴다
```

**우리 구조가 조건에 맞는다.** 전부 무료이고, 원본이 아니라 분포를 낸다.

> ⚠ **승인 전에 광고를 붙이면 약관 위반이다.** 수집·발행은 비상업이라 지금 해도 된다.
> 신청서는 `docs/신규사업/riot-production-신청서.md` 에 써 뒀고,
> 필요한 실물 지면 `https://seoulmarkets.com/esports` 는 2026-08-02 에 올렸다.

### ⚠ 개인정보 — 처음부터 안 담는 쪽으로 설계했다

API 응답에 `puuid`(플레이어 식별자)가 들어 있다. **수집 시점에 버린다.**
분포만으로 재현이 되고, **안 쌓으면 삭제 요구 대응 의무도 안 생긴다.**
데이터를 파는 회사에서 개인정보는 자산이 아니라 부채다.

## 6. 수익 — 정직하게, 크지 않다

**이 데이터를 팔아서 큰돈이 되지 않는다.** 그렇게 보고하는 것이 맞다.

| 경로 | 현실성 | 왜 |
|---|---|---|
| **광고** (WikiTip) | ○ **주 수익원** | 승인 뒤. 무료 도구로 유입, 광고로 회수 — 이미 WikiTip 모델 |
| 데이터 API 판매 | △ | 살 사람이 있다면 e스포츠 매체·베팅 쪽인데, **베팅은 안 한다**(아래) |
| 기사 유통 배분 | ○ | MSN·SmartNews 등 기존 경로에 그대로 얹는다 |
| B2B 라이선스 | ✕ 당분간 | 시계열이 최소 1년은 쌓여야 상품이 된다 |

**금융 데이터 사업(`tools/pricing.json`)의 가격 체계를 여기 그대로 붙이지 않는다.**
그쪽은 기관이 연 단위로 사는 시장이고, 여기는 광고 시장이다. **성격이 다르다.**

### 하지 않을 것

```
✕ 베팅·오즈 데이터   한국에서 불법 소지 · 규제 위험 · 우리 매체 성격과 정반대
✕ 선수 개인 추적     개인정보. 위 5장
✕ 프로 경기 데이터 우회 수집   문서화 안 된 내부 API 는 안 쓴다
✕ 유료 구독          Riot 조건상 무료 층이 필수이고, 이 데이터로 과금할 근거가 약하다
```


## 8. 확인 못 한 것 — 정직하게

- **e스포츠 데이터를 실제로 사는 곳이 있는지** 확인하지 못했다. 검색 결과에
  「e스포츠 애널리틱스 플랫폼 매출」 자료가 없었다. **시장이 없을 수도 있다.**
  그래서 이 보고서는 데이터 판매가 아니라 콘텐츠·광고로 결론을 냈다.
- **Riot Production 승인 통과율·소요 기간**을 확인하지 못했다.
- 위 시장 규모는 **조사기관 추정치**다. 기관마다 33억~45억으로 갈린다.
  단일 숫자로 인용하지 말 것.
