# 진로컨설팅 AI — 설계와 학습 대상

작성 2026-08-02 · **담당: 나** · 사장님 지시

> 「진로컨설팅 AI 를 만들어. **모든 검사와 진로를 판단**할 수 있게 해.
> 그리고 고객과 **1:1 상담**으로 **희망의 교육**을 열자. **현재는 절망의 교육**이야.
> **무엇을 학습해야 하는지 알아봐**」
> 「**당연히 보호자랑 같이 해야지**」

## 0. KLifeMap 이 이미 세운 원칙을 그대로 쓴다

사장님 지시로 `~/Documents/GitHub/klifemap` 의 AI 구조를 읽었다.
`tools/build-ai-corpus.js` 에 이런 줄이 있다.

> **「판정 자체는 엔진이 한다. 이 말뭉치는 *어떻게 설명하고 무엇을 말하지 않는가*를
> 가르치기 위한 것이다.」**

**이게 정답이고, 내가 투자 AI 에서 따로 도달한 결론과 같다.** 그대로 가져온다.

```
판정   결정론 엔진이 한다.  같은 입력 → 같은 답. 재현·감사 가능
설명   LLM 이 한다.        말투·순서·무엇을 말하지 않을지
```

**LLM 이 진로를 「정하지」 않는다. 정해진 것을 「말한다」.**
이 경계를 흐리면 같은 아이에게 두 번 다른 답을 주게 되고, 그 순간 상품이 무너진다.

### KLifeMap 구조에서 가져올 것

| 그쪽 | 내 쪽 |
|---|---|
| `ai/chatCoachEngine.js` | 1:1 대화 상태 관리 |
| `ai/reportEngine.js` · `reportSchema.js` | 리포트 생성 · 스키마 |
| `ai/promptTemplates` | 판정과 말투의 분리 |
| `ai/providers.js` | 모델 교체 |
| `ai/translate.js` | 다국어 (한중일 화교권에 그대로 필요) |
| `tools/build-ai-corpus.js` | **말뭉치를 거르는 방법** — 승인/교정/미검증 3분류 |

**새로 만들 것이 거의 없다.** 갈아 끼우는 것은 **판정 엔진과 학습 자료**뿐이다.

## 1. 보호자 동석 — 구조로 박는다

> 사장님: 「당연히 보호자랑 같이 해야지」

**아이와 AI 가 단둘이 대화하는 경로를 아예 만들지 않는다.**

```
계정      보호자 명의
세션      보호자가 연다
대화 이력  보호자가 본다
아이 단독 로그인   ← 만들지 않는다
```

이 한 줄이 세 문제를 동시에 푼다.

| 문제 | 어떻게 풀리나 |
|---|---|
| 법정대리인 동의 | 계정 자체가 보호자 것이라 **구조로 해결** |
| 위기 상황 | **혼자 있는 아이가 없다.** 사람이 옆에 있다 |
| 「AI 상담은 위험」 규제 | 규제가 겨누는 것은 **「아이 혼자 AI 와 대화」**다 |

### ⚠ 그래도 위기 대응은 넣는다

보호자가 옆에 있어도 대화 중에 신호가 나올 수 있다.
그리고 **보호자 본인이 위기일 수도 있다.**

```
① 위기 표현 감지 → 상담을 이어가지 않고 즉시 안내로 전환
② 고정 안내 — 자살예방상담 109 · 청소년전화 1388 (24시간)
③ 그 대화는 로그에 표시해 남긴다
④ 「괜찮아질 거예요」류로 넘기지 않는다 — 그게 가장 위험하다
```

**여성가족부·과기정통부가 청소년 위기징후 탐지 AI 를 시범운영 중이고,
「AI 에 고민 상담은 위험」이라는 청소년 가이드라인이 준비되고 있다.**
나오고 나서 붙이면 늦다. 처음부터 넣는다.

## 2. 판정 엔진 — **무엇으로 판단하나** (LLM 아님)

네 축을 결정론으로 계산한다. LLM 은 여기 개입하지 않는다.

| 축 | 입력 | 출처 |
|---|---|---|
| **① 기질** | 신강신약 · 성향(일간 음양오행+격) · 격국 | **KLifeMap 명리 엔진에서 세 값만** |
| **② 동기 구조** | 자율성 · 유능감 · 관계성 | 자기결정이론 기반 척도 |
| **③ 흥미·적성** | 진로심리검사 결과 | **커리어넷 진로심리검사 API** |
| **④ 결과 데이터** | 학과별 유지취업률 · 중도탈락률 · 임금 | 대학알리미 · 커리어넷 · 고용부 |

**①은 출발점이고 ④는 검증이다.** 넷이 다 있어야 「진로를 판단한다」가 성립한다.
하나라도 빠지면 사주 상담이거나 흥미검사거나 통계표일 뿐이다.

⚠ 명리는 **세 값만.** 운세·대운·궁합·택일·합격예측은 **가져오지 않는다.**
아이 진로에 시점 예측을 붙이면 진학 점집이 된다.

## 3. **무엇을 학습해야 하는가** — 사장님이 물으신 것

판정은 엔진이 하므로, 학습은 **「어떻게 말하고 무엇을 말하지 않는가」**다.
KLifeMap 과 같은 원칙이되 **자료가 다르다** — 나는 사장님이 가르쳐 주신 말뭉치가 없다.

### ① 커리어넷 **진로상담사례** — 이것이 학습 자료의 본체다

교육부 커리어넷 오픈API 에 **진로상담사례**가 있다.
**공공저작물 제1유형** — 출처만 밝히면 상업적 이용·변형·재배포가 된다.

```
실제 학생·학부모의 질문과 전문가의 답변
→ 어떤 질문이 오는지, 어떻게 답하는지, 무엇을 단정하지 않는지
→ 말투와 상담 구조의 원천
```

**이게 KLifeMap 의 「사장님 가르침 말뭉치」에 해당하는 자리다.**
그쪽은 사장님이 직접 가르치셨고, 내 쪽은 **교육부가 공개한 전문가 상담이 그 역할을 한다.**
라이선스가 깨끗해서 그대로 쓸 수 있다.

### ② 진로상담 이론 — 대화의 뼈대

| 이론 | 무엇을 대는가 |
|---|---|
| **Super 진로발달이론** | 진로는 한 번 정하는 것이 아니라 **자아개념이 자라며 발달**한다. 초등~고2 가 성장기·탐색기다 |
| **Krumboltz 우연학습이론** | 「계획된 우연」 — **미리 정해두는 것이 답이 아니다.** 호기심·인내·유연성·낙관·위험감수를 기른다 |
| **Savickas 진로구성이론** | 진로는 **이야기로 구성된다.** 아이가 자기 이야기를 만들게 돕는다 |

**셋 다 「하나로 정해준다」의 반대편에 있다.** 그래서 이 사업의 취지와 맞는다 —
「자기 삶을 주도하게 하는 교육」이 이 이론들의 언어로 이미 정리돼 있다.

### ③ 학습과학 — 무엇을 조언할 것인가

인출 연습 · 간격 반복 · 교차 연습 · 메타인지 · 자기조절학습.
**근거가 탄탄한 것만 쓴다.**

### ④ **금지 목록** — 이게 승인 목록만큼 중요하다

KLifeMap 이 「사장님이 되돌린 대목」을 따로 담은 것과 같은 자리다.
**교정이 승인보다 값지다.**

```
✗ 폐기된 신경신화   좌뇌형·우뇌형 · 학습유형(시각/청각/운동)별 수업 · 「뇌의 10%」
✗ 시점 예측         「언제 붙는다」 「이 학교에 간다」
✗ 단정              「이 아이는 이과다」 「이 직업이 맞다」
✗ 위로로 넘기기      위기 신호에 「괜찮아질 거예요」
✗ 학원 권유         우리는 학원을 팔지 않는다. 그게 우리 자리다
```

### ⑤ 말투 규격 — 문장이 끝나는 방식을 강제한다

기질 축의 문장은 **반드시 「먼저 시험해 보자」로 끝난다.**

```
✗  신약한 사주니 혼자 하는 일은 안 맞는다
○  지지가 있을 때 힘을 내는 아이다 — 그런 환경을 먼저 시험해 보자
```

**이건 학습이 아니라 템플릿으로 강제한다.** 학습에만 맡기면 새어 나간다.

## 4. 「절망의 교육」에서 「희망의 교육」으로 — 무엇이 다른가

사장님 말씀이 이 상품의 정의다. 구체적으로 무엇이 다른지 적어 둔다.

| | 절망 | **희망** |
|---|---|---|
| 시간 | **대입까지** — 그 뒤가 없다 | **대입 이후** — 10년 뒤를 본다 |
| 비교 | 남과 비교한 등수 | **어제의 자기와 비교** |
| 정보 | 「이 대학 가면 된다」 | **「가서 실제로 어떻게 됐나」**(유지취업률) |
| 주체 | 부모·학원이 정한다 | **아이가 정하고 어른이 검증한다** |
| 실패 | 끝 | 경로 수정 — 라이프맵을 다시 그린다 |
| 조언자 | **학원을 파는 사람** | **아무것도 안 파는 사람** |

**마지막 줄이 우리의 자리다.** 나머지는 그 자리에서 자연히 나온다.

## 5. 두 형태로 낸다 — 리포트와 대화

같은 판정을 두 형태로 낸다. **판정 엔진은 하나다.**

```
판정 엔진 ─┬─→ 진단 리포트   한 번에 읽는 것. 보호자가 저장하고 다시 본다
           └─→ 1:1 상담     되묻는 것. 「그럼 이 학과는요?」
```

**리포트가 먼저다.** 대화는 리포트를 근거로만 말한다 —
리포트에 없는 판정을 대화에서 새로 만들지 않는다. 그러면 재현이 깨진다.

## 7. 정직하게 — 약한 곳

**① 진로 판단의 정확도를 검증할 방법이 없다.**
투자는 맞았는지 나중에 안다. **진로는 10년 뒤에나 안다.**
그래서 「맞춘다」고 말하지 않고 **「무엇을 보고 판단했는지 전부 보여준다」**로 간다.
근거를 공개하는 것이 정확도를 주장하는 것보다 정직하고, 실제로 더 유용하다.

**② 커리어넷 상담사례의 양과 질을 아직 모른다.**
키를 받아 봐야 안다. 부족하면 진로상담 이론과 금지 목록만으로 시작하고
**말뭉치는 우리 상담 이력으로 쌓는다** — KLifeMap 이 사장님 대화로 쌓은 것과 같은 방식.

**③ 명리 세 값이 실제로 도움이 되는지 측정이 어렵다.**
①과 같은 문제다. **기질 축을 뺐을 때와 넣었을 때의 만족도**는 잴 수 있으니
그걸로라도 확인한다.

**④ 보호자 동석이 대화의 솔직함을 줄인다.**
아이가 부모 앞에서 못 하는 말이 있다. **이건 안전과 맞바꾼 것이고, 맞바꿀 만하다.**
다만 설계에서 보완한다 — 아이가 혼자 답하는 **비공개 문항**을 두되,
**그 답은 집계로만 반영하고 원문을 보호자에게 보여주지 않는다.**
