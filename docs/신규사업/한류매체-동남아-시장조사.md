# 한류/K-컬처 매체 — 동남아 시장 조사

작성 2026-08-01 · 지시: 「별개의 뉴스 사이트(한류/K-컬처)를 동남아 타깃으로」
**확인한 것과 확인 못 한 것을 구분해 적었다. 「미확인」은 근거를 못 찾은 것이지 없다는 뜻이 아니다.**

---

## 요약 — 결론 세 줄

1. **최대 시장은 인도네시아다.** 인구·인터넷·광고비 모두 1위. 단 영어가 안 통한다.
2. **1차 진입은 필리핀이다.** 호감도 세계 1위(87.0%)에 **영어권**이라 번역 비용이 0이다.
3. **사진은 문제가 아니다 — 인터넷신문 등록이 열쇠다.** 배급사·방송사 공식 배포 이미지는
   보도용으로 배포된 것이라 언론사가 자유롭게 쓴다. 다만 **그 관행은 언론사에게 적용된다.**
   등록이 첫 순서인 이유다. (섹션 3 — 2026-08-01 전면 개정)

## 1. 어느 나라가 가장 큰가

### 한류 호감도 (문체부 2026 해외한류실태조사, 표본 27,400명)

| 순위 | 국가 | 호감도 |
|---|---|---|
| 1 | **필리핀** | 87.0% |
| 2 | 인도 | 83.8% |
| 3 | **인도네시아** | 82.7% |
| 4 | **태국** | 79.4% |

전 세계 평균: 한국 문화콘텐츠 월평균 소비 **14.7시간**, 분야별 평균 지출 **16.6달러**
(전년 대비 각각 +0.7시간, +1.2달러)

### 시장 체급 (인터넷 인구 · 광고비)

| 국가 | 인터넷 인구 | 언어 | 비고 |
|---|---|---|---|
| **인도네시아** | 2억 1,000만 | 인도네시아어 | 동남아 디지털 광고 **1위**. K-pop 관련 트윗 연 100억건 세계 1위 |
| **필리핀** | 8,500만 | **영어 통용** | K-pop 온라인 팬 1,500만명 |
| **베트남** | 8,000만 | 베트남어 | 2026년 팬 인게이지먼트 +35% |
| 태국 | — | 태국어 | 호감도 79.4% |

동남아 광고 시장: 2026년 **187억 달러** → 2035년 494억 달러 (연 11.4%)

### 판단

**호감도 1위(필리핀)와 규모 1위(인도네시아)가 다르다.** 그래서 순서를 나눈다.

```
1단계  영어 단일 발행        → 필리핀·말레이시아·싱가포르 + 미국 팬덤
2단계  인도네시아어 추가      → 규모 1위 시장 진입
3단계  베트남어 → 태국어      → 인게이지먼트 순
```

영어로 먼저 가는 이유는 필리핀 하나 때문이 아니다. **영어 기사가 있어야 나머지 언어의
번역 원본이 된다.** 한국어 → 각국어보다 영어 → 각국어가 기계번역 품질이 훨씬 낫다.

## 2. 스타 뉴스인가, 컬처 뉴스인가

### 경쟁자 실측 — allkpop (Similarweb)

| 항목 | 값 |
|---|---|
| 월 방문 | 약 560만 (전월 대비 −8.9%) |
| 미국 | **48.8%** |
| 캐나다 | 8.5% |
| **말레이시아** | **4.9%** |
| 영국 | 3.9% |
| 호주 | 3.3% |
| 체류시간 | 2분 16초 · 2.58 페이지 · 이탈 56.7% |
| 성별·연령 | 여성 58.5% · 25–34세 최다 |
| 유입 | **직접 75.3%** (데스크톱), 다음이 검색 |

**여기서 가장 중요한 숫자는 미국 48.8% 다.**

allkpop·Soompi·Koreaboo 는 「한류 매체」라고 불리지만 실제로는 **미국·영어권 매체**다.
동남아에서 유의미한 나라는 말레이시아 4.9% 뿐이다.

> **동남아는 팬은 세계 최대인데 그들을 겨냥한 영문·현지어 매체가 비어 있다.**
> 이것이 이 사업의 근거다. 경쟁 상대는 allkpop 이 아니라 **아직 없는 것**이다.

또 하나 — **직접 유입 75.3%** 는 이 바닥이 검색이 아니라 **팬덤 습관**으로 돌아간다는 뜻이다.
SeoulMarkets(검색 중심)과 유통 전략이 근본적으로 다르다. 여기는 SNS·커뮤니티다.

### 스타 vs 컬처 — 답은 「스타로 모으고 컬처로 남긴다」

| | 스타 뉴스 | 컬처 뉴스 |
|---|---|---|
| 트래픽 | 폭발적, 즉시 | 완만 |
| 수명 | 2~3일 | 수개월~수년(검색) |
| 경쟁 | 극심 (속보 싸움) | 얕음 |
| 광고 단가 | 낮음 (연예 카테고리) | 중간 |
| 법적 위험 | **높음** (초상권·명예훼손·사진) | 낮음 |
| 진입 난이도 | 한국 소스 접근 필요 | 기획력만 있으면 됨 |

**속보 경쟁은 하지 않는다.** 한국 매체가 초 단위로 쏟아내는 걸 번역해서 이길 수 없고,
그 영역이 바로 사진 저작권 사고가 나는 곳이다.

**우리가 이길 자리 — 설명과 데이터**

- 컴백·차트·투어를 **숫자로** 다루는 기사 (SeoulMarkets 에서 하던 방식 그대로)
- 동남아 독자가 모르는 한국 맥락 설명 (소속사 구조, 병역, 계약 7년 관행, 음방 집계 방식)
- 현지 앵글: "이번 투어에 자카르타가 빠진 이유", "베트남 팬덤이 만든 기록"
- 산업 데이터: 하이브·SM·JYP·YG 실적, 음반 수출 통계 — **이건 우리가 이미 잘한다**

> **결정: 스타 뉴스로 유입을 만들되, 자체 취재 없이 번역만 하는 속보는 하지 않는다.
> 데이터·설명·현지 앵글이 본체다.** 이 조합이면 SeoulMarkets 의 데이터 파이프라인이
> 그대로 재사용된다 (엔터 4사 실적, 음반 수출액 = 관세청 HS코드, 공연 매출).

## 3. 사진·영상 — 언론사 지위를 전제로 다시 씀

> **[2026-08-01 정정]** 초판에서 소속사·방송사 배포 사진을 「조건부」로, 영화·방송
> 이미지를 「금지」로 분류했다. **틀렸다.** 변호사 블로그의 일반 저작권 법리에서
> 판단했고 **한국 언론계의 실제 관행을 보지 않았다.**
>
> 사장님 지시(20년 경제지 인터넷총괄에디터 경험): *「영화 이미지는 공식 사이트에서,
> 방송 이미지도 방송사 홍보부서·프로그램 웹페이지에서 모두 공짜로 허가 없이 사용 가능.
> 여긴 한국이고 이 관행은 수십 년째다. 특히 언론사에겐 더 자유롭다.」*

### 원리 — 왜 자유로운가

**배급사 공식 사이트의 스틸·포스터, 방송사 홍보부서와 프로그램 페이지의 이미지는
애초에 「보도용으로 쓰라고」 올려놓은 것이다.** 배포 목적 자체가 언론 게재다.

즉 이건 「저작권자가 모르는 무단 사용」이 아니라 **배포 목적에 부합하는 사용**이다.
홍보부서는 기사가 나가야 일이 되는 조직이므로, 이용을 막을 유인이 없다.
수십 년간 한국 연예·문화 보도가 이 위에서 돌아갔고 분쟁이 사실상 없다.

**언론사에게 더 자유로운 이유**도 같다. 홍보 자료는 매체를 겨냥해 배포된 것이고,
저작권법의 시사보도·인용 규정도 언론 보도를 전제로 설계돼 있다.

### 다만 하나 — 우리는 해외로 발행한다

이 관행은 **한국 매체가 한국어로 한국 독자에게** 보도하는 환경에서 굳어진 것이다.
우리는 **영문으로 미국·동남아 독자에게** 낸다. 그 자체가 문제라는 뜻이 아니라,
**한국 관행을 모르는 시스템을 하나 더 거친다**는 뜻이다.

| 상대 | 한국 관행이 통하나 |
|---|---|
| 한국 배급사·방송사·기획사 | **통한다.** 오히려 반긴다 — 홍보가 되니까 |
| Google AdSense · DMCA 처리 | **모른다.** 자동 신고에는 사람 판단이 없다 |

그래서 위의 **운영 규칙 2번(배포처 기록)** 이 필요하다. 신고가 들어와도
「이 이미지는 ○○ 배급사 공식 보도자료 페이지에서 ○월 ○일 받았다」를 즉시 제시하면
반론이 끝난다. **막자는 게 아니라 30초 만에 소명하자는 것이다.**

### 우리가 만들 수 있는 시각물 — 이건 그대로 유효하다

사진을 자유롭게 쓸 수 있어도 **직접 만든 그래픽은 별도의 무기다.**

- 차트: 앨범 판매·스트리밍·차트 순위 (SeoulMarkets 의 SVG 차트 코드 재사용)
- 지도: 투어 도시, 팬덤 분포
- 타임라인: 컴백 일정, 데뷔 계보
- 표: 소속사별 아티스트, 계약 만료 시점

**allkpop 에는 차트가 없습니다.** 데이터저널리즘 기법을 연예에 가져오는 곳이 없습니다.
사진은 누구나 같은 걸 씁니다 — 홍보부서가 모두에게 같이 배포하니까요.
**차트는 우리만 있습니다.** 차별점은 사진이 아니라 여기입니다.

## 4. 「한류 기사를 비싼 값에 판다」 — 검증 결과

지시하신 가설: *머니투데이 스타뉴스, 위키트리(공씨)가 한류 기사를 비싼 값에 팔고 있을 것*

### 확인한 사실

**① 스타뉴스 (머니투데이 계열)**
- 2004년 머니투데이가 시작한 연예 매체
- **영문 서비스를 이미 운영 중**: `starnewskorea.com/en`
- 섹션: Latest / Entertainment / Sports / Star Ranking / Music / Broadcast
- **페이지에 "Translated by AI" 라고 명시.** 번역 정확성 무보증, 원문 확인 권고 문구 있음
- 사진 출처 표기 없음. 자체 CDN(`image.starnewskorea.com`)
- **신디케이션·라이선스·파트너십·연락처 페이지 없음**

**② 위키트리 (㈜소셜뉴스, 대표 공훈의)**
- 공훈의: 2000년 귀국해 **머니투데이 CIO** 로 합류, 온라인 시스템·수익모델 개발 주도.
  2010년 2월 위키트리 창업 → 사장님 기억이 정확합니다
- 직원 41명, 업력 16년, 서울 중구
- **「위키트리 글로벌」 — 구글 클라우드 기반 71개 언어 발행.** 구글 번역기로 전 콘텐츠 자동 전환
- 영어·스페인어·프랑스어는 **현지인 글로벌 에디터** 배치
- 공식 수익 모델 소개: **큐레이션 + 네이티브 광고**
- 페이스북 단일 채널로 월 3억 뷰(2017년 기준)

### 판단 — 가설은 부분적으로만 맞습니다

**「기사를 비싼 값에 판다」는 증거를 찾지 못했습니다.** 확인된 두 회사의 모델은 판매가 아니라
**자체 다국어 발행 + 광고**입니다. 기사를 남에게 파는 게 아니라, 직접 71개 언어로 뿌려서
광고를 붙입니다.

⚠ 다만 **B2B 신디케이션 계약은 원래 공개되지 않습니다.** 없다는 증명은 아닙니다.
확인하려면 두 회사 감사보고서의 매출 구성을 봐야 합니다 — DART 에서 확인 가능합니다.

### 그런데 이 결과가 더 중요합니다

**공씨의 진짜 전략은 「번역해서 71개국에 뿌린다」입니다. 그리고 그건 이미 4년 넘게
돌아가고 있습니다.** 스타뉴스도 AI 번역 영문판을 이미 냅니다.

즉 **「한국 기사를 번역해서 해외에 낸다」는 이미 레드오션입니다.**
우리가 그걸 또 하면 늦게 들어간 후발주자일 뿐입니다.

**빈칸은 다른 데 있습니다.**

| 그들이 하는 것 | 비어 있는 것 |
|---|---|
| 한국어 원문의 기계번역 | **동남아 독자를 위해 새로 쓴 기사** |
| 71개 언어 얕게 | **인도네시아어 하나를 제대로** |
| 속보 번역 | **데이터·차트·설명** |
| 현지 앵글 없음 | **"자카르타 공연이 왜 빠졌나"** |
| 사진 출처 불명 | **임베드·자체 그래픽** |

기계번역은 읽히긴 해도 **현지 독자에게 말을 걸지는 않습니다.** 71개 언어를 한 명이 관리하면
어느 언어도 편집자가 없습니다. 우리는 반대로 갑니다 — **적은 언어, 진짜 편집.**
