## 1. 판정은 두 단계다 — 주제와 문체를 나눠서 본다

**이 둘을 섞으면 판단이 흐려진다.** 주제가 맞는데 문체가 안 맞는 글을 버리게 되고
(아깝다), 주제가 안 맞는 글을 문체만 고쳐 싣게 된다(사이트가 흐려진다).

```
① 주제가 맞는가?        아니오 →  ✕ 안 가져온다. 고쳐도 안 된다
        ↓ 예
② 문체가 맞는가?        아니오 →  ✏ 고쳐서 싣는다  ← 사장님 지시
        ↓ 예
      그대로 싣는다
```

### ① 주제 — 맞는 것과 안 맞는 것

| | |
|---|---|
| ✅ 싣는다 | K-pop · 한국 드라마 · 한국 영화 · **한국 e스포츠** · 그 산업의 데이터 |
| ✅ 싣는다 | 동남아 독자가 한국 문화를 볼 때 필요한 맥락 (한국어 보도가 안 해주는 것) |
| ✕ 안 싣는다 | 한국과 무관한 것 — 프랑스·중국 요리, 일반 생활정보 |
| ✕ 안 싣는다 | 연예인 사생활·루머·확인 안 된 열애설 |
| ✕ 안 싣는다 | 베팅·오즈 (Riot 약관에도 걸린다) |

**2026-08-03 실제 판정 사례** — `wikitip.tistory.com` 51편을 전수로 봤다.
프랑스 요리·중국 요리·스테이크·베이킹·보충제·피부관리. **한 편도 ①을 통과하지 못했다.**
건수(56편)만 보고 「자산」이라 했던 것이 잘못이었다. **건수는 가치가 아니다.**

### ② 문체 — 맞지 않으면 **고쳐서** 싣는다

주제가 맞으면 버리지 않는다. 아래로 고친다.

```
언어      **영어.** 예외 없다. 한국어 원문이 있으면 번역이 아니라 영어로 다시 쓴다
          (기계번역 티가 나면 구글이 저품질로 본다. 영어 독자에게 자연스러운 문장으로)
길이      한 편이 한 가지를 말한다. 여러 주제를 한 글에 담지 않는다
숫자      **주장 대신 숫자.** 「인기가 많다」가 아니라 「챌린저 승률 53.64%」
출처      모든 숫자에 출처와 기준시각. SeoulMarkets 과 같은 규칙이다
제목      낚지 않는다. 글이 답하는 질문을 그대로 쓴다
고지      데이터 출처 표기. Riot 데이터에는 Riot 지정 비공식 고지를 반드시
```

**「수정해서 올려」는 「대충 손봐서」가 아니다.** 위 여섯 줄을 다 통과시키는 것이다.
통과 못 시킬 것 같으면 그 글은 안 싣는 편이 낫다 — 한 편의 저품질이 사이트 전체
평가를 깎는다.

## 2. e스포츠 — 이 축의 규칙

```
✅ 싣는다   지역별 랭크 사다리 분포 · 한국이 왜 강한가를 숫자로
           패치·챔피언 변화 (Data Dragon)
✕ 안 싣는다 선수 개인 점수화 · 개인 식별자 · 특정 선수 비난
✕ 안 싣는다 프로 경기 데이터 — 개발자 API 에 없다(403 실측).
           문서화 안 된 lolesports 내부 주소는 쓰지 않는다
⛔ 승인 전  **광고를 붙이지 않는다.** Riot Production 승인 전 광고는 약관 위반이고
           벌은 API 접근 영구 박탈이다. `Base.astro` 의 `noAds` 로 코드에서 막아 뒀다
```

상세: `docs/신규사업/riot-production-신청서.md`

## 3. 옮겨올 콘텐츠를 검토하는 절차

**옮기기 전에 제목이라도 전수로 읽는다.** 51편 뽑는 데 2분 걸렸다.

```bash
# ① 어디에 무엇이 있나 — 루트만 보지 말 것. 하위 도메인에 본체가 있을 수 있다
for h in example.com a.example.com 2023.example.com korea.example.com; do
  echo "$h $(curl -s "https://$h/sitemap.xml" | grep -c '<loc>')편"
done

# ② 제목을 전수로 뽑는다 (내용을 봐야 판정할 수 있다)
curl -s https://<blog>/sitemap.xml | grep -o '<loc>[^<]*' | sed 's/<loc>//'
```

**두 번 틀린 자리다.**
- 루트만 보고 하위 도메인을 안 봤다 → 인텔리티비 407편을 「1편」이라 했다
- 건수만 보고 내용을 안 봤다 → 요리 글 51편을 「버리면 안 될 자산」이라 했다

## 4. 안 지키면 무엇이 깨지나

**주제 일관성이 검색 노출을 정한다.** 구글은 사이트가 무엇에 관한 곳인지를 본다.
K컬처 사이트의 절반이 요리 글이면 그 사이트는 무엇도 아닌 곳이 된다.

**그리고 광고 단가가 주제로 정해진다.** 흐린 사이트에는 흐린 광고가 붙고
단가가 내려간다. 콘셉트를 지키는 것이 곧 수익 방어다.
