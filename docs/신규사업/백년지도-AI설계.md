## 1. 백년지도 AI 셋 — 같은 구조로 간다

| | 이름 | 하는 일 | 무엇으로 만드나 |
|---|---|---|---|
| ① | **판정 엔진** | 공공데이터 → 사실 판정 | ⛔ **LLM 아님.** 규칙 코드 |
| ② | **해설 AI** | 판정을 사람 말로 옮긴다 | LLM |
| ③ | **동행 상담 AI** | 보호자와 아이가 **함께** 쓰는 상담 | LLM + ①의 판정 |

### ① 판정 엔진 — 이미 절반은 만들어져 있다

지금 학과 페이지가 이미 이 방식이다. `attach-employment.mjs` 가 KOSIS 수치를 붙이고,
페이지가 **규칙으로 문장을 만든다**(LLM 이 쓰지 않는다).

```
특성화고를 졸업하고 취업한 100명 가운데, 1년 뒤에도 그 자리에 남아 있는 사람은 82명입니다.
2년 뒤에는 67명이 됩니다. 1년 사이에 15명이 그 자리를 떠났습니다.
```

이 문장에는 **LLM 이 한 글자도 안 들어갔다.** 숫자가 바뀌면 문장도 같이 바뀐다.

⭐ **이 원칙을 끝까지 지킨다 — 숫자는 LLM 이 만들지 않는다.**
진로를 두고 하는 말이라, 틀린 숫자가 그대로 아이의 선택이 된다.

### ② 해설 AI — LLM 이 쓰는 것은 「뜻」이지 「숫자」가 아니다

| LLM 이 쓰는 것 | LLM 이 쓰지 않는 것 |
|---|---|
| 「이 숫자가 당신 아이에게 무슨 뜻인가」 | 숫자 그 자체 |
| 「이 길을 고른 사람들이 어디서 힘들어했나」 | 학과명·학교명·통계 수치 |
| 「무엇을 더 알아봐야 하나」 | 「이 학과가 좋다/나쁘다」 판정 |

구조 — **숫자는 프롬프트에 값으로 넣고, 출력에서 숫자를 다시 검증한다.**
출력에 원본에 없던 숫자가 나오면 **버린다.** (①의 판정값과 대조)

### ③ 동행 상담 AI

⚠ **보호자 동석이 구조다.** 아이가 혼자 AI 와 대화하는 경로는 만들지 않는다 (사장님 지시).
로그인·세션 설계에서부터 이걸 강제한다. 나중에 붙이는 기능이 아니다.

## 2. ⛔ 지키는 선 — 이것부터 정하고 만든다

| | 왜 |
|---|---|
| **숫자는 LLM 이 만들지 않는다** | 틀린 숫자가 아이의 진로를 바꾼다 |
| **「몇 위」를 만들지 않는다** | 그게 줄세우기다. 사장님 지시 |
| **「이 학과가 맞다/안 맞다」로 쓰지 않는다** | 1번도 같은 규칙이다 — 「같은 직업도 사람에 따라 잘 풀리는 방식이 다르다」 |
| **겁을 줘서 팔지 않는다** | 사장님 지시 (1번 메모에서 확인) |
| **추정한 것은 추정이라 밝힌다** | 계열 추정·이름 매칭이 이미 그렇게 돼 있다 |
| **아이 혼자 대화하는 경로 없음** | 보호자 동석이 구조 |
