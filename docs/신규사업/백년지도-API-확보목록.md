## 1-4. ⛔→✅ 대학알리미 — 크롤링은 막혔고, 정식 창구가 열려 있다

```
robots.txt   User-agent: *
             Disallow: /          ← 전면 차단
```

**규칙 Ⅴ-3 대로 우회하지 않는다.** 그런데 같은 사이트의 공공데이터 이용정책은 정반대다 —

> 「대학알리미에서 제공하는 공공데이터는 공공데이터법에 따라 **누구나 이용가능하고,
> 영리목적의 이용을 포함한 자유로운 활용이 보장**됩니다」
> 「공공데이터포털을 통해 제공 중인 공공데이터는 **별도의 신청절차 없이 이용 가능**하며」

즉 **막힌 것은 「우리가 긁는 것」이지 「데이터를 받는 것」이 아니다.** 순서는 이렇다.

## 1-5. ⛔ KESS — **8월 3일 판단을 취소한다**

8월 3일 문서에 「키도 로그인도 필요 없다, curl 로 부르면 된다」고 적혀 있다. **틀렸다. 두 가지가 걸린다.**

**(1) robots 가 그 경로를 막고 있다**

```
User-agent: *
Disallow: /ad*   /mobile/po*   /mobile/co*   /po*   /co*   /ksearch*
```

받으려던 주소가 `/contents/dataset` 과 `/contents/dataSet/downLoad.do` 다. **둘 다 `/co*` 에 걸린다.**
게다가 `Python`·`aiohttp`·`GPTBot`·`Googlebot` 등은 이름을 찍어 `Disallow: /` 로 막아 뒀다 —
**스크립트 접근을 막겠다는 뜻이 분명하다.**

**(2) 라이선스가 정면으로 충돌한다**

| 문서 | 내용 |
|---|---|
| 공공데이터 이용정책 | 「영리 목적의 이용을 포함한 자유로운 활용이 보장」 |
| **지적재산보호정책** | 「제공받은 컨텐츠는 **개인열람의 목적으로만** 사용해야」<br>「서면 동의 없이 … 재배포 … **인터넷 사이트 제작/구성 및 데이터베이스 구축에 이용**하는 것,<br>기타 **영리적 목적으로 활용하는 것은 법으로 금지**」<br>「공공누리 **제4유형**을 부착하여 개방」 |

**공공누리 제4유형 = 출처표시 + 상업적이용금지 + 변경금지.** 백년지도는 영리 서비스이고
우리가 하는 일이 정확히 「데이터베이스 구축」과 「변경(가공)」이다. **그대로는 못 쓴다.**

⭐ **이것도 관세청과 같은 패턴이다 — 같은 데이터라도 경로가 다르면 조건이 다르다.**
KESS 홈페이지 직접 다운로드(4유형·개인열람)와 공공데이터포털 경유(공공데이터법·영리 자유)가 갈린다.

**결론 — KESS 직접 수집은 하지 않는다.** 같은 숫자를 아래 둘로 받는다.

```
① 공공데이터포털의 한국교육개발원 데이터셋      포털이 열렸으니 지금 확인 가능
② KOSIS 교육 통계                             약관에 상업적 활용이 명시돼 있다 (1-6)
```

포털 하단 「분야별 데이터포털」에 **교육통계서비스가 링크돼 있다** — 포털 등록 경로가 있다는 뜻이다.

## 1-7. ⭐ NEIS — 키 없이도 응답한다. 다만 5행씩이다

```
호출    https://open.neis.go.kr/hub/schoolInfo?Type=json&pIndex=1&pSize=5
결과    INFO-000 정상 처리 · list_total_count = 12,665
robots  없다 (404)
```

**실측한 것**

| 시험 | 결과 |
|---|---|
| 키 없이 호출 | ✅ 된다 |
| `pSize=100` · `pSize=1000` | ⚠ **무시된다. 5행만 온다** |
| `pIndex=6` 이상 | ✅ 된다 (페이지는 계속 넘어간다) |
| `schoolMajorinfo`·`hisTimetable`·`SchoolSchedule` | ERROR-300 「필수 값 누락」 — **교육청코드·학교코드가 먼저 필요하다** |

**그래서 순서가 정해진다** — `schoolInfo` 로 전국 학교 마스터(12,665건)를 먼저 받고,
그 코드로 학과·시간표·학사일정을 돈다. 마스터가 모든 것의 앞에 온다.

⚠ **무키로 12,665건이면 2,533회 호출이다.** 되기는 되지만 예의가 아니고 차단당하기 좋다.
**키가 있으면 pSize 1000 으로 13회면 끝난다.** → 사장님 소셜 로그인 1회가 필요한 이유가 이것이다.
