**승인에 시간이 걸리는 것부터 지금 신청한다.** 9월 1일에 신청하면 9월이 대기로 지나간다.

## ⭐ 지금 당장 되는 것 — **공공데이터포털 차단과 무관하다**

포털(data.go.kr)이 「전환 작업」으로 회원가입이 막혀 있어 그쪽 경유 API 가 전부 대기 중이다.
**그런데 아래는 별도 사이트라 지금 발급된다.** 이것부터 한다.

### 1. 나이스(NEIS) 교육정보 개방 포털 — **즉시 발급 · 회원가입 불필요**

```
주소     https://open.neis.go.kr/
인증키   https://open.neis.go.kr/portal/guide/apiGuidePage.do
로그인   구글·네이버·다음 계정으로 된다. 별도 회원가입 없음
발급     **신청 즉시.** 마이페이지에서 확인
비용     무료
```

**백년지도에 왜 필요한가** — 전국 학교의 사실 정보를 갖는다.
학부모가 「우리 아이 학교」로 시작할 수 있게 하는 진입점이다.

| 데이터셋 | 쓸 자리 |
|---|---|
| [학교기본정보](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN17020190531110010104913&infSeq=2) | 학교명·소재지·남녀공학·설립구분. **전국 학교 마스터** |
| [학교학과정보](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN14020190311111456561190&infSeq=2) | **특성화고 학과** — 「이 학과 나오면 어떻게 됐나」의 고교 축 |
| [고등학교시간표](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN18620200826103326268120&infSeq=2) | 실제 이수 과목. 진로 상담의 근거 |
| [학사일정](https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN17220190722175038389180&infSeq=2&cateId=A0005) | 입시·상담 시점 캘린더 |

> 개발자 가이드: https://open.neis.go.kr/portal/guide/apiGuidePage.do
> Open API 소개: https://open.neis.go.kr/portal/guide/apiIntroPage.do

⚠ 같은 데이터가 [공공데이터포털에도 있다](https://www.data.go.kr/data/15122275/openapi.do).
**포털 경유는 지금 막혀 있으니 NEIS 직접으로 간다.** 경로가 다르면 조건도 다르다 —
관세청에서 배운 것과 같다. **NEIS 직접 경로의 이용약관을 발급 시 확인해 기록한다.**

## ⬜ 키가 필요한지 아직 확인 못 한 것

**9월 착수 전에 확인만이라도 해 둔다.** 키가 필요하면 그때 신청하면 늦는다.

| | 주소 | 왜 필요한가 | 확인할 것 |
|---|---|---|---|
| **대학알리미** | https://www.academyinfo.go.kr/ | **학과별 취업률·유지취업률·중도탈락률.** 백년지도의 핵심 축이다 | API 가 있나, 없으면 공시 파일 다운로드로 되나 |
| 한국교육개발원 교육통계(KESS) | https://kess.kedi.re.kr/ | 진학·졸업·계열별 추이 | 〃 |
| 국가통계포털 KOSIS | https://kosis.kr/openapi/ | 인구·진학률 등 배경 통계 | 키 발급 절차 |
| 대입정보포털 「어디가」 | https://www.adiga.kr/ | 입시 결과·전형 정보 | API 제공 여부. **없을 가능성이 높다** |

⚠ **대학알리미가 제일 중요하다.** 「이 학과 나오면 실제로 어떻게 됐나」가
백년지도의 존재 이유인데 그 숫자가 여기 있다.
`docs/작업스케줄-2026하반기.md` 9월 항목에 **「대학알리미 아카이빙」**이 이미 잡혀 있고,
**커리어넷 없이도 되는 유일한 축**이라 승인 대기와 무관하게 진행할 수 있다.
