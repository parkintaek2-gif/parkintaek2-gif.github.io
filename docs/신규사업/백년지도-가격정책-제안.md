백년지도의 존재 이유였던 「학과별 취업률·유지취업률·중도탈락률」이 대학알리미에 그대로 있다.

## 1-2. 돈은 「사람」에서 나온다

| 형태 | 가격 |
|---|---|
| 온라인 컨설팅(단건) | 3만 ~ 10만원, 로드맵·첨삭 포함 시 30만원+ |
| 부분 컨설팅 | 회당 10만 ~ 30만원 |
| **대입 컨설팅 평균** | **172,000원** |

**정보는 공짜고, 해석은 비싸다.** 시장이 이미 그렇게 갈려 있다.

## 1-3. 그래서 백년지도가 파는 것은 「데이터」가 아니다

대학알리미가 **주지 않는 것**이 우리 상품이다.

| 대학알리미가 주는 것 | 대학알리미가 **안** 주는 것 = 우리 자리 |
|---|---|
| 학과별 취업률 (한 학교, 한 학과) | **그 학과가 어느 직업으로 이어지는지** |
| 유지취업률·중도탈락률 | **그 직업이 실제로 무슨 일을 하는지**(직무정보) |
| 65개 항목을 각각 | **학과 → 직업 → 직무 → 그 직업에서 인정받는 법(시상) / 잘리는 법(징계)** 을 한 줄로 |
| 대학만 | **고교(특성화고 학과)부터 대학 밖 경로(일학습병행·내일배움카드)까지** |
| 원자료 표 | 기준을 고르면 다시 정렬되는 **동적 순위표** |

⭐ **「대학 이후」가 그대로 상품 정의다.** 남들은 대학까지 주고 끊는다.

# Ⅲ. 제안 — 가격안

## 3-1. 기본 구조 — KLifeMap 의 「가격 사다리」를 그대로 가져온다

KLifeMap `pricing.json` 에 이런 판단이 적혀 있고, 백년지도에 그대로 맞는다.

> 「지금 최저가가 19,000원이라 처음 온 사람이 바로 29,000원을 질러야 한다.
>  **무료 만세력과 유료 사이가 절벽이다.** 무료 → 9,900 → 29,000 사다리를 만드는 것이 목적이다」

## 3-2. 안

| | 상품 | 값 | 무엇 |
|---|---|---|---|
| **무료** | 학교·학과 찾기 | **0원** | 전국 학교 12,665곳 · 학과 18,169건 조회. **미끼이자 SEO 자산** |
| **1단** | **학과 한 곳 파보기** | **9,900원** | 그 학과 → 이어지는 직업 → 실제 직무 → 취업률·유지취업률·중도탈락률. **한 장** |
| **2단** | **우리 아이 진로 지도** | **29,000원** | 관심 학과 3~5개 비교 + 대학 밖 경로(특성화고·일학습병행·내일배움카드) + **보호자용 대화 가이드** |
| **3단** | 「대학 이후」 심화 | **49,000원** | 그 직업에서 **인정받는 법(시상) / 잘리는 법(징계)** 까지. 모토 그대로 |
| **구독** | 학년 통과권 · 6개월 | **39,000원** | 입시 캘린더 + 공시 갱신 알림. 진학은 1회성이 아니라 학년 내내다 |
| **구독** | 학년 통과권 · 1년 | **59,000원** | |
| **B2B** | 학교·교육청·학원 | **협의** | 메이저맵이 여기서 번다. 우리도 여기가 본체가 될 수 있다 |

### 왜 이 값인가

- **9,900원** — KLifeMap 이 진입 상품으로 잡아 둔 자리와 같다. 무료와 유료 사이 절벽을 없앤다
- **29,000원** — 온라인 컨설팅 최저가(3만원) 바로 아래. 「컨설팅 한 번 값도 안 된다」가 성립한다
- **49,000원** — 대입 컨설팅 평균(172,000원)의 **1/3 이하**. 비교 대상이 명확하다
- **구독 39,000/59,000** — KLifeMap 전체이용권(6개월 149,000)보다 낮게 둔다.
  백년지도는 진학 시즌 상품이라 체류가 짧다
- ⛔ **10만원을 넘기지 않는다.** 넘는 순간 「사람이 붙는 컨설팅」과 비교당하는데, 우리는 사람이 없다

## 3-3. KLifeMap 에서 가져올 것 — 코드를 읽고 고른 것

| 자산 | 위치 | 가져올 이유 |
|---|---|---|
| **가격표 파일 분리** | `billing/pricing.json` | 숫자만 바꾸면 즉시 반영, 재배포 불필요. **오픈 직후 가격은 반드시 흔들린다** |
| **가격 사다리 주석** | pricing.json `_why` | 값의 근거를 파일 안에 남기는 방식. 나중에 왜 그 값인지 잊지 않는다 |
| **번들 규칙** | `general_bundled` | 선행 상품 보유 여부로 가격이 갈림 |
| **다건 할인** | `bundleDiscount` 2건 5%·3건 7%·4건 10% | 그대로 |
| **구독 범위 제외** | `_scopeNote` | 고가 상품을 구독에 넣지 않는 판단 |
| **판매가능 테스트** | `tests/product-sellability.test.js` | **팔 수 없는 상품이 가격표에 오르는 사고를 막는다.** 오픈 직전에 꼭 필요 |
| **쿠폰** | `tests/coupon-billing.test.js` | 오픈 프로모션 |
| **B2B API 요금 구조** | `apiPlans` 월 기본료 + 초과 건당 | 학교·학원 대상에 그대로 쓸 수 있다 |

⛔ **안 가져올 것** — `expertModeTopup`(최소 50만원 충전금 지갑). 백년지도는 학부모 대상이라
50만원 충전을 요구할 수 없다.

## 3-4. ⚠ 자기잠식 — 먼저 정리해야 한다

KLifeMap 가격표에 **진로·자녀 상품이 이미 있다.**

| 상품 | 단가 | 번들가 |
|---|---|---|
| `careerCoach` 진로 코칭 | 19,000 | 48,000 |
| `parentCoaching` 부모 코칭 | 29,000 | 58,000 |
| `childCareerCoaching` **자녀진로 코칭** | 29,000 | 58,000 |

**둘 다 「자녀 진로」를 판다.** 가르는 축은 이렇게 제안한다.

```
KLifeMap   명리 기반   「이 아이는 어떤 성향인가」        타고난 것
백년지도   공공데이터   「그 길로 가면 실제로 어떻게 됐나」   벌어진 것
```

**섞지 않는다.** 대신 서로 보낸다 — 백년지도 결과 화면 끝에 KLifeMap 을, 그 반대도.

# Ⅳ. 8/15 에 무엇을 열 것인가 — 두 갈래

## 갈래 A. PG 가 11일 안에 나온다면

위 가격표 그대로 연다. 다만 **1단(9,900원)만 켜고 나머지는 나중에 켠다.**
가격은 오픈 후 2주 데이터를 보고 조정한다 — 그래서 `pricing.json` 분리가 필요하다.

## 갈래 B. PG 가 안 나온다면 ← **이쪽 확률이 높다고 본다**

**무료로 연다. 결제는 나중에 붙인다.** 근거가 있다.

1. **지금 상품이 없다.** 오늘 확보한 건 학교 12,665 · 학과 18,169 뿐이고,
   **대학 축(대학알리미)은 아직 한 건도 없다.** 「대학 이후」의 대학이 비어 있다
2. **noindex 를 떼고 검색에 색인되는 데만 몇 주가 걸린다.** 유입 0 에서 유료로 열면 매출도 0 이다
3. **무료 구간이 어차피 필요하다.** 위 사다리의 맨 아래가 무료다. 그걸 먼저 여는 것뿐이다
4. 대신 **가입만 받는다.** 오픈 알림 신청 = 결제 붙는 날의 첫 고객 명단이다

⚠ **이건 「오픈을 미루자」가 아니다.** 8/15 에 여는 것은 그대로 하고, **파는 것을 미루는 것**이다.
