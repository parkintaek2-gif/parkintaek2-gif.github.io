# 기업·CEO 데이터를 이미 파는 곳들

실측 2026-08-04 08:2x KST · 사장님 지시

> 「**CEO 데이터를 모아 보도하는 작은 언론사들이 있다.
>  어디서 어떤 데이터를 갖고 와서 쓰는지 확인해 봐.**」
> 「얘네들이 **보도자료를 각 언론사에 많이 뿌리거든.** 자체 보도도 하지만
>  보도자료를 많이 뿌려. **그것도 확인해 봐. 그러면 찾기 쉬울 거야**」
> 「사장이 헤럴드 출신(내외경제)」 · 「한 군데는 일요신문·경향신문 출신, 고려대 졸업」
> 「한 군데 이름이 **CEO랭킹** 뭐 비슷했던 거 같아」

**사장님이 이름을 대 주셔서 찾았다. 검색만으로는 못 찾았을 것이다.**
이 바닥은 검색 최적화가 안 돼 있어서, 아는 사람이 짚어 줘야 나온다.

## 2. ⭐ 구조가 우리와 같다 — 이미 검증된 모델이다

**CEO스코어가 데이터 판매와 언론을 두 개로 분리해 놨다.**
CEO랭킹도 똑같이 둘이다. 사장님이 정하신 「**데이터 제공 + 언론 보도**」와 같은 형태다.

```
데이터 쪽   ceoscore.co.kr      ceoranking.com      → 유료. 장바구니·회원
언론 쪽     ceoscoredaily.com   ceorankingnews.com  → 무료. 보도자료 배포
```

**새로 발명할 게 아니다. 되는 게 확인된 구조다.**

### 보도자료가 실제로 퍼진다 — 사장님 말씀대로다

국민일보·서울이코노미뉴스·네이트가 「**CEO스코어가 조사한 결과**」로 그대로 받아 쓴다.
뉴스스페이스는 아예 「**랭킹연구소**」라는 **고정 코너**로 CXO연구소 데이터를 정기 게재한다.

**한 번 뿌리면 수십 곳이 받아 쓰고, 출처에 이름이 박힌다.**
우리가 아직 언론사가 아니어도 되는 경로가 이것이다 —
「언론이 아닌 곳은 보도자료를 배포함」이라고 사장님이 가르쳐 주신 그대로다.

---

## 3. ⚠ 그런데 여기서도 「상을 파는」 구조가 보인다

CEO랭킹뉴스 메뉴에 **「어워즈」와 「CEO골프대회」**가 있다. 광고·제휴 표기도 잡혔다.

사장님이 앞서 짚어 주신 것과 정확히 맞는다 —
「언론사들이 **상을 만들어서 돈을 벌지**」.

**기업 평가를 하는 곳이 그 기업에게 상을 준다.** 평가의 독립성이 여기서 흔들린다.
⚠ 우리는 이 길로 가지 않는다. 시상을 만들면 **적중률 데이터의 신뢰가 통째로 죽는다.**
투자 AI 셋에서 리스크 관리자를 독립시킨 것과 같은 이유다.

## 4. ⭐ 빈자리 — 그들은 **재무**를 하고, 우리는 **사람**을 한다

축이 갈린다. 이게 우리 자리다.

| | 그들 | 우리 |
|---|---|---|
| 축 | 매출·순이익·성장성·수익성·안전성·활동성 | **근속·급여·성별격차·임원 재직기간·학력** |
| 단위 | 회사 | **회사 + 사람** |
| 질문 | 이 회사가 잘하나 | **이 회사에서 사람이 어떻게 사나** |
| 독자 | 투자자·거래처 | 투자자 **+ 취업준비생·학부모** |

**「1인평균급여 순위」를 그들이 안 한다.** 재무 등급에 안 들어가는 항목이라서다.
그런데 그게 사장님이 바로 짚으신 것이고, **개인에게 가장 절실한 숫자**다.

그리고 우리에게는 그들에게 없는 게 하나 더 있다 —
**애널리스트 리포트 66,105건.** 재무 데이터는 사면 되지만 이건 1년을 모아야 생긴다.

⚠ 다만 그들이 **외감법인 32,000개**를 다룬다. 우리는 상장사 2,900개다.
비상장 대기업이 빠져 있다. 감사보고서 경로를 따로 봐야 한다.
