# 지방 스포츠 연중기획 15건 — 순위

**2026-09-29 · 5번(총괄)**

> 사장님 지시 — 「연중기획 15건 순위 매겨서 메일로 보내」

---

## Ⅰ. 무엇을 잣대로 세웠나

### 1-1. 규정이 정한 것 (제8조 제5항 가)호 (ㄱ) 원문)

> 「'심층보도'란 단순한 사실 전달을 넘어 **독자적 취재 및 자료 분석**을 통해 독자 및
> 시청자에게 의미 있는 정보를 제공하는 기사를 의미. 즉, 해당 보도는 사건 혹은 이슈의
> **배경, 구조, 이해관계, 사회적 의미**를 깊이 있게 조명하여 **새로운 정보, 문제의식,
> 해석**을 제공해야 함」

그래서 세 가지를 잽니다.

```
㉮ 남의 표를 옮기지 않고 «우리가» 자료를 분석하는가
㉯ 배경·구조·이해관계를 짚는가 (사건 하나를 크게 쓰는 것이 아니다)
㉰ 새로운 해석 또는 대안이 나오는가
```

### 1-2. 제가 덧붙인 것 — 「열두 달을 버티는가」

연중기획은 한 번 잘 쓰는 것이 아니라 **열두 번을 버티는 것**입니다.
그래서 규정 점수가 같으면 아래로 갈랐습니다.

```
㉱ 자료가 «이미» 세상에 공개돼 있나 — 없으면 둘째 달에 멈춥니다
㉲ 사람을 섭외하지 않고 굴러가나 — 사장님 지시(사람을 거치는 계획 금지)
㉳ 달마다 «다른 각»이 나오나 — 같은 말을 열두 번 하면 연중기획이 아닙니다
㉴ 충북·청주의 고유한 이야기인가 — 전국 어디에나 해당하면 지역지가 쓸 까닭이 없습니다
```

### 1-3. ⚠ 순위를 매기기 전에 제가 실제로 재 본 것

「자료가 있을 것 같다」와 「있다」는 다릅니다. 충청북도 공식 페이지에서 직접 확인했습니다.

| 무엇 | 실측값 | 기준 시점 |
|---|---|---|
| 충북 직장운동경기부(실업팀) | **50팀 · 410명** | 2026. 6 |
| 충북 공공체육시설 | **3,152개소** | 2026. 7 |
| 제천시 동네 생활체육시설 | **33개** (시군 격차의 실물) | 2026 |

⇒ 1위·3위로 올린 두 건은 **자료가 있다는 것을 제가 눈으로 확인한 것**입니다.
  나머지는 출처만 확인했고 수까지는 아직 못 쟀습니다. 그 구분을 표에 적었습니다.

## Ⅲ. 왜 이 차례인가 — 위 다섯만

### 3-1. 1위 · 충북 실업팀 생존기

```
규정   창단·해체의 «이해관계»(시군 재정)를 짚고, 예산 대비 성적이라는 «새 해석»을 낸다
자료   제가 직접 확인 — 50팀 410명(2026.6). 지방재정365 보조금 공시와 맞댈 수 있다
달마다 1월 총정리 → 종목별 → 도민체전·전국체전 성적 교차 → 12월 차년도 예산안
사람   섭외가 필요 없다. 전부 공시 자료다
```

⭐ 결정적인 것 — **실업팀은 연중 실제로 생기고 없어집니다.**
  다른 기획은 자료가 1년에 한 번 갱신되지만, 이것은 사건이 계속 붙습니다.

### 3-2. 2위 · 충북 체육시설 격차 지도 (두 건을 합쳤습니다)

중부매일 안(격차)과 제 안(건립비 대비 이용률)은 **같은 자료를 앞뒤에서 보는 것**입니다.
따로 하면 둘 다 얇아지고, 합치면 「몇 개 있나 → 얼마 들었나 → 쓰이나」로 한 줄이 섭니다.

```
자료   제가 직접 확인 — 충북 3,152개소(2026.7) · 제천 동네시설 33개
새 것  「부족하다」는 상투구를 «인구 대비»로 뒤집거나 확인한다
덤    예산 기사라 경제 카테고리로도 제출할 수 있다
```

### 3-3. 3위 · 충북 학생선수 유출 지도

```
규정   현상 뒤의 «구조»(처우·시설)를 짚고 «대안»(장학금·전용시설)까지 간다 — 세 요건을 다 채운다
달마다 3월 초→중 · 가을 중→고 · 겨울 대학 특기자 — 학사일정이 달을 저절로 나눈다
약점  선수등록시스템의 소속 변경 이력을 어디까지 볼 수 있는지 아직 못 쟀다
```

### 3-4. 4위 · 충북 체육예산 성적표

제 ⑤번과 중부매일 ④번이 같은 것이라 합쳤습니다. **1위와도 자료가 겹칩니다** —
1위가 「팀」을 보고 이것은 「돈」을 봅니다. 둘 다 하면 독자가 같은 기사로 읽습니다.
⇒ **1위를 먼저 굴리고, 이것은 5월 소년체전·10월 전국체전에 맞춰 두 번만 씁니다.**

### 3-5. 5위 · 충북 출신 프로선수 지도

```
강점  선수 이름이 제목에 들어간다 — 열다섯 건 가운데 «검색 유입»이 가장 세다
약점  규정의 ㉰(새 해석·대안)가 약하다. 「유출」이라는 문제의식을 붙여야 심층이 된다
```

⇒ 3위(학생선수 유출)와 **한 기획의 앞뒤**로 묶는 편이 낫습니다 —
  고등학교까지가 3위, 프로 이후가 5위입니다.

## Ⅳ. 빼거나 미루자고 보는 것

### 4-1. 12위 · 충북 은퇴선수 그 후 — 규정 점수는 가장 높지만 순위는 낮췄습니다

중부매일 계정은 이것을 「가장 나은 셋」에 넣었고, **규정만 보면 그 판단이 맞습니다.**
공개되지 않은 명단을 직접 대조하는 것이라 「독자적 자료 분석」을 제일 세게 채웁니다.

그런데 두 가지를 재 보니 걸립니다.

```
🔴 은퇴선수가 «지금 무엇을 하는지»는 공개 자료로 안 나온다.
   지도자 등록 여부까지는 대조할 수 있지만, 전직·무직은 본인에게 물어야 안다
   ⇒ 사장님 지시 「사람을 거치는 계획을 세우지 않는다」에 걸린다
🔴 그리고 개인의 «무직» 여부를 우리가 세어 내는 것은 회사 강령에도 맞지 않는다
   (「사람이 스스로 정하도록 돕는 것」이지 사람을 세는 것이 아니다)
```

⇒ **버리지는 않습니다.** 「은퇴 후 지도자로 남은 비율」처럼 **공개 자료로 셀 수 있는 축**으로
  좁히면 살아납니다. 그렇게 좁힌 뒤에 다시 올리겠습니다.

### 4-2. 14·15위 — 겹쳐서 내린 것입니다

제 ⑤(스포츠 예산)는 4위와, 제 ②(공공체육시설 이용률)는 2위와 같은 기획입니다.
**열다섯이 아니라 열셋**으로 보시면 됩니다. 겹친 둘은 위 기획에 흡수했습니다.

## Ⅴ. 제가 권하는 실제 편성

연중기획 하나로 열두 달을 채우기보다 **세 갈래로 굴리는 편**이 규정에도 유리합니다.
카테고리마다 최소 1건씩을 따로 채워야 하기 때문입니다.

```
본 갈래 (매달)     1위 충북 실업팀 생존기        — 스포츠 카테고리
곁 갈래 (분기)     2위 체육시설 격차 지도        — 경제·사회 카테고리로도 제출
학사 갈래 (3·9·12월) 3위+5위 선수 유출 ~ 프로 진출  — 스포츠 카테고리
```

⚠ 다만 **규정을 다시 읽어 보니 사장님이 아신 것과 세 군데가 다릅니다.**

| | 사장님이 아신 것 | 규정에 적힌 것 |
|---|---|---|
| 주기 | 매월 | 뉴스제휴위가 특정한 **3개월** 치를 한 번에 낸다 |
| 건수 | 카테고리별 1건 | 카테고리마다 최소 1건 **+ 총 24건**(일간지·카테고리 5개 이상) |
| 쓰이는 곳 | 운영 평가 | **제휴 심사** 항목이다 (운영 평가 <표.16>에는 없다) |

⇒ 그래서 이 연중기획은 **「매달 숙제를 채우는 것」이 아니라 「제휴 심사 때 낼 24건을
  미리 쌓아 두는 것」**으로 보는 편이 맞습니다. 그 관점에서도 위 편성이 유리합니다 —
  한 갈래로 열두 건을 쌓으면 카테고리가 하나뿐이라 총 건수를 못 채웁니다.
