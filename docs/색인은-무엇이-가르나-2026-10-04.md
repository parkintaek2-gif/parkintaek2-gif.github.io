# 색인은 무엇이 가르나 — 가설 셋을 세우고 셋 다 틀렸다

잰 날 2026-10-04 04:10~04:20 KST · 5번(총괄)

사장님이 「검색 색인, seo, geo효과는 언제 나타나기 시작하니?」라고 물으셔서
색인이 왜 막히는지 파고들었다. **가설 셋을 세웠고 셋 다 수가 뒤집었다.**
틀린 것을 적어 두는 것이 다음 사람에게 쓸모가 있다.

---

## 가설 ① 「지면끼리 겹쳐서 안 된다」 — 틀렸다

`check-page-sameness.mjs` 로 쟀다.

| 지면 | 겹침 | 색인 |
|---|---|---|
| `/group/pristin-v` | **86%** | ✅ 됐다 |
| `/born-on/12-07` | 79% | 🔴 안 됐다 |

**겹침이 더 심한 쪽이 색인됐다.** 겹침은 가르는 축이 아니다.

⚠ 그렇다고 겹침이 좋다는 뜻은 아니다. 다만 **색인의 까닭으로 삼을 수 없다.**

---

## 가설 ② 「들어오는 링크가 적어서 안 된다」 — 이것도 틀렸다

`check-inbound-links.mjs` 로 16,095장을 전수로 셌다.

| 지면 | 들어오는 링크 | 색인 |
|---|---|---|
| `/about` (KCW) | **3,016개** | 🔴 안 됐다 |
| `/titles` | 1,502개 | 🔴 안 됐다 |
| `/group/pristin-v` | **3개** | ✅ 됐다 |
| `/school/8321190` | 2개 | ✅ 됐다 |
| `/school/8321182` | 3개 | 🔴 안 됐다 |

**링크가 3,000개여도 안 되고, 2개여도 된다.**

---

## 🔴 가설 ③ 「klifemap 은 글로 들어가는 문이 없다」 — 이것도 틀렸다

이것은 **내가 2026-10-04 밤샘보고에 사장님께 올린 줄이고, 틀렸다.**

보고에 이렇게 적었다 — 「글 2,870장에 들어가는 문이 없었습니다 · 글 목록
지면에서 0개」. 04:15 에 **라이브를 직접 눌러 보니 사실이 아니었다.**

```
/content          첫 쪽에 글 20개 + 쪽 링크 «57쪽 전부»   ← 사슬이 아니라 평면이다
/content?lang=en  31쪽   ja 30쪽   zh 30쪽
```

세어 보면 ko 1,139 · en 620 · ja 600 · zh 600 = **2,959장.** 사이트맵의 2,918장과 맞는다.
**모든 글이 `/content` 에서 두세 홉 안에 닿고 있었다.**

### 왜 내 자는 「0개」라고 했나 — 자의 흠이다

```
check-inbound-links.mjs 는 «dist/ 안의 파일»을 읽는다
/content 는 파일이 아니라 server.js 523줄이 «그려서 내보내는» 지면이다
⇒ 자가 아예 못 보는 지면을 「없다」로 적었다
```

⚠ **메모리 「자를-먼저-의심한다-0이-나오면」을 또 밟았다.** 같은 밤에 두 번이다
(한 번은 사이트 접두사, 한 번은 이것). 0 이 나오면 자를 먼저 의심한다.

### 그래도 어제 한 일이 헛일은 아니다

`contents.html` 에 뚫은 글 링크 198개와 갈래 입구 17개는 **갈래별로 들어가는 새 길**이다
(`/content` 는 날짜순 한 줄뿐이었다). 다만 **그것이 색인 6% 의 까닭은 아니었다.**
처방이 해롭진 않으나 병을 짚은 것이 아니다.

```
⛔ 말할 수 없다   「겹쳐서 안 된다」·「링크가 적어서 안 된다」·「문이 없어서 안 된다」
                 셋 다 수가 안 받쳐 준다
⬜ 못 쟀다        구글이 «왜» 안 넣는지. 서치콘솔은 까닭을 한 줄로만 준다
```

남은 설명은 하나뿐인데, 그것은 우리가 어쩌지 못하는 쪽이다 —
**아직 구글이 안 온 것**이다. klifemap 은 새 .ai 도메인에 2,918장을 한꺼번에 내놓았다.

사장님이 2026-08-25 에 이미 말씀하셨다 —
> 「콘텐트가 차별화되고, 꾸준히 생산되는 거를 구글, 네이버가 감지할 때까지
>  어차피 시간이 걸려. **중간에 포기하지만 않으면 돼**」

내가 밤새 찾던 「막은 것」이 없을 수도 있다는 뜻이다.

## 이 글의 한계 — 0 으로 채우지 않는다

- **표본이 작다.** 사이트마다 2~8장씩만 물었다. URL 검사 API 에 하루 한도가 있다.
- **겹침은 세 장씩만 견줬다.** 366장 전체를 서로 견주려면 다른 자가 필요하다.
- 표본이 작으니 **「틀렸다」도 세게 말하지 않는다** — 다만 「이 수로는 못 세운다」는 분명하다.
- 100yearmap 의 `/major/…` 는 주소가 퍼센트 인코딩이라 **아예 못 쟀다.**

② 표본을 늘린다        URL 검사 한도를 날마다 나눠 쓰면 한 달에 전수에 가까워진다
