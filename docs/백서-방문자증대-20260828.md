## 2. 효과가 «잰 수로» 확인된 것

### ✅ ① 색인에 들어간 지면이 이틀 만에 절반에서 4분의 3으로 (5번)

구글 URL Inspection API 로 **같은 40장**을 두 번 물었습니다(표본을 새로 뽑지 않았습니다 —
새로 뽑으면 다른 지면을 재고 견주는 꼴이 됩니다).

| | 8월 25일 | 8월 27일 | 움직임 |
|---|---:|---:|---:|
| **들어갔다** | 21장 (52.5%) | **30장 (75.0%)** | **+9장** |
| **발견만**(주소는 아는데 안 넣음) | 18장 (45.0%) | 9장 (22.5%) | **−9장** |
| 구글이 모른다 | 1장 | 1장 | 0 |

⚠ 이 자는 ~9% 흔들립니다. 그런데 **18장 중 9장이 한 방향으로** 움직였습니다 — 흔들림으로
설명되는 크기가 아닙니다.
⛔ **어느 일이 효과를 냈는지는 못 가릅니다.** 그 사이에 넷을 같이 했습니다(사이트맵
`lastmod` 채우기 · 제목 줄이기 · 설명 줄이기 · IndexNow). **가장 그럴듯한 것은 `lastmod`**
입니다만 **짐작이고, 짐작이라고 적습니다.** 다음 회차에 하나씩 갈라 재겠습니다.

### ✅ ② 색인은 「지면」이 아니라 «갈래»로 갈립니다 (5번)

| 갈래 | 지면 수 | 표본 색인률 |
|---|---:|---:|
| `/born-on` (며칠에 태어난 스타) | 366장 | **20/20 = 100%** |
| `/group` (그룹) | 263장 | 16/20 = 80% |
| `/title` (작품) | 557장 | 14/20 = 70% |

⭐ 「우리 사이트가 색인이 안 된다」가 아니라 **「어떤 갈래는 스무 장이 스무 장 다 들어간다」**입니다.
사이트 평균(83%)만 보면 100%인 갈래와 70%인 갈래가 섞여 아무것도 안 보입니다.
⚠ **그래서 다음 일은 「지면을 더 내는 것」이 아니라 「잘되는 갈래를 늘리는 것」입니다.**

### ✅ ③ 손님은 «기사»를 읽습니다 — 대량 지면은 안 읽습니다 (5번)

| | 지면 수 | 노출 | 검색으로 온 사람의 체류 |
|---|---:|---:|---|
| `/person` (사람 지면) | **636장** | **0** | — |
| 기사(영어뉴스) | 몇 편 | 있음 | **107~530초 · 한 번에 5장까지** |

🔴 **636장을 만들었는데 검색에 한 번도 안 떴습니다.** 이 한 줄로 5번의 방향을
**지면 대량생산 → 영어뉴스(기사)** 로 돌렸습니다.

### ✅ ④ 틀린 기사를 라이브에서 걷어냈습니다 (6번)

| | 전 | 후 |
|---|---|---|
| 틀린 절대값이 실린 무역 기사 | **8편 라이브** | 내림 4편 = 404 · 다시 쓴 4편 = 200 |
| 틀린 헤드라인이 라이브에 남은 것 | 8편 | **0편** |

자료에 눈금이 끊긴 자리(2026-03 스케일브레이크)가 있어 절대값이 허깨비였습니다.
**「재 보고 안 되면 안 된다고 적는다」**를 그대로 한 것입니다 —
그리고 같은 일이 다시 나지 않도록 **검사(`check-trade-scale-break`)로 굳혔습니다.**

### ✅ ⑤ 「내 병목은 색인이 아니라 «순위»였다」 (6번)

```
/article 평균 순위 13.3위 = 구글 «2페이지»
```
색인은 되어 있는데 **1페이지에 못 올라가 아무도 안 누른 것**이었습니다.
⭐ 그래서 6번은 광역어를 버리고 **롱테일**(`korea trade with X` 61장)로 방향을 틀었습니다.
이 베팅은 아직 못 쟀고 **9/10에 잽니다.**

⚠ **이것이 5번의 발견(「색인이 안 된다」)과 다른 병목입니다.**
같은 「검색이 안 된다」라도 **유닛마다 막힌 자리가 다릅니다** — 갈라 재야 보입니다.

### ✅ ⑥ 체류는 유입과 따로 움직입니다 (6번)

```
SeoulMarkets — 2.27장/세션 · 241초. 유입은 네 유닛 중 꼴찌인데 «체류»는 2위
```
**사람이 적게 와도 온 사람은 오래 봅니다.** 상호링크와 차트가 든 것으로 보이나,
어느 것이 들었는지는 못 가릅니다.

## 3. ⭐ 해 봤는데 «효과가 없었던» 것 — 이 백서에서 가장 값진 칸

🔴 **③이 없으면 백서가 아니라 자랑입니다.** 안 된 것을 적어 두면 다른 유닛이 같은 곳에
시간을 안 씁니다. **그것이 이 문서를 만드는 값의 절반입니다.**

| 그럴듯했던 생각 | 재 봤더니 | 접었나 |
|---|---|---|
| **지면이 얇아서 색인이 안 된다** | 거꾸로였습니다 — `/title` 7,093자(가장 두꺼움) 색인률 **70%**, `/born-on` 1,322자(가장 얇음) **100%** | ⛔ **접음** |
| **자료가 적어서 색인이 안 된다** | 같은 표본 안에서 견줌 — 안 든 것 28.2자리 vs 든 것 29.9자리. 115자리짜리가 안 들어가고 3자리짜리가 들어감 | ⛔ **접음** |
| **안쪽 링크를 더 걸면 색인된다** | 2,717장을 훑어 셈 — 안 든 지면이 링크 23장·14장, **든 지면이 4장뿐** | ⛔ **접음** (다만 갈래를 나눔 — 아래) |
| **막다른 지면이 체류를 막는다** | 자를 세워 전 지면을 잼 — **막다른 지면이 0장.** 가설 자체가 틀림 | ⛔ **접음** |
| **`/title` 열 장을 깊게 해서 색인을 늘린다** | 사흘 뒤 대조군과 견줌 — **5/10 대 5/10, 갈림까지 똑같음** | ⚠ **이 정도 깊이는 접음.** 손댄 크기가 1%p 였으므로 「소용없다」가 아니라 **「이 정도로는 안 움직인다」** |
| **IndexNow 통보로 색인을 늘린다** | 2,716장 전부 통보 완료(안 알린 지면 0장). 그런데 4주간 노출 0인 지면이 **874장(71.5%)** | ⚠ **더 붓지 않음.** 색인은 통보가 아니라 «지면의 값»으로 들어감 |
| **첫 문을 위로 올리면 눌린다** | 「닿을 수 있나」와 「실제로 눌리나」는 다른 것이었음. 눌림을 못 재고 있음 | ⚠ **판정 보류** |
| **애드센스 검토 요청을 지금 넣는다** | 읽은 흔적 있는 손님이 하루 1.2명 — 반려 개연성이 큼 | ⚠ **미룸.** 사람이 먼저 온 뒤에 넣음 |
| **태그 허브 지면을 많이 내면 유입이 는다** (6번) | GSC 28일 **노출 0** — 갈래별로 갈라 보고서야 드러남 | ⛔ **지면으로는 값이 없음 확인.** 「지면이 아니라 자료」로 둘지 검토 중 |
| **월별 무역수지 「국면전환」 기사** (6번) | 자료에 눈금이 끊긴 자리(2026-03)가 있어 절대값이 허깨비 — **헤드라인이 틀림** | ⛔ **접음**(라이브에서 내림). 검사로 재발을 막음 |
| **제목을 고쳤으니 클릭이 오를 것** (6번) | 8/27 고침, 다음 날 아침 GSC 변화 **0** | ⚠ **안 접음** — 재크롤 지연. **「고쳤으니 오를 것」을 효과로 안 적음** |

⭐ **링크 가설에서 나온 갈래 나누기** — 이것이 전 유닛에 퍼졌습니다.
```
「구글이모른다」(발견 전)  → 링크가 약이다
「발견만」(발견 후 안 넣음) → 링크는 약이 아니다. 구글은 이미 주소를 안다 —
                            «가 보고 안 넣기로 한 것»이다
```

## 5. 「중복된 것」을 걷어내고 — 여러 유닛이 «따로» 부딪힌 같은 벽

사장님이 「중복된 것 빼고」라고 하셨습니다. 여러 유닛이 각자 부딪힌 것을 하나로 묶습니다.

| # | 같은 벽 | 누가 부딪혔나 | 그래서 정한 것 |
|---|---|---|---|
| ① | Direct 가 71~96% — 우리 자신을 손님으로 셌다 | 네 유닛 전부 | 손님은 **Organic Search 로만** 센다 |
| ② | 표본이 적은데 「효과 없음」이라 적었다 | 4번 (노출 88·클릭 0) | **노출 150** 전에는 판정하지 않는다 |
| ③ | 전문 용어로 제목을 달아 아무도 안 찾았다 | 4번(일주) · 6번(gini) · 5번(/person) | 제목은 **손님이 검색하는 말**로 단다 |
| ④ | 지면을 대량으로 냈는데 노출 0 | 5번(636장) · 6번(집중도) | 장수보다 **한 편의 깊이** |
| ⑤ | 새 지면이 색인에 안 들어간다 | 3번(4장) · 5번(9장) | 「구글이모른다」와 「발견만」을 **갈라서** 다룬다 |
| ⑥ | **자가 조용히 틀렸다** | 5번 3회 · 4번 1회 · 3번 1회 | 자를 세우면 **아는 참인 것**에 대 본다 |
| ⑦ | 「보냈다」와 「보낼 수 있다」를 안 갈랐다 | 5번 2회 | 성공이라 답하기 전에 **실제로 나갔는지**를 본다 |
| ⑧ | **자료에 눈금이 끊긴 자리를 못 보고 기사를 냈다** | 6번(무역 8편) · 3번(단위 이름이 거짓) | 시계열은 **끊긴 자리부터 찾고** 검사로 굳힌다 |
| ⑨ | **고쳤으니 오를 것이라고 적었다** | 6번 · 4번 | **재크롤 전에는 「효과」 칸에 안 적는다** |

### ⭐ 그런데 «병목은 유닛마다 달랐습니다» — 이것이 가장 값진 대조입니다

| 유닛 | 막힌 자리 | 잰 수 | 그래서 할 일 |

## 6. 이 백서에서 굳힌 «전사 규칙» 넷

말로 하는 규칙은 잊히므로 **전부 자가시험(검사)으로 굳혔습니다.**

```
① 손님은 Organic Search 로만 센다      Direct 에는 우리 자신과 봇이 섞인다
② 노출 150 전에는 판정하지 않는다       표본이 적으면 0클릭도 우연이다
③ 사람 수를 나눠서 「명」이라 안 적는다   나눈 값에는 「명꼴」을 붙인다
④ 자를 세우면 아는 참인 것에 대 본다     자가 조용한 것과 문제가 없는 것은 다르다
```

⚠ ③은 오늘 사장님께서 「**사람이 소숫점인게 이해가 안돼**」라고 지적하신 것입니다.
어제는 보고서만 고쳐서 **오늘 아침 같은 줄이 또 나왔습니다.** 자 **일곱 자리**를
고쳐야 끝났습니다 — **지적은 문장이 아니라 «그 문장을 만든 자»를 고쳐야 끝납니다.**

## 9. 마지막으로 — 정직하게

「효과 확인」 칸에 색인 말고는 채울 것이 없었습니다. 채우고 싶었지만 없는 것을 적지 않습니다.

> **「재 보고 안 된다고 적는 것도 결과다.」**

우리가 8월에 실제로 얻은 것은 **방문자가 아니라 「무엇을 재야 하는지」**입니다.
Direct 를 손님으로 세고 있었다는 것 · 표본이 모자란데 판정하고 있었다는 것 ·
전문 용어로 제목을 달고 있었다는 것 · **그럴듯한 가설 열이 재 보니 틀렸다는 것** ·
그리고 **막힌 자리가 유닛마다 달랐다는 것**(5번 색인 · 6번 순위 · 3번 발견 · 4번 클릭).
이 다섯을 8월에 몰랐다면 9월에도 같은 자리에서 같은 일을 반복했을 것입니다.

**9월 목표는 유닛당 하루 1,000명이고, 지금 가장 높은 3번이 13명꼴입니다.**
멀다는 것을 압니다. **중간에 포기하지 않겠습니다.**
