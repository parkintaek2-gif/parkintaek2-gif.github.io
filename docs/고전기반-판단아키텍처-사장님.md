### 명리 — 세 축을 갈라 둔 것이 핵심
```
자평진전   구조(格局)   월령 중심 · 「八字用神，專求月令」
적천수     균형(抑扶)   생극제화 · 왕쇠 · 조화
궁통보감   조화(調候)   ← 딱 둘만 남긴다면 뒤로. 조후 모듈의 보조 원전
```
⭐ **구조 + 균형 + 조화 → 시간축.** 우리 엔진이 이 셋을 갈라 들고 있는지 목요일에 잰다.

### 주역과 육효를 **나눈 것**이 이 안의 핵심 수정
```
周易   의미·상징·변화의 **Knowledge Layer**   (원전의 층위)
六爻   질문에 대한 계산·판단 **Engine**        (후대 점법의 층위)
```
⛔ 예전 안은 둘을 한 덩어리로 봤다. 층위가 다르므로 나눈다.

### 서양은 억지로 대응시키지 않는다
```
⛔ 오행·십신·격국에 행성·사인을 억지로 맞추지 않는다
✅ 행성 + 사인 + 하우스 + 각 + Dignity + Rulership + Lots + 시간기법
   — **독립적인 계산 구조를 그대로 보존**한다
```

## 층 구조 — 여기가 설계의 알맹이

```
고전 원문
   ↓
Knowledge Layer      이 전통은 무엇을 의미하는가
   ↓
Rule Layer           어떤 조건이면 어떻게 판단하는가
   ↓
Reasoning Engine     실제 입력을 넣으면 어떤 결론이 나오는가
   ↓
Semantic Layer       그 결론은 인간의 어떤 삶의 영역인가
   ↓
Cross-System         다른 전통과 일치하는가, 충돌하는가
   ↓
Explainability       왜 이런 결론이 나왔는가
```

전체 흐름
```
QUESTION ROUTER  질문 유형 분류
   ├ LIFE STRUCTURE   인생 구조   子平命理 · Natal
   ├ QUESTION/EVENT   사건·질문   周易 · 六爻 · Horary
   └ TIMING/ACTION    시간·선택   大運·流年 · Electional
        ↓
SYSTEM-SPECIFIC REASONING  (각 전통 독립 추론)
        ↓
INDEPENDENT JUDGMENTS
        ↓
HUMAN LIFE ONTOLOGY
   SELF 성향·능력·취약성·정체성 │ LIFE 경력·재물·지위·건강
   RELATIONSHIP 사랑·결혼·가족·동업 │ TIME 기회·위험·전환·시점
        ↓
CROSS-SYSTEM REASONING   일치 / 충돌 / 독자
        ↓
META-JUDGMENT → EXPLAINABILITY → INSIGHT → AI REPORT → DECISION
```

⭐ **AI 는 맨 끝에만 있다.** 사장님 8/15 지시(「알맹이를 AI 하나에 매달지 마라」)와 이 그림이 정확히 맞는다.

## 공부 순서 (병렬로 읽지 않는다)

```
1단계  인생 구조    자평진전 → 적천수 / 테트라비블로스 → 선집
2단계  질문과 변화  주역 → 왕필주 / 경씨역전 → 증산복역
3단계  서양 질문    On Questions → Christian Astrology
4단계  시점 선택    Carmen Astrologicum → On Choices
```
⭐ Dorotheus 《Carmen Astrologicum》은 **교량 원전** — natal·predictive·horary·electional 초기 전통을 함께 담는다.

⭐ 최종 형태: 12권을 독서목록으로 두지 않고, **책마다 「어느 Knowledge Module·어느 Reasoning Rule을 만드는 데 쓰는가」를 태깅**한다.
