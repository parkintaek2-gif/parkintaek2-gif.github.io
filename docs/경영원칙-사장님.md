## 2. 목표 — **낮추지 않는다**

> 「목표를 이루는게 현실적으로 어렵다 > **목표를 낮춘다(x), 방법을 바꾸거나 새 방법을 찾아
> 목표를 이룬다(o)**」

```
⛔ 「어려우니 600억으로 잡는다」 · 「2034년으로 미룬다」 · 「이 줄을 지운다」
⭐ 빠진 **방법의 이름**을 댄다. 못 대면 「아직 방법을 못 찾았다」고 적고 계속 찾는다
```
⭐ 「현실적으로 어렵다」는 **목표에 대한 판정이 아니라 지금 쥔 방법에 대한 판정**이다.
⚠ ⛔ 근거 없이 큰 수를 얹으라는 뜻이 아니다. **금액은 지키고 방법을 이름으로 댄다.**

## 3. 🔴 목표는 **한 번도 못 이루면 안 된다** — 가는 중에 바꾼다

> 「그래서 **목표가 단 한번도 실현을 못하면 안된다.** 실현 못할 것 같으면
> **과정 중에도 전략을 수정해** 목표를 실현해야 한다」

⛔ 기한이 끝나고 나서 「못 채웠습니다」를 적는 것은 늦다. **그때는 이미 못 이룬 것**이다.
⭐ 그래서 **가는 중에 잰다.** 못 갈 것 같으면 **그 자리에서 전략을 바꾼다.**

### 그래서 이렇게 잰다 — 기한의 절반과 4분의 3에서 본다

| 볼 때 | 그때 진도가 | 하는 것 |
|---|---|---|
| 기한의 **1/2** | 절반 미만 | ⭐ **전략을 바꾼다.** 같은 방법을 더 열심히 하지 않는다 |
| 기한의 **3/4** | 3/4 미만 | 🔴 **다른 방법을 하나 더 붙인다.** 이미 늦었으니 겹쳐서 친다 |
| 기한 당일 | 미달 | ⛔ 여기서 처음 알면 **재는 자가 없던 것**이다. 그것부터 고친다 |

⛔ **「열심히 했는데 안 됐다」는 답이 아니다.** 안 될 것을 언제 알았느냐가 답이다.

## 4. 낮춰 왔으면 — **숫자가 아니라 까닭을 캔다**

> 「낮춰온 계획 > **숫자만 고쳐 올린다는 안된다. 왜 낮춘 건지 원인을 분석해야 해답을 찾을 수 있다.**
> 수동적·수세적으로 하지 마라. **능동적·공격적으로 하라**」

```
⛔ 되돌려 보내고 숫자를 다시 받는다  → 까닭이 그대로 남아 다음 달에 또 낮춘다
⭐ 낮춘 자리마다 **왜 낮췄는지**를 캔다. 그 까닭이 곧 우리가 칠 곳이다
```

### 계획에 쓰지 않는 말
```
⛔ 「손님이 오면」 · 「기회가 되면」 · 「반응을 보고」 · 「안 되면 뺀다」   ← 기다리는 말
⭐ 「먼저 만들어 ○○에 보낸다」 · 「○월 ○일에 ○○를 친다」 · 「안 되면 ___ 로 바꾼다」
```

## 5. 상품 — **퀄리티를 높이거나 더 좋은 새 상품을 못 만들면 잘못 경영한 것**

> 「기존 계획 대비 업그레이드 된 상품이 없으면 잘못 경영한 거다」
> 🔴 (23:3x 다듬으심) 「**상품을 안 올리면이 아니다. 상품의 퀄리티를 높이거나
> 더 좋은 새 상품을 만들지 못하면 잘못 경영한 거다**」

⛔ 「몇 편 올렸나」가 아니다. **물건이 좋아졌나**다. 편수·게시 횟수로 잘했다고 말하지 않는다.

```
길은 둘뿐이다
  ① 지금 상품의 **퀄리티를 높인다**   더 정확 · 더 깊이 · 더 빨리 · 더 쓰기 쉽게
  ② **더 좋은 새 상품**을 만든다      지금 것보다 손님에게 값진 것. ⛔ 그냥 다른 것 말고 **더 좋은 것**

⛔ 같은 물건을 다르게 자르는 것은 ①도 ②도 아니다 (값만 바꾸기 · 손님만 바꾸기 · 곳 수만 늘리기)
⛔ 「새로 모을 자료가 없다」는 강점이 아니다 — 상품이 안 자란다는 뜻이다
```
⭐ 해마다 ① 또는 ②가 있어야 한다. 없는 해는 **그해가 잘못 경영한 해**다.

## 6. 계획은 **혼자 짜지 않는다** · 그리고 **대신 고쳐 주지 않는다**

> 「**혼자 짜지마라.** 비즈니스유닛들한테 계획을 받아 실현가능하게 만들라」
> 「**네가 직접 고치지 마라. 고치게 해라.** 고민해서 시장조사해서 전략을 달리하고 해답을 찾고
> **상품을 고도화·다양화**해 매출을 늘려라」

```
⛔ 2번이 답을 미리 적어 주지 않는다 — 적어 주면 그쪽은 고르기만 하고 그건 2번 계획이 된다
⭐ 2번은 **묻고 · 재고 · 어긋난 것을 짚는다.** 고치는 것은 그 자리에 앉은 사람이 한다
```

### 계획을 짜는 여섯 단
```
① 고민       지금 것이 왜 안 팔리는가. ⛔ 「아직 안 열어서」는 답이 아니다
② 시장조사   같은 것을 파는 곳 셋 · 값 · 무엇을 주고 안 주는지. ⛔ 짐작 금지, 본 곳 주소를 적는다
③ 전략       그들과 **같은 방식으로 안 할 길** 하나. ⛔ 「더 싸게」는 전략이 아니다
④ 해답       하려면 무엇이 있어야 하나. 있는 것/없는 것을 갈라 적고 **언제 만들지**까지
⑤ 고도화·다양화  ⛔ 둘 다. 고도화만 하면 손님이 안 늘고, 다양화만 하면 값이 안 오른다
⑥ 매출       2027·2029·2032 에 **손님 수 × 값**. ⛔ 총액만 적지 않는다
```
