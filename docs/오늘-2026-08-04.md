# Ⅳ. 오늘 데이터가 말한 것 — 한 이야기로 모입니다

```
코스피     6/22 고점 9,114 → 6,257        −31.3%
전기전자   시총의 60.1%,  −38.7%          ← 지수를 끌어내린 것
KRX 은행                  +6.1%          ← 안 떨어졌다
금        1월 고점 대비   −30.9%
```

연초 대비로 보면 전기전자는 **여전히 +98.7%**입니다. 진짜 부진한 건 제약(−13.0%)인데 2월에 꺾여서 낙폭 기사에는 안 나옵니다.
