## Ⅲ. API 키 — **값은 `.env` 에 있다. 문서에 옮겨 적지 않는다**

🔴 **이 저장소는 공개다.** 키 값을 커밋하면 전 세계가 읽는다.
당신은 **같은 PC** 에서 돌므로 같은 `.env` 를 읽으면 된다.

```
C:\Users\USER\Documents\GitHub\dataeconomics\.env
```

### 3-1. 당신이 쓸 키

| 이름 | 무엇 | 상태 |
|---|---|---|
| `RIOT_API_KEY` | Riot 랭크 사다리 | ⚠ **24시간마다 만료**. 아래 3-2 |

읽는 법은 기존 수집기를 그대로 베낀다 (`scripts/collect-riot-ladder.mjs` 참고).

## Ⅸ. 일하는 법 — 오늘 내가 값을 치른 것들

전문은 `docs/일하는-법-최종본.md`. **여기 있는 건 오늘 실제로 당한 것만.**

```
· **규칙을 두 벌 두지 않는다.** 판정 규칙을 두 군데 적으면 어느 쪽이 맞는지 아무도 모른다
  오늘 나는 같은 실수를 **네 번** 했다 (합계 고르기·이상점검·파일명 자리·검증 스크립트)
  → 정본 하나를 `export` 해서 **import 해 쓴다**

· **검사가 헛도는지 확인한다.** 일부러 틀리게 해 보고 **실제로 실패하는지** 본다
  오늘 라우팅 시험이 **두 번** 헛돌았다 (포트 재사용 · fetch 의 Host 헤더)

· **도구가 입력을 바꾼다.** 윈도 셸은 한글을 CP949 로, fetch 는 Host 를 버린다
  둘 다 **오류가 안 난다.** 없는 병을 고치거나 있는 병을 못 본다

· **원본을 같이 저장한다.** 파서를 고쳤을 때 다시 안 받으려고
  오늘 원문이 없어 2,921번을 다시 불렀고, 있어서 **0번**으로 고쳤다

· **없는 것을 0 으로 만들지 않는다.** null 로 둔다
  0 으로 하면 순위 맨 아래가 오염되고 평균이 틀어진다

  주식수로는 1/4 인 걸 알았다. 그대로 썼으면 틀린 기사가 나갔다

· **재 보고 안 된다고 적는 것도 결과다.** 억지로 만들어 내지 않는다
```
