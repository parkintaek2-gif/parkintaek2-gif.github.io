## 0. 먼저 — **이용허락범위를 보고 시작했다**

```
https://www.hrd4u.or.kr/hrd4u_new/contents.do?menuNo=0613   저작권보호정책
```
🔴 **공공누리(KOGL) 표시가 없다.** 적혀 있는 것은 이것뿐이다 —

> 「한국산업인력공단 HRD4U 홈페이지의 내용은 저작권법에 의한 보호를 받는 저작물로서,
>   이에 대한 무단복제 및 배포를 원칙적으로 금합니다.」

허락받는 길은 **① 공단과 별도 협의 ② 서면 허락 ③ 출처 표시**뿐이고, 창구는
공단 미디어방송부 ☎ 052-714-8294 다.

⭐ 그래서 이 자료는 **두 가지를 갈라 두었다** —
```
받아서 읽는 것 (조사·분석)      ✅ 했다. 공개된 지면에서 로그인 없이 받았다
지면에 옮겨 싣는 것 (재배포)    ⛔ 아직 안 한다. 허락을 받고서 한다
```
🖐 **사장님/2번 손** — 백년지도에 이 숫자를 쓰려면 공단 서면 허락이 필요하다.
   숫자(사실) 자체는 저작권 대상이 아니지만, **표·그림·문장을 그대로 옮기는 것은 다르다.**
