## Ⅲ. 무료 상품 — 🔴 **없다. 공개 지면이 5장이 전부다**

### 3-1. 잰 방법과 결과

```

⇒ **FnGuide 의 공개 웹 표면은 5장이다.** 나머지 전부가 로그인 뒤에 있다.

### 3-2. 이것이 뜻하는 것 — 우리에게 열린 자리

```
검색으로 들어올 지면이 5장뿐이다 ⇒ FnGuide 는 «검색 유입으로 안 자라는» 회사다
무료 층이 없다              ⇒ 값을 알아보러 온 사람이 «써 보지 못하고» 나간다
약관에 무료 체험 «가능» 조항만 있다  ⇒ 상시 무료 티어는 운영하지 않는다

⭐ 우리는 반대로 간다 — **무료·색인되는 지면을 넓게 깔고, 그 위에 유료를 얹는다.**

### 6-4. 🔴 한경컨센서스는 **소급이 안 된다** — 오늘 재서 알았다

「창을 365일로 넓히면 종목 커버가 늘어나나」를 실제로 돌려서 쟀다. **안 늘어난다.**

| 우리가 요청한 창 | 실제로 온 날짜 범위 | 건수 | 쪽 | 종목 | 증권사 |
|---|---|---|---|---|---|
| 31일 (2026-08-08~09-08) | 2026-08-10 ~ 09-08 (21일) | 623 | 13 | 165 | 12 |
| **365일** (2025-09-09~2026-09-09) | **2026-08-10 ~ 09-09 (22일)** | **624** | **13** | **165** | **12** |

⇒ **365일을 달라고 해도 같은 30일치가 온다.** 지면이 창을 자기가 정한다(수집기 출력도
그것을 적는다 — 「이 창은 지면이 정한 것이다」). 13쪽·약 624건이 천장이다.

🔴 **그래서 한경컨센서스는 「아카이빙은 하루도 빠뜨리지 않는다」 목록에 들어가야 한다.**
지금까지 그 목록에 없었다. 한 달이 지나면 그날치는 **영영 못 받는다.**
목표주가를 바꾼 105건 같은 것은 그날 안 받으면 끝이다.
✅ 이 문서를 쓰면서 `CLAUDE.md` 와 `docs/인계-현재상태.md` 의 아카이빙 목록에 넣었다.

### 6-5. 그래서 FnGuide 를 얼마나 덮나 — 정직하게

```
FnConsensus 가 말하는 커버리지   「1,000여개 상장 기업」
한경컨센서스 30일 실측           165 종목 (목표주가가 붙은 것은 135 종목) · 12 증권사
                              ⇒ 종목 기준 약 16.5% (목표주가 기준 약 13.5%)
```

🔴 **한경컨센서스만으로는 FnConsensus 를 대체하지 못한다.** 까닭이 분명하다 —
한경컨센서스는 **한경에 리포트를 «주는» 12개 증권사만** 싣는다. 대형사(미래에셋·한국투자·
NH·삼성·KB 등)가 빠져 있다. FnGuide 는 그 대형사와 개별 제휴로 받는다. **그 제휴가 해자다.**

✅ 그러나 **덮이는 것이 분명히 있다.** 그리고 그것이 우리가 팔 수 있는 축이다.

```
✅ 목표주가의 «변화»            105건/30일 — 올림·내림·그대로가 판정돼 있다
✅ 애널리스트 이름              181명 · 621/624건에 붙어 있다 — 사람 축이 살아 있다
                              (FnGuide 도 이 축으로 랭킹을 만든다)
✅ 증권사별 발행량              12곳의 리포트 생산량이 그대로 세어진다
✅ 갈래(기업·산업·시장·경제·파생)   리포트가 어디에 쏠리는가
⬜ 실적 추정치(매출·영업이익)    목록에 없다 — PDF 안에 있고 우리는 PDF 를 쓰지 않는다. **못 쟀다**
```

⭐ 축을 바꿔서 보면 커버율이 달라진다. **종목 커버는 16.5% 로 얇지만, 애널리스트 커버는
181명이고 우리 손에 «이름과 그 사람이 바꾼 목표주가»가 함께 있다.** FnGuide 가 「컨센서스
랭킹」으로 파는 것이 바로 이 축이다. 얇은 축으로 싸우지 않고 두꺼운 축으로 간다.

### 6-6. 한경컨센서스에서 «아직 안 받고 있는» 축 — 2번에게 맡길 것

지면에서 확인한 갈래 단추: **전체 · 기업 · 산업 · 시장 · 경제 · 파생 · 애널리스트**

```
🔴 「애널리스트」 축을 우리가 안 받고 있다 — 사람별 지면이 따로 있다
🔴 매일 받아야 한다 — 소급이 안 된다(6-4). 지금은 사람이 생각날 때 돌리고 있었다
🟡 「상하향 리포트」·「실적속보」에 해당하는 목록이 한경에도 있나
✅ 창 넓히기는 «끝났다» — 재 봤고, 안 늘어난다(6-4). 2번이 다시 시도할 필요 없다
```

### 7-2. 이들의 약점 — 우리가 파고들 곳

```
1. 원천이 남의 것이다
   컨센서스 여섯 곳이 사실상 Refinitiv 한 우물을 나눠 쓴다.
   ⇒ Refinitiv 의 한국 커버리지가 곧 그들의 한계다. 중소형주가 얇다.

2. 「사람」 축이 없다
   전부 «재무»를 판다. 근속·급여·성별격차·임원 재직기간·학력을 파는 곳이 없다.
   ⇒ 우리 강령이 못박은 자리 그대로다 — 「그들은 재무를, 우리는 사람을」

3. 한국 특유의 축이 없다
   대차거래 · 신용융자 · 증시주변자금 · 의무보호예수 · 메자닌 CB·BW · 지분공시 세부.
   이것들은 «한국 제도»에서만 나오는 수라 글로벌 벤더의 표에 칸이 없다.

4. 검색으로 안 잡힌다
   MarketScreener 류는 종목 지면이 수만 장이지만, «한국 제도 용어»를 영어로 설명한
   지면이 없다. 「What is a Korean mezzanine CB?」에 답하는 영문 지면이 비어 있다.
```

⭐ 결론 — **실시간·틱은 우리 자리가 아니다.** 우리 자리는 **한국 제도에서만 나오는 수를,
영어로, 사람 축까지 붙여서** 내는 것이다. 그 자리는 지금 비어 있다.

### 8-2. 그러면 우리가 일본어·중국어로 내야 하나 — 데이터로 답한다

「한국 주식을 누가 들고 있나」로 재는 것이 맞다. 금융감독원 「외국인 증권투자 동향」 —

```
2026-01  외국인 상장주식 보유 1,701.4조원 = 시가총액의 32.0%
         (상장채권 330.5조원 포함 총 2,031.9조원)
2026-05  보유 비중 — 미국 41.7% · 유럽 31.7% · 아시아 13.9%
```

```
미국 41.7% + 유럽 31.7% = 73.4%   →  영어 하나로 닿는다
아시아 전체가 13.9%                →  그 안에서 일본·중국·싱가포르·홍콩이 나뉜다
                                   ⇒ 일본어·중국어 각각은 한 자릿수 %
```

⚠ 정직하게 붙인다 — 이 수는 **보관국 기준**이다. 룩셈부르크·아일랜드가 크게 잡히는 것은
펀드 설립지 때문이고, 실제 결정을 누가 하는지와는 다르다. **그래서 이 수는 「영어가 압도적으로
크다」까지만 말할 수 있고, 「일본 자금이 정확히 몇 %」는 말할 수 없다.** 그것은 못 쟀다.

### 8-3. 그래서 정한 것

```
지금       영어 하나에 힘을 모은다. 73.4% 가 영어로 닿고, 그 자리가 비어 있다
나중       유료 상품이 «영어로» 실제로 팔린 뒤에 일본어를 검토한다
           까닭: 일본은 QUICK 이 이미 자리를 잡아 «우리 자료의 일본어판»이 아니라
                «일본 투자자용 한국 자료»라는 좁은 칸으로 들어가게 된다
⛔ 지금 세 언어로 벌리지 않는다 — 하루 발행 몫이 정해져 있고, 힘이 흩어지면
   영어 지면의 두께가 얇아진다. 두께가 곧 검색 유입이다
```

## Ⅸ. 🔴 콘셉트는 그대로, 구현·형식·내용은 다르게 (사장님 지시)

> 「fn가이드 유료 상품의 콘셉트는 그대로 갖고 오되, **구현 방식-결과물 형식과 내용에는 차이를 둬야함**」

### 9-1. 그대로 가져오는 것 — 콘셉트

```
1. 상품을 «축»으로 가른다      리포트 / 컨센서스 / 지분 / 시계열 / 스크리너 / 메자닌
2. 축마다 값이 다르다          귀한 축이 비싸다 (FnGuide: 리서치 33만 ↔ 지분 11만)
3. 정기결제로 판다             월·연 두 갈래
4. 맛보기 층을 둔다            FnGuide 의 1일권 자리
5. 개인용과 기관용을 나눈다     www(개인) ↔ corp(기관)
```

### 9-2. 반드시 달라야 하는 것 — 구현 방식·형식·내용

| 항목 | FnGuide | **SeoulMarkets (우리)** | 왜 다르게 하나 |
|---|---|---|---|
| **언어** | 한국어 전용 | **영어** | 비어 있는 자리다 (Ⅳ) |

| **못 잰 것** | 표에 안 보임 | **「못 쟀다」를 칸에 적는다.** 0 으로 안 채운다 | 강령 |
| **연간권** | 월×12 (할인 0) | **연간에 실제 할인을 준다** | 할인 없는 연간권은 해지를 막는 장치다. 우리는 그 방식으로 안 판다 |
| **환불** | 7일·무이용 조건, 1일권 불가 | **더 넓게 준다** | 신뢰가 우리 자산이다. 우리는 아직 이름이 없다 |
| **자문** | — | **투자자문 아님을 모든 지면에** | YMYL · 미국 독자 |

⭐ 한 줄로 — **FnGuide 는 「한국어 단말을 파는 회사」다. 우리는 「영문 데이터 파일을 파는 회사」다.**
콘셉트(축·층·정기결제)는 같고, 손에 쥐어지는 물건이 다르다.
