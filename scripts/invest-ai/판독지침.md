# 투자AI ①판독층 — 무인 판독 지침 (크론이 세션을 깨우면 이 절차를 따른다)

**판독 주체 = 이 Claude Code 세션.** 별도 API 키가 아니라, 크론이 세션을 깨우고 세션이 읽는다.
자리지킴·2번소통 크론과 같은 방식이다. 사람 손 없이, 매일.

## 절차 (매일 1회, 크론 「투자AI 뉴스판독」이 깨울 때)

1. `cd C:\Users\USER\Documents\GitHub\dataeconomics && git pull -q`
2. **구조화 원천부터(LLM 불요).** 오늘 새로 뜬 것:
   - DART 공시(opendart.fss.or.kr) — 실적·가이던스·주요사항. 이미 표·숫자라 규칙으로 신호화.
   - KOSIS/한은/관세청 — 통계 갱신. 값 자체가 신호.
3. **자유 텍스트(세션이 읽어 판단).** 공개·무로그인 영어/한국어 경제 헤드라인 소수(연합·한경 영문 등).
   - WebSearch/WebFetch로 «공개 페이지»만. 로그인·유료·JS전용은 «못 읽음»으로 두고 짐작 안 채운다(신조).
4. 읽은 것을 **신호 레코드**로 만든다(스키마 = `lib-signal.mjs` §3):
   - `ts`=원문 발표시각, `source`/`sourceId`=되짚을 수 있게, `entity{market,code}`(단일종목 확신 없으면 시장/지수 코드: KR/KOSPI 등 매크로 신호로), `kind`, `direction±1/0`, `strength0~3`, `horizon`(일), `evidence`=원문 짧은 인용, `model`=판독한 모델·버전.
5. **저장:** `node scripts/invest-ai/signal-store.mjs <YYYYMMDD> '[신호배열]'` — 멱등(같은 sourceId 재실행해도 안 겹침).
6. **매매층 확인(선택):** `node scripts/invest-ai/run-paper.mjs src/data/invest-ai/signals-<YYYYMMDD>.jsonl` → ②③가 포지션·한도 판정, 감사원장 1줄.
7. 커밋: 내 경로만 add(⛔ add -A 금지) → push. 메모에 [진행] 한 줄.

## ⛔ 못박는 것
- **시세 예측·개인 투자조언 아니다.** 신호는 «무슨 일이 있었나»의 구조화 기록이지 매수·매도 권유가 아니다.
- **근거 없는 신호 안 쌓는다.** evidence(원문 인용)·sourceId 없으면 저장소가 거부한다.
- **못 읽으면 못 읽었다고.** 0으로 채우거나 짐작으로 direction을 정하지 않는다.
- **판단은 규칙(②③), LLM(세션)은 읽기만.** 돈이 움직이는 자리엔 세션이 손대지 않는다.
- 절대시세·FSC 제4유형(9/9) 대상 API는 안 쓴다. 자체 규칙·공개 원천만.
